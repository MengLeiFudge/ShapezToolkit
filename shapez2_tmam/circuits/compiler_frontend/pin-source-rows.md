# 顶针候选五层封存

将 `pin-source-rows.spz2bp` 与五层行读取器 `pin-row-reader.spz2bp` 合装。封存控制锁存本次顶盖参数，依次请求 `0`～`4` 层。五层全部读回后才发布整组。合法空层保留为空信号，不影响整组有效位。

| 信号 | 频道 | 用法 |
| --- | ---: | --- |
| `enable` | 1702280 | 换组前置 0 满 96 信号刻，输入稳定后置 1 |
| 候选 `ready` | 1701858 | 置 1 表示候选已冻结，候选的 `advance` 保持 0 |
| `mode` | 1702281 | 1 生成最大族模板，0 生成成员顶盖 |
| `crystal_mask` | 1702282 | 0～15，最低位对应 q0 |
| `members` | 1702283～1702286 | q0～q3。成员模式下，掩码外的列取 0 空、1 `Cu`、2 合法针 |
| 整组 `ready` | 1702287 | 1 表示五层全部读回 |
| 整组 `valid` | 1702288 | 1 表示整组合法，可读取五行 |
| 封存五行 | 1702289～1702293 | 由底到顶直接读取，合法空层仍为空 |

启动前稳定顶盖参数，保持至少到启动后 96 信号刻，使其进入锁存。保持冻结候选及 `1701200`～`1701204` 的原目标行，直到下游读完封存结果。封存输出使用独立频道，闭包按 `1702289`～`1702293` 由底到顶取行。

每层启动前先让读取器复位 120 信号刻并看到旧 `ready=0`。启动后等待该层 `ready=1` 再捕获形状与有效位。整组预留 71,664 信号刻，以整组 `ready=1` 为采样条件。若某层不合法，整组 `ready=1`、`valid=0`，五行为空。封存控制将读取器的 `1702200`～`1702207` 作为专用请求口，回读 `1702208`～`1702210`。

关闭 `enable` 或候选 `ready` 撤销都会清除已发布的五行和状态。候选在一轮中撤销后，先将封存控制复位，再启动下一组。采样时同时确认候选仍处于冻结状态。

从仓库根目录重导控制蓝图与同名频道表。

```powershell
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_source_rows `
  shapez2_tmam/circuits/compiler_frontend/pin-row-reader.json `
  --output shapez2_tmam/circuits/compiler_frontend/pin-source-rows.spz2bp
```

封存控制占 21 块平台、19,738 个建筑。原生离线合装按板内同拍、无线 12 信号刻回放。目标 `------P-:------Ru` 封存为 `------Ru`、三层有效空行和顶盖 `CuCuCucr`，启动后 71,112 信号刻就绪。第二份冻结输入核对了 `crP-cr--`、合法空顶盖及非法顶盖。启动后修改顶盖参数、撤销已封存候选、读取中撤销再恢复均已核对。游戏内联动待验收。
