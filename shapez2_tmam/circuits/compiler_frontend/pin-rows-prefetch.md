# 顶针前态低四行预取

四列候选冻结后，本件用现有 `pin-row-reader` 依次读取第 0～3 层，原色行和 `prefetch_ready` 同时发布。低四行保持到撤销四列候选。每次顶盖获准后，同一读取器只读第 4 层，再按原五层封存接口发布完整前态。

```powershell
$inputDir = 'shapez2_tmam/blueprints/验收/电路/顶针逆推'
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_rows_prefetch `
  "$inputDir/pin-row-reader.json" "$inputDir/pin-source-rows.json" `
  --output pin-rows-prefetch.spz2bp
```

用本件替换旧 `pin-source-rows.spz2bp`，保留 `pin-row-reader.spz2bp`。两版封存控制占用同一组读行器发送频道。目标原色五行仍接现有读取器 1701200–1701204，图像条件所需的 1704304–1704308 由上层接目标行。先让目标和冻结四槽材料稳定，再置候选就绪。

| 频道 | 信号与接法 |
| --- | --- |
| 1701858 | 四列 `candidate_ready`。为 1 时预取并保持，换槽时清零至少 96 信号 tick。 |
| 1704300–1704303 / 1704309 | 原色低四行及 `prefetch_ready`，从底到顶。空层保留空信号。 |
| 1702280 | 顶盖封存请求。换模板或成员前清零至少 96 tick，再用新参数置 1。 |
| 1702281–1702286 | 模式、晶体掩码及 q0～q3 三值参数，保持到当前顶盖封存结束。 |
| 1702287 / 1702288 | 五层规则沿用 `ready` 和 `valid`。非法参数返回 `ready=1, valid=0`。 |
| 1702289–1702293 | 五层封存原色行，从底到顶。 |

离线回放使用原生读取器和两份冻结四槽。含晶族读取 0、1、2、3 后，同槽模板、成员及非法参数请求各只启动一次第 4 层。低四行在三次请求间保持，撤销四槽后清空。第二份候选的三个空层以空信号发布。模型为板内组合、无线固定 12 信号 tick。

控制件共 24 块平台、20,814 个建筑。低四行等待预算为 61,680 tick，取第五层为 9,948 tick。游戏内时序待验。
