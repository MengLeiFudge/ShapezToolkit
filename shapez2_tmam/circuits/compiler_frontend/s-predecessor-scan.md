# S 前态四列枚举

样件固定目标 `CuRgSbWm:cr------`。原生四列计数器从 `(2,0,0,0)` 枚举到 `(2,1,1,1)`，`q3` 最快。生成器按 `Solver4._predecessors` 计算晶体和堆叠前缀闭包要求的下界，逐列取非空格数和 `--limits` 的较小值作为上界。每个候选保留各列最底的指定数量非空格，同一格的颜色、种类和原层号都保留。五层分别输出，层内直接选用原色常量。

```sh
python -m shapez2_tmam.circuits.compiler_frontend.s_predecessor_scan 'CuRgSbWm:cr------' --output s-predecessor-scan.spz2bp
```

更换目标或各列上界时重导。`--limits 5 5 5 5` 是默认值，按 `q0` 到 `q3` 排列。`--channel-base` 可移动整段频道。样件的蓝图和同名接口表分别为 [s-predecessor-scan.spz2bp](s-predecessor-scan.spz2bp) 和 [s-predecessor-scan.json](s-predecessor-scan.json)。

| 频道 | 信号 | 接法 |
| --- | --- | --- |
| 1703400 | `enable` | 保持 `0` 至少 480 信号 tick 完成复位，再置 `1` 开始。 |
| 1703401 | `advance` | 等 `ready=1`，读完当前候选后置 `1`。见 `ready=0` 或 `exhausted=1` 后恢复 `0`。持续高电平只确认一笔。 |
| 1703402 | `ready` | 为 `1` 时读取五行和四个计数。有效候选保持到 `advance` 或复位。 |
| 1703403 | `exhausted` | 末项已确认，或范围内没有非空候选。保持到复位。 |
| 1703404–1703408 | `rows` | 底层到顶层的原色单层。空层传原生空信号。 |
| 1703409–1703412 | `counts` | `q0` 到 `q3` 的保留数，`0` 是整数信号。 |

整件批量导入或完整重载，保持固定接线和频道独占。时序沿用板内无环、无线固定 12 signal tick 的模型。每次更新给行选择和计数状态 480 tick 稳定时间，调用方按 `ready` 取数。样件预留 1703400–1703499。

`--limits` 可接前置裁剪所得的逐列上界。候选的接地、尾料锚定及后续可制作性由上层在 `ready` 时判断。过滤失败用同一个 `advance` 继续。接受时保持 `advance=0` 可继续读取同一候选。

| 原生离线回放 | 原始候选 | 经同一接地和尾料判据后的候选 |
| --- | ---: | ---: |
| 固定样件，保留红晶和完整末项 | 8 | 8 |
| 单层四色，四列进位并跳过全空项 | 15 | 15 |
| 有空底格和中间空层，保留原层位 | 2 | 0 |
| 上界低于保晶下界 | 0 | 0 |
| 各列上界均为零 | 0 | 0 |

五组的计数和五层行均按 Python 遍历顺序逐项一致。过滤结果与 `Solver4._predecessors` 一致。另核对复位重跑、上次确认信号仍为高电平以及末项确认。固定样件为 15 块平台、15,814 个建筑，重导的蓝图及接口表逐字节一致。
