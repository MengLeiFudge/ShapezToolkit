# 顶针前态五层读取

冻结一份四列候选后，按层号 `0`～`4` 请求前态原色行。下部四层保留目标的形状和颜色，第五层按晶体掩码生成族模板或成员顶盖。五层共用选列、四格保存和拼行电路。

导入 `pin-row-reader.spz2bp`，接四列候选样件与五层原色读取。两个输入对应同一目标和切向。模块内的选列、标签、顶盖许可和拼行频道都在 `1702200`～`1702279` 范围内。

| 信号 | 频道 | 取值 |
| --- | ---: | --- |
| `enable` | 1702200 | 1 启动当前请求，0 复位 |
| `level` | 1702201 | 0 为底层，4 为顶盖 |
| `mode` | 1702202 | 顶盖取 1 生成模板、0 生成成员 |
| `crystal_mask` | 1702203 | 顶盖晶体掩码 0～15，最低位对应 q0 |
| `members` | 1702204～1702207 | 成员模式下，掩码外的 q0～q3 分别取 0 空格、1 `Cu`、2 合法针 |
| 原目标五层原色行 | 1701200～1701204 | 由底到顶，空层发空信号 |
| 四列候选 `ready` | 1701858 | 1 时读取冻结的槽号与材料，四列频道沿用候选接口 |
| 初始标签 | 1702250 | 留空 |
| `ready` | 1702208 | 1 表示本层已读完 |
| `valid` | 1702209 | 1 表示本层合法，包括整行为空 |
| `row` | 1702210 | 有效时提供原生形状，整行为空时发空信号 |

按以下顺序读取同一候选的各层。

1. 保持候选的 `advance=0`，确认候选 `ready=1`。
2. 每次请求前保持行读取器 `enable=0` 至少 96 信号刻。设置层号和本层参数，输入稳定后置 `enable=1`，保持至本层读回。
3. 层号 0～3 预留 15,192 信号刻，层号 4 预留 9,720 信号刻。采样时检查 `ready=1` 与 `valid`，再读取 `row`。换层回到第 2 步。
4. 读完所需层后再推进候选。候选 `ready` 撤销会清除行读取状态。

顶盖模板和成员都在掩码列放红晶 `cr`，并检查该列是否允许。模板在其余列放 `Cu`，成员按 `members` 选格。掩码须由上层按整形接触条件选择。若某格许可不满足，本层返回 `ready=1`、`valid=0`。越界层号、越界掩码或未知顶盖模式会保持 `ready=0`。

在仓库根目录重导蓝图与同名频道表。

```powershell
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_row_reader `
  shapez2_tmam/blueprints/验收/电路/顶针逆推 `
  shapez2_tmam/blueprints/验收/电路/原层读取/read-five-rows.json `
  --output shapez2_tmam/circuits/compiler_frontend/pin-row-reader.spz2bp
```

样件占 38 块平台、40,863 个建筑。原生离线回放把已发布的四列枚举样件与五层读取器合装，目标 `------P-:------Ru` 冻结槽号 `(0, 0, 0, 0)` 后，依次读得 `------Ru`、三个有效空行和掩码 `8` 的顶盖 `CuCuCucr`。另一组冻结列输入核对了两层原色、掩码 `5` 的模板 `crCucrCu`、成员 `crP-cr--` 和再读底层。回放按板内同拍、无线 12 信号刻计算，下部行和顶盖分别在 15,120 和 9,660 信号刻就绪，游戏内联动待验收。
