# 顶针逆推的第五层顶盖

读取四列已冻结的来源候选，使用共用的逐列推进逻辑检查晶体和针的许可，再把四格合成第五层。蓝图包含选列、顶盖许可和拼行模块。合装时只保留一份共用频道模块，以同名 JSON 的 `channels` 为准。

```powershell
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_cap_row 'shapez2_tmam/blueprints/验收/电路/顶针逆推' --output shapez2_tmam/circuits/compiler_frontend/pin-cap-row.spz2bp
```

源码复用 `pin_candidate_row.py`。导出生成蓝图和同名频道表，共 23 块平台、26,065 个建筑。

| 信号 | 频道 | 取值 |
| --- | ---: | --- |
| 启用 | 1701940 | 1 开始，0 复位 |
| 模式 | 1701941 | 1 生成最大族模板，0 生成成员顶层 |
| 晶体掩码 | 1701942 | 0～15，最低位对应 q0 |
| 成员选格 | 1701943～1701946 | q0～q3，未掩码列取 0 空格、1 `Cu`、2 合法针 |
| 冻结候选就绪 | 1701858 | 1 表示候选可读 |
| 完成 | 1701947 | 1 表示四列已读完 |
| 有效 | 1701948 | 1 表示四格均合法 |
| 顶盖行 | 1701949 | 有效时发布原生形状，整行空时为空信号 |

两个模式都在掩码列放红晶 `cr` 并验证该列许可。模板在其余列放 `Cu`。成员模式读取其余列的选格。族的整形接触条件由上层在选择掩码时检查。

换候选或选格前关闭启用并保持至少 96 信号 tick。先稳定输入与冻结候选，再启用并等完成。每列分配 1680 tick 的准备时间。从启用到读回预留 8244 tick，结果保持到复位。

原生蓝图离线回放使用前三列顶格为 `Ru`、第四列全空的冻结候选。掩码 `5` 生成 `crCucrCu`，同一掩码下令 q1 取针、q3 取空得到 `crP-cr--`。全空成员返回完成与有效均为 1，行信号为空。第四列选禁止的针或晶体时，完成为 1、有效为 0。
