# 尾针搜索当前节点输入

导入 `tail-node-inputs.spz2bp`，把当前节点五行和已经通过 S 筛选的候选五行分别接入。默认导出包括两部分，共 28 块平台。用 `--part target` 或 `--part candidate` 可单独导出对应部分。组合版及其分件使用同一组频道，每组只安装一次。

```powershell
py -B -m shapez2_tmam.circuits.compiler_frontend.tail_node_inputs `
  --output shapez2_tmam/circuits/compiler_frontend/tail-node-inputs.spz2bp
```

| 部分 | 输入 | 输出 | 采样条件 |
| --- | --- | --- | --- |
| 当前节点 | `1705350–54` 原色五行，`1705330` 预检请求 | `1703509–12` 四列 S 上界，`1705356` 顶针总许可 | 原色五行稳定且请求为 `1` 后保持 1968 信号 tick。`1705531=1` 表示准备到时。 |
| S 候选 | `1703513–17` 原色五行，`1704802` S ready | `1701842–45` 原向四列材料字 | S ready 为 `1` 且五行稳定至少 1152 信号 tick 后，可由主控启动 `1705333`。 |

五行都按底到顶输入，空行使用空信号。上界直接采用 `pin_prefix_limit`，`-1` 表示该列排除。总许可要求四列 A 通过、所有上界非负且至少存在一层晶体。诊断口 `1705525–28` 是四列 A，`1705530` 是四列 A 的合取，`1705529` 表示存在最低晶层。主控另合并共享 G 扫描及剩余顶针预算。预检请求拉低后，目标五行保持原值即可在 S 阶段继续读取许可和上界。换节点时撤销预检请求满 48 tick，再发下一次请求。

候选材料字以 `Cu`、`Ru`、`Su`、`Wu` 分别表示空格、普通块、针、晶体，五层标记始终保持原层位。S ready 撤销后等待 24 tick，材料字回到空信号。使用本件时，原图读列器需要让出 `1701842–45`。主控把当前节点五行转接到 S 枚举的 `1703504–08`，并负责 S 枚举和顶针子件的启停。

离线回放按板内同拍、无线 12 信号 tick 计算。原生五组上界与列 A 输出和 Python 一致，覆盖无晶、底晶拒绝、悬空针和换节点。候选 `CuRgSbWm:crcg----:--------:--cbCy--` 保留中间空层。接实际 `pin-column-sample` 后，候选 `------P-:------Ru` 的首组槽号为 `(0, 0, 0, 0)`，q0 到 q2 均为有效空列。游戏内联动待验收。
