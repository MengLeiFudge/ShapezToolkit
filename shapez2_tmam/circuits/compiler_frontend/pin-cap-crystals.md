# 顶盖触顶晶体筛选

本件接读顶盖参数板的图像请求。四个向下行闭包和三个向上补全保留实际层位，输出原前态上与第五层晶体相连的全部格。融合只看晶体的环向水平及竖直邻接。判定再逐格检查目标晶体在低一层有同色来源，且来源未被触顶删除。目标底层必须没有晶体。扫描依据见[四列晶体的顶边连通扫描](../../docs/proofs/01-foundations.md#s01-14)，保留条件沿用 `pin_constraints.pin_image_matches`。

```powershell
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_cap_crystals `
  shapez2_tmam/circuits/compiler_frontend/pin-cap-plan.json `
  --output pin-cap-crystals.spz2bp
```

导出同时生成同名频道表。`--channel-base` 可移动私有预留段，默认 1704300–1704399。四类纯 Python 方法经过通用前端和后端编译，各得到一块原生计算平台，再按层复制接入。

| 频道 | 信号 | 接法 |
| --- | --- | --- |
| 1703743 / 1703303 | 顶盖请求 / 当前掩码 | 接 `pin_cap_plan`。请求 `1` 启动晶体筛选，请求 `2` 转发递归过滤。 |
| 1701867 等 | 四列冻结材料 | 按同名 JSON 的 `source_materials` 接线。每格取整数 0 空、1 普通、2 针、3 晶体。 |
| 1704300–1704303 | 前态原色行 | 从底到顶四路。使用同一冻结槽的原色，不经过虚拟堆叠。 |
| 1704304–1704308 | 目标原色行 | 从底到顶五路。以上两组空层均用原生空信号。 |
| 1704309 | `rows_ready` | 同一槽的前态原色行和目标行备齐后置 1，保持到请求结束。 |
| 1704313 / 1704314 | `crystal_ready` / `crystal_ok` | 输入保持稳定后给出本段结果。删除位按 JSON `outputs.deleted` 的原层位与象限顺序读取。 |
| 1704312 | `rest_request` | 本段通过后转发 `1`，等剩余图像条件。顶盖请求 `2` 转为 `2`。 |
| 1704310 / 1704311 | `rest_ready` / `rest_ok` | 剩余过滤收到请求后回 `ready=1` 和整数 `ok=0` 或 `1`，保持到请求转空再清除。 |
| 1703741 / 1703742 | 顶盖 `filter_ready` / `filter_ok` | 晶体失败直接回 `1,0`。晶体通过时等待本次剩余过滤回报，再统一回复。 |

复位后保持固定接线和频道独占。图像请求及本次行数据备齐后，晶体计算等待 5352 信号 tick，按 `crystal_ready` 读取。完整图像回报还要核对最大族代表、当前掩码的顶盖接触、原底占用与新地面针、静止格、非晶体落点和支撑。源格在融合后若仍有晶体，也可能在后续下落碎裂，剩余过滤负责核对这些格。

## 同一真实来源对照

目标 `P-P-P-P-:P-P-P-P-:CuCuCuCu:cr------:cr------` 的真实族使用槽 `(7,4,4,4)`。前态低四行是 `P-P-P-P-:CuCuCuCu:cr------:cr------`。

| 掩码 | 删除结果 | 保留晶体判定 |
| --- | --- | --- |
| `8` | 第五层 q3 | 通过，等待剩余图像回报。 |
| `9` | 第三、四层 q0 和第五层 q0、q3 | 直接注入 q0 顶晶以核对拒绝路径。目标的两颗红晶同时失去来源。 |
| `8`，目标第三层后的第一颗红晶改绿 | 第五层 q3 | 颜色不相等，直接拒绝。 |

原生离线回放按板内组合、无线固定 12 信号 tick，核对同一来源的 16 个掩码及另外 180 份晶体网格。删除位逐格匹配 `Rules.groups(..., fused=True)`，其中 15 份网格需要向上补全。另核对输入未齐、旧回报清除、剩余图像回报和递归转发。样件共 27 块平台、23,492 个建筑，游戏内时序待验。
