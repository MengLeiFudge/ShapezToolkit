# 成功叶端输入锁存

锁存板保存共用闭包选出的切向、四列前缀高度、五层原色、四份材料字和可选顶盖参数。当前列高度从锁存的四个高度中按 writer 的查询列选择。原色空层保持空信号，整数高度 `0` 保持整数。

| 方向 | 频道 | 用途 |
| --- | --- | --- |
| 输入 | `1704600` | `1` 保持本单，`0` 清空并允许下次捕获 |
| 输入 | `1704601` | 捕获请求，保持至就绪 |
| 输入 | `1703004` | 共用闭包已选出叶端的标记 |
| 输出 | `1704602` | 快照就绪 |
| 输出 | `1704620`、`1704621` | 可选顶盖、切向 |
| 输出 | `1704622`–`1704625` | 四列高度 |
| 输出 | `1704626`–`1704630` | 从底到顶的五层原色 |
| 输出 | `1704631`–`1704634` | 四份材料字 |
| 输出 | `1704635` | 当前查询列的冻结高度 |

开单时保持 `1704600=1`。共用闭包选出结果且字段稳定后，置 `1704601=1`，等 `1704602=1` 再撤销或复用闭包。两遍期间持续保持 `1704600=1`。同一保持周期内，后续捕获请求不会覆盖已保存的字段。换单时先清空，等就绪清零后再捕获。

```bash
python -m shapez2_tmam.circuits.compiler_backend.leaf_snapshot \
  --output leaf-snapshot.spz2bp

python -m shapez2_tmam.circuits.compiler_backend.leaf_snapshot \
  --path success-path.spz2bp --output success-path-with-leaf-snapshot.spz2bp
```

`--path` 读取已导出的两遍成功路径，改接叶端各输入，并在快照尚未就绪时拦住批次启动。整单目标、父帧存储和实体写入仍按原有接口接入。

独立版为 10 板、8,723 个建筑，接入 294 板成功路径后为 305 板。离线接 101 板真实共用闭包，捕获必须尾针目标的叶端后，在首笔发令前撤销闭包。两遍各确认地址 `0`–`74`，与原成功路径逐笔一致，最终只在槽 `0` 留下目标。另核对提前启动、重复捕获、合法空行、零高度和换单重新捕获。游戏内时序留待实机验收。
