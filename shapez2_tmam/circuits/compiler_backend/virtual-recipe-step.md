# 虚拟六槽配方单步

`virtual_recipe_step.step(slots, opcode, a, b, destination, base, color)` 读取六个旧槽和一笔六字段指令，返回 `(next_slots, valid)`。旧槽使用 `synthesis.physics.Shape` 或 `None`，基础料可以传图形或短代码，颜色用 `color:r` 这类信号名。`None` 表示空信号，整数 `0` 表示实际槽 0。

| 操作号 | 动作 | 消费的槽与材料 |
| --- | --- | --- |
| `1` / `2` / `3` | 顺转 / 逆转 / 转半圈 | `a` |
| `4` / `5` | 取正面半形 / 背面半形 | `a` |
| `6` | 顶针 | `a` |
| `7` | 堆叠，`a` 在下，`b` 在上 | `a`、`b` |
| `8` / `9` | 交换半形，取以 `a` / `b` 为正面的出口 | `a`、`b` |
| `10` | 结晶 | `a` 和 `color`，支持红绿蓝、青品黄白 |
| `14` | 领取基础料 | `base`，须为非空无晶单层 |

双输入必须来自两个有物品的不同槽。目的槽必须为空或是本笔消费的槽。成功时消费输入，保留选中出口并写入目的槽。被拒绝时返回原六槽。调用方可用同一份旧槽检查或重算，提交方在 `valid=1` 时锁存全部六个新槽。未用字段按工道约定发空信号。

```bash
python -m shapez2_tmam.circuits.compiler_backend.virtual_recipe_step \
  --output virtual-recipe-step.spz2bp
```

| 频道 | 信号 |
| --- | --- |
| `1702700`–`1702705` | `opcode/a/b/destination/base/color` |
| `1702706`–`1702711` | 旧槽 `0`–`5` |
| `1702712`–`1702717` | 新槽 `0`–`5` |
| `1702718` | `valid`，本笔有效发 `1`，被拒绝发 `0` |

整件需要 7 块 3×3 平台。保持整组输入至少 3,072 信号 tick 再读取全部输出。`valid` 与新槽都是组合输出，提交方负责采样时钟和请求确认。

离线按原生接线对照 Python 检查了 4,817 组单步，覆盖空地址、槽 0、双输入重号、覆写被消费的槽、被占目的槽、空出口、基础料和颜色信号。三份实际配方逐笔执行了 40、41 和 145 笔，最终都只剩一个与目标一致的成品。游戏内时序待验。
