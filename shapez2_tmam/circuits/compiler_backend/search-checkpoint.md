# 父搜索游标存取

和父帧共用深度与捕获信号。共存三层，根深度为 `0`。捕获将当前 13 个整数写入指定深度并清除更深层，较浅层继续保留。读指定深度时，电路给出已保存的字段，并分别比较当前 S 计数、来源槽和顶盖参数。每个字段独立保存，整数 `0` 是合法值。

| 用途 | 输入频道 | 读回频道 |
| --- | --- | --- |
| 四列 S 保留计数 | `1703518`–`1703521` | `1705010`–`1705013` |
| 四列来源槽 | `1701865`、`1701871`、`1701877`、`1701883` | `1705014`–`1705017` |
| 顶盖掩码 | `1703303` | `1705018` |
| 四列顶格成员 | `1703308`–`1703311` | `1705019`–`1705022` |

| 频道 | 用途 |
| --- | --- |
| `1704200` | `1` 保持，`0` 清空所有深度 |
| `1704201` | 读取深度，`0`–`2` |
| `1704202` | 写入深度，`0`–`2` |
| `1704203` | `1` 捕获，`0` 读取 |
| `1705000` | 所选深度的全部游标字段就绪 |
| `1705001` | 四个 S 计数均相等 |
| `1705002` | 四个来源槽均相等 |
| `1705003` | 顶盖掩码和四个成员均相等 |

捕获前保持深度和全部游标至少 96 信号 tick，再保持捕获高电平至少 96 信号 tick。恢复时给定读号，等待至少 96 信号 tick 后使用 `ready`。重查得到的当前游标变化后，也等至少 96 信号 tick 再取对应匹配位。无效读号、未写入或已清除的深度均不发布就绪。捕获缺少任一字段时，该层游标也不发布就绪。

```bash
python -m shapez2_tmam.circuits.compiler_backend.search_checkpoint \
  --output search-checkpoint.spz2bp
```

原生件为 22 板、31,984 个建筑。与父帧原色存储合装离线核对 37 次读回，覆盖全零游标、13 个字段逐项失配、倒序读取、写父帧清子帧、重新写入、无效读写深度及整组复位。游戏内时序待实机验收。
