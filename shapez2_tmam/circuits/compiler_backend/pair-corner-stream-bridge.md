# 动态角备料的共用写入确认器

用 78 板动态角备料版的 `pair-writer.spz2bp`、同名 JSON 与 `dense-stream-clock.json` 重导。以下命令使用离线回放时的输入目录。

```bash
writer_dir=.codex/corner-writer.JKoPbq
python -m shapez2_tmam.circuits.compiler_backend.pair_corner_bridge \
  --writer "$writer_dir/pair-writer.spz2bp" \
  --dense-clock "$writer_dir/dense-stream-clock.json" \
  --output pair-corner-stream-bridge.spz2bp
```

待重导的 `pair-writer.spz2bp` 的 SHA-256 为 `84a6cc1dd834acd859e2937aa4ff824ca4832c1ad4f92af2654aee5528505384`。合装确认器与写入件共 125 块平台、138,392 个建筑。原生解码确认 225 个全局发射频道各有一个发射器。

| 频道 | 信号 |
| --- | --- |
| `1702052` / `1702053` | 制角总运行与整角完工 |
| `1701636` | 制角子步骤来源。`1` 紧柱，`2` 释放，`4` 逐层追加 |
| `1701637` / `1701638` | 子步骤请求与本次完工。未完成时回 `0` |
| `1701640` / `1701642` | 紧柱待结晶色和占用，复位须同时回到整数 `0` |

收到整角运行后，先把子步骤请求保持为整数 `0` 至少 96 信号 tick，并发布稳定的来源与参数。拉高子步骤请求后保持参数，直到读到 `1701638=1`。每次子步骤完工后清零请求至少 96 tick，并等 `1701638=0` 再起下一步。逐层追加用角级追加参数 `1701651`–`1701653`。确认器等待两个写入时钟归零及公开完工撤销，再启动本次调用。

离线回放解码实际 78 板和 47 板原生接线，按 12 信号 tick 无线模型，由模型提供制角子步骤和实体写入 ACK。验证待结晶色、占用和旧完工独立残留时各自阻止启动。制角先后调用紧柱、释放和追加，其中追加写入 10 笔。主控重新取得写入权后，仍拉高的制角请求没有启动写入。58 板样件的蓝图和接口表重导逐字节一致。游戏内时序及整单完工待验。
