# 双半形方法确认器与共用写入桥

从双半形配方写入分册的 `pair-writer.spz2bp` 和同名 JSON 生成确认器。

```bash
python -m shapez2_tmam.circuits.compiler_backend.pair_sequence_bridge \
  --writer path/to/pair-writer.spz2bp \
  --output pair-sequence-bridge.spz2bp
```

将这份确认器与原 `pair-writer` 合装。`pair-writer` 已含 `pair-job`、`pair-job-inputs` 和 `pair-job-cursor` 三块主控。如果已经摆放旧确认器，用本件替换。确认器占 37 块平台，与写入件共 95 块，合计 106,121 个建筑。生成时检查两件的 184 个全局发射频道和相互收发端口。

| `kind` | 用途 | 写入来源 `1701740` | 启动与完工 |
| --- | --- | --- | --- |
| `0` | 跳过 | 空 | 阶段参数稳定后推进 |
| `1` | 制角 | 空 | 独立端口 `1702052` / `1702053` |
| `2` | 拼半形 | `3` | 共用桥 `1701761` / `1701766` |
| `3` | 合并整形 | `3` | 共用桥 `1701761` / `1701766` |
| `4` | 追加尾料 | `4` | 共用桥 `1701761` / `1701766` |
| `5` | 恢复切向 | `3` | 共用桥 `1701761` / `1701766` |

启用 `1701695` 前向 `pair-writer` 提供稳定的列高度、切向和尾料参数。完成后由主控在 `1701699` 发布 `1`。中途停单时把 `1701695` 保持为 `0` 至少 72 信号 tick，同时按工道协议清空写入地址和存储。执行新订单前将已清空的公开地址、写入请求和 ACK 接回写入桥。

每次共用调用先拉低启动口。适配板收到公开完工撤销、内部完工为 `0` 且步号和追加状态归零后才允许启动。启动后同时看到内部和公开完工为 `1`，确认器才接受本次阶段。即使相邻两阶段选中同一来源，下一阶段也要重新通过复位判据。

离线回放使用两件原生蓝图的接线和 12 信号 tick 的无线模型。制角完成信号及实体写入口的请求与 ACK 由模型提供。回放覆盖 15 笔真实拼合、追加和转向指令、公开及内部旧 `done`、整数槽 `0`、空操作数和首笔写入中断后重跑。游戏内写入与制角联调待验。
