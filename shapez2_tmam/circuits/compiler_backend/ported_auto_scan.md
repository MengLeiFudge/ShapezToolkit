# 四象限五层自主拆层器

`ported_scan_loop` 默认导出共 8 岛格的三块相邻平台。2×2 主时钟用原生布局器放置 3×3×3 全局收发器及其频道常量，经四对板缝凹口送出 `p0`、`p1`、`p2`、`armed`。数据板的有线寄存器保存剩余图形 A 和待写回的下半 B。读出板按 `sample` 发布 `top` 与从 1 起算的 `original_layer`。中间空层按原层号跳过，空目标直接结束。

## 使用

先给稳定的 `target` 并保持 `enable=0` 至少 96 信号刻，再将 `enable` 置为 `1`。输入保持到 `done=1`。每层的 `sample` 持续 48 信号刻，在此期间从两个输出凹口读取同一组数据。重新拉低 `enable` 复位，扫描中途换单也执行同样的复位。全部输入输出凹口见导出的同名 JSON。

`--clock-only` 可单独导出共享主时钟。后续接多路同步扫描时，把四个相位信号走同岛层有线分支送至各数据板。共用该时钟的扫描器同时复位启动，默认占用 1709500～1709505。可用 `--clock-channel` 为独立时钟另选六条连续频道。

## 游戏里的更新与相位长度

以下基于本地 Shapez 2 `1.2.0-rc3` 游戏程序集反编译。

| 源码 | 对应规则 |
| --- | --- |
| `SimulationGraph.ValidateCluster`、`SimulationCluster.RecomputeUpdateOrder` | 更新前按连通簇重建模拟节点顺序。用已访问集合停止回访，因此一个闭环里有连接会在提供方更新前读取。 |
| `SignalNetworkSystem`、`SignalNetworkSimulation.Update` | 导线、岔接与换层连续段组成一个信号网络。网络作为一个模拟节点合并输入。 |
| `SignalPortSystem.CreateTransferSimulation`、`SignalPortTransferSimulation.Update` | 短距收发两端共用一个转发模拟节点。该节点在本批内逐刻读取再发送，适用本地导体缓冲。 |
| `SignalSimulation`、`SignalBuffer.TryPopSignal` | 每模拟秒 12 个信号刻，每批最多 4 个。读者用本批与提供方最后一批的起始差修正四格缓冲索引。同批可即时读，逆序边可读上一批。 |
| `SignalChannelRingBuffer.ReadSignal` | 无线环形缓冲按 `RegionTotal = 4 + 2×4` 固定回读 12 信号刻。 |

本地闭环的延时随更新顺序和批长变化。主时钟以六条无线频道保存五位计数和首圈完成位，每 12 刻加一；计数的高三位每 48 刻更新一个相位。正常连续更新中，对一条本地缓冲边为到达加四格历史回填合计预留 8 刻。原生接线的写回闭环包含 A、B、下半三个导线网，以及 A/B 的保持与写入门和拆层器。A 保持时，A 经拆层到 B 的写入路径最多四条缓冲边，预留 32 刻。启用 B 保持后两条边预留 16 刻，旧写入路在下一相才撤销。B 写回 A 使用同样的先写、重叠、再撤写顺序。相位解码、短距时钟分发及读出在闭环之外，按依赖先后更新。

| 相位 | 动作 |
| --- | --- |
| 0 | A/B 独立保持。A 非空时发布一组样本。 |
| 1 | 关闭 B 保持，清除旧写回值。 |
| 2 | A 保持。将 A 的下半写入 B。 |
| 3 | B 同时打开写入和保持，使 B 的反馈历史装入新值。 |
| 4 | B 独立保持。关闭 A 保持，清除已采样的旧值。 |
| 5 | 将 B 写入 A。 |
| 6 | A 同时打开写入和保持，使 A 的反馈历史装入新值。 |
| 7 | A/B 独立保持，进入下一次采样。 |

## 原生对照

| 项目 | `iterative-scanner-4q5l` | 自主拆层器 |
| --- | ---: | ---: |
| 1×1 岛格 | 127 | 8 |
| 实体平台 | 127 | 3 |
| 建筑条目（含导线） | 1,147 | 1,045 |
| 全局接收 / 发射 | 175 / 134 | 6 / 6，集中于主时钟 |
| 跨板飞线 | 0 | 6 对 |
| 最稀板三维利用率 | 4.6% | 20.6% |
| 每层间隔 | 384 刻，32 模拟秒 | 384 刻，32 模拟秒 |

重读原生蓝图后，`ported_replay.BatchReplay` 按实际导线网、飞线转发节点和逻辑门推进。对每个反馈强连通分量，以哪一节点最后更新为分支，精确求出最多逆序依赖的更新排列。拆层器的反馈分量有 8 个节点、0 对飞线，最多出现 7 条逆序边。`ported_scan_audit` 对照含 `(4,1,4,1)` 对抗批长的六种批次和排列，共 105,408 信号刻，核对每层的原层号、48 刻有效窗、完成保持和中途复位。

```bash
python -m shapez2_tmam.circuits.compiler_backend.ported_scan_audit autonomous-scan.spz2bp \
  --output autonomous-scan.ticks.json
```
