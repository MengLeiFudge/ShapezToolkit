# 尾部搜索运算板

S 枚举及追加许可、Pin 静止格核对、递归准入和完整节点 G 预检共用一件 36 板支撑扫描。蓝图共 238 块平台、229,917 个建筑。[原生蓝图](tail-search-workers.spz2bp) · [接口与发射频道清单](tail-search-workers.json)

| 环节 | 请求及输入 | 回报 |
| --- | --- | --- |
| 完整节点 G 预检 | `1705330` 启动，`1705350–54` 底到顶原色行 | `1705303` 完工，`1705304` 通过 |
| S 前态 | `1704800` 启动，`1704801` 拒绝并继续，`1705350–54` 目标行，`1703509–12` 上界 | `1704802` 就绪，`1704803` 穷尽，`1703513–17` 候选行，`1703518–21` 计数 |
| Pin 静止格与递归准入 | `1704502` 核对请求，`1704304–08` 被顶目标行，其余输入见频道表 | `1704500` 就绪，`1704501` 通过 |
| 共享扫描 | 四路各有独立请求，保持输入至各路释放 | `1705230` 重叠故障，Pin 从 `1704425–29` 读可达行 |

主控把 `1705331/32` 接 S 的 `1704800/01`。在尾部搜索中，Pin 的被顶目标由当前 S 候选 `1703513–17` 提供，接至 `1704304–08`。原生无线发射清单可和上层模块逐件核对。运算板本身的 404 条发射频道均为单发射。与四列、顶盖、晶体、单层控制、落点、节点输入、尾部调度和帧控制合计核对 812 条，重复为零。

## 重导

每个输入蓝图旁需有同名 JSON。接口表 `parts` 记录本件所用的精确蓝图指纹。原 `support-scan` 默认取仓库验收册版本。

```bash
python -m shapez2_tmam.circuits.compiler_backend.tail_search_workers \
  --s-search s-candidate-search.spz2bp \
  --pin-stationary pin-stationary.spz2bp \
  --descent pin-descent-filter.spz2bp \
  --shared-scan shared-support-scan-preflight.spz2bp \
  --output tail-search-workers.spz2bp
```
