# 四角接续双半形的六槽回放

```bash
python -m shapez2_tmam.circuits.factory_assembly.corner_sequence direct --output direct-corner.json
python -m shapez2_tmam.circuits.factory_assembly.corner_sequence suspended --output suspended-corner.json
```

| 样件 | 目标短代码 | 连续工段 | 峰值活槽 | 成品槽 |
|---|---|---:|---:|---:|
| 直接落角 | `P-RuWuCu:CuRu--cr:--RuWucr:cbRu--Cu:SuRuSuCu` | 98 | 5 | 0 |
| 悬空落角 | `P-SuCu--:P-SuCuRu:cgSuCu--:RuSuCucy:WuSuCuSu` | 149 | 6 | 0 |

`instructions` 按地址排列，逐笔保留 `opcode/a/b/destination/base/color`。未用字段为 `null`，槽 0 为整数 `0`。`stages` 记录每笔执行后仍有物品的槽和形状。`phases` 用 `[start, stop)` 标出工序区间及交接时的活槽，空区间表示可跳过的工序。每条配方从全空槽开始，由现有物理模型逐笔回放。

先把 q0、q1 分别做在槽 0、1，合成的前半形留槽 0。保留槽 0，复用槽 1 做 q2，槽 2 做 q3。后一半合形时消费槽 2，结果写在槽 1。最后从槽 0、1 拼成完整图形并写回槽 0。

直接落角样件的 q0 先去掉地面针，制造最高晶以下的紧柱，再顶一次补回地面针。接助手后逐层加上方的普通料，再用远锚带走填隙的辅助晶体。q2 没有晶体，五层基础料与助手一起逐层叠入，原列空位保持为空。无待碎填充晶体的角跳过远锚备料和释放。

悬空样件的 q0 先制 `cg------`，顶两次补回主柱地面针，再逐层加普通料。q3 的原列是 `空、Ru、空、cy、Su`，落点为第 1 层，晶下间隙上端为第 3 层，层号从零起算。此时槽 0、1 分别保留前半形和 q2。q3 的接续如下。

| 工段区间 | 工序 | 区间结束后的活槽 |
|---|---|---|
| `[68, 84)` | 接好第一次碎晶用的远柱，保留完整初始主形 | 0、1、2 |
| `[84, 92)` | 在槽 3 备近锚 | 0、1、2、3 |
| `[92, 109)` | 槽 4、5 搭五层普通远柱，依次转交支撑，消费远柱和近锚 | 0、1、2 |
| `[109, 132)` | 槽 3、4、5 合做触顶补形，补形留槽 3 | 0、1、2、3 |
| `[132, 134)` | 消费补形并顶破，普通格落到第 1 层 | 0、1、2 |
| `[134, 142)` | 逐层补助手和顶部原色普通格，末切并恢复朝向 | 0、1、2 |
| `[142, 149)` | 合后半形，再拼两半 | 0 |

两份回放的四角及两个半形均与理论构造对应阶段一致。这两份工段数可用于主控排程和容量核对。实机整线验证需要容纳相应连续地址的工道。
