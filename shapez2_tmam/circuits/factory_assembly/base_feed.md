# 基础料卸货与选料合板

```bash
python -m shapez2_tmam.circuits.factory_assembly.production --stages 6 --handoff --compact-dyes --compact-base --output six-slot-production.spz2bp
```

`--compact-base` 把每个基础料地址的四块卸货台并入四角选料台。混编车依次为 `q2、q3、q1、q0` 卸货，每角三节车分别装 `C/R/S`、`W`、`r/g/b`。上游仍用单料车经配料台装混编车，每个有效货层有四路同料。按导出 JSON 的 `interfaces.load` 对接车厢、层和行。

地址 `i` 的基础料车朝北停在 `(18i−9,−17)`，比原车头位置向东移 3 个区块。沿用 12 节车的卸货顺序。各角的选料台直接收车厢的四种整片和三原色，在东侧将一条整片带、七色管和制针红管交给备料台。启用 `--compact-dyes` 时，独立结晶车停在 `(18i−6,3)`。六段成品口位于 `(96,0,0)` 东侧底层第 31 行。

基础料每地址节省 4 块 3×3 平台和 2,684 个建筑。样件六段的 24 块合板逐一核对了原色卸货和混色配比、四种整片选料、跨台带管端口。配料端同货层的四个装车口和原混编车厢次序已对照原生蓝图。

## 共用供货的一带下界

设成品带速为 `B` 件/秒。一个领料地址的四个角可以同时要求同一种整片。例如 `CrCgCbCw` 每件领四片 C，各角至少 `B` 件/秒，该地址至少 `4B` 件/秒。若同一份订单有 `n` 个这样的基础料地址，共用 C 源至少需要 `4nB` 件/秒。单条速率为 `B` 的上游带最多供其中一路，`4n` 条等速带或等效并行供给才能覆盖该例。纯色整片直通只走 `q0`，该地址的整片需求为 `B`。

染色每个启用角最多消耗对应原色 `10B` 升/秒。制针红管单角需 `20B` 升/秒。`P-P-P-Cr` 同一地址的三个针角和一个红染角合计需 `70B` 升/秒。混色按实际启用行核算，制针和红染复用每角的红色底层第 28 行。连续生产时，若该行实测只能交付 `P` 升/秒，该角制针最多支持 `P/20` 件/秒。

车队可以服务多个地址。对每个实际启用的卸货行，平均每趟卸入缓冲量 `Q`、平均到站间隔 `T` 和该行需求 `D` 须满足 `Q/T ≥ D`，缓冲还须覆盖最长到站间隔。合计运力须覆盖同一订单所有同时领料的地址。四路同料车层提供并行卸载位置，单角整片仍经过选料后的第 9 行单带，制针仍经过第 11 行单管。实际到站量、管带速率和持续一满带由 #72 验收。
