# 四色 40/41 道长单的供货与接轨

两单在同一条 41 段工道上换单生产。满带设为 `B` 件成品/秒，各在用地址按稳定生产同时领料。两单每件都用 C 28 片、R/S/W 各 3 片，基础料用红 80 升，结晶另用红 30 升、绿 30 升、蓝 20 升。以逐车层和卸货行定容时，先把同单不同地址的需求相加，再取两单的较大值。该值包括换单后仍用同一装载线路的层位。[配方](four_color_sample.py) · [逐行用量](capacity.py)

## 基础料混编车

两单的基础料地址都是 `0、1、7、8、17、18、24、25、36、38`。下表每格列出该货层的持续需求系数和对应地址。持续供货量为系数乘 `B`，整片以件/秒计，红色以升/秒计。整片 C/R/S 用第 −12 行，W 用第 8 行，制针红料用第 28 行。40 道启用 11 个层位，41 道启用 10 个层位，同一车队支持换单时共需保留 13 个可装载层位，车厢顺序按现有 12 节混编表接入。[角别与装载表](base_feed.md)

| 车厢/层（底层为 0） | 货种 | 40 道用量系数及地址 | 41 道用量系数及地址 |
|---|---|---|---|
| 1/0 | C | 7，1、7、8、17、18、24、25 | 同左 |
| 1/2 | S | 2，36、38 | 0 |
| 2/0 | W | 0 | 2，36、38 |
| 4/0 | C | 7，1、7、8、17、18、24、25 | 9，再加 36、38 |
| 5/0 | W | 2，36、38 | 0 |
| 7/0 | C | 7，1、7、8、17、18、24、25 | 同左 |
| 7/1 | R | 2，36、38 | 0 |
| 7/2 | S | 0 | 2，36、38 |
| 10/0 | C | 7，0、1、8、18、25、36、38 | 5，0、1、8、18、25 |
| 10/1 | R | 1，7 | 3，7、36、38 |
| 10/2 | S | 1，17 | 同左 |
| 11/0 | W | 1，24 | 同左 |
| 12/0 | 红 | 80，1、8、18、25 各 20 | 同左 |

若用统一 C 源服务所有基础料地址，干线需同时供 `28B` 件/秒。W 仍须随切向送到不同车厢。两单互斥时，所有 C 来源加起来仍只需 `28B`，固定各层的最大装载需求则为 `7B + 9B + 7B + 7B = 30B`，可按所选订单装车。

## 独立结晶车

结晶使用 1 节三层流体车，地址 `3、10、20、27` 同时用料。每台结晶机处理 `B` 件/秒时，出料管需要 `20B` 升/秒。地址 27 的黄色由两条 `10B` 的原色管混合。

| 车厢层 | 货种 | 沿途需求（升/秒） | 有效卸货行 |
|---|---|---:|---|
| 0 | 红 | `30B` | 地址 3 第 28 行 `20B`，地址 27 第 30 行 `10B` |
| 1 | 绿 | `30B` | 地址 20 第 31 行 `20B`，地址 27 第 29 行 `10B` |
| 2 | 蓝 | `20B` | 地址 10 第 31 行 `20B` |

## 车队频率与车站缓冲

设一条线路的每趟车都服务表中的所有地址。以 `Q` 表示该趟在某个货层沿途实际卸入的量，`d` 表示表中该货层的用量系数。该层要求每秒至少 `dB/Q` 趟。对各卸货行用该行实际收到的 `Q` 和用量同算一次，取所有层和行中的最大值。乘 60 得最低每分钟班次。若往返时间为 `C` 秒，均匀发车时至少需要 `ceil(C × 最低每秒班次)` 列车。选车队时还要计入停靠、回装和各站卸货速率。

缓冲按每行的最长断供间隔 `G` 秒定容。固体至少 `ceil(该行用量系数 × B × G)` 件，流体至少 `该行用量系数 × B × G` 升。例如，`B=2`、最长断供 60 秒时，各在用整片行需 120 件。制针红色各在用行需 2,400 升，黄晶的红、绿行各需 1,200 升。若每分钟一趟，基础料 12 号车底层沿途需实卸 9,600 升，第 4 号车底层在 41 道订单需实卸 1,080 片 C。独立结晶车的三层分别需实卸红 3,600 升、绿 3,600 升、蓝 2,400 升。将现场的量和时间代入即可得到该站的频率和缓冲。

同货种可共用上游来料与库存。基础料车和结晶车按各自层位装车，在共用主轨后分别进各自站台，保留 12 节与 1 节的相应卸货坐标。两套车共用上游红源时至少需 `110B` 升/秒。共用主轨要容纳两条线路的发车频率之和，按共享段实测可安全通行的频率核对。混编车各层仍要把货送到每个活跃地址。站场只留单带卸载时，速率为 `B` 的带只够一个持续领料行。上面的班次是供货下界，实际速度、最长断供时间和持续满带随 #72 实机核对。

## 按实测到货验收

```bash
python -m shapez2_tmam.circuits.factory_assembly.books physical --four-color --belt-rate 2 --measurements measurements.json --output-dir four-color-capacity
```

省略 `--measurements` 可先导出待测清单。仓库的 [2 件/秒待测清单](../../blueprints/验收/实体/四色含晶/four-color-capacity.json) 来自此命令生成的 `physical.json`。`--belt-rate` 填验收带速，示例按 `2` 件/秒。沿用实体分册的 `rates` 和 `deliveries`。在 `rates.output_belt` 填末端带实际持续出货率。在 `deliveries` 按 `stage`、`station` 填实际到站间隔 `interval_seconds`，并按 `wagon`、`layer`、`row` 填每趟卸入缓冲的 `amount`。图形用件数，流体用升。加工机、内部带和管仍分别在 `rates` 录入持续速率。

`physical.json` 的 `capacity` 分别列出 40 道和 41 道订单。`paths` 包含地址、车厢层、卸货行、实际卸量、间隔、供给率和最小每趟卸量。`usage=pin` 标记制针红管，`usage=crystal` 标记独立结晶原色。`output` 单独列出成品带坐标与实测供给率。`status` 可为 `meets_target`、`insufficient` 或 `unmeasured`。已有一项低于目标时，整单状态为 `insufficient`，缺项仍保留在 `unknown_capacity_checks`。成品带缺测或低于目标时，`parallel_lines` 留空。带速、管速和到货量都应取稳定段的实测值。

## 最重车层按接轨分两路

保持 12 节车顺序和每层四路同料，基础料车分别服务 `0、1、7、8、17` 与 `18、24、25、36、38`。两路各经过五个既有地址，41 道订单第 4 节车底层的 C 负担从一条线路的 `9B` 件/秒分为两路各 `4B` 和 `5B`。40 道对应 `4B` 和 `3B`。基础料红层两单均由单路 `80B` 分为两路各 `40B`。两路若从同一装车场出发，合计发车需求和各站原有有效卸货行保持各自核算。分路降低单趟载荷，每个地址的卸货速率和缓冲仍按该地址的需求定容。

## 原生站场与长单重导

```bash
python -m shapez2_tmam.circuits.factory_assembly.production --stages 2 --handoff --compact-base --compact-dyes --output four-color-feed-ports.spz2bp
python -m shapez2_tmam.circuits.factory_assembly.acceptance --four-color --compact --compact-feeds --output four-color-compact-feeds.spz2bp
```

第一条命令生成两段通用站场，便于检查相邻地址的车头位置、12 节混编车和一节结晶车的接点。第二条命令生成用于统计占地的 41 段四色验收线。每个基础料地址把四块卸货台并入选料，所有 10 站共省 40 块平台。4 个结晶站各合并一块平台。两种车头同时向东移 3 个区块，按同名 JSON 的 `interfaces.stations` 接入。整线从 1,198 个岛项目、774,533 个建筑减到 1,154 个岛项目、745,633 个建筑，仍在 `(726,0,0)` 东侧底层第 31 行出带。
