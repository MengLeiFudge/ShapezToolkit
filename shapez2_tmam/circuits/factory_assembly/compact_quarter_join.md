# 通用工道四角拼合减板页

把基础料的四路转向并入三次半形交换所在的大平台。每道保留四条独立进带、q0 整片直通、原出料带和六槽工道。四路各走一条带，最后仍在原有合流器汇成一条成品带。

| 原生布局 | 大平台 原版 → 合板 | 建筑 原版 → 合板 |
|---|---:|---:|
| 单道续接页 | 32 → 31 | 26,804 → 26,646 |
| 九道续接页，地址 0～8 | 288 → 279 | 241,236 → 239,814 |
| 九道成品末页，地址 477～485 | 285 → 276 | 240,088 → 238,666 |

486 道按 54 页、最后一页带成品出口及 8 块公共控制板估算，大平台从 15,557 块降至 15,071 块。

## 生成和接站

在仓库根目录运行，蓝图旁生成同名 JSON 接线表。每页可选 1～9 个连续地址；仅最后一页加 `--terminal`。公共控制板沿用 `full_line_pages` 导出，并使用整线配置的地址容量。

```sh
python -m shapez2_tmam.circuits.factory_assembly.compact_quarter_join --start 0 --count 9 --output compact-quarter-join.spz2bp
python -m shapez2_tmam.circuits.factory_assembly.compact_quarter_join --start 477 --count 9 --terminal --output compact-quarter-join-final.spz2bp
```

以工段原点为基准，基础料站车头从 `(-9, -17)` 平移到 `(-6, -17)`。来轨外接 `(-7, -19, 0)`，离轨外接 `(-6, -19, 0)`。现有混合车仍按原车厢、原层、四路同料卸车。结晶站、配方六字段、道间六条槽带和末道成品口沿用通用版。相邻页按各自 JSON 的 `input` 和 `output` 对接。

拼合板在相对岛坐标 `(3, -3, 0)`。板内北侧 x 从 8 到 11 分别接 q0、q1、q3、q2，带层为 0。三次交换和各自的废料口沿用原拼合件。南口 `(30, 37, 0)` 仍接六槽收料板。

原生解码已对照 9 道续接页和 9 道末页的基础料站、四入一出、道间六口及成品读口。游戏内持续满带和换单清空由 #72 验收，合板后额外观察 q0 分流及四路进带是否排空。
