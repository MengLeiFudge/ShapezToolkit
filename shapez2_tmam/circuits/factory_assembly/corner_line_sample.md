# 四角到双半形的六槽回放

`corner_line(target, heights, alternate=False)` 接收目标短代码和已闭合的四列前缀高度。高度按当前切向的 q0～q3 排列。四角拼成两半后，原色尾料按原层从底到顶堆叠。反向切口在尾料完成后顺转一格，恢复目标方向。

```bash
python -m shapez2_tmam.circuits.factory_assembly.corner_line_sample direct --output direct.json
python -m shapez2_tmam.circuits.factory_assembly.corner_line_sample suspended --output suspended.json
```

JSON 的 `instructions` 数组按地址排列，每笔包含 `opcode/a/b/destination/base/color`。`null` 发原生空信号，整数 `0` 是实际槽号。`phases` 给出左闭右开的地址区间和结束时的活槽。`stages` 给出每笔落槽后的活槽及物品短代码。

`calls` 按执行顺序给出 `kind`、`parameters`、首地址 `start`、写入笔数 `count` 和调用结束后的 `live`。调用 `expand_call(kind, parameters)` 可得到该区间的六字段指令。计数为零时直接推进到下一次调用。

| `kind` | 调用参数 |
| --- | --- |
| `dense` | 原色单格 `rows`、目标槽和临时槽、地面针前缀长度。触顶补形改用 `trigger_rows`、目标槽、触发槽、临时槽和方向。 |
| `append` | 原色单层 `rows`、下料是否存在、下料槽和上料槽。 |
| `transform` | 固定操作列表，每项为 `opcode, a[, b]`。`destinations` 可逐笔指定写回槽，省略时写回 `a`。 |
| `release` | 直接释放、支撑交接或顶破，参数给主形槽、相关材料槽和方向。支撑交接附保留槽及 `first_cut_done`。 |

| 样件 | 目标短代码 | 前缀高度 | 调用 | 工段 | 峰值活槽 | 成品槽 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| 直接落角 | `CuRuSuP-:--RuSucb:crRuSucb:SuRuWuRu:WuRuSuSu` | 3 / 3 / 3 / 3 | 18 | 94 | 4 | 0 |
| 悬空落角 | `CuRuSuP-:--RuSu--:crRuSuRb:SuRuSu--:WuRuSucg` | 3 / 3 / 5 / 5 | 24 | 145 | 6 | 0 |

两份样件的 q0 都先把落点材料移到晶下空隙上沿，再用远锚带走填充晶体。直接样件的 q3 先做好蓝晶紧柱并切掉填充料，再用一次顶针补回底部针前缀。q3 助手直接逐层上料，第 82 笔转向前跳过空远锚。

| 悬空样件地址（含首尾） | 工序 | 结束时的活槽 |
| --- | --- | --- |
| 49–53 | 第一半形拼合，消费第二角 | 0 第一半形 |
| 63–74 | q3 主柱保留近侧填充料，再补一层普通料 | 0 第一半形、1 第三角、2 第四角主形 |
| 75–84 | 近锚备料 | 0、1、2、3 近锚 |
| 85–100 | 4、5 搭远柱，交换后近锚接手 | 0、1、2，3～5 可复用 |
| 101–125 | 3 放晶脊，4、5 搭触顶针柱并拼补形 | 0、1、2、3 补形 |
| 126–133 | 消费补形完成顶破，再补两层助手、切取和转向 | 0、1、2 第四角 |
| 134–138 | 第二半形拼合，消费第四角 | 0、1 第二半形 |
| 139–144 | 合并双半形，补入 q0/q1 的两份原色尾料 | 0 成品 |

悬空样件的初始主柱触地，近侧填充料可直接当支撑。补到五层后，形状与原 172 道配方的首次支撑切取出口一致。该样件的基础料工段从 58 减为 49，每件成品的 C 整片用量从 213 减为 177，沿用原有基础料短代码和货种。需要碎掉空底补晶的角仍执行原有初始支撑步骤。

地址 85–100 的支撑交接结束后才复用槽 3～5 制备触顶补形。前半形和第三角一直保存在槽 0、1，峰值仍为六槽。直接样件的尾料是完整的最后两层，悬空样件的尾料只有 q0/q1。

两份配方均通过 `recipe.replay`。两段拼合后的半形各自与 `CornerBuilder.pair` 的制造证书逐形一致。现有 48 工段实体验收线要执行这些指令，需按样件容量扩建。游戏内锁存、换单和满带由房间 #72 跟踪。
