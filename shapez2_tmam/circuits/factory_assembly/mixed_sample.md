# 动态含晶六槽工道

```bash
python -m shapez2_tmam.circuits.factory_assembly.mixed_sample --output mixed-dynamic.spz2bp
python -m shapez2_tmam.circuits.factory_assembly.mixed_sample --compact --output mixed-dynamic-compact.spz2bp
python -m shapez2_tmam.circuits.factory_assembly.production --stages 6 --handoff --compact-dyes --output six-slot-production.spz2bp
```

前两条命令合装私有配方发布器、动态提交桥和六段实体。`--compact` 只安装这两份订单需要的停靠点。第三条命令只导出实体工道，供外置主控按容量接入。`--compact-dyes` 将结晶卸货、混色和转接合到一块 3×3 平台，仍使用现有的一节三原色流体车。结晶车头位由 `(18i−9,3)` 移到 `(18i−6,3)`，朝北，`i` 是从零起算的地址。基础料车头和成品带均按 `interfaces.stations` 和 `interfaces.output` 接入。

## 接线与换单

样件按 `1640047` 的订单号和工道发布的地址 `1640000` 计算当前六字段和候选地址。发布器来自表中两份逐笔回放过的配方，装方结果由回放产物给出。接入其他动态主控时，移去 JSON 中 `fixture.platforms` 的六块发布板，由主控独占原目标、实际回放、长度、通过位以及私有候选频道。

| 频道 | 信号 |
|---|---|
| `1680001–1680006` | `opcode/a/b/destination/base/color`。整数 `0` 是合法槽号。空字段发空信号 |
| `1680007` | 六字段对应的地址，首笔用整数 `0` |
| `1640002–1640007` | 提交桥发布的工道六字段，保持当前组直到地址推进或复位 |
| `1640046` | 桥确认公开字段与当前组吻合后发布的地址标签 |
| `1640008/1640009`、`1640013` | 两个实体存储组的回读和逐笔 ACK |

主控按其字段板的最长路径报告配置 `submit_bridge` 的等待。样件等待 384 信号 tick。换单先停料，保留旧目标和旧配方让在途品排出，检查加工机、支路和成品带。三个操作开关置 0，保持写入相位 `3` 连续至少 128 tick，然后选择新单并打开 `run`、`clean_confirmed`。末笔 ACK 后 `loaded=1` 才开料。双回读接管占用 `1683000–1683004`，其余频道与开关见同名 JSON。

## 站点和一带供货

| 装配 | 基础料停靠点 | 结晶停靠点 | 岛项目 | 建筑 |
|---|---|---|---:|---:|
| 六段通用线，原结晶两平台 | 0–5 | 0–5 | 498 | 200,428 |
| 六段通用线，合并结晶平台 | 0–5 | 0–5 | 492 | 197,338 |
| 两单共用站场，合并结晶平台 | 0、1、2、4 | 1、3 | 336 | 160,280 |

任意地址可接收操作 14 或 10 时，各地址保留两类停靠点。单个地址每份订单只执行一个操作。以地址 1 为例，两单复用槽带和加工台，分别使用基础料和结晶收料口。上游按货种共用同一套配料装车和车队时，先合计同一订单所有地址的用量，再取互斥订单各货种的最大值。设满带为 `B` 件/秒，两单共用上游至少要能供 C `7B` 件/秒，R、S、W 各 `2B` 件/秒，红、绿各 `10B` 升/秒、蓝 `20B` 升/秒。沿线每个在用卸料行还要按自己的到站流量和缓冲核算。两份订单的行、层和车厢见 JSON 的 `orders[].paths`。

新结晶平台七个出口逐一核对原色来源和混色比例。黄晶站的红色底层第 30 行、绿色中层第 29 行各需 `10B` 升/秒，黄管需 `20B` 升/秒。蓝晶站的蓝色顶层第 31 行及直通蓝管均需 `20B` 升/秒。若同一车队服务多个同时工作的结晶地址，按各站实际卸入量求和，车厢和车站内部的缓冲还要覆盖最长无车间隔。成品单带口位于 `(96,0,0)` 东侧底层第 31 行。

板间无线 12 拍、配方和桥板内同拍、实体写入每门一拍的离线回放中，两单分别在 8,363 和 5,569 拍后确认 6 和 4 笔。中断了第二单地址 1 的重叠写入，复位再装成功。长单换短单后地址 4、5 的六字段均为空，连同从基础料换成结晶时清掉的 `base` 等字段一并核对。实际锁存和一满带由 #72 的游戏内验收确认。
