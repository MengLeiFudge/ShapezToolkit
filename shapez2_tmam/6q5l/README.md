# 6 象限 5 层

本部分限定六象限、最多五层，单独研究其可制作性。六列按环相邻；采用按单象限旋转、半切保留连续三列的模型。实体加工仍以游戏源码核对的连接、晶体碎裂、下落和输出分组规则为依据。

## 接手目标与阅读顺序

本范围已有[统一合成算法及覆盖证明](synthesis.md)，使用保留精确操作输出的有限配方目录。另有[完整可制作反例](non-k-half.md)：三列半形可以不属于 K，两份半形交换后还可以得到不稳定输出。因此不能直接移植四象限的全局约化。

1. 先读[三列半形与不稳定输出构造](non-k-half.md)，核对五层以内的完整配方，明确 K 和稳定性筛选为什么会漏掉合法目标。
2. 读[统一合成算法](synthesis.md)，核对操作实例、精确结算、目录规则、配方展开及终止/可靠/完备证明。
3. 读[通用列内不变量](../general/column-invariants.md)，这些局部约束仍可使用；四象限堆叠约化只在明确满足 K 等前提时引用。
4. 接着读[一般参数构造族](../general/wide-half-loops.md)，了解反例如何扩展到所有偶数 n≥6、H≥5。

## 可以引用的共同结论

- [通用列内不变量](../general/column-invariants.md)中的 Q、J，以及保留晶体前态位置、顶针输出地面针与输入底层占用的对应关系，按相同局部规则使用。
- 保留晶体每次顶针提高一层且不能下落，所以五层上限下，它自生成后沿自身路径最多经历四次顶针。该界只限制这条晶体路径，不限制所有支路或结晶前的加工。
- 必须保留单次加工的实际输出；源码不会在新接触后自动反复合组直到稳定。

## 本范围已经证明的结论

1. **K 不是全部可制作状态的必要条件。** [完整半形构造](non-k-half.md)从基础料制造 U∈K，再半切得到 H∉K；全过程不超过五层。
2. **可制作输出不一定稳定。** 两份 H 旋转到互补半面并交换，各自切割阶段保持不动，拼接后的新接触却使支撑环合为一个无支撑大组。交换器不追加重力，所以该不稳定格位确实是合法输出。
3. **存在完整的有限搜索合成方法。** [统一算法](synthesis.md)保留真实双输入堆叠及原始输出，以轮数下降的配方记录生成制造树；终止、可靠性、完备性和标签覆盖均已证明。

这一方法的原始状态上界为 4^30−1，不能称为实用求解器；未执行目录计算，未取得实际状态数量或游戏蓝图。理论覆盖保证不依赖全量目标验证。

## 后续研究

六象限的有限合成方式及覆盖证明完成后，按顺序进入一般参数研究。进一步压缩本范围算法时，应寻找能保留无针环与不稳定状态的结构分解；不能使用已被反例否定的 K 或稳定性过滤。

四象限的 1296 个单段前态界及基础堆叠全局约化不作为六象限答案。若要提出更强的六象限约化，需要独立证明它处理全部合法输入，包括双输入操作的双方。
