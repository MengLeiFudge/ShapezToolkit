# 6 象限 5 层

本部分限定六象限、最多五层，单独研究其可制作性。六列按环相邻；采用按单象限旋转、半切保留连续三列的模型。实体加工仍以游戏源码核对的连接、晶体碎裂、下落和输出分组规则为依据。

## 可以引用的共同结论

- [通用列内不变量](../general/column-invariants.md)中的 Q、J，以及保留晶体前态位置、顶针输出地面针与输入底层占用的对应关系，按相同局部规则使用。
- 保留晶体每次顶针提高一层且不能下落，所以五层上限下，它自生成后沿自身路径最多经历四次顶针。该界只限制这条晶体路径，不限制所有支路或结晶前的加工。
- 必须保留单次加工的实际输出；源码不会在新接触后自动反复合组直到稳定。

## 需要单独证明的部分

1. **三列半形的可制作性。** 四象限半形只有两列，不同非针组的高度区间不能重叠。三列中，同层两端格可以不相邻，原证明的关键步骤已不成立，需要重新分析支撑与晶体融合。
2. **K 对加工的闭包。** 四象限五层的顶针证明使用四列三层的特定环结构，不能因为层数仍是五就直接套用。当前不将六象限的 R ⊆ K 或全部可制作图形稳定作为已证明事实。
3. **堆叠约化和完整逆向。** 可以引用明确满足 K 前提的论证思路，但尚未证明全部可制作下料都满足该前提。四象限的 1296 候选数及独立单列结论不在这里直接列为六象限定理。

本部分尚无独立覆盖性证明或已核对的专属 TMAM 资料。Mari 的已下载压缩包记录在[四象限五层](../4q5l/mari-tmam.md)，不作为六象限实现的证据。八象限八层的一般反例同样不能直接判定六象限五层可达什么。
