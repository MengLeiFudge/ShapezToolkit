# Pin计数以下的普通材料前缀与可省的高次数尾部

采用偶数象限n≥2、固定高度上限H≥2。起点是任意合法最后Swap输出，尾部只含Pin、Stack及可吸收的旋转。Stack允许任意合法上料；无需假设全图属于K或稳定。N、P、C分别表示普通格、针和晶体，层号从0开始。

**若一条制造尾部含至少H−1次Pin，则同一目标存在零尾Pin的制造路线。** 因此最少尾Pin数为正的目标满足`min Pin ≤ H−2`。这里允许重新准备两个合法半形；不减少固定起点的必需Pin数，也不计半形与上料的准备成本。

## 1. 随Pin次数提高的晶体下边界

设已经完成i次Pin。尾部中现存的每颗C都来自起点，其当前高度为原高度加i。Stack不能带入保留C，C下落时会碎掉，所以当前所有C都在第i层或以上。来源与计数依据见[主干尾部界](stack-progress.md#6-任意含晶体目标的主干尾部界)。

记Eᵢ为当前物品第0至i层的N/P，擦去这一范围内的全部C，舍弃更高材料。只在i≤H−1时使用这个记号。

**前缀引理：Eᵢ独立稳定。** 它无需借助任何C或更高材料支撑。因为Eᵢ全为N/P，这等价于每个水平N块和单针都触地，或有直接下方支撑；这些支撑沿高度严格下降，最终到达地面。

## 2. 前缀引理的操作归纳

### 起点

i=0时，E₀只含地面N/P，自然独立稳定。起点的高层可以不稳定，这不影响地面结论。

### Stack

已有Eᵢ提供只使用低层N/P的完整支撑路径。第i层以下没有C，非针组不可能从第i层穿进更低层；因此把第i层N与同层C连接，也不会把它正下的支撑合并为组内支撑。旧Eᵢ全部保持。

新进入该前缀的材料只可能是普通块或针。它们若下落并停在第i层以下或恰第i层，阻挡位置必在更低层；那里没有C。因此每个新增块触地，或被更低的N/P直接挡住。按落点高度递增，这些块都加入独立稳定的N/P前缀。

同层普通块重新合并不会吞掉位于下一层的支撑边。一次Stack的原始输出因而仍满足结论，无需额外稳定化。

### Pin

由i次进入i+1次，并先设i≤H−2。旧Eᵢ的格不会被截顶；它们提高一层，原地面N/P下方的新针继续提供地面支撑。原地面C下方也可能增加针，这些新针自身触地，不会破坏已有证书。

提高后的所有C都在第i+1层或以上。旧Eᵢ的纯N/P证书因此保持，不能因更高处顶破而失去支撑。

其他材料若进入新前缀第0至i+1层，必在本次结算中下落：它们原来高于i，直接抬升不会进入这个范围。每个落入的普通块或针仍由更低的N/P或地面阻挡，和Stack情形相同。故Eᵢ₊₁独立稳定。

旋转只改变列号，保持上述性质。归纳完成。这个论证没有把六象限以上的整个输出当作稳定图形，也没有把一般Stack替换成基础单层Stack。

## 3. 达到H−1次Pin时的全部材料

先考虑尾部恰有H−1次Pin，并且成品T含C。

所有目标C都来自起点地面，现在只能位于第H−1层。每个这样的晶体列，在每次Pin之前地面均非空：第一次是旧C，后来是此前生成的针。最终该列恰为：

`P^(H−1) C`。

该列没有空洞，也没有其他N/P可插入其下。目标全部N/P则属于E_H−1，故擦掉目标C后仍独立稳定。

### 零尾Pin的显式重建

1. 对每个目标C所在列，预制一根`P^(H−1) C`紧柱。可从地面C开始做H−1次Pin，这些Pin属于起点准备；每次输入C都低于最高允许层，因此不被顶破。
2. 在两个互补半面内分别拼好这些独立紧柱，其他列先空置。各柱都有同列触地支撑，切出半形时保留整段已有C。再Swap得到B′。
3. 从低到高添加目标的其余N/P。每个水平N块作为一次无晶体基础上料，每根针单独追加。由于目标N/P擦晶后独立稳定，各块都有地面或已经完成的下一层支撑，恰好落到目标高度。

B′的晶体列已经占满全部H层；新增材料不会使用这些列，因为其中的目标N/P已经全部是B′的针前缀。因此高晶体不会挡住新增块的落点。其他列按高度递增填入，没有先放上盖、再向其下插料的问题。

得到`B′ → Stack* → T`，零尾Pin。各柱及半形均有实际制造过程，不只是一个稳定候选。

## 4. 更多Pin与无晶体目标

若尾部含至少H次Pin，任何起点C都会达到上限外，不能留在成品中；Stack也不能补回C。因此成品全为N/P。

[可制作输出的无晶体组支撑性质](stack-progress.md#1-可制作输出的无晶体组有直接支撑)保证这样的成品稳定。其所有组都是单层N块或针，支撑边严格向下，可以直接从地面开始逐层Stack制造。第一层可由两个基础半形Swap拼出，其余层逐块追加，仍是零尾Pin。

同理，第3节中恰有H−1次Pin但最终无C的情况也直接归入此处。空目标单独按空输出处理，不构成正Pin数下界。

于是任意一条至少H−1次Pin的路线都具有零尾Pin替代。反过来，若目标的最少尾Pin数为正，它的任何路线都不可能达到H−1次；已有路线必满足：

`1 ≤ min Pin(T) ≤ H−2`。

### 全部保留晶体原来触地时的同一改写

更一般地，若一条含p次Pin的路线中，全部目标C都来自起点地面，则它们在目标中同处第p层，各自下面恰为p根连续触地针。先准备这些`P^p C`柱，再从低到高补其余N/P，同样得到零尾Pin路线，不要求p=H−1。

第0至p层的新增N/P由前缀引理独立支撑。第p层以上没有C，所有N块和针由可制作输出的支撑性质获得下一层支撑；该支撑可以是第p层C，也可以是已添加的N/P。晶体列在第p层以下已经占满针，新上料不会在那里插入格；第p层以上则可正常在这些柱上堆叠。因此逐层追加没有来源冲突。

特别地，若目标C全在同一层h，而某条路线有h次Pin，那么该目标其实具有零尾Pin路线。故这类目标若最少尾Pin数为正，还满足`min Pin ≤ h−1`。这没有把“所有C同层”本身当作零尾Pin的充分条件；p=h这一来源条件是证明所必需的。

## 5. 对三次必要顶破的直接约束

结合[四象限顶破几何与顶盖替换](ceiling-destruction-bound.md#5-破坏次数对pin次数的必要下界)：如果一个四象限目标要求每条路线至少有e次晶体破坏，则其任意路线至少需要`e+floor((e−1)/2)`次Pin，而且它不属于零尾Pin目标。因此：

`H ≥ e + floor((e−1)/2) + 2`。

三次必要破坏要求H≥6。因此**四象限五层及更低上限，不能出现强制三次晶体破坏的完整目标**。[四次Pin的完整排除](dl-dd-reduction.md#6-三次必要破坏的新下界)进一步要求三次必要破坏至少有五次Pin，把高度下界收紧为H≥7，排除四象限六层及以下。[唯一低处释放与顶层边界](single-deep-release.md)进一步得到三次必要破坏要求H≥10，排除四象限九层及以下。这里排除任意合法起点下的必要性，并不禁止某个固定起点执行三次破坏。

一般偶数n仍有`min Pin ≤ H−2`，但四象限的DDD排除不能用于六象限。所以六象限五层的三次必要顶破没有被本页排除；任意高度四象限的三破坏目标也仍未解决。
