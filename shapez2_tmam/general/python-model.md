# 偶数参数的Python模型与构造边界

Rules现在接受偶数象限n≥2、制造层数上限H≥2。采用单象限旋转、等分半切，以及既有一次分组/下落规则。开放的是参数化物理及已证明的构造接口；没有把固定参数的有限目录证明实现成实用完整通用求解器。

## 1. 参数化部分

| 接口 | 范围与行为 |
|---|---|
| Rules | 按n环邻接，按H截高；Stack上料提高H+1；Pin排除原第H层并处理融合删除 |
| Builder | 基础层、无晶体纯针行段、独立柱、晶体前缀、连续半面拼接；replicate可提升同H的小象限真实配方 |
| Constructor | 两象限任意H及通用无晶体目标完整判定；其余独立柱/前缀及复制商图局部构造未覆盖时返回unknown |
| stack_successors | K_add下料的n²+1种结构基础块；未通过充分判据时保留真实上料 |
| ordinary_stack / single_stack | 给定真实下料的普通追加、针尾及部分交错N/P构造；依次尝试无C、原位补C、列内压紧及针下间隙载体，不额外结算下料 |
| HalfCatalog | 按前/后半用途保留最低成本原输入；按目标n个有向投影选目录内较短配方 |
| StackPlan / StackCatalog | 任意堆叠的精确摘要及目标前缀匹配，保留每个键最短的已知凭据；缺失不是不可制作证明 |
| Recipe.steps / step_count / register_count | 任意本模型配置的消费式步骤与完整中间产物；建立节点时计算总步骤数和物品槽需求，按子树槽需求降序调度 |

物理规则保持：groups的邻接取模n；collapse的静止组、移动N/P块的层序落点不依赖四象限或五层；cut用n/2；stack与pin使用实例H；rotate按整数列置换。实现采用[一次排序、反向支撑队列及列顶扫描](physics-scan.md)，stationary在collapse和上料摘要间共用。新接触不在本次加工中合组，交换后不追加重力。规则证明来源见[六象限局部计算](../6q5l/synthesis.md#2-不依赖-k-的精确操作计算)、[一般参数模型](general-model.md)和[通用堆叠证明](pin-tail-stack.md)。

无晶体目标的完整判据也跨参数成立：非针组只有单层水平连接，针独立，所有直接支撑边严格向下，不存在悬空环。每个非地面块必须正下方有支撑；相邻普通块合并只发生在同层，不会吞掉这些下方支撑。因此可制作无晶体输出稳定，并可按层精确重建。任一整空中间层或无支撑块都会被逐层构造拒绝。

独立N/C紧柱用其他列普通助手隔离结晶，再用相交于目标列的两个半切切出。n=2时半面本身就是单列，也成立。连续柱的针前缀及普通/针尾部沿原构造生成；拼接的保留窗口覆盖已有片段，丢弃侧只有空格，因此不会误删已有晶体融合组。

## 2. 固定范围没有自动扩大

- 完整Solver4、CornerBuilder、前缀强制闭包、Pin/Cut逆像生成器与四列Pin像判据都明确要求4q5l。
- Constructor只在原4q5l/6q5l范围调用旧列A筛选；四象限半形算法仍只用于4q5l。K必要性另已由两列几何推广到n=2任意H，并接入两象限完整前缀构造；其余参数不能因不属于K而被判不可制作。
- 原生解码和无晶体电路保留4/6象限五层范围；四象限六寄存器指令保持4q5l。
- 奇数象限与H=1直接拒绝；没有为它们猜测新的切割或Pin语义。

Recipe保存制造上限height，Builder创建和组合配方时传递并检查它。相同格位在不同H下执行Pin可能得到不同结果，所以不能只看成品高度判断配方配置。不同象限或上限的输入不能混接；instructions也会拒绝非4q5l配方。

## 3. 使用方式

```bash
python -m shapez2_tmam.synthesis 'cr--------------' --quadrants 8 --height 8
```

默认仍为4q5l。--complete要求--quadrants 4 --height 5；--instructions接受--quadrants 4或6及--height 5，六象限净转两格拆成两包，继续复用同一物品槽。参数不符合时在处理目标前报错。普通结果仍为solved/unsolvable/unknown，其中含晶体局部构造失败返回unknown。

Python可直接建立Builder(Rules(8, 8))并调用single_stack或HalfCatalog。所有输入图形须由同一Rules解析、所有输入Recipe须来自同一制造配置。

[八象限八层代表](../examples/8q8l-single-stack.md)已展开为98步：八层辅助晶体塔顶破后形成非K下料，再将双层普通上料一次堆入。最终只有六层，但全过程要求八层上限。它是既有证明的具体配方导出，不表示默认Constructor已能从任意同类目标自动发现该准备过程。
