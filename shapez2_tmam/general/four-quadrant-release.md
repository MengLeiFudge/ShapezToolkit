# 四象限任意层：直接释放构造的覆盖边界

四象限五层的直接释放可以推广到任意H≥2，无需新增工序模板。这里证明充分构造；一般悬空落点仍不能套用五层顶破程序。

## 1. 可直接推广的条件

设指定主列w满足[列条件A](angle-synthesis.md)。对每颗正下方为空的目标C_r，记最近下方N的目标层为m，层号从0开始。再要求：

```text
m=0，或w[m−1]非空。
```

也就是每个需要回落的N在目标位置有地面或同列直接阻挡。这不是要求整列连续；可以有多个晶体区间和多个间隙，数量随H增长。

## 2. 同一个制造过程

主列固定q0，永久助手放q1；另一朝向对称。

1. 把每个上述N_m的来源移到r−1。最高目标C以下其余空位填牺牲C，保留其余目标格。永久助手为H层N，仅在各r−1放P，防止把活动N固定在来源层。
2. 用连续晶体前缀和N/P后缀构造主列及助手。主列最高C以下连续；针仍只在触地前缀，所以该准备步骤合法。
3. 若没有牺牲C，直接得到目标角。否则在q3准备一根H层N/C柱：牺牲C所在层放C，其余放N。与前两列交换拼合。
4. 半切只保留q0/q1，切掉q3并连带删除主列牺牲C，活动N落回各自目标m。

这是`CornerBuilder._simple_corner`原来的过程，只把助手及触发柱长度从5换成H。

## 3. 为什么不会删除目标C

每段目标C正下方若有空隙，其最近N被放在该段C的正下方r−1，从上方把牺牲C与目标C隔开。下方若还有目标C，A要求其正上方非空，且两段C之间有空格时至少有两个N。

因此被上移的最近N不会是下方目标C正上方唯一的N；至少有一个未移动N把下方目标C与牺牲区间隔开。底部没有下方目标C时也不产生融合风险。其余直接相连的目标C构成连续段，不需要在段内填牺牲C。

永久助手没有C，远侧柱的C只与牺牲C同层相邻；原本隔离的牺牲区间也由远柱的N层隔开。所以任何触及切除侧的晶体融合分量都不含目标C。

## 4. 为什么多个落点互不干扰

永久助手是一根连续N/P柱。所有未移动主列N/C都在同层接到助手N；助手P只位于活动N的来源层r−1。因此未移动的主列格及保留C被固定。

若m>0，条件要求目标(m−1)非空。该格不会是另一个被上移N：它若为另一间隙的最近N，则对应的C必须在m−1与当前最近N_m之间，整数层号上不存在这个位置。它也不在某个活动N的来源层，因为这将要求目标m本身为C，与N_m矛盾。故它保留在m−1并获得固定支撑；移动N恰好落到m。m=0时则落地。

不同间隙由保留C及不移动N分隔，单列先后顺序保持，不会累计错落一层。最高C以上的目标N/P也没有被移动，按与助手共同构造的原层位保留。最终角是指定主列加永久N/P助手。

## 5. 程序中的范围

四象限任意H的`build`和`pair`接受上述直接释放；两列目标还须稳定。制造外向两角、拼合后去助手的证明同样适用，因为助手只含N/P。四象限五层仍另有已证的参数顶破，所以其列A充要条件保持完整。

H≠5且存在悬空落点时，当前程序返回None，不推定该角不可制作。`Constructor.construct`可以尝试两个切向的这些半形，全部失败仍返回unknown。没有把4q5l的全局K筛选、三次尾部Pin界或完整求解器推广到任意H。

例如`CN-N-C`满足A，但N的落点下方为空，不在本定理内。目标地面C若被保留，它自生成以后沿该保留格到最终输出的路径不能再经历Pin，因为保留C不能下落，而每次Pin把它提高一层。此约束不禁止其他辅助支路Pin，也不证明该列不可制作。[everain文献核对](column-paper-assessment.md)补了三连晶窗口的环下落，以及联合提高普通双格后拆框恢复的八层半边实例；这些充分构造已手工核对，尚未接入程序。[制造历史归纳](half-history-normalization.md)已补齐两个半边候选的拒绝方向和S列必要性；[完整列构造](column-construction-complete.md)已补齐任意层S判据的充分方向，并与半边必要性合成双候选充要判据。新构造尚未接入本页的Python直接释放入口。

本页是任意层充分构造的人工证明；没有运行新高度目标、枚举、测试或游戏。已有五层固定配方的行为保持。
