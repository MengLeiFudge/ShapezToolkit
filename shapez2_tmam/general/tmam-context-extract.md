## 2. 固定下部来源，顶盖只有至多四种破坏效果

来源：`TMAM_v87_REPORT_KO` 第2至3节，原文9523—9605行。

令机器上限 H≥2，来源为 `w:a`，w 是下方 H−1 层，a 是机器最高层。只对 w 中的晶体建立融合连通分量，记录这些分量在 w 最高层暴露的位置。令：

```text
D(w,a) = 与 a 中晶体竖直相邻的 w 的晶体连通分量集合
```

若 `D(w,a)=D(w,b)`，则：

```text
Pin_H(w:a) = Pin_H(w:b)
```

理由可以直接拆成三步：最高层的所有晶体都是删除起点；向下传播的删除集合只取决于触及哪些 w 分量；最高层其余材料全部截去，且 H≥2 时地面针来源仍在相同的 w 中。因此重力之前的保留网格完全相同，之后的确定性加工也相同。

四象限的一行最多暴露两个互不连通的晶体分量，只有对角晶体可能分离。因此固定 w 后，破坏集合至多有 `2²=4` 种。扫描过程中还可把暴露边界编码为18种状态：空1、单晶体4、相邻双晶体4、对角双晶体的两种连接关系4、三晶体4、四晶体1。18是晶体连接边界数，不是整个求解器的状态数。

### 与现有代码的差别

[`PinFamily`](../synthesis/inverse.py)已经按“同一下方四层＋同一顶层晶体掩码”合并空/N/P顶盖。`pin_families`仍逐个允许晶体掩码检查 Pin 像；[`pin-cursor`](../4q5l/pin-cursor.md)的电路也使用这种分族。

新增价值是进一步合并**不同晶体掩码但相同破坏效果**的物理计算。对某个已计算的破坏类型，物理失配可以同时否定该类型的全部顶盖。实际收益受已有最大顶盖筛选影响，尚无测量，不能把16→4写成整个求解器四倍加速。

### 必须保留的制造区别

相同 Pin 输出不表示两个完整来源都可制作。v87 用 F0 的实际接受顶盖作为制造见证；任意拼出的最简顶盖只用于表示物理效果。

我们若采用该方法，应把两层问题分开：

1. 按破坏集合共享 `pin_image_matches` 或正向 Pin 的结果。
2. 在每种效果内保留全部可能的来源制造分支，或另证完整的代表选择规则。
3. 成功时返回带真实制造证书的原来源，而非随意选择的顶盖。

这是本次最接近现有实现、且不需要大目录即可利用的局部结果。

## 3. C7-BlockBatch：一次顶破同时安排多个落点

来源：`ALL_LAYER_BLOCK_BATCH_REPORT_KO`，原文60—412行。

外部构造将目标列分为：

```text
w = Z · c · I1 · c · … · Im · c · T
```

其快速分支要求：w属于其已有 Corner 语言；最低晶体前的 Z 不含针且走 event 路线；Z 的第二枚普通格位置不超过2；内部段属于其定义的 natural 或 weak-strict event 段。文本没有在本报告中完整重述这些语言定义，所以不能仅凭列A或这一形式接受所有列。

### 可复用的机械机制

四列 A/B/C/D 分工如下：

- A放目标材料、临时提高的普通格和局部牺牲晶体。
- B保留永久支撑；在应独立下降的普通格旁放针，避免横向粘住；在应共同下降的位置放普通格。
- C为贯穿实际上限的牺牲晶体塔，Pin顶破时触发删除。
- D提供连到牺牲塔的晶体桥、与活动普通格同行的普通格，以及目标落点下一层的挡块。

活动格和D的同行普通格共同下落，D的挡块决定停止高度。因而即使目标列的落点正下为空，也可以借另一列停住。多个区间通过保留晶体与不同来源层隔开，在同一次从下到上的重力处理中完成。

最低压紧区的普通格位置为 `p1<…<pk`（位置从0计，序号i从1计）。报告取：

```text
b = max { i | p_i ≤ i }
d = max { i | p_i = i−1 }，没有时为0
```

将前b枚普通格在 Pin 前连续放于1…b层。Pin后位于2…b+1层；前d枚下降两层，其余下降一层。B中的针链与普通双格使这些不同下降量在同一次结算中成立。

### 保留一个可继续核对的具体输入

目标A列自底向上为 `SS-S-cS-S-c`。报告给出的完整前驱为：

```text
-ScP:SccP:SPcP:SScP:cScS:SScS:cScS:cScc:SPcS:cScS:--c-
```

该前驱占11层，必须用实际cap11理解这个实例，不能按目标列的10层截短。报告称一次Pin后，A列完成三个底块落位 `2→0、3→1、4→3`，以及上方 `9→8` 的局部恢复；这些坐标是Pin后、下落前的来源坐标。完整四列的输出还含助手，不能把它直接称为已取得独立目标列或最终半形。

### 能补哪个缺口

[`four-quadrant-release`](four-quadrant-release.md)目前要求每个活动N的目标位置触地或有同列直接阻挡；`CornerBuilder.build`在非五层四象限不处理一般悬空落点。外部D列挡块机制正好提供一个候选补充。

落地前仍须证明：四列前驱如何在同一个H内从基础料组装；辅助晶体不会连到目标晶体；B/D支撑不会误固定活动格；加工后助手能按合法Cut/Swap路线去除或置换。每列单独属于某种语言，不能代替四列整体前驱的制造证明。

该机制已与everain路线合并进[四象限完整列构造](column-construction-complete.md)：源格、旁列挡块及满高触发的支撑证明已经补齐，底块使用最多两次提升的准备路线。外部特定压紧公式和本节11层前驱的完整效果仍未据此自动获得验证。

## 4. 目标游标：合并不同前驱的等价搜索历史

来源：`TMAM_v85_REPORT_KO` 第2至4节，原文8963—9051行；v86结合逆判定见9348—9378行。

固定目标T，按列列出全部非空目标格，保留原层号：

```text
column[q] = [(height, kind), …]
p[q] = 该列已经生成的目标格数量
h[q] = −1                         当p[q]=0
       column[q][p[q]−1].height   其他情况
```

同列格不能互相穿过，所以匹配目标的部分输出是该列列表的前缀。对固定T，四个p确定已经生成的目标网格及当前列顶。

外部并非只用四个p作为状态。其完整合并键还包含来源扫描行号、来源F0自动机状态、待破坏晶体的连接边界，以及有向支撑关系与尚未履行的支撑义务：

```text
state = (source_row, source_state, destruction_boundary,
         support_boundary, p0, p1, p2, p3)
```

相同键的历史才共享后续搜索。移动块的落点由 `1+max(h[q])` 计算；只有对应各列的下一目标格在高度、材料上完全匹配，才推进游标。固定格仍按来源坐标处理，不能把所有格都当作从无限高处落下。

终态允许留下尚未生成的目标N/P后缀，并逐层验证它们可由后续Stack追加。所有目标C必须已有来源。外部据此得到一次PP加后续Stack的完整F1判定；固定四列、固定来源识别器及物理边界下，状态上界为 `O(KH⁵)`。常数K可能很大。

### 对本项目的增量价值

[`Solver4.predecessors`](../synthesis/solver4.py)已经按目标列前缀选择S前态，但其后仍调用`pin_families`组合来源列，再递归取得来源证书。它与外部的“逐行生成来源，同时消耗输出游标，合并相同边界历史”不是同一种枚举顺序。

值得借鉴的是把匹配条件提前嵌入来源生成，并共享具有相同未来行为的历史。不能只按四个目标游标合并，否则会丢掉辅助晶体的未来删除、支撑和来源可制作性约束。

来源方面，[任意高度零尾针闭包](zero-pin-source-closure.md)已利用完整半边定理，给出不依赖外部F0 DFA的判定及制造证书。它尚未实现为逐行联合自动机；直接调用现有Python局部构造器仍只有局部肯定能力，失败仍是unknown。下一步的状态摘要必须保留该完整来源语义。

支撑语义也须对齐。v85使用到地面的有向可达义务；本项目[`Rules.stationary`](../synthesis/physics.py)保留最大静止集合，K判据允许含针环，而Pin分支另用G接地条件。不能把v85的接地条件推广成所有来源、所有象限的稳定性定义；须证明所接入的具体阶段满足相应接地前提。

v86进一步给出 `C(L(PP(F0)))` 这个受限两次Pin语言的联合游标，免去外层四个中间截点枚举。它的局部算法仍可研究；把它称为全体图形判定器所依赖的旧rank2猜想已被文件开头的新rank3结果否定。

## 5. 无顶破Pin之前的追加，可以移到之后

来源：`TMAM_v86_REPORT_KO` 第1至2节，原文9267—9315行。

为避免与材料C混淆，这里把外部追加闭包记为 `Cl`，L表示输入稳定且**机器最高层没有晶体**的Pin。外部结论为：

```text
Cl(L(Cl(A))) = Cl(L(A))
```

对一个原先落在第ℓ层的普通连通块或单针，移动方法为：

| 原落点 | 改到L之后的处理 |
|---|---|
| ℓ=0 | 先在该块涉及的各列补地面针，再堆原块 |
| 1≤ℓ≤H−2 | 堆原块，其落点自动提高一层 |
| ℓ=H−1或更高 | 原块最终会被截去，省略 |

该等式允许改变追加操作的数量，不是两台机器无条件交换。新地面占用产生的针必须补回；有顶破晶体的Pin不能套用。

本项目[第一次无顶破Pin移到交换前](tail-sequence-extension.md)已经证明了相关但不同的正规化。外部结果补充的是对任意合适中间输入的追加闭包交换，可用于受限尾部的存在性判定与搜索合并。

我们的[单层Stack次数下界](forced-stack-length.md)仍需按原计数保留：上述变换可能增加补针步骤，不直接给出等长或更短的制造计划，更不能用于否定必须发生在破坏型Pin之间的Stack。

## 6. 值得追索的尾部上界与有限闭包证据

### cap5可能只需一次外层Pin

v46原文2917—2959行称：固定cap3、4、5均在F1达到完整PP/Stack闭包，即这些范围 `G=F1`。这比本项目完整4q5l逆推允许至多三次尾部Pin的存在性上界更紧，值得优先核对。

但两者目前不能直接等同。需要核对外部Half语言是否包含本项目全部合法半形、F0是否恰好对应我们的A→S，以及物理、起点和供料约定。原文的cap5全目录及闭包结果不在这份文本里；若希望不依赖大表缩短电路搜索，仍需在本项目模型内得到可检查的完整证明。仅有一个总数不能把`remaining_pins`改成1。

### 全高度rank≤3与至多五步

原文1—13行后补结果称：固定共同cap、完整非空F0来源和供应物免费准备时，所有可制造目标最小外层PP rank≤3，主路径至多5次PP或二元Stack；cap17有精确rank3且最少5步的目标；另有指定底部与屋顶的全高度扩展族。

对我们有价值的是**全高度上界和归一化方法**。本项目已对H=12的[T₃](t3-pin-lower-bound.md)证明最少三次尾部Pin，并证明[最短词P→S→P→P](t3-forced-order.md)。因此外部17层例子不能被描述为本项目首次获得rank3，也不能被读成rank3最少从17层出现。两边起点和rank定义仍须先对齐。

五步中的Stack允许准备好的供应物作为输入，而本项目的无界结果计单层Stack。多层上料可以一次提供很多格，两种口径并不直接矛盾。`Recipe.step_count`还计所有准备树，亦不受该五步声明约束。

这份文件只给出research 228/230/232/235的摘要与审查哈希，没有完整证明、归一化步骤和五步证书。现阶段应保留它们为研究依据，不能直接把任意高度搜索截为三次Pin或五次操作。尤其需要取得230的供应物类别与构造方法，才能判断它是否能转成少量可复用的实体制造阶段。
