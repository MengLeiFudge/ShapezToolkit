# 可制作图形的任意有限次重新结算级联

采用偶数象限、任意高度的既有局部规则。N为普通块，C为合法同色晶体，`.`为空；层号和列号均从0开始。F表示重新按当前格位分组并执行一次重力结算。F可用“堆叠一层纯晶体”实现：上料晶体全部碎裂，不增加普通格或针，见[堆叠进展量](stack-progress.md)。

**对任意整数k≥1，存在可制作的S，使前k次F每次都改变图形，第k次之后稳定。** 以下给出n=4k+6、H=6k−1的充分构造。k=3对应十八象限、十七层。这里的“需要k次”指从给定S反复施加F到达稳定态；不是最终成品在所有加工配方中的最少堆叠数，也没有证明n、H最小。

## 1. 逐级加宽的支撑环

把级号j从上到下编为1至k，定义：

- 第j级底层h_j=2+6(k−j)。
- 右晶体柱r_j=2j+2，内部普通块列b_j=2j。
- 左晶体柱始终在q0。

第j级占三层，格位为：

| 层 | 晶体 | 普通格 |
|---|---|---|
| h_j+2 | q0、q(r_j) | q(b_j)、q(b_j+1) |
| h_j+1 | q0、q(r_j) | q(b_j) |
| h_j | q0、q(r_j) | q1至q(r_j−1) |

未列格为空。两根三C柱经底部普通横条连成框架G_j；顶层的两颗N也连到右柱。中层q(b_j)的单N为独立组B_j。G_j的顶帽受B_j阻挡，B_j受G_j的底条阻挡，构成不触地的无针支撑环。

在地面补q0与q(2k+2)两颗N。每个非顶级框架，即j=2至k，另在q0的h_j+3、h_j+4各补一颗N；h_j+5保持空。这些N直接受下方晶体柱支撑，但与上一框架之间留有一格空隙。

称所得图形为D。所有框架分别互阻，补格及地面格也稳定，所以F(D)=D。

## 2. D确实能从基础原料制造

D只占q0至q(2k+2)，恰在n/2=2k+3列的标准半面内。先核对[列条件A](angle-synthesis.md)：

1. 没有针，针条件为空。
2. q0最低C在第2层，最近下方格为地面N。上下两段三C柱之间为`N N .`，有两个普通隔断，且下方C的正上方非空。
3. 最宽的底级右柱q(2k+2)下方有地面N；其余第j级右柱恰处在下一级内部块列b_(j+1)，下方最近非空格是下一级顶帽N。每根右柱仅有一段连续C。
4. 其他列没有C，条件自动成立。

采用[递归外侧脚手架](scaffold-halves.md)的固定右端剥离。第一步移去最右列，给q0左侧补全高N柱。下面证明此方向的全部中间半形稳定：

- 保留原列q0至qt，并在左侧补足已剥离列数的全高N柱。q0所有非针格都接到全高N柱，因此每一级仍保留的左晶体柱及底条有地面支撑。
- 若某级右柱仍在，整个框架经底条连到左柱，其内部N正下方也有底条。
- 若右柱已经移去，残余顶帽只要非空，就仍含q(b_j)，正下方有B_j；B_j正下方是已受支撑的底条。若q(b_j)已被剥离，位于它右侧的整个顶帽也早已移去，不留下悬空尾段。
- q0的补格及地面格保持支撑。最终剥离q0后只剩全高N柱。

所以每个中间半形都稳定。由该算法的反向恢复定理，逐次调用同一个角程序、交换和去助手，就能从无晶体基础料制造D。准备全过程使用同一n、H，不需要超过H的辅助塔。

## 3. 制造级联起点S

对D堆叠q1的一颗普通N。q1的最高格是第1级的底条，高度h_1；顶帽与中层原来均不占q1。因此上料落在h_1+1，与q0的C和q2的B_1同时相邻。

这次堆叠内，旧G_1、B_1仍按原组互相支撑；新增接触不会在本次结算中合组。输出S等于D加这一颗N，全部18颗晶体在k=3时仍保留。下一次重新分组才把G_1、B_1与新增N并成一个无外部下方支撑的组。

## 4. 为什么每轮只推进一级

归纳假设：第j轮开始时，前j−1级晶体已消失，第j级已被上一轮的横条接通；更低级仍保留原来的两个互阻组。

第j级底层是h_j，正下方h_j−1在框架各列都空。对q0，上一较低框架的补N最高只到h_j−2。因此合并组可开始下落，两根三C柱共六颗晶体全部碎裂。

若j<k，第j级原底条是连续普通块

`I_j = q1至q(2j+1)`。

它落向下一级。下一级顶帽和内部块从q(2j+2)才开始，q1至q(2j+1)在其顶层和中层全空。下一级底条却占满这些列，所以I_j恰好落在h_(j+1)+1。

落稳的I_j左端邻接下一级q0的中层C，右端邻接下一级B_(j+1)。这条新横条接通G_(j+1)与B_(j+1)，但当前F不会合并新接触，故下一级的六颗C本轮全部不动，留到下一轮才碎裂。

还须排除其他碎片提前越级：

- 第j级其他普通碎片，以及更高各级留下的普通格，除q0补格外，都位于I_j列区间内。第j级碎裂前，其底条挡住它们；碎裂后，下一级底条挡住它们。它们不能穿过这条连续底条去触碰更低级。
- 第j级原底条在上述列内低于其他落料，同列格位不穿透，故不会被别的上方碎片抢占更低落点。
- q0补格只沿q0下降，且被下一根保留的左晶体柱阻挡。它们不能横移到内部块列，也不能把隔着至少一列空位的两个旧组接通。
- 新横条只增加接触和阻挡；本次物理组不因新接触收缩，原有低级支撑环保持。

因此每次F恰好删除当前一级的六颗晶体，并为下一级建立下一轮的合组条件。最后一级碎裂后全图只剩普通格；本次下落已使各水平块落稳，重新分组最多合并同层普通块，不会把低一层的阻挡变成组内格，所以此后F不再改变结果。

由归纳得到：

`c(F^t(S)) = 6(k−t)，0≤t≤k；F^(k+1)(S)=F^k(S)`。

前k轮的晶体数每次严格减少，所以少执行任何一轮都尚未到达稳定态。对任意给定k，构造都有限，证明了在n、H可增长时，必要结算次数没有统一常数上界。

## 6. 与八象限十四层截图的关系

用户提供的`7f6b9ea67807ed9979c790cc47b171f8.png`展示两轮重新结算：中部碎裂形成新横向连接，随后下部支撑环在下一轮失稳。这张具体图此前没有进入代表目录；旧文档已研究过一次重新分组失稳，但没有给出任意有限轮的可制作构造。

截图的初始节点还需区分任意网格与可制作物品。按图逐格读取，q0第6层C正上方第7层为空，同列第12层又有C；这违反[晶体间隙必要条件](../4q5l/mari-corners.md)。因此不能直接把该初始网格作为可制作级联族的证明起点。本页在同一列相邻两段晶体间补足`N N .`，并另证整个准备图可制造，没有把截图的下落现象当作制造证书。

本构造没有证明固定八象限下可达到多少轮，也不提供任何目标的最少总体加工次数。证明依据是人工归纳、既有通用角/脚手架构造与源码结算规则。十八象限十七层固定代表现已由Python展开制造配方，并导出三次真实Stack的中间产物及格子图，晶体数为18→12→6→0；这份产品不替代一般k的归纳证明。没有测试、枚举、完整搜索或游戏验证，尚未生成对应游戏蓝图。
