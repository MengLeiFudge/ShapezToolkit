# 任意层角的列条件与三列释放构造

本页研究一个主列能否制成可供后续拼装的角。采用偶数象限n、全过程高度上限H、任意无C单层供料、已界定晶体颜色及现有局部加工规则。层号从0开始，N/P/C/空分别表示普通格、针、晶体和空位。

**结论：对所有偶数n≥6、H≥2，非空主列可配一根相邻N/P助手制成角，当且仅当满足下述列条件A。** 充分性使用同一套三列释放构造；多个间隙、落地和中途停止只改变辅助料参数。四象限五层也有相同充要条件，由[直接释放与参数化顶破](../4q5l/corner-synthesis.md)证明；四象限任意层的充分性尚未证明。

这是角的结论，不是任意全图的完整求解定理。指定助手的两列角、存在某个助手的主列，以及全图，是三个不同的问题。这里先解存在助手的主列，再给稳定两列角的合成推论；三列以上的无针支撑环不能强拆为互相独立的稳定两列角。

## 1. 不按完整列字串分类的必要条件

把主列补空到H格，定义A：

1. 非地面P正下方非空。
2. 最高C以下的P全部属于从地面开始的连续针前缀。
3. C正下方若为空，向下最近的非空格必须是N。
4. 同列相邻两颗C之间若有空位，则中间至少两个N，且下方C紧邻的上一格非空。

条件1来自针独立成组及直接阻挡；条件2、3见[通用列不变量](column-invariants.md)，条件4见[晶体间隙不变量](../4q5l/mari-corners.md)。这些必要性证明不依赖五层、四象限、支撑必须触地或不存在循环。颜色不改变连接关系，但制造时必须保留目标标签。

A可以顺列扫描判定：记录针前缀、最近非空格、上一颗C、其后的N数量和是否出现空位。它检查局部关系，不匹配长度H的完整字串。后面的构造证明A在n≥6时也充分。

## 2. 四列工作位置与两次半切

固定主列M在q0，最终助手F在q1，临时近支撑A在q(n−1)，切除触发列E在q(n−2)。令h=n/2。最后只保留M、F。

先把M/F放在半面{q0,…,q(h−1)}，把A/E放在互补半面，用Swap拼合。第一次Cut保留从q(n−1)开始的h列：包含A、M、F，排除E。第二次Cut保留从q0开始的h列：包含M、F，排除A。

n≥6恰好保证第一次半切容纳三个工作列。更大n的其余列为空，所需工作列数不随n增加。镜像后同样成立。四象限的半面只有两列，不能直接执行这一步；这只证明本构造需要三列工作空间，不证明四象限目标不可制作。

## 3. 一次扫描产生辅助料

设c是最高目标C的层号。若没有C，令c=−1；以下区间为空，仍可使用同一供料与切割流程。

### 3.1 把待下落N移到间隙顶部

对每颗正下方为空的目标C_r，记最近下方N的目标层为m。把该N的来源位置改为s=r−1，并清空原m。记录映射s→m。目标中m与r之间全空，所以不存在覆盖另一目标格的问题。不同C的这些区间互不重叠。

保留所有其他目标格，将0至c内剩余空位填成牺牲C。这些填充位置组成若干连续区间[a,b]。每个区间的上端b+1都是N：原来C下有空隙时，刚放入的来源N负责隔断；其他空段的上端也只能是N。

填充C不与保留C竖直相连。向上由上述N隔开；向下若有保留C，条件4保证其上一格是N，且另有一个N可作为上方间隙的移动格，不能把唯一隔断移走。底部针前缀保持；整个0至c前缀连续，且内部无P。

### 3.2 远助手托住保留格

F的H格默认全部为N；仅在每个来源层s改为P。

F始终是连续触地N/P柱。主列的未移动N及保留C都接触F的同层N，因此保持原位；来源层s的N接触F的P，不能粘上F，保留释放自由度。c以上的普通格也都接触F的N；目标P按条件1受同列直接支撑。

### 3.3 近支撑决定落点

A的H格默认全部为N。对每个牺牲区间[a,b]：

- 若b+1=s是一个记录的来源层，把A的m至b改为C。
- 否则只把A的b改为C。

E逐层使用与A相同的N/C材料。A、E都是连续触地N/C柱，可独立制造或共同逐层结晶；其晶体不与任何保留的主列C水平相连。每个主列牺牲区间都接触至少一格A的牺牲C，每格A的C都接触E的C。

这里的两种区间赋值只确定同一释放程序的删除掩码。制造阶段及切割次数不随区间类型或数量增加。

## 4. 辅助料本身可制造

主列的连续前缀满足独立柱制造条件：先制N/C核心，再补触地针前缀。随后由低到高追加F及主列c以上的N/P。F逐层有正下支撑；主列后缀N通过同层F获得支撑，后缀P由条件1保证。整个准备过程不需要悬空晶体原料。

A/E为同层同色的连续N/C两列，可以使用[共同逐层结晶](rectangular-columns.md)制造。准备各支路及拼合时，所有独立柱都连续触地，主列后缀已有F托住，所以Swap预先半切不改变输入。

所有中间产物的高度不超过H。没有顶破；制造主列底针前缀时的Pin不触顶。供料、Stack、Crystal、必要的底针Pin以及固定次数的旋转/切割/交换，足以构成真实制造树。

## 5. 第一次半切的精确效果

切掉E，晶体融合删除移走A的全部C及主列的全部牺牲区间。没有保留C连接到它们，故目标C不被删除。

F保持连续触地，主列的所有未移动N/C仍由F保持；P的原支撑保持。下面证明近支撑的落点，不能只假设它能停在所需高度。

对牺牲区间[a,b]，若a>0，其下方主列格不会是即将移动的来源N：移动来源的上一格必是保留C。该下方格若为N/C，就由F保持，A在a−1的N与它粘连；若为P，则属于地面针前缀，其旁的A从地面连续为N。因此A在区间起点以下有固定支撑；a=0时直接使用地面。

对于来源区间，A的[a,m−1]为连续N，由上述支撑保持；[m,b]为已删除的C。主列和A在s=b+1的两个N构成同一水平块。它不接触F的非针格，故能够下落。其主列下方最高障碍不高于m−1；A列下方最高障碍恰为m−1（m=0时为地面−1）。落点为

`1 + max(主列可用列顶, 近支撑可用列顶) = m`。

故落地m=0和中途停止m>0使用同一公式。新接触在本次下落中不重新合组，也不需要它来停止水平块。

对于非来源区间，仅删除A的b层C；其下N由低处支撑，b+1层N与主列的固定N粘连，故上方不会塌落。

不同牺牲区间之间的保留N/C恢复固定支撑，前一个区间的删除不会累积成后一个区间的额外下降。沿区间从低到高归纳，全部来源N精确回到目标m；其余主列格均不动。第一次Cut后主列已经等于目标。

## 6. 第二次半切与充要结论

第一次切割后A不再含晶体。再次Cut去掉A，不会融合删除主列晶体。回到m的N此时接触F在m的N：m不是任何来源层，因而那里没有隔离P。重新分组后这些N与F相连，故切掉A也不会再次下降。其他主列格的支撑同样保持。

最终得到精确目标主列和相邻N/P助手F。无C列、没有间隙的列、多处间隙及不同落点均按同一过程处理。必要性已由第1节给出，因此：

`存在相邻N/P助手使主列可制作 ⇔ A`，适用于偶数n≥6、H≥2。

材料参数可以O(H)扫描产生，制造表项数为O(H)，另外固定次数的净旋转在大n中可能需要O(n)原生单格旋转。每份独立柱/并行两列最多两物品槽；M/F准备支路至多三槽，A/E并行支路至多两槽，合成一个角至多三槽。两个完整角拼合至多四槽。完整中间图形的序列化大小不等于O(H)，也不能把制造表项数当游戏建筑数。

例如九层主列`-N-CN-N-C`满足A，其中两个来源映射为2→1、7→6。准备主列为`CCNCNCCNC`；F为`NNPNNNNPN`；A和E均为`NCNNNNCNN`。两处近支撑分别留下第0层和第5层作为落点下方障碍。一次释放让两格N分别回到第1、6层，不需要为这个九层组合增加模板。

## 7. 循环支撑按结构判断

两列角中的同层非针格必互相连接，因此两个不同非针组的高度区间不重叠。不同非针组之间的直接支撑只能向更低区间；通过一串针到达另一个非针组时，也只能到更低区间。因此，两列支撑环只能从某个非针组G，经同列一串针，再回到G。

若针链长k≥1，位于a至b层，G在该列同时占a−1和b+1层。G要绕过这些针连接上下端点，只能沿另一列跨过每个层间；竖直连接只存在于C/C之间。因此另一列必须有从a−1到b+1的k+2颗连续C。反之，这个C脊和同组上下端点恰好组成`G→针链→G`，可以形成悬空支撑。端点必须为非针；在可制作列中，上端点进一步由Q限制为N。

k=1就是三颗连续C对应一根针，局部结构如下（上方为较高层，底端N/C与顶端N属于右侧晶体连接的同一组）：

```text
N    C
P    C
N/C  C
```

这个必要性只针对两列中的这种支撑环，不是所有宽图形的通用三C下界。三列以上允许无针环，见[宽半形构造](wide-half-loops.md)。

一般支撑判定仍使用原始最大粘连组：每个非地面组必须至少有一个不同组的直接阻挡。也可反复剔除既不触地、又没有剩余支撑边的组；全部组都保留当且仅当图形静止。环是合法的保留原因，不能用“都能到地面”的条件替换。

## 8. 指定两列角，包括含晶体助手

给定只占相邻两列的稳定目标T。在n≥6、任意H下，T可制作当且仅当两列各满足A。

必要性仍为列不变量。充分性分别用本页通用构造制造两根目标列，把N/P助手朝向目标外侧。用Swap保留两角完整列并拼合，然后用两个半面的交集切出目标两列。

中间去掉一侧助手时，T本身的地面或含针环支撑仍成立：两列非针组高度区间互不重叠，所以T的支撑环必含P；增加另一侧N/P助手只可能合并非针组，不能吞并针节点和含针环。最后去掉另一侧助手后，T稳定性保证不下落。两根助手都无C，整个拆助手过程不触发目标晶体融合删除。

这允许目标的另一列包含晶体，包括第7节的循环支撑结构。它不意味着含C助手可以随时删掉：上述证明把两根指定目标列都作为成品保留，只删额外生成的N/P助手。

## 9. 实现与尚未闭合的部分

Python入口为`CornerBuilder.build`；n≥6采用高度参数化的三列释放，4q5l采用直接释放与由r/m生成的统一顶破。指定稳定两列角由`CornerBuilder.pair`生成；它使用同一列构造两次，而不是新增循环支撑专用配方。失败分清列必要条件、目标稳定性和供料边界，未覆盖的全图仍不能判不可解。

四象限任意层的[直接释放](four-quadrant-release.md)已取得充分构造，剩余悬空落点的主要缺口是：在只能保留两列的切割条件下，怎样通用地实现第5节的支撑交接，同时不因顶破删除其他目标C。五层困难角的一次Pin配方不能直接推广成任意多间隙的归纳。[递归外侧脚手架](scaffold-halves.md)进一步把H_k、V_k及多晶体列环接入通用角和双半形入口，并在六象限覆盖原稳定两列角；无法固定方向剥离的半形及完整全图分解仍开放，本页两列定理没有代替这些缺口。

一代[闲鱼TMAM](../../shapez1_tmam/xianyu_20221129/logic.md)使用七种制件模板及四种拼装顺序，载荷和朝向是参数。这提供了按加工机制组织实现的参照；不是二代需要或最多只能有七类的证明。

研究依据为逐步制造、融合隔断、精确落点及支撑图证明，以及对应源码静态核对。没有运行枚举、图形探针或游戏；没有据此生成新电路或声称建筑数量下降。
