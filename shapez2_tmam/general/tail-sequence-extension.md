# 任意强制序列的推广障碍：开头抬升与末尾补针

本页继续研究[任意正整数次数序列](forced-tail-order.md)，不重复证明已经成立的全局 P→S→P 实例。P 表示 Pin，S 表示单层 Stack；准备两个半形的操作不计入最后 Swap 后的尾部。以下给出两个排除错误推广的结果，并确定整体抬升族的最少 Pin 数；它们不是对任意序列命题的整体证伪。

## 1. 没有顶破晶体的第一次 Pin 可以移到交换前

设四象限合法尾部的开头为：

`B → S₁ → … → Sₘ → X → P → Y`。

B 来自两个合法切后半形；Sᵢ 的上料都是单层，允许 N/针及随后碎掉的 C。若 X 顶层没有 C，则可以另行准备合法交换起点 B′，只用至多 m 次单层 Stack 得到同一个 Y，尾部省去这次 Pin。

### Pin 在这里不引起下落

[四象限任意层 K 定理](four-quadrant-tail-support.md)保证 B、X∈K。此前所有 Stack 保留 B 的旧格及全部 C，故 X 顶层没有 C，也等价于 B 顶层没有 C。

这次 Pin 只删除顶层 N/针、把其他格提高一层，并按原地面占用补针。顶层没有 C，顶层的非针组只有单层 N，不能通过竖直连接托住较低组；顶层针也没有上方保留格。下方 K 支撑证书不受影响，所以不发生下落。

### 新起点的制造

记 G 为从 B 到 X 新增的地面格。每个这样的格所在列在 B 中必须整列为空：上料不能穿过旧格落地。把 G 按两个半形分别加入原半形，新增格均直接触地，可以用基础单层制造。

随后对这两个半形分别 Pin，再 Swap，得到 B′。两个半形都没有顶层 C，因此没有融合删除；各自只截去顶层 N/针、整体提高并补地面针。切线外仍为空，最后 Swap 的切割不会另碎 C。

B′ 恰好包含旧 B 与 G 经截顶和抬升后的保留格，以及由全部原地面占用产生的新针。余下差额都是原 S 段在非地面、非顶层加入的 N/针，统一提高一层。

### 保留单层 Stack 次数上界

逐个处理原 Sᵢ：保留其最终落在原第1至H−2层的普通连通块和针，去掉落地的部分，以及在原顶层或上限外而不进入 Y 的部分。剩余格仍可合成一份单层上料；没有保留格的那一步直接省去。

这些上料按原顺序堆到 B′ 上，落点恰好提高一层。提前放入 G 不会挡住任何较早保留块：若某列较早已有新块，后来就不可能再往它下面加入地面格。去掉原顶层阻挡也不影响保留块：使用该阻挡的后续上料原本只能落在上限外，不属于本次保留部分。

对其余列，原高度和支撑关系统一提高一层，列顶最大值落点公式保持。归纳得到最终逐格等于 Y，Stack 次数不增加。

因此，在允许任意合法半形准备的全局最简尾部中，**第一次 Pin 必须真正顶破至少一个晶体融合分量**。若开头连续几次 Pin 都只是抬高，可以逐次把它们移到交换前；单纯增加开头等待抬升次数，不能强制任意 a₁。

这不是“任何连续 Pin 都能压成一次”的定理。已经发生顶破后，不能直接把中间状态当成新的合法交换起点。

[无顶破Pin与追加闭包交换](external-local-reductions.md#2-无顶破pin与追加闭包的交换)另证：对任意合适中间D，Cl(L(Cl(D)))=Cl(L(D))。它把此前追加移到无顶破Pin之后，需要补回新地面针，且不保持Stack次数；不能用于消除破坏型Pin之间的必要工序。

## 2. 将 T₂ 整体抬高 r 层，也不强制多 r 次尾部 Pin

取任意整数 r≥2，使用四象限、高度上限

`Hᵣ = r+11`。

定义 Lᵣ：把原 T₂ 的全部格提高 r 层，再在四列底部各加 r 根连续针。它等于在足够高度上限下对 T₂ 连做 r 次无顶破 Pin；最高格位于 r+10，恰为 Hᵣ 的顶层。

直接照着这条路线制造，会得到尾部 `P → S → P^(r+1)`，共 r+2 次 Pin。这里起点的两个辅助塔必须分别补到当前 Hᵣ−1、Hᵣ−2，不能在改变 H 后直接沿用原十二层短代码。

下面给出更短的合法起点 Bᵣ：**对所有 r≥2，仍只需 P→S→P 即得到 Lᵣ。** 高度上限与长路线相同，没有额外借用更高空间。

## 3. Bᵣ 的统一定义及制造凭据

以下层号从0开始，未列出的格为空，空区间不放格。N 取 Su，C 取 cr。

| 列 | 针 | 普通格 N | 晶体 C |
|---|---|---|---|
| q0 | 0…r−3 | r−2、r+3、r+4、r+6 | r+5；r+7…r+10 |
| q1 | 0…r−1；r+5 | r、r+7 | r+1…r+4 |
| q2 | 0…r−1 | r、r+1、r+2 | r+4…r+9 |
| q3 | 0…r−1；r+4…r+7 | r、r+8 | r+2、r+3 |

q0 底部是这次换起点的关键：原先需要最后释放到地面的那颗 N，现在直接放在 r−2 层，下方预制 r−2 根针。两次尾部 Pin 后，它恰到第 r 层，下方恰有 r 根针。r≥2 正是这个准备方式成立的条件；r=1 不在本构造范围内。

按 q0/q1 与 q2/q3 分半，两半独立静止：

- 左半的低处 q0 N 由自身针前缀或地面托住；q1 的 C 塔由第 r 层 N 托住。q0 第 r+3、r+4层 N 横向接在 q1 塔上，再托住 q0 保留 C 与上塔。q1 第 r+7层 N 接在上塔旁。
- 右半的 q3 双 C 通过 q2 第 r+2层 N 接到较低连续 N/针。q3 的四根非触地针和第 r+8层 N，再托住 q2 辅助高塔。

四列满足列条件 A。C 正下方有空隙的活动落点只有 q2 的第 r+2层 N、q3 的第 r 层 N；前者正下为 N，后者正下为针。两者都有直接下方阻挡。因而两半都由[任意层直接释放](four-quadrant-release.md)给出制造凭据，再 Swap 得到 Bᵣ，不把“静止”单独当作可制作证明。

## 4. 三步路线的逐项结果

**第一次 P：** q0 上塔 r+7…r+10 触顶，全删。q1 低塔与 q2 高塔的辅助分量最高为 r+9，本轮保留并升到顶层 r+10。

原 q0 第 r+6层 N 升到 r+7；原 q1 第 r+7层 N 升到 r+8，仍由 q2 辅助塔横向托住。

**一次 S：** 上料为 q0/q1 双 N，短代码 `SuSu----`。它落在 r+9 层，此层已有 q3 的旧 N 和 q2 的 C。

**第二次 P：** q1/q2 辅助分量触顶删除。新 q0/q1 双 N 与旧 q3 N 同在 r+10 层，由 q3 针链支撑，形成目标顶条。其余关键格为：

- q0：针前缀长度 r，低 N 在 r；其上 N 在 r+5、r+6，C 在 r+7，N 在 r+8。
- q1：针前缀长度 r+2，低 N 在 r+2；原非触地针落到 r+3，悬空 N 落到 r+4。
- q2：针前缀长度 r+2，三个 N 在 r+2、r+3、r+4，辅助 C 全删。
- q3：针前缀长度 r+2，N 在 r+2，双 C 在 r+4、r+5，四根针在 r+6…r+9，顶条 N 在 r+10。

这些格逐项等于 Lᵣ。与直接抬升路线相比，准备 q0 的底部针前缀省去了 r 次尾部 Pin。

## 5. 具体代表：r=2，四象限十三层

这个例子中，直接抬升路线为 `P→S→P→P→P`，新路线为 `P→S→P`。两条路线都在 H=13 内完成。

起点 B₂：

```text
 z   q0 q1 q2 q3
12    C  .  .  .
11    C  .  C  .
10    C  .  C  N
 9    C  N  C  针
 8    N  .  C  针
 7    C  针 C  针
 6    N  C  C  针
 5    N  C  .  C
 4    .  C  N  C
 3    .  C  N  .
 2    .  N  N  N
 1    .  针 针 针
 0    N  针 针 针
```

```text
B₂ = SuP-P-P-:--P-P-P-:--SuSuSu:--crSu--:--crSucr:Sucr--cr:SucrcrP-:crP-crP-:Su--crP-:crSucrP-:cr--crSu:cr--cr--:cr------
```

依次顶针一次、堆入 `SuSu----`、再顶针一次，得到：

```text
L₂ = P-P-P-P-:P-P-P-P-:SuP-P-P-:--P-P-P-:--SuSuSu:--P-Su--:--SuSucr:Su----cr:Su----P-:cr----P-:Su----P-:------P-:SuSu--Su
```

L₂ 就是 T₂ 整体上移两层、下方填两层全针。这里先给出两次 Pin 的可行上界；第6节再独立排除零次和一次，证明所有 r≥2 的 Lᵣ 最少恰需两次。原 T₂ 的全局下界不能直接平移过去。

## 6. 整体抬升族的最少 Pin 数

对本页 r≥2、Hᵣ=r+11 的 Lᵣ，第3至4节已经给出两次 Pin 上界。下面补零次和一次的排除，得到精确值：

`min Pin(Lᵣ) = 2，r≥2。`

零次不可能：K 下料只能追加，故目标 q0 第r+5层 N 已在起点。标准切向中它没有同层邻居及正下支撑；另一切向中，它与 q3 第r+4、r+5层 C 构成的组下方为空。两种切后半形都不合法。

反设只用一次 Pin。以下逆推取自[T₃ 下界](t3-pin-lower-bound.md)第2至5节，但显式保留参数 r；不假设增加底针能保持旧下界。

- 保留 C 的来源为 q0 第r+6层、q3 第r+3及r+4层；q0 固定 N 在r+4、r+5。
- 保留双 C 的输出支撑迫使 q2 三个 N 的来源依次为r+1、r+2、r+3，全部固定。q3 低 N 不能在r+2层粘住它们，故来源为r+1，正上r+2层为空。
- q3/q0 半形内保留组下方为空，切向被排除。标准切向则迫使 q1 第r+4层辅助 C，向上通过r+5层转到 q2 第r+6层。它必须融合删除。
- 原右半形 q2 第r+4层为空，辅助塔只能经 q3 获得支撑。其上部 N 若低于r+9，既不会截去，也达不到目标屋顶r+10；若高于r+9，至少五根旧针会保留，超过目标四根。含针环的较低 N 至多在Hᵣ−3=r+8，也不能成为目标。因此原 q3 必有r+5…r+8四针和r+9屋顶 N；q2 辅助 C 连续到r+9。
- 旧 q3 屋顶阻止最后才补 q0/q1 屋顶；移动普通块也没有允许的直接落点。因此三份屋顶的来源均为r+9层。其下所有目标 N/针已存在。
- q1 非触地针只能在r+6层，U/V只能分占r+7、r+8层。U在上会失去全部支撑；V在上若预置于左半形，需要一颗被屋顶和U隔离、不能删除的 q0 C，若后补又没有正确落点。

因此一次 Pin 也不成立，完成这个无限族的下界。该结论只确定 Pin 总数，没有同时声称每个 r 都强制同一最简操作词。

r=1 是另外一个结果：H₁=12，L₁就是T₃，其[最少 Pin 数为3](t3-pin-lower-bound.md)。所以这一族并不随着整体抬升次数持续增加必要 Pin 数：r=1需要3次，r≥2反而只需2次。各 r 使用本页规定的高度上限，不能据此声称固定参数下任意目标的复杂度都不单调。

## 7. 任意序列命题现在还缺什么

无顶破的开头抬升可以移入半形准备；对 T₂ 的整体抬升族，r≥2已得到精确的两次 Pin 配方与下界，r=1的T₃则恰需三次。这些结果解决了该族的 Pin 计数，不证明任意给定正整数序列都不可能被其他结构强制。

剩下的核心是可重复的支撑交接，以及跨所有合法起点的次数和顺序下界。[T₃的最短词已独立证明为P→S→P→P](t3-forced-order.md)，但最后一次Pin只截盖并抬升，没有产生新的支撑交接。这个完整实例仍不能直接升级为任意交替次数序列的证明。

证据为 K 下料的落点约化、半形制造定理、列内次序与顶破的人工推导。没有运行物理模型、目标搜索、枚举、测试或游戏；短代码为表格的文字转写。
