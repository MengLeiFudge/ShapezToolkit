# T₃ 的最少尾部顶针数：从任意交换起点都需要三次

本页继续研究[强制工序](forced-tail-order.md)中的四象限、H=12 目标 T₃。P 表示 Pin，S 表示 Stack；N/C/针表示材料，层号从0开始。起点 B 可以是任意合法两半的最后一次交换结果；各次上料任意，不固定为原截图配方。主干旋转吸收到 B 与各次上料的朝向。

**结论：T₃ 的最少尾部 Pin 数恰为3。** 已有 `D → P → S(SuSu----) → P → P → T₃` 达到这个下界。本页排除一切只含一次或两次 Pin 的路线；零次已在原文排除。允许两次 Pin 之前、之间和之后任意补料。

这只确定 Pin 总数，不证明最短路线的操作词唯一，也不证明任意正整数交替次数序列都可以被强制。

## 1. 目标与通用逆推约束

```text
 z   q0 q1 q2 q3
11    N  N  .  N
10    .  .  .  针
 9    N  .  .  针
 8    C  .  .  针
 7    N  .  .  针
 6    N  .  .  C
 5    .  N  N  C
 4    .  针 N  .
 3    .  N  N  N
 2    .  针 针 针
 1    N  针 针 针
 0    针 针 针 针
```

```text
T₃ = P-P-P-P-:SuP-P-P-:--P-P-P-:--SuSuSu:--P-Su--:--SuSucr:Su----cr:Su----P-:cr----P-:Su----P-:------P-:SuSu--Su
```

引用[四象限任意层 K 定理](four-quadrant-tail-support.md)：尾部所有状态均属于 K。Stack 保留旧下料及其全部 C，只从列顶上方追加 N/针。最后一次 Pin 的输出 E 因而是目标的逐列下方前缀，含全部目标 C；额外格不能再靠后续 Stack 消除。

另外使用[列内 Q/J 与地面针来源](column-invariants.md)、[移动组不能成为固定组的最终支撑](../4q5l/support-closure.md)，以及两列半形的非针组区间性质。普通格不会在尾部被拆开；同列保留格不能穿过彼此。

假设总 Pin 数 p 为1或2，记第一次 Pin 前为 X。所有保留 C 来自 B，在 X 中位于：

- q0：8−p；
- q3：5−p、6−p。

q0 的两个 N，目标层号6、7，必须分别来自 X 的6−p、7−p，且每次只抬升、不下落。它们处在保留 C 以下，不能后补。

## 2. 两个假设都锁定同一低层骨架

先看最后一次 Pin 前的状态 Y。p=1 时 Y=X；p=2 时 Y 还允许包含两次 Pin 之间的全部 Stack。

保留 C 为 q0 第7层及 q3 第4、5层；q0 的第5、6层 N 固定。q0 第4层必空：N/C 会与 q3 第4层保留 C 粘连或融合，最终留下目标外格；针则违反 Q 或造成过长地面针前缀。

最后 Pin 后，q3 双 C 所在固定组要获得支撑，必须含 q2 第5层 N。它不能靠移动过的普通格补成固定支撑。该 N 已在 E，故其下方目标 q2 第3、4层 N 也必须在 E，不能在旧 N 下方后插。列内次序及最多提高一层把三者来源依次锁定为 Y 的 q2 第2、3、4层，全部固定。

q3 的地面针前缀在 Y 中长2，低 N 只能位于第2或3层。若在第3层，它与 q2 第3层固定 N 粘连，最后会到第4层，不能成为目标第3层 N。因此 Y 的低 N 位于第2层；第3层为空。

p=1 时这就直接给出 X 的低层骨架：q3 针0/1、N2、空3；q2 针0/1、N2/3/4。

p=2 时不能立即把这个结论向前平移：第一次 Pin 后可能还有辅助 C 支撑保留组，q2 的普通格也可能试图在中间补入。现在只可确定 X 的 q3 为针0、低 N 在1或2层；首次 Pin 后，这个 N 已在第2层，因为保留 C 下方不能接受中间补料。q0 的目标底部针0、N1则迫使 X 地面为空，低 N 在第一次 Pin 后落地，第二次再为它补针；否则地面针数不符。源低 N 只能在1或2层，第3层会粘住保留的 q3 C。

第3节先分别排除另一切向，第4节再用原右半形的辅助塔处理“中间补入 q2”这条分支。

## 3. 原半形切向与辅助分量

先排除 q3/q0 切向。

p=1 时，保留的 q3 双 C 与 q0 第5层 N 所在组，下方 q3 第3层已空；q0 第4层也为空，理由同第2节。较高 N 与针不能从上方给这个组提供支撑。因此原半形不属于 K。

p=2 时，q0/q3 两颗低 N 不能同层，否则不能分落到目标第1、3层。

- 若 q3 低 N 在1层，q0 低 N 就在2层。原 q3/q0 半形中它没有支撑：q0 第1层 C 违反 J；q3 第2层 C 会与保留 C 融合，N/针则多留材料。因此不合法。
- 若 q3 低 N 在2层，q0 低 N 就在1层，原半形必须用 q3 第1层辅助 C 托住后者。该 C 正下是针0，不能跌碎；为了让 q0 低 N 首次落地，它必须首次触顶融合删除。路径跨过第3层只能走 q1，继而第4层也只能走 q1：另外三列不是保留 C，就是会与保留 C 融合的位置。因此 q1 第3、4层辅助 C 均首次删除。

在第二种情形中，首次 Pin 后的 q3 低 N 已在2层，正上3层为空；q0 第4层也为空。原 q1 第4层辅助 C 已删，不能继续经 q0 第5层 N 托住保留组。因此首次 Pin 的输出必须已有 q2 第4层固定 N。其下两颗目标 N 不能再从旧 N 上方插入，也已在首次输出的第2、3层。反推得 X 的 q2 第1、2、3层 N 均固定。但第2层 N 会粘住原 q3 第2层 N，使它不能首次下落到第2层，矛盾。

这里没有把首次输出预先当成目标前缀；是先确定 q1 对应辅助 C 已删除，才排除其残余支撑。

只剩 q0/q1 与 q2/q3。q0 第6−p层 N 必须原已在 B；它正下为空，原左半形中同层 q1 必须有辅助 C。不能换成 N，否则那个 N 会随保留组固定到目标没有的 q1 第6层。

记该辅助 C 的融合分量为 R。它通过 q0 的固定 N 连接保留 C，因此不能下落碎掉；必须在某次 Pin 中触顶融合删除。

R 的向上路径必须经过 q1 第7−p层，再经过 q2 第8−p层：这一带 q0 分别为固定 N 和保留 C，不能放待删 C；q3 也不能提前出现辅助 C。后一点由 Q/J 及目标的唯一上部 N 得到：在 q3 保留双 C 以上再出现辅助 C，前面必须先有一个分隔 N；低于11−p的这种 N 既不能达到目标屋顶，也不能被 p 次截高删除。

原右半形因此含 q2 第8−p层的辅助塔。q2 第6−p层必空：C 会与 q3 保留 C 融合，N 会固定到目标没有的 q2 第6层，针违反 Q。辅助塔不能沿 q2 直接落到低层骨架。

## 4. 原右半形强制预置屋顶

证明 q3 第11−p层 N 及下面四根针必已在 B。

若辅助塔通过地面路径获得支撑，这条路径必须转到 q3。取保留双 C 以上、路径首先使用的 q3 普通格。它下面不能先出现另一段辅助 C 而没有分隔 N；这是 J 及晶体间隙条件的限制。

这个 N 若低于11−p，不能成为目标唯一的上部 N，也不能截掉。若高于11−p，为了从下面的保留双 C 托住它，至少要预置五根针；最低五根经历 p 次 Pin 都不会截去，已经超过目标的四根。若路径先经过另一颗较低 N，那颗 N 又回到前一种情况。于是地面路径必须使用第11−p层 N，其下恰是第7−p至10−p层的四根针。

还需排除只靠含针环托住辅助塔的替代。两列非针组的高度区间不交叠，q2 的非触地针又不能处于该塔之下。因此这种环必须在 q3 用一根或多根针连接两个普通格。较低 N 至多在第9层：其上至少还要容纳一根针和另一个 N。

- p=1：第9层及以下的 N 不会截去，也到不了目标第11层，矛盾。
- p=2：低于第9层同样不行。第9层 N 则必须保留成目标屋顶；既然旧屋顶已经存在，其下四根目标针不能以后从上方插入，只能预先位于第5至8层。这又得到同一个屋顶与针链。

所以两种支撑都迫使：

```text
q3：针在 7−p…10−p，N 在 11−p。
```

Q 随即排除 q3 保留双 C 以上的全部辅助 C。右半形辅助塔连接这个屋顶，只能沿 q2 连续 C 上行。因此 R 包含 q2 第8−p至11−p层的整段 C。

这个屋顶及四针始终由保留双 C 托住，每次只提高一层。它不能改成交换后的新上料。

### 两次 Pin 时，q2 的低 N 也不能中途补入

p=2 时，R 含 q1 第4、5层及 q2 第6至9层 C。分两种删除时刻：

- R 撑过第一次 Pin：q2 的高塔挡住全部中间上料，Y 中第2、3、4层的三颗 N 必须已经在首次输出。第4层 N 不能从 X 第4层落来（会粘住保留 C），也不能从第5层落来（会粘住仍保留的 q1 第5层 R），更不能穿过第6层以上的高塔。因此来源只能是第3层；另外两颗依次来自第1、2层，均固定。
- R 在第一次删除：q1 原第4层 C 已不在。首次输出中 q3 第3层为空，q0 第4层也为空，保留双 C 必须依靠 q2 第4层固定 N 取得支撑。其下两颗 N 不能以后插入，故同样反推出 X 的 q2 第1、2、3层固定 N。

两种情况都得到同一结论。原 q3 低 N 若在第2层，就会粘住 q2 第2层固定 N，不能下落。因此 X 的 q3 低 N 在第1层，正上第2层为空；q0 低 N 则必须在第2层。第6节将利用这个已证骨架进一步确定 R 首次删除。

## 5. 一次 Pin 路线不成立

此时 p=1。原 q3 屋顶在第10层，Pin 后成为 E 的第11层旧 N。后置 Stack 不能补 q0/q1 第11层屋顶：只带 q0/q1 会落低一层，带 q3 会被旧屋顶挡高，带 q2 则留下目标外格。因此 q0/q1 屋顶也必须原在 X 第10层。

它们不能从更高处落到第11层：移动普通块需要第10层直接支撑，那里仅有 q3 的针；但 q3 已有固定屋顶，不能再多带一个 q3 N。于是屋顶在 Pin 中不下落。

记 q0 目标第9层 N 为 U，q1 目标第5层 N 为 V。屋顶挡住后插，全部较低目标格都必须已在 X。R 含 q1 第5、6层 C，故 q1 的非触地针必须高于第6层，再往上才是 V。它不能在第8层：正下第7层若是 C/N，会连接 q0 第7层保留 C；若是针，则增加另一根非触地针。因此该针在第7层，U/V 只能分别占第8、9层。

U/V 不能同层，否则无法分落到目标的第9、5层。

- U 在9、V 在8：U 下方为空，q1 同层 C 被非触地针的 Q 禁止，q3 同层为针，不能静止。
- U 在8、V 在9：若 V 原在 B，左半形需要 q0 第9层 C 托住它。该 C 被下方 U、上方屋顶和两侧 V/针隔离，又由 U 托住，不能融合删除或下落。若 V 来自前置 Stack，单格只能落在 q1 第7层针上方的第8层；带 q0 会多留一格，带 q2 会被原辅助塔挡到屋顶以上。

两种情形都不成立。这里使用的是原[一次 Pin 排除](t2-one-pin-exclusion.md)的屋顶障碍，低层支撑与切向已在本页重新证明，没有把 T₂ 的全部下界直接平移。

## 6. 两次 Pin 时，R 必须在第一次就删除

现在 p=2。q0 的目标底部为针0、N1。X 的 q0 地面必须为空；否则两次 Pin 至少留下两根连续地面针。目标 N1 必须在第一次 Pin 后落到地面，第二次才在它下方生成那一根针。若等到第二次才落下，无法同时产生目标地面针。

X 的低 N 只能在第1或2层：第3层会与保留的 q3 C 粘连，第4、5层已是另外两颗固定 N。第1层又会粘住第4节已锁定的 q3 第1层固定 N。因此它必须在第2层。

该 N 位于保留 C 以下，已在 B。原左半形中，其正下 q0 第1层不能有 C（地面空，违反 J），也不能多放 N/针；同层 q1 只能用辅助 C，不能用无法分开的 N。

这颗 q1 第2层 C 不能在第一次 Pin 中靠下落删除：

- 下方若为 N1，它只能成为目标 q1 N3，因而必须固定，继续支撑上面的 C；
- 下方若为 C1，它与第2层 C 融合，并一直支撑到非空地面；地面为空违反 J；
- 下方若为针1，Q 要求针0也存在，两次 Pin 后前缀过长；
- 下方若为空，J 要求地面 N；但地面 N 最多升到第2层，不是目标允许的 q1 N。

所以它必须在首次 Pin 触顶融合删除。其通向第11层的路径跨过第3层时，只能走 q1：该行 q3 是保留 C，q0/q2 的 C 都会与它融合。故路径包含 q1 第3层 C，随即连上第3节强制的 q1 第4层 C。两者属于同一 R。

**R 因而首次删除，包括 q2 第6至9层 C。** q2 第10层 C 若存在也与它相连；第11层 C 不论属于哪个分量都在首次 Pin 删除。因此首次 Pin 后，q2 高处不能留下另一根替代辅助塔。

## 7. 两次 Pin 之间补屋顶也不成立

仍记最后一次 Pin 前为 Y。q3 的旧屋顶在第10层，针链在第6至9层。与第5节相同，最终 q0/q1 屋顶不能在最后 Pin 之后补入；它们在最后 Pin 中也不能下落到第11层，因为移动块没有合法的第10层直接支撑。因此 Y 的 q0/q1/q3 第10层都是 N。

先证明 Y 的 q0/q1 第9层都为空。

q0 的 U 只能在第8或9层。q1 屋顶以下的非触地针及其上方 V 都已在 Y，不能以后插入。因此 q1 第9层不能是 C：那根较低的非触地针会违反 Q。q2 第9层 C 已随 R 首次删除；q3 第9层是针。

若 U 在第9层，其正下为空，同层 q1 不能放 C，也不能放终点高度不同的 V；q3 是针。U 不稳定，所以 U 在第8层。q0 第9层若改放 C，它被 U、屋顶、q1 非晶体格及 q3 针完全隔离，由固定 U 托住，第二次 Pin 既不触顶也不下落，仍会多留 C。故 q0 第9层为空。

q2 第9层也不能改用 N：q2 已有三颗较低 N，额外 N 不会在最后一次 Pin 中截去，下落也只会多留第四颗。q0/q1 第9层的针同样无法成为目标材料；它不能截去，而 q1 的非触地针还必须低于 V。

若 V 在第9层，它只能由正下方第8层针托住：其他较低 N 必须在那根非触地针以下；q1 第8层 C 也会违反 Q。但这根第8层针的下方第7层无合法支撑：C 会与 q0 第7层保留 C 融合，N 会粘住它而固定到目标外第8层，另一根针又会多留材料。同层 q0 已空，q2 辅助 C 已删，因此 V 也不能位于第9层。

于是，两次 Pin 之间若想新增第10层 q0/q1 屋顶，单用这些列缺少第9层落点；带 q3 被旧屋顶挡住；带 q2 会留下不能删除的第10层普通格。中间所有 Stack 都保留旧格，所以不能先加垫块、随后在同一个 Stack 段移走。

屋顶也不能在首次 Pin 中从更高位置落到第10层：同样没有第9层直接支撑，且不能再带一个 q3 N。故 q0/q1 屋顶只能原已在 X 第9层，首次 Pin 时固定提高。

## 8. 首次 Pin 前预置屋顶同样矛盾

X 的第9层现在已是 q0/q1/q3 三 N。其下全部待保留普通格和针都必须已经存在，不能以后从屋顶上方插入。

R 含 q1 第4、5层 C。目标非触地针必须高于它、低于 V，且 V 低于第9层屋顶。针若在第7层，其正下第6层既不能是 C/N（连接 q0 保留 C），也不能多放针。因此针在第6层，U/V 只能在第7、8层，并且不能同层。

- U 在8、V 在7：U 正下无支撑，同层 q1 C 违反 Q，q3 为针，不属于 K。
- U 在7、V 在8：若 V 原在 B，左半形只能借 q0 第8层 C 支撑。这颗 C 被 U、屋顶、V 和 q3 针隔离，并始终受保留 C 上的 U 支撑；两次 Pin 都不能删掉它。若 V 来自前置 Stack，单格会落在第7层；带 q0 多留一格，带 q2 被原第6至9层 C 塔挡高。

所以首次 Pin 前也无法预置屋顶。结合第7节，所有两次 Pin 路线均被排除，中间允许任意次 Stack 也没有例外。

## 9. 结论及对任意序列的限制

零次、一两次 Pin 全部不可能；原制造路线使用三次。因此：

`min Pin(T₃，任意合法最后交换起点，任意前后及中间 Stack) = 3`。

原路线的最后一次 Pin 没有顶破 C，却仍不能据此删掉这个目标所需的第三次 Pin。[首次无顶破 Pin 的前移定理](tail-sequence-extension.md)只适用于第一个 Pin，不能扩成“所有不顶破的 Pin 都可以移到交换前”。

这个新下界仍没有证明 T₃ 的所有最简路线都具有 `P S P P` 的同一顺序；更没有给出任意序列的构造。与 r≥2 的[整体抬升族](tail-sequence-extension.md)相比，r=1 的底部只容纳一根针，不能把低 N 预放在两次 Pin 所需的负高度，必须真正发生释放。r≥2 时已有更换起点的两次 Pin 配方，不能从本例继续按抬升层数归纳。

证据为人工逆推、支撑与列内不变量、两种半切方向排除及已有制造配方。没有执行枚举、求解器、物理模型、测试或游戏。本页只在四象限、H=12 的既定规则下证明上述目标的 Pin 总数。
