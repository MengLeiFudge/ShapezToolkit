# 四象限任意层：交换后的整个顶针／堆叠尾部保持 K

本页将[第一次顶针的结论](first-pin-support.md)推进到任意有限个 Pin 和 Stack。对象仍是两个合法相邻两列半形交换得到的起点 B；不把任意稳定格位图当成合法起点。

**定理：四象限、任意高度上限 H，从 B 出发，只执行 Pin、Stack 和旋转，所有中间输出均属于 K。** K 表示每个最大粘连组都能通向地面或含针支撑环。允许任意合法上料，不要求上料只有一层。本文为人工证明，没有执行枚举、物理模型或游戏。

这个起点范围已足以处理[强制尾部顺序](forced-tail-order.md)中的任意最后 Swap 起点。第7节再单独处理基础料、切割和结晶起点，得到同一规则下全部四象限可制作输出均属于 K。

## 1. 贯穿尾部的材料来源

旋转可以通过调整起点和上料朝向吸收，以下保持列编号固定。

Stack 不带入能留在输出中的新 C。保留的旧 C 不下落；每次 Pin 只把它提高一层。因此在同一尾部中，任意两颗仍保留的 C 的相对位置始终不变。它们之间的融合邻接关系也不变。

固定 B 的某个原半形非针组 G₀，其中含 C。相邻两列中，G₀ 只含一个 C 融合分量，每个 N 都水平附着于同层 C，最高占用层也是最高 C 层。故只要 G₀ 有任意一颗 C 保留，整个 G₀ 都保留，并随 Pin 统一抬升；不能只删除其中部分 C 或同层 N。证明见[两列组引理](first-pin-support.md#2-相邻两列中一个非针组至多含一个晶体融合分量)。

G₀ 在原半形内有一份 K 支撑证书。离开 G₀ 后经过的其他非针组都严格低于 G₀ 的最低层；路径上的针可以在 G₀ 高度范围内，但不会高于它的最高 C。证书也可能直接回到 G₀，形成含针环，或 G₀ 本身触地。

这里的证书指完整保留相关组及其支撑边，足以给出地面路径或含针闭合路径。只要证书的格不被删去，它本身就能阻止下落；后续合并非针组也不会吞掉地面或针节点。

## 2. 同层两颗 C 构成可追溯的融合屏障

四列环中，同层两颗不同 C 的闭邻域覆盖全部四列。不论两颗 C 相邻还是相对，该层的任何其他位置都邻接至少一颗 C。

因此，只要这两颗 C 在一次 Pin 中保留，该层就不可能有被顶破融合删除的 C。顶破删除从顶部传播到该层及以下，必须经过该层，故该层及以下没有融合删除。

更强的是：若两颗 C 在某个较晚状态 Y 中仍存在，那么它们从 B 到 Y 一直存在。这道屏障也就一直存在，只随 Pin 平移。之前任何一次 Pin 都不能通过它删除下方 C。

于是得到历史保护引理：

> 设原半形组 G₀ 有 C 保留到 Y，其最低层在 Y 中为 a。若 Y 的某个不低于 a 的层含至少两颗 C，则 G₀ 的原半形 K 证书从 B 到 Y 一直保留。

证明：证书的其他非针组都低于 a，始终在这道屏障下；G₀ 自身因有 C 保留而整体保留；针不参与融合删除，其高度又不超过 G₀ 的保留最高 C，不能被截顶。原地面支撑在每次 Pin 后由新增地面针接续。按加工次数归纳，证书不会先失去支撑再下落。Stack 仅增加格位，不会破坏这份证书。

## 3. 没有同层双 C 时，支撑证书不能绕到上方晶体

设状态 Y∈K，G₀ 的最低 C 层为 a，且 Y 中所有不低于 a 的层都至多有一颗 C。

G₀ 的 C 分量只能是一根单列连续塔，记范围为 a 至 b。否则要在相邻列间连接 C，某层就至少有两颗 C。

含这根塔的最大非针组 V 也不能再含其他 C。任何粘连路径跨层都必须经过 C/C；从这一根塔接入别的 C 列，必在某层出现两颗 C。同列相邻 C 原已属于 G₀；若要接入隔着间隙的同列 C，也须借其他 C 列绕行，仍产生同层双 C。V 的所有普通格因此也在 a 至 b 内。

一般地，一个含 C 的非针组，每个被占用层都含 C：若某层只有 N，它不能通过竖直连接接入其他层。因此，Y 中其他含 C 组的高度范围不能与 a 至 b 重叠，否则又会出现同层双 C。它们只能全部在 a 以下，或全部在 b 以上。

现在沿 V 的 K 支撑路径行走。支撑边下降一层，纯 N 组和针没有跨层的内部连接；低处含 C 组的整个范围又在 a 以下。所以路径不能进入全部位于 b 以上的含 C 组。

这证明 V 有一份满足以下界限的 K 证书：

- 证书中的 C 只来自 G₀，或位于 a 以下；
- 证书中的全部 N/针都不高于 b。

它不要求仍使用原半形证书，允许之前的加工已经换过支撑。

## 4. 与保留 C 相连的普通横条形成持久屏障

考虑某层的一颗 C v，以及同层与它连续相连的普通横条。假设这些格占满四列，或占三列且唯一空位邻接 v。它们阻止顶破融合删除穿过这一层，理由与同层双 C 相同：已占位置保留，空位若放待删除 C，就会连带删除 v。

只要 v 在后续尾部中保留，这条普通横条也始终保留：它与 v 的连接只经过 N，Pin 不会拆断这种连接；整组不能下落而仍保留 v；同层 N 也不能比 v 先被截去。因而它是一道从形成时刻起持续存在的屏障。

令 Y 是这条横条已经形成的某个 K 状态，G₀ 是 v 所属的原半形组，a、b 为 G₀ 在 Y 中的最低与最高 C 层，横条所在层为 l。于是 a≤l≤b。

分两种情况：

1. **Y 中某个不低于 a 的层含两颗 C。** 第2节保证 G₀ 的原半形证书一直保留到 Y。从 Y 往后，新横条在 l 层继续保护证书的较低非针组；G₀ 整体保留，证书的针不受融合删除，也不高于保留最高 C。因此证书继续保留。
2. **Y 中不低于 a 的层都至多一颗 C。** 第3节给出另一份证书：其他 C 全在 a 以下，全部 N/针不高于 b。新横条阻止删除传播到 a 以下；G₀ 保留，其最高 C 又保证这些 N/针不会被截掉。因此这份证书也继续保留。

两种情况都得到：**横条一旦在 K 状态形成，其所属保留 C 此后始终有 K 支撑。** 这一步允许制造过程中更换支撑证书，解决了不能直接重复套用“第一次 Pin”证明的问题。

## 5. 反证排除首次离开 K

B∈K，K 上的 Stack 保持 K，旋转也保持 K。若存在反例，取第一次输出不属于 K 的操作，它必为 Pin；其输入及此前所有输出均在 K。

分析这次 Pin 融合删除后的结算。至少有一个未移动组不能到达地面或含针环，否则[未移动／移动组结算引理](../4q5l/support-closure.md#2-下落中移动过的组不能成为未移动组的最终支撑)会使全部输出仍在 K。

在这些坏组可达的支撑子图中取一个末端强连通分量。它不含地面或针，必含非针支撑环。[四列任意高度的环屏障引理](first-pin-support.md#3-四列任意高度的无针环有一道融合屏障)给出其中某组的一道保留屏障：某层至少占三格，并有保留 C，唯一可能空位邻接保留 C。

- 若屏障层有至少两颗 C，直接应用第2节。选其中任意一颗 C 的原半形组，其最低层不高于屏障层；原证书一直保留，坏组实际上有 K 支撑，矛盾。
- 若屏障层只有一颗 C，其余格全是相连的 N，属于第4节的持久横条。屏障来自未移动组，所以在本次 Pin 输入里已存在，不能是本次下落后才新接上的横条。取此前第一次形成它的输出 Y；按“首次离开 K”的选择，Y∈K。第4节保证直到本次 Pin 后，该 C 仍有 K 支撑，同样矛盾。

所以不存在首次离开 K 的 Pin。整个有限尾部始终保持 K。

## 6. 对强制工序研究的直接作用

对任意 `B → Stack* → Pin → Pin → Stack* → T₂`，第二次 Pin 的输出也在 K。因此它必须逐格包含于 T₂，并含恰好三颗目标 C；不能额外留 C，再用尾部 Stack 碎掉。

这消除了连续两次 Pin 逆推中的支撑范围缺口。[T₂ 的全局交替证明](t2-forced-interleaving.md)再分析两次删除的时间、第一轮普通格下落及顶条来源，完成连续两次 Pin 的排除。本页闭包本身不直接给出具体目标的最少工序。

## 7. 补齐其他起点：全部四象限可制作输出属于 K

前述证明对起点只用了下列来源结构：它由若干不重叠的稳定一列或相邻两列片段拼成；每个原片段中，含 C 的非针组只有一个融合分量，所有附着 N 不高于该组最高 C；其支撑路径离开本组后只经过更低的非针组。原片段不要求仍是全图最大组，拼接后的水平粘连按非针节点合并处理。

一列片段同样满足这些条件。其含 C 组是连续 C 段；其他 N/针各自成组，支撑向下，含 C 组的最高格自然是 C。因此把证明中的“原半形”换成“原片段”，第1至5节的全部步骤仍成立。

沿任意制造树的 Stack 下料支路回溯，忽略旋转及仅改标签的染色，找到最后一次不属于 Pin/Stack 的操作。其输出分以下几种：

- **基础单层。** 按四个单列分片，每个非空格触地，满足条件。
- **Cut。** 输出占相邻两列，属于 K，原两列组与支撑区间引理直接适用；不要求 Cut 输入原本属于 K。
- **Swap。** 两个合法切后半形，正是已证起点。
- **Crystal。** 在当前高度内填满空格并把针转为 C，输出每列都是从地面连续占满的 N/C 前缀。按四个单列分片，各片段独立静止，具有逐段向下的支撑证书。拼接只合并非针组，不破坏地面支撑。

空产物按空条件处理。以上覆盖本研究制造操作的全部根情形。每个根之后的整个 Pin/Stack 尾部均由同一证明保持 K，所以任意 H 下都有：

`R(4,H) ⊆ K`。

这里只改变象限数与高度，不改变已约定的晶体融合、基础供料和加工规则。没有推出 K 是可制作的充分条件，Q/J 等必要条件仍不能省去。

直接推论：四象限合法成品的纯重新结算 F 恒为恒等；不存在需要再次纯下落才稳定的可制作四象限状态。该结论不禁止 Pin 顶破引起下落，也不禁止像 T₂ 那样强制交替 Pin 与 Stack。对偶数象限的非平凡 F 级联，结合两象限定理，最小象限数至少为6；已有八象限构造给出的上界仍为8。
