# 通用列内不变量与顶针位置约束

本文属于 x 象限 y 层的一般理论，采用[参数化模型](general-model.md)的局部加工规则：普通形状与顶针下落不消失，晶体下落即碎，同列格位不能穿透。下列证明不要求整个图形稳定。不同象限数的切割、旋转仍须满足模型定义；没有运行枚举、仿真或游戏验证。

用 N 表示任意普通形状，P 表示顶针，C 表示晶体。层号从地面起为 1；“列”指某一个象限的纵向格位。四象限五层的独立单列数量和依赖稳定输入的逆向规则另见[特例文档](../4q5l/column-theory.md)。

## 1. 列内格位可以怎样变化

源码依据是 `ShapeOperationCrystallize.ExecuteInternal`、`ShapeOperationPushPin.ExecuteInternal`、`ShapeOperationSwapHalves.ExecuteInternal/MergeHalves`，以及 `ShapeLogic.Logic_IsConnected/Logic_IsFused/Logic_AllowFallDownByOne/SimulateFallDownPhysics`。程序集及部件规则的核对范围见[来源记录](../4q5l/coverage-research.md#8-来源及核对范围)。

1. 旋转只置换整列。切割保留或去掉整列；交换先切割、再拼接半形，不会把两份输入的同一列按层混合。
2. 重力只沿原列下降。两个最终保留的格不能在同列互相穿过；若两个格暂属同组，其相对位置也不会颠倒。
3. 普通格和顶针不会因下落或晶体连锁碎裂而消失。只要同列更高处的某个晶体还保留，这些较低的非晶体格也不能被顶层截断删掉。
4. 保留晶体不能下落。顶针会让它提高一层，其他研究范围内的操作不改变其层高。
5. 结晶把当前高度以内的空格和顶针都变成晶体，结果没有空格和顶针。
6. 堆叠上料的晶体不能进入结果。若下料中的某个晶体保留，它在本次堆叠中没有下落；上料格从高度上限外下降，不能穿过这个保留晶体进入其同列下方。下料其他部分可能移动或碎裂，不假设整个下料不动。

这些事实允许沿保留晶体所在列追溯制造过程。不能先把某个较低普通格删掉，再从上方把材料塞进晶体下方；上述操作并没有这种能力。

## 2. 不变量 Q：晶体下方的顶针必须属于触地针前缀

定义一列的触地针前缀为从第一层开始连续的 q 个顶针。q 可以是 0；紧接其上的格只要存在，就不能再是顶针，否则前缀还应继续延长。

**Q：一列中，只要某个顶针上方还有晶体，这个顶针就必须在该列的触地针前缀内。** 等价地，最高晶体以下的顶针只能构成底部连续前缀，不能悬空、不能夹在其他材料之间。

证明可沿制造树归纳：

- 基础输入没有晶体，条件为空；结晶输出没有顶针，也满足 Q。
- 旋转只换列。切割和交换保留某列时，也保留该列的整个针前缀。前缀从地面逐格受支撑，不下落；它不能被晶体碎裂删除。原先位于保留晶体上方的顶针也不能穿过晶体，变成它下方的新顶针。
- 堆叠的保留晶体来自下料且不下落。新顶针从上方进入，不能穿过它；原先就在它下方的顶针属于触地针前缀，不会移动或消失。原来位于它上方的旧顶针同样不能穿过它。
- 顶针把保留部分提高一层。原针前缀若非空，其下方必补一个地面针，得到更长前缀。若原前缀为空，新加在地面的针本身就是长度一的前缀；若该列原第一层为空，就不加针。原来位于保留晶体下方的顶针仍只来自旧前缀，其他顶针不能穿过保留晶体。
- 染色不改变位置或材料类别。

所以所有可制作图形满足 Q。该证明不要求每列独立受支撑，也不要求整个图形稳定，适用于半形和全图中的每一列。

### 稳定但不可制作的单列

独立单列 C-P-C 逐层受支撑，但中间顶针上方有晶体，下面却是晶体，违反 Q。四象限表示为：

```text
cr------:P-------:cr------
```

它属于 K，却不可制作。在四象限五层中，结合 R ⊆ K 可知 R 严格小于 K；一般参数下不能反过来要求全部可制作状态都属于 K。

## 3. 不变量 J：晶体下方若有空隙，最近的下方格必须是普通形状

**J：对任意晶体，若其正下方在图形范围内为空，沿同列向下遇到的第一个非空格必须是 N。不能是 P、不能是 C，也不能一直到地面都没有格。** 第一层晶体直接接触地面，不适用这个空隙条件。

先看一次切割或顶针中保留的晶体。用加工前、统一升高前的坐标分类：

- 若它原来正下方是晶体，两格属于同一融合组，也属于同一粘连组。发生切割或顶破连锁碎裂时会一起删除；若下落，也不能只保留其中一个。因此在上格保留的情况下，下格也保留，二者保持相邻。
- 若它原来正下方是普通格，这个较低普通格不会消失。普通格即使下落，也不能穿过其他保留格；它仍是该晶体下面最近的非空格，只是间距可能增大。
- 若它原来正下方是顶针，Q 保证那里是触地针前缀的末端。切割时该前缀不动，顶针时整体升高并补地面针，不能在其上方凭空产生间隙。
- 若原来已有间隙，归纳前提 J 保证最近的下方格是普通格。它不会被删掉，也不会与其他保留格交换列内次序，因此仍满足 J。
- 若晶体原来在地面，切割后仍在地面；顶针后正下方是新针，不产生空隙。

堆叠时，保留晶体来自下料且不下落；下料其他格位的下落适用同样的分类论证，上料不能穿过该晶体插入其下方。结晶输出没有空格；旋转、交换拼接和染色不改变列内关系。因此，制造树归纳同样得到 J，无须先假设整个下料稳定。

直接推论：若某列底部为空，那么该列最低非空格不能是晶体。顶针也不能作为悬空的最低格：它独立成组，结算停止时必须有正下方格位；最后的截高不能删掉这个比它更低的支撑。这项局部性质在旋转、拼接后仍保持，结晶则消除所有顶针。因此，底部悬空的非空列，最低格只能是普通形状。这不等于整个图形重新分组后稳定。

### 满足 K 和 Q 仍不够

四象限中的以下半形逐层通过右列向地面传递支撑，属于 K；没有顶针，所以满足 Q：

```text
crCu----:--Cu----:crCu----
```

但左列上方晶体隔着空格看到的下一个非空格是晶体，违反 J，不可制作。一般参数下保留的必要关系是 R ⊆ Q ∩ J；加入 K 的关系只在已有对应闭包证明的范围内使用。

## 4. 顶针逆向的通用位置约束

设 D 为非空可制作输入，T 为一次顶针的输出。这里只确定必然成立的信息，不把必要条件当作完整逆向算法。

### 保留晶体的前态位置唯一

T 在第 z 层的晶体，必来自 D 同列第 z−1 层的晶体，且 z 至少为 2。不能用“先提高再掉回原位”解释保留晶体，因为晶体一旦下落就消失。D 可以另外含有后来碎掉的晶体；这些消失部分仍是一般逆向问题的未知量。

### 输出地面针精确记录输入底层的占用列

D 第一层每个非空列都会生成一个新地面针，它不会移动或消失。因此这些列在 T 第一层一定是 P。

反过来，若某列在 D 第一层为空，任何旧顶针下面都必有一个更低的普通格：该列最低非空格不能是晶体（J），也不能是悬空顶针（局部针支撑性质）。如果旧顶针能保留，该较低普通格也不会被顶层截断或碎裂删除。它始终挡在旧顶针下面，所以旧顶针不能落到地面。

于是有精确等式：

```text
T 第一层为 P 的列集合 = D 第一层非空的列集合
```

T 的地面普通格只能落在 D 原第一层为空的列。T 第一层不能有晶体。

不稳定输入即使没有顶破，也可能在本次加工中下落。因此，一般情况下不能直接去掉输出底层、整体下移，就当成唯一前态。依赖稳定输入的四象限五层结论见[单列与逆向特例](../4q5l/column-theory.md)。
