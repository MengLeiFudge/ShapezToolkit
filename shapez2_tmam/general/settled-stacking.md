# 一次结算后进入安全范围的堆叠约化

适用于偶数n≥2、制造上限H≥2的既有规则，F表示一次重新分组、重力及截高。沿用[精确堆叠摘要](stack-summaries.md)与[安全追加范围K_X](grounded-barriers.md)。本页允许原下料D不稳定，也不把F(D)免费当作实体输入。

## 1. 扩大可以省去任意上料搜索的下料范围

定义K_pre为满足F(D)非空且F(D)∈K_X的可制作下料。K_X中的图形稳定，因此K_X⊆K_pre。对D∈K_pre及任意可制作上料U，记D₀=F(D)。精确摘要给出

`Stack(D,U) = Evaluate(D₀, P(U))`。

D₀∈K_X，所以F(D₀)=D₀，再用同一等式得到

`Stack(D,U) = Stack(D₀,U)`。

该等式只比较输出。要把右边用作真实制造，还须取得D₀：取全针基础层，结晶为纯C单层Z，再Stack(D,Z)。Z抬高后没有地面或悬空支撑环，所有C移动即碎，不贡献N/P；结果正是F(D)=D₀。准备Z为两步，触发Stack为一步。

随后由K_X定理，把Stack(D₀,U)改为最终新增N/P的逐块或逐层追加，至多H个非空层。每次的中间物品仍在K_X。故原来的任意一次Stack可改为一次真实结算触发及至多H次基础层追加；如果D本来已在K_X，直接省掉触发步骤。

本结论不要求最终新增格来自容易制造的原上料，也不需要构造原U。只用目标新增格的基础供料。它保持输出及标签，未证明配方最短。

## 2. 严格扩大：六象限不稳定输出V

[六象限V](../6q5l/non-k-half.md#5-再拼合两份半形得到可制作但不稳定的输出)是已给出实体制造树的五层图形。其高处所有C和N在重新分组后成为一个没有下方支撑的组，所以V不稳定、不属于K_X。

第一次结算使全部高处C碎裂。剩余N按各水平块下落：q0、q3原地面N保持；原第三层的q1/q2、q4/q5两块落到地面；原第四层q2、q5单格落到第1层；原第五层q1/q2、q4/q5两块落到第2层。因此

`F(V) = CuCuCuCuCuCu:----Cu----Cu:--CuCu--CuCu`。

它无C，所有N块都有直接向下的支撑，层号沿支撑严格下降并终止于地面。因此F(V)∈K⊆K_X，V∈K_pre。该推广覆盖一个旧判据必须拒绝的真实下料。

原V仍保留在可制作目录中，作为Cut、Pin、Swap的输入及目标时不作替换。只在为它生成Stack后继时应用本页规则。

## 3. 闭包算法与候选数量

[`stack_successors`](../synthesis/stack_reduction.py)保持原接口，按以下顺序生成合法上料及其输出：

1. D∈K_X：保留原有连续普通块和单针域，共至多n²+1项。
2. D∉K_X，但D₀=F(D)非空、D₀∈K_X：只生成一项`(Z,D₀)`，Z为纯红晶体单层。
3. 其余下料：保留全部已知真实上料，不增加否定条件。

Z属于[完整目录的显式紧图形种子](../6q5l/synthesis.md#3-显式可制造种子及颜色)，也有两步基础配方。因此新增后继可靠。完备性按制造树归纳：任何被省去的Stack边都能换成本页的有限基础链；D₀进入目录后，由原K_X后继逐步产生同一输出。最终闭包保持，首次出现轮数及最短配方不保证保持。

设旧快照有M个图形，其中M_safe个在K_X，另外M_pre个一次结算后进入K_X。六象限每轮Stack后继数量的上界由

`37 M_safe + (M − M_safe) M`

变为

`37 M_safe + M_pre + (M − M_safe − M_pre) M`。

每个新增适用下料的该轮上料分支从M项变为1项；后续基础追加需要其他轮。这不是完整算法运行时间的同倍改善，也没有证明M_pre占比。

## 4. 保留的缺口与电路意义

F(D)仍不稳定或不属于K_X时，本页不给出压缩。即使反复F最终稳定，也不能多结算几次再制造：这些额外结算可能删除原Stack本来保留的晶体。一般参数的紧凑完整求解仍缺这部分上料及起点分解。

电路可复用一次物理结算和K_X判定通路：先检查原D，失败后检查D₀，只需切换工作状态。它不授权把未证明等价的复杂Stack拆开。当前已实现Python候选接口，尚未为六象限构建完整搜索网表；无建筑收益测量。

证据为上述等式、显式纯C触发配方、V的逐块人工推导及源码静态重读。没有运行目标、目录枚举、物理模拟或测试。
