# 一般参数下的堆叠进展量与线性尾部界

采用偶数象限n≥2、制造高度上限H≥2的既有规则，层号从0开始。F表示按当前格位分组、执行一次重力并截高。下文的输入是实际可制作图形，不把任意语法网格当作可制作输入；允许非K及不稳定输出。

结论：令b(S)为普通格与针的总数，c(S)为晶体数，θ(S)=b(S)−c(S)。每次改变结果的Stack都使θ至少增加1。含晶体目标T从最后一次Cut、Swap、Crystal或基础供料之后，存在至多

`θ(T) + nH + n·h ≤ n(3H−1)`

次Stack/Pin的主干尾部，h为T最低晶体的零基层号；另计一个净朝向调整；若只调用单象限旋转，它至多需要⌊n/2⌋次原生操作。这个界不包含各次上料的制造子树，不是完整制造树、搜索时间或建筑数量的线性界。

## 1. 可制作输出的无晶体组有直接支撑

性质B：重新按输出格位分组时，每个不含C的最大粘连组都触地，或至少有一格的正下方属于另一个组。不含C的组只能是单层水平N块或一个P，所以其下方格必然在组外。

基础单层显然满足B。旋转、染色保持B。结晶输出在其高度内每格都是N/C；不含C的组是一整行N，触地或受完整的下一层支撑。

对Cut、Pin及Stack，考察一次物理结算结束后、输出重新分组之前的组：

- 移动过的组不再含C，只剩水平N块或单P；它触地或在紧邻下方有最终阻挡。
- 未移动且不含C的组同样是单层N块或单P。它在结算终点有地面或另一个未移动组的直接支撑。
- 未移动且含C的组，不会因为截高而只留下一个无C低层片段。Cut和Pin的保留格在结算前已全部位于H层内。Stack中未移动的下料组全部在H层内，未移动的上料组则全部在H层外、整体删除；上下料最初分离，不能属于同一个初始组。

高度小于H的单层块不会部分截高，其直接支撑比它更低，也不会在最后截高时消失。输出重新分组时，如果某个最终组不含C，它只能合并若干同层N块，或者仍为原单P。原有下一层支撑不可能变成这个单层组内部的格。因此B成立。

Swap先分别生成上述Cut输出，再拼合。若拼合后的组含C，B不对它作要求；否则它仍只合并同层N块，或保持单P，低一层的支撑不会消失。故Swap也保持B。沿制造树归纳，所有可制作输出满足B。

B没有声称含C组稳定。交换后把多个旧组粘成一个无外部支撑的晶体组，仍然允许；[V_k](wide-half-loops.md#4-两个半形拼合得到不稳定输出-v_k)正是这种情况。

## 2. 非空可制作输出必有地面格

使用[通用J不变量及针的直接支撑](column-invariants.md)。假设非空图形最低占用层m>0：

1. m层不能有C，否则该C正下方为空，J要求同列更低处有N，与m最低矛盾。
2. m层不能有P，否则违反针必须有正下方支撑。
3. 因而m层只有N。此层没有C，N又没有竖直粘边，所以这些N属于仅占m层的无C组。它们不触地、下方全空，与B矛盾。

故至少一列在第0层占用。此结论不要求全图稳定，也不允许因此删掉中间空层。

## 3. 一次重新结算若改变结果，必减少晶体

在D的最大粘连组支撑图上，静止集合由反复剥离“无地面、无剩余外部下方支撑”的组得到。如果第一轮没有可剥离组，所有组均静止，F(D)=D。

如果存在第一轮可剥离组，B保证它不可能是无C组，因此至少一个含C组开始下落并碎掉晶体。随后是否还有普通格下落不影响这个事实。F不生成晶体，所以

`F(D) ≠ D ⇒ c(F(D)) < c(D)`。

反过来，晶体数减少当然意味着图形改变。因此对可制作D，F(D)=D当且仅当晶体数保持。不能将此判据用于任意网格：悬空单N就不满足B。

F还可由合法实体操作取得：把全P基础层结晶为一层纯C上料，然后Stack到D。该上料抬高后无静止组，C全部碎裂、不加入N/P；结果恰为F(D)。故反复F的每个非空状态仍可制作，每次非恒等结算至少损失一颗原晶体；至多c(D)次改变后稳定。判断已经稳定可能还需一次相等检查。另由[逐级加宽的支撑环](gravity-cascade.md)给出n=4k+6、H=6k−1的可制作族，每次恰损失六颗C、共k轮后稳定。因此次数在一般参数下无统一常数上界；这不声称达到本页的c(D)上界。

## 4. 任意堆叠段的线性长度界

[精确堆叠分解](stack-summaries.md)保证：下料贡献恰为F(D)，上料不贡献C，只能贡献新的N/P。下料N/P不消失、不升高，也不可能在最后截高时被删。

记a为实际保留的上料N/P格数，d为损失的下料C数。则

`b(Stack(D,U)) = b(D)+a`，

`c(Stack(D,U)) = c(D)−d`，

`θ(Stack(D,U))−θ(D) = a+d ≥ 0`。

若a=d=0，由第3节d=0得到F(D)=D；又没有任何上料格保留，所以Stack输出就是D。故每次非恒等Stack均有a+d≥1。这个结论保留一次加工的原始输出，没有在结果后补F。

一段仅含Stack及旋转的制造过程可删除恒等Stack。旋转不改变θ，且−nH≤θ≤nH，所以从起点D开始，有效Stack数量至多

`nH−b(D)+c(D) ≤ 2nH`。

更精确地，若该段终点T已知，数量至多θ(T)−θ(D)。这把一般下料的Stack段变成按θ严格递增的有向无环关系；上料选择仍可能很大，也不能把非K下料的一次复杂Stack改成多次基础Stack。

## 5. 顶针的计数损失最多n−1

对非空可制作输入D，记g为原地面占用列数，t为原最高允许层H−1上的N/P数，d为本次消失的C数。

Pin只删除原最高层的N/P；其余N/P先升高一层，再下落，不会超出H层或因融合而消失。按删除前地面占用补出g根新针。因此

`b(Pin(D)) = b(D)−t+g`，

`θ(Pin(D))−θ(D) = g−t+d ≥ 1−n`。

这里用到第2节的g≥1，以及t≤n、d≥0。H≥2保证原地面不是被排除的最高层。该结论允许Pin触发顶破、原不稳定结构下落及晶体消失。

## 6. 任意含晶体目标的主干尾部界

从制造树根沿Stack的下料支路、Pin/Rotate的唯一输入回溯，停在最近的Cut、Swap、Crystal或基础供料，记该输出为A。尾部仅含Stack、Pin和旋转；各上料仍保留自己的真实制造子树。

每颗最终晶体都已在A中：Stack上料不能增加C，Pin只抬高或删除C。最终保留的C不能下落。若尾部有p次Pin，T中每颗晶体的层号都等于其A中层号加p，因此p≤h，其中h是T最低C的零基层号。

令i为尾部已经执行的Pin次数，定义

`Ω = θ(当前物品)+n·i`。

有效Stack使Ω增加至少1；Pin由第5节也使Ω增加至少1。删除恒等Stack后，主干Stack/Pin总数L满足

`L ≤ θ(T)−θ(A)+np ≤ θ(T)+nH+nh ≤ n(3H−1)`。

可单独给出Stack次数s的界：

`s ≤ θ(T)−θ(A)+(n−1)p ≤ θ(T)+nH+(n−1)h`。

旋转与Pin等变；旋转后的Stack等于共同旋转两输入再Stack。把主干旋转移到末尾，同时调整各次上料的净朝向，即可只留一个主干净朝向调整。它可以用至多⌊n/2⌋次单象限旋转执行；若机器还提供半周旋转，可能更少。移入上料的旋转计入上料子树，不是免费加工。

例如6q5l的宽松界为84次主干Stack/Pin，8q8l为184次；各自另加一个净朝向调整。这里不把一般n下的任意角度旋转误计为一次原生加工。四象限五层已有依赖K及半形构造的更强专项结论，本页通用界不替代它。

## 7. 对搜索与时序电路的含义

本页给出每条规范化制造尾部的线性深度界，只依赖n、H与目标计数，并不限制搜索要尝试多少条尾部。寻找起点、恢复上料制造凭据、展开侧支及判断不可制作仍未因此完成；候选总数和完整制造树可以远大于主干长度。

后续实现可用一个θ计算器和一个Pin计数器管理尾部进展，用同一份候选生成、物理判定和回放模块逐次循环。不能按尾部上界复制84套或184套电路。状态存储、候选分支、请求/确认和稳定采样时序仍需分别设计、统计；本页未生成新的游戏网表或走线。

证明依赖局部物理、B及J的制造树归纳、计数恒等式和保留晶体的来源追踪。已静态核对[Rules.collapse/stack/pin/cut/swap](../synthesis/physics.py)的直接边界，没有执行测试、目标枚举、物理探针或游戏验证。
