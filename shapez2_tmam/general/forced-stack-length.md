# 一次顶针之后，逐层堆叠的必要次数没有常数上界

本页推进[任意指定次数序列](forced-tail-order.md)中的 Stack 次数问题。参数固定为四象限，高度上限 H 可增长；P 表示 Pin，S 表示单层 Stack。起点允许任意合法最后 Swap 输出，Pin 前后都允许任意补料，旋转吸收入起点与上料朝向。只计主干尾部，上料及两半的准备另计。

**结论：存在一个显式目标族，每个目标都必须且只能用一次尾部 Pin，而 Pin 之后的单层 Stack 最少次数无界。** 更进一步，对每个正整数 k，都存在该族中的一个目标，使这个后段的最少 Stack 次数恰为 k。后一个结论是存在性证明，尚未给出每个 k 对应的具体成员和最优起点。

这不是任意交替序列的完整证明。本页旧目标族仍允许最优后段路线带前置Stack；新的[保留晶体限制辅助路径构造](forced-stack-word.md)已对每个偶数n≥4、k≥1给出明确目标，证明完整最短词恰为P S^k，并排除以前置Stack抵消k次后段Stack。

## 1. 目标族与统一制造路线

取 H≥5，整数 0≤b≤H−3。N 取 Cu，C 取 cr。定义 A_b：

```text
层号          q0 q1 q2 q3
3…b+2          N  N  N  N   共 b 层；b=0 时没有这些层
2              C  N  .  N
1              N  .  .  .
0              针 .  针 .
```

短代码为基础三层：

```text
P---P---:Cu------:crCu--Cu
```

再接 b 份 `:CuCuCuCu`。

准备 D_H：

```text
层号          q0 q1 q2 q3
2…H−1          .  .  C  .
1              C  N  C  N
0              N  .  C  .
```

两半 q0/q1 与 q2/q3 都稳定：左半由地面 N 支撑保留 C 和侧 N，右半由触地连续 C 塔支撑另一侧 N。它们满足列 A，且没有 C 下方悬空落点，[四象限任意高度直接释放](four-quadrant-release.md)给出制造凭据。这个构造是[必须一次尾 Pin 的三层目标](../4q5l/necessary-tail-pin.md)的辅助塔高度扩展。

P 删除整个 q2 辅助塔，得到 A_0。随后每次堆入一份完整单层 `CuCuCuCu`，依次得到 A_1、A_2、…、A_b。

因此统一可行路线为：

`D_H → P → S^b → A_b`。

它证明 Pin 后最多需要 b 次 Stack，没有先断言这个配方最优。

### 利用准备高度预制一部分上层

还可以在最后 Swap 之前预制 s 层，其中 H≥2s+4、0≤s≤b。准备 B_(s,H)，未列出的格为空：

| 列 | 普通格 N | 晶体 C |
|---|---|---|
| q0 | 0；2…s+1 | 1 |
| q1 | 1…s+1 | s+2…H−1 |
| q2 | s+3…2s+2 | 0…s+2 |
| q3 | 1；s+3…2s+2 | 无 |

空区间不放格。两半01/23分别稳定，全部 C 都有直接下邻，两列半形仍由已有构造制造。q1 高塔和 q2 低塔在 s+2 层连接，组成触顶删除的同一分量；q0 的保留 C 被普通格隔开。

Pin 删除这个分量后，q0/q1 的 s 层预制普通双格固定提高；q2/q3 的 s 层普通双格失去低塔支撑，依次落在目标第3至s+2层。最下面的双格由 q3 旧侧 N2 托住，后面的双格由前面已经落位的普通格托住。最高预制 N 在2s+2层，H≥2s+4保证它不被截去。因此一次 Pin 恰好得到 A_s。

之后只需再堆 b−s 层。取 t=floor((H−4)/2)、s=min(b,t)，得到改进的可行上界：

`Pin 后 Stack 次数 ≤ max(0,b−floor((H−4)/2))`。

特别地，同一目标 A_b 在 H≥2b+4 的环境中可以只用一次尾部 Pin。必要次数必须连同全过程高度上限一起讨论，不能只报最终图形的层数。

## 2. 任意合法尾部恰好一次 Pin

目标 q0 的最低 C 在第2层，触地针前缀长度为1。[保留 C 与地面针计数](forced-tail-order.md#5-任意起点下的pin计数上界)给出：

`p ≤ max(1,2−2) = 1`。

零次 Pin 也不可能。由[四象限 K 定理](four-quadrant-tail-support.md)，只有 Stack 的尾部保持旧格及全部 C，只追加 N/针。目标两侧的 q1/q3 第2层 N 正下为空；新增块不能借旧 q0 C 把自己当成已支撑普通块，也不能带目标第2层不存在的 q2 N。因此两颗侧 N 都必须已经在交换起点。

任意相邻两列切向，都有一颗侧 N 与 q0 保留 C 分处两个半形。缺少 q0 C 的那个半形不能托住它：同层 q2 为空，正下也为空。较高的全 N 层只有水平粘连，不能从上方支撑这个低 N。这个半形不属于 K，不可能是合法切后结果。

所以所有合法尾部都具有：

`B → S^a → X → P → E → S^c → A_b`，其中 a,c≥0。

下界将允许任意 a，不把提前堆料的路线排除在外。

## 3. Pin 输入必须有一条贯穿全高的辅助晶体路径

X 的保留 C 必在 q0 第1层，其下方目标 N1 必来自 q0 地面 N。

目标两侧第2层 N 不能在 Pin 后新增，理由与零次排除相同。它们也不能在 Pin 中移动到第2层：移动普通块在该处没有直接下方支撑，不能带目标没有的 q2 N，也不能带 q0 的保留 C。因此两颗侧 N 原在 X 第1层，只随 Pin 固定提高。

它们还必须原已在 B。若通过前置 Stack 加入第1层，单格正下为空；带 q2 新 N 会在 Pin 后留下低于第3层的额外 N，带 q0 又遇到旧 C，均不可行。

原两半中，远离 q0 C 的那颗侧 N，必须借 q2 第1层辅助 C 支撑。同层 q2 若为 N，则该普通格最多提高到第2层，也不能截去，目标没有它。

q2 地面也只能为 C：地面空不满足第1层 C 的 J 条件；地面 N 会留下第1层额外 N；地面针会使目标针前缀变成两根。故 q2 第0、1层同属一个触地融合分量 R。

R 不能下落碎裂：Pin 后其底部仍受新地面针支撑。目标没有 q2 的 C，后续 Stack 又不能删旧 C，所以 R 必须在这一次 Pin 中触顶融合删除。

**R 从第0层连接到第H−1层，因此每个中间层至少占一颗 C。** 路径可以转列、分叉，不要求它始终沿 q2 直上。这是下面计数不依赖具体准备塔的原因。

## 4. 高度填满时的全局后段下界

现在取 b=H−3，即目标顶部恰好填到 H−1 层。

目标上部需要 4b 颗 N。Pin 前能成为这些普通格的来源，仅在 X 第2至H−2层：

- 第0、1层的普通格只有前述三颗固定 N，它们分别成为目标低处 N1、两颗侧 N2；额外低 N 无法消失或升到上部。
- 第H−1层 N 会在 Pin 中截去，不能留下。
- Pin 不会把 C 或针变成 N。

第2至H−2层共 b 层、4b 个格位。由第3节，每层至少一格属于 R。因此 X 在这些层最多预存 3b 颗上部 N，不管这些 N 原在 B，还是经任意次前置 Stack 加入。

至少有：

`4b − 3b = b`

颗目标 N 必须在 Pin 后补入。每份四象限单层上料最多提供四颗 N，所以任意合法路线都满足：

`c ≥ ceil(b/4) = ceil((H−3)/4)`。

结合统一路线：

`ceil((H−3)/4) ≤ min c(A_(H−3)) ≤ H−3−floor((H−4)/2)`。

对未填满的任意 b，同一来源容量计算与第1节预制构造给出：

`max(0,b−floor(3(H−3)/4)) ≤ min c(A_b) ≤ max(0,b−floor((H−4)/2))`。

这是任意起点、任意前置 Stack 与任意合法单层上料下的界。它已经排除了“每段只保留固定常数次 Stack 就能覆盖所有四象限任意层目标”的设想。

这里的 Stack 在补普通材料，不是在同一个形状上反复执行纯重新结算 F。因此它与四象限全部可制作状态属于 K、F 恒等的结论不冲突。若允许多层上料，一份上料可以提供超过四颗 N，这个次数下界不能照搬。

## 5. 每个正整数都能成为后段的精确最少次数

固定任意 k≥1，取 H=4k+3。在同一个高度上限下，考虑 b=0…4k 的有限目标族。定义：

`f_H(b) = A_b 所有合法尾部中，唯一一次 Pin 之后的单层 Stack 最少次数`。

前置 Stack 次数不固定，也不计入这个函数。统一配方保证每个目标可制作，故最小值存在，且：

1. `f_H(0)=0`。
2. `f_H(4k)≥k`，由第4节。
3. `f_H(b+1)≤f_H(b)+1`：直接在 A_b 的任意最优后段路线末尾多堆一层全 N，即得到 A_(b+1)，并且不超过相同的 H。

取第一个使 f_H(b)≥k 的 b。它大于0；前一个值小于 k，而向上最多跳1，所以该值只能恰好等于 k。第1节预制构造还给出 f_H(b)≤max(0,b−(2k−1))，因此得到：

**对每个 k≥1，存在 3k−1≤b≤4k，使 f_(4k+3)(b)=k。**

不需要假设 f_H 单调；它可以下降，第一次越过给定整数时仍不能跳过该整数。这个证明没有执行任何成员搜索，也没有计算最优配方。

其精确含义是：该目标所有合法尾部都至少包含 k 次后段 Stack，而且存在某条尾部恰好包含 k 次。达到 k 的路线可能为 `S^a P S^k`，其中 a>0；本页没有把它未经证明地改写成 `P S^k`，也没有宣称它同时最小化尾部总步数。

## 6. 一个明确可制作、至少需要两次后段 Stack 的成员

取 H=11、b=8。目标由基础三层加八层全 N 构成，短代码为：

```text
P---P---:Cu------:crCu--Cu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu
```

取预制参数 s=3，B_(3,11) 的短代码为：

```text
Cu--cr--:crCucrCu:CuCucr--:CuCucr--:CuCucr--:--crcr--:--crCuCu:--crCuCu:--crCuCu:--cr----:--cr----
```

把其01/23两半按第1节制造并交换，顶针一次先得到 A_3，再连续堆入五份 `CuCuCuCu`，得到 A_8。最高预制普通格在第8层，不会被 H=11 的顶针截去。

任何其他合法最后交换起点也只能用一次 Pin；它之后至少还需两次单层 Stack。因此一段 Stack 不能普遍压成一次。这个具体目标当前证明的范围是 `2≤min c≤5`，没有给出恰好两次的最优配方。

## 7. 任意交替序列仍缺少的部分

现在已经有全局最短词P→S→P、P→S→P→P，以及[任意偶数n≥4的完整P S^k明确构造](forced-stack-word.md)。本页旧族的无界下界和首次越界论证仍成立，但完整单段词已经由新构造独立闭合。

尚未证明的是：任意选定的多个段可以组合，同时排除换起点、前置Stack、并行补料和跨段提供支撑。本页第5节的最小值仍只针对旧族的后段次数，不应把新族的最优配方套给旧成员。新的P S^k定理也没有覆盖任意a≥2的P^a S^b或任意多个段。

证据为半形制造凭据、K 追加性质、保留材料来源、融合路径逐层占位计数及有限整数首次越界论证。没有运行测试、枚举、求解器、物理模型或游戏。
