# T₂ 强制两次顶针之间堆叠：任意交换起点的排除证明

本页证明[四象限十二层目标 T₂](forced-tail-order.md#1-截图的起点与两个目标)的全局尾部顺序下界：

> 从任意合法最后 Swap 起点出发，只用 Pin、Stack 和旋转得到 T₂，必须恰好执行两次 Pin，而且两次 Pin 之间必须有有效 Stack。

已有指定起点 D 的 `P → S → P` 制造路线，所以这个下界可以达到。[一次 Pin 排除](t2-one-pin-exclusion.md)已证明至少两次，[保留晶体与触地针计数](forced-tail-order.md#5-任意起点下的pin计数上界)已证明至多两次。本页排除剩下的“换起点后连续执行两次 Pin”路线。

“全局”限定在上述最后 Swap 后的尾部模型，起点两半与 Stack 上料可任意合法制造。它不把最后一次结晶等其他根操作强行计为 Swap。本文只作人工证明，未运行搜索、枚举或物理模拟。

## 1. 反设与支撑范围

反设存在：

`B → Stack* → X → P → Y → P → E → Stack* → T₂`。

B 是两个合法切后半形的交换结果。旋转吸收到起点和各份上料，按目标列编号。层号从0开始，高度上限12。

[整个尾部保持 K](four-quadrant-tail-support.md)保证 X、Y、E 都属于 K。E 是 T₂ 的逐列下方前缀，包含全部目标 C，不能含额外 C；最后一段 Stack 只追加普通格或针。

目标三颗 C 的来源固定为 X 的 q0 第5层、q3 第2、3层。它们经历两次统一抬升，不下落。其他 C 必须在这两次 Pin 内消失。

一个在某次 Pin 中移动过的格，不能成为该次未移动组的最终支撑。以下反推保留 C 时始终使用这个[结算边界](../4q5l/support-closure.md#2-下落中移动过的组不能成为未移动组的最终支撑)，不把本轮新接触当成提前合并。

## 2. 低处 q0 普通格锁定切向与删除时刻

q0 在目标 C 以下的三个 N 位于0、5、6层。因此 X 的第3、4层必须是 N；最低 N 只能在第1层。它不能在地面，否则第一轮就生成目标没有的地面针；也不能在第2层，否则会与保留的 q3 第2层 C 粘连，最终停在第4层而非地面。

X 的 q0 第2层为空：N 会产生上述矛盾，C 会与保留 C 融合，针也无法消失成目标 N。

q3 最低目标 C 下只有两根触地针及一个 N。X 的低 N 只能在第0或1层。若在第1层，它会与 q0 第1层 N 水平粘连，不能最终分别到第2层与地面。因此 q3 第0层为 N，第1层为空；原有地面针会使两次 Pin 后的针前缀过长，也不允许。

q0 第1层 N 不能来自前置 Stack，因为同列更高的保留 C 已在 B。在 q3/q0 半形中，它正下与同层邻格均为空，无法静止。所以 B 只能按 q0/q1、q2/q3 分半。

在 q0/q1 半形中，这个 N 必由 q1 第1层辅助 C 托住。同层 N 会与它始终粘连，不能成为目标 q1 的较高普通格。

这颗辅助 C 必须撑过第一轮 Pin。若第一轮就失去它，q0 的低 N 会成为单格，直接落地；第二轮随即在 q0 生成地面针，违背目标。它不能只落一层悬停，q0 下方没有其他格，同层也没有能与它一起保留的普通块。

q1 第1层辅助 C 又不能在第二轮自行跌碎：原 q1 第0层不能为空，否则违反 J；不能为针，否则最后触地针过多；若为 N，它一直由新增地面针托住，若为 C，则与第1层辅助 C 属于同一融合分量。只要该分量未融合删除，就仍有固定底部支撑。

因此，这个分量**第一轮保留，第二轮顶破删除**，其在 X 中的最高 C 恰为第10层。记为 R。

## 3. R 必须穿过 q1 低塔及 q2 高塔

先排除 X 中 q3 第4至10层的辅助 C。若有，取其中最低者。第4层会与保留 C 融合，不允许；更高处的最低 C，由 Q/J 必须与下面的保留 C 之间隔着 N。这个 N 至多在第9层，经历两次 Pin 也不会截去，只能成为目标第10层的唯一上部 N。

于是 E 已含 q3 顶条 N，下面四根针也必须在 E，不能事后插入。原针链必须从保留的 q3 第3层 C 上方连续立起，位于第4至7层：若另有 N 夹在 C 与针链之间，它也不会消失，目标却没有对应材料。这与更高辅助 C 下方不得有非触地针的 Q 矛盾。

因此 q3 第4至10层没有辅助 C。原第11层仍可能有首轮就删除的 C，但它不能属于 R。

R 从 q1 第1层通向第10层，必须跨过第2、3层。那里 q0/q2 的 C 都会与保留的 q3 C 融合，只有 q1 可以通过。所以 q1 第1至3层连续为 R 的 C。继续向上，第4层须经过 q1；第5层的 q0 是保留 C，q1 的 C 会与它融合，q3 又没有可用 C，只能经过 q2。

因此 R 至少含：

- q1 第1至4层 C；
- q2 第4、5层 C。

这些格在第一轮后仍在，Y 相应含 q1 第2至5层 C、q2 第5、6层 C。

## 4. 第二轮不能临时补出保留 C 的低处支撑

第二轮删除 R 后，保留的 q3 双 C 与 q0 第5层目标 N 构成固定组。它不能依赖最终才下落到位的普通格。

它正下的 q3 第3层、q0 第4层在目标中为空。q1 的目标第4层 N 也不能预先属于这个固定组：在 Y 的对应第3层原本是 R 的 C，第二轮才被删掉。

所以该固定组必须预先包含 Y 的 q2 第3层 N，并依靠 q2 第2层 N。q2 第2层 N 在删除 R 后没有可保留的水平连接：q1 同层为待删 C，q3 同层为空。它还必须依靠 q2 第1层 N。

反推第一轮：q2 原第4层 R 的 C 一直保留，阻止更高普通格下穿。Y 第3层 N 只能来自 X 第2层；X 第3层若为 N，会粘住保留的 q3 第3层 C，一直固定到最终第5层，目标没有它。再按列内顺序反推，Y 第2、1层 N 分别来自 X 第1、0层。

故 X 的 q2 第0、1、2层都是 N，第3层为空。第3层不能放 C，与保留 C 融合；不能放 N，落点错误；不能放针，因为它位于 R 的 C 下方，却不是触地针前缀。

## 5. 原右半形锁定旧顶条

B 的 q2/q3 半形含 R 在 q2 第4、5层的 C。q2 第3层为空，q3 第4至10层没有 C，R 又不能含第11层 C。因此这个半形必须通过 q3 的普通格和针取得支撑。

先排除 R 自己带一个悬空针环。这样的环在 q3 必有上下两个附着于 R 的 N，中间至少一根针；上 N 不高于 R 的最高层10，故下 N 至多在第8层，中间至少有一根不高于第9层的针。下 N 和这根较高的针经历两轮都不会截去，顺序也不会颠倒。而目标 q3 在保留 C 以上的唯一 N 高于所有针，矛盾。

所以 R 必须沿支撑路径向下，最终借 q3 的针链接到保留的第3层 C。取支撑路径离开 R 时的那个 q3 普通格，记其高度为 t。它下方若又遇到同组较低 N，就回到已排除的含针环；这段高度内 q2 的连续 C 又使同层 q3 N 必属于同组，不能另当成独立支撑。因此这条链直到第3层 C 之间只能是针。

- t≤9 时，N 会保留到最终，只能成为第10层顶条，所以 t≥8。
- t=9 时，下面五根针全部保留，超出目标允许的四根。
- t=10 时，N 虽可能在第二轮截去，但下面六根针仍有多余保留格。
- t=11 不属于 R 所在的原两列非针组：该组每个占用层都须含 C，会要求 R 有第11层 C。

故 t=8。原半形必须已有 q3 第4至7层针、第8层 N；R 的 q2 C 连续经过第4至8层。它们在第一轮全部保留。

于是 Y 确定含 q3 第5至8层针、第9层 N，以及 q2 第5至9层辅助 C 塔。这个旧 N 在第二轮后固定为 E 的 q3 第10层顶条。

## 6. 两轮之间的上部局部状态被锁定

既然 E 已有 q3 第10层 N，最终 Stack 就不能再补 q0/q1 第10层屋顶：不带 q3 会落得过低，带 q3 会被旧屋顶挡得过高，带 q2 会增加目标外格。也不能加垫块再删除。因此 q0/q1 屋顶都必须在 E。

它们不能在第二轮从更高处落到第10层。移动的水平 N 块需要第9层的直接下方支撑，那里只有 q3 的针；该块不能再带一份 q3 N，因为旧屋顶 N 已存在，也不能带目标没有的 q2 N。因此两格在第二轮不动，来自 Y 的第9层。详细落点论证与[一次 Pin 排除第7节](t2-one-pin-exclusion.md#7-整条屋顶必须在-pin-前就位)相同，不使用该文的起点切向假设。

Y 的 q0/q1 第9层既已有屋顶，它们以下的目标普通格和针也都必须在 E。设 Y 的 q0 普通格 U 将成为目标第8层，q1 普通格 V 将成为目标第4层。

- U 在保留的 q0 第6层 C 与第9层屋顶之间，只能位于第7或8层。
- Y 的 q1 已有第5层辅助 C，目标第3层的非触地针只能在它上方，且低于 V 与屋顶，所以只能位于第6或7层。
- 若针在第7层，正下第6层不能放 C（会融合进保留 C）、N（会固定在错误位置）或另一根针（目标没有额外针）。故针在第6层，V 在第7或8层。
- U、V 不能同层，否则普通格不会分离，不能落到不同目标高度。

若 U 在第8层、V 在第7层，U 在 Y 中无法静止：q0 第7层不能有额外 N/针，不能有融合进保留 C 的 C；同层 q1 不能放 C，违反第6层非触地针上方禁 C 的 Q，也没有允许的 N；q3 同层为针，不粘连。

因此只能 U 在第7层、V 在第8层。q1 第7层为空。q0 第8层也为空：若放 C，它被下方 U、上方屋顶、左右 V/针完全隔离，既不触顶又受 U 支撑，第二轮不能删除；若放 N/针，则是目标容不下的额外非晶体格。

Y 的关键上部骨架因而是：

```text
 z   q0 q1 q2 q3
 9    N  N  C  N
 8    .  N  C  针
 7    N  .  C  针
 6    C  针 C  针
 5    N  C  C  针
```

这些是必须存在或必须为空的位置；更低格和更高辅助部分不影响下一步排除。

## 7. V 不能是第一轮下落产生的

Y 的 V 位于 q1 第8层，左右分别为空与旧 C，所以若它在第一轮移动过，碎晶后保留的普通块只能是一个单格。它不能与旧 C 在下落中提前合组。

单格要停在第8层，正下第7层必须非空，但 Y 的该位置为空。故 V 在第一轮没有移动，必来自 X 的 q1 第7层 N。

Y 第6层的非触地针则来自 X 第5或6层：它必须低于原 V，且至多提高一层。原第6层针不能静止，正下第5层不能是 C（与保留 q0 C 融合）、N（固定到 Y 的针位）、或另一根针（会在 Y 留下第7层额外针）。所以原针在第5层，原 q1 第6层为空。

## 8. 原 V 无法准备，也无法提前堆入

现在区分 X 的 q1 第7层 V 是否已经在 B。

### V 已在 B

原 q0/q1 半形中，V 正下第6层为空，必须靠同层 q0 的非针格托住。同层 N 不行：它会与 V 一起在第一轮固定到第8层，但 Y 的 q0 第8层为空。因此必须是 q0 第7层辅助 C。

该 C 下方第6层必须是 N。若为空，最近的下方格是第5层保留 C，违反 J；若为 C，就融合进保留 C；若为针，则违反 Q。这颗 N 由保留 C 托住，所以辅助 C 不能靠下落消失。

Y 的 q0 第8层为空，故原第7层辅助 C 必须在第一轮融合顶破。它左右是 V 和 q3 第7层针，下方是 N，只能向上连接。原 q1 第5层已有非触地针，Q 禁止其更高 C；q3 第8层是旧屋顶 N，第9、10层也没有辅助 C。因此融合路径只能沿 q0 连续占据第7至11层。

这使 X 的 q0 第8至11层全为 C。但 Y 的 q0 屋顶 N 在第9层，其原材料必须来自 X 的第8层或更高处，不能凭 Pin 新增。这些位置已全被 C 占据，矛盾。

### V 来自前置 Stack

B→X 的 Stack 段保持 K，新增普通块必须满足基础堆叠的最终支撑判据。V 在原第7层，其正下第6层为空；同层 q0 不能有 N，否则会与 V 一起保留到 Y 的禁止位置；q2 已是来自 B 的 R 晶体，不能作为新增普通块的一部分。故含 V 的新增水平块只能是单格，而它没有正下支撑。

任意复杂上料在 K 下料上的约化也受这个判据约束。因此 V 不能通过前置 Stack 放到所需位置。

两个来源均不成立，反设路线不存在。

## 9. 已证明的全局结论与尚未解决的任意序列

T₂ 的尾部 Pin 数恰为2，且不能连续执行。已有 `D → P → S → P → T₂` 达到下界，所以确实存在完整目标，强制在两次 Pin 之间进行有效 Stack。前置或后置 Stack、任意合法上料、另换合法交换起点，都不能取消这次中间加工。

这解决的是一个全局交替实例。它没有证明任意正整数序列 `(a₁,b₁,a₂,b₂,…)` 都能被强制。后者还需构造可重复的约束，并排除不同阶段互相支撑、提前准备屋顶或合并 Stack 的替代路线；不能仅复制本例就宣布成立。
