# 交换后的强制顶针与堆叠顺序：全局交替实例与任意序列问题

本页研究用户截图`106106a7c58f57adf7254a393c7d7ba7.png`的四象限、十二层例子。P表示一次Pin，S表示一次Stack；具体材料另用N/C/针表示。只计最后一次主干Swap之后的Pin/Stack，旋转吸收到起点和上料朝向。上料具有合法制造凭据；讨论逐层堆叠时，每份上料限定一层。

**已证明：T₂从任意合法最后交换起点出发，必须恰好执行2次Pin，而且两次Pin之间必须有有效Stack。** [一次Pin排除](t2-one-pin-exclusion.md)与[连续两次Pin排除](t2-forced-interleaving.md)共同完成必要性；指定D的P→S→P路线达到下界。T₃目前仍只证明尾部Pin数在1至3之间。

两个全局命题的状态：

1. **已证明**：存在完整目标，使任何合法最后交换起点及上料都无法省去Pin/Stack交替。T₂是一个实例，其最短尾部操作词为P→S→P。
2. **未证明或证伪**：对任意正整数序列(a₁,b₁,a₂,b₂,…)，存在目标强制这些次数及顺序。

这里把“强制”理解为不能通过换起点、换上料或重排删减得到更简单尾部。插入恒等加工或先添加随后丢弃的无用材料，不构成有意义的反例。展示一个给定词的加工结果，只证明可行性。

## 1. 截图的起点与两个目标

层号从0开始，H=12。N取Su，C取cr；不同晶体颜色不影响本页的分组和融合推导。截图起点D为：

```text
 z   q0 q1 q2 q3
11    C  .  .  .
10    C  .  C  .
 9    C  .  C  .
 8    C  .  C  N
 7    C  N  C  针
 6    N  .  C  针
 5    C  针 C  针
 4    N  C  C  针
 3    N  C  .  C
 2    .  C  N  C
 1    N  C  N  .
 0    .  N  N  N
```

短代码：

```text
--SuSuSu:SucrSu--:--crSucr:Sucr--cr:SucrcrP-:crP-crP-:Su--crP-:crSucrP-:cr--crSu:cr--cr--:cr--cr--:cr------
```

截图路线是`D → P → S(q0/q1双N) → P → T₂ → P → T₃`。中间目标T₂为：

```text
 z   q0 q1 q2 q3
10    N  N  .  N
 9    .  .  .  针
 8    N  .  .  针
 7    C  .  .  针
 6    N  .  .  针
 5    N  .  .  C
 4    .  N  N  C

 2    .  N  N  N

```

```text
T₂ = SuP-P-P-:--P-P-P-:--SuSuSu:--P-Su--:--SuSucr:Su----cr:Su----P-:cr----P-:Su----P-:------P-:SuSu--Su
```

T₂静止且最高只到第10层。再Pin不截掉任何原格，只整体升高，并给四个原地面占用列补针，得到T₃：

```text
T₃ = P-P-P-P-:SuP-P-P-:--P-P-P-:--SuSuSu:--P-Su--:--SuSucr:Su----cr:Su----P-:cr----P-:Su----P-:------P-:SuSu--Su
```

因此截图最后一次Pin没有新的顶破事件；它的存在本身不能证明最小尾部Pin数等于3。

## 2. 起点D有基础料制造证书

标准两半q0/q1、q2/q3各自静止：

- 左半的q1第1至4层C由地面N支撑；q0第5层C及上方第7至11层C分别受第4、6层N支撑。q1第7层N接在q0高C柱旁，针有直接下方支撑。
- 右半的q3第2、3层C通过q2第2层N支撑到地面；q3第4至7层针和第8层N由此托住q2第4至10层C柱。不能删掉q3第8层N后仍称这个半形静止。

各列满足A。[四象限任意层直接释放](four-quadrant-release.md)所需的额外落点条件也成立：q2第4层C下的最近N在第2层，正下第1层为N；q3第2层C下最近N在地面；q0/q1没有C正下空隙的其他活动落点。因此两份稳定半形可以分别制造，再Swap得到D，准备过程不超过12层。

## 3. 指定路线的两次删除与上料落点

D中有四个相关晶体融合分量：

- q0第7至11层的上塔，首次Pin触顶删除。
- q1第1至4层C与q2第4至10层C，在第4层连成辅助分量。首次Pin后最高到第11层，第二次Pin才删除。
- q0第5层的保留C。
- q3第2、3层的保留C。

第一次Pin后，q0最高格为第7层N；q1最高格为第8层N，它通过q2仍保留的辅助C柱保持悬空。q0/q1双N上料恰落在第9层。此层原本还有q2的C和q3的N。

第二次Pin删除第二个辅助分量后：

- 新加q0/q1双N与原q3第8层N一起处于第10层，通过q3第9层针受支撑，形成目标顶条。
- 原q1第5层针落到第3层，原q1第7层N落到第4层。
- 原q0第1层N失去q1辅助C的横向支撑，落到地面。
- 两组保留C分别到q0第7层、q3第4/5层；其余直接支撑格保持相应层位。

这得到逐格等于T₂的结果。T₂各组有到地面的支撑路径，故下一次Pin只作第1节的抬升。

## 4. 从同一个D出发，中间Stack不可省

允许改变上料、增加其他Pin/Stack，但起点固定为D，终点固定为T₂。

### Pin数被保留晶体锁定为2

Stack不带入新C，保留C不能下落。把全部主干旋转合到末尾，记初始列到最终列的净旋转为t：

- t=0：q3的两颗C只能来自D的第2、3层，因此p=2。
- t=1：最终q3来自初始q2；要在第4、5层保留两C，只能p=0。但最终q0第7层C将来自初始q3第7层，那里没有C。
- t=2：最终q3来自初始q1，要求p为1、2或3。最终q0却来自初始q2；该列地面有N，经历任一次Pin都会留下地面针，而且位于保留C以下不能被删除，与目标q0地面N矛盾。
- t=3：最终q3来自初始q0；该列第5层以下没有连续两C，更高的连续C不能在非负次Pin后到第4、5层。

所以净旋转只能为0，主干Pin数只能为2。中间旋转仍可通过调整各次上料朝向吸收，不改变下面的排除。

### 第一轮Pin以前不能加入目标顶条的q0格

D的q0最高层第11层有C。D属于K，任意前置Stack保持旧下料及其C；新上料不能穿过这颗C落入12层以内。因此目标q0第10层N不能来自第一次Pin之前的Stack。

D原有q0普通格最高仅在第6层，即使经历两次Pin也最多到第8层。故目标q0第10层N必来自某次Stack，而非D中已有格。

### 两次Pin都完成以后也不能补入这个格

反设两次Pin之间没有Stack。原q3第8层N始终受原针链和保留C支撑，两次Pin后固定在第10层。

D的晶体融合删除不受普通上料颜色或标签影响：第一轮删q0上塔，第二轮删q1/q2辅助分量，此后只剩目标三颗C。后续Stack不能再损失C，否则无法补回目标；由[晶体数进展量](stack-progress.md)，其下料每次F均为恒等。已有N/P也不会再移动或消失。

因此，后续阶段中任何落入高度上限内的新增N/P都必须属于目标尚缺的格。未补顶条q0格时，该列最高只能是目标第8层N；q1若没有第10层顶条格，最高只能是第4层N。q1第10层N也不能独自静止：其下方为空，同层没有q0，也不能借q2或针连接到q3。

考虑包含目标q0新格的上料水平N块：

- 只含q0，或含q0/q1，都会落到第9层，而非第10层。
- 含q3，则被已有q3第10层N挡在至少第11层。
- 含q2，则同时添加一个目标第10层不存在的q2普通格，不能在没有后续Pin的情况下删除。

提前加一个普通支撑格把它垫高也不行：那个支撑格会永久留下，目标在相应位置没有它。上料中的晶体不进入结果，不能借它保留一个悬空水平N块。

两端都排除，所以至少一次Stack必须发生在两次Pin之间。第3节给出恰好一次的制造路线，故**指定D到T₂的最简Pin/Stack词为P S P**。

这项证明的关键是D的顶部阻挡和原q3顶条的来源，不能把D换成任意B后继续沿用。

## 5. 任意起点下的Pin计数上界

设某条尾部从任意合法起点出发，仅含Pin、Stack及旋转，终点仍保留晶体。选目标某列最低C，其零基层号为c；该列触地连续针前缀长度为r。尾部Pin数为p，则

`p ≤ max(r,c−2)`。

证明：若起点该列地面非空，每次Pin都会生成一根新地面针。它们位于保留C以下，不能被Stack插入、下落穿过或截高删除，因此r≥p。若p>r，则起点该列地面必为空；其保留C来源高度为c−p。由J，该高度既不能为0，也不能为1：地面空时，第1层C下不可能找到更低的N。因此c−p≥2，得到p≤c−2。两种情况合并即得结论。

这不依赖K或起点是否固定。对本图：

- T₂的q3有r=2、c=4，所以任意这种尾部至多2次Pin。
- T₃的q3有r=3、c=5，所以任意这种尾部至多3次Pin。

这个界限制实际可用的Pin数，不是最少Pin数的证明。

## 6. 任意交换起点都不能零Pin得到T₂/T₃

四象限任意高度下，两列切割输出属于K；交换拼接保持K；K下料的Stack保持旧格和全部C，并可约化为无C追加。这些局部结论不需要假设全部四象限高层图形属于K。

假设某交换起点B不经Pin，仅用Stack得到T₂。于是B逐格包含于T₂，且包含全部目标C。

q0第5层N正下为空，同层唯一相邻目标非针格是q3的旧C。它不能作为新上料单N落在第5层，因此也必须已经在B。

考察B的两个可能半切方向：

- q0/q1与q2/q3：左半的q0第5层N没有同层邻居，也没有正下方支撑，不能是合法切后半形。
- q3/q0与q1/q2：q3第4、5层C及q0第5层N形成的组，底部q3第3层和q0第4层均为空。更高普通格与针不把它连接成一个更高的晶体组，因此该半形不静止，也不可能是切后输出。

两个切向都不成立，故零尾Pin不可能。T₃仅把这个支撑障碍提高一层，新增底部针没有填上障碍正下方的空格，同一排除适用。

本节与第5节先得到T₂含1至2次Pin、T₃含1至3次Pin。[一次Pin完整排除](t2-one-pin-exclusion.md)把T₂收紧为恰好2次；[连续两次Pin排除](t2-forced-interleaving.md)进一步证明必须在中间Stack。T₃的下界尚未同步提高。

## 7. 全局交替实例已闭合；任意序列仍开放

[四象限任意H的尾部支撑定理](four-quadrant-tail-support.md)证明：从合法交换起点出发，整个Pin/Stack尾部都保持K。它通过追溯同层双C屏障和普通横条形成时的支撑证书完成归纳，不是直接重复套用第一次Pin定理。因此第二次Pin输出不能额外留C再靠Stack清理。

[连续两次Pin排除](t2-forced-interleaving.md)在这个范围内反推全部起点。目标地面N迫使一份辅助分量撑过首Pin、第二Pin才删除；原右半形又迫使旧顶条已经存在。两轮之间的局部形态被锁定后，悬空普通格必须来自原半形，却需要一根首轮触顶删除的C塔；该塔占满q0第7至11层，使必要屋顶N无处准备。前置和后置Stack也不能绕开这个矛盾。

所以第一个全局存在命题由T₂成立。这里证明最短尾部及中间Stack的必要性，不声称所有合法较长配方逐步完全相同。

第二个任意序列命题还需可重复的工序约束，并证明多个约束拼合后不会互相提供额外支撑或产生更短起点。当前固定八象限下落级联没有提供这个性质。

有一个可以直接排除的推广方向：[相邻象限等宽复制](sector-replication.md)不会增加必要阶段数。令Eₘ把每列扩成m列，则已有路线直接提升为 `Eₘ(D) → P → S(Eₘ(U)) → P → Eₘ(T₂)`，其中U仍是单层上料。因此无论扩成多少象限，这个复制族都至多用2次Pin、1次Stack；不能用复制规模声称强制更长序列。大图的更强下界也不能从四象限自动继承。

证据为截图逐格转写、支撑定理、材料来源、人工Pin/Stack逆推及操作复制对应。没有运行目标搜索、枚举、测试、物理模型或游戏。任意正整数次数序列的强制性保持未证明状态。
