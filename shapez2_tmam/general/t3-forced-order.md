# T₃ 的最短尾部操作词恰为 P→S→P→P

沿用[强制工序](forced-tail-order.md)的四象限、H=12 模型。P 为一次 Pin，S 为一次单层 Stack；起点 B 可以是任意合法最后 Swap 输出，准备两半与上料的操作不计入尾部。旋转吸收入起点及上料方向。N/C/针表示材料，层号从0开始。

[T₃ 的次数下界](t3-pin-lower-bound.md)已排除少于三次 Pin；列内计数上界又排除多于三次。本页进一步证明：

1. 任意合法尾部都必须在第一次、第二次 Pin 之间进行有效 Stack。
2. 第二次 Pin 后，高度0至10的部分已经恰为 T₂；最多额外带一个第11层顶盖。
3. 后两次 Pin 之间及最后 Pin 之后的 Stack 均可删去，不改变 T₃。

已有 `D → P → S(SuSu----) → P → P → T₃` 达到四步。因此，**最短尾部为四步，忽略旋转后的操作词唯一是 P→S→P→P**。这里的唯一性不涉及起点、上料或较长配方。

## 1. 三次 Pin 的来源与低格释放时刻

允许路线写成：

`B → S* → X → P₁ → S* → Y → P₂ → E → S* → Z → P₃ → W → S* → T₃`。

[四象限支撑定理](four-quadrant-tail-support.md)保证全程属于 K，每段 Stack 只追加 N/针，保留全部旧格和 C。W 是目标的逐列下方前缀。

X 中三颗保留 C 位于 q0 第5层、q3 第2和3层。q0 的两个较低固定 N 位于第3、4层；最低 N 只能在第1层：地面非空会导致最后至少三根地面针，第2层 N 则会粘住保留的 q3 C，无法成为目标第1层 N。因此 q0 第0、2层为空。

q3 的低 N 只能在第0或1层。第1层会与 q0 低 N 粘连，却要到不同终点，故只能为地面 N，第1层为空。原有地面针也会使三次 Pin 后的前缀超过目标三根。

q3/q0 半形不能托住悬空的 q0 第1层 N。因此切向只能是 q0/q1 与 q2/q3；原左半必须以 q1 第1层辅助 C 托住它。

目标 q0 为针0、N1，所以低 N 必须在第二次 Pin 后落地，第三次才在它下方补针。第一次落地会产生两根底针；第三次才落地则没有办法同时取得目标地面针。上方保留 C 又挡住另外补入地面材料。

这颗辅助 C 不能靠下落删除：q1 地面必须非空，地面针会使前缀过长，地面 N 保持直接支撑，地面 C 则与它属于同一融合分量。因此其分量 R **首次保留、第二次触顶删除**，在 X 中最高 C 恰为第10层。

## 2. 原右半形强制 q3 旧屋顶

R 从 q1 第1层向上，跨过第2、3层时只能留在 q1：另外各列的 C 都会进入保留融合分量。第4层仍须经过 q1，第5层则转到 q2，以避开 q0 保留 C。

这里 q3 第4至9层不能有辅助 C。第4层直接与保留 C 融合；更高辅助 C 之前须有分隔 N。若该 N 低于第8层，它既不能到达目标第11层屋顶，也不会在三次 Pin 中截去；若在第8层，它已经是旧屋顶，下方四根目标针必须预存，Q 又禁止其上再放 C。

因此 R 至少含 q1 第1至4层及 q2 第4、5层 C。q2 第3层为空：C 会融合进保留 C，N 会固定到目标没有的第6层，针则违反 Q 或地面前缀计数。

原右半形的 R 不能沿 q2 直接接地，只能借 q3 的普通格和针取得支撑。该两列非针组只有一个融合分量，附着 N 的高度不超过 R 的最高 C，即第10层。

若靠地面路径支撑，设转到 q3 的 N 位于 t 层。t<8 时，它不能成为目标屋顶，也不能截去；t>8 时，通向下面保留 C 的针链至少含第4至8层五根针，这五根经过三次 Pin 都保留，超过目标四根。若路径先经过另一颗较低 N，则仍归入这个计数。因此只能 t=8。

若靠含针环支撑，q3 必有上下两个 N，中间至少一根针，较低 N 至多在第8层。低于8仍不行；恰为8时，它必须保留成目标屋顶，下面四根目标针不能以后插入，也必须已在原半形。

故两种支撑均得到：

```text
X 的 q3：针4…7，N8。
X 的 R：q2 连续 C4…8，最高 C10。
```

Q 随即排除 q3 保留双 C 以上的全部辅助 C。屋顶和针链只随 Pin 抬升，永不下落。第二次 Pin 后 q3 屋顶在第10层，第三次后在第11层。

还得到一个后面要用的事实：**第二次 Pin 后，q2 第6层及以上不再有 C。** 来源第4至8层属于 R；第9层 C 若有也连着 R；第10层 C 最迟第二次删除；第11层 C 首次删除。Stack 不能补回 C。

## 3. 第三次 Pin 前，三份屋顶都已就位

W 已有 q3 第11层旧屋顶。最后的 Stack 段不能补 q0/q1 第11层屋顶：只用 q0/q1，目标允许的下方最高格为 q0 第9层 N，会落低一层；带 q3 会被旧屋顶挡高；带 q2 则多留目标外格。也不能加垫块后再删。

所以 W 必须已有全部三份屋顶。这些屋顶也不能在第三次 Pin 中移动到第11层：移动块需要第10层直接支撑，而那里只有 q3 的针；但 q3 已有固定屋顶，不能再带一个 q3 N。故 Z 的第10层已是 q0/q1/q3 三 N。

q2 第10层没有 C，因为第2节已证明全部高 C 都在前两次消失。那里若为 N，会粘住两侧旧屋顶并固定到目标没有的 q2 第11层。若为针，它不会截去，也不能穿过较低 N 落进地面针前缀：W 的保留双 C 需要 q2 第5层固定 N 支撑，其下两个目标 N 不能后插，反推已锁定 Z 的 q2 第2、3、4层 N。因此该针也会多留材料。

因此：

```text
Z 第10层：N N . N
```

**这一整行没有 C。** 第三次 Pin 即使在第11层顶破 C，其融合分量也不能越过第10层。顶层的非针组只有单层，不能从上方支撑较低组。截去整个第11层后，下方 K 支撑不受影响；第三次 Pin 对所有较低格只作整体抬升，并按地面占用补针。

此外，W 已有三份屋顶，q0/q1/q3 较低目标格都不能以后插入。保留的 q3 双 C 组必须包含 q2 第5层 N 才能获得支撑；它下面的两颗 N 也不能后插。因此 W 已经完整等于 T₃。

把这次无下落抬升反向还原，得到：

`Z = T₂ + 第11层的可选顶盖`。

这里允许合法的 N、针或 C 顶盖，不声称任意顶盖都能制造。第三次 Pin 把它全部截去；它不能给下面增加任何支撑关系。

## 4. 第二次 Pin 后补屋顶也不可能

需要区分 E 与 Z，不能把中间 Stack 段直接当成空。

在第11层顶盖以下，Z 的 q0/q1 第9层均为空，q2 最高只有第4层 N，q3 第10层已经是旧屋顶。若某份中间上料添加 q0/q1 第10层屋顶：

- 只带这些新增列，没有第9层落点；
- 带 q3，被已有第10层 N 挡高；
- 带 q2，产生无法留在 Z 的普通格。

Stack 保留旧格，所以不能先垫高、再把第9层垫块移走。故 q0/q1 屋顶已经在 E。

三个旧屋顶又把全部较低目标材料挡在它们下方。q2 方面，E 中的保留双 C 同样需要旧 q2 第4层 N 支撑；其下两颗 N 也必须已经存在。于是：

`E = T₂ + 第11层的可选顶盖`。

E→Z 的有效变化最多是给第11层追加 N/针；这些材料随第三次 Pin 截去。因此这段 Stack 全部可省。W 已等于 T₃，最后的 Stack 段也不承担目标制造。

这一步只针对该目标及其三次 Pin 来源，不是一般的“末尾 Stack 都可以前移”定理。

## 5. 假设两次 Pin 之间没有 Stack

现在反设 P₁ 与 P₂ 之间没有有效 Stack。Y 就是第一次 Pin 的输出。

E 的第0至10层已恰为 T₂，另有可能的顶盖。以下只使用屋顶下的材料，因此不能用这个顶盖逃开来源约束。

E 的 q0/q1 第10层屋顶不可能在 P₂ 中下落到位：其正下第9层没有允许的支撑；移动块又不能再包含旧 q3 屋顶。所以 Y 的第9层已是三份屋顶。

Y 的 q0 保留 C 在第6层。记 U 为最终 q0 第9层 N，V 为最终 q1 第5层 N。相对于 E，它们就是 T₂ 第8层、第4层的那两颗 N。

屋顶挡住后补，且 R 在 Y 含 q1 第2至5层 C。因此 q1 非触地针只能在第6层；若在第7层，其正下第6层 C/N 会连接保留 C，针则多留材料。U、V 只能分占第7、8层，不能同层粘连。

U8、V7 会使 U 失去所有支撑，所以必须 U7、V8。q1 第7层为空；q0 第8层也为空。该位置若放 C，会被 U、屋顶、V 和 q3 针隔离，且由 U 托住，后两次 Pin 都不能删除；N/针则多留屋顶下的材料。

因此 Y 的必要上部骨架为：

```text
 z   q0 q1 q2 q3
 9    N  N  C  N
 8    .  N  C  针
 7    N  .  C  针
 6    C  针 C  针
 5    N  C  C  针
```

第11层顶盖不会影响这些格位及其下落判据。

## 6. 必需的 V 无法提前准备

Y 的 V 在 q1 第8层，左右为空和旧 C，正下第7层为空。如果 V 在第一次 Pin 中移动过，碎晶后的普通块只能是单格，却没有直接落点。因此它必须原在 X 的 q1 第7层、固定提高到第8层。

Y 第6层针来自 X 第5层：若原在第6层，其正下第5层不能是 C/N（连接保留 C），也不能再放一根针。因此 X 的 q1 第6层为空。

分两种来源：

- V 原已在 B。左半形必须以 q0 第7层辅助 C 托住它。J/Q 迫使该 C 正下第6层为 N，该 N 又由第5层保留 C 支撑，所以辅助 C 不能跌碎。Y 的对应第8层为空，说明它首次触顶删除。左右为 V 和 q3 第7层针，下方为 N；q1 的非触地针禁止更高 C，q3 旧屋顶及针链也禁止更高 C。融合路径只能沿 q0 连续占据第7至11层，堵死 Y 第9层屋顶所需的原 N 来源。
- V 来自前置 Stack。它正下第6层为空，同层 q0 不能带 N，否则它也会随 V 固定到 Y 的禁止位置；q2 是旧 R 的 C，不能作为新增普通块的一部分。单格没有第7层落点。

两种来源都不成立。因此 P₁、P₂ 之间必须有有效 Stack。这个屋顶障碍与[T₂ 的顺序证明](t2-forced-interleaving.md)相同，但本页已独立处理第三次 Pin、额外顶盖和后段补料，没有直接把 T₂ 的结论套在未知中间态上。

## 7. 已解决的操作词与尚未解决的推广

三次 Pin 必须保留；至少一次 Stack 必须在前两次之间。因此最短尾部至少四步。既有 D 的路线使用一次单层双 N 上料，恰为：

`P → S → P → P`。

任意四步最短尾部只能具有这个操作词。较长路线可以多插入 Stack；其中第二次 Pin 后的 Stack 对目标均无必要，可以删去。这不声称所有起点和所有中间物品唯一。

现在已有两个完整目标的全局最短词：T₂ 为 P→S→P，T₃ 为 P→S→P→P。T₃ 因而确实提供了“堆叠之后连续两次顶针”的必要实例，而不是仅有三次 Pin 总数。

仍未解决的是任意 `(a₁,b₁,a₂,b₂,…)`。本例末尾第三次 Pin 只抬升，不产生新的支撑交接；把相同结构继续抬高又会落入已有两次 Pin 的替代族。因此不能把这一个连续段机械重复，宣称获得任意次数或任意多次切换。

证据为来源追踪、两列半形支撑、顶盖隔离及人工落点排除。没有运行测试、枚举、求解器、物理模型或游戏。
