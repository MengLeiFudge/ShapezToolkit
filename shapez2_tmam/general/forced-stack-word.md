# 任意长度的完整操作词P S^k：明确目标与全局下界

采用偶数象限n=2m≥4、共同制造上限H=k+3，其中k≥1。P表示Pin，S表示一次单层Stack；最后Swap后的主干只允许这两种操作及可吸收的旋转。两半和上料可以任意合法预制，但全过程共用H。层号从0开始。

**对每个k及每个偶数n≥4，下面的目标T_(n,k)恰好需要一次尾Pin，Pin之后至少需要k次单层Stack；显式路线P S^k达到下界。因此它的最短尾部共k+1步，操作词必为P S^k。** 允许任意前置Stack、不同交换起点和上料，不会降低这个下界。

这完成任意序列猜想中单段`(1,k)`的明确构造，包括排除用前置Stack替代所需后段次数。它不证明多个段可以串接，也不把较长配方里的无用加工称为唯一制造过程。

## 1. 一套参数化目标

记缺口三列为`J={m−1,m,m+1}`，其余列为K。K是经过q0的连续环形区间，q0∈K。N取Cu，保留C取cr。未列位置为空。

| 列 | 地面至低层 | 上部 |
|---|---|---|
| q0 | P0、N1、C2 | C3…H−1 |
| q∈K且q≠0 | N2 | C3…H−1 |
| q(m−1)、q(m+1) | N2 | N3…H−1 |
| qm | P0；第1、2层空 | N3…H−1 |

所以第2层是q0的C、qm的空位和其他n−2枚N；第3至H−1层，K列全是保留C，J三列全是N。qm恰有k枚普通格，全部位于第3至H−1层。

例如四象限、k=3、H=6时，目标自下而上为：

```text
P---P---:Cu------:crCu--Cu:crCuCuCu:crCuCuCu:crCuCuCu
```

六象限、k=3、H=6时，目标为：

```text
P-----P-----:Cu----------:crCuCu--CuCu:crcrCuCuCucr:crcrCuCuCucr:crcrCuCuCucr
```

短代码按表格逐格转写；下面的证明使用参数化格位，不依赖执行模型。

## 2. 合法交换起点与达到下界的路线

准备D_(n,k)，辅助晶体可取cc：

| 列 | 来源格 |
|---|---|
| q0 | N0；保留C1…H−2 |
| q∈K且q≠0 | N1；保留C2…H−2 |
| q(m−1)、q(m+1) | N1 |
| qm | 辅助C0…H−1 |

两份半形分别占0…m−1和m…n−1。第一半的第1层由q0的C及其余N连成，q0通过N0接地；第二半的第1层由qm的C及其余N连成，qm直接触地。较高的每根保留C柱都立在第1层N上。因此两份半形稳定。

### 半形的实际制造

n≥6时，每列满足[列条件A](angle-synthesis.md)。对两半均从左端开始[递归剥离](scaffold-halves.md)：删掉首列，在右侧添加完整N助手后，剩下的第1层N横条接到助手；所有上部C都有该横条提供的直接下邻，故仍稳定。后续每次剥离保持同一性质，最终进入纯N基例。反向恢复给出真实制造树，全程不超过H。

n=4时，两半是q0/q1和q2/q3。C柱均连续接地或直接立在地面N上，侧N位于第1层并由C柱托住。它们满足[四象限完整半形构造](column-construction-complete.md)的直接候选；也属于既有无悬空晶体下落点的直接构造范围。故同样具有制造凭据。

两半稳定，Swap预切不会改变它们，拼合得到D。

### 尾部加工

D的辅助C只在qm。其左右两列m−1、m+1在第1层是N，更高处为空，因此辅助塔不与保留C融合。执行一次P，恰好删除整根辅助塔；其余C提高一层。q0和qm原来触地，得到两枚地面针。

第1层的N原本横向连接q0的保留C。qm辅助C被删除后，这条横向连接分成左右两臂，但两臂都仍接到q0，所以它们只提高到第2层，不下落。较高保留C的直接下方N也保留。因此本次输出已经具有目标的全部C、两枚地面针及第1、2层材料，只缺J三列在第3至H−1层的普通格。

连续k次堆叠同一份J三列普通块。第一次两侧列的最高格为第2层N，中间qm只有地面针，三格块恰落到第3层；以后每次再提高一层。它们接到K中的保留C，并有之前完成的下一层阻挡，均保持原位。最后逐格得到T_(n,k)。

## 3. 所有合法尾部至多一次Pin

q0最低目标C位于第2层，其下面是P0、N1。保留C不能下落，Stack不能带入新C，因此p次Pin要求它的来源高度为2−p。

p≥3时来源高度为负，不可能。p=2时，该C必须来自地面；两次Pin会在它下面形成两根连续地面针，不可能得到目标第1层N。因此p≤1。

以下分别排除p=0，并研究p=1的全部来源。证明不假设六象限或更宽状态属于K，也允许Stack触发旧下料下落。

## 4. 零Pin不可能：低处普通横条不能由Stack补入

反设`B → Stack* → T`。全程不生成C，目标C从B开始就在最终位置。Stack不删除旧N/P，也不提高旧N/P；地面占用不会消失。

令A为除q0、qm之外的全部列。目标在A列第0、1层均为空。因此在整个尾部中，这些位置不可能出现N/P；也不能有C0，因为地面C永远不能下落碎裂。C1也不可能：若正下为空，[J不变量](column-invariants.md)要求同列更低处有N，而该列地面始终为空。

所以A列第1层在整条路线中始终为空。目标第2层的N若是在某次Stack中新增或移动到位，其水平普通块必须在某个参与列的第1层取得直接阻挡。但这个块：

- 不能包含q0，因为q0第2层始终有保留C；
- 不能包含qm，因为落入qm第2层的N无法在仅Stack尾部中消失或升到目标第3层以上；
- 只包含A列时，第1层又始终全空。

故这些N不可能由新增或下落取得，必须已经以第2层N的身份存在于B，而且之后不移动。

### 缺少q0的半形必含辅助C

任一等分半切中，q0与qm互为对径，必在不同半形。考察不含q0的那份真实切后半形。它在第2层已有上述N，所在列第1层为空；同层除qm之外全是被锁定的N。

合法机器输出的[无C组直接支撑性质](stack-progress.md#1-可制作输出的无晶体组有直接支撑)禁止这些普通块悬空。因此qm第2层必须为C，使其成为含C组。这一步不把切后半形稳定当作一般前提。

qm的目标没有任何第0至2层N，也没有第1层P。此处旧N/P不能通过Stack删除，所以来源C2下面不能用N或P1；若第1层空，J也找不到更低N。故qm第1层只能为C。

第0层不能空（J），不能是N（目标不含该N），也不能是C（地面C无法在Stack中消失）。只能为P。于是辅助C1/C2直接受永久地面针托住。任意新增粘连都不能吞并独立的针节点；这些C永远不能下落碎裂，与目标qm无C矛盾。

因此p=0不可能。结合第3节，每条合法尾部都恰有一次Pin。

## 5. 一次Pin的全部来源都被迫保留同一根辅助塔

写任意路线为`B → Stack* → X → P → E → Stack* → T`。

q0的保留C来源为第1至H−2层，目标N1必须来自其下的原地面N0。其他K列的保留C来源为第2至H−2层。A列在Pin输入时地面必空，否则会产生目标没有的地面针；qm的最终低部只有一根地面针。

### 第2层横条在Pin中不能移动，也不能事后补入

Pin之后，A列第1层不可能有C，因为那必须来自这些列原来的地面C，而它们原地面为空。该处N/P也不可能保留：它们既不能升高，也不能在后续Stack中消失，落到地面同样违反目标。

qm第1层若在E中仍有C，它来自原地面C，下面已生成P0，因此永远不能在后续Stack中删除；目标禁止它。qm第1层N/P也会留下额外低格，故同样排除。q0第1层则为固定N。

因此目标第2层N的移动块仍找不到直接下方阻挡：它不能含q0的保留C位置，不能向qm添加永久多余N，其余列的第1层全空。它们在Pin中只能固定提高，在Pin后也不能新增。所以X在全部A列第1层已有这些N。

它们还必须已经在B。若前置Stack要把某个N块放到第1层，A列原地面全空；带q0会撞上保留C1，带qm则会加入在这次Pin后无法消失的第2层或更低N。故前置Stack不能提供它们。

### 原半形与地面材料锁定辅助分量

再取不含q0的原半形。其第1层N在本列没有地面阻挡；除qm外同层均已锁为N。因此无C组支撑性质再次迫使qm第1层为辅助C。

qm原地面不能空（J）；不能为N，否则Pin后多留N1；不能为P，否则得到两根地面针。只能为C。qm第0、1层属于同一触地融合分量R。它在任何前置Stack中都不能跌碎；唯一一次Pin后若未全部删除，也会由新增地面针继续托住。因此R必须在这次Pin中通过触顶融合删除。

R连接第0层和第H−1层，故每个中间层至少有一颗R晶体。第2至H−2层，K中的全部C都是已锁定的保留晶体，R不能占据或融合到它们。两侧缺口列m−1、m+1各自紧邻K中的保留C，放R晶体也会融合到保留分量。故R在这些层只能经过qm。

已知qm第1层为R；第H−2层也只能从qm继续向上到第H−1层。因此qm的第0至H−1层全部为辅助C。这个结论覆盖任意路线中的X，并未把它假设为第2节的特定D。

## 6. 单层计数给出完整词的精确下界

上一节说明：唯一Pin之前，qm在整个允许高度内没有一个普通格位置。前置Stack既不能插到这根塔下面，也不能在高度上限外储存普通格。Pin只删除C、抬升或下落N/P并补针，不把C变成N。

所以目标qm在第3至H−1层的k枚N，全部必须来自Pin之后的Stack。每份单层上料在qm最多提供一枚N，故后段至少k次Stack。

第2节的`P S^k`恰好达到下界，总计k+1步。因此所有最短尾部都没有前置Stack，P/S操作词均为`P S^k`。任何较长路线也不能用前置Stack抵消这k次后段Stack。

k=0可单独使用[必须一次尾Pin的基础目标](../4q5l/necessary-tail-pin.md)；本页k≥1使上部保留晶体约束和非空Stack段同时存在。

## 7. 与原任意序列命题的关系

[此前的全普通上部族](forced-stack-length.md)只给出后段次数的无界下界及首次越界存在性，最优后段路线还可能带前置Stack。本页改用保留晶体限制辅助路径，给出每个k的明确目标，并直接锁定完整最短词。

后续[中间窗口构造](forced-middle-stack-word.md)已证明每个k≥1都有完整最短词P S^k P。两族仍未证明`P^a S^b`中任意a≥2都可强制，也未证明任意多个交替窗口能够组合。若把本页目标整体抬高并预补地面针，来源也可以预制相同针前缀，不能据此增加必要Pin数。任意有限正整数序列的全局命题仍须另证。

证据为两半制造证书、材料来源、无C组支撑性质、J及永久针支撑、保留晶体隔离和单层计数。全文人工推导，没有运行测试、枚举、求解器、物理模拟或游戏，没有修改Python或电路。
