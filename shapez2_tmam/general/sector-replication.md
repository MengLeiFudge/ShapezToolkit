# 相邻象限等宽复制与配方提升

采用相同制造高度上限H≥2。设d≥2为偶数，m≥1为整数，n=dm。把d象限每个格(z,q)复制为n象限同层连续m格(z,mq+j)，0≤j<m，标签完全相同，记此映射为E_m。空产物仍映射为空。

这给出可靠的正向制造方法：d象限目标有配方时，E_m目标也有对应n象限配方。反向不成立为一般推理规则：大机器可以使用打破这些相邻块对称性的中间图形，所以不能根据小目标不可制作，就判大目标不可制作。

## 1. 分组、静止与下落保持对应

每个非针格的m个副本在同层相邻，属于同一个粘连组。原图两个非针格相邻时，复制后的两组格也通过水平边界或竖直C边相连；反之，复制图中任何跨原格的粘边都来自原图的一条粘边。因此非针最大组一一对应。晶体融合组也一一对应。

一根P复制为m根独立P，不能把它们当作一个水平刚性块。每根副本的正下方都对应原P正下方的组或同序号P副本；原非针组对某根P的支撑边则复制为对该P各副本的相同支撑关系。地面属性保持。

用同步剥离证明静止对应：初始保留全部组；每轮删除没有地面、也没有通向剩余组的直接支撑边的组。非针组是否被删除与原图一致，P的全部副本也同时与原P被删除。归纳到固定点，原静止非针组与全部副本静止格对应，原移动组及P副本也对应。该论证同时适用于有地面及空地面结算，不要求原图属于K或稳定。

移动C碎裂后，每个水平N块扩张为对应水平块，P仍分别下落。同一原列的m个副本列具有相同障碍高度；N块落点是占用列顶最大值加一，复制不改变这个最大值。P副本彼此不共享列，同层的处理顺序可以交换，最终落点相同。按来源层归纳，全部落点与标签保持对应；按相同H截高也对应。因此单次物理结算满足

`Collapse_n(E_m(S)) = E_m(Collapse_d(S))`。

这是单次结算关系，不能在输出后擅自增加重新分组和重力。

## 2. 每个制造操作的提升

| 原操作 | n象限中的操作 | 原因 |
|---|---|---|
| 无C基础层 | 每个格复制m份的基础层 | 仍不含C，符合既定供料前提 |
| Rotate(t) | Rotate(mt) | 把整个复制块移动t个原象限 |
| Cut出口0/1 | 同出口Cut | n/2=m(d/2)，切线位于复制块边界，不会只切掉部分副本 |
| Swap出口0/1 | 同出口Swap | 两边半切对应，再交叉拼接，不追加重力 |
| Pin | 一次Pin | 顶层及其融合删除对应，地面针按同一占用掩码复制，再应用结算对应 |
| Crystal(color) | 同色Crystal | 每格空/P转换为C，其他标签保持；高度不变 |
| Stack | 一次Stack | 上料均抬高H+1，初始网格复制对应，再应用结算对应 |

对Cut，跨切线的原晶体融合组恰好对应跨新切线的融合组，所以保留侧的连带删除也一致。对Pin，触顶融合组及原地面占用按高度判定，不随横向复制改变。由制造树归纳，每个中间产物都恰好是原中间产物的E_m像。

高度上限必须相同，不能把一个较高上限的准备过程直接搬到较低上限。所有旋转都要按m缩放；不能只重复目标编码而沿用原旋转参数。

## 3. 从输入图形找复制结构

把目标每一列从底到顶的全部标签作为一个列字。相同只指列字完全相同，包括内部空格、部件及颜色。沿象限环把连续相同列分为若干段，长度为r₁…r_k；取真实段边界为起点。全列相同时起点取0，只记一段长度n。

最大的可压缩宽度为

`m = gcd(n/2, r₁, …, r_k)`。

因为商图仍要求偶数象限，所以m必须整除n/2；又因为每个复制块内的列完全相同，它必须整除每个连续段长度。这两个条件也充分：从段边界每m列取一列，即得偶数d=n/m的商图。m=1时没有这种压缩；m>1时d<n，构造递归严格减小象限数。

压缩图按所选起点对齐。小图配方提升后，再旋转回该起点，得到原输入目标。此识别不搜索格位目录，也不猜测标签擦除后的近似对称。

## 4. 制造证书可以逐节点变换

`Builder.replicate`读取真实小图配方，把每个中间图形按E_m扩张，旋转参数乘m，其他操作及物品输入顺序保持。根据第2节，无需为每个大图节点重新执行一遍物理结算。扩张后的节点仍包含完整中间图形，末端恢复朝向后必须等于目标。

遍历使用显式栈，不因任意H的深制造树依赖Python递归深度。相同源Recipe对象可以共用变换后的对象；消费式计数仍按每个输入出现次数累加，没有复制实体物品。

不计最后恢复朝向，变换保持制造表项数与物品槽需求；恢复朝向至多增加一个净旋转表项。大象限下Rotate(mt)可能要多次调用单象限旋转设备，表项数不能直接当作原生操作次数、建筑数或游戏耗时。

`Constructor`只在已有直接构造未覆盖时尝试商图，不改变旧成功配方。先尝试最大复制宽度；若还能得到另一份四象限商图，再尝试该商图，以保留四象限角构造的能力。商图由较小Rules、相同H的默认Constructor求解，不自动开启完整四象限搜索。成功提升真实配方；失败仍返回unknown，不把商图的否定结果传给原目标，也不宣称遍历了全部可能商图制造方式。

## 5. 八象限的间隙代表与边界

取已有四象限单次融合删除代表：

`CuCu----:--P-----:crCu----:--Cu----:--Cu----`。

每个象限复制两份，再整体转一个八象限单位。目标含有带空隙的晶体列，原通用独立柱/前缀构造不能制造该列；压缩后可以调用四象限角构造，再提升其配方。恢复方向还覆盖了复制块边界不从q0开始的情况。

[八象限完整代表配方](../examples/8q-replicated-gap.md)已由默认Constructor导出52个表项、3个物品槽。它使用四象限构造器取得的证书，再直接扩张中间图形；不是在八象限重新执行全部物理来验证证明。

这个族说明一般参数可以复用较小象限的结构构造。它没有覆盖所有大象限图形，也没有证明某个旋转、半切或高度规则不同的Mod自动符合本模型。游戏电路应复用较小逻辑核心和逐格扩张/参数换算模块；具体原生信号转换、存储和时序仍需单独设计。

证据来自组图对应、同步剥离、落点归纳和制造树归纳，没有运行枚举、测试或游戏验证。
