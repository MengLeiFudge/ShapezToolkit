用户提供的 PDF 对当前研究有直接价值，尤其是四象限任意层的带普通支柱列，以及两列半边的共同下落构造。本文记录已核对的用途与证据边界；没有把 PDF 的全部完备性声明直接接成程序拒绝条件。

来源：作者 everain，15页，用户文件 `D:\Downloads\Shapez 2 列与可分形状的判定和构造.pdf`。SHA-256：`b5be3d82834aa28af8c2057357e1f7d8eac6312502f9ed32774258cb51c7b48a`。已读取全文提取文字，并查看关键算法页的原页图，补齐文字提取缺失的公式。本记录的层号沿用 PDF，从1开始；短代码逐层自底向上。

## 1. 三个问题必须保持区分

PDF 第2页区分：

- 孤立列：成品只有目标列。
- S 列：目标列旁边保留一根连续触地的纯普通柱，覆盖目标高度。
- L 列：目标列能出现在某个合法整图中，其他辅助结构不限。

第2至3页的“可分形状”指：存在一条切向，静态分开的两个半边都可以作为真实半破输出取得，因而可以直接交换拼成目标。

这些对象不能互相替代。一个列不属于 S，不意味着它不能与含晶体的邻列共同成为合法半边；一个整图不可分，也不意味着它不能在交换后继续用 Pin/Stack 制造。PDF 没有声称解决四象限全部整图、六象限全部三列半边或任意强制操作序列。

## 3. 已独立核对的三连晶环下落

PDF 第5至6页构造 G 能补一个现有直接释放未覆盖的充分构造。

取主列：

```text
原列：cT..Tccc
目标：cT.T.ccc
```

把第5层普通格移到第4层，目标第3层仍为空。主列旁原有普通支柱。按文中构造换入满高辅助列 B：第4层为 C，第7层为针，其余为普通格。

主列第6至8层的三连晶，与 B 的普通格6、针7、普通格8形成含针支撑环。这个上部组在下方支撑改变后仍可保持。再从 B 的另一侧接入仅第4层为 C、其余为普通格的桥柱，切掉桥柱，连带删除 B 的第4层 C。

主列和 B 的第5层普通双格一起下落。B 的第3层普通格保持接地支撑，双格恰停在第4层；主列的三连晶由上面的针环保留。随后接回普通支柱，再去掉 B。

原主列的 C 均有直接下邻，已在本项目[直接释放充分构造](four-quadrant-release.md)的范围内；辅助 B 连续接地且 C 在针以下，也有独立制造凭据。因此这不是只在任意网格上演示一次下落，而是可接入既有制造链的局部构造。

这里没有沿主列执行 Pin，地面 C 可以保留。它对应用户此前提示的“四象限八层、三连晶参与循环支撑”。这次只核对了该窗口和构造 G 的支撑机制，没有据此宣布全部四象限 S 判据已证。

## 4. 已独立核对的八层共同下落半边

PDF 第15页给出如下半边 Q。把第4层普通双格提高到第5层，得到带外框时制造的前态 Q′：

```text
层号      Q          Q′
 8       T c        T c
 7       P c        P c
 6       c c        c c
 5       . .        T T
 4       T T        . .
 3       . T        . T
 2       T T        T T
 1       c T        c T
```

Q′ 两列的最高 C 均有直接下邻；左列第1层 C 与第6层 C 之间的空隙由两枚 N 分隔。两列分别配外向普通柱，均可由本项目现有直接释放构造制造。

把两个带外柱输入交换拼为“普通柱、左列、右列、普通柱”，再半破去掉两根外柱。Q′ 上部的右列三连晶与左列 C6、针7、普通格8形成针环，保持原位。第5层普通双格正下第4层全空，下降一层后被右列第3层普通格挡住，恰好得到 Q。

Q 的短代码：

```text
crCu----:CuCu----:--Cu----:CuCu----:--------:crcr----:P-cr----:Cucr----
```

Q′ 的静态内部网格：

```text
crCu----:CuCu----:--Cu----:--------:CuCu----:crcr----:P-cr----:Cucr----
```

**Q′ 必须连同外柱准备，不能把没有外柱的 Q′ 当成已可制作的中间输出。** 它单独存在时，第5层双格无支撑；真实半破会立即完成上述下落。这与四象限合法输出都属于 K 的结论相容。

这个具体半边已有独立的充分制造论证。它说明可以补一个“联合提高双格、拆框共同恢复”的通用构造入口，而不必要求目标的每一列先独立通过现有直接释放条件。尚未修改 Python 或导出实体配方。

## 5. 必要性已补证，充分构造仍待核对

PDF 第8页声明四象限带普通柱列的判据：

`u ∈ S ⇔ P(u) 且 (D(u) 或 F(u))`。

其中 P 是五项共用条件；D 是无晶体、底格为针、或最低 C 下至少两空；F 要求每个 C 下洞能够以三连晶环恢复，或在下方区间找到相邻普通双格，最低区间还允许地面普通格作为终点。

第13页算法8只试两个半边前态：目标本身，以及按“较低最高 C 的最大粘连组”确定的一次普通双格联合逆提升。PDF 声明两个候选都失败即可拒绝。

PDF 正文未逐项展开任意制造历史的排除论证。补充推导已完成两部分：

1. [两个前态的约化](half-predecessor-reduction.md)：先消去最终会碎掉的临时C，再证明所有列条件失败都来自唯一跨两列晶体针环下方的普通双格；把它们提回组底前一层即可同时恢复两列。
2. [制造历史归纳](half-history-normalization.md)：Pin输出每列都满足底部资源条件；Stack保持旧晶体核心；同切向保留规范前态，换切向删除全部失败核心。由此覆盖任意合法Cut输出，证明两个候选均失败即可拒绝该半边，并推出真实S列必须满足文中的列条件。

还未完成的是充分构造的全参数核对：通过列条件后，递归提升、一次Pin批量恢复，以及算法6的底块整理和提前弱落是否总能按规定制造。两个具体充分构造见第3、4节。

理论上的“双候选均失败”已能排除半边；现有Python尚未实现这个新判据，其已有构造器返回失败仍须保持unknown。半边不可得也不能直接当成整个目标不可制作。
