# 保留针下间隙的上料层高约束

这是[列内压紧载体](packed-column-stack.md)之后的第四候选，采用相同的原下料D、一次结算D₀及新增Δ合同。前三候选成功时保持原配方；第四候选只扩大未覆盖范围。适用于偶数n≥2、H≥2。

## 1. 不必把第一根针以下也压成连续N/P

列内压紧为每列的全部N/P要求相邻来源高度相差1。当两个水平N块同时经过两列，而两列之间的针数量不同，就可能产生不相容的等式。例如一列为NPN，另一列为NN，共享底部和顶部N块：前者要求两个N相差2，后者要求相差1。

独立柱制造只要求最高辅助C以下不能夹着非触地前缀的针。一个足够宽、无需选分支的载体族是：**每列的全部C都在该列第一根目标针以下；第一根针起的N/P后缀连续。** 没有针的列可以在任意两个N之间补C。它包含上轮的“C前缀＋连续N/P”族。

因此，为每个Δ水平N块及单P设置一个来源层变量x_b，而不是每列只设一个起点。原块内所有格共享x_b，保持刚性与普通标签。

## 2. 线性数量的差分约束

加入以下约束：

1. 每块`0≤x_b<H`。
2. 同一列从下到上相邻的两个目标格属于块a、b时，`x_b≥x_a+1`，保留该列顺序。
3. 从该列第一根P起，相邻目标格必须连续，所以另加`x_a≥x_b−1`。第一根P之前的间隙允许填C。
4. 对每对相邻列，按目标高度扫描N行；前后相邻的两个非空N行属于块a、b时，`x_b≥x_a+1`。同目标行的相邻N本来就是同一个块，不再需要等式边。

第4项保留相邻列的N行顺序，保证不同目标N块不会在来源中意外粘合。不同列且没有邻接约束的块仍可以调整处理先后。同列中间即使有P，所有原标签和顺序也保持。

块数M≤nH，每个列格和相邻列扫描只产生常数条边，边数O(nH)。从全0开始进行最多M轮下界松弛；超高或正环拒绝，否则取得逐块最小解。证明与列起点的差分约束相同。时间上界O(MnH)≤O(n²H²)，存储O(nH)。实现只扫描Δ实际最高层以内；制造上限更高时，不扫描额外空白行。这是确定性多项式约束求解，不是对每块枚举H个来源层。

## 3. 实体制造、释放与精确输出

按求得的x放入全部原N/P，再在每个非空列中，从地面到该列最高格把空隙填C。每列第一根P及以上无空隙，因此没有C在P上方。每根柱均可独立制造，之后按已有半面拼接方法取得实体上料B。

x逐分量最小，使每列最高格最低，所以辅助C总数及整体载体高度也在这套约束族内最小。它不保证配方加工次数最少，也不保证最小解一定释放。

仍必须检查`stationary(B, grounded=False)`为空。通过时，全部C碎裂，全部N/P释放；普通块划分和共享列顺序都与Δ相同。由目标直接支撑及列顶落点归纳，实际`Stack(D,B)`恰好得到T。无需把原下料额外结算，也不要求它属于K。

若约束有解但最小解含悬空支撑环，这一种安排返回未覆盖。程序随后尝试第5节的触地针前缀形式；两种最小解都失败，也不能排除其他高度安排或其他真实复杂上料。

## 4. 六象限五层的扩域代表

原下料：q1四层N柱、q5三层N柱。新增格如下：

| 零基层 | Δ，q0…q5 | 新载体B，q0…q5 |
|---:|---|---|
| 4 | `-N----` | 空 |
| 3 | `---NNN` | 空 |
| 2 | 空 | `---NNN` |
| 1 | `---P--` | `-N-PCC` |
| 0 | `N--NN-` | `NC-NNC` |

三个旧候选的失败原因可以分别静态定位：

- 无C下落把q0、q1的N粘在一起，却要求它们回到不同目标层。
- 原位补C在q3产生N-P-C-N，不能独立制造；辅助C还可能围住该针形成静止环。
- 全列压紧时，q3的NPN要求底顶N相差2，q4的NN要求相差1；它们共享底顶普通块，所以等式不相容。

新载体允许q4在两个N之间保留一颗C。q3仍为NPN，q4为NCN，q5为CCN；它们顶端N对齐于来源第2层。底部晶体组没有向下支撑，空地面剥离后依次释放q3的P及顶端三连N。顶端三连N在真实下料上被q5旧柱托到第3层，保留q3/q4的目标空隙。

这证明第四候选严格扩大固定下料的一次堆叠成功域。目标本身无C、可从零逐层制造；此处解决的是复用给定下料并只加工一次的问题。[完整代表配方](../examples/6q-layer-constraints.md)已导出57个表项、3个物品槽，包含下料与上料的制造。

## 5. 触地针前缀的规范化形式

每列在第一个N之前，可能先有k根目标P。把这些P的来源层固定为0至k−1；第一N及其后的格保留同列顺序。从第一个N之后遇到的第一根P起，才要求后缀连续。其余空隙仍填C。

初始k根P的固定不需要额外求解器：同列递增和非负性已经要求第i根P的层号至少i，只需把它的变量上界设为i。P是单格独立块，不会与另一列争用这个上界。其他列的N块对齐、相邻N行保序及高度限制全部保持。

### 为什么无需枚举每列是否采用触地前缀

考虑仅在Δ非空列内补C、列顶为最后一个目标N/P、保持原N块和相邻N行次序的连续独立柱载体。它的各列已满足Q，但初始目标P之间可能夹C，或者整列被C前缀抬高。对每列作如下规范化：

1. 把第一N之前的全部k根P移到0至k−1，保持P次序；全P列也同样处理。
2. 保持全部N和第一N之后的P的来源层不变；在新的地面至列顶范围内以C补齐其余空隙。

若有N，它原来已高于k根P，所以原N层号至少k，不会被新前缀覆盖。N块划分与相邻N行次序完全不变；P仍在原列序中。第一N之后的任何P都不是触地针前缀的一部分，Q已要求它上方不能再有C，因此这段NP后缀本来就是连续的。规范化后所有初始P触地，允许中间C位于这些P上方；其余P仍处于最高C之上。故新柱满足独立制造条件。

有N的列顶不变；全P列只降低列顶。因此规范化不增加高度或辅助C数。由此，第5节的线性约束有解，当且仅当上述保持相邻N行次序的连续柱填隙族有制造几何可行解。各列不需要做2^n种“针前缀/非前缀”选择。这个完备性仅针对制造几何，不包括全体释放。

移动针及改填C可能改变横向粘连与支撑环，所以规范化后仍必须重新检查空地面静止集合。程序先尝试第2节的最小解，再尝试本节最小解，保留已有成功路径；没有把规范化当成对任意下料等价的物理操作。

### 六象限五层的触地前缀代表

原下料为q1四层N柱、q3地面N、q4两层N柱。新增q0地面N、q1第4层N，以及q3的P₁/N₂/N₄和q4的N₂/P₃/N₄。层号仍从0开始。

无C候选把q0/q1粘合；原位补C在q3形成C-P-N-C-N；全列压紧及未固定针前缀的第2节形式，则要求q3两个N相差1、q4两个N相差2，均失败。触地前缀形式把q3做成P-N-C-N，把q4做成C-N-P-N，两个N层对齐，初始q3针触地。载体从底到顶为：

```text
NC-PC-
-N-NN-
---CP-
---NN-
```

空地面结算中，底针与底C组先失去支撑，随后释放第一对N，再释放中间P/C与顶端N块，没有残留支撑环。在真实下料上，q3初始针停于第1层，第一对N停于第2层，q4针停于第3层，顶端N停于第4层，恰好得到目标。这给出固定针前缀的严格扩域实例；[完整配方](../examples/6q-ground-pin-prefix.md)已导出51个表项、3个物品槽。

## 6. 实现与复用成本边界

程序复用同一个差分下界求解器：第三候选以n个列起点为变量，第四候选以M个物理块为变量，依次尝试普通间隙和触地针前缀两种约束。旧成功路径不额外进入后面的形式。释放检查和实体独立柱制造沿用现有模块；触地形式只改针变量上界及连续后缀的起点，不增加指数枚举。

游戏实现应在同一组加法、比较、选址和写回模块上扫描约束；变量、边表和变化位属于存储与控制成本。最坏轮数增加，不要求按轮数复制电路。这里给出计算与存储界，尚未把它们折算为游戏建筑，也没有生成走线。

证明依据来源块连接、列内次序、针下间隙位置及真实制造凭据；没有运行枚举、测试或游戏验证。
