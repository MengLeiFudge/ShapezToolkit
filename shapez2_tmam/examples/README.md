物品槽只计这份制造树的同时存活物品，不含搜索状态和传输缓存。配方先制造槽需求较大的子树，再按原输入语义消费；见[槽数调度证明](../research/proofs/04-stacking.md#s04-19)。

四象限表中的字串只描述q0主列，从底到顶；完整目标还包含q1辅助列。辅助列属于成品，不能在最后擅自切掉。N用普通未着色圆形Cu，C用红晶体cr，P用P-，空格用--。两象限例子使用六层上限，八象限复杂堆叠使用八层上限，十八象限级联使用十七层上限，其余例子使用五层上限；八象限复杂堆叠最终只有六层，但准备晶体塔需要八层。所用配置须提供单象限旋转、等分半切及相同局部规则；不能仅凭图形码长度推定某个Mod符合这些前提。

## 操作与方向

每个图形码用冒号分层，从底到顶；每层从左到右为q0、q1……，q(n−1)与q0相邻。空底层和空中间层必须保留。

| 加工 | 操作方法 |
|---|---|
| base | 准备产物栏所示的一份无晶体单层料，允许普通格与针；配方没有把晶体当作天然原料 |
| rotate | 参数t表示q移动到(q+t) mod n；按象限计，不按度。负数反向。2q每步180°，4q每步90°，6q每步60°，8q每步45° |
| cut | 出口0保留q0到q(n/2−1)，出口1保留另一半；弃置未选出口 |
| swap | 输入按A、B排序；出口0取A前半+B后半，出口1取B前半+A后半。先分别切割结算再拼接 |
| stack | 输入按下料、上料排序；不可交换 |
| pin | 对输入执行一次顶针加工 |
| crystal | 参数r表示红色结晶；对输入执行结晶加工 |

编号只标记当前这份实物。两个输入均被消耗；一个编号不会作为免费复制品重复用。V的91步已把两份H独立展开。基础供料遵循当前TMAM的“任意无晶体单层可供给”前提，原料工厂不包含在表内。

## 六象限H的简明流程

1. 独立制造q0的`C N C C C`柱、q1的单C、q5的`N P N N N`柱。拼接保留三根柱，得到文档中的S。
2. 保留连续半面`{q4,q5,q0}`。q1辅助C被切除，其融合的q0地面C一同消失，q0的N回落；上方晶体由q5侧面材料托住，得到A。
3. 独立准备B：依次堆入q3单N、q3单N、q1/q2/q3三连N、q2单N、q1/q2双N。
4. 拼接取A的`{q4,q5,q0}`及B的`{q1,q2,q3}`。
5. 保留`{q0,q1,q2}`，得到H。其第三层与第五层普通格经q0晶体脊连接成框架，第四层q2普通格与框架互相支撑。

H的非空列具有相同列顶，因此由[接地来源与潜在粘合定理](../research/proofs/04-stacking.md#s04-02-h9)，它虽然不属于K，仍可安全逐层追加。

V只需独立生产两份H，将第二份转三个象限，再交换拼合。V就是最后输出；不要为了整理成品再送进触发重力的加工设备。

若要观察重新加工的变化，按[第九份配方](6q-V-stack.md)再给V堆入q3单格Cu。预期晶体全部碎裂，得到`CuCuCuCuCuCu:----CuCu--Cu:--CuCu--CuCu`。这份配方已通过[任意下料的单次普通追加](../research/proofs/04-stacking.md#s04-10)接口生成；从V开始只需一份基础料和一次Stack。

## 重新导出

十八象限级联单独导出，使用已有Pillow及中文字体；`--font`可指定字体文件：

```bash
python -m shapez2_tmam.synthesis.cascade_example --output shapez2_tmam/examples
```

其余30份代表使用原批量入口：

```bash
python -m shapez2_tmam.synthesis.examples --instructions --output shapez2_tmam/examples
```

四/六象限五层的26份代表另有同名`.instructions.json`，可逐包提交到对应[六槽回放器](../blueprints/README.md#六寄存器配方回放)。[半圈规范化](../research/proofs/04-stacking.md#s04-18-h6)使这些最终配方每个表项只发一包；[六象限H](6q-H.instructions.json)为45包、3个活动槽。未经规范化的自定义六象限树仍可能把两格旋转拆包，因此提交时以指令id与request为准。两象限六层、八象限及十八象限代表没有此原生指令产品，仍按步骤表使用符合配置的设备。

这些步骤数是当前明确配方的长度，不是最短路径证明，也不是电路元件数。一个rotate表项描述净朝向；若当前机器不能一次转到该角度，需要连续调用旋转设备，因此表项数也不等于原生设备调用次数。长配方可以由同一个旋转/切割/堆叠模块按时序循环执行。对应理论见[四象限角构造](../research/proofs/02-four-quadrants.md#s02-03)、[六象限非K半形](../research/proofs/03-general-construction.md#s03-02)和[一般偶数象限构造族](../research/proofs/01-foundations.md#s01-04)。
