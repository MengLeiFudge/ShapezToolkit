# 固定触地针前缀以保留中间晶体

已有q1四层柱、q3地面N及q4两层柱；上料把q3做成P-N-C-N、q4做成C-N-P-N。q3初始针触地，使其中间晶体可制造，并让两列普通块对齐。

配置：6象限、5层上限。

目标（从底到顶，q0为每层最左格）：

`CuCu--CuCu--:--Cu--P-Cu--:--Cu--CuCu--:--Cu----P---:--Cu--CuCu--`

共42步，含基础供料；不是最短路径。输入编号指向已完成物品，使用后消耗。
物品槽峰值为3，不含搜索状态及传输缓存；[槽数调度证明](../general/recipe-slots.md)。
同一子配方出现两次时分别生产。Cut/Swap的另一个出口弃置；按表中出口继续。

[操作与方向说明](README.md)；本配方未在游戏中验证。
