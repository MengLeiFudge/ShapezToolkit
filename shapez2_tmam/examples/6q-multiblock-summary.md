# 多块复杂上料替换为无晶体载体

原上料q0为CCCN、q3为NPN；辅助C抬高后全碎。摘要落地时四块不合并，改用q0地面N和q3的NPN，四步准备后堆到q0单N下料。

配置：6象限、5层上限。

目标（从底到顶，q0为每层最左格）：

`Cu----Cu----:Cu----P-----:------Cu----`

共6步，含基础供料；不是最短路径。输入编号指向已完成物品，使用后消耗。
物品槽峰值为2，不含搜索状态及传输缓存；[槽数调度证明](../general/recipe-slots.md)。
同一子配方出现两次时分别生产。Cut/Swap的另一个出口弃置；按表中出口继续。

[操作与方向说明](README.md)；本配方未在游戏中验证。
