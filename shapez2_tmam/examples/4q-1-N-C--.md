# 单次融合删除

先把普通格提高到间隙顶部，以针隔开辅助支撑，切掉辅助晶体后普通格回落。

配置：4象限、5层上限。

目标（从底到顶，q0为每层最左格）：

`CuCu----:--P-----:crCu----:--Cu----:--Cu----`

共37步，含基础供料；不是最短路径。输入编号指向已完成物品，使用后消耗。
物品槽峰值为3，不含搜索状态及传输缓存；[槽数调度证明](../general/recipe-slots.md)。
同一子配方出现两次时分别生产。Cut/Swap的另一个出口弃置；按表中出口继续。

[操作与方向说明](README.md)；本配方未在游戏中验证。
