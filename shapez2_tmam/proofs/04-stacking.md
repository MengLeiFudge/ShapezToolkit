## 04-01 K下料的通用堆叠化简

原文标识：`general/conditional-stacking.md`。

对偶数 n≥2、层数上限 H≥2，沿用半切、单象限旋转及一次加工内不合并新接触的参数化规则。K 表示每个最大粘连组都能沿直接支撑边到达地面，或到达包含顶针的支撑环。本文不假定全部可制造状态属于 K。

结论：任意 Stack(D,U)，只要 D∈K，就能从同一个 D 用连续普通块或单针逐次堆叠取得相同输出。结构目录因此可以对 K 下料只保留至多 n²+1 种上料；非 K 下料保留全部真实双输入堆叠。四象限既有约化是这一定理在 R₄⊆K 下的特例。更大的范围由[K_add](#s04-02)给出，包含六象限非K半形H；Python现已采用K_add判据。

<a id="s04-01-h1"></a>

### 1. K在新增基础块下闭合

原格位不动时，加入普通格只会收缩一些非针粘连组；顶针节点保持独立。通向地面的路径在收缩后仍通地面。包含针的支撑环不能被收缩成一个节点：针与支撑它、被它支撑的其他组始终分离，因此仍有经过该针的非平凡闭合路径。原来通向该环的组仍有支撑。

一个新落稳的普通连通块或单针，必在地面，或直接支撑于旧图。即使随后与旧组合并，上一段的收缩论证仍保留其支撑。因此结果仍属于 K，原格位不移、不删。论证未使用象限数或五层上限。

<a id="s04-01-h2"></a>

### 2. 任意上料可以换成最终保留的基础块

上料整体提高 H+1 层，起初与 D 分离。D 的组原本稳定；新接触不会在本次结算中合并旧组，所以 D 始终不动。

上料晶体若随组开始下落就消失；若始终不动，就留在上限外并被截掉。因此最终新增格 Δ 只含普通格或针。含晶体的移动组在第一次下落时拆成水平普通块及单针，此时仍在 D 上方。每个保留下来的块均不能穿过原列顶，且最终至少有一格位于地面或紧贴下方保留格。下方格的高度更低，不会因为最终截高而被删。

设 h_D(q) 为 D 的列顶人类层号，空列为0。T 能从 D∈K 仅以基础块追加取得，当且仅当：

1. D逐格包含于T，标签不变。
2. Δ=T\D不含晶体。
3. 每个新增格(z,q)均满足z>h_D(q)。
4. 只在Δ内部按层划分普通连通块，针单独成块；每块在地面，或至少有一格正下方在T中非空。

必要性如上。充分性：按目标层号递增加入每个块；此前同列全部格低于目标层，而第4项给出目标层正下方的支撑。块的落点公式

`z = 1 + max(h_current(q), q属于该块)`

使它恰好停在目标层。每步后仍在K，归纳得到T。至多nH个有效块；同一目标层的块列集合互斥，可合并为一份无晶体单层上料，所以也有至多H次Stack的实现。零新增格使用零次操作。

这里仅用最终保留块；不能把任意上料的晶体预先删除，再把剩余全部格堆入。原上料的支撑环可能让某些普通格也留在上限外，最后一同截掉。

<a id="s04-01-h3"></a>

### 3. 结构目录的上料域从整个目录缩到n²+1

擦除普通部件及颜色，只保留N/P/C/空结构。基础块只有：

- 环上长度1到n−1的连续普通区间：每个长度有n个起点，共n(n−1)种。
- 整环普通块：1种。
- 每列一个单针：n种。

合计 n(n−1)+1+n=n²+1。四象限17种，六象限37种。任何任意上料堆叠输出，都可由第2节的有限序列取得；序列每一步恰使用上述某一种结构基础块。目标普通标签沿新增格回填基础料即可，不要求所有普通格都使用Cu。

在有限配方目录中替换Stack规则：

```text
若D属于K：对每种连续普通基础块或单针b，加入Stack(D,b)
若D不属于K：对旧目录每个U，加入真实Stack(D,U)
```

其他Rotate/Pin/Cut/Swap及种子规则保持。所有新记录仍只引用旧轮中的D与初始基础料；非K分支引用旧轮D/U。

可靠性：每条边仍是一个真实加工，基础块均为合法种子。

完备性：对原制造树归纳。非Stack节点或非K下料节点保留原操作。K下料的Stack节点换成第2节的有限基础块链；链的起点可由归纳制造，每个后继会在后续某轮加入。不能声称替换后的输出仍在原来同一轮出现，但有限轮出现足以保证最终闭包相同。有限状态空间和单调增长仍保证终止，停稳后缺失目标才可判不可制造。

若旧目录有M项，其中M_K项属于K，则每轮Stack候选上界从M²变为

`M_K·(n²+1) + (M−M_K)·M`。

这只是Stack候选数，不包含Swap、种子或全部状态规模。没有证明M_K占比，也没有证明六象限整体已实用。六象限非K半形及一般复杂堆叠反例必须保留，见[非K半形](03-general-construction.md#s03-02)、[八象限反例](01-foundations.md#s01-03)。

<a id="s04-01-h4"></a>

### 4. Python与电路实现边界

[`stack_reduction.stack_successors`](../synthesis/stack_reduction.py)实现结构目录接口，目前把本页K条件扩大为[K_add](#s04-02)。通过时生成连续区间/单针，用列顶最大值直接计算落点，跳过截高后完全不变的边；未通过时，若一次结算进入安全类则使用[纯C触发约化](#s04-04)，否则逐个调用真实Stack。它接受擦除标签的结构状态，基础上料统一用Cu作为N代表。Rules已开放偶数n≥2、H≥2，见[参数化模型与固定接口边界](#s04-20)。

K分支无需对下料每次重建物理组，也无需保存任意多层上料。候选生成只需模式、起点、长度；列顶可共用，落点取对应区间最大值。六象限上料域最多37项，而非上料目录地址。实际门数尚未编译，不能由候选数直接换算为37个元件。

四象限已有全局K约化，本结论不会再次减少其搜索域；它主要让六象限/一般参数保留强约化的适用部分。对四象限的反馈是继续优化S前缀和Pin逆像，而不是误删已在标准形中消除的复杂上料。

证据为结构证明、既有物理实现静态重读及Python LSP；未运行目录枚举、目标搜索、测试或游戏。

## 04-02 按接地来源与潜在粘合扩大堆叠约化范围

原文标识：`general/addition-components.md`。

适用于偶数n≥2、H≥2的既有局部规则，层号从0开始。定义可静态检查的充分条件K_add，使任意复杂Stack在此范围内都可改用基础块序列，且结果仍在K_add。

这个范围包含[K](#s04-01)和[受列顶保护的普通块范围K_top](#s04-05)，还包含所有“非空列具有相同列顶”的稳定图形。因此六象限非K半形H及一般H_k也可以逐层追加。K_add仍不是完整可制作性判据，其外的下料保留真实复杂Stack。

<a id="s04-02-h1"></a>

### 1. 先分清旧图的接地组

对D建立最大粘连组及向下支撑图。G₀为能够沿支撑边到达地面的全部组；其余组记为Q。一个Q组不可能有通向G₀的支撑边，否则它本来就属于G₀。

原格位不动时，G₀中的支撑路径在任何非针组合并后都仍通向地面。若新N把一个Q组粘到G₀，它也取得地面路径。这种粘合不会导致该组失稳。

记h_D(q)为列顶，空列为−1。所有允许的新格位构成

`E = {(z,q) : h_D(q)<z<H}`。

后文分析只允许在E添加N/P，不删除或移动原D。

<a id="s04-02-h2"></a>

### 2. 哪些新块可能只靠悬空旧组托住

在E内标记集合R：

1. 某列非空且其最高格属于Q时，把该格正上方的一格加入种子；超出H的不加。
2. 从种子只沿“向上同列”及“同层环上相邻列”的E内边传播，不向下传播。

R是可能由非接地旧组间接支撑的新块区域；它只是几何上界，不是实际可制造的新料。

设一次Stack或逐块追加已经产生落稳的新N/P块，每块至少有一个直接下方支撑。沿新块之间的支撑链向下：新块都是单层，层号严格下降，最终到地面或某个旧D格。首次碰到旧格时，它必为该列旧列顶，因为新格不能插入列顶下方。

如果这条链终止于Q，反向看它就是从上述种子出发、沿向上边和新N块内部水平边到当前块的路径，完全包含于R。因此：

> 一个新块若不在R内，就必有一条经新块到地面或G₀的支撑路径，因而取得地面支撑。

每个N块要么全在R，要么全不在R，因为其水平连接都在E中；单P也无此歧义。R内的块仍可能有其他地面路径，不能反向判定它一定悬空。实际新P只会减少水平连接，用N的传播规则作上界是安全的。

这些地面路径在输出重新分组后继续存在。它们终止于地面，不会像悬空环那样因全部收缩而消失。

<a id="s04-02-h3"></a>

#### 危险区域只需每列一个高度

E在每列都是向上连续的区间；R也向上封闭。因此记a_q为R在该列的最低层，没有R时取H。种子列初始化a_q=h_D(q)+1，其余列初始化H。沿相邻列q→r传播，更新：

`a_r ← min(a_r, max(a_q, h_D(r)+1))`。

它表示源列已经能到达的最低高度，以及进入目标列空区所需的最低高度，两者取大值。任意传播路径的最低可达高度，就是起点种子高度与途中各列空区下界的最大值。删去路径中的回路不会增加这个最大值，故只需考虑环上的简单路径，方向只有顺时针与逆时针。

选择初始a最小的列作为起点，从它顺时针扫一圈，再逆时针扫一圈，共2n次边松弛，即取得全部a_q。起点值已是全局最小种子高度，不可能再降低；任何越过起点的单向路径，都可以从这个更低或等高的起点重新开始，所得高度不会更差。其余单向简单路径在相应一圈中按顺序被处理。中间借用已传播值仍对应真实路径，不能产生过低的高度。故危险区域阶段只需O(n)时间、O(n)存储，与H无关；后续按z≥a_q读取R即可。

<a id="s04-02-h4"></a>

### 3. 只对未保证接地的新连接分组

再定义X：E中与某个G₀的N/C格水平相邻的位置。若实际在X放入N，它会直接粘到接地旧组，因此这个N必接地；P不粘连，不作同样判断。建立仅供分析的网格V：

- 保留D中Q组的全部原格及材料。
- 在R\X的每个位置放N。
- 不放G₀的格，也不填其他新位置。

仅调用粘连分组，不调用重力或结晶。V不作为免费物料，也不要求可制造或稳定。每个原Q组完整落在V的某个组内，以其编号记为λ。

还可省掉全部高于原图最高格的虚拟N。记原图实际高度为L≤H，这些N在第L层及以上，没有同层原格，也不能与下方C竖直粘连，所以不会连接任何原Q组。R传播又不向下，因此只求0至L−1内的R，使用L作为无标记哨兵，就与完整H范围在原组上的λ完全相同。K_add成员判定由原图决定，不随允许的额外空白高度增大而改变；程序不为未占用的高层分配分析格。

若实际输出中两个Q组通过新N粘合，有两种情况：

- 新粘合组包含G₀、E\R中的新N块，或X中的新N。由前两节或直接水平粘连，它取得地面路径。
- 新粘合组不包含这些格。全部新N连接都来自R\X，所以被它合并的旧组只能具有同一个λ。新P不参与连接，即使位于X也不能合并原组。

因此，仍然没有地面路径的合并，只能发生在相同λ内部。原P始终独立，不可能与其他原组同λ。

<a id="s04-02-h5"></a>

### 4. K_add的图判据

使用原Q组之间的支撑图，不使用V的支撑图。称一个原支撑环受保护，当它包含至少两个不同λ的组。

定义K_add：每个Q组都能沿原支撑边到达某个受保护环；G₀中的组已通地面，无需附加条件。

等价检查为：求Q支撑图的强连通分量，其凝聚图的每个汇点分量都必须包含至少两个λ。每个有限有向图节点都能到达汇点；同一强连通分量若含不同λ，就有跨这两种λ的有向环。单节点、无外部支撑的浮空组只有一个λ，会被拒绝。Q为空时条件成立。

这个条件保证D稳定。不能改为“V稳定”或“把所有可能合并组先收缩后稳定”：一次最大合并可能把某个失稳片段与有外部支撑的片段合在一起，掩盖中途失败。这里保留原支撑图，并要求其环跨越不能无接地合并的边界。

<a id="s04-02-h6"></a>

#### 不求强连通分量的等价检查

把Q中至少有一条支撑边指向不同λ的组作为种子，沿原支撑图反向传播。全部Q都被覆盖，当且仅当K_add成立。

必要性：每个受保护环含跨λ边，通向它的组也能到达这种边的起点。充分性：若反向传播覆盖全部Q，则每个汇点强连通分量中的节点都能到达一个跨λ边的起点；由于汇点没有出边，这条跨λ边也在分量内部，所以该分量至少含两个λ，满足上面的等价判据。

实现只需要标签不等比较和一次反向可达队列，不需要保存强连通分量的递归栈、访问序号或低链接值。数学证明仍使用汇点分量，程序不必把它们实际求出来。

<a id="s04-02-h7"></a>

### 5. 支撑环不会被追加破坏

D∈K_add时稳定，第一次Stack中旧D不动。写回新接触后，取一个原受保护环：

- 若环的任一部分取得了地面路径，其余部分沿原环边也能到达地面。
- 若环上没有部分接地，则第3节保证合并只能发生在同λ内。环经过至少两种λ，不能全部收缩成一个节点；删除内部边后仍有非平凡有向环。

原来通向该环的路径继续有效。新块沿严格向下的支撑链到旧组或地面，也取得支撑。因此输出稳定，原格保持原位。

还需确认下一次仍可使用同一条件。设扩展结果为D'：

1. 原接地组和不在R中的新块仍接地。因此D'的非接地旧格只能来自原Q，非接地新格只能来自R。
2. 若D'某列顶仍非接地，它若为原列顶，其上方原本就是R种子；若为新格，它在R内，其上方也已由向上传播包含。D'的新空区又是E的子集，所以重新计算的R'⊆R。
3. 旧接地组继续接地，新空区缩小，故X'在新空区内仍包含原X。新非接地N只可能位于R\X，V'中新填N也只可能在R'\X'⊆R\X。去掉D'接地组后，V'的非针粘边都是原V粘边的子集；位于原X的新非接地P可以作为额外孤立节点出现，但不连接任何原组。因此不同旧λ不会在V'中合并。
4. 仍未接地的原受保护环及到它的路径，继续跨至少两个新潜在分组；新非接地组也有通向旧非接地组的支撑路径。

于是D'仍属于K_add，归纳可继续。实际中新增加的地面路径只会加强这个证书，不会扩大危险区域。

<a id="s04-02-h8"></a>

### 6. 复杂Stack的基础块替换

对D∈K_add，任意真实Stack(D,U)保持旧D；最终新增Δ只含N/P、严格位于旧列顶以上、每块有直接下方支撑。这些必要事实沿用[通用堆叠证明](#s04-01-h2)。

按目标层号递增，逐块加入Δ。第5节保证每步仍在K_add，列顶公式保证每块准确停在目标位置。因此整条基础块链取得同一个原始输出，而无需保留U的制造历史。

同层可以合为一份单层料，至多H次Stack；结构逐块上料域仍为n²+1。完整闭包中可对K_add下料改用这些基础块，对其余下料保持全部真实上料。由制造树归纳，每个删去的复杂Stack都有有限基础链替代，故保持最终闭包；不保证同一轮出现，也不保证配方更短。

<a id="s04-02-h9"></a>

### 7. 包含K、K_top及等列顶的稳定图形

K中的非接地支撑环含P。P在V中独立，环中另一个组与它不同λ，所以该环受保护。

K_top的额外锚组是受列顶保护的纯N块。它在V中没有新增成员：外侧邻列的列顶不低于块所在层，那里不属于E；N没有竖直粘边。含这个锚组的环也跨至少两个λ。故K⊆K_top⊆K_add。

现在设D稳定，全部非空列的列顶都等于t。Q列顶产生的R种子全在t+1层，传播只向上或水平，所以R只占t以上。D的原格全在t及以下，新增N又不能向下与旧C竖直粘连，因此V中每个原Q组都有独立λ。

稳定性保证每个非接地组沿支撑边到某个至少两节点的环，这些环自然跨λ。所以：

> 任意非空、稳定、所有非空列等列顶的图形，都属于K_add。

这一结论不要求图形可制作；应用于真实制造时仍需起点的制造凭据。[宽半形H_k](01-foundations.md#s01-04)已经对n=2k≥6、H≥5提供该凭据：全部非空列顶为4，图形稳定但不属于K。因此K_add在这些参数的可制作集合内严格大于K。

特别地，六象限H可安全使用基础块/逐层追加。V本身不稳定，不能通过本判据；八象限复杂堆叠反例的下料列顶不齐，其暴露的内块仍可被新N无接地粘合，所以没有被此定理错误约化。

<a id="s04-02-h10"></a>

### 8. 对程序与时序电路的含义

计算内容是旧组/支撑图、一次地面可达传播、两圈危险高度扫描、接地邻接屏蔽X、一次分析分组，以及跨λ支撑边种子的反向传播。只需原图实际高度L内的格，规模不随制造上限H的空白部分增大，也不遍历完整4^(nH)状态表。危险高度只需O(n)；两次分组沿用现有排序实现，整项静态检查的上界为O(nL log(nL))时间、O(nL)存储。

等列顶稳定分支可以先用更便宜的列顶与稳定性检查取得证书；已有K和受保护普通块也是较便宜的充分分支。只有前面未覆盖时才需要完整K_add分析，避免把所有输入都送入较重通路。

Python的`support.in_addition_class`采用以上两圈危险高度扫描和跨标签边反向传播，K检查及等列顶稳定快路保持。[接地屏障等价性](#s04-03)证明：在环形象限上，提前阻止R横穿X不会改变旧Q组的潜在分区，故无需额外逐行屏障扫描。`stack_successors`据此选择基础块分支，未获证书时保留真实复杂上料或检查一次结算结果。未来电路复用同一分组/传播模块，以时序切换阶段；危险高度仅保存n个数，不能按阶段数复制整份核心。尚未统计建筑或生成走线。

判据失败只定位到某个非地面汇点分量的组可能无接地合并。实际桥接是否可制造、是否必然带来其他支撑仍未完全刻画，K_add不是最大安全范围。证明来自支撑路径、粘边包含和显式H_k制造族，没有运行模拟、测试、枚举或游戏。

## 04-03 环形象限上的接地屏障等价性

原文标识：`general/grounded-barriers.md`。

适用于偶数n≥2、H≥2。沿用[接地来源与潜在粘合](#s04-02)中的旧接地组G₀、其余旧组Q、列顶h、允许新格区E、接地邻接位置X和危险可达区R。

结论：在传播R时提前禁止N横穿X，虽然可能减少标记的新格，却不会改变旧Q组的潜在粘合标签。因此它与现有K_add判据完全等价，不能扩大安全追加的接受范围。Python保留较便宜的两圈高度松弛，不另加逐行屏障扫描。

<a id="s04-03-h1"></a>

### 1. 更细传播的定义

X中的位置与G₀的N/C同层相邻。在这里添加N会接地；添加P不横向粘连，仍可能只靠Q支撑。因此可以定义更细的传播R_X：

- 种子仍为Q列顶正上方的E格。
- 同列向上始终允许，包括经过X；其含义可以是连续针支撑。
- 同层相邻只允许在两端均属于E\X时通过。

构造两个分析网格：V保留旧Q并在R\X填N，V_X保留旧Q并在R_X\X填N。其旧组标签分别为λ和λ_X。由于R_X⊆R，λ_X至多把原标签细分，不会合并原来不同的标签。

真正未接地的新块仍被R_X覆盖：其向下支撑链不经过地面或G₀，也不经过X中的N；反向读取这条链时，竖直步可以经过P，水平步完全在E\X。这个观察说明细化本身安全，但还不能证明它会改善判据。

<a id="s04-03-h2"></a>

### 2. X只出现在空列区间的端点

固定一层z，令E_z={q:h(q)<z}。在象限环上，E_z由若干连续区间组成，或者占满整环。

若q∈X_z，它的一个邻列r在同层有旧G₀的N/C，所以h(r)≥z，r不属于E_z。因此X_z只能出现在E_z区间的端点，不能处于区间内部。整环都属于E_z时，X_z为空。

在一个非整环区间内填N，只有两端可能与旧格横向粘连。若区间含X端点，这一端的旧相邻格属于G₀，已从分析网格中删除；另一端至多接触一个旧Q组。因此，该区间内新增的N不能连接两个不同旧Q组。它们只能附在一个旧组上，或成为没有旧组的独立块。

N与上下旧C没有竖直粘边，所以不能绕过这个两端限制。只有旧C-C之间的竖直边保持，已包含在原Q组内。

<a id="s04-03-h3"></a>

### 3. 每个旧可达区间都至少保留一个新可达列

逐行归纳。旧R在E_z的每个区间内要么全可达，要么全不可达，因为旧传播允许沿区间全部水平边移动。

如果一个区间在本行第一次可达，则其中存在本行种子，或有来自上一行的旧可达列：

- 本行种子同时属于R_X。
- 对第二种情况，由于E在每列向上封闭，上一行所在的E区间完整包含于本行某个区间。按归纳假设，上一行的区间至少含一个R_X可达列；该列可以向上传播，包括它位于X时的针支撑。

所以，每个R可达的E_z区间中都至少有一个R_X可达列。若该区间不含X，新水平边没有被删除，R_X便覆盖整个区间。

这个论证使用可达格的保留，不把X中的P误当成被屏障删除的格；若连向上边也禁止，结论不成立。

<a id="s04-03-h4"></a>

### 4. 两种分析网格在旧组上完全相同

考察V中通过新增N连接两个不同旧Q组的任一路径。路径上的每一段新增N都在同一层的E区间内：

- 若该区间含X，第2节证明它至多接触一个旧Q组，不能作为两个旧组之间的连接段，可以从连接路径中去掉。
- 若不含X，且它在V中有N，则其区间被R到达。第3节保证整个区间也被R_X到达，所以同一连接段完整保留在V_X中。

因此，V中任意两个连通的旧Q组在V_X中也连通。结合R_X⊆R的反向包含，得到旧组上的分区完全相同：

`λ_X与λ诱导相同的旧Q组划分`。

原支撑图完全未变；跨标签边、受保护环、汇点分量和最终反向可达判据也全部相同。若把R_X版本称为K_X，则K_X=K_add，而不只是K_add⊆K_X。

<a id="s04-03-h5"></a>

### 5. 对实现与后续研究的意义

[`in_addition_class`](../synthesis/support.py)继续用每列一个危险高度，从最低种子顺、逆各扫一圈；只在填分析网格时排除X。传播只需O(n)时间与O(n)存储；连同分组和实际图高L内的分析格，整体仍为O(nL log(nL))时间、O(nL)存储。更细的逐行屏障传播需要O(nL)传播时间，却给出相同接受结果，因此不进入最终实现。

这条等价性排除了一个看似可扩域、实际只减少无关分析格的方向。要继续扩大K_add，必须引入当前分区没有表达的新约束，例如同时粘合的可实现性、强制新增地面支撑，或对整个追加序列的限制；不能只在现有X端点上阻断水平传播。

游戏实现同样可保留n个危险高度并时序复用比较/更新通路，无需为接地屏障另设逐层状态机。没有新增网表或建筑收益统计。

证据来自环形空列区间、端点邻接、逐行可达归纳及旧组分区等价；不依赖目标枚举、运行测试、模拟或游戏。

## 04-04 一次结算后进入安全范围的堆叠约化

原文标识：`general/settled-stacking.md`。

适用于偶数n≥2、制造上限H≥2的既有规则，F表示一次重新分组、重力及截高。沿用[精确堆叠摘要](#s04-06)与[安全追加范围K_add](#s04-02)。本页允许原下料D不稳定，也不把F(D)免费当作实体输入。

<a id="s04-04-h1"></a>

### 1. 扩大可以省去任意上料搜索的下料范围

定义K_pre为满足F(D)非空且F(D)∈K_add的可制作下料。K_add中的图形稳定，因此K_add⊆K_pre。对D∈K_pre及任意可制作上料U，记D₀=F(D)。精确摘要给出

`Stack(D,U) = Evaluate(D₀, P(U))`。

D₀∈K_add，所以F(D₀)=D₀，再用同一等式得到

`Stack(D,U) = Stack(D₀,U)`。

该等式只比较输出。要把右边用作真实制造，还须取得D₀：取全针基础层，结晶为纯C单层Z，再Stack(D,Z)。Z抬高后没有地面或悬空支撑环，所有C移动即碎，不贡献N/P；结果正是F(D)=D₀。准备Z为两步，触发Stack为一步。

随后由K_add定理，把Stack(D₀,U)改为最终新增N/P的逐块或逐层追加，至多H个非空层。每次的中间物品仍在K_add。故原来的任意一次Stack可改为一次真实结算触发及至多H次基础层追加；如果D本来已在K_add，直接省掉触发步骤。

本结论不要求最终新增格来自容易制造的原上料，也不需要构造原U。只用目标新增格的基础供料。它保持输出及标签，未证明配方最短。

<a id="s04-04-h2"></a>

### 2. 严格扩大：六象限不稳定输出V

[六象限V](03-general-construction.md#s03-02-h5)是已给出实体制造树的五层图形。其高处所有C和N在重新分组后成为一个没有下方支撑的组，所以V不稳定、不属于K_add。

第一次结算使全部高处C碎裂。剩余N按各水平块下落：q0、q3原地面N保持；原第三层的q1/q2、q4/q5两块落到地面；原第四层q2、q5单格落到第1层；原第五层q1/q2、q4/q5两块落到第2层。因此

`F(V) = CuCuCuCuCuCu:----Cu----Cu:--CuCu--CuCu`。

它无C，所有N块都有直接向下的支撑，层号沿支撑严格下降并终止于地面。因此F(V)∈K⊆K_add，V∈K_pre。该推广覆盖一个旧判据必须拒绝的真实下料。

原V仍保留在可制作目录中，作为Cut、Pin、Swap的输入及目标时不作替换。只在为它生成Stack后继时应用本页规则。

<a id="s04-04-h3"></a>

### 3. 闭包算法与候选数量

[`stack_successors`](../synthesis/stack_reduction.py)保持原接口，按以下顺序生成合法上料及其输出：

1. D∈K_add：保留原有连续普通块和单针域，共至多n²+1项。
2. D∉K_add，但D₀=F(D)非空、D₀∈K_add：只生成一项`(Z,D₀)`，Z为纯红晶体单层。
3. 其余下料：保留全部已知真实上料，不增加否定条件。

Z属于[完整目录的显式紧图形种子](03-general-construction.md#s03-01-h5)，也有两步基础配方。因此新增后继可靠。完备性按制造树归纳：任何被省去的Stack边都能换成本页的有限基础链；D₀进入目录后，由原K_add后继逐步产生同一输出。最终闭包保持，首次出现轮数及最短配方不保证保持。

设旧快照有M个图形，其中M_safe个在K_add，另外M_pre个一次结算后进入K_add。六象限每轮Stack后继数量的上界由

`37 M_safe + (M − M_safe) M`

变为

`37 M_safe + M_pre + (M − M_safe − M_pre) M`。

每个新增适用下料的该轮上料分支从M项变为1项；后续基础追加需要其他轮。这不是完整算法运行时间的同倍改善，也没有证明M_pre占比。

<a id="s04-04-h4"></a>

### 4. 保留的缺口与电路意义

F(D)仍不稳定或不属于K_add时，本页不给出压缩。即使反复F最终稳定，也不能多结算几次再制造：这些额外结算可能删除原Stack本来保留的晶体。一般参数的紧凑完整求解仍缺这部分上料及起点分解。

电路可复用一次物理结算和K_add判定通路：先检查原D，失败后检查D₀，只需切换工作状态。它不授权把未证明等价的复杂Stack拆开。当前已实现Python候选接口，尚未为六象限构建完整搜索网表；无建筑收益测量。

证据为上述等式、显式纯C触发配方、V的逐块人工推导及源码静态重读。没有运行目标、目录枚举、物理模拟或测试。

## 04-05 受列顶保护的普通块与更大的堆叠约化范围

原文标识：`general/protected-stack.md`。

适用于偶数象限n≥2、制造高度上限H≥2的既有局部规则。层号从0开始，h_D(q)为D第q列最高占用层，空列为−1。

[K下料约化](#s04-01)利用顶针不会参加新粘连，保证含针支撑环不会因追加普通块而消失。普通块中也存在同样不会被后续追加粘合的结构。本页据此定义更大的充分条件K_top，证明其在堆叠下封闭，并给出n≥8、H≥5时属于K_top但不属于K的可制造族。

K_top仍是堆叠约化的充分条件，不是全局可制作性判据，也没有覆盖所有非K下料。

<a id="s04-05-h1"></a>

### 1. 受列顶保护的纯普通块

在D当前最大粘连组中，取一个不含C、P的组B。它是位于同一层z、占据环上连续列集合J的纯N块。对每个与J水平相邻但不在J内的列r，要求

`h_D(r) ≥ z`。

满足该条件的B称为受列顶保护的普通块。若J为整环，外侧邻列集合为空，条件自动成立。

考虑任何保持D原格位、且只在原列顶以上加入N/P的扩展。B本身不变；其左右外侧位置(z,r)不能加入新N，因为z≤h_D(r)。原先同层相邻的N/C本就应属于B，故外侧原格只能为空或P。新P不粘连，N没有竖直粘边。因此B不会与任何其他组粘合，甚至不会获得新的成员。

扩展后各列顶只升不降，条件仍成立。以后继续从列顶上方追加，也无法改变这个事实。这里依赖“从上方追加且不移动/删除旧格”，不能推广到Cut、Pin或Crystal。

<a id="s04-05-h2"></a>

### 2. K_top的定义和静态判据

建立D的最大粘连组支撑图：G→L表示G有一格正下方紧邻另一组L；触地组另连地面。

把单P组及第1节的受保护普通块统称为锚组。定义K_top：每个组都能沿支撑边到达地面，或到达一个含锚组的有向支撑环。

支撑环至少包含两个组，不允许把同组内部的上下格当作自环。这个定义保证D稳定。全部P本来就是锚组，所以K⊆K_top。

可用如下等价条件检查，无需枚举支撑环：

1. 每个锚组都触地，或至少有一个直接下方支撑。
2. 从地面组与全部锚组开始，沿反向支撑边传播，能够到达全部组。

必要性直接来自定义。充分性：每个非锚组沿条件2的路径到地面或锚组；从非地面的锚组先沿条件1选择一条支撑边，再沿条件2到地面或下一个锚组。在有限锚组集合上继续，要么触地，要么重复一个锚组，形成含锚组的非平凡闭合路径，故所有组满足定义。不能省略条件1，否则悬空单针或悬空受保护N块会被误判。

列顶、保护条件和图传播都可由有限扫描完成；组图建立后检查为O(v+e)。本页给出数学判据，Python结构目录现已采用包含本页范围的K_add判据。

<a id="s04-05-h3"></a>

### 3. 加入落稳的基础块保持K_top

设D∈K_top。加入一个真实从上方落稳的水平N块或单P，且结果未超高。

D原本稳定，本次加工中不合并新接触，所以旧格不移动、不消失。新格严格高于D同列列顶，且触地或直接支撑在旧格上。写回结果重新分组只可能合并非针组；旧P独立，受保护普通块由第1节也保持独立。

原通向地面的支撑路径在合并后仍通向地面。原含锚环不能全部收缩为一个组，因为其中锚组与其余组始终分离；去掉内部边后仍留下经过该锚组的非平凡闭合路径。原通向这个环的组也仍有路径。

新块的下方支撑通向上述旧路径或地面；合并不会破坏这些路径。旧锚组在新图中仍是锚组。因此输出仍属于K_top，旧格保持原位。超高而整个丢弃的基础块是恒等加工，可省略。

由归纳，任意有限基础块追加序列都保持K_top。

<a id="s04-05-h4"></a>

### 4. 任意复杂上料仍可改成基础块序列

令D∈K_top，上料U任意且真实可制造，T=Stack(D,U)。D稳定，在本次加工中保持原位。上料C要么移动即碎，要么静止在高度上限外，不能进入结果。其余保留格组成Δ=T\D，并满足：

- D逐格保留，Δ只含N/P。
- Δ每格严格高于D同列列顶。
- 仅在Δ内部划分水平N块及单P；每块触地或有T中的直接下方支撑。

这些必要条件的证明与[K下料的通用堆叠化简](#s04-01-h2)相同，只用到D稳定和上料的局部物理。

充分性：把Δ的块按目标层号递增加入。每次列顶公式给出准确落点；第3节使下一个中间物品仍属于K_top，旧格不动，所以归纳不中断。得到的最终格位恰好等于T。实际Stack输出与这个逐块结果是同一个原始图形，因此它也属于K_top。

同层块可以合为一份无C单层上料，至多H次Stack。擦除普通部件和颜色后，逐块结构上料域仍只有n²+1种连续普通区间或单针。

所以完整闭包理论可以采用更强分支：D∈K_top时仅扩展这些基础块；其余D仍保留真实复杂上料。每个删去的复杂Stack都有有限基础块链替代，故保持最终可制作闭包，但不保证同一轮、同样步骤数或同样制造成本。

<a id="s04-05-h5"></a>

### 5. 严格扩展：八象限起的可制造族

令n=2k，k≥4，H≥5。定义W_k只占q0至q(k−1)：

| 零基层 | q0 | q1至q(k−1) | 其余列 |
|---|---|---|---|
| 4 | C | 全部N | 空 |
| 3 | C | 仅q2为N，其余空 | 空 |
| 2 | C | 全部N | 空 |
| 1 | 空 | 全空 | 空 |
| 0 | N | 全空 | 空 |

外组G由q0三层C脊和第2、第4层N帽组成。内组B只有(3,q2)一个N。B被G的底帽支撑，G的顶帽被B支撑；这个悬空环没有针，也不通地面，所以W_k不属于K。

B的两邻列为q1、q3，二者列顶均为4，高于B的层3。因此B受列顶保护。G与B的环含这个锚组；地面N另有地面路径，故W_k属于K_top。

<a id="s04-05-h6"></a>

#### 真实制造

沿用[宽半形的构造](01-foundations.md#s01-04-h2)，先制造A：q0为`N - C C C`，q(n−1)为`N P N N N`，其余为空。A由三根独立柱`C N C C C`、单C、`N P N N N`拼合并切掉牺牲C取得，全部步骤已在该文展开。

在互补半面q1至qk内制造B侧脚手架：

1. qk地面单N，再叠qk单N到第1层。
2. 加入q1至qk连续N块，停在第2层。
3. 加入q2单N，停在第3层。
4. 加入q1至q(k−1)连续N块，停在第4层。

将A与脚手架按这两个互补半面交换拼合，再切留q0至q(k−1)。被切掉的qk和q(n−1)仅有N/P，不引起保留C的融合删除。外组和q2内块已互相阻挡，切掉两侧脚手架后仍保留；结果恰为W_k。

构造最高五层，无顶破，故同一制造适用于所有H≥5。结晶标签可按已有独立柱方法指定，普通标签直接来自供料。

[八象限代表W_4的完整配方](../examples/8q-protected-loop.md)已展开为45个表项、3个物品槽，配置为八象限五层。目标为：

`Cu--------------:----------------:crCuCuCu--------:cr--Cu----------:crCuCuCu--------`

它与原宽半形族的区别是内块位于q2，被两侧较高列夹住。六象限原H的内块在q2，但其外侧q3为空，因此不能套用此保护证明。这里的严格扩展实例要求n≥8，不声称已经证明六象限可制作集合内也严格扩大。

<a id="s04-05-h7"></a>

### 6. 适用边界与电路复用

[接地来源与潜在粘合](#s04-02)进一步给出包含K_top的K_add，并把六象限H也纳入安全范围。这个结果区分了“非K”与“不能逐块追加”：部分非K图形仍有无法被后续加料合并的支撑环。它没有反驳原来复杂上料必须保持一次Stack的反例；那些目标没有本页给出的完整锚组路径证明。

四象限五层已经有R⊆K，扩大条件不会再缩小其既有上料域。一般参数的潜在收益是让更多下料使用基础块发生器，避免为这些分支寻找任意复杂上料。

未来电路可复用列顶扫描、组/支撑传播和基础块发生器，以计数器和握手切换阶段；保护判断只增加一种锚组来源，不要求为每个块复制整份物理核心。Python通过K_add覆盖本页判据；尚未统计新门数、建筑数或时序，也未生成蓝图。

证明依据组不合并条件、支撑环收缩与显式制造族。没有运行图形枚举、测试、模拟或游戏验证。

## 04-06 任意堆叠的输入摘要与原配方凭据

原文标识：`general/stack-summaries.md`。

本页处理偶数n≥2、H≥2的任意合法下料D、上料U，包含非K、不稳定状态，以及普通格和针交错的上料。不是把全部上料改成基础层，而是给每份上料计算可共用的精确摘要，并保留其原制造配方。

<a id="s04-06-h1"></a>

### 1. 下料摘要是一次结算结果

Stack中上下料初始分离；所有下料来源层都低于所有上料来源层。依据[一次结算的静止组与块落点公式](03-general-construction.md#s03-01-h2)，下料贡献独立于U，恰为D₀=F(D)。计算上料块落点时，只需D₀各列的保留格及列顶。

因此若F(D)=F(D')，则对任意同配置上料U，Stack(D,U)=Stack(D',U)。缓存可以用D₀作键，只保存一份原输入配方D。不能直接把D₀当作实际下料，因为F(D₀)可能不等于D₀。

<a id="s04-06-h2"></a>

### 2. 找出上料的静止组

上料抬高H+1层后不触地，也不直接接触下料。按U原格位建组、建向下的组间支撑边，使用空地面种子：反复删除没有指向剩余组的支撑边的节点。剩余F_U正是从未移动的上料组。

F_U的全部格都保持在高度上限外，最终截掉；但它们仍会阻挡其上方的其他移动块，所以不能立即删掉而忽略影响。

其余组的晶体首次移动即碎，N/P拆成水平普通块与单针。把这些移动块按来源层递增排列，同层按最小象限排序。源层相同的块列集合互不相交。

<a id="s04-06-h3"></a>

### 3. 排除无论下料如何都无法进入高度上限的块

每列记录一个障碍来源高度b(q)，初值为F_U在该列的最低格高度，无格时为H。

按移动块的来源层z递增处理。若块占据列集合J中存在q满足b(q)<z，则该块最终必在上限外：它在该列上方，不能穿过已经固定或必被截高的较早格；这些障碍最终高度至少H+1。将这个块的所有列都更新b(q)=min(b(q),z)。

这里记录的是原来源高度，而不是未知的最终高度。只有原来更高、共享列的块才必须受它阻挡；较低来源块已经先完成下落，不能被后来从上方落下的块反过来阻挡。

若所有q都有b(q)≥z，这个块没有任何上述固定障碍，保留到上料摘要中。归纳可知：被排除块在任何D下都超高；保留块的更低来源同列障碍只可能来自D₀或更早的保留块。保留块仍可能因为某个具体下料很高而超高，这部分留给求值阶段处理。

<a id="s04-06-h4"></a>

### 4. 摘要只需有序的带标签块

对保留块，所有原D₀格都低于其来源，所有较早保留块的落点也低于其来源。因此源层绝对数值不再参与落点，只需保留共享列块之间的先后关系。

两个列集合不相交的块互相不改变列顶，可以交换计算顺序。为得到固定编码，给每块取秩r=1+max(该块各列此前块的秩)，更新这些列的秩，再按(r,最小象限)排列。共享列的块仍保持原先后；同秩块互不相交。故这种重排不改变任何下料上的结果。

上料摘要P(U)就是上述块序列，每块保存列集合、普通部件/颜色或针标签。它没有晶体，也没有必被截高的格，但没有把多个独立块擅自粘成一个新物品。

给定D₀，从其列顶开始逐块取z=1+max(占据列的当前列顶)，放入该块并更新列顶。即使z≥H，也必须更新列顶，使后续同列块同样受超高块阻挡；只在返回结果时省略这些超高格。

于是得到精确分解：

`Stack(D,U) = Evaluate(F(D), P(U))`。

这不是把P(U)当成实体上料。一般块序列未必能由一个容易制造的无晶体物品承载；制造时仍使用摘要对应的原U。

<a id="s04-06-h5"></a>

### 5. 凭据缓存与安全的极小替换

相同F(D)的下料可以共用一个原下料凭据；相同P(U)的上料可以共用一个原上料凭据。任意一对键的求值只需列顶更新，不需要重新划分上下料物理组。若原目录有M项，实际需要组合的是不同下料摘要数L与不同上料摘要数B，候选数变为L·B；没有证明所有输入集都能明显减少，也不宣称完整求解已实用。

给定目标T，先筛下料摘要：D₀的每一格必须原位保留且标签相同；T的每一格晶体也必须已在D₀中，因为上料晶体要么静止在高度上限外，要么移动即碎。新增格还必须严格高于D₀的同列最高格。任一条件不满足，都可在组合上料摘要前排除该下料。

摘要可尝试以下实体替换：

- 空序列：一份全针基础层结晶成一层纯C，Stack时全碎；共两步准备。
- 只有一个块：直接取该普通连通块或单针的基础层；一步准备。
- 多个块：按[唯一无晶体载体判据](#s04-07)计算空地面落点；块数保持时可用至多2H−1步的无C上料，成本更低才替换，否则保持原凭据。不存在同摘要无C载体时，再按[含C载体约束](#s04-08)对规范序及同秩着色序生成至多四份候选，确认全部释放、取得实体凭据且成本改善才替换。

例如六象限非K半形H作上料时，悬空框架及内部普通块都属于F_U，只剩q0地面普通格进入摘要。因此它在任意下料上的Stack效果与q0单格普通基础料完全相同。当前H代表配方需要45步，这个用途只需一步供料；这是特定用途的等价，不代表H作为其他机器输入也能这样替换。

[`StackPlan`与`StackCatalog`](../synthesis/stack_plan.py)实现上述编译、求值及带原配方的查找。catalog.construct(target)只搜索已登记摘要对，成功返回这些凭据中总步数最少的真实Stack制造树；缺失返回None，不能判全局不可制作。固定代表配方用于交付具体路径，覆盖证明仍来自本页的归纳。

<a id="s04-06-h6"></a>

### 6. 按目标逐块匹配，无需生成候选结果

通过下料筛选后，记Δ=T−D₀。逐块计算落点：若落点在H以上，仅更新列顶；若仍可见，则块的每格必须属于Δ且标签相同，否则立即拒绝。处理完毕时，可见新增格数必须等于|Δ|。

这是精确判据。每块落点严格高于其所有占据列的旧列顶，故不会覆盖D₀或较早落下的格；后续步骤也不能删除已经落下的可见格。可见格不匹配不可被后续块修复。全部可见格属于Δ且数量相等，就恰好得到Δ，不需要另外保存一份完整候选图形。超高块继续影响列顶，不能因其不可见而跳过这个更新。

匹配每对摘要的最坏扫描量为上料摘要格数，至多nH；比较前的下料筛选及列顶计算可对同一D₀共用。提前停止减少实际访问，但最坏仍可能访问全部L·B对，不承诺一个普遍的加速比例。

<a id="s04-06-h7"></a>

### 7. 消费式配方成本与目录内最短选择

定义s(R)=1+Σs(子配方)，其中基础供料也计一步。制造树引用同一个Python对象两次，就需要制造两份物品，必须加两次。按树归纳，此递推恰好等于Recipe.steps展开的指令数量；Recipe.step_count在建立节点时保存该值，无需为比较成本展开整棵树。

下料和上料摘要的等价分别对任意另一侧成立，因此每个键只需保留已登记的最低成本制造凭据。同键步骤数相同时保留物品槽更少者。构造目标时按(总步数s(D)+s(U)+1, 二元加工槽需求)字典序比较；找到成本c的候选后，可跳过该二元组≥c的其余键对。槽数递推及替换单调性见[物品槽调度](#s04-19-h5)。最终只为选中的一对构造实际Stack节点。

这保证已登记摘要对及上述规范上料替换中的最短步骤数，不保证所有可制作配方中的全局最短。该成本统计供料和加工次数，不是建筑数量或游戏耗时；建筑复用、并行供料及传输时序仍须另行建模。

## 04-07 多块上料摘要的无晶体实体替换

原文标识：`general/noncrystal-carrier.md`。

适用于偶数n≥2、H≥2。沿用[精确堆叠摘要](#s04-06)：任意实际Stack(D,U)等于Evaluate(F(D),P(U))。这里给出任意块数摘要的无晶体载体判据，不要求D属于K、K_add或稳定。

<a id="s04-07-h1"></a>

### 1. 空地面落点给出唯一候选

取真实上料U的摘要P，将其有序N/P块从空列顶−1开始逐块放下。每块落点为其占用列当前最高列顶加1；记所得图形为S。空地面只是计算参数，不是一份可以交给游戏机器的实体下料。

所有摘要格都会保留在S内。按原来源层归纳，每块更早的同列块都来自更低层，空地面落点不超过该块原来源层；因此最高落点小于H。摘要的规范重排只交换互不共列的块，不改变这些落点。不存在截高丢失。

每个落下的块都触地，或至少有一个格被更早落下的格直接托住。这些支撑沿层号严格下降。新接触可能合并水平普通块，但不会删除支撑，故S是稳定无晶体图形，始终具有统一逐层制造配方。

若U'是一份可制造、无晶体且P(U')=P的实体，由无晶体稳定性定理及其空地面块结算可得

`U' = Evaluate(空列顶, P(U')) = S`。

因此，同摘要的无晶体实体若存在，必定就是S；不需要枚举其他高度排列。这个唯一性针对相同摘要，不宣称不同摘要不可能在某些下料上碰巧产生相同结果。

<a id="s04-07-h2"></a>

### 2. 块数保持是充要判据

设P含b个块。S的重新分组不会拆开原普通块，也不会合并针，只可能把原来分开的普通块横向粘成一块。因此：

`存在可制造无晶体U'且P(U')=P ⇔ S的物理块数=b`。

充分性：块数相等意味着每个原块保持。各列原块的先后次序在落下时保持；摘要按共享列次序规范化，因此P(S)=P。取Builder.noncrystal(S)即得真实凭据。

必要性：唯一候选只能是S。若S中出现新合并，其摘要块数小于b，故P(S)≠P，不可能有另一份同摘要无晶体物品。

对于满足判据的摘要，任何下料D都满足

`Stack(D,U) = Evaluate(F(D),P) = Stack(D,S)`。

替换发生在上料准备侧，不额外结算D，也不把一次Stack拆成对D的多次加工。原上料中被排除的静止组和必超高格已由摘要编译处理，不会在此重新加入。

<a id="s04-07-h3"></a>

### 3. 实现与成本

[StackPlan.noncrystal_carrier](../synthesis/stack_plan.py)只计算空地面落点、重新分组并比较块数。空摘要没有非空无晶体载体，仍使用两步准备的纯晶体触发料；单块摘要仍直接使用基础层。

StackCatalog.add对每个首次出现的多块摘要尝试这个唯一载体，用既有Builder.noncrystal取得配方。只有(步骤数,物品槽数)字典序更小时才替换原凭据；同摘要后续登记只比较新旧凭据，不重复生成相同载体。下料摘要仍保存原物品的制造树，不能把上料用途的替换传播到下料、Cut或Pin用途。

若S有h层，统一逐层准备成本为2h−1，至多2H−1步、至多两个物品槽。这个数包括基础供料，不包含最后一次Stack。它不是所有制造方式的最短成本；目录仍按已有凭据和本次规范载体取优。

空地面求值扫描摘要格数，重新分组沿用现有排序实现，时间上界O(nH log(nH))、空间O(nH)。这是每个新摘要的预处理，不是每对下料/上料重新计算。六象限及一般参数的完整摘要目录仍可能巨大，本页没有解决其穷尽规模。

<a id="s04-07-h4"></a>

### 4. 六象限五层代表

原上料的q0为C-C-C-N，q3为N-P-N，其余列为空。两列可以独立制造；抬高后辅助C全碎，摘要保留四个N/P块。

唯一无晶体载体为q0地面N、q3的N-P-N：

`Cu----Cu----:------P-----:------Cu----`。

两列不相邻，下落不会发生新的N块粘合。该上料统一用五步准备：取q0/q3双N基础层，再分别供给q3单P、q3单N并逐次Stack。若下料为q0单N，一次Stack后的目标为

`Cu----Cu----:Cu----P-----:------Cu----`。

从基础料开始总共七步、两个物品槽即可取得这个代表目标。完整消费式步骤与包见[多块上料替换代表](../examples/6q-multiblock-summary.md)。它用于观察辅助晶体如何从上料准备流程中消失；任意下料上的等价性由上述证明保证。

<a id="s04-07-h5"></a>

### 5. 边界

块合并时不能直接改用S，也不能把此判据失败当成目标不可制造。目录会继续尝试[按摘要构造含C载体](#s04-08)，失败或没有成本改善时保留原上料；不同摘要或限定下料的替换仍可继续研究。本项不扩大否定范围，不改变游戏协议和现有电路。证据来自块不分裂、同列保序、唯一候选及实际配方构造；不依赖测试、目标枚举或游戏验证。

## 04-08 从上料摘要构造含晶体的紧凑载体

原文标识：`general/crystal-carrier.md`。

本页适用于偶数n≥2、H≥2。输入为[上料摘要](#s04-06)P中的水平普通块和单针，目标是制造一个对任意下料都与原上料等效的实体U。它是受限载体族的构造法，不是完整可制造性判据，也不保证全局最短配方。

<a id="s04-08-h1"></a>

### 1. 保留块及各列先后即可

摘要已经删除必超高块，并规范化互不占同列的块的顺序。为每块i引入来源高度hᵢ，范围0≤hᵢ<H。同一块的全部格共用高度，各列中相继出现的块i、j满足hⱼ≥hᵢ+1。

为避免原本独立的普通块横向粘合，对每对环形相邻列，按摘要顺序收集在任一列出现的普通块，去掉同块的重复出现；相继两块也满足hⱼ≥hᵢ+1。针不参与这条约束。这样，同块的水平连接保持，异块在相邻列不可能同高，因此重新分组恰好得到原来的普通块与单针。

相邻列约束可以强于必要条件：两个不占同列的块原本允许交换，每次约束求解固定一种块顺序。目录先用规范序，再用[同秩三着色序](#s04-09)，后者只重排互不共列的块；两者失败仍不能排除其他排序可行。

<a id="s04-08-h2"></a>

### 2. 两种可制造的列形

把每列从地面到最高N/P之间的空格补成同色晶体C。尝试两种约束族：

- 普通后缀：从每列第一根针开始，后续N/P格逐个相邻，不允许再插C。相继块i、j除下界外增加hᵢ≥hⱼ−1，合起来要求hⱼ=hᵢ+1。
- 触地针前缀：每列最初连续的k根针固定在0至k−1层；从第一格普通料之后遇到的第一根针开始，才要求后续N/P连续。前缀和后缀之间允许C间隙。

两者都属于[满足Q的独立柱已证制造范围](#s04-20-h1)。第一族以结晶核心和连续N/P后缀制造；第二族再用触地针前缀包住核心。全针列在第一族也可取地面连续针，无需晶体。

所有约束均为差分下界，另有逐变量上限。由全零向量开始反复松弛hⱼ=max(hⱼ,hᵢ+d)，取得该约束族的逐分量最小解；超过上限或存在正环则拒绝。初始针的上限依次为0、1、…，结合各列严格递增及非负下界，恰好把它们固定在地面。块数为b时，至多b轮即可判定。

高度最小不等于制造步骤最少，也不保证晶体能全部释放。两族给出相同高度向量时，只制造一次。

<a id="s04-08-h3"></a>

### 3. 释放条件与摘要等价证明

对补C实体使用空地面种子求静止组。若存在任何静止格，拒绝该候选；若为空，则所有组都移动，C全部碎裂，所有N/P块参与下降，没有必须剔除的固定高处障碍。

约束保证这些N/P块与P逐块相同，且每列的块先后相同。重新按共享列的前驱秩规范化，所得序列因此仍是P。由堆叠摘要定理，对任意同配置合法下料D，都有：

`Stack(D,U) = Evaluate(F(D),P) = Stack(D,原上料)`。

该等价不要求D属于K或安全追加类，也不要求D稳定。它只适用于Stack上料用途。

通过释放条件后，用独立柱构造器取得真实制造凭据。目录仅在首次登记该摘要且不存在同摘要无C载体时，对至多两种保序排列分别尝试两族，总计至多四份候选；按步数、物品槽数与原配方比较，成本改善才替换。任一族失败均保留原凭据，不得据此返回目标不可解。

<a id="s04-08-h4"></a>

### 4. 复杂度与时序实现

直接遍历摘要中的格即可建立列内序列及相邻列普通块约束；每格至多触及两条相邻列边。格数m≤nH，变量数b≤m，约束和工作存储为O(n+m)，两族求解共O(bm+n)，最坏O(n²H²+n)。求解后另外支付O(nH)的补C实体展开、静止组判定及独立柱制造成本，不把这些费用算作零。

这避免建立“n列×b块”的稀疏图形再逐格扫描。游戏中可依次读取边，以一套加法、比较和写回电路完成松弛；重复轮次至无更新或达到b轮。两族顺次复用同一存储与运算器。这里只确定算法和可复用状态，不给出尚未编译的建筑数量。

<a id="s04-08-h5"></a>

### 5. 固定代表

六象限五层原上料为q0单N、q1的CCCN、q3的NPN。自由落地会把q0、q1普通格粘为一块，所以不存在同摘要无晶体载体。

相邻列约束只要求q1普通格比q0高一层；q3的NPN保持连续。最小解把q1的CCCN缩成CN，其余不变，辅助C仍能全部释放。将它堆到q1三层普通柱上，可得到与原上料完全相同的目标：

`CuCu--Cu----:--Cu--P-----:--Cu--Cu----:--Cu--------`

配合矩形核心与不等高后缀并行制造，当前完整配方为19步、19条指令包、3个物品槽；同一目标的原补C交错配方为26步，少7步。制造已经统一逐层追加，省步不是保留专用电路的理由。这些是制造次数，不是建筑数。具体准备步骤和机器指令见[6q-crystal-summary](../examples/6q-crystal-summary.md)。覆盖任意下料的理由来自上述摘要等价证明，固定导出只交付一个可在游戏中复现的制造路径。

## 04-09 同秩普通块的三着色重排

原文标识：`general/carrier-ordering.md`。

本页接续[含晶体载体](#s04-08)。规范摘要中的象限排序只用于取得唯一编码；制造载体时，不必让这些独立块按同样顺序逐个升高。适用于已有参数化规则的偶数n≥2、H≥2。

<a id="s04-09-h1"></a>

### 1. 同秩块可以任意重排

每块的秩为1加所占列此前块秩的最大值。共享列的先后块秩严格递增，所以同秩块的列集合互不相交。对同秩块任意重排，各列先后不变；规范化后仍得到同一摘要，对任意下料的Stack效果也相同。

<a id="s04-09-h2"></a>

### 2. 三种颜色足够

固定一个秩，只考虑其中的普通块。每块是环上连续区间；同秩块互不重叠，所以每块最多在区间两端接触两个其他普通块。针不参与普通连接。

依次处理普通块，选择0、1、2中尚未被已处理邻块使用的最小颜色。最多禁用两色，必定可以选出颜色。后处理块避开已处理邻块，故最后所有相邻普通块颜色不同。全圈单块无其他邻块；两象限的重复邻接只算同一个邻块，不影响结论。

然后按“秩、颜色、原次序”排列；针使用颜色0，仅参与次序，不参与邻色限制。这只改变同秩块顺序，因此保持摘要。把新序列送入原差分约束构造器即可：相邻普通块按颜色顺序错层，同列仍按原顺序递增。

这不是最优着色或全排列搜索。保留原规范序，再尝试一个着色序；相同序列不重复生成。每个序列至多尝试两种列形，总计至多四份载体。每份仍要满足高度上限、全体释放和实体制造条件；成本更低才替换。

<a id="s04-09-h3"></a>

### 3. 满圈独立单格不再需要n层

考虑摘要恰好是在每列各落下一格普通料，全部为互相独立的块。原规范序为q0、q1、…、q(n−1)。相邻普通块严格保序会强制h₀<h₁<…<hₙ₋₁，需要至少n层。这是排序引入的限制，不是制造需要。

偶数环的贪心颜色为0、1交错。新序将偶数列置于奇数列之前，最小来源高度变成偶数列0、奇数列1；只需两层：

- 底层：偶数列保留指定普通格，奇数列填辅助C。
- 顶层：奇数列保留指定普通格，偶数列为空。

底层非针格连成一个触地组。抬高后该组没有任何下方支撑，会移动并碎掉C；顶层各普通格也分别下落。因此没有悬空静止组，摘要正是全部独立单格。

此载体有与n无关的四步制造：供给“偶数列普通格、奇数列针”的基础层，结晶，把奇数列普通基础层Stack到其上。两份基础供料加两次加工共四步，最多两个物品槽。普通标签可逐列不同。该结论不把这四步当作一般摘要的制造上界。

<a id="s04-09-h4"></a>

### 4. 实现成本与范围

StackPlan.carrier_orders在摘要上计算秩，按(秩,列)保存已着色的普通格。每格查左右两个邻位，三种颜色固定比较；按秩分桶，再顺序读三个颜色桶，无需比较排序。m个摘要格、b个块使用O(n+m)时间与空间，秩桶数不超过b。

游戏实现可复用列秩存储、邻位读取和三色选择器；边构造与差分松弛沿用同一运算通路。增加的是一个候选序，不按块数复制求解电路。尚未为该算法编译建筑数或走线。

六象限五层的[固定代表](../examples/6q-colored-summary.md)将五层阶梯上料替换为两层交错上料；原规范序自身需要六层，不能通过五层上限。重排扩大了这项局部构造的覆盖，仍未给出全部摘要的完整紧凑制造法。

## 04-10 不新增针的单次堆叠：任意下料的直接构造

原文标识：`general/ordinary-stack.md`。

参数为偶数n≥2、H≥2，采用既有一次分组、下落途中只拆组不合组的物理。D是任意可制造下料，可以非K或不稳定。本文不把一次Stack拆成多次Stack。

令F(D)为D按原分组执行一次重力后的格位结果，记为D₀。F仅用于计算条件，不在制造路径中增加一道加工。目标T与D₀相比只新增普通格时，存在一次合法Stack(D,U)=T，当且仅当：

1. T逐格保留D₀及其标签。
2. Δ=T\D₀只含普通格，不含新晶体或新针。
3. Δ每个格严格高于D₀的同列列顶。
4. Δ内部每个水平普通连通块，位于地面或至少有一格正下方在T中非空。

D₀允许为空。与K下料的逐块约化不同，这里的下料在加工前可能下落；实际制造仍使用D，而不是把D₀当成新输入再次分组。

<a id="s04-10-h1"></a>

### 1. 下料的结算独立于上料

上料初始整体位于H+1及以上的零基层号，下料在0到H−1。两者初始不粘连。下料的地面关系、组间直接支撑都不依赖上料。

依据[静止组与水平落点公式](03-general-construction.md#s03-01-h2)，固定上料格位都在高度上限外，不能成为下料正下方的阻挡；所有移动下料块的来源层都低于所有移动上料块，先完成落点计算。上料不能穿过下料后反过来从下面阻止其原本应有的下落。因此Stack中的下料贡献恰为D₀，与U无关。

这不表示可以把Stack(D,U)替换成Stack(D₀,U)：后者会对D₀重新分组，可能多碎一次晶体。本定理只在同一次加工中使用D₀作计算依据。

<a id="s04-10-h2"></a>

### 2. 四项条件的必要性

D₀中的格位全部保留。上料固定晶体在上限外被截掉，移动晶体首次下落即消失，所以不会新增晶体。

每个保留的上料普通块都是从D₀上方落下，不能穿过同列保留格，因此新增位置严格高于原列顶。每块最终停在地面或直接下方保留格上；支撑格高度更低，不会在截高时消失。将同层相邻的上料普通块合并为Δ的最大块仍保留至少一个直接支撑。

第2项是不新增针这一子问题的范围条件。任意上料若最终没有针保留，也落入本定理，无须限制其原始输入是否含针。

<a id="s04-10-h3"></a>

### 3. 直接制造一份紧密N/C上料

取h=max(1, Δ最高人类层号)，构造高度h的完整矩形U*：

- 每个属于Δ的位置放相同标签的普通格。
- 其余位置全部放合法颜色晶体，例如红晶体cr。

U*没有针和空格，属于已有的紧密N/C种子，能逐列制造并拼接。h≤H，整个种子制造不需要突破高度上限。Δ为空时，取一层全晶体即可。

将U*作为上料。初始每层全部是N/C，因此该层是一个水平粘连组；相邻两层只有存在竖直C边才合组。所以每个最大组覆盖连续若干整层，组间支撑只能沿层区间向下，不能形成悬空支撑环。最下组不触地，也不直接接触下料，所有上料组最终都会开始移动，其全部晶体均消失。

去掉晶体后，上料只剩Δ的水平普通块；它们的来源层顺序恰按目标层排列，并整体位于全部下料来源之上。按目标层递增处理：第3项使所有原下料格低于目标块；先处理的新增块也位于更低目标层；第4项给出目标层正下方的支撑。落点公式使每块恰停在目标位置。

本次加工不会因新增普通块接触D中的旧组而重新合组，所以无需K闭包，也无需中间前缀在重新分组后稳定。最终结果恰为T，完成充分性证明。

所有上料块的来源层都高于全部下料来源，落点只依赖上料块之间的层次顺序。因此可先将Δ整体向下平移，使其最低非空层为地面，再按上述办法填C；制造上料的高度降到Δ的层跨度。若平移后的纯普通图形已能逐层制造，直接用它作上料，无需填C。两者都保留各水平块及其来源先后，落点证明相同。单个新增层可以直接使用普通基础料。

<a id="s04-10-h4"></a>

### 4. 对搜索的影响与限制

给定D和T，当新增部分没有针时，无需遍历任何上料目录：计算D₀、检查四项条件、直接制造U*即可。来源D本身仍须有制造证书；该定理没有解决如何找到全部D。

在正向有限目录中，非K下料的任意无针上料可以只保留紧密N/C种子，因为其输出不会新增针，必有上述替代上料。更强地，即使原上料含针，只要其针均未进入结果也可替代。仍有新针保留时，不能直接把缺格填成C：这些C可能围绕上料针形成悬空支撑环，使本来需要落下的格留在上限外。因此这部分继续保留一般Stack规则。

四象限全K时已有更便宜的逐层追加，优先使用原方案。此定理主要处理六象限和一般参数中的非K/不稳定下料，减少其中一个任意输入树的搜索。紧密种子的配方可能比原上料长；消除搜索依赖不等于每份配方都更短，也没有得到完整实用六象限算法。

[八象限八层复杂堆叠反例](01-foundations.md#s01-03-h7)不被推翻：它要求保留一次Stack，而本文恰好保留这一点，只替换上料的制造方式。

[`ordinary_stack`](../synthesis/stack_reduction.py)提供Python构造：输入Builder、真实下料配方和目标；子问题条件不满足时返回None，不作全局不可制作判断。成功时返回真实的一次Stack制造树。实现优先采用[紧凑无晶体上料](#s04-11)，否则使用更省辅助料的[列前缀构造](#s04-14)；single_stack也覆盖针尾域及部分交错N/P目标。上文完整矩形仍作为充分性证明。物理与构造接口已支持偶数n≥2、H≥2，见[参数化模型](#s04-20)；没有运行完整目标搜索、测试或游戏验证。

## 04-11 交错普通格与针的单次堆叠载体

原文标识：`general/interleaved-stack.md`。

适用于偶数n≥2、H≥2的既有局部规则。给定真实下料配方D及目标T，记D₀=F(D)、Δ=T−D₀。实际仍只对原D执行一次Stack。下文沿用[单次普通追加](#s04-10)和[针尾构造](#s04-14)的必要条件：

- T原位保留D₀的全部格与标签；Δ只含普通格N与针P。
- 每个新增格严格高于D₀同列最高格。
- Δ的每个水平普通连通块或单针，都触地或在T中有紧邻下方的支撑格。

这些条件不保证一般上料可制造。本页提供两个确定性候选：无晶体候选用块数守恒判据，补C候选检查抬高后的静止集合；两者均取得真实制造凭据，不遍历任意上料。物理等价沿用[精确堆叠摘要](#s04-06)。两者失败后，Python继续尝试[列内压紧](#s04-12)和[保留针下间隙](#s04-13)两个约束载体。

<a id="s04-11-h1"></a>

### 1. 无晶体自由下落候选

令A=F(Δ)，把新增格单独放在空地面上结算一次。Δ不含晶体，原物理组均为单层普通块或单针，支撑边严格向下，不可能出现悬空支撑环。每个移动块最终触地或直接落在更早保留的格上，原固定块的向下支撑也保持。因此A的每个块都有直接下方支撑或触地。

下落后的新接触可能合并同层普通块，但合并不会移除已有的直接支撑。A仍是稳定无晶体形，可由Builder.noncrystal制造；若A共h层，基础逐层方案为h次供料和h−1次堆叠，共2h−1步。当前统一使用这套[逐层构造](#s04-15)，不另设纯针段快捷路径。整个准备只发生在上料侧，不对D追加任何加工。

A可能改变作为上料时的行为。例：下料q1有三层普通柱，目标新增q0地面N与q1第四层N。两新增单格独立下落后会在地面相邻并粘成一个块；该块放到真实下料上，两格一起落到第四层，不能得到目标。

在本页必要条件已通过时，有如下精确判据：

`Stack(D, F(Δ)) = T ⇔ F(Δ)的物理块数 = Δ的物理块数`。

这里每个水平普通连通块和每根针各算一块。无C下落不丢格，也不拆开原普通块；只可能在结果重新分组时合并原普通块。因此块数相等，恰好表示没有发生新的块合并。

充分性：无合并时，A保持Δ的全部原块。同列格在下落中不能穿过彼此，所以共享列的块先后顺序保持；不同列的块可交换处理次序。A抬高后全体移动，逐块用目标的直接支撑及同列次序归纳，落点恰好回到Δ原位置。

必要性：若发生合并，至少一对相邻普通格来自Δ不同层；若原层相同，它们在Δ中就已属于同一块。假设Stack仍能得到T，因为目标新增格总数等于A格数，不能有任何上料格被截高。每列格数及从下到上的次序均保持，故该列第k个上料格只能对应Δ该列第k格。上述新合并的一对格因此必须分别回到不同目标层；但它们现在属于同一个刚性普通块，只能停在同一层，矛盾。

实现只需重算A的分组数并与已取得的Δ分组数比较，不必再编译和求值A的堆叠摘要。若原先直接平移Δ得到的无晶体上料可制造，它本来就稳定，F(Δ)等于该平移形，也不发生新合并，故新判据保留旧直接分支的成功范围。

此候选可消去内部空层及列间不必要的高度差；也允许N/P任意交错。没有证明它覆盖所有交错目标。

<a id="s04-11-h2"></a>

### 2. 补晶体的连续列候选

若第一个候选不匹配，沿用Δ整体下移至最低新增层为零的格位。在每个非空列内，把地面至该列最高新增格之间的空隙补为辅助晶体C；原N/P标签保持，空列及列顶以上不填。

旧针尾构造只允许每列N在下、P在上，利用非针掩码的支撑森林保证上料全部释放。现在不再提前拒绝P上方的N，而是对同一个补C候选B执行两个独立判断：

1. B在空地面种子下的最大静止集合必须为空。
2. Builder.independent_columns(B)必须取得制造凭据。

第一项恰好等价于上料摘要P(B)保留全部|Δ|个N/P格。若空地面静止集合非空，每个剩余组至少依赖另一个剩余组，有限图中必含支撑环。这个集合不能只含C：任一两个纯C组的直接竖直支撑接触，本应把它们粘成同一组，不可能成为组间边。因此非空集合必含至少一个N/P格，抬高后该格静止在高度上限外，不能成为目标。反之，静止集合为空时，全部C移动即碎，所有N/P释放，也没有固定高处障碍使它们必然超高。

因为B的全部N/P恰好对应Δ，且相对来源层未改变，全体释放后其块划分、标签及共享列次序与Δ一致。按目标高度递增归纳，必要条件保证每块恰在目标层受到直接支撑，全部落回Δ且不被截高。若某个N/P静止丢失，新增格数不足，不能由C补回。故静止集合为空又恰好等价于Evaluate(D₀,P(B))=T。

实现直接调用Rules.stationary(filled, grounded=False)，省去摘要的必超高传播、移动块排序、规范秩和候选求值。这个简化只适用于本页载体及必要条件；一般上料允许丢弃多余格，不能套用。

第二项沿用已有独立列构造：每列连续触地；若含C，首个非针格之前允许针前缀，之后直到最高C不能夹针；最高C上方允许任意N/P后缀。每列可独立保留，逐次半面拼接不会切断已有列。条件不满足时返回None，不把理论图形直接当成原料。

第一项处理支撑环、上料晶体碎裂和高处障碍。即使每列可独立制造，也不能省略它：例如一列NPN旁放一根覆盖同高度的晶体脊，晶体脊横向粘住上下两个N，会产生“普通晶体组→中间针→普通晶体组”的悬空支撑环。把这份上料抬高后，相关格不下落，不能产生要求的新增格。

两个判断均成功时，B的制造凭据与全体释放证明共同保证这一次Stack得到T。原针尾域仍由旧支撑森林定理保证成功；不新增针的普通追加域也保持。超出本页候选的目标交给后续两个约束载体；全部失败才返回None，仍不能判定全局不可制作。

<a id="s04-11-h3"></a>

### 3. 实现与代表路径

[single_stack](../synthesis/stack_reduction.py)复用既有物理及列制造器。无C分支比较块数，补C分支排除空地面静止格，通过后才展开上料配方；最后仅对选中上料生成实际Stack节点并核对目标。没有新增搜索维度、依赖或游戏电路。

- [六象限紧凑交错上料](../examples/6q-compact-interleaved.md)：非K半形H旁已有q5两层普通柱；追加q3地面普通格，以及q5上方的NPN。原目标新增格含内部空层，独立下落后得到三层无C上料，按通用逐层流程五步准备。
- [六象限补C交错上料](../examples/6q-crystal-interleaved.md)：下料为q1三层普通柱；追加q0地面N、q1第四层N及q3的NPN。自由下落候选因q0/q1普通格粘合被排除；补C候选由q0单格N、q1的CCCN和q3的NPN三列组成。q3与晶体列不接触，支撑图无环，最终辅助C全碎。

两份路径都包含完整消费式步骤及中间图形码，供游戏手工复现。步数包含基础供料；不等于建筑数量，也不宣称全局最短。覆盖及等价结论依据上述证明，不依据有限例子的数量。

## 04-12 列内压紧与差分约束的单次上料

原文标识：`general/packed-column-stack.md`。

适用于偶数n≥2、H≥2。沿用[交错上料](#s04-11)的输入合同：原下料D有制造凭据，D₀=F(D)，目标保留D₀；新增Δ仅含N/P，严格高于旧列顶，每个新增水平N块或单P有目标中的直接下方支撑。实际只对原D做一次Stack。

旧的无C候选可能把不同高度的普通块粘合；按目标空隙补C又可能产生不可独立制造的N-P-C列。本页先压掉每列内部空隙，再用列底C前缀调整横向对齐。高度选择由差分约束求出，不枚举上料图形。

<a id="s04-12-h1"></a>

### 1. 载体族与需要保留的关系

把Δ第q列从下到上的标签记为w_q，长度m_q；原格(z,q)在这列中的零基序号为i(z,q)。选择整数s_q≥0，把w_q连续放在来源层s_q至s_q+m_q−1，并在0至s_q−1填红C。空列始终为空。要求s_q+m_q≤H。

每根非空柱都是`C…C + 任意N/P序列`，所以满足独立柱制造条件：全部C在所有针下方，最高C以上可以任意交错N/P。先独立造柱，再按半面拼接，可以取得真实实体凭据。

需要避免把原普通块拆开或把不同普通块合并。对每对环上相邻列q、r，按目标高度扫描这两列的全部N格：

- 同一目标层有两个N时，要求来源高度相等。它们原本属于同一个水平N块。
- 两个相邻的非空N行之间，要求后一行的来源高度严格大于前一行。

每行任选一个N作代表；同层两格的等式保证代表选择不影响约束。连续行的严格不等式通过传递性保留两列全部N行的先后顺序，不必为每一对N建边。P不横向粘连，不参与此扫描。

这些约束保证来源网格的N水平块与Δ逐格对应：原相邻N仍同层；原相邻列中不同目标行的N不会意外同层。同列全部N/P的先后顺序由连续w_q保留。不同列、互不相关的块允许改变全局先后次序。

<a id="s04-12-h2"></a>

### 2. 差分约束与最小高度

每格来源高度为s_q+i(z,q)。两个代表(q,i)、(r,j)的等式写为

` s_r ≥ s_q+i−j `及` s_q ≥ s_r+j−i `。

前一行代表(q,i)、后一行代表(r,j)的严格不等式写为

` s_r ≥ s_q+i−j+1 `。

所有约束都具有s_v≥s_u+d的形式。初始化所有s为0，逐边把s_v提高到max(s_v,s_u+d)，最多扫描n轮：

1. 一轮无变化时，当前s满足全部约束。
2. 任何s_q+m_q>H时，这个载体族在当前约束下没有高度合格的解。
3. 第n轮仍变化时存在正权环，约束无解。

证明：把每个s_q≥0看作从共同源点到q的零权边。没有正环时，最强下界由至多n−1条列间边的简单路径取得；逐轮松弛至少覆盖相应长度的路径。初始化和每次更新都不超过任意可行解，因此终止结果是逐分量最小解。它同时最小化辅助C总数Σs_q及载体最大高度max(s_q+m_q)。这一最小性仅在本页固定列内压紧、保留相邻N行次序的族内成立，不是全部上料的最优性。

每对相邻列最多H个N行，边数O(nH)，最多n轮松弛，所以约束部分时间O(n²H)、存储O(nH)。不需要检查4^(nH)种格位，也不需要遍历各列起点的笛卡尔积。

<a id="s04-12-h3"></a>

### 3. 仍须检查全体释放

设最小解构成的实体载体为B。仍要求`stationary(B, grounded=False)`为空：抬高后的所有组都能移动，C首次下落时碎裂，全部N/P释放。列底C会横向粘住其他列的N，可能形成含针支撑环，因此不能由“独立柱可制造”直接推出全体释放。

本实现只检查最小解。若它的静止集合非空，就返回未覆盖；没有证明其他满足约束的更高解也必失败。线性约束的可行性判定与释放判据应明确区分。

全体释放时，C删除后留下的N块和单P恰好是Δ中的块，标签及同列先后顺序都保持。按这些共享列依赖的拓扑顺序归纳：每个块只受旧D₀列顶及已处理的共享列块阻挡；目标中它有直接下方支撑，又不与更低块重叠，所以列顶公式给出的落点恰好是原目标层。互不共享列的块交换处理顺序不影响结果。全部目标层小于H，故没有N/P被截高。

于是`Stack(D,B)=T`。下料只结算一次，证明不要求D或D₀属于K，也不在最终图形后追加稳定化。

<a id="s04-12-h4"></a>

### 4. 六象限五层中严格扩大的成功域

以下用N表示Cu、C表示cr，表中层号从0开始。原下料为q1的四层普通柱及q4的三层普通柱，二者都触地。

| 层 | 目标新增Δ，q0…q5 | 压紧上料B，q0…q5 |
|---:|---|---|
| 4 | `-N----` | 空 |
| 3 | `---NN-` | 空 |
| 2 | 空 | `---NN-` |
| 1 | `---P--` | `-N-PC-` |
| 0 | `N--N--` | `NC-NC-` |

无C自由下落会把q0地面N与q1高处N粘成同一块，不能回到两个不同目标层。原格位补C则在q3得到N-P-C-N，违反独立列的针前缀条件，旧两个候选都失败。

新约束给出s₀=0、s₁=1、s₃=0、s₄=2。q3的NPN压成三层；q4列为CCN，与q3最后的N同层。q0/q1的N保持不同来源高度。辅助C所在组没有封闭支撑环，全部上料释放：q0落地，q1的N停在第4层；q3的N、P依次落地和第1层；最后q3/q4双N被q4旧柱托在第3层，q3第2层保持空隙。

这是固定下料的一次Stack子问题的严格扩域，不声称整个目标以前不可制造。该目标无C，本来就可以从零逐层制作；本页保存已有下料并只再加工一次。[完整代表配方](../examples/6q-packed-columns.md)已导出34个表项、3个物品槽，包含下料与三层上料的制造。

<a id="s04-12-h5"></a>

### 5. 实现与时序复用

`stack_reduction.single_stack`保留原两个候选的优先级，失败后才调用列压紧载体。先建立序号、约束和最小高度，再检查释放，最后调用既有独立柱制造器。成功返回真实Stack配方；此候选失败后继续尝试[保留针下间隙](#s04-13)，全部候选失败才返回None，不判全局不可制作。

约束松弛只需复用一套“读两个起点、加常数、比较、写回”通路，扫描边并记录本轮是否变化；n个起点、列长度和约束是存储需求。分组与释放检查也复用已有物理模块。扫描轮数决定时序，不意味着复制n套计算核心。尚未把这些寄存器、存储与控制器折算为原生建筑或生成走线。

证据为列序保持、差分约束路径界、全体释放及目标落点归纳；不是枚举得到的结论。固定代表另附Python导出的逐步制造产品，不能替代一般证明或游戏验证。

## 04-13 保留针下间隙的上料层高约束

原文标识：`general/layer-constraint-stack.md`。

这是[列内压紧载体](#s04-12)之后的第四候选，采用相同的原下料D、一次结算D₀及新增Δ合同。前三候选成功时保持原配方；第四候选只扩大未覆盖范围。适用于偶数n≥2、H≥2。

<a id="s04-13-h1"></a>

### 1. 不必把第一根针以下也压成连续N/P

列内压紧为每列的全部N/P要求相邻来源高度相差1。当两个水平N块同时经过两列，而两列之间的针数量不同，就可能产生不相容的等式。例如一列为NPN，另一列为NN，共享底部和顶部N块：前者要求两个N相差2，后者要求相差1。

独立柱制造只要求最高辅助C以下不能夹着非触地前缀的针。一个足够宽、无需选分支的载体族是：**每列的全部C都在该列第一根目标针以下；第一根针起的N/P后缀连续。** 没有针的列可以在任意两个N之间补C。它包含上轮的“C前缀＋连续N/P”族。

因此，为每个Δ水平N块及单P设置一个来源层变量x_b，而不是每列只设一个起点。原块内所有格共享x_b，保持刚性与普通标签。

<a id="s04-13-h2"></a>

### 2. 线性数量的差分约束

加入以下约束：

1. 每块`0≤x_b<H`。
2. 同一列从下到上相邻的两个目标格属于块a、b时，`x_b≥x_a+1`，保留该列顺序。
3. 从该列第一根P起，相邻目标格必须连续，所以另加`x_a≥x_b−1`。第一根P之前的间隙允许填C。
4. 对每对相邻列，按目标高度扫描N行；前后相邻的两个非空N行属于块a、b时，`x_b≥x_a+1`。同目标行的相邻N本来就是同一个块，不再需要等式边。

第4项保留相邻列的N行顺序，保证不同目标N块不会在来源中意外粘合。不同列且没有邻接约束的块仍可以调整处理先后。同列中间即使有P，所有原标签和顺序也保持。

块数M≤nH，每个列格和相邻列扫描只产生常数条边，边数O(nH)。从全0开始进行最多M轮下界松弛；超高或正环拒绝，否则取得逐块最小解。证明与列起点的差分约束相同。时间上界O(MnH)≤O(n²H²)，存储O(nH)。实现只扫描Δ实际最高层以内；制造上限更高时，不扫描额外空白行。这是确定性多项式约束求解，不是对每块枚举H个来源层。

<a id="s04-13-h3"></a>

### 3. 实体制造、释放与精确输出

按求得的x放入全部原N/P，再在每个非空列中，从地面到该列最高格把空隙填C。每列第一根P及以上无空隙，因此没有C在P上方。每根柱均可独立制造，之后按已有半面拼接方法取得实体上料B。

x逐分量最小，使每列最高格最低，所以辅助C总数及整体载体高度也在这套约束族内最小。它不保证配方加工次数最少，也不保证最小解一定释放。

仍必须检查`stationary(B, grounded=False)`为空。通过时，全部C碎裂，全部N/P释放；普通块划分和共享列顺序都与Δ相同。由目标直接支撑及列顶落点归纳，实际`Stack(D,B)`恰好得到T。无需把原下料额外结算，也不要求它属于K。

若约束有解但最小解含悬空支撑环，这一种安排返回未覆盖。程序随后尝试第5节的触地针前缀形式；两种最小解都失败，也不能排除其他高度安排或其他真实复杂上料。

<a id="s04-13-h4"></a>

### 4. 六象限五层的扩域代表

原下料：q1四层N柱、q5三层N柱。新增格如下：

| 零基层 | Δ，q0…q5 | 新载体B，q0…q5 |
|---:|---|---|
| 4 | `-N----` | 空 |
| 3 | `---NNN` | 空 |
| 2 | 空 | `---NNN` |
| 1 | `---P--` | `-N-PCC` |
| 0 | `N--NN-` | `NC-NNC` |

三个旧候选的失败原因可以分别静态定位：

- 无C下落把q0、q1的N粘在一起，却要求它们回到不同目标层。
- 原位补C在q3产生N-P-C-N，不能独立制造；辅助C还可能围住该针形成静止环。
- 全列压紧时，q3的NPN要求底顶N相差2，q4的NN要求相差1；它们共享底顶普通块，所以等式不相容。

新载体允许q4在两个N之间保留一颗C。q3仍为NPN，q4为NCN，q5为CCN；它们顶端N对齐于来源第2层。底部晶体组没有向下支撑，空地面剥离后依次释放q3的P及顶端三连N。顶端三连N在真实下料上被q5旧柱托到第3层，保留q3/q4的目标空隙。

这证明第四候选严格扩大固定下料的一次堆叠成功域。目标本身无C、可从零逐层制造；此处解决的是复用给定下料并只加工一次的问题。[完整代表配方](../examples/6q-layer-constraints.md)已导出45个表项、3个物品槽，包含下料与上料的制造。

<a id="s04-13-h5"></a>

### 5. 触地针前缀的规范化形式

每列在第一个N之前，可能先有k根目标P。把这些P的来源层固定为0至k−1；第一N及其后的格保留同列顺序。从第一个N之后遇到的第一根P起，才要求后缀连续。其余空隙仍填C。

初始k根P的固定不需要额外求解器：同列递增和非负性已经要求第i根P的层号至少i，只需把它的变量上界设为i。P是单格独立块，不会与另一列争用这个上界。其他列的N块对齐、相邻N行保序及高度限制全部保持。

<a id="s04-13-h6"></a>

#### 为什么无需枚举每列是否采用触地前缀

考虑仅在Δ非空列内补C、列顶为最后一个目标N/P、保持原N块和相邻N行次序的连续独立柱载体。它的各列已满足Q，但初始目标P之间可能夹C，或者整列被C前缀抬高。对每列作如下规范化：

1. 把第一N之前的全部k根P移到0至k−1，保持P次序；全P列也同样处理。
2. 保持全部N和第一N之后的P的来源层不变；在新的地面至列顶范围内以C补齐其余空隙。

若有N，它原来已高于k根P，所以原N层号至少k，不会被新前缀覆盖。N块划分与相邻N行次序完全不变；P仍在原列序中。第一N之后的任何P都不是触地针前缀的一部分，Q已要求它上方不能再有C，因此这段NP后缀本来就是连续的。规范化后所有初始P触地，允许中间C位于这些P上方；其余P仍处于最高C之上。故新柱满足独立制造条件。

有N的列顶不变；全P列只降低列顶。因此规范化不增加高度或辅助C数。由此，第5节的线性约束有解，当且仅当上述保持相邻N行次序的连续柱填隙族有制造几何可行解。各列不需要做2^n种“针前缀/非前缀”选择。这个完备性仅针对制造几何，不包括全体释放。

移动针及改填C可能改变横向粘连与支撑环，所以规范化后仍必须重新检查空地面静止集合。程序先尝试第2节的最小解，再尝试本节最小解，保留已有成功路径；没有把规范化当成对任意下料等价的物理操作。

<a id="s04-13-h7"></a>

#### 六象限五层的触地前缀代表

原下料为q1四层N柱、q3地面N、q4两层N柱。新增q0地面N、q1第4层N，以及q3的P₁/N₂/N₄和q4的N₂/P₃/N₄。层号仍从0开始。

无C候选把q0/q1粘合；原位补C在q3形成C-P-N-C-N；全列压紧及未固定针前缀的第2节形式，则要求q3两个N相差1、q4两个N相差2，均失败。触地前缀形式把q3做成P-N-C-N，把q4做成C-N-P-N，两个N层对齐，初始q3针触地。载体从底到顶为：

```text
NC-PC-
-N-NN-
---CP-
---NN-
```

空地面结算中，底针与底C组先失去支撑，随后释放第一对N，再释放中间P/C与顶端N块，没有残留支撑环。在真实下料上，q3初始针停于第1层，第一对N停于第2层，q4针停于第3层，顶端N停于第4层，恰好得到目标。这给出固定针前缀的严格扩域实例；[完整配方](../examples/6q-ground-pin-prefix.md)已导出42个表项、3个物品槽。

<a id="s04-13-h8"></a>

### 6. 实现与复用成本边界

程序复用同一个差分下界求解器：第三候选以n个列起点为变量，第四候选以M个物理块为变量，依次尝试普通间隙和触地针前缀两种约束。旧成功路径不额外进入后面的形式。释放检查和实体独立柱制造沿用现有模块；触地形式只改针变量上界及连续后缀的起点，不增加指数枚举。

游戏实现应在同一组加法、比较、选址和写回模块上扫描约束；变量、边表和变化位属于存储与控制成本。最坏轮数增加，不要求按轮数复制电路。这里给出计算与存储界，尚未把它们折算为游戏建筑，也没有生成走线。

证明依据来源块连接、列内次序、针下间隙位置及真实制造凭据；没有运行枚举、测试或游戏验证。

## 04-14 单次堆叠中的针尾：列前缀上料构造

原文标识：`general/pin-tail-stack.md`。

沿用偶数n≥2、H≥2的参数化加工规则。D是已有制造配方的任意下料，允许非K和不稳定；D₀=F(D)只用于计算，不额外加工D。Δ=T\D₀为目标新增格。

本定理把[不新增针的单次堆叠](#s04-10)推广到含针的一类目标，并减少辅助晶体。仍保留一次真实Stack(D,U)，不拆成多次堆叠。

<a id="s04-14-h1"></a>

### 1. 适用域与充要条件

适用域：Δ只含普通格和针；在每列中，所有新增普通格都低于所有新增针。允许只有普通格、只有针或整列没有新增格。

在此域内，存在一次合法Stack(D,U)=T，当且仅当：

1. T逐格保留D₀及其标签。
2. Δ没有晶体。
3. 每个新增格严格高于D₀的同列列顶。
4. 仅在Δ内部划分水平普通连通块，针各自成块；每块在地面，或至少有一格正下方在T中非空。

必要性与普通追加相同：上下料初始分离，下料贡献独立地等于D₀；上料晶体不保留；所有新增块从下料上方落下，不能穿过同列保留格，停止时必有直接支撑。针独立成组，所以每根非地面针必须正下方有格。

针尾必连续。若同列新增针之间存在空位，较高的针正下方不能是D₀：所有新增针都高于D₀列顶；也不能是新增普通格，因为适用域禁止普通格在针上方。于是违反第4项。这个连续性由条件推出，不依赖枚举。

<a id="s04-14-h2"></a>

### 2. 按列构造上料

先将Δ整体向下平移，使最低非空层位于地面，记为Δ'。所有上料进入Stack时仍在全部下料来源之上，平移保持块之间的层次顺序，不改变预期落点。

对Δ'每个非空列：

- 保留其普通格与针。
- 从地面到该列第一根针以下，空位填红晶体；无针列填到该列最高普通格。
- 针尾顶端以上为空；没有新增格的列整个为空。

所得U*的每列都是连续触地的N/C前缀，再接可选的连续针尾。独立列可用既有Builder.column制造，再沿空切线拼接，不需要外部晶体原料，也不超过H层。没有新增格时，使用一层纯晶体上料触发下料的一次结算；纯晶体可由一份全针基础层结晶取得。

相较填满整个矩形，U*不填空列，也不填各列所需高度以上的C。所需晶体数只等于各列前缀内的缺格数。

<a id="s04-14-h3"></a>

### 3. 上料支撑图无环

令A_z为U*第z层的非针占用列集合。每列的非针格恰是地面开始的前缀，所以A_(z+1)⊆A_z。

先把每层的水平非针连通分量当节点。任意上层分量的列集合连通，且包含于下一层集合，因此完整落在下一层唯一一个水平分量中。给每个上层分量连向这个唯一父节点，得到向下的森林。

实际物理组只比这些水平分量多了竖直C连接。每条竖直C连接恰沿上述父边；合组等价于收缩森林中的部分边。收缩森林边不会产生环，其余非针直接支撑边也来自同一森林。

每根针只向正下方的针或非针组连边。非针格都在本列针尾以下，故不存在非针组向针的支撑边；针链也只有向下边。加入针后仍无有向环。

Stack将U*整体抬高，去掉原地面支撑；它与下料初始相隔至少一层。因此上料没有固定组，每个组都会开始移动，全部辅助C均碎裂。针和普通格不会消失。

<a id="s04-14-h4"></a>

### 4. 精确落点与覆盖

C消失后，上料剩下的正是Δ'的水平普通块与单针。它们的来源层顺序与目标中Δ相同。按目标层递增计算落点：D₀同列格位都更低，先处理的新增块也更低，第4项又保证目标位置正下方存在支撑。因此每块恰好停在目标层，结果逐格等于T。

本次下落不合并新接触，故不要求D₀或中间追加前缀在重新分组后稳定。实际下料始终是D，不把虚拟D₀作为新物品重新加工。

这给出了适用域内的充分性，连同第1节必要性得到充要判据。普通追加是没有针尾的特例，因此旧ordinary_stack可使用更短的列前缀上料而保持接受域。

<a id="s04-14-h5"></a>

### 5. 更便宜的直接上料与尚未覆盖的情况

无晶体候选现在先取A=F(Δ)。如果下落前后块数相等，说明原普通块没有因新接触而合并；此时A能制造，且Stack(D,A)=T。这个充要判据及其保留旧直接分支的证明见[交错上料构造](#s04-11)。

紧凑候选失配后，才构造本页的补C连续列。Python不再把P上方出现N直接视为失败，而是检查抬高后的最大静止集合为空，再由独立列制造器取得凭据；针尾域仍由本页森林定理保证。一般交错列可能不满足独立制造条件，也可能围住针形成悬空环，所以这两种候选没有给出全部交错目标的完备判定。

single_stack与ordinary_stack共用必要条件、紧凑上料判据及补C构造；ordinary_stack保留原“不新增针”接口。搜索优化发生在给定下料后的上料生成，尚未消除下料本身的搜索，也未解决完整六象限实用复杂度。候选失败不能判定目标全局不可制作，也不能预先删除其他真实上料。

证据为物理规则静态重读和上述森林/落点证明。代码静态诊断与具体配方导出分别记录，不以几个代表图形代替覆盖证明。

## 04-15 无晶体制造统一使用逐层供料与堆叠

原文标识：`general/pin-row-segments.md`。

适用于偶数n≥2、H≥2的Python构造，以及四象限五层的动态ROM。所有无晶体目标、独立列无晶体后缀和已证明安全的追加段，共用逐层base/Stack方式。纯针行也是普通的N/P基础料，不再使用专门的行段识别与Pin发令。

选择这一统一方式的目标是减少电路建筑和控制分支。允许连续针段多做若干次供料或堆叠；最少制造步骤不作为保留专用处理器的理由。

<a id="s04-15-h1"></a>

### 1. 覆盖所有稳定无晶体目标

无晶体图形的普通组只有水平连接，针各自独立。非地面组稳定，当且仅当至少一格的正下方有支撑；针必须有同列直接支撑。支撑始终指向更低层，不存在悬空循环。

设已经制成目标第0至z−1层。取目标第z层作为一份基础上料。每个水平普通块至少有一列在z−1层有目标格，其他列的当前列顶不超过z−1；其下落高度为1加所占列当前最高列顶，恰为z。针同样落在自己的直接支撑上。因此本次Stack精确得到更长的目标前缀。

从地面层开始归纳，得到整个目标。稳定非空无晶体目标没有全空中间层；程序保留空行拒绝及最终精确结果比较。该构造仍完整判定无晶体目标，不因统一处理而损失覆盖。

纯针段是上述归纳的子类。它不需要独立的识别条件、段顶选择器或Pin操作。删除专用实现后，不再在两个可行制造方式之间比较或切换。

<a id="s04-15-h2"></a>

### 2. 含晶体主体上的后缀

独立列及矩形核心都连续触地，最高C以上的N/P后缀在各列保持连续。逐层追加时每格有正下方支撑，旧主体保持，辅助晶体不会因本次追加下落。

完整控制器的S追加段沿用既有K下料和新增块支撑证明。不能将这个逐层替换推广到任意非K下料；复杂Stack仍须遵守其单次加工合同。

晶体核心所需的触地针前缀、角构造的顶破以及完整尾部逆推仍使用Pin。这些操作有不同的制造作用，不属于被通用逐层追加覆盖的纯针行段专用优化。

<a id="s04-15-h3"></a>

### 3. Python与电路统一流程

Builder.noncrystal直接按目标行调用base和Stack。Builder.column与rectangular_columns也直接逐行追加无C后缀，原_noncrystal_segments生成器已经删除。

CornerProgram.noncrystal_rows对每行计算非空标志，统一发令：

1. 有非空行时供料。若已有下料，写入work+1；否则写入work。
2. 有非空行且已有下料时，执行Stack(work,work+1)，结果回到work。

“已有下料”只由调用参数或较早的非空行决定，不读取更高层；各行的占用判断和前缀OR可以组合并行。每行最多两条ROM记录，不再计算相邻纯针掩码、反向传播段顶、动态选择Pin/Stack或切换加工源槽。

归纳不变量：每行完成后，work保存目前的完整前缀，work+1为空。空行不供料也不加工。调用者继续负责证明该追加安全；此函数不引入任意图形逐层可造的假设。

<a id="s04-15-h4"></a>

### 4. 成本与证据

有h个非空行时，从空槽开始发令2h−1条；已有下料时发令2h条。最多两个活动物品槽；独立使用本构造制造五层无C目标至多9条。完整半形入口已统一走两角流程，不再采用这个快捷界。若旧纯针段算法可合并p个边界，新流程多p条制造指令；这是主动接受的时间换体积取舍。

完整控制器的两角、两半形时序调用、叶端/父帧共用追加及六槽回放保持。实际非线缆建筑、ROM、状态和周期以[当前生产网表报告](../reports/README.md)为准，不能由Python行数或指令数推算体积。

证明来自逐层落点与支撑归纳。验证采用静态重读、LSP、固定配方生产导出及网表编译；不依赖目标枚举、测试或游戏运行。

## 04-16 交换只需半形结果与原输入凭据

原文标识：`general/swap-witnesses.md`。

适用偶数n=2k、固定高度H、单象限旋转和等分半切。不要求输入或输出属于K，也不要求交换后稳定。令L(D)、R(D)分别为原生Cut的前半、后半结果，包含融合删除及一次重力；允许结果为空。

原生交换出口0严格为 `L(D) ∪ R(U)`，出口1为 `L(U) ∪ R(D)`。拼合后不再执行重力。因此固定方向的交换输出只依赖两个半形结果，而不依赖输入的其余结构。

<a id="s04-16-h1"></a>

### 1. 为什么必须保留原输入

为每个不同半形结果a保存一个凭据D，使L(D)=a。a是索引键，D的制造树才是后续机器的真实输入。不能把a当作输入代替D：对a再次切割会重新分组并重算重力，一般参数下尚无L(L(D))=L(D)保证。

将所有后半结果旋转k列，归一化到前半位置。若R(U)=b，则L(Rotate(U,k))=Rotate(b,k)，这是旋转对列邻接、融合及同列重力的置换对称性。登记所有输入的n个旋转方向后，同一个前半凭据表就覆盖所有切向的前后半。

给两个表项a、b，凭据分别为D_a、D_b。真实加工取：

`Swap_0(D_a, Rotate(D_b,k)) = a ∪ Rotate(b,k)`。

这里先制造两份原输入，再旋转第二份并执行一次交换。凭据表若共用同一制造树，必须分别生产两份实物。空半形也保存合法非空原输入的凭据，例如切掉一份位于后半的基础料；空物品本身不能接入机器。

<a id="s04-16-h2"></a>

### 2. 完备性与规模

可靠性：每个凭据有制造树，旋转及交换都是合法实体操作，所以每个合并结果可制作。

完备性：任意真实Swap(D,U)的两个切后结果均有表项。把D、U分别替换成同键凭据，切割后的保留格逐格相同；最终并集也完全相同。出口1通过交换输入顺序覆盖。表项无须保留全部前像，也不需要对原输入满足全局稳定性作假设。

结构半形最多含kH格，因此连同空半形，表大小A≤4^(kH)。从表项对产生全部交换输出至多A²−1≤4^(nH)−1种，而直接对整个状态目录的有序输入对使用粗界会达到4^(2nH)。这是按输出等价类消除重复，并未把全部可制造状态都降为半形，也没有消除非K下料的复杂Stack。

分轮目录若要求父节点来自旧轮，先冻结旧目录并登记其旋转后的切割结果，再产生交换输出；凭据中的旋转可以作为固定宏展开。若坚持单操作轮数，加入所需旋转后推迟到后续轮，最终闭包仍相同。不能以提前结束某个未闭合的中间轮为不可制作证明。

<a id="s04-16-h3"></a>

### 3. 已有半形表时，目标的最后一步无需穷举配对

将目标T沿每条直径分成两个纯格位投影。这里不能对T执行Cut，因为那会改变待匹配的目标。将两个投影归一化到前半位置，并分别查询凭据表：

- 两项都存在：取对应原输入，旋转第二份并交换，最后旋转回目标朝向。
- 某项缺失：只说明当前表还没有这条末步路径，返回unknown，不能判不可制作。

不同直径只有k条，故目标末步构造只需k对查表。4q为2对，6q为3对。即使目标是交换后不稳定的V，也可直接投影查到两个H，不会先对V重新结算而碎掉晶体。

[`HalfCatalog`](../synthesis/half_catalog.py)实现这个有凭据的Python接口，并进一步[比较用途成本](#s04-17)：`add(recipe)`按前半、后半用途分别保留已知最低成本原输入；`join(target)`检查n个有向起点，取表内总步数最低的制造树或返回None。存在性只需k条直径，而成本比较需要两种朝向，故这里是4q查4对、6q查6对。它是增量合成部件，不是独立完整求解器；表的增长仍需完整外层流程。Python物理与此接口已开放偶数n≥2、H≥2，见[参数化模型](#s04-20)。

对游戏电路的意义是把“两个整图候选是否值得交换”改为“目标两个半面的可制造前像是否已有凭据”，并可复用同一个切割/查表/回放模块。表规模和凭据发现仍是难点，不能只凭查表次数声称已经能在游戏中实用。

依据为原生交换调用顺序、旋转对称性和集合等价证明；未运行完整目录、测试、游戏或Mod。具体H/V制造路径见[代表配方](../examples/README.md)。

## 04-17 恒等加工消除与交换凭据的用途成本

原文标识：`general/orientation-cost.md`。

本页优化制造树的实际步骤，保留目标格位、标签和消费语义。适用既有偶数n≥2、H≥2模型。本页局部规则不跨加工搬移旋转；允许跨加工变换的完整条件及最终证书优化见[整树朝向安排](#s04-18)。

<a id="s04-17-h1"></a>

### 1. 连续旋转只需一个节点

Rotate只置换列位置，不执行重力。对任意原始状态S，包括不稳定状态，有：

`Rotate(Rotate(S,a),b) = Rotate(S,(a+b) mod n)`。

因此Builder.apply在新增旋转时，可以沿输入的连续rotate节点累加参数，只保留最早的非旋转输入与一个模n参数。参数为零时直接返回该输入；若非零旋转后的完整带标签图形也等于原图形，则同样无需实体操作。

这不要求S稳定，也不重复制造输入。被去掉的节点都只消费并转交同一物品；新的制造树仍取得一份原输入。只删除一元节点，所以步骤数和物品寄存器峰值都不会增加。

同样，Cut、Pin或Crystal在完成原参数校验及精确物理计算后，如果输出完整带标签图形与唯一输入相同，就直接保留原输入配方。后续操作只依赖这个原始格位状态，并不保存上次加工的物理分组，故删除这个恒等节点不改变任何后续输出。仍会改变图形的加工不能删除；空产物也不能当作恒等。双输入Stack/Swap节点保持，以保留组合凭据的成本及末步结构。

<a id="s04-17-h2"></a>

### 2. 半形凭据必须区分实际使用的出口

[半形等价证明](#s04-16)允许为每个切后结果共用原输入凭据。若只关心存在性，可以把全部半形归一到前半，再旋转第二份输入；但最低成本不能只保留一个前半最短配方：补上的半圈旋转可能抵消某个配方末尾已有的旋转，使它在后半用途下反而更便宜。

HalfCatalog因此为两个用途分别保留最低成本凭据：

- fronts[a]：原生Cut前半恰为a的实际输入。
- backs[b]：原生Cut后半旋转半圈后恰为b的实际输入；仅键归一化，凭据保持原朝向。

add登记每个输入的n种旋转。每次Cut已算出两个出口，都用于登记；不再丢弃后半结果。各表先按实际输入step_count取最低值，同长时取register_count最低者，空半形键也保留非空输入凭据。

任意同键凭据用于同一个出口时都产生完全相同的保留格。交换后又不额外结算，因此对另一侧任意凭据，替换成该用途下的较短原输入都保持结果。分别保留两侧最短者不会丢失表内的最低成本配对。

<a id="s04-17-h3"></a>

### 3. 按目标直接比较成本

几何上只有n/2条直径，足够回答已有凭据能否构造目标。为了比较制造成本，还需区分每条直径的两个朝向：两侧凭据的成本可能不同，恢复目标朝向的旋转也可能省略。因此join检查n个有向起点，不枚举两表的任意配对。

每个起点先虚拟旋转目标，取得前半和归一化后半的纯格位投影；不对目标执行Cut。两项存在时，成本为：

`前半凭据步数 + 后半凭据步数 + 1次Swap + 恢复朝向的旋转成本`。

恢复旋转成本为0或1：若已对齐图形等于原目标就是0，否则就是1。本节对既定用途凭据计价，保留Swap前后的朝向，不跨Swap改写配方。总步数相同的起点，再按二元加工的物品槽需求取优，递推及单调性见[物品槽调度](#s04-19-h5)。选出起点后，才用两个原输入生成真实Swap和必要的最终Rotate，并精确核对目标。

每个方向只查一对键，查询量由存在性版本的n/2对增加到n对，换取已登记凭据及这些方向内的最低制造成本。缺少某项仍表示unknown，不是全局不可制作。表内最短也不是所有游戏配方中的全局最短。

<a id="s04-17-h4"></a>

### 4. 实现边界

[recipe.py](../synthesis/recipe.py)的Builder.apply合并连续旋转，并删除精确结果等于输入的一元加工。[half_catalog.py](../synthesis/half_catalog.py)保存两种用途的原输入，使用Recipe.step_count比较消费成本。不会把切后形作为原输入再切一次，也不会把共享的配方对象当作免费物品复制。

具体配方产品和说明由[examples.py](../synthesis/examples.py)导出；对旋转收尾的交换配方，里程碑取实际Swap节点的第二个输入。理论证明及静态诊断覆盖上述等价边界，没有运行测试、完整目录或游戏验证。

## 04-18 制造树的全局朝向安排

原文标识：`general/recipe-orientation.md`。

本页固定一份真实制造树，只改变各中间物品的朝向、基础料朝向及切割/交换的出口。适用偶数n≥2、H≥2，基础供料仍为任意无晶体单层。目标格位和标签保持；不改变非旋转加工的种类、消费关系或次数。

<a id="s04-18-h1"></a>

### 1. 可以穿过哪些加工

记R_t为按象限旋转t，h=n/2。旋转不执行重力。对任意输入，包括非K及重新分组后不稳定的状态，有：

- `Pin(R_t(A)) = R_t(Pin(A))`。
- `Crystal_c(R_t(A)) = R_t(Crystal_c(A))`。
- `Stack(R_t(A), R_t(B)) = R_t(Stack(A,B))`，下料和上料顺序保持。
- `Cut_(1-p)(R_h(A)) = R_h(Cut_p(A))`。
- `Swap_(1-p)(R_h(A), R_h(B)) = R_h(Swap_p(A,B))`，两个输入不交换。

前三式由旋转对水平邻接、竖直晶体边、地面及层高的保持得到：原分组、晶体融合删除、最大静止集合逐一对应；移动普通块的列顶最大值不变，针也在对应列落下。旋转置换列但不改高度，故截高保持。Crystal逐格替换，直接对应。没有加入一次额外结算，也没有把Stack拆开。

后两式只对半圈写出。半圈把前后半面互换，跨切线的融合组和删除关系保持，半切各自的结算由同一旋转对应；Swap再交叉拼接。原出口0取A前+B后，旋转半圈后成为A后+B前，恰为旋转输入的出口1。任意角度不能无条件穿过固定切线。

基础层R_t(A)仍可直接供给，不必先供给A再实体旋转。这使用既定的基础供料合同，不等于原料工厂内部的旋转免费。

<a id="s04-18-h2"></a>

### 2. 每个节点只需记录n个朝向

对原节点v的输出S_v，令D_v(r)为制造R_r(S_v)的最低步骤配方，r取0至n−1。最低范围限定为：保留原非旋转加工树骨架，使用第1节的变换，并允许在加工之间插入净旋转。

显式rotate(t)节点不保留一个强制操作，直接使用其子节点的D(r+t)。连续旋转因此自动合并。base节点的每个朝向都只需一个基础料节点。

对其他节点先计算原生加工候选B_v(s)：

| 加工 | 原生候选朝向s | 子树及出口 |
|---|---|---|
| Pin、Crystal | 全部n个朝向 | 子树D(s)，原参数 |
| Stack | 全部n个朝向 | 下料D(s)、上料D(s)，原输入顺序 |
| Cut | 0、h | 子树D(s)，s=h时出口翻转 |
| Swap | 0、h | 两个输入均D(s)，s=h时出口翻转 |

候选实际产物为R_s(S_v)，成本为`1+sum(子树成本)`。最后可接一次旋转得到目标朝向r：

`cost D_v(r) = min_s (cost B_v(s) + [R_s(S_v) ≠ R_r(S_v)])`。

这里比较完整带标签的图形。若两个朝向因图形对称而相同，转向成本为0；否则一个净旋转表项即可连接。不是仅比较占用掩码或N/P/C类别。

<a id="s04-18-h3"></a>

### 3. 无需对每个目标朝向重扫全部候选

把B候选按实际产物Shape分组，每组保留成本最低者；另外保存所有候选中的最低者B_min。对每个目标朝向，仅比较：

1. 同一完整Shape的最低候选，若存在；
2. B_min加至多一个净旋转。

所有其他不同Shape的候选也都要加1，其成本不会小于B_min+1；相同Shape的候选则已由第1项覆盖。因此每节点只需O(n)次候选选择，不需要O(n²)次成本比较。

这不是对全部图形状态枚举：V个不同源Recipe对象只有O(Vn)个朝向状态。实现保存各旋转图形的完整网格，若最大实际图高为L，则构造/哈希这些网格的上界为O(Vn²L)，存储也采用这一宽松上界；不能只报成本比较次数而忽略网格大小。使用显式后序栈处理任意深制造树。

<a id="s04-18-h4"></a>

### 4. 正确性、最优性及边界

制造树归纳给出每个D_v(r)的真实产物为R_r(S_v)：叶子直接成立，原生候选由第1节成立，末次旋转只改朝向。最终取D_root(0)，目标完全保持。

同一归纳证明上述变换族内的最优性：固定原生加工朝向s后，各消费子树独立取相应最低成本；非旋转节点之后的连续旋转至多保留一次。所有允许的s及末次旋转都已比较。原配方在这个族内，故结果步骤数不增加。

非旋转树骨架、每份基础料和每条双输入消费关系保持。移除或插入一元旋转不改变子树物品槽递推，因此`register_count`严格保持。共享Python对象仍按每个输入出现次数消耗，不能省去另一份实体生产。

这个最优性不涵盖其他合成算法、更换辅助材料、删除非旋转加工、改变Stack分段或全部可能配方。一步rotate记录净朝向；大象限机器可能需要多次原生旋转，因此没有证明原生调用数或游戏时间最少。也没有优化完整搜索的候选数量。

<a id="s04-18-h5"></a>

### 5. Python与时序实现位置

[`optimize_rotations`](../synthesis/orientation.py)读取已取得的证书，按上述证明直接变换节点的完整中间图形，不重新执行每个朝向的物理。CLI在输出最终步骤/寄存器指令前调用一次；代表配方导出也使用它。所有偶数象限还按第6节，以半圈等价选择更短的净角度。`Constructor`及`Solver4`内部保持原始证书，不在每次候选检查里运行此优化。直接Python调用者可以在取得成功证书后显式调用。

导出配方中的关键阶段使用原构造的标准朝向示意；实际操作方向及物品编号以完整步骤表为准。最终目标与物品槽不变。

游戏实现可按节点、朝向循环处理同一组成本比较和选择电路，保存朝向状态及回溯选择；不需要为n个朝向复制n套物理核心。基础供料按最终选择的朝向发令，Cut/Swap按选择的出口发令。具体存储、控制和建筑数量须由电路编译另计，本证明不替代这些工程结果。

<a id="s04-18-h6"></a>

### 6. 半圈可推入配方，净旋转只需四分之一圈

令h=n/2。对任意制造树A，把每份base转h、每个Cut/Swap出口翻转，其余操作与旋转参数保持；由第1节逐节点归纳，所得树制造R_h(A)，非旋转加工、旋转参数、消费关系和成本全部保持。变换再做一次还原。因此`cost D_v(r+h)=cost D_v(r)`，不要求中间状态稳定、属于K或具有图形对称。

原生候选朝向集合对加h封闭：Cut/Swap的0与h互换，其余加工的全部朝向两两配对。子树最优成本也成对相同，故按完整Shape分组之后，某候选S与R_h(S)的最低成本仍相同。

第3节若选择B_min后接净旋转t，就同时比较t与`(t+h) mod n`的最短有向角度。后者更短时，改取B_min旋转h对应Shape的同成本原生候选，再接t+h。产物为`R_(t+h)(R_h(B_min))=R_t(B_min)`，表项数与物品槽保持。每个目标朝向只增加一次已分组候选查询，仍为O(n)候选选择，无须维护额外包成本状态或重扫全部候选。

如果t=h，目标本身已有同成本的半圈原生候选，第3节的直接分支已经选中它，不会生成半圈旋转；同Shape的其他旋转对称也由直接分支处理。对其余角度，在相差h的两个候选中选短者，得到`min(t,n−t) ≤ floor(n/4)`。原rotate节点仍只重索引状态，所以最终配方的全部显式旋转都满足此界。

这同时给出任意偶数n、任意H的规范形：半圈旋转可全部去掉，每次显式旋转至多四分之一圈。不增加其他加工，也不改变目标或基础供料合同。n=2不需要显式旋转；n=4或6只需单象限顺/逆旋转；n=8最多两格。

对四/六象限五层的当前[时序回放接口](08-circuits.md#s08-01)，优化后的每个制造表项恰好发一包。设既定变换族内最少表项为M，任何配方的包数都至少为其表项数，因而至少为M；本规范形恰用M包，故同时达到该变换族内最少表项和最少发令包。这个结论不覆盖更换制造骨架、辅助料或原生指令集，也不代表完整搜索或实体工厂耗时最短。任意未经此优化的六象限输入树仍可能含两格旋转，`instructions()`继续保留两包展开。

证据为旋转对应与动态规划归纳、源码静态检查，以及固定代表配方的交付导出；没有运行测试、全图枚举或游戏验证。

## 04-19 制造树的物品槽调度

原文标识：`general/recipe-slots.md`。

本页在制造树不变时调整子配方的执行先后，不改变Stack上下料、Swap左右输入、加工参数、目标或实体消耗次数。优化对象是同时存活的物品槽，不是搜索帧、逻辑状态寄存器或游戏建筑总数。

<a id="s04-19-h1"></a>

### 1. 逐子树制造的槽数递推

每个基础料需要一个槽。一元加工消费原物品并可复用同一槽，需求等于子配方需求。多输入加工先依次完整制造各子配方，保留每份结果，再消费它们并复用一个输入槽输出。

设子配方槽数按执行顺序为d₀、d₁……。制造第i个子配方时，已有i份结果需要保留，峰值为dᵢ+i。因此当前节点需求为max(dᵢ+i)，无输入时为1。

最优顺序是按d降序。若相邻两个需求a<b却先做a，在前方已有k份结果时，其峰值为max(a+k,b+k+1)=b+k+1；交换后的峰值max(b+k,a+k+1)不大于它。反复交换逆序对即可得到降序，且不改变后续保留的结果数量。

二元加工因而得到熟悉的递推：两子树需求相同为r时需要r+1槽，不同时需要较大值。这个最小性针对“每次完整制造一个子树、无外部溢出、无重算”的调度族，不声称任意交错、改变制造树或额外存储条件下的全局最优。

<a id="s04-19-h2"></a>

### 2. 执行顺序与操作数顺序分开

Recipe.register_count在建立不可变节点时，按上述递推保存槽数。Recipe.steps在展开一个节点前，稳定地按子配方槽数降序排执行索引；需求相同则保持原顺序。

节点准备就绪后，子结果编号按原输入位置回填。例如先造Stack的上料B，再造下料A，最终Stack仍记录inputs=[A的编号,B的编号]。原上下料语义不变。父节点仍在所有子结果之后输出，且各输入只消费一次。

相同Python子树对象出现两次仍分别展开，不能用一个结果编号免费复制。输入数量和总步骤数都不变。独立子物品在准备期间没有接触，交换它们的准备顺序不触发游戏物理。

<a id="s04-19-h3"></a>

### 3. 寄存器指令与交付数据

instructions(registers)在输出任何指令前检查预算是否达到register_count。默认仍为六个物品槽，旧分配器继续在基础料时取空槽、加工时消费原输入并复用第一个操作数槽。物品编号映射已恢复原操作数顺序，因此a/b及目标槽选择无需改变。

由步骤展开不变量，准备某子树时实际保留的外部物品数恰为其之前的子结果数；所以分配器的实际峰值不超过递推值。六槽旧上界仍成立，因为降序调度不比原先固定输入顺序更差。

[代表配方](../examples/README.md)的JSON提供register_count，Markdown同时说明槽峰值。它只估计这份消费式制造配方的活动物品数量；完整万能机的搜索状态、指令寄存器和传输缓存仍须另外计算，不能直接据此删游戏电路中的状态。

<a id="s04-19-h4"></a>

### 4. 证据与限制

实现位于[recipe.py](../synthesis/recipe.py)的Recipe.__post_init__、steps及instructions。证明依据相邻交换、消费式后序展开和原操作数位置保持。固定配方导出用于交付新的步骤顺序与成本，不是指令模拟或游戏测试。

未改变已有游戏蓝图的寄存器数量，也未运行完整目标搜索、测试或浏览器验证。

<a id="s04-19-h5"></a>

### 5. 同长度配方优先选择较少物品槽

HalfCatalog的前/后半表，以及StackCatalog的下/上料表，都按(step_count, register_count)字典序保留同键凭据。首先最小化步骤数，只在步骤相同时选择物品槽较少者。原半形或堆叠摘要保持，因此替换不改变其他输入与加工结果。

二元加工的槽需求为g(a,b)=max(a,b)+(a=b)。它对两参数分别单调不减：固定b，a<b时为b，a=b时为b+1，a>b时为a≥b+1。因此同键同长度凭据换成槽需求更低者，不会提高任何父配方的槽峰值。结合原步骤数可加性，每个键只保留这一词典序最优凭据，仍保留目录内“总步骤最少，其中槽数最少”的候选。

HalfCatalog.join按(两输入步骤数+Swap+必要旋转, g(a,b))比较全部有向起点；末尾旋转不增加槽数。StackCatalog.construct用(两输入步骤数+Stack, g(a,b))比较，成本剪枝也比较完整二元组，不能因步骤相同就提前跳过更省槽的候选。两指标均相同则保留先登记的凭据。

这不是多目标Pareto目录：更长但更省槽的配方仍可能被排除，也不能据此解决给定严格槽预算下的最短路径问题。成本只在已登记凭据及既有极小上料替换范围内取优，不扩大全局覆盖。

## 04-20 偶数参数的Python模型与构造边界

原文标识：`general/python-model.md`。

Rules现在接受偶数象限n≥2、制造层数上限H≥2。采用单象限旋转、等分半切，以及既有一次分组/下落规则。开放的是参数化物理及已证明的构造接口；没有把固定参数的有限目录证明实现成实用完整通用求解器。

<a id="s04-20-h1"></a>

### 1. 参数化部分

| 接口 | 范围与行为 |
|---|---|
| Rules | 按n环邻接，按H截高；Stack上料提高H+1；Pin排除原第H层并处理融合删除 |
| Builder | 基础层、无晶体统一逐层追加、独立柱、晶体前缀、连续半面拼接；replicate可提升同H的小象限真实配方 |
| Constructor | 两象限任意H及通用无晶体目标完整判定；六象限半形统一递归脚手架，更大象限保留相邻两列入口，共用paired_halves拼接；其余局部构造未覆盖时返回unknown |
| CornerBuilder | 4q5l按落点参数制造；n≥6任意H统一三列释放，A是主列存在N/P助手的充要条件；pair可保留指定两列的含针环；4q任意H另有直接释放充分构造，supported_half支持n≥6的递归多晶体列脚手架，六象限后续阶段复用带外侧N柱的两列扫描 |
| stack_successors | K_add下料的n²+1种结构基础块；一次结算后安全者用纯C触发料，其余保留真实上料 |
| ordinary_stack / single_stack | 给定真实下料的普通追加、针尾及部分交错N/P构造；依次尝试无C、原位补C、列内压紧及针下间隙载体，不额外结算下料 |
| HalfCatalog | 按前/后半用途保留最低成本原输入；按目标n个有向投影选目录内较短配方 |
| StackPlan / StackCatalog | 任意堆叠的精确摘要及目标前缀匹配，首次登记按无C/含C载体压缩上料，保留每键最低成本凭据；缺失不是不可制作证明 |
| Recipe.steps / step_count / register_count | 任意本模型配置的消费式步骤与完整中间产物；建立节点时计算总步骤数和物品槽需求，按子树槽需求降序调度 |

物理规则保持：groups的邻接取模n；collapse的静止组、移动N/P块的层序落点不依赖四象限或五层；cut用n/2；stack与pin使用实例H；rotate按整数列置换。实现采用[一次排序、反向支撑队列及列顶扫描](01-foundations.md#s01-02)，stationary在collapse和上料摘要间共用。新接触不在本次加工中合组，交换后不追加重力。规则证明来源见[六象限局部计算](03-general-construction.md#s03-01-h2)、[一般参数模型](01-foundations.md#s01-03)和[通用堆叠证明](#s04-14)。

无晶体目标的完整判据也跨参数成立：非针组只有单层水平连接，针独立，所有直接支撑边严格向下，不存在悬空环。每个非地面块必须正下方有支撑；相邻普通块合并只发生在同层，不会吞掉这些下方支撑。因此可制作无晶体输出稳定，并可按层精确重建。任一整空中间层或无支撑块都会被逐层构造拒绝。

独立N/C紧柱用其他列普通助手隔离结晶，再用相交于目标列的两个半切切出。n=2时半面本身就是单列，也成立。连续柱的针前缀及普通/针尾部沿原构造生成；拼接的保留窗口覆盖已有片段，丢弃侧只有空格，因此不会误删已有晶体融合组。

<a id="s04-20-h2"></a>

### 2. 固定范围没有自动扩大

- 完整Solver4、前缀强制闭包、Pin/Cut逆像生成器与四列Pin像判据仍要求4q5l；CornerBuilder另有n≥6任意H的[角构造](03-general-construction.md#s03-03)和[脚手架半形](03-general-construction.md#s03-04)，以及4q任意H的[直接释放](02-four-quadrants.md#s02-15)。
- Constructor对全部参数应用通用列A必要筛选；A的角存在性充分证明仅用于4q5l及n≥6任意H，4q其他高度仅使用已证明的直接释放子域，失败不判不可制作。K必要性另已由两列几何推广到n=2任意H，并接入两象限完整前缀构造；其余参数不能因不属于K而被判不可制作。
- 原生解码、无晶体电路及六寄存器指令支持4q5l和6q5l；完整逆推控制器仍只支持4q5l。
- 奇数象限与H=1直接拒绝；没有为它们猜测新的切割或Pin语义。

Recipe保存制造上限height，Builder创建和组合配方时传递并检查它。相同格位在不同H下执行Pin可能得到不同结果，所以不能只看成品高度判断配方配置。不同象限或上限的输入不能混接；instructions拒绝4q5l和6q5l以外的配置。

<a id="s04-20-h3"></a>

### 3. 使用方式

```bash
python -m shapez2_tmam.synthesis 'cr--------------' --quadrants 8 --height 8
```

默认仍为4q5l。--complete要求--quadrants 4 --height 5；--instructions接受--quadrants 4或6及--height 5，最终证书的半圈规范化使每个表项只发一包；未规范化的六象限树仍可将净两格旋转拆包，继续复用同一物品槽。参数不符合时在处理目标前报错。普通结果仍为solved/unsolvable/unknown，其中含晶体局部构造失败返回unknown。

Python可直接建立Builder(Rules(8, 8))并调用single_stack或HalfCatalog。所有输入图形须由同一Rules解析、所有输入Recipe须来自同一制造配置。

[八象限八层代表](../examples/8q8l-single-stack.md)已展开为98步：八层辅助晶体塔顶破后形成非K下料，再将双层普通上料一次堆入。最终只有六层，但全过程要求八层上限。它是既有证明的具体配方导出，不表示默认Constructor已能从任意同类目标自动发现该准备过程。

本轮递归脚手架修改经静态自审及LSP诊断；31份固定代表及26份原生指令产品已导出，包含必须一次尾Pin的完整四象限目标、六象限多晶体列双环，以及[十八象限十七层三次级联](../examples/18q17l-cascade/README.md)的854步配方、短代码和格子图。三次级联使用独立导出入口，其余30份仍使用原批量入口。未执行完整求解、目录枚举、测试或游戏/Mod验证。Python参数化模型不自动保证具体Mod提供相同旋转、半切及高度规则。
