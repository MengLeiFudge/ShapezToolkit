# TMAM 理论 III：一般偶数象限的列构造与循环支撑

**理论论文正文**

本文研究象限数和高度参数化后的局部充要构造，重点是三列释放、循环支撑、递归脚手架、非 K 半形和不稳定输出。结论只在明确的偶数象限模型下成立。

本论文按定理依赖组织。每个“文献章节”保留对应证明原文；章节标题前的来源路径只用于追溯，不引入工程实现内容。

## 文献章节 1：general/angle-synthesis.md

## 任意层角的列条件与三列释放构造

本页研究一个主列能否制成可供后续拼装的角。采用偶数象限n、全过程高度上限H、任意无C单层供料、已界定晶体颜色及现有局部加工规则。层号从0开始，N/P/C/空分别表示普通格、针、晶体和空位。

**结论：对所有偶数n≥6、H≥2，非空主列可配一根相邻N/P助手制成角，当且仅当满足下述列条件A。** 充分性使用同一套三列释放构造；多个间隙、落地和中途停止只改变辅助料参数。四象限五层也有相同充要条件，由直接释放与参数化顶破证明；四象限任意层须改用更强的完整S列判据与构造，不能直接沿用A作为充分条件。

这是角的结论，不是任意全图的完整求解定理。指定助手的两列角、存在某个助手的主列，以及全图，是三个不同的问题。这里先解存在助手的主列，再给稳定两列角的合成推论；三列以上的无针支撑环不能强拆为互相独立的稳定两列角。

### 1. 不按完整列字串分类的必要条件

把主列补空到H格，定义A：

1. 非地面P正下方非空。
2. 最高C以下的P全部属于从地面开始的连续针前缀。
3. C正下方若为空，向下最近的非空格必须是N。
4. 同列相邻两颗C之间若有空位，则中间至少两个N，且下方C紧邻的上一格非空。

条件1来自针独立成组及直接阻挡；条件2、3见通用列不变量，条件4见晶体间隙不变量。这些必要性证明不依赖五层、四象限、支撑必须触地或不存在循环。颜色不改变连接关系，但制造时必须保留目标标签。

A可以顺列扫描判定：记录针前缀、最近非空格、上一颗C、其后的N数量和是否出现空位。它检查局部关系，不匹配长度H的完整字串。后面的构造证明A在n≥6时也充分。

### 2. 四列工作位置与两次半切

固定主列M在q0，最终助手F在q1，临时近支撑A在q(n−1)，切除触发列E在q(n−2)。令h=n/2。最后只保留M、F。

先把M/F放在半面{q0,…,q(h−1)}，把A/E放在互补半面，用Swap拼合。第一次Cut保留从q(n−1)开始的h列：包含A、M、F，排除E。第二次Cut保留从q0开始的h列：包含M、F，排除A。

n≥6恰好保证第一次半切容纳三个工作列。更大n的其余列为空，所需工作列数不随n增加。镜像后同样成立。四象限的半面只有两列，不能直接执行这一步；这只证明本构造需要三列工作空间，不证明四象限目标不可制作。

### 3. 一次扫描产生辅助料

设c是最高目标C的层号。若没有C，令c=−1；以下区间为空，仍可使用同一供料与切割流程。

#### 3.1 把待下落N移到间隙顶部

对每颗正下方为空的目标C_r，记最近下方N的目标层为m。把该N的来源位置改为s=r−1，并清空原m。记录映射s→m。目标中m与r之间全空，所以不存在覆盖另一目标格的问题。不同C的这些区间互不重叠。

保留所有其他目标格，将0至c内剩余空位填成牺牲C。这些填充位置组成若干连续区间[a,b]。每个区间的上端b+1都是N：原来C下有空隙时，刚放入的来源N负责隔断；其他空段的上端也只能是N。

填充C不与保留C竖直相连。向上由上述N隔开；向下若有保留C，条件4保证其上一格是N，且另有一个N可作为上方间隙的移动格，不能把唯一隔断移走。底部针前缀保持；整个0至c前缀连续，且内部无P。

#### 3.2 远助手托住保留格

F的H格默认全部为N；仅在每个来源层s改为P。

F始终是连续触地N/P柱。主列的未移动N及保留C都接触F的同层N，因此保持原位；来源层s的N接触F的P，不能粘上F，保留释放自由度。c以上的普通格也都接触F的N；目标P按条件1受同列直接支撑。

#### 3.3 近支撑决定落点

A的H格默认全部为N。对每个牺牲区间[a,b]：

- 若b+1=s是一个记录的来源层，把A的m至b改为C。
- 否则只把A的b改为C。

E逐层使用与A相同的N/C材料。A、E都是连续触地N/C柱，可独立制造或共同逐层结晶；其晶体不与任何保留的主列C水平相连。每个主列牺牲区间都接触至少一格A的牺牲C，每格A的C都接触E的C。

这里的两种区间赋值只确定同一释放程序的删除掩码。制造阶段及切割次数不随区间类型或数量增加。

### 4. 辅助料本身可制造

主列的连续前缀满足独立柱制造条件：先制N/C核心，再补触地针前缀。随后由低到高追加F及主列c以上的N/P。F逐层有正下支撑；主列后缀N通过同层F获得支撑，后缀P由条件1保证。整个准备过程不需要悬空晶体原料。

A/E为同层同色的连续N/C两列，可以使用共同逐层结晶制造。准备各支路及拼合时，所有独立柱都连续触地，主列后缀已有F托住，所以Swap预先半切不改变输入。

所有中间产物的高度不超过H。没有顶破；制造主列底针前缀时的Pin不触顶。供料、Stack、Crystal、必要的底针Pin以及固定次数的旋转/切割/交换，足以构成真实制造树。

### 5. 第一次半切的精确效果

切掉E，晶体融合删除移走A的全部C及主列的全部牺牲区间。没有保留C连接到它们，故目标C不被删除。

F保持连续触地，主列的所有未移动N/C仍由F保持；P的原支撑保持。下面证明近支撑的落点，不能只假设它能停在所需高度。

对牺牲区间[a,b]，若a>0，其下方主列格不会是即将移动的来源N：移动来源的上一格必是保留C。该下方格若为N/C，就由F保持，A在a−1的N与它粘连；若为P，则属于地面针前缀，其旁的A从地面连续为N。因此A在区间起点以下有固定支撑；a=0时直接使用地面。

对于来源区间，A的[a,m−1]为连续N，由上述支撑保持；[m,b]为已删除的C。主列和A在s=b+1的两个N构成同一水平块。它不接触F的非针格，故能够下落。其主列下方最高障碍不高于m−1；A列下方最高障碍恰为m−1（m=0时为地面−1）。落点为

`1 + max(主列可用列顶, 近支撑可用列顶) = m`。

故落地m=0和中途停止m>0使用同一公式。新接触在本次下落中不重新合组，也不需要它来停止水平块。

对于非来源区间，仅删除A的b层C；其下N由低处支撑，b+1层N与主列的固定N粘连，故上方不会塌落。

不同牺牲区间之间的保留N/C恢复固定支撑，前一个区间的删除不会累积成后一个区间的额外下降。沿区间从低到高归纳，全部来源N精确回到目标m；其余主列格均不动。第一次Cut后主列已经等于目标。

### 6. 第二次半切与充要结论

第一次切割后A不再含晶体。再次Cut去掉A，不会融合删除主列晶体。回到m的N此时接触F在m的N：m不是任何来源层，因而那里没有隔离P。重新分组后这些N与F相连，故切掉A也不会再次下降。其他主列格的支撑同样保持。

最终得到精确目标主列和相邻N/P助手F。无C列、没有间隙的列、多处间隙及不同落点均按同一过程处理。必要性已由第1节给出，因此：

`存在相邻N/P助手使主列可制作 ⇔ A`，适用于偶数n≥6、H≥2。

这些参数只影响辅助结构的层位与方向，不增加构造类别；完整中间图形仍由同一参数化构造给出。

例如九层主列`-N-CN-N-C`满足A，其中两个来源映射为2→1、7→6。准备主列为`CCNCNCCNC`；F为`NNPNNNNPN`；A和E均为`NCNNNNCNN`。两处近支撑分别留下第0层和第5层作为落点下方障碍。一次释放让两格N分别回到第1、6层，不需要为这个九层组合增加模板。

### 7. 循环支撑按结构判断

两列角中的同层非针格必互相连接，因此两个不同非针组的高度区间不重叠。不同非针组之间的直接支撑只能向更低区间；通过一串针到达另一个非针组时，也只能到更低区间。因此，两列支撑环只能从某个非针组G，经同列一串针，再回到G。

若针链长k≥1，位于a至b层，G在该列同时占a−1和b+1层。G要绕过这些针连接上下端点，只能沿另一列跨过每个层间；竖直连接只存在于C/C之间。因此另一列必须有从a−1到b+1的k+2颗连续C。反之，这个C脊和同组上下端点恰好组成`G→针链→G`，可以形成悬空支撑。端点必须为非针；在可制作列中，上端点进一步由Q限制为N。

k=1就是三颗连续C对应一根针，局部结构如下（上方为较高层，底端N/C与顶端N属于右侧晶体连接的同一组）：

```text
N    C
P    C
N/C  C
```

这个必要性只针对两列中的这种支撑环，不是所有宽图形的通用三C下界。三列以上允许无针环，见宽半形构造。

一般支撑判定仍使用原始最大粘连组：每个非地面组必须至少有一个不同组的直接阻挡。也可反复剔除既不触地、又没有剩余支撑边的组；全部组都保留当且仅当图形静止。环是合法的保留原因，不能用“都能到地面”的条件替换。

### 8. 指定两列角，包括含晶体助手

给定只占相邻两列的稳定目标T。在n≥6、任意H下，T可制作当且仅当两列各满足A。

必要性仍为列不变量。充分性分别用本页通用构造制造两根目标列，把N/P助手朝向目标外侧。用Swap保留两角完整列并拼合，然后用两个半面的交集切出目标两列。

中间去掉一侧助手时，T本身的地面或含针环支撑仍成立：两列非针组高度区间互不重叠，所以T的支撑环必含P；增加另一侧N/P助手只可能合并非针组，不能吞并针节点和含针环。最后去掉另一侧助手后，T稳定性保证不下落。两根助手都无C，整个拆助手过程不触发目标晶体融合删除。

这允许目标的另一列包含晶体，包括第7节的循环支撑结构。它不意味着含C助手可以随时删掉：上述证明把两根指定目标列都作为成品保留，只删额外生成的N/P助手。


## 文献章节 2：general/scaffold-halves.md

## 递归外侧脚手架：用同一个角程序制造多晶体列半形

设n=2k≥6、H≥2，目标半形T仅占q0至q(k−1)，所有目标列满足A，晶体供料在已确认范围内。以下给出逐列转交支撑的充分构造；允许含针环和无针环，不要求属于K。它覆盖原来“晶体只在一根边列”的脚手架方案，并在六象限覆盖旧稳定两列角入口。

### 1. 统一的剥离步骤

固定从左端剥离。对当前标准半形U：

1. 检查U自身的全部组静止。支撑环按最大静止集合保留，不能替换为地面可达检查。
2. 若U不含C，用通用逐层N/P程序制造，结束分解。
3. 否则记下q0列，保留q1至q(k−1)原格，在qk补一根H层全N柱，得到下一级脚手架V。
4. 把V旋转−1回标准半面，重复相同步骤。

每步只删除一根原目标列，并在另一端添加全N柱；固定方向不会再次删除新加柱，直到原目标的k列都已删除。所以至多k次剥离后必然没有C。中途任一半形不静止，这个方向失败；再从右端按对称过程尝试一次。右端版本删除q(k−1)、在q(n−1)补全N柱，再旋转+1归一化。

证明只需保留至多k个目标半形作为恢复参数，没有逐图形模板，也没有任意状态闭包或二叉分支树。失败仅表示两个固定方向均未覆盖，不表示目标不可制作。

### 2. 反向恢复的归纳证明

假设已经制造下一级脚手架V。把它旋回q1至qk的互补半面。

使用通用角构造制造所记q0列及q(n−1)的N/P助手，得到A。因为该列满足A，任意H都能取得真实基础料配方。A位于{q(k+1),…,q(n−1),q0}，与V互补。若原q0列为空，直接跳过A。

交换A与V。两份输入分别稳定，而且各自在被选半面以外没有格，预切不会改变它们。交换后，目标区域恰好是当前U；两个外侧助手q(n−1)、qk均只含N/P。随后半切保留q0至q(k−1)：

- 删除侧没有C，所以任何目标晶体融合分量都未被切断。
- 保留侧格位恰好为已检查静止的U，所以全部组不移动，包含无针环在内。

得到U的制造证书。由无C基例反向归纳，恢复全部阶段，最终制造T。右端版采用同样的互补半面与去助手步骤，不需要反射机器。

### 3. 原单边晶体方案被完整覆盖

原方案要求T稳定、C仅在左边列、其余N/P加右外侧全N柱后稳定。新过程第一步恰生成那个普通脚手架，第二步即进入无C基例；恢复步骤相同。右边列同理。因此原H及整个H_k族无需另一条制造路径，原通用H/V配方的加工树保持。

新过程进一步允许脚手架自身含C，只要继续转交后能到达普通基例。每次恢复仍调用同一角制造、交换及去助手程序。

### 4. 六象限旧两列角入口也被覆盖

三列半形中，若目标只占q0/q1，则先从空的右边q2剥离。下一级是左侧全N柱加原两列目标，归一化后仍为三列。

给稳定两列角外加一根全N边柱，不会合并两个旧非针组：每颗新N只在同一层接触一个旧列，竖直N不粘连。因此旧组间支撑及含针环保持；新柱自身由地面逐层支撑，全部格静止。

继续从右端剥离原q1后，剩下原q0及两根全N柱。所有非针主列格都在同层接到相邻全N柱，P的正下支撑由列A保证，故仍静止。再剥离原q0就进入全N基例。q1/q2目标从左端开始，单列目标也包含在内。

所以任意H下，六象限稳定相邻两列且各列A的目标都由这个过程覆盖。`Constructor.half`在六象限删除独立pair分支，统一使用`supported_half`。四象限仍使用它自己的完整半形构造；八象限以上的内部两列可能两端都有空列，尚未证明固定单方向剥离覆盖全部pair，因此保留原pair入口，不无证删掉已知覆盖。

#### 共用两列扫描，省去后续三列分组

六象限第一次剥离以后，三列中的一根边列必为完整N柱。另两列仍满足列A。把它们暂看成两列网格：每颗外侧N只接触一列的同层格，不能合并两个旧非针组；旧两列非针组的高度区间互不重叠。

外侧N柱与各旧组连接后的组仍按高度区间排列。每组在N柱的最低占用行，若不触地，其正下方N必属于更低区间或独立单层N，故所有与该柱相接的旧非针组都取得地面支撑。没有相接的旧组则必须继续满足原来的直接阻挡条件，针仍要求自身正下方非空。

因此沿用`stable_half`的层区间扫描，只需把“该区间包含靠助手侧的非针格”加入支撑标志，就与完整三列静止判定等价。实现参数为`supported_column=0/1`；默认None保持原两列判据。六象限根目标仍作一次完整支撑检查，两个剥离方向的后续阶段复用两列扫描，不再求三列组图。没有借此取消任何真实支撑条件。

### 5. 含两根晶体列的无针环

取五层三列半形W：

```text
层号   q0 q1 q2
  4     C  N  N
  3     C  .  C
  2     C  N  N
  1     .  .  .
  0     N  .  .
```

它把H内侧N改成C。q0三C和上下N帽构成外组G，q2第3层C是另一个组B；G的上帽被B阻挡，B又被G的下帽阻挡。两组互相支撑，不需要针，也不通向地面。各列满足A。

从左剥离q0后，q2的N/C/N接到新增全N柱，q1的两个帽格也通过q2支撑，脚手架静止。再剥离q1，剩下q2目标列及全N柱，仍静止；最后剥离q2进入普通基例。由同一反向流程取得W，再拼两份W得到完整多晶体列双环。

这个输入没有专用代码分支。原单边C条件无法接受W；新过程通过三次同一支撑转交完成。两半拼出的完整目标可以不稳定，最后交换后直接输出，不额外结算重力。


## 文献章节 3：general/addition-components.md

## 按接地来源与潜在粘合扩大堆叠约化范围

适用于偶数n≥2、H≥2的既有局部规则，层号从0开始。定义可静态检查的充分条件K_add，使任意复杂Stack在此范围内都可改用基础块序列，且结果仍在K_add。

这个范围包含K和受列顶保护的普通块范围K_top，还包含所有“非空列具有相同列顶”的稳定图形。因此六象限非K半形H及一般H_k也可以逐层追加。K_add仍不是完整可制作性判据，其外的下料保留真实复杂Stack。

### 1. 先分清旧图的接地组

对D建立最大粘连组及向下支撑图。G₀为能够沿支撑边到达地面的全部组；其余组记为Q。一个Q组不可能有通向G₀的支撑边，否则它本来就属于G₀。

原格位不动时，G₀中的支撑路径在任何非针组合并后都仍通向地面。若新N把一个Q组粘到G₀，它也取得地面路径。这种粘合不会导致该组失稳。

记h_D(q)为列顶，空列为−1。所有允许的新格位构成

`E = {(z,q) : h_D(q)<z<H}`。

后文分析只允许在E添加N/P，不删除或移动原D。

### 2. 哪些新块可能只靠悬空旧组托住

在E内标记集合R：

1. 某列非空且其最高格属于Q时，把该格正上方的一格加入种子；超出H的不加。
2. 从种子只沿“向上同列”及“同层环上相邻列”的E内边传播，不向下传播。

R是可能由非接地旧组间接支撑的新块区域；它只是几何上界，不是实际可制造的新料。

设一次Stack或逐块追加已经产生落稳的新N/P块，每块至少有一个直接下方支撑。沿新块之间的支撑链向下：新块都是单层，层号严格下降，最终到地面或某个旧D格。首次碰到旧格时，它必为该列旧列顶，因为新格不能插入列顶下方。

如果这条链终止于Q，反向看它就是从上述种子出发、沿向上边和新N块内部水平边到当前块的路径，完全包含于R。因此：

> 一个新块若不在R内，就必有一条经新块到地面或G₀的支撑路径，因而取得地面支撑。

每个N块要么全在R，要么全不在R，因为其水平连接都在E中；单P也无此歧义。R内的块仍可能有其他地面路径，不能反向判定它一定悬空。实际新P只会减少水平连接，用N的传播规则作上界是安全的。

这些地面路径在输出重新分组后继续存在。它们终止于地面，不会像悬空环那样因全部收缩而消失。

#### 危险区域只需每列一个高度

E在每列都是向上连续的区间；R也向上封闭。因此记a_q为R在该列的最低层，没有R时取H。种子列初始化a_q=h_D(q)+1，其余列初始化H。沿相邻列q→r传播，更新：

`a_r ← min(a_r, max(a_q, h_D(r)+1))`。

它表示源列已经能到达的最低高度，以及进入目标列空区所需的最低高度，两者取大值。任意传播路径的最低可达高度，就是起点种子高度与途中各列空区下界的最大值。删去路径中的回路不会增加这个最大值，故只需考虑环上的简单路径，方向只有顺时针与逆时针。

选择初始a最小的列作为起点，从它顺时针扫一圈，再逆时针扫一圈，共2n次边松弛，即取得全部a_q。起点值已是全局最小种子高度，不可能再降低；任何越过起点的单向路径，都可以从这个更低或等高的起点重新开始，所得高度不会更差。其余单向简单路径在相应一圈中按顺序被处理。中间借用已传播值仍对应真实路径，不能产生过低的高度。故危险区域阶段只需O(n)时间、O(n)存储，与H无关；后续按z≥a_q读取R即可。

### 3. 只对未保证接地的新连接分组

再定义X：E中与某个G₀的N/C格水平相邻的位置。若实际在X放入N，它会直接粘到接地旧组，因此这个N必接地；P不粘连，不作同样判断。建立仅供分析的网格V：

- 保留D中Q组的全部原格及材料。
- 在R\X的每个位置放N。
- 不放G₀的格，也不填其他新位置。

仅调用粘连分组，不调用重力或结晶。V不作为免费物料，也不要求可制造或稳定。每个原Q组完整落在V的某个组内，以其编号记为λ。

还可省掉全部高于原图最高格的虚拟N。记原图实际高度为L≤H，这些N在第L层及以上，没有同层原格，也不能与下方C竖直粘连，所以不会连接任何原Q组。R传播又不向下，因此只求0至L−1内的R，使用L作为无标记哨兵，就与完整H范围在原组上的λ完全相同。K_add成员判定由原图决定，不随允许的额外空白高度增大而改变；分析不为未占用的高层分配分析格。

若实际输出中两个Q组通过新N粘合，有两种情况：

- 新粘合组包含G₀、E\R中的新N块，或X中的新N。由前两节或直接水平粘连，它取得地面路径。
- 新粘合组不包含这些格。全部新N连接都来自R\X，所以被它合并的旧组只能具有同一个λ。新P不参与连接，即使位于X也不能合并原组。

因此，仍然没有地面路径的合并，只能发生在相同λ内部。原P始终独立，不可能与其他原组同λ。

### 4. K_add的图判据

使用原Q组之间的支撑图，不使用V的支撑图。称一个原支撑环受保护，当它包含至少两个不同λ的组。

定义K_add：每个Q组都能沿原支撑边到达某个受保护环；G₀中的组已通地面，无需附加条件。

等价检查为：求Q支撑图的强连通分量，其凝聚图的每个汇点分量都必须包含至少两个λ。每个有限有向图节点都能到达汇点；同一强连通分量若含不同λ，就有跨这两种λ的有向环。单节点、无外部支撑的浮空组只有一个λ，会被拒绝。Q为空时条件成立。

这个条件保证D稳定。不能改为“V稳定”或“把所有可能合并组先收缩后稳定”：一次最大合并可能把某个失稳片段与有外部支撑的片段合在一起，掩盖中途失败。这里保留原支撑图，并要求其环跨越不能无接地合并的边界。

#### 不求强连通分量的等价检查

把Q中至少有一条支撑边指向不同λ的组作为种子，沿原支撑图反向传播。全部Q都被覆盖，当且仅当K_add成立。

必要性：每个受保护环含跨λ边，通向它的组也能到达这种边的起点。充分性：若反向传播覆盖全部Q，则每个汇点强连通分量中的节点都能到达一个跨λ边的起点；由于汇点没有出边，这条跨λ边也在分量内部，所以该分量至少含两个λ，满足上面的等价判据。

判据只需标签不等比较和一次反向可达传播，不需要把强连通分量显式构造出来；数学证明中的汇点分量只用于说明充分性。

### 5. 支撑环不会被追加破坏

D∈K_add时稳定，第一次Stack中旧D不动。写回新接触后，取一个原受保护环：

- 若环的任一部分取得了地面路径，其余部分沿原环边也能到达地面。
- 若环上没有部分接地，则第3节保证合并只能发生在同λ内。环经过至少两种λ，不能全部收缩成一个节点；删除内部边后仍有非平凡有向环。

原来通向该环的路径继续有效。新块沿严格向下的支撑链到旧组或地面，也取得支撑。因此输出稳定，原格保持原位。

还需确认下一次仍可使用同一条件。设扩展结果为D'：

1. 原接地组和不在R中的新块仍接地。因此D'的非接地旧格只能来自原Q，非接地新格只能来自R。
2. 若D'某列顶仍非接地，它若为原列顶，其上方原本就是R种子；若为新格，它在R内，其上方也已由向上传播包含。D'的新空区又是E的子集，所以重新计算的R'⊆R。
3. 旧接地组继续接地，新空区缩小，故X'在新空区内仍包含原X。新非接地N只可能位于R\X，V'中新填N也只可能在R'\X'⊆R\X。去掉D'接地组后，V'的非针粘边都是原V粘边的子集；位于原X的新非接地P可以作为额外孤立节点出现，但不连接任何原组。因此不同旧λ不会在V'中合并。
4. 仍未接地的原受保护环及到它的路径，继续跨至少两个新潜在分组；新非接地组也有通向旧非接地组的支撑路径。

于是D'仍属于K_add，归纳可继续。实际中新增加的地面路径只会加强这个证书，不会扩大危险区域。

### 6. 复杂Stack的基础块替换

对D∈K_add，任意真实Stack(D,U)保持旧D；最终新增Δ只含N/P、严格位于旧列顶以上、每块有直接下方支撑。这些必要事实沿用通用堆叠证明。

按目标层号递增，逐块加入Δ。第5节保证每步仍在K_add，列顶公式保证每块准确停在目标位置。因此整条基础块链取得同一个原始输出，而无需保留U的制造历史。

同层可以合为一份单层料，至多H次Stack；结构逐块上料域仍为n²+1。完整闭包中可对K_add下料改用这些基础块，对其余下料保持全部真实上料。由制造树归纳，每个删去的复杂Stack都有有限基础链替代，故保持最终闭包；不保证同一轮出现，也不保证配方更短。

### 7. 包含K、K_top及等列顶的稳定图形

K中的非接地支撑环含P。P在V中独立，环中另一个组与它不同λ，所以该环受保护。

K_top的额外锚组是受列顶保护的纯N块。它在V中没有新增成员：外侧邻列的列顶不低于块所在层，那里不属于E；N没有竖直粘边。含这个锚组的环也跨至少两个λ。故K⊆K_top⊆K_add。

现在设D稳定，全部非空列的列顶都等于t。Q列顶产生的R种子全在t+1层，传播只向上或水平，所以R只占t以上。D的原格全在t及以下，新增N又不能向下与旧C竖直粘连，因此V中每个原Q组都有独立λ。

稳定性保证每个非接地组沿支撑边到某个至少两节点的环，这些环自然跨λ。所以：

> 任意非空、稳定、所有非空列等列顶的图形，都属于K_add。

这一结论不要求图形可制作；应用于真实制造时仍需起点的制造凭据。宽半形H_k已经对n=2k≥6、H≥5提供该凭据：全部非空列顶为4，图形稳定但不属于K。因此K_add在这些参数的可制作集合内严格大于K。

特别地，六象限H可安全使用基础块/逐层追加。V本身不稳定，不能通过本判据；八象限复杂堆叠反例的下料列顶不齐，其暴露的内块仍可被新N无接地粘合，所以没有被此定理错误约化。


## 文献章节 4：general/conditional-stacking.md

## K下料的通用堆叠化简

对偶数 n≥2、层数上限 H≥2，沿用半切、单象限旋转及一次加工内不合并新接触的参数化规则。K 表示每个最大粘连组都能沿直接支撑边到达地面，或到达包含顶针的支撑环。本文不假定全部可制造状态属于 K。

### 1. K在新增基础块下闭合

原格位不动时，加入普通格只会收缩一些非针粘连组；顶针节点保持独立。通向地面的路径在收缩后仍通地面。包含针的支撑环不能被收缩成一个节点：针与支撑它、被它支撑的其他组始终分离，因此仍有经过该针的非平凡闭合路径。原来通向该环的组仍有支撑。

一个新落稳的普通连通块或单针，必在地面，或直接支撑于旧图。即使随后与旧组合并，上一段的收缩论证仍保留其支撑。因此结果仍属于 K，原格位不移、不删。论证未使用象限数或五层上限。

### 2. 任意上料可以换成最终保留的基础块

上料整体提高 H+1 层，起初与 D 分离。D 的组原本稳定；新接触不会在本次结算中合并旧组，所以 D 始终不动。

上料晶体若随组开始下落就消失；若始终不动，就留在上限外并被截掉。因此最终新增格 Δ 只含普通格或针。含晶体的移动组在第一次下落时拆成水平普通块及单针，此时仍在 D 上方。每个保留下来的块均不能穿过原列顶，且最终至少有一格位于地面或紧贴下方保留格。下方格的高度更低，不会因为最终截高而被删。

设 h_D(q) 为 D 的列顶人类层号，空列为0。T 能从 D∈K 仅以基础块追加取得，当且仅当：

1. D逐格包含于T，标签不变。
2. Δ=T\D不含晶体。
3. 每个新增格(z,q)均满足z>h_D(q)。
4. 只在Δ内部按层划分普通连通块，针单独成块；每块在地面，或至少有一格正下方在T中非空。

必要性如上。充分性：按目标层号递增加入每个块；此前同列全部格低于目标层，而第4项给出目标层正下方的支撑。块的落点公式

`z = 1 + max(h_current(q), q属于该块)`

使它恰好停在目标层。每步后仍在K，归纳得到T。至多nH个有效块；同一目标层的块列集合互斥，可合并为一份无晶体单层上料，所以也有至多H次Stack的实现。零新增格使用零次操作。

这里仅用最终保留块；不能把任意上料的晶体预先删除，再把剩余全部格堆入。原上料的支撑环可能让某些普通格也留在上限外，最后一同截掉。

### 3. 结构目录的上料域从整个目录缩到n²+1

擦除普通部件及颜色，只保留N/P/C/空结构。基础块只有：

- 环上长度1到n−1的连续普通区间：每个长度有n个起点，共n(n−1)种。
- 整环普通块：1种。
- 每列一个单针：n种。

合计 n(n−1)+1+n=n²+1。四象限17种，六象限37种。任何任意上料堆叠输出，都可由第2节的有限序列取得；序列每一步恰使用上述某一种结构基础块。目标普通标签沿新增格回填基础料即可，不要求所有普通格都使用Cu。

在有限配方目录中替换Stack规则：

```text
若D属于K：对每种连续普通基础块或单针b，加入Stack(D,b)
若D不属于K：对旧目录每个U，加入真实Stack(D,U)
```

其他Rotate/Pin/Cut/Swap及种子规则保持。所有新记录仍只引用旧轮中的D与初始基础料；非K分支引用旧轮D/U。

可靠性：每条边仍是一个真实加工，基础块均为合法种子。

完备性：对原制造树归纳。非Stack节点或非K下料节点保留原操作。K下料的Stack节点换成第2节的有限基础块链；链的起点可由归纳制造，每个后继会在后续某轮加入。不能声称替换后的输出仍在原来同一轮出现，但有限轮出现足以保证最终闭包相同。有限状态空间和单调增长仍保证终止，停稳后缺失目标才可判不可制造。

若旧目录有M项，其中M_K项属于K，则每轮Stack候选上界从M²变为

`M_K·(n²+1) + (M−M_K)·M`。

这只是Stack候选数，不包含Swap、种子或全部状态规模。没有证明M_K占比，也没有证明六象限整体已实用。六象限非K半形及一般复杂堆叠反例必须保留，见非K半形、八象限反例。


## 文献章节 5：general/settled-stacking.md

## 一次结算后进入安全范围的堆叠约化

适用于偶数n≥2、制造上限H≥2的既有规则，F表示一次重新分组、重力及截高。沿用精确堆叠摘要与安全追加范围K_add。本页允许原下料D不稳定，也不把F(D)免费当作实体输入。

### 1. 扩大可以省去任意上料搜索的下料范围

定义K_pre为满足F(D)非空且F(D)∈K_add的可制作下料。K_add中的图形稳定，因此K_add⊆K_pre。对D∈K_pre及任意可制作上料U，记D₀=F(D)。精确摘要给出

`Stack(D,U) = Evaluate(D₀, P(U))`。

D₀∈K_add，所以F(D₀)=D₀，再用同一等式得到

`Stack(D,U) = Stack(D₀,U)`。

该等式只比较输出。要把右边用作真实制造，还须取得D₀：取全针基础层，结晶为纯C单层Z，再Stack(D,Z)。Z抬高后没有地面或悬空支撑环，所有C移动即碎，不贡献N/P；结果正是F(D)=D₀。准备Z为两步，触发Stack为一步。

随后由K_add定理，把Stack(D₀,U)改为最终新增N/P的逐块或逐层追加，至多H个非空层。每次的中间物品仍在K_add。故原来的任意一次Stack可改为一次真实结算触发及至多H次基础层追加；如果D本来已在K_add，直接省掉触发步骤。

本结论不要求最终新增格来自容易制造的原上料，也不需要构造原U。只用目标新增格的基础供料。它保持输出及标签，未证明配方最短。

### 2. 严格扩大：六象限不稳定输出V

六象限V是已给出实体制造树的五层图形。其高处所有C和N在重新分组后成为一个没有下方支撑的组，所以V不稳定、不属于K_add。

第一次结算使全部高处C碎裂。剩余N按各水平块下落：q0、q3原地面N保持；原第三层的q1/q2、q4/q5两块落到地面；原第四层q2、q5单格落到第1层；原第五层q1/q2、q4/q5两块落到第2层。因此

`F(V) = CuCuCuCuCuCu:----Cu----Cu:--CuCu--CuCu`。

它无C，所有N块都有直接向下的支撑，层号沿支撑严格下降并终止于地面。因此F(V)∈K⊆K_add，V∈K_pre。该推广覆盖一个旧判据必须拒绝的真实下料。

原V仍保留在可制作目录中，作为Cut、Pin、Swap的输入及目标时不作替换。只在为它生成Stack后继时应用本页规则。

### 3. 闭包算法与候选数量

`stack_successors`保持原接口，按以下顺序生成合法上料及其输出：

1. D∈K_add：保留原有连续普通块和单针域，共至多n²+1项。
2. D∉K_add，但D₀=F(D)非空、D₀∈K_add：只生成一项`(Z,D₀)`，Z为纯红晶体单层。
3. 其余下料：保留全部已知真实上料，不增加否定条件。

Z属于完整目录的显式紧图形种子，也有两步基础配方。因此新增后继可靠。完备性按制造树归纳：任何被省去的Stack边都能换成本页的有限基础链；D₀进入目录后，由原K_add后继逐步产生同一输出。最终闭包保持，首次出现轮数及最短配方不保证保持。

设旧快照有M个图形，其中M_safe个在K_add，另外M_pre个一次结算后进入K_add。六象限每轮Stack后继数量的上界由

`37 M_safe + (M − M_safe) M`

变为

`37 M_safe + M_pre + (M − M_safe − M_pre) M`。

每个新增适用下料的该轮上料分支从M项变为1项；后续基础追加需要其他轮。这不是完整算法运行时间的同倍改善，也没有证明M_pre占比。


## 文献章节 6：6q5l/non-k-half.md

## 六象限五层：无针悬空环与不稳定的可制作输出

本页给出从合法基础原料出发、全过程输入和输出都不超过五层的构造：半切可以把 K 中的可制作图形变成不属于 K 的三列半形；两份这样的半形交换拼合，还会得到可制作但不稳定的输出。因此四象限的 R⊆K、全局稳定性及其据此取得的约化不能直接移植。

采用本目录模型：六列按环相邻，允许单象限旋转，半切保留连续三列，基础输入为任意无晶体单层。N/P/C 分别表示普通块、针和晶体。层号从底部 1 开始；以下是源码规则下的人工构造，没有执行仿真或游戏。

### 1. 独立原料列

分别制造以下三列，其他列全空：

| 列 | 从底到顶的内容 |
|---|---|
| q0 | C N C C C |
| q1 | C |
| q5 | N P N N N |

N/P 列逐格堆叠。任意连续 N/C 列可用五列辅助 N，逐层加入目标 N 或 P、在 P 层结晶取得；再半切保留 `{q4,q5,q0}` 和 `{q0,q1,q2}`，交集仅为 q0。辅助列没有晶体，目标柱连续触地，两刀不会改变目标柱。旋转可取得其他朝向。

先交换拼合 q0、q1：把两份输入分别保留在 `{q4,q5,q0}` 和 `{q1,q2,q3}` 一侧。再把得到的 q0/q1 片段保留在 `{q0,q1,q2}`，与独立 q5 列保留在 `{q3,q4,q5}` 拼合。得到 S：

```text
       q0 q1 q2 q3 q4 q5
L5      C  .  .  .  .  N
L4      C  .  .  .  .  N
L3      C  .  .  .  .  N
L2      N  .  .  .  .  P
L1      C  C  .  .  .  N
```

所需切割轴由共同旋转输入、交换后旋转回去取得；不要求机器有额外切割模式。S 的各组均能沿支撑到地面，故 S∈K。

### 2. 第一次切割：留下悬空晶体柱及辅助针列

对 S 半切保留 `{q4,q5,q0}`。q1 的地面 C 被切掉，同一融合分量中的 q0 地面 C 连带消失。q0 第三至第五层晶体被第二层 N 隔开，不属于该融合分量。

q0 第二层 N 与 q5 同层 P 不粘连，失去下方 C 后落到地面。上方晶体柱及 q5 第三至第五层 N 属于一个组，被 q5 第二层 P 阻挡；P 又由 q5 地面 N 支撑。得到 A：

```text
       q0 q1 q2 q3 q4 q5
L5      C  .  .  .  .  N
L4      C  .  .  .  .  N
L3      C  .  .  .  .  N
L2      .  .  .  .  .  P
L1      N  .  .  .  .  N
```

A 是占据 `{q4,q5,q0}` 的可制作半形，仍属于 K。晶体下方的空第二层没有通过把保留晶体抬高再落下取得。

### 3. 制造另一半并拼合

仅用无晶体基础块依次制造 B：

1. q3 单格 N 作为第一层原料。
2. 再堆 q3 单格 N，落到第二层。
3. 堆 q1、q2、q3 三格相连 N，因 q3 列顶为 2，落到第三层。
4. 堆 q2 单格 N，落到第四层。
5. 堆 q1、q2 两格相连 N，因 q2 列顶为 4，落到第五层。

B 占据 `{q1,q2,q3}`，与 A 的半面互补。合法交换拼合得到 U：

```text
       q0 q1 q2 q3 q4 q5
L5      C  N  N  .  .  N
L4      C  .  N  .  .  N
L3      C  N  N  N  .  N
L2      .  .  .  N  .  P
L1      N  .  .  N  .  N
```

第三、第五层的帽形 N 和 q0 晶体柱属于大组 G；第四层 q2 的 N 是独立组 B0。G 与 B0 互相阻挡，但 G 同时通过 q5 的针列及 q3 的普通列取得地面支撑。因此 U∈K。

### 4. 第二次切割：得到非 K 半形

对 U 半切保留 `{q0,q1,q2}`。被切掉的 q3、q4、q5 没有晶体，不引起任何晶体融合删除。留下：

```text
       q0 q1 q2
L5      C  N  N
L4      C  .  N
L3      C  N  N
L2      .  .  .
L1      N  .  .
```

记此半形为 H。其非地面组只有：

- G：q0 第三至第五层晶体，加上第三、第五层 q1/q2 的 N。
- B0：第四层 q2 的单格 N。

G 的第五层 q2 格被 B0 阻挡；B0 被 G 的第三层 q2 格阻挡。两者互相阻挡，均不下落，晶体全部保留。地面 q0 的 N 与 G 之间隔着空第二层，不提供直接支撑。

因此 H 稳定且可制作，但 G↔B0 的支撑环不经过地面，也没有顶针，H∉K。这给出：

```text
U ∈ R₆,₅ ∩ K
Cut(U) = H ∈ R₆,₅ \ K
```

制造中最高原料和中间结果均为五层；没有借用更高层上限。它与一般模型的八象限八层反例是不同构造。

### 5. 再拼合两份半形：得到可制作但不稳定的输出

分别制造 H 和旋转三个象限的 H′。H 占 q0～q2，H′ 占 q3～q5。交换器先分别切出两侧：各自只切掉空列，原支撑环仍在，两个半形均保持原位。然后拼合，并且不再执行重力，得到 V：

```text
       q0 q1 q2 q3 q4 q5
L5      C  N  N  C  N  N
L4      C  .  N  C  .  N
L3      C  N  N  C  N  N
L2      .  .  .  .  .  .
L1      N  .  .  N  .  .
```

第三、第五层的跨边界接触把两个外组 G、G′ 粘在一起；第四层 q2 的内块接触 q3 晶体，q5 的内块接触 q0 晶体，所以两个内块也被吸收。按 V 的当前格位重新分组，第三至第五层全部成为一个非针组。

这个组最低在第三层，第二层全空，没有地面格，也没有任何外部直接阻挡。因此下一次触发重力时它必开始下降，所有晶体随即碎裂。V 是交换器的合法非空输出，却在重新分组的意义下不稳定。

这独立证明了六象限五层的“全部可制作图形稳定”为假。不能在交换输出后擅自增加一次重力，也不能把不稳定格位从可制作目录中排除。

### 6. 对六象限合成的约束

上面的两个构造分别否定六象限五层中的 R⊆K、半切输出必属于 K，以及全部可制作输出稳定。它们没有证明每个非 K 下料都不能拆分堆叠；这里只撤回四象限全局约化的适用依据。

算法若把 K 或稳定性当作全部可制作目标的必要条件，就会错误拒绝 H 或 V。下一次加工对 V 重新分组并碎晶，也使“可制作下料始终原位保留”的全局假设直接失败。

六象限统一合成算法因此保留真实双输入堆叠和原始操作输出，不按 K 或重新分组稳定性筛除状态。这个选择有明确的合法反例依据。


## 文献章节 7：6q5l/synthesis.md

## 六象限五层的统一合成算法与覆盖定理

本页给出第二套完整合成方法：**保存精确操作输出的分轮配方目录**。对任意非空六象限五层目标，算法有限终止；目标可制作时输出合法制造树，不可制作时返回否定结论。

六象限已经存在可制作但不属于 K 的半形，以及可制作但不稳定的拼合输出。因此这里保留真实双输入堆叠，允许不稳定中间状态，不能把四象限的基础堆叠约化作为全局规则。这个方法的代价很高；本页证明覆盖与终止，不声称它适合直接用于实时 TMAM 控制。

### 1. 操作实例与范围

取六列、五层，列按环相邻，允许单象限旋转。基础输入是任意无晶体单层，普通种类与合法颜色不影响结构物理。空物品不作为实体输入。

以下定理适用于将 `shapePartCount=6`、`maxShapeLayers=5` 传入这组操作的模型。它不声称已核验某个具体存档、Mod 或原料供给系统；本文只讨论实体制造操作。

### 2. 不依赖 K 的精确操作计算

#### 有界重力计算

将静止组与水平落点证明用于六列：证明只使用同列不穿透、晶体首次下降即消失、其他格不因下落消失、下落中只拆组不合组，没有使用“两列半形”或“四列三层”的几何性质。

在重力开始前的活组支撑图上，反复删除无地面、也没有指向剩余组的直接支撑边的组。最后剩余 F 恰为始终未移动的组；它包含任意有向支撑环，不要求环内有针。其余组第一次移动时晶体全部碎裂，N/P 分成水平块。

按这些块的初始层号递增处理。块 b 的落点为 1 加以下高度的最大值（空集取 0）：它占据列中、初始位置下方的 F 固定格高度；所有更低来源、与它共享列的移动块的最终高度。已移动格不能成为从未移动格的新阻挡，保留格的列内次序不能颠倒，所以这个公式与逐组下落等价。

这个论证也适用于临时高度超过五层的初始格位。五层上限只在全部下落结束后执行一次截高；截高之后不再下落、不再按晶体融合删除。

#### 操作表

| 操作 | 对非空输入的精确计算 |
|---|---|
| 旋转 | 置换整列，不执行重力 |
| 半切 | 在完整输入上记录晶体融合分量；保留三列；跨切线的融合分量在保留侧也删除；执行上述一次重力 |
| 交换 | 对两输入分别按半切结算，交换互补半面，折叠为格位输出；拼接后不再执行重力 |
| 顶针 | 删除原第五层及其触及融合分量中的低层晶体；原第一至第四层提高一层；按删除前原第一层占用补地面针；执行一次重力 |
| 堆叠 Stack(D,U) | 下料 D 保持初始位置，上料 U 所有格提高六层，再对合并格位执行一次重力，最后删除高于第五层的格；不预删上料晶体 |

一次堆叠最多有六十个初始格，临时高度最高十一层。重力中的活格只下降或消失，所以局部计算有限。新接触仅在下次需要重力的操作开始时重新分组，不能在当前输出后补一次稳定化。

这些定义与静态重读的 `ShapeOperationStack/PushPin/Cut/SwapHalves/Rotate` 及 `ShapeLogic.Collapse` 调用顺序对应。局部计算本身可以写成代码，但本页没有通过执行模拟来取得结论。

### 3. 显式可制造种子及颜色

结构状态是六列五行的 N/P/C/空编码，固定地面坐标，只补顶部空行，不删除空底层或中间层。非空编码全集 U₆ 的规模为：

```text
N₆ = |U₆| = 4^30 − 1 = 2^60 − 1
```

种子集合 B₆ 包括所有非空无晶体基础单层，以及所有高度 1～5、每格均为 N/C 的紧图形。

紧图形不是天然原料，其配方如下：分别制造每根目标柱，另五列填辅助 N；逐层加入目标 N 或 P，在目标为 P 的层结晶，并指定需要的晶体颜色。已完成的 N/C 不受影响。完成后用两个三列半面相交于目标单列的切割切出连续柱：例如 q0 用 `{q4,q5,q0}` 和 `{q0,q1,q2}`。辅助列无晶体，目标柱连续触地，切出不碎裂、不下落。

将相邻柱拼成长度至多三的片段，再拼成两个三列半形，最后交换合并。追加新柱时选切线把已有连续片段与新柱分置两侧；另一条切线位于片段之外。这样每次预先半切只去掉空列，已拼部分不被拆开。故每个紧图形种子有合法有限配方，全过程不超过五层。

任意结晶输出都是紧图形，可以用上述独立配方代替它及此前历史。这消除了搜索中对结晶前历史的依赖。普通染色不改变结构，可在最终制造树中向来源基础料传递标签；晶体标签在紧图形种子处逐格恢复。两份输入的标签分别赋给两份物品，不要求一份实物同时满足不同标签。

因此可在有限结构全集上推导；结论仍覆盖所有允许的普通种类及合法配色。

### 4. 分轮目录与目标合成程序

R₀=B₆，并为每个种子记录第 3 节的具体配方。定义：

```text
Rᵢ₊₁ = Rᵢ
       ∪ {Rotate(D), Pin(D), Cut_left(D), Cut_right(D) : D∈Rᵢ}
       ∪ {Stack(D,U), Swap_1(D,U), Swap_2(D,U) : D,U∈Rᵢ}
```

所有非空输出按原始格位写入目录；旋转可取 +1 即可生成全部朝向，也可直接使用全部六个净旋转。每轮只读取旧快照 Rᵢ。对每个第一次出现的编码，记录操作名、参数和一个或两个旧目录输入，称为它的配方记录。

必须保留的实现规则：

- Stack先用K_add条件化简：通过判据的下料使用37种连续普通块或单针；原下料失败但一次结算后进入K_add时，只生成纯C触发上料，下一轮从结算结果继续基础追加；其余下料保留全部真实上料。这些替换保持最终闭包，不保证同一轮出现相同状态。Swap保持精确操作或使用带原输入的半形凭据。
- 不按 K 或全图稳定性筛除状态。反例中的 H 和 V均属于必须保留的状态。
- 不在操作后增加重力、删空底层，或把原始输出换成另一个稳定图形。
- 空输出只表示该出口没有物品，不加入非空目录，不接入后续机器。

合成程序如下：

```text
Synthesize6(T):
    preserve coordinates, erase ordinary kinds and colors
    initialize R with all explicit seeds and their recipes
    if T already has a recipe: return ExpandAndLabel(T)
    repeat:
        old := frozen snapshot of R
        apply every listed unary operation to every member of old
        apply every listed binary operation to every ordered pair of old
        record each new nonempty output with parents from old
        if T has appeared: return ExpandAndLabel(T)
        if no new output appeared: return NotManufacturable
```

ExpandAndLabel 按配方记录递归生产输入物品，执行记录的实体操作并选择所需出口。种子展开为基础原料加工。标签从目标向来源回填，在紧图形处使用逐列配色宏。每个共享子配方需要几份物品就生产几份。

此算法可以按目标提前返回；证明不要求先对所有目标分别执行一遍。其全覆盖性由下节的制造树归纳给出。

### 5. 完整证明

#### 有限终止

Rᵢ 单调增加且包含于 U₆。每个增长轮至少新增一个编码，最多 N₆ 个编码；首次没有增长后，按相同规则以后也不会增长。因此不超过 N₆ 次扩展就停止。每轮的操作种类、参数及输入对都有限，局部操作计算有限，故每轮也终止。

配方记录只引用更早轮数的输入，展开时轮数严格下降，所以不会产生循环制造依赖。树可能很大，但有限。有限的每格标签回填不会影响终止。

#### 可靠性

R₀ 的成员都有第 3 节的合法制造树。假设 Rᵢ 中每个成员可制作，Rᵢ₊₁ 新成员只由合法输入执行一个真实实体操作取得，所以新成员也可制作，并且记录的操作给出相应配方。按轮数归纳，目录没有不可制作的非空成员。

不稳定成员不破坏这项归纳：输入是原操作输出的实物，下一次加工按自身规则重建组并结算即可。游戏没有“物品在进入下一台机器前必须再次稳定”的额外前提。

#### 完备性

设 T 有任意有限合法制造树。擦除标签，把每个靠近根的结晶节点及其输入子树替换成结果紧图形的种子配方；染色节点在结构上省略。剩余树的叶子都在 R₀，内部节点只使用第 4 节列出的操作。

按这棵树的高度归纳：叶子出现在第 0 轮；一个或两个子结果都已出现时，某个后续轮会遍历该节点的真实操作及真实输入对，因此其输出也出现。二输出机器选择的两个出口均已列入规则。根 T 必在有限轮出现。

所以算法对每个可制作 T 必返回配方。若目录停稳仍无 T，却假设 T 可制作，上一段会推出 T 应出现在已封闭的目录中，矛盾；否定结果也正确。

#### 标签覆盖

物理连接、融合与下落不依赖普通种类或颜色。把最终标签沿保留格来源向基础叶子和紧图形种子传递，分别选择相应普通原料及逐格晶体颜色，就得到目标的完整标签。所有删除格的标签任取合法值。因此结构完备性提升为带合法标签的完备性。

综上：

> Synthesize6 对每个非空六象限五层目标有限终止；它返回合法制造树，当且仅当该目标可制作，且树的输出逐格等于目标。
