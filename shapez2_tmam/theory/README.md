## 阅读方法

I 是公用基础。II 解决四象限五层，III 研究参数化偶数象限，IV 研究重复结算和全局操作顺序。每篇正文保留所选原证明章节，并在章节标题中标明原始来源路径，便于回到九卷参考证明核对。

“未决”只表示论文中明确没有证明或证伪的命题，不等于缺少已给出的构造族或局部下界。
