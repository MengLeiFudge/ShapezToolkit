# TMAM 理论 IV 附录：交替工序约化

**摘要。**本文研究最后一次 Swap 后的 Pin/单层 Stack 工序。四象限中，无向下顶破的 Pin 可跨过 Stack 段，局部代价至多增加一次 Stack，且此界可达到。地面占用计数与 DDD 禁止定理进一步给出：以 Pin 开头、任意两次 Pin 之间都有 Stack 的唯一最短词至多含八次 Pin。对于六象限，连续三列的一次结算稳定定理保证真实半切输出稳定，并导出首个无向下顶破 Pin 的等长替代。一般偶数象限中，首个 Pin 的必要性还受跨半晶体删除与半面支撑约束。上述结论不依赖高度上限的具体数值；任意指定交替序列的全局存在性仍未解决。

## 1. 模型与命题的量词

固定四象限和高度上限 H≥2，层号从0开始。P、S 分别表示一次 Pin 和一次单层 Stack，N、C 表示普通格和晶体，材料顶针写作“针”。旋转吸收到起点与上料朝向。两个半形及上料可合法预制，准备过程与尾部共用 H。

起点 B 必须来自两份真实切后半形的最后一次 Swap。允许更换 B 和全部上料，代价只计该次 Swap 后的 P、S 次数。设目标 T 的最小总操作数为 d(T)。需要区分：

- **阶段必要性：**所有合法路线都不能绕过指定阶段。
- **唯一最短操作词：**所有长度为 d(T) 的路线具有相同的 P/S 词；来源与上料不要求唯一。
- **某条最短操作词：**只要求存在一条长度为 d(T) 的路线具有指定词，允许不同词并列最短。

本文的八次上界针对第二项。对第三项，产生同长度替代不足以排除原词。

对每次 Pin 的输入，定义两类事件：

- D：某列在 H−2、H−1 层同时为 C，融合删除会传播到顶层以下。
- L：没有这样的同列 CC。它仍可能删除最高层的孤立晶体分量，但不会向下传播晶体删除。

以下使用四个已有结论：[四象限全部可制作输出属于 K](../proofs/01-foundations.md#s01-06)，所以 Stack 保持旧格、仅在列顶追加 N/针；[非空合法输出必有地面格](../proofs/01-foundations.md#s01-07-h4)；[地面占用沿尾部单调增加](../proofs/01-foundations.md#s01-08-h12)；[按 Pin 次序不能出现 DDD](../proofs/07-reductions.md#s07-01-h2)，其中各次 Pin 之间允许任意 Stack。高度不够容纳所需晶体时，DDD 同样不可能。

记 G(X) 为状态 X 的地面非空列集合。Stack 不删除旧地面格；Pin 根据删除前的地面占用补针，即使原地面 C 随后删除，新针仍保留。因此 G 只增不减。一列至多贡献一次“地面由空变成非空”的事件。

## 2. 跨过 L 的局部改写及精确代价

### 引理 1：最多增加一份补针层

设 X₀→S₁→X₁→…→Sₘ→Xₘ→L 是合法四象限路径，每份上料只有一层。令 G=G(Xₘ)\G(X₀)。存在同一起点、同一最终状态的改写

```text
S^m L  ⇒  L S^r，    r≤m+δ，
δ=0（G为空），δ=1（G非空）。
```

这里表示存在相应上料，不要求原上料保持不变；任意相同后缀均可继续接上。

**证明。**所有 Xᵢ 都属于 K，旧格及晶体位置在 Stack 中保持。Xₘ 满足 L 条件，所以 X₀ 也满足。L 只去掉最高层的独立非针组和针，再抬升低部、按原地面占用补针；它不使低部下落。

若某列新料能落在地面，该列此前必整列为空，因为上料不能穿过旧列顶。因此 G 中各列在 X₀ 都整列为空。在 L(X₀) 后，先用一份纯针单层上料，同时补齐 G 中的地面针；G 为空时省略此步。

依原顺序处理每份上料：去掉不能保留的 C；对其余水平 N 块和单针，省去原落点为 H−1 或更高的整块，保留其他块。同一份上料各块不共列，过滤后仍可合成一份单层上料。

原来落地的块现在落在预置针上；其他保留块的旧阻挡整体提高一层，所以各保留块落点都提高一层。提前补针不会阻挡更早的保留块：某列首次取得地面格前，还未被较早上料占用。删去高处块也不影响保留落点，因为依赖这些阻挡的后续块原本就不能通过 L 保留。逐份归纳，最终恰为 L(Xₘ)，至多使用 m 份过滤上料及一份针层。证毕。

### 命题 2：局部的额外一次 Stack 不能统一省去

对每个 m≥1，存在固定合法起点，使 S^m L 改写为 L S* 时，恰好需要 m+1 次单层 Stack。

**构造与证明。**取 H=m+2。X 只有 q0 地面的一颗 C，q2 整列为空。连续 m 次向 q2 堆叠单 N，得到该列第0至 m−1层的 N，再执行 L。目标 Y 为：

| 列 | 从地面向上的非空格 |
|---|---|
| q0 | 针、C |
| q2 | 针、m枚连续 N |
| q1、q3 | 空 |

整个过程各列连续触地，X 可由单列晶体构造取得；L 前最高 N 为 m−1，C 位于地面，因此没有截顶损失或向下晶体删除。

若从同一 X 先做 L，q2 仍为空。Y 的 q2 共含 m+1 个格，每份单层上料在该列最多贡献一个格，故后段至少需要 m+1 次 Stack。先补 q2 地面针，再补 m 枚 N，恰好达到下界。

例如 m=2 时，L 后目标的短代码为：

```text
P---P---:cr--Cu--:----Cu--
```

m=2 的原路线为两次 q2 单 N 堆叠后 Pin；先 Pin 则须堆叠 q2 的针、N、N。另行准备两根完整柱后直接 Swap，也能得到该目标。因此这是固定输入的局部下界，不是全局强制交替实例。

## 3. 最短路线的来源与地面约束

### 引理 3：最短路线的第一次 Pin 必须为 D

若第一次 Pin 为 L，即使它之前有单层 Stack，也能更换合法交换起点，省去该 Pin，并且不增加 Stack 次数。

**证明。**L 删除的晶体分量只占最高一层。沿历史回溯，这些分量在 B 中也只占一层，可按[合法顶盖替换](../proofs/07-reductions.md#s07-01-h6)改为 N，保持非针连接、支撑和最终结果。如此第一次 Pin 输入最高层没有 C。

把此前 Stack 新增的地面块分配到原两份半形：这些块只使用原本整列为空的列，均可直接落地。随后分别 Pin 两半，再 Swap，得到新的合法起点。其内容等于旧 B 与这些地面块经过截顶、抬升和补针的结果。原 Stack 段其余保留块按顺序加入，落点都提高一层；原落地块和顶层丢弃块从上料中省去。每份原上料最多对应一份新单层上料，所以尾部少一次 Pin，Stack 不增加。此即[首次无顶破 Pin 前移](../proofs/06-forced-words.md#s06-10-h1)的构造。证毕。

### 引理 4：以 Pin 开头的最短路线，交换两半都非空

**证明。**设 B=Swap(Q₀,Q₁)，Q₀、Q₁ 是真实切后半形。若仅一半 Q 非空，则 Pin(B)=Pin(Q)。Pin 不扩大列集合，且四象限的 Pin(Q) 仍属于 K，因而稳定。可以在准备阶段制造 Pin(Q)，把它作为同一半面的输入；另一侧沿用能切出空半形的输入。最后 Swap 的预切既不删保留列上的晶体，也不改变稳定的 Pin(Q)，所得新起点恰为 Pin(B)。这省去首个尾 Pin，得到更短路线。两半都空时首 Pin 是恒等，也不可能最短。

所以两半必须非空。每份合法非空半形至少有一个地面格，两半列集合不重叠，故 G(B) 至少有两列。证毕。

这个论证要求首个尾操作就是 Pin。若前面已有 Stack，新上料可能建立跨半连接，不能直接分别 Pin 原两半来吸收它。

## 4. 最短路线的正规形

### 定理 5：紧前带 Stack 的 L 只有有限次例外

对任意具有合法尾部的四象限目标，存在一条总操作数最少的路线，使下列性质成立：每个紧前带有非空 Stack 段的 L，该 Stack 段都必须新增至少一个地面占用列。

因此，这类 L 至多出现三次。如果目标有一条以 Pin 开头的最短路线，则也可以选取仍以 Pin 开头的最短路线，使这类 L 至多出现两次。两个上界都与 H 无关。

**证明。**在全部最短路线中，再取下列非负整数最小的一条：

```text
I = 满足“一个 S 出现在一个 P 之前”的操作对数。
```

最短路线存在时，这个整数也存在最小值。考察其中一个紧前带非空 Stack 段 S^m 的 L。若该段没有新增地面占用，引理1把它改成 L S^r，r≤m，且段后状态完全相同。

若 r<m，总步数减少，与最短性矛盾。若 r=m，只把该 L 越过 m 个 S，其他 Pin 与 Stack 的相对计数不变，I 恰减少 m，也矛盾。因此每个这样的 L 前都必须出现新的地面占用。

各个紧前 Stack 段互不重叠，地面占用又只增不减，故每个 L 可以对应一个不同的新地面列。含 Pin 的最短路线，其第一次 Pin 必为 D，因而 B 已含晶体并非空。B 至少有一个地面列，最多剩三个可新增列；没有 Pin 的路线自动满足结论。

若限定在以 Pin 开头的最短路线中取 I 最小，上述局部改写保留开头的 Pin，证明仍成立。引理4又给出 B 至少两个地面列，因此最多有两个例外。证毕。

这是一条“可以选取某个最短代表”的结论，不声称每条最短路线都已经正规化，也不限制 D 前的必要 Stack。它没有给任意路线的 Pin 总数或交替段数一个常数上界。

## 5. 完全交替的唯一最短词至多八次 Pin

### 定理 6：以 Pin 开头的完全交替上界

设目标 T 的所有最短路线都具有同一个操作词

```text
P S^b₁ P S^b₂ … P S^b₍p−1₎ P S^bₚ，
b₁,…,b₍p−1₎≥1，bₚ≥0。
```

即它以 Pin 开头，每对相邻 Pin 之间都有 Stack，末尾 Stack 可以省略。则

```text
p ≤ 8。
```

更精确地，对任意一条这样的最短路线，令 e 为第一枚 Pin 输入时的空地面列数，则 p≤3e+2，且 e≤2。

**证明。**引理3排除第一次 Pin 为 L，引理4给出 e≤2。记这条路线中 L 的总数为 ℓ。所有 L 前都有一个非空的 Pin 间 Stack 段。

如果其中某段没有新增地面占用，引理1给出不更长的路线，并使该 L 与前一个 Pin 相邻。若新路线更短，与最短性矛盾；若等长，其操作词含相邻 PP，与假设的唯一完全交替词不同。因此每个 L 前的该段都必须新增地面占用。

这些新增列互不重复，所以 ℓ≤e。D/L 词不含 DDD，故 D 被 ℓ 个 L 分成至多 ℓ+1段，每段最多两个 D。因此

```text
p−ℓ ≤ 2(ℓ+1)，
p ≤ 3ℓ+2 ≤ 3e+2 ≤ 8。
```

证毕。

按第一枚 Pin 输入的地面占用，可以直接读出更小的条件上界：

| 已占地面列数 | 剩余空列 e | 完全交替的唯一最短词的 Pin 上界 |
|---:|---:|---:|
| 2 | 2 | 8 |
| 3 | 1 | 5 |
| 4 | 0 | 2 |

这些数是必要上界，未证明能够达到。特别地，不能把 p≤8 理解为每个八次以内的词都存在对应目标。

**推论。**四象限任意高度，都不存在以 `(PS)^9` 为唯一最短尾部操作词的目标。更一般地，以 P 开头且含至少九个 Pin、全部 Pin 间隔均有 Stack 的词，都不能被所有最短路线共同强制。这个否定允许自由选择交换起点、上料和 H。

若允许最短词在首个 Pin 前另有 Stack，则非空起点只保证至少一个地面列，相同计数给出 p≤11；此时不使用引理4的双半地面下界。两种情形均不排除指定词与非交替词并列最短。

## 6. 对一般偶数象限命题的边界

八次界依赖四象限的两项特性：全部中间输出保持 K，以及 D/L 词不含 DDD。六象限已有合法 DDD 及任意有限 D/L 时钟；Stack 还可能使旧下料再次下落。因此不能把 n 代入地面计数，就得到一般偶数象限的相同结论。

对更宽形状，引理1可以在[每个 Stack 输入、输出都稳定](../proofs/06-forced-words.md#s06-11-h18)的明确前提下使用。若某个 Stack 前状态不稳定，旧格可能下落到地面；这些格并非可自由推迟的新上料，补针重排可能失效。单独检查 L 输入已经稳定并不足够。

[六象限独立竖列时钟](../proofs/06-forced-words.md#s06-11-h9)的最终各列形如“p根地面针、C、一至两枚N”。这些列可在两半内独立预制，最后直接 Swap，故具有零尾 Pin 路线。该已知构造不能提供全局必要性；本文的局部代价构造也具有同样的来源绕过。

可变偶数象限的任意指定交替序列，以及必须顶破三座不同晶体塔的完整目标，仍未解决。本文证明了局部重排代价、四象限最短路线正规形和完全交替的唯一最短词上界。

## 7. 连续三列的一次结算必稳定

从本节起允许六象限或更宽的偶数象限。F 表示按输入格位重新分组并完成一次重力；稳定指 F(X)=X。以下三列按一条路径相邻，左右边列互不相邻，列外为空。

### 定理 7：三列结算稳定性

设有限格位图 X 只占连续三列，执行 F 时末尾截高不删除保留格。则 F(X) 稳定，即 F(F(X))=F(X)。不要求 X 已稳定或可制作；融合删除可以在这次 F 之前完成。

**证明。**在本次结算中，记从未下落的原粘连组为固定组。移动组中的晶体全部消失，剩余材料只能是水平 N 块或单针。[固定组的最终支撑只能来自其他固定组或地面](../proofs/01-foundations.md#s01-12-h2)。所以固定组沿支撑边必到达地面或一个有向环。

结算写回时，新的水平接触可以合并非针组，针始终独立。需要证明这些合并不会消除全部支撑。

**第一步：非针组的层区间。**对非针组 A，记 a(A)、b(A) 为最低、最高层。连接路径不能跳层，所以 A 在区间 I(A)=[a(A),b(A)] 的每一层都至少占一格。

同一层若出现两个不同非针组，它们只能分别占左、右边列，各占一格；中列没有非针格。三个不同非针组的层区间不能同时重叠。若两个组共同经过相邻两层，则它们在这两层各自保持同一边列，因为跨层连接只能使用同列相邻晶体。

由此还有一个支撑限制：若 A→B 是非针组间的支撑边，且 a(A)≤a(B)，该边必从 B 的顶层上方落到 B 的顶层。设支撑格在 z+1 层、阻挡格在 z 层。由于 z≥a(B)≥a(A)，A 也经过 z 层；若 B 还经过 z+1 层，两个组在相邻两层各居不同边列，不可能同列上下接触。因此 b(B)=z。

**第二步：无针环的几何。**取固定组支撑图中一个不含针的简单有向环。选其中最低层号最小的组 G，并沿环写成

```text
G → H₁ → H₂ → … → Hᵣ → G，    r≥1。
```

第一条边及上一限制给出 I(H₁)⊂I(G)，且 b(H₁)<b(G)。若 I(Hᵢ) 已包含于 I(G)，下一个非 G 成员不能与 Hᵢ 在任何一层重叠，否则 G、Hᵢ、Hᵢ₊₁ 三个非针组同时出现。它只能整个位于 Hᵢ 下方；G 的最低层又是环内最小值，所以 I(Hᵢ₊₁) 仍包含于 I(G)。

归纳可知，H₁至Hᵣ的区间互不重叠，自上而下排列。最后的 Hᵣ→G 只能从 Hᵣ 的最低层取得下方阻挡，故 a(Hᵣ)>a(G)。于是全部 Hᵢ 的区间都严格位于 G 的区间内部。

在 H₁ 的最高层 b₁=b(H₁)，G 与 H₁ 各占一边。G→H₁ 又要求 G 在另一边的 b₁+1 层有格。沿 G 内的连接路径，从这个托顶格走到 b₁ 层的格，穿过 b₁ 层的唯一通道在相反边列。因此 G 必在某个 v>b₁ 的中列占一格。这颗固定格位于全部 Hᵢ 上方，形成阻挡中列落料的顶盖。

**第三步：落料不能把环合并。**若一个移动 N 最终要落到某个 Hᵢ 层区间的中列，其来源高度 t 不可能在 I(G) 内：G 在 t 层有非针格，中列 N 会与它重叠或相邻，早已属于固定组 G。它也不能从 G 下方向上移动。因此只能有 t>b(G)。

但是中列的固定顶盖在 v 层，且 v>b(Hᵢ)。落料不能穿过它，故无法到达所需中列位置。于是没有移动 N 能在 Hᵢ 的层区间把它连接到 G。

Hᵢ 也不能经其他固定非针组绕接到 G：任何与 Hᵢ 层区间重叠的第三个固定非针组，都会与 G 一同违反每层至多两组的性质。新加入的 N 只有水平连接，不能连接层区间不相交的旧组。故每个 Hᵢ 都不会与其他固定组合并，整个环保留了组间支撑。

**第四步：恢复全部输出。**含针环不会全部并成一个非针组，因为针不参与粘连；无针环由第二、三步保护。触地组在合并后仍触地。因此每个旧固定组在最终重新分组后，仍能沿支撑到地面或未被消除的环。

纯移动材料形成的输出组只是一层 N 或单针。它们沿向下支撑到达地面或含固定格的组；每条纯移动组之间的边都严格降低层高，不会形成无支撑的循环。所有输出组都有支撑，F(X) 稳定。证毕。

### 推论 8：六象限半切输出稳定且可重复使用

任意六象限、任意 H≥2，真实 Cut 的每个非空输出 Q 都稳定。把 Q 再送入同一方向、保留同一半面的 Cut，输出仍为 Q。

**证明。**融合删除之后，Cut 的重力输入仅在连续三列内，并且已经位于 H 层以内。下落不会增加高度，最后没有截高损失，故定理7适用。再次半切只删除空列，不删除晶体；重新结算因 Q 稳定而保持 Q。证毕。

因此六象限的真实切后半形可以先作为物品制造，再作为交换器输入使用。需要比较制备成本时，仍须计入取得这个半形的加工；原输入凭据并不因此具有相同成本。

这个结论允许[三列无针支撑环](../proofs/01-foundations.md#s01-04)，没有把稳定等同于 K。两个稳定半形拼接后仍可能不稳定，因为 Swap 会建立跨半连接，且拼合后不再执行 F。也没有由此证明任意稳定三列网格都可制造。

## 8. 首个顶针必须留下什么跨半障碍

本节仍只计最后 Swap 后的 P、单层 S。准备与尾部共用 n、H，允许更换真实交换起点及全部上料，首个尾操作为 P。

### 定理 9：分别准备两半、一次结算的替代

取任意偶数 n≥4。设 B=Q₀∪Q₁ 是最后 Swap 的输出，Qᵢ 是两个互补半面的真实切后结果。对任何形状 X，记 Γ(X) 为与第 H−1 层 C 融合相连的全部晶体，记 V(X) 为 Pin 完成融合删除、截顶、抬升和按原地面补针之后、尚未执行 F 的格位。于是 P(X)=F(V(X))。

若同时满足：

1. **两半的晶体删除相同：**Γ(Qᵢ)=Γ(B)∩Qᵢ，i=0,1。
2. **顶针结算前的两半分别稳定：**把 V(B) 按同一切向投影得到 V₀、V₁，则 F(Vᵢ)=Vᵢ。

就能更换合法交换起点，用至多一次单层 S 精确替代首个尾 P，不增加尾部总操作数。任意原后缀均可原样接上。

**证明。**条件1加上逐列截顶、抬升与补针，给出 V(Qᵢ)=Vᵢ。条件2进一步给出 P(Qᵢ)=Vᵢ。

在准备阶段，先按原凭据制造各非空 Qᵢ，再分别 Pin，得到 Vᵢ。它们不越出原半面，又各自稳定，所以作为新交换器输入时，预切不改变其格位。空半面仍使用能切出空结果的合法非空输入。新交换起点恰为

```text
B′ = V₀ ∪ V₁ = V(B)。
```

随后堆叠一份由全针单层结晶得到的纯晶体单层。这份上料全部碎掉，不贡献 N/针；它只对下料执行一次 F。因此

```text
B′ → S_C → F(B′) = P(B)。
```

这里 S_C 是一次合法单层 Stack。若 B′ 本来稳定，则省略它。准备阶段没有提高 H；原后缀从相同状态继续，目标不变。证毕。

**必要条件。**若一个目标的所有最短路线都共同以 P 开头，则其中每条路线的首 P 至少违反上述一项：要么某些晶体必须经另一半传来的融合路径才被顶破，要么 V(B) 的某个半面单独不能稳定。这是首步必要性的排除条件，不是充分制造判据；两种障碍可以同时存在。

条件1只要求删除结果一致，并不禁止跨半晶体连接。跨半连接若没有改变哪些晶体被删除，仍满足条件1。条件2检查的是删除、抬升和补针后的投影，不能用原 Qᵢ 的稳定性代替。

### 推论 10：六象限不能强制以无向下顶破的 Pin 开头

在六象限任意高度中，若最后 Swap 后的首 P 为 L，即输入最高两层没有同列 CC，则它可以被定理9的至多一次 S 替代。若原 B 稳定，则首 P 可以完全移入准备阶段，连这次 S 也不需要。

**证明。**由推论8，两份真实 Qᵢ 都稳定。L 的触顶晶体分量仅在最高层；其中每颗晶体本身已经触顶，所以完整形与两半分别 Pin 时都删掉同一批最高层 C，满足条件1。

最高层没有通向低层的竖直晶体连接。去掉它只删除独立顶层组，不删除低部的支撑；低部整体提高一层，原地面支撑由新针替代。因此稳定 Qᵢ 的 V(Qᵢ) 仍稳定，满足条件2。若 B 自身稳定，同一论证也说明 V(B) 稳定。证毕。

所以，若所有最短路线共同以 P 开头，其首 P 必须为 D。这个结论允许原 B 不稳定，也没有断言“某条最短路线不能以 L 开头”：替代路线有时同样长，但改为以 S 开头，形成并列最短。

### 推论 11：六象限最短 Pin 开头仍要求两个非空半形

在六象限中，任一以 P 开头的最短路线，其最后 Swap 的两份真实半形都非空；初始地面至少占两列。

**证明。**若只有一份 Q 非空，则 P(B)=P(Q)。Pin 不扩大列集合，正式重力开始前的格位仍在连续三列及 H 层以内。由定理7，P(Q) 稳定。因此可以在准备阶段先制造 P(Q)，再把它与空半面交换，直接取得原首 P 的输出，严格省去一步。与最短性矛盾。

[两份非空真实半形各至少有一个地面格](../proofs/01-foundations.md#s01-07-h4)，而两半列集合不重叠。于是地面占用至少为2。证毕。

## 9. 对任意序列构造的约束

六象限已允许任意有限 D/L 时钟，但要强制首个尾 Pin，还必须让定理9的至少一个跨半障碍对所有可替代起点成立。只在某条配方中展示三座塔按时顶破，不提供这个来源下界。

三列定理解决了六象限真实半形在重新结算下的稳定性，没有解决所有稳定半形的制造性，也没有约化六象限的全部中间 Stack。四象限的八次界仍依赖 DDD 禁止定理，不能移植到六象限。

一般偶数象限下，任意指定交替序列是否都能成为不可绕过的阶段顺序或唯一最短词，以及是否存在全局必须顶破三座不同晶体塔的目标，仍需独立的来源排除证明。
