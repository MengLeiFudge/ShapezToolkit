# 基础单层备料与拼装

本册从 C、R、S、W 四种无色整片和染料制造配方要求的任意非空无晶体单层。整片订单直接出货，其他订单每角领一件原料，再合并为一件单层。四件可以来自同一种货。图形和染料从配料列车到厂。

| 工道 | 西侧进料 `(y,建筑层)` | 东侧出料 | 用法 |
|---|---|---|---|
| [调色](base-palette-4q5l.spz2bp) | 图形厂的混合流体车从底至顶装红、绿、蓝，三车厢出口对准西侧三组接口 | 黄 `(-11,0)`、品红 `(-9,1)`、青 `(9,2)`、白 `(30,0)`、三原色 `(11,L)` | 白色先混绿蓝，再把所得青色与红色等量混合。各出口颜色固定 |
| [染色](base-paint-4q5l.spz2bp) | 每层 `(8,L)` 整片、`(9,L)` 对应颜色 | `(8,L)` 同类整片 | 每层固定一种颜色。无色订单直接用原料 |
| [纯针](base-stock-4q5l.spz2bp) | `(8,0)` 任一整片、`(9,0)` 任一可结晶染料 | `(8,0)` 四针 | 五层限高下连续顶针五次，得到五层全针。结晶将全塔融合，下一针顶碎全塔并在地面生成四针 |
| 同平台的空角占位 | `(10,1)` 或 `(10,2)` 任一整片 | 同入口行和层 | 半破后逆转得 `{q3,q0}`，供目标 q0、q1 空角。半破后顺转得 `{q1,q2}`，供目标 q2、q3 空角 |
| [四角拼装](base-quarters-4q5l.spz2bp) | 底层从北向南，`y=8,9,10,11` 分别领目标 `q2,q3,q1,q0` 的料 | `(11,0)` 目标单层 | 三台交换机、两台逆转机。另一出口接垃圾桶 |

两台第一级交换机各取南路前半、北路后半，再逆转一格。这样南侧中间产物的 q0、q1 分别来自原南路 q1、原北路 q2，北侧中间产物的 q2、q3 来自原北路 q3、原南路 q0。第二级取这两份中间产物的对应半边。空角占位料在不选中的半边留有实物，即使目标连续两个角都为空，第二级仍可同时收到两件料。

[基础料订单电路](../../电路/基础料订单/quarter-order-4q5l.json)给出单个角所需原料、颜色及纯针或占位工道。厂外也可用 `python main.py tmam2 synth --complete --production --instructions -- 目标短代码` 导出同一份配方的基础层订单与每件成品的原料、染料需求。用料按整片单次使用、副产物丢弃计算。每秒需求量等于每件用量乘目标带速，列车往返周期和机器加工率另计。
