# 四象限五层逐层生产线

这份装配接收目标图形和混合列车。电路先拆出每个非空层，用一整层针托住拆出的上料。普通格和针落到托底上，悬空晶体破碎。取最上层作为该工段的基础料订单。若整层都是晶体，留下的四针提供结晶骨架所需的高度。

电路从底到顶回放基础料堆叠。结果等于目标时写九条指令。否则用七种染料分别预演末次结晶。命中时写十条，最后一条在槽 0 上结晶。两条路径共用备料、写入和出货线路。两种回放均未命中时保持停料，目标的可制作性仍待完整求解器判定。[游戏蓝图](layer-factory-4q5l.spz2bp) · [车站和出口坐标](layer-factory-4q5l.json)

## 接入

1. 在 `1600000` 提供四象限、最多五层的目标图形。在 `1640030` 提供整数 `0`，保持目标至少 256 个信号 tick，从空工道开始。
2. 五个基础料站均使用十二节混合车。从车头起按图形、图形、流体重复四组，每组三节分别装 C/R/S、W/空/空、红/绿/蓝，均按底到顶排列。一层的四条带装同一种货。[工段换装站](../../配料/工段供货/)
3. 结晶站位于 `(153,3)`，车头朝北。车头后第一节为流体车，按底、中、顶分别装红、绿、蓝。单节卸货口供给七种固定颜色的厂内混色管路。[染料换装与车库](../../配料/README.md)
4. 保持目标，将 `1640030` 改为整数 `1`。各工段分两组回读指令字段，主控收到最后一笔应答才在 `1640015` 放行领料。第十工段在九条指令的订单下保持直通。
5. 成品口在 `(168,0)` 平台东侧、建筑底层、岛内第 `31` 行。过滤器保留与目标整件相同的图形。换单前须排清旧物料。

## 验证范围

蓝图生成时检查工段占地、局部逻辑接线、跨台输送口和混色路径。游戏内换单、列车连续到货、实体合成及一满带持续出货仍待验收。运行 `python main.py tmam2 blueprint layer-factory-4q5l` 可重新生成本册装配。
