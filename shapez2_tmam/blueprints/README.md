# Shapez 2 TMAM 蓝图册

四象限五层的新增蓝图按[整厂约定](整厂约定.md)设计与验收。制作层的全部实体来料经过单料列车、配料站和混合列车。

在游戏蓝图库中保留下面的目录层级。`.spz2bp` 是可导入的原生蓝图。电路的同名 JSON 给出该版本的频道及采样时序。

| 分册 | 内容 |
|---|---|
| [电路／配方加工](电路/配方加工/workcell-4q5l.json) | 新版消费式指令的虚拟加工，按操作号输出一步加工结果 |
| [电路／目标取格](电路/目标取格/cell-at-4q5l.json) | 按实际层号和象限读取去色部件与颜色，保留中间空层 |
| [电路／逐层配方](电路/逐层配方/layer-controller-4q5l.json) | 无晶体逐层解、九条指令的寻址、双存储板回读及开工控制 |
| [电路／配方写入](电路/配方写入/stage-writer-4q5l.json) | 把一条六槽指令写入指定工段，两组字段均回读成功后应答 |
| [电路／列判据](电路/列判据/README.md) | 新版自动列扫描，上下两块 3×3 平台分时查同一张 25 行表 |
| [电路／基础料订单](电路/基础料订单/) | 新版按象限分时译码，返回整片原料、颜色与工道选择 |
| [实体／基础单层](实体/基础单层/README.md) | 三层染色、纯针和空角备料、四角拼装 |
| [实体／逐层生产线](实体/逐层生产线/README.md) | 五个基础料车站和一个结晶染料站，按目标写九条堆叠备料指令或追加第十条结晶指令 |
| [实体／指令工道](实体/指令工道/train-fed-stage-4q5l.json) | 带备料、加工、六槽取回料和混合车卸货的单个可编程工段 |
| [配料／工段供货](配料/工段供货/mixed-stage-depot.json) | 十二节混合列车的车厢顺序和七种单料的换装站 |
| [电路／完整主控（上一代）](电路/完整主控/) | 四象限五层求解、成功配方的虚拟回放与指令输出。双层大平台版文件名含 `packed` |
| [电路／扫描与时序](电路/扫描与时序/) | 图形解码、单步与循环扫描、时钟、寄存器 |
| [电路／起点与半形](电路/起点与半形/) | 无晶体目标、标准半形、双半形起点及追加 |
| [电路／顶针逆推](电路/顶针逆推/) | 来源列、顶针像和候选标签 |
| [电路／加工与指令](电路/加工与指令/) | 虚拟加工与六槽配方回放 |
| [实体／图形加工](实体/图形加工/) | 三层共用一块 3×3 平台，包含旋转、半破、顶针、堆叠及交换工道 |
| [实体／实体槽位](实体/实体槽位/) | 六个入料读口和可分别控制的取料 A、B 出口 |
| [实体／结晶加工](实体/结晶加工/) | 3×3 单色结晶平台，输入图形和染料，出口带物品读取器 |
| [配料](配料/README.md) | 单料车转装混合车的逐层接口、装载表和制作厂收货站 |
| [火车／图形货运](火车/图形货运/) | 单节图形货车的机库、装货站及卸货站 |
| [火车／染料货运](火车/染料货运/) | 单节流体货车的机库、装货站及卸货站 |

上一代主控快照为 [factory-control-4q5l](电路/完整主控/factory-control-4q5l.spz2bp) 和[对应频道表](电路/完整主控/factory-control-4q5l.json)。工厂收到请求后执行一次，物品进入目标槽才回送本次 `request`。等待期间主控在后续采样窗口重复发布同一包。双方同时复位，实体端从空槽和整数 0 确认位开始。整厂自动运行还需基础单层供料、各实体槽的取回料调度、工道选路及收货确认。实体主控已将两处解码器的十次测高按方法就地布线。其他搜索和控制通路仍大量使用无线模板。各册的用途和摆放说明见[电路接口](电路/README.md)、[实体端口](实体/README.md)及[火车站场](火车/README.md)。

在仓库根目录运行 `python main.py tmam2 blueprint --list` 可查各蓝图的名字与分册，`python main.py tmam2 blueprint --all` 按分册重新生成。`--output-dir` 指定整套图册的根目录。
