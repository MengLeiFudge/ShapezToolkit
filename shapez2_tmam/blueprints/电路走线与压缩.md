# TMAM 电路走线与压缩

这里规定 Python 方法怎样自动变成可导入的 Shapez 2 电路。适用于四象限五层整厂的电路分册。算法、信号接口和目标时序由源码定义，元件坐标、换层、飞线与蓝图编码由生成器决定。

## 模块和接线

| 接线范围 | 生成规则 |
| --- | --- |
| 模块内部 | 共用输入只接一次。将同一计算的取值、变换与消费方放在一起，内部信号经导线、分支、线桥、换层线和短距飞线交接。 |
| 同岛层的一发一收 | 同板接本地导线。跨板时按信号依赖把两块板摆到相邻位置，给相对的凹口分配端口并接通飞线。 |
| 上层调用下层 | 按职责划分模块，明确输入、输出、采样和复位。一发一收的内部频道只在确实跨岛层时保留无线。 |
| 整厂接口 | 整厂接收目标形状，返回结果和配方。制作、配料和火车各自使用已约定的接口。 |
| 无线端口 | 剩余的模块无线口优先沿同一侧竖排，数据端朝板内。端口数量取决于模块职责，重复接收同一信号时先检查能否共用。 |

同一方法的条件判断、局部选路和单次更新在一个模块内处理。可独立计算的路线可以并行，求解时间看最长的一条依赖链。反复调用的路线、逐层读写及循环使用共享的计算块。发布下一轮前，先确认本轮结果已保存。把无线反馈改成短线时，生成器须重新核对延迟、复位和更新顺序，避免把原本分时的状态更新接成组合环。

按信号依赖分组后再决定哪些模块叠到其他岛层。需要相邻摆放的板先配好飞线两侧端口。放置后从原生蓝图确认配对和端口驱动。若一发一收位于同岛层且仍使用无线，则该布局未通过。

参考册中的并行 MAM 以相同局部网表重复四路计算，适合把读入、变换和取值编成一套共用输入的布线单元。压缩版 Corner MAM 同时使用同板短距线和相邻板板缝，Exo 与 Virtual Corner MAM 则展示了大板与小板两种尺度的跨板交接。短距候选按实际省下的导线、占格和时序选择，采用前核对端口朝向、距离和竞争配对。

## 自动生成顺序

1. **整理方法。** 清理无用输出和重复计算，明确公开调用口。对不会同时执行且接口相同的工序，考虑共用一份时序计算块。运行时间另算。
2. **逐个试摆并接线。** 从已接通的输入、输出或飞线端点生长。每次只试摆一个器件，用当前可用路径接入已有线网，比较实际加线量后定下位置、朝向和建筑层。可以贴到互补端口时直接接触。保留后续分支的接入口，堵住时允许重布已经放下的局部线路。
3. **按需选平台。** 综合使用三个岛层和三个建筑层。生成器根据器件和接线选择平台尺寸与相对位置，用稀疏平台和过长走线定位可缩减的区域。平台外框尽量集中。基础平台每岛格宽 20 个建筑格，默认矩形平台普通外缘各留 3 格。用游戏资源中的锚点换算坐标，从布局开始检查器件整块占地、线缆和换层件，并按游戏掩码判断凹口。飞线在同一岛层使用，跨岛层通过模块接口。
4. **导出后回查。** 重新解码原生文件，核对实际占地、各逻辑输入的驱动源、线桥分网、短距端口配对和端到端时序。以游戏放置后保留的建筑核对导入结果。通过核对的同功能布置按下节规则选优。

### 先估面积，再布全图

整厂压缩迭代先按网表统计门、常量、寄存器、端口的占格。全局收发器各按 27 格计。用职责和接线结构相近的现有模块，校准线路占格与器件占格之比，以及每个 1×1 岛格平均承载的三维建筑格数。用候选的预计总占格除以每岛格平均承载，向上取整，按模块汇总岛格预算。反馈、控制和共享模块的选择器均计入。

同时用现有可用平台的最高每岛格容量计算乐观下界。下界超预算的候选先改网表。接近预算的候选先布线核对占格贡献最大的模块，再导出全套。容量下界、样件外推、整图实测分别记录。每岛格平均承载按实际平台面积求和，岛层分别计入。

## 审阅与放行

对功能、接线和时序均通过核对的方案，**先比较实际使用的 1×1 岛格总数，岛格相近时比较建筑总数**。1×2 计 2 格，3×3 计 9 格，不同岛层分别计入。建筑总数计入器件、导线和飞线端点各自的原生条目。

- **三维空间利用率。** 按建筑实际占用的三维格位去重，除以各平台三层可建格数之和。多格器件和换层件逐格计入。普通器件与线缆只能放在普通可建区。逐板占比用于定位能缩小的平台。
- **俯视占地率。** 将所有建筑层和岛层投影到同一平面并去重。报告分别按整套电路外框面积和实际平台可建面积计算比例，便于区分板内空白和板间空白。
- **体积。** 按尺寸统计平台件数，并报告俯视占用岛格、外框长宽、岛层数和各建筑层的器件数与线缆件数。俯视占地按叠放后的平面投影去重。
- **全局收发。** 四象限五层整厂电路总计至多 555 个全局收发器。每个收发器按 27 个建筑格计。对完整原生蓝图按实际接收端和发射端核查同岛层的一发一收，并统计有实际跨板飞线连接的板组。满足接线规则的方案再比较岛格数和建筑总数。
- **可复核。** 审阅包从原生蓝图读取坐标和接线，逐岛层、逐建筑层画图，并附同名接口表。下列命令导出三个现有样件的审阅图。电路修改和整厂联调以用户确认的布线为准。

用 `python -m shapez2_tmam.circuits.factory_link_audit 蓝图.spz2bp --check` 回查整图。只要发现同岛层一发一收仍走无线，或全局收发总数超出上限，命令便返回失败并列出位置。

用 `python -m shapez2_tmam.circuits.factory_unicast_wiring 原图.spz2bp --channel 频道 --output 候选.spz2bp` 重布已核对时序的跨板单播。生成器在当前外框内移动可平移的板，接入原板线路或重布单板，再核对原生配对和逻辑输入的实际驱动。逐条回查仍待接线的频道，避免把局部样件当作整厂通过。

单板组合方法用 `compile_method --left-rail` 生成同侧收发布局，再用 `python -m shapez2_tmam.circuits.factory_progressive_layout 原图.spz2bp --board 1 --output 候选.spz2bp` 逐器件重布。用 `--keep-size` 在指定的原平台轮廓内比较布线。候选先核对逻辑输入驱动和原有跨板飞线，再报告占地与建筑数。

原色读列样件用同一个原层信号产生四列标签。旋转与原颜色读取在组合方法里共用输入，列号仍按 `q0` 到 `q3` 输出。下列命令选用 S 前态第五行的接口。

```bash
python -m shapez2_tmam.circuits.compile_method shapez2_tmam/synthesis/shape_methods.py \
  --field q0=read_labeled_corner --field q1=read_labeled_corner_q1 \
  --field q2=read_labeled_corner_q2 --field q3=read_labeled_corner_q3 \
  --input-channel row=1705354 --output-channel q0=1703643 --output-channel q1=1703648 \
  --output-channel q2=1703653 --output-channel q3=1703658 \
  --left-rail --output 原色读列-左侧收发.spz2bp
python -m shapez2_tmam.circuits.factory_progressive_layout 原色读列-左侧收发.spz2bp \
  --board 1 --keep-size --output 原色读列-逐器件布线.spz2bp
```

打开 `TMAM电路审阅/index.html` 查看图。审阅表按平台列出 L0、L1、L2 的占地率。导出叶端锁存的三岛层布置时使用下列命令，游戏须解锁下层和上层岛面。

```bash
python -m shapez2_tmam.circuits.compiler_backend.leaf_snapshot \
  --stacked --output leaf-snapshot-stacked.spz2bp
```

中间岛层用三块 1×1 平台分别推进锁存阶段、保存两个字段、保存第零列高度并输出选列高度。阶段控制通过四对飞线分别向两块板发送 `load` 和 `retain`，沿用原有的全局信号。上下岛层各用一块 2×1 平台保存六个字段，读取既有 `hold` 和 `phase` 频道。俯视仍占三个岛格，外框为 2×2。

中层每个控制门在试摆时就连接已有端口，再确定位置、朝向和层位。上下两块锁存板各有 20 个全局收发器，占单板可建空间的 36%。闭包复用版让原闭包保留已选结果，回放按原频道读取，省去这两块锁存板和相关控制板。
