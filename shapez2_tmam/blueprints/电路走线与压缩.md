# TMAM 电路走线与压缩

这里规定 Python 方法怎样自动变成可导入的 Shapez 2 电路。适用于四象限五层整厂的电路分册。算法、信号接口和目标时序由源码定义，元件坐标、换层、飞线与蓝图编码由生成器决定。

## 模块和接线

| 接线范围 | 生成规则 |
| --- | --- |
| 模块内部 | 使用导线、分支、线桥和换层线，内部全局收发器数为零。将共享输入、状态寄存器和它们的使用者一起布置。 |
| 同一模块跨相邻平台 | 在平台边缘预留飞线端口。生成器按发射端、接收端、朝向和距离核对实际配对，再布板内的引线。 |
| 上层调用下层 | 按职责划分模块，明确输入、输出、采样和复位。在这个边界可以用全局收发器，每个频道应对应一项明确的调用信号。 |
| 整厂接口 | 整厂接收目标形状，返回结果和配方。制作、配料和火车各自使用已约定的接口。 |

同一方法的条件判断、局部选路和单次更新在一个模块内处理。可独立计算的路线可以并行，求解时间看最长的一条依赖链。反复调用的路线、逐层读写及循环使用共享的计算块。发布下一轮前，先确认本轮结果已保存。把无线反馈改成短线时，生成器须重新核对延迟、复位和更新顺序，避免把原本分时的状态更新接成组合环。

## 自动生成顺序

1. **整理方法。** 清理无用输出和重复计算，明确公开调用口。对不会同时执行且接口相同的工序，考虑共用一份时序计算块。运行时间另算。
2. **把器件和接线一起摆。** 从相互依赖的器件小组开始，试摆时同时选择朝向、层位、端口和短线路。先为共用信号、飞线和换层留路。每条局部线路会影响后续摆放。线路拥挤或绕远时，允许挪动、旋转器件、换层或重排附近接线，再一起评价。参考 BC TMAM 的紧凑重复单元，把常用的输入、运算和取值器件沿短支路布置。
3. **按需选平台。** 对可分开的模块使用三个岛层叠放，每块平台把建筑和线路铺到三个建筑层。生成器根据器件和实际走线选择平台尺寸、数量及相对位置，优先压缩占地率最低的平台，并比较投影面积和外框长宽。整体外框尽量接近正方形。基础平台每岛格宽 20 个建筑格，默认矩形平台普通外缘各留 3 格，以游戏资源记录的平台锚点换算坐标。从布局开始就检查器件的整块占地、线缆和换层件，使用凹口时按游戏的凹口掩码检查。飞线在同一岛层使用，跨岛层通过模块接口。
4. **导出后回查。** 重新解码原生文件，核对实际占地、各逻辑输入的驱动源、线桥分网、短距端口配对和端到端时序。交付游戏蓝图时以实际放置后保留建筑为准，预览计数只反映蓝图中的条目。对功能相同且通过接线和时序核对的布置，比较岛格面积、外框、线缆件、全局收发数量和运行时序。用逐板建筑占比定位还值得压缩的位置。

## 审阅与放行

- **三层占地率。** 每块平台单独达到 75% 才通过。按建筑实际占用的三维格位去重，除以该平台三层的可建格数。跨层换层件和多格器件按实体占用逐格计入，外缘不可建格不进入分母，可建凹口照常计入。占地冲突、越界或器件占地未核实时都暂不通过。压缩靠重排、合板或换用合适的平台尺寸。
- **俯视占地率。** 将同一平台三层的实际占用平面格合并去重，再除以一层可建格数。用它观察从上方看到的空地，结合逐层图判断空间集中在哪一层。
- **建筑占比。** 保留 50% 压缩目标。以建筑条目数除以平台外框宽 × 长 × 3，每件器件或线缆计一次。叠放的平台各有自己的三层容量。
- **体积。** 按尺寸统计平台数，另报俯视占用岛格、外框长宽、岛层数和各建筑层的器件数与线缆件数。俯视占地按叠放后的平面投影去重。
- **接线。** 列出所有全局发射、接收、频道及用途，再数飞线对。内部无线为零属于模块级的验收条件。首版现有样件用来审阅布线；跨整厂的合板、布线密度和时序仍按重导结果验收。
- **可复核。** 审阅包从原生蓝图读取坐标和接线，逐岛层、逐建筑层画图，并附同名接口表。使用以下命令查看三个现有样件。生成器的输出供人审核，电路修改和整厂联调以用户确认的布线为准。

```bash
parts=shapez2_tmam/blueprints/验收/电路
python -m shapez2_tmam.circuits.export_wiring_review \
  "$parts/原层读取/read-five-rows.spz2bp" \
  "$parts/堆叠前缀/pack-stack-row.spz2bp" \
  "$parts/配方回放/leaf-snapshot.spz2bp" \
  --output-dir TMAM电路审阅
```

打开 `TMAM电路审阅/index.html` 查看图。审阅表按平台列出 L0、L1、L2 的占地率。导出叶端锁存的三岛层布置时使用下列命令，游戏须解锁下层和上层岛面。

```bash
python -m shapez2_tmam.circuits.compiler_backend.leaf_snapshot \
  --stacked --output leaf-snapshot-stacked.spz2bp
```

中间岛层用 L 形平台推进锁存阶段并输出选列高度，上下岛层各用一块 2×1 平台保存六个字段。两组存储读取既有 `hold` 和 `phase` 频道。读高需要的跨层数据来自各字段已发布的频道。审阅图按原生岛格绘制 L 形平台的缺角，俯视面积按实际岛格去重。
