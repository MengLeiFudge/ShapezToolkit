# TMAM 电路走线与压缩

从 Python 方法生成 Shapez 2 电路时，方法提供信号与调用关系，生成器决定平台、器件位置、走线与原生蓝图编码。制作层的目标、配方及状态接口沿用[整厂约定](整厂约定.md)。

## 接线从网表开始

方法编译后的输入和输出先保留为逻辑端口。总装按信号依赖分组，再分配物理端口。内部信号走板内导线或同岛层板缝飞线。一发多收时铺一条可分支的主干，接收端沿主干取值。整厂外部接口的全局收发器集中布在板的一侧，数据口朝内。自主拆层的共用时钟另有六条私有计时频道，数据寄存器和模块间时钟分发走本地接线。

优先在同一岛层拼接相互调用的模块，利用建筑的 L0、L1、L2 三层布线。平台形状和朝向按有效可建区、板缝凹口和模块连接共同选择。1×4、2×4 及其旋转沿用原生锚点、建筑掩码和凹口。岛层叠放按实际接线可达性评估。

已有定步和调用控制组件使用无线往返延迟保存状态。迁移时按新布置核对复位、保存、分支采样和重复调用时的传播顺序。旧电路的无线反馈模型见[四阶段控制与等深锁存](../docs/proofs/08-circuits.md#s08-05)。有线写回按[有线状态写回](#有线状态写回)的独立时序协议验证。

## 布局和走线一起决定

1. **用直连摆出串联单元。** 一发一收的串联门优先让出入口相贴。方向、层位和位置一起试摆，需要间隔时计入真实导线代价。
2. **重复计算沿主干排布。** 将每列或每角的同构计算排好一份，再平移或旋转复用。共用信号沿主干分发，汇聚门按上游实际方向摆放。并行计算的读取时间由最长依赖链决定，重复调用的计算可时序复用。
3. **用短距飞线参与寻路。** 用游戏里的朝向、距离和配对规则产生跳线候选，让寻路直接比较直线、转弯、换层和跳线。板间先按连接关系相邻，再给对向凹口分配端点。发生拥塞时允许拆线重布或移动局部器件，只有无冲突的成图进入比较。
4. **按实际布线裁定平台。** 比较平台候选时把器件、线缆和端口全部算进去。单块放不下时按网表切分，并为穿过板缝的信号留实际接线位置。

这些做法来自整套参考蓝图。并行 MAM 展示了如何排同构计算，压缩版 Corner MAM 展示了同板跳线如何越过线路，Exo 与 Virtual Corner MAM 展示了不同尺度的跨板连接。

## 选优和验收

同功能、同接口且通过接线核对的方案，先比实际占用的 **1×1 岛格总数**，岛格相近再比原生建筑条目数。1×2 计 2 格，3×3 计 9 格，各岛层分别计入。器件、导线和长短距收发端点都计入建筑条目数。

各板的三维占用率、俯视占地率、长宽和全局收发器数量用于定位布局问题。三维按去重后的建筑占格除以各板三层可建格数之和。俯视按投影去重，并分别用可建面积和整个外框作分母。尺寸为 3×3×3 的全局收发器按 27 格计。

整厂先用逻辑网表和已布样件估算岛格。网表统计器件占格，同类型样件提供实际线路占格与板容量，再挑估算贡献最大的模块验证。整图导出后重读原生文件，逐项核对可建区、相交、逻辑端口驱动、飞线配对和采样时序。游戏内以实际放下后保留的建筑和信号表现验收。

## 四列原色读取

`ported_layout` 接受参数相同的多个 Python 方法。默认从西侧输入、东侧输出，可用 `--input-notch 名称=X,Y,L,N` 和 `--output-notch 名称=X,Y,L,E` 指定凹口。`N/E/S/W` 表示平台外侧，`L` 为 0 至 2。互相连接的两块板在同一岛层，将同一信号的发送与接收布在对向凹口。

布局器先合并重复门并裁掉无用门。仅使用反相时，直接反转比较器模式。同时使用两种极性时，正相从比较器与取反门之间的单格分支引出，两路共用一个比较器和一份比较常量。四门裁切链直接贴合。相同的输出子图成组试摆，条带可在建筑层之间平移，各条带的接点从共用主干取值。

短距飞线参与寻路，跳线须跨过已有器件或另一线网，并保持唯一配对。增量试摆失败时，可保留器件与凹口、拆掉现有走线，优先重布失败网并给历史拥塞位置加价。接口表记录直贴单元、带分支的比较单元、同构单元和飞线跨过的占用格。

```bash
out=.codex/tmp/deliverables/wired-row-dense
python -m shapez2_tmam.circuits.compiler_backend.ported_layout \
  shapez2_tmam/synthesis/shape_methods.py \
  --field q0=read_labeled_corner --field q1=read_labeled_corner_q1 \
  --field q2=read_labeled_corner_q2 --field q3=read_labeled_corner_q3 \
  --output "$out/row-two.spz2bp"
```

省略 `--platform` 时，生成器按拓扑深度估算适合的宽度，再从岛格较少的平台开始试布。需要核对指定平台时，可加 `--platform 1x2/0`。只指定一个字段可导出单列。

用 `python -m shapez2_tmam.circuits.export_wiring_review` 读入原生蓝图，指定 `--output-dir` 后打开 `index.html`。逐板表列出三层利用率、俯视占地、换层件和飞线端点。公开短距口朝外相邻岛格须空闲，审阅器逐口写入 `.ports.json`，存在堵口时报告验收失败并返回非零状态。`--audit` 可提供按蓝图文件名索引的门级对照和生成耗时。

## 单输出并行与多板总装

堆叠行编码 `pack_stack_row` 虽然只有一个出口，四个象限仍独立计算。布局器沿拼合树或同构的选值总线找分支，把两个或四个可分离分支排在公共分发汇聚板两侧。同构分支编一次，旋转复用。同一选值总线的驱动全部留在同一分区。单板在同岛格候选内按建筑条目选优；每条线的寻路和重布都有搜索上限。

```bash
out=.codex/tmp/deliverables/wired-five
python -m shapez2_tmam.circuits.compiler_backend.ported_layout \
  shapez2_tmam/synthesis/shape_methods.py \
  --field pack=pack_stack_row --output "$out/pack-stack-row.spz2bp"
python -m shapez2_tmam.circuits.compiler_backend.ported_read_five \
  --output "$out/read-five.spz2bp"
python -m shapez2_tmam.circuits.compiler_backend.ported_read_five \
  --decoder --output "$out/decoder-4q5l.spz2bp"
```

[平面总装器](../circuits/compiler_backend/ported_assembly.py) 按端口图选择同岛层外框、板位和凹口。公开端口只能从朝向空地的凹口选取，成图按原生端点及平台旋转复查。走廊可同时承载多路信号，跨板凹口与板内主干优先分层，板内寻路可用短距飞线越过实际障碍。`through` 可让共享出入口的信号共用一块走廊。

五层读列沿剩余图形逐层拆行，最低两层共用一块拆行板。普通模式发布 20 个带色单格。`--decoder` 发布有效位、五个原色行与每格的形状、颜色、占用、针、晶体，最低两行通过共用走廊分别送到颜色和材料判断板。`--check-targets` 接收目标短代码 JSON 数组，重读原生文件后对照公开输出。

## 有线状态写回

[自主拆层器](../circuits/compiler_backend/ported_auto_scan.md) 接收 `target` 和 `enable`，自动依次输出非空顶层 `top`、从 1 起算的 `original_layer` 与有效期 `sample`，扫完保持 `done`。换单前把 `enable` 拉低至少 96 信号刻。主时钟每 48 刻换相，每 384 刻采样一层。两路图形状态用有线寄存器保存。

```bash
python -m shapez2_tmam.circuits.compiler_backend.ported_scan_loop \
  --output .codex/tmp/deliverables/wired-autonomous/autonomous-scan.spz2bp
```

`--clock-only` 导出共用时钟与相位凹口表。`--external-phases` 导出外部逐相驱动的调试样件，其复位和保持期沿用同名接口表。

常速连续更新且每批至多四个信号刻是当前时序保证的运行条件。暂停后继续使用原布局，改线、换时钟或更换目标后按接口重新复位。

## 整厂迁移

按现有原生蓝图跟踪每条频道后，先定外部网关与共用时钟，再按计算职责迁移。逐部件岛格、频道、窄接口与迁移顺序见[整厂有线重构预算](整厂有线重构预算.md)。
