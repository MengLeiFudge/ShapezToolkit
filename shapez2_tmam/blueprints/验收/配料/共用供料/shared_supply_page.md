# 通用九道页的共用混合车供料

这张工道页接通地址 0–8 的六槽通路、四角基础料、七色结晶和六机堆叠。基础料按 `4+4+1` 共用三座 12 节站，结晶按 `2+2+2+2+1` 共用五座单节站。两端保持原六槽行、层和地址间距，可作为整线中段安装。控制沿用同容量的全线控制页。[九道工道蓝图](shared-supply-page.spz2bp) · [供料接点、支路和读带口](shared-supply-page.json)

## 供料接线与容量

| 路径 | 2 件/秒成品的持续要求 |
| --- | --- |
| 基础料图形带 | 每地址每角启用的图形带 2 件/秒。四道同时从同一车厢层取料时合计 8 件/秒，四条带每条须达到 2 件/秒。|
| 基础料原色管 | 每地址每角的制针红管 40 升/秒，普通染色最高 20 升/秒。四道同角制针时同车厢红层合计 160 升/秒，沿四条独立红管供料。|
| 结晶管 | 每地址在用色 40 升/秒。两地址同色时，共用成品色管和相应混色出口 80 升/秒。同为原色时，该原色有效卸货行也须达到 80 升/秒。|

基础料各组的共用站沿用每角三节 `C/R/S`、`W/空/空`、`r/g/b`。每个实际货层的四个卸货行分别接到四个地址，七种原料在整条路径内保持独立。各地址的末端转接台把三原色送进本地址原有的混色和制针支路。结晶站的共用混色板从东口和北口分别出七色，再送到两道各自的加工台。单道组用原七色混色件。`base_contacts` 和 `crystal_contacts` 可按地址查源站、通路和到达口，`base_stops` 与 `crystal_stops` 给出外部干轨的接点。

实测分别录入卸货带、独立原色管、结晶共用色管和末端支口。`--unload-belt` 与 `--pipe-rate` 使用各自持续速率。还要按车厢层和实际卸货行核对每趟有效货量、到站间隔及最长缺货期间的缓冲。满带实测沿用房间 #72。

## 换单清空口

先停领料，让旧件沿原工道排出。`changeover.returns` 给出每个地址的基础料成品回口、普通工道回口、堆叠 A/B 和堆叠回料读带器。`changeover.slot_exit` 给出一组末端六个槽带的读带器。逐台检查单边堆叠料、备角和拼合内部缓冲，再确认这五类回口及六槽末端确已排空。固定货种的原料带和原色管可保留库存。旧料确认清空后，以写入相位 3 连续保持至少 128 信号 tick，再启动新单。

页末保留六槽直通，废料沿下游已有的末端过滤与废料口清理。读带口用于观察，物料清空由现场确认。

```bash
python -m shapez2_tmam.circuits.factory_assembly.shared_supply_page --start 0 --output shared-supply-page.spz2bp
```

`--start` 采用全线地址。已核对地址 499–507 的重定位，同样为三座基础料站、五座结晶站；首尾六槽位置随绝对地址移动。
