# 顶针族递归准入

本件处理顶盖请求 `2`。低四行沿用冻结四槽的原色和层位。第五层按 `1703303` 的掩码生成红晶，其余列填 `Cu`。五行按层号 0～4 交给 G 扫描，允许第五层普通格为可选格。

逐列调用 `pin_prefix_limit` 核对 `pin_base_possible`，再调用 `column_admissible` 核对成员的列 A 前置。列 A 对空顶格和普通顶格给出相同结果，掩码内仍以晶体执行判定。候选模板的最低晶层必须比 pushed 的最低晶层更低。S 前缀保留所有晶体及其层位，因此 pushed 与 `_family_recipe` 接收的上层目标使用同一个最低晶层。两边的层号从 0 开始，无晶体用内部值 5 表示。

```powershell
$dir = 'shapez2_tmam/blueprints/验收/电路/顶针逆推'
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_descent_filter `
  "$dir/pin-cap-crystals.json" --output pin-descent-filter.spz2bp
```

默认使用下表的 G 调用频道，供共享扫描调度桥转接。给命令加 `--support "$dir/support-scan.json"` 可直接绑定已有扫描板。直接绑定时，由本件独占扫描输入频道。原生成件为 44 块平台、32,737 个建筑，原生 G 扫描板作为外接组件使用。

| 频道 | 信号与接法 |
| --- | --- |
| 1704902 | 递归请求。`2` 启动，保持到收到回报。 |
| 1703303 / 1704309 | 当前晶体掩码、冻结行就绪。 |
| 1704300–1704303 | 原色低四行，从底到顶，空层发空信号。冻结材料按 JSON 的 `source_materials` 接入。 |
| 1704304–1704308 | pushed 原色五行，从底到顶。 |
| 1705100–1705102 | 默认 G 调用的 `enable`、`grounded`、`optional_top`。两个选项在调用时均为 1。 |
| 1705103–1705107 | 默认 G 输入五行，按 0～4 顺序保持。 |
| 1705108 / 1705109 | 默认 G 回报 `done`、`accepted`。清除旧回报时令 `done=0`，完工时保持 `done=1`，并回整数 `accepted=0` 或 `1`。 |
| 1704900 / 1704901 | 本件回 `ready`、`ok`。列 A、顶针上界或最低晶层检查失败直接拒绝，其余等待本次 G 回报。 |

读入同一冻结候选的全部字段后保持稳定。局部判定预算为 1800 信号 tick。通过后等待 120 tick 并确认 G 的 `done=0`，再开启扫描。请求撤销后清空回报并释放 G 调用。

## 离线验收

与原生 support-scan 合装回放七组输入。真实族槽 `(7,4,4,4)` 的掩码 `8` 生成 `CuCuCucr`，最低晶层从 pushed 的 3 降到模板的 2，四项均通过。另核对 `pin_base_possible`、列 A、G 失败、最低晶层相同、pushed 无晶体及掩码 `0`。前三项本地判定通过而 G 失败时，扫描结果正确拒绝。默认私人频道还核对了旧 `done`、原色未齐及请求中断后重跑。模型采用板内组合传播及无线固定 12 信号 tick。游戏内时序待验。
