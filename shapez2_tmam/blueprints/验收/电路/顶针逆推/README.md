# 四列顶针候选枚举样件

样件包含一份单列游标、11 个原生校验模块和四列循环。导入整件蓝图即可连接目标和控制信号。此样件使用 1701800～1701903，替换同频道的四列循环样件。

在仓库根目录重导蓝图及同名频道表。自动布线可能耗时数分钟。

```powershell
py -m shapez2_tmam.circuits.compiler_frontend.pin_column_sample --output pin-column-sample.spz2bp
```

| 信号 | 频道 | 操作 |
| --- | ---: | --- |
| `enable` | 1701840 | 先保持 `0` 满 96 信号刻，再置 `1`。换目标时重复复位。 |
| `advance` | 1701841 | `0` 保留当前候选。候选就绪后置 `1`，等 `ready` 拉低再恢复 `0`。 |
| `q0` 至 `q3` | 1701842～1701845 | 接四列五层材料字，启动前接入，搜索和暂停期间保持。 |
| `ready` | 1701858 | `1` 时读取四列槽号、续读槽和自底向上的四格材料。 |
| `exhausted` | 1701859 | `1` 表示当前目标的结构候选已穷尽。 |

四个输出列分别占 1701865～1701870、1701871～1701876、1701877～1701882 和 1701883～1701888。各列按 `slot`、`next_slot`、`material_0` 至 `material_3` 排列。材料 `0` 表示有效候选中的空格。按 `ready` 采样整组。

用目标 `------P-:------Ru` 验收时，q0～q2 接 `Cu------:Cu------:Cu------:Cu------:Cu------`，q3 接 `Su------:Ru------:Cu------:Cu------:Cu------`。按原生接线回放，首组槽号为 `(0, 0, 0, 0)`，q3 材料为 `(1, 0, 0, 0)`。16 组槽号和材料与 Python 单列参考一致。每组暂停 216 信号刻期间，四列字段保持。确认后依序返回下一组。全部穷尽后复位换成 q0 底层为晶体的目标，返回无匹配。

样件占 49 块平台、66,950 个建筑。每列用一块平台选择写入、保持或清除，两块平台保存该列的六个字段。原生接线的 195 个接收器和 90 个发射器已核对频道和占地。离线回放按板内同拍和无线 12 信号刻计算。游戏内联动待验收。

## 把当前候选送给顶盖和保序标签模块

导入 `pin-column-select.spz2bp`。它从四列样件接收 `ready`、四个目标材料字和冻存的槽号与材料。整组候选就绪后保持 `advance=0`，把列号 `0`～`3` 送到 `1701904`。换列后保持输入至少 384 信号刻，再按 `1701906` 的 `valid=1` 读取。读完所需列之后再推进整形候选。

| 输出 | 频道 | 用法 |
| --- | --- | --- |
| `word` | 1701520 | 所选列五层目标材料字，直连 `pin-cap-column`。 |
| `z0` 至 `z3` | 1701521～1701524 | 所选列自底向上的四格材料，直连 `pin-cap-column`。`z0` 至 `z2` 也直连 `pin-source-rank`。 |
| `slot` | 1701905 | 所选列的命中槽号。 |
| `valid` | 1701906 | `1` 表示选中冻结候选。槽 `0` 和四格全为 `0` 都可以有效。 |

列号越界、为空或当前候选未就绪时，选择器发 `valid=0` 和空载荷。顶盖和来源序号各按同名频道表等待稳定。保序标签扫描仍需调用方提供层号和原色行。

在仓库根目录重导选择器及同名频道表。

```powershell
py -m shapez2_tmam.circuits.compiler_frontend.pin_column_select `
  shapez2_tmam/blueprints/验收/电路/顶针逆推/pin-column-sample.json `
  shapez2_tmam/blueprints/验收/电路/顶针逆推/pin-cap-column.json `
  --output pin-column-select.spz2bp
```

选择器占 6 块平台、4,763 个建筑。原生离线回放用同一份逐列读取一组冻结候选，验证了换列、空有效列、非法列号、继续后的槽号和复位输出，并与顶盖和来源序号的 Python 方法对照。
