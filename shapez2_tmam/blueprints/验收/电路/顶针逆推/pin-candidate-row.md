# 顶针候选原色行读取

导入 `pin-candidate-row.spz2bp`，另放置[四列候选样件](pin-column-sample.json)及原目标的[五层原色读取](../原层读取/read-five-rows.json)。行读取器内置选列器、保序标签扫描和整行拼合。原色行与四列目标材料字须来自同一切向。

| 信号 | 频道 | 操作 |
| --- | ---: | --- |
| `enable` | 1701920 | 每次读取前保持 `0` 满 96 信号刻。参数稳定并且四列候选就绪后置 `1`。 |
| `level` | 1701547 | 前态下部的层号，自底向上为 `0`～`3`。 |
| 目标原色行 | 1701200～1701204 | 自底向上的五个单层信号，空层发空信号。 |
| 四列候选 `ready` | 1701858 | 使用冻结候选，读取期间保持候选的 `advance=0`。 |
| 初始标签 | 1701532 | 留空。 |
| 原色 `row` | 1701924 | 先读 `ready`，再取本层原色行。 |
| 行 `ready` | 1701925 | `1` 表示整行可读。整行为空时 `ready` 也为 `1`。 |

保持层号、原色行和整份候选，启动后按 15,192 信号刻留出等待时间，并以 `ready=1` 作为采样条件。重复读取同一候选的下一层时，先把行读取器的 `enable` 置 `0` 满 96 信号刻，再提供层号并启动。读完整份候选后再推进。第 4 层的顶盖继续走顶盖模块。

默认控制频道为 1701920～1701934。整件同时占用选列和标签模块的原频道。使用本件时，移除同频道的独立选列器、来源序号、保序标签、来源格和整行拼合模块。

在仓库根目录重导蓝图和同名 JSON。

```powershell
py -m shapez2_tmam.circuits.compiler_frontend.pin_candidate_row `
  shapez2_tmam/blueprints/验收/电路/顶针逆推 `
  shapez2_tmam/blueprints/验收/电路/原层读取/read-five-rows.json `
  --output pin-candidate-row.spz2bp
```

样件占 29 块平台、30,421 个建筑。原生离线回放以 `P-P-P---:SbP-cg--` 为目标，同一候选按层号 `0 → 1 → 0` 读取，得到 `SbP-cg--`、空行、`SbP-cg--`。三次均在启动后 15,108 信号刻就绪。回放按板内同拍、无线 12 信号刻计算，游戏内联动待验收。
