# 原图与冻结候选共用的前缀闭包

合装件保留 79 板原件的两种切向、行编码、含晶预处理、五轮闭包和列 A 判定。原图读取器与封存读取器在原色行、四列材料字和预处理启动三个接点切换。两种模式共用 62 块原件平台。

| 信号 | 频道 | 用法 |
| --- | ---: | --- |
| `enable` | 1703000 | 每轮开始前置 0 满 432 信号刻，参数稳定后置 1 |
| `mode` | 1703001 | 0 读原图，1 读五层封存候选 |
| `optional_top` | 1703002 | 0 扫描顶层，1 预处理顶层支撑并将闭包首轮置空 |
| `column` | 1703003 | 查询所选切向的第 0～3 列 |
| 原目标 | 1600000 | 原图模式输入 |
| 封存有效位及五层原色 | 1702288～1702293 | 封存模式输入，五行由底到顶，空层保留空信号 |
| `chosen`、`exhausted` | 1703004、1703005 | 为 1 时分别表示选中切向、两向耗尽 |
| `alternate` | 1703006 | `chosen=1` 后读取。0 表示原向，1 表示逆时针转一格 |
| 查询列高度 | 1703007 | 对应 `column` 的高度 |
| 四列高度 | 1703008～1703011 | 选中切向的 q0～q3 |
| 五层原色行 | 1703012～1703016 | 选中切向，由底到顶，空层仍为空信号 |

保持选定输入及模式，等 `chosen=1` 再读取结果。封存模式下，有效位撤销会清除公开输出，本轮进入停机状态。运行中更换模式也会停机。将 `enable` 置 0 满 432 信号刻后可启动新一轮。

同名 JSON 的 `closure` 记录三个共用接点的位置。原色行映射到 `1703143`～`1703147`，材料字映射到 `1703116`～`1703119`，预处理启动映射到 `1703103`。预留频道范围是 `1703000`～`1703299`。

```powershell
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.dual_source_closure `
  shapez2_tmam/blueprints/验收/电路/双半形/auto-prefix-flywire.spz2bp `
  shapez2_tmam/blueprints/验收/电路/顶针逆推/pin-source-words.spz2bp `
  --output dual-source-closure.spz2bp
```

合装件共 101 块平台、124,288 个建筑、61 对短距口和 214 个唯一发射频道。原生离线回放按板内同拍、无线 12 信号刻核对。同一份图形分别从原图和封存口送入，两个模式在共用计算频道上的材料字、行数据和顶层输入一致，最终切向和四列高度也一致。`cbcr----:CucrCu--` 的备用切向为 1，四高度为 `2、2、0、1`。中间空层耗尽、封存撤销、恢复有效位后保持停机及复位重开均已核对。游戏内联动待验收。
