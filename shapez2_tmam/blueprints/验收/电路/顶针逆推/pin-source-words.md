# 冻结顶针候选的四列材料字

从封存控制接入 `1702289`～`1702293` 的五层原色行和 `1702288` 的整组有效位。每块平台读一列，按材料类别生成前缀闭包使用的五层材料字。

| 信号 | 频道 | 用法 |
| --- | ---: | --- |
| 封存五行 | 1702289～1702293 | 输入由底到顶，空层输入空信号 |
| 封存 `valid` | 1702288 | 整数 1 时发布四份材料字 |
| `alternate` | 1702340 | 整数 0 使用输入朝向，整数 1 将输入逆时针转一格后取列 |
| q0～q3 材料字 | 1702341～1702344 | 按当前切向输出。每份材料字的五个标记都位于 q0 |

接未转向的封存行时，切向取 `orient_cut` 同义信号。`alternate=0` 对应输入 q0、q1、q2、q3，`alternate=1` 对应输入 q1、q2、q3、q0。已经按当前切向封存的五行使用 `alternate=0`。

从底到顶，空格、普通块、针、晶体分别记为 `Cu------`、`Ru------`、`Su------`、`Wu------`。空列仍返回五层 `Cu------`，以保留全部层位。封存有效位撤销，或切向缺失、越界时，四路输出均为空信号。

切向和封存输入稳定后预留 1216 信号刻再采样。时序沿用组合编译的保持条件，整件批量导入或完整重载，保持固定接线，采用常速 Hybrid 或 AlwaysHighUPS，每批最多 4 信号刻。

```powershell
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_source_words `
  shapez2_tmam/blueprints/验收/电路/顶针逆推/pin-source-rows.json `
  --output pin-source-words.spz2bp
```

原生样件占 4 块平台、8115 个建筑，内部没有全局收发。解码后沿实际接线对照 Python 材料标记与切向，共核对 360 组单格与层位、混合材料和撤销。与四列枚举、五层读取、封存控制及原色读取合装后，206 个发射频道均唯一。游戏内联动待验收。
