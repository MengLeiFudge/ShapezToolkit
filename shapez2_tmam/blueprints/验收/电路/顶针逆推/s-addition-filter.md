# S 前态追加许可

逐层计算目标相对 S 前态的新增格。地面直接提供支撑。上层每组新增普通块只需一处直接下挡，普通块沿四列环相邻。新增针各自需要直接下挡。下挡读取目标的前一层，因此已在前一层追加的格也能提供支撑。空增量通过。

本件执行 `prefix_closure.unanchored_additions` 的四象限非晶分支，复用 `row_support.addition_needs_lower`。候选按 `Solver4._predecessors` 保留其原层位及目标中已有的晶体。若目标中的晶体位置缺失，则拒绝。K/G 条件由外部判断。

| 方向 | 频道 | 用途 |
| --- | --- | --- |
| 输入 | `1704700` | `1` 开始，`0` 复位 |
| 输入 | `1704710`–`1704714` | 目标五行，由底至顶 |
| 输入 | `1703513`–`1703517` | S 前态五行，由底至顶 |
| 输出 | `1704701` | 完成 |
| 输出 | `1704702` | 许可，完成时读取 |

空行发空信号。两组原色行在启动前给定，保持到完成。完成和许可保持到启动拉低。连续调用时将启动置 `0` 至少 48 信号 tick，再送下一组并启动。五层共用一套行计算，每层等待 2232 信号 tick，首次遇到缺少下挡或新增晶体的行即结束。通过路径的接口等待上界为 11400 信号 tick。

```bash
python -m shapez2_tmam.circuits.compiler_backend.s_addition_filter \
  --output s-addition-filter.spz2bp
```

原生件为 11 板、12,491 个建筑。离线回放覆盖全部 625 种单层非晶状态，以及 112 组整件。固定例覆盖针与普通块分组、四列环邻、对侧普通块经相邻块相连、前一层新增格支撑、已保留晶体支撑和空增量。另核对中途复位及结果保持。通过路径在 12 tick 无线模型中的最长实测为 11244 信号 tick。
