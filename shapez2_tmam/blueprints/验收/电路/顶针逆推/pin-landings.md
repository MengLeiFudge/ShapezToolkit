# 顶针非晶格落点筛选

读取冻结前态的四行和目标五行，从底向顶配对各列非晶格。每对来源和落点必须同形同色，落点不得高于顶针抬升后的位置，下降区间不能经过目标保留晶体。单独核对原底层占用与目标地面针，新地面针不参与逐格配对。普通格在原层水平相邻时必须落到同高。每个移动普通块至少有一处直接下挡，移动针各自需要下挡。

```powershell
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_landings `
  shapez2_tmam/blueprints/验收/电路/顶针逆推/pin-cap-crystals.json `
  --output pin-landings.spz2bp
```

导出同时生成同名频道表。`--channel-base` 可移动 1704500–1704599 预留段。输入原色、材料和行就绪与晶体筛选共用。冻结输入保持到请求结束，按 `landing_ready` 取数。等待预算见接口表的 `settling_budget_ticks`。

| 频道 | 信号 | 接法 |
| --- | --- | --- |
| 1704312 | 请求 | `1` 查落点和下挡，`2` 转发递归过滤。 |
| 1704503 / 1704504 | `landing_ready` / `landing_ok` | 落点及块条件的本地结果。 |
| 1704589 / 1704590 | `columns_ok` / `blocks_ok` | 分别读取逐列配对、同组等高与下挡结果。 |
| 1704549–1704564 | `cursors` | 按前态底层到第四层、每层 q0 到 q3 排列。非晶格对应其目标层号，空格与晶体沿用前一个落点。`-1` 表示尚未匹配，`-2` 表示失败。 |
| 1704502 | `rest_request` | 局部通过时转发图像请求 1，递归请求转发为 2。 |
| 1704500 / 1704501 | `rest_ready` / `rest_ok` | 接剩余图像条件和递归过滤。新请求回整数 `ok=0` 或 `1` 和 `ready=1`，保持到请求转空后清除。 |
| 1704310 / 1704311 | 晶体筛选的下游回报 | 局部失败直接回 `1,0`。通过后等待剩余过滤的本次回报。 |

剩余图像过滤还需核对最大族代表及掩码接触条件、删晶后活格的真实最大静止集合与推定集合相等，包含晶体与普通格粘连的情况。落点诊断和副本字段可供支撑扫描使用。制造证书及成品正向顶针核对沿用上层接口。

四列并行，每列共用一套落点和形色比对电路，按底到顶处理四层。每轮先选取原色行、材料和上一层游标，同时用本层匹配结果核对同组等高和下挡。采样时保存四个游标并记住本层是否失败。下一轮只读已保存的游标。最后一轮保存后，等逐列余量检查和下挡汇总稳定，再发布 `landing_ready`。请求撤销时清除游标和本地完成状态。

独立件占 46 块平台、75,580 个建筑。导出时核对原生收发频道，计算各轮的等待预算。优先在游戏中验收真实含晶落点、穿晶拒绝、同组异高、无挡以及连续请求和中途撤销。
