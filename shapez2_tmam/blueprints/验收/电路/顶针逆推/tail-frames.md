# 顶针父帧的原色行存储

保存顶针结果和追加目标，每组各五行。根的外层顶针边写深度 0，向叶端递增。成功路径回放从最深已写帧开始读，逐帧回到 0。

| 信号 | 频道 | 用法 |
| --- | --- | --- |
| `enable` | 1704200 | 置 0 清除全部帧和有效位，当前订单保持 1 |
| `read` | 1704201 | 帧号 0～2，空信号或 `-1` 撤销读取 |
| `write`、`capture` | 1704202、1704203 | 写深度 0～2。行数据稳定后给 `capture=1`，保持满采样期再撤销 |
| 输入原色 | 1704230～1704239 | 目标五行在前，顶针结果五行在后，各从底向顶 |
| `valid` | 1704205 | 所选帧已保存时为 1，合法空行保持空信号 |
| 输出原色 | 1704220～1704229 | 顺序与输入一致 |

改变写深度、输入行和读取地址前先撤销捕获信号。复位、捕获和读号切换各预留 1816 信号刻，采样时检查有效位。覆盖父帧会清空更深的帧。已写帧在当前订单的两遍回放间保持有效。

```bash
python -m shapez2_tmam.circuits.compile_tail_frames --output tail-frames.spz2bp
```

原生件使用 11 块 3×3 平台。离线按板内组合和无线 12 信号刻回放，三层倒序读取、撤销读号、合法空行、写父帧清子帧和复位均通过。游戏内时序待验。
