# 动态 S 前态枚举

输入五路原色单层和四列非空格数上界。电路从底向顶为各列非空格编号，记录最高晶体高度，再按 `Solver4._predecessors` 的堆叠前缀闭包从顶向底补齐必保留的格。四列枚举从下界开始，逐列计数上界取输入上界与实际格数的较小值。`q3` 最快，`q0` 最慢。

```sh
python -m shapez2_tmam.circuits.compiler_frontend.s_predecessor_dynamic --output s-predecessor-dynamic.spz2bp
```

导出同时生成同名 JSON 频道表。`--channel-base` 可移动完整的 200 个预留频道，默认预留 1703500–1703699。生成器复用固定枚举器的计数和进位，以及验收册中的 `read-labeled-corner` 与 `pin-source-row` 原生计算板。

| 频道 | 信号 | 接法 |
| --- | --- | --- |
| 1703500 | `enable` | 置 `0` 后换输入。五行和上界稳定、`enable` 保持 `0` 满 4096 信号 tick 后置 `1`。 |
| 1703501 | `advance` | 等 `ready=1` 后读取当前候选，再置 `1`。见 `ready=0` 或 `exhausted=1` 后恢复 `0`。连续高电平只确认一笔。 |
| 1703502 / 1703503 | `ready` / `exhausted` | 前者指示当前候选可读。后者在末项确认或范围内没有非空候选时置 `1`，保持到复位。 |
| 1703504–1703508 | 原色输入 | 从底到顶固定五路。每路为原色单层，空层用空信号。 |
| 1703509–1703512 | 上界输入 | `q0` 到 `q3`，整数 `0`～`5`，无额外裁剪时各写 `5`。 |
| 1703513–1703517 | 候选原色行 | 从底到顶固定五路。保留原色和原层位，空层用空信号。 |
| 1703518–1703521 | 保留计数 | `q0` 到 `q3`。保留格数为整数，`0` 为合法值。 |

整件批量导入或完整重载，保持接线和频道独占。运行期间保持五行和上界稳定，单候选稳定等待为 1632 信号 tick，调用方按 `ready` 取数。接地和尾料锚定可对 `ready` 时的五行执行，过滤失败后同样以 `advance` 继续。

## 动态验收

先送 `CuRgSbWm:crcg----:--------:--cbCy--`，逐层写入五个输入。第 3、5 层为空。四个上界输入均为 `5`。应依次读到下表，两次的第 3、5 层都为空。

| 计数 | 第 1 层 | 第 2 层 | 第 4 层 |
| --- | --- | --- | --- |
| `(2,3,2,0)` | `CuRgSb--` | `crcg----` | `--cbCy--` |
| `(2,3,2,1)` | `CuRgSbWm` | `crcg----` | `--cbCy--` |

同一份蓝图连续回放七组输入，核对了 24 个原生候选、四列上下界、复位、旧确认高电平、越过空候选和上界耗尽。回放采用板内组合、无线固定 12 tick 模型。离线应用 Python 的接地和尾料判据后，七组顺序均与 `Solver4._predecessors` 一致。

样件为 81 块 3×3 平台、98,193 个建筑。游戏内时序待验。
