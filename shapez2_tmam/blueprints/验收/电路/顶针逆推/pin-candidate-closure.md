# 冻结顶针候选的自动前缀闭包

合装件从封存频道直接读取五层原色。试切向时逐层旋转，并用配套的四列读取件生成同一切向的材料字。原色行始终是五个独立信号，旋转不会改变层位。原 79 板蓝图中的含晶预处理、五轮闭包、列 A 判定和可选顶盖继续参与计算。

| 信号 | 频道 | 用法 |
| --- | ---: | --- |
| `enable` | 1702400 | 每次换候选或模式时置 `0` 满 432 信号刻，参数稳定后置 `1` |
| `optional_top` | 1702401 | `0` 让闭包扫描顶层，`1` 由可选顶盖板预处理支撑并给闭包首轮发空信号 |
| `column` | 1702402 | 在选中的切向中查询 `0`～`3` 列 |
| 封存有效位 | 1702288 | `1` 表示五行已封存且有效 |
| 封存原色行 | 1702289～1702293 | 第 1～5 层，保持当前候选的原始列序和空层 |
| `chosen` / `exhausted` | 1702403 / 1702404 | `1` 表示已经选中切向或两种切向均失败 |
| `alternate` | 1702405 | `chosen=1` 时，`0` 为原向，`1` 为逆时针转一格 |
| 查询列高度 | 1702406 | 对应 `column` 的前缀高度 |
| 四列高度 | 1702407～1702410 | 同一选定切向的 q0～q3 |
| 原色行 | 1702411～1702415 | 选定切向的第 1～5 层，空层发空信号 |

接到 `chosen=1` 后读取高度和原色行。保持候选五行和有效位，直到下游读完。撤销 `enable` 或封存有效位会清除公开状态和数据，下一组启动前按 432 信号刻复位。整件使用 `1702400`～`1702629`，可与目标图形的自动闭包同场使用。

79 板原件的三个替换点是 `1701200`～`1701204` 的转向原色行、`1700963`～`1700966` 的同切向材料字，以及 `1700932` 的材料就绪位。候选版移除原图朝向、原层和串行读列的 17 块平台，并把这些接点迁入自己的频道段。同名 JSON 的 `closure` 给出迁移后的频道。每个切向等待材料字稳定后才启动含晶预处理。合装件已包含四列材料字读取器。

```powershell
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_candidate_closure `
  shapez2_tmam/blueprints/验收/电路/双半形/auto-prefix-flywire.spz2bp `
  shapez2_tmam/blueprints/验收/电路/顶针逆推/pin-source-words.spz2bp `
  --output pin-candidate-closure.spz2bp
```

样件占 80 块平台、102,013 个建筑，保留 61 对原生短距端口。原生离线按板内同拍、无线 12 信号刻回放。`CuRuSuWu` 选原向，`cbcr----:CucrCu--` 试完两个切向后选备用方向，四高度为 `2、2、0、1`。保留中间空层的 `Ru------:--------:Ru------` 走完两种切向并返回 `exhausted=1`。五层圆柱切换可选顶盖时，编码顶层仍在，闭包首轮输入按模式切换。接收封存有效位撤销后，公开状态、高度及原色行均清空。游戏内联动待验收。
