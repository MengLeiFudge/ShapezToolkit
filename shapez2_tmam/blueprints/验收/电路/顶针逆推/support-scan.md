# 四象限五层 K/G 支撑检查

输入通过列 A 的五层网格。五行用独立的原色信号，空层保留为空。行传播从地面向上，沿相邻非针格横向扩展，沿竖直连续晶体向下补全。K 模式把针作为额外种子，G 模式仅从地面出发。可选顶格模式允许第五层普通格未被标记。每根针的正下方仍须有格，地面针除外。[十次行闭包证明](../../../../docs/proofs/01-foundations.md#s01-18)

| 信号 | 频道 | 用法 |
| --- | --- | --- |
| `enable` | 1704410 | 置 0 满 96 信号刻后换输入。输入稳定后置 1 并保持 |
| `grounded` | 1704413 | 0 为 K，1 为 G |
| `optional_top` | 1704414 | 1 允许第五层普通格作为可选格 |
| 五行 | 1704420～1704424 | 底层到顶层，保持至完工 |
| `done`、`accepted` | 1704412、1704416 | `done=1` 时采样判定，`accepted=1` 表示通过 |
| 可达标记 | 1704425～1704429 | 每层被标记的格用 `Cu` 表示，其余为空 |
