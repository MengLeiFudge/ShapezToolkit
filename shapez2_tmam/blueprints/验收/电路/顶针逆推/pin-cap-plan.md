# 顶针族顶盖参数枚举

把 `pin-cap-plan.spz2bp` 接到单次顶针层控制和冻结的四列候选。电路从 15 到 0 检查顶盖晶体掩码。既有的单列顶盖判定负责排除目标顶层已有晶体和加晶后列 A 不成立的列。通过整图像过滤的每个掩码发布一次模板。收到模板耗尽回报并且还有尾针余量时，再请求递归过滤。

成员按 `PinFamily.members()` 的顺序从 `q3` 向 `q0` 进位。掩码覆盖的列固定为 0，由掩码生成晶体。其余列依次取 0 空格、1 普通块 `Cu`，下方有格时还可取 2 针。当前四槽的全部允许族及成员结束后，发布 `kind=0`，单层搜索随后推进四列槽。四列 `ready` 拉低后重置掩码和成员计数。

```powershell
$inputDir = 'shapez2_tmam/blueprints/验收/电路/顶针逆推'
py -B -X utf8 -m shapez2_tmam.circuits.compiler_frontend.pin_cap_plan `
  "$inputDir/pin-layer-search.json" "$inputDir/pin-column-loop.json" `
  --output pin-cap-plan.spz2bp
```

导出同时生成同名 JSON。`--channel-base` 移动私有预留段，默认 1703740–1703839。样件使用四列候选的原材料字和冻结材料字段，频道详见接口表。

| 信号 | 频道 | 约定 |
| --- | --- | --- |
| `enable` / `tuple_ready` | 1703300 / 1701858 | 两者为 1 时工作。开始或更换冻结四槽前，至少有一个信号保持 0 满 48 信号 tick。 |
| `plan` / `reject` | 1703312 / 1703313 | 单层控制请求参数。`reject=1` 处理模板耗尽，`2` 处理成员耗尽。 |
| `plan_ready` / `kind` / `mask` | 1703301 / 1703302 / 1703303 | `ready=1` 时读取参数。`kind=1` 为模板，`2` 为成员，`0` 为当前四槽查完。掩码最低位对应 `q0`。 |
| `members` | 1703308–1703311 | `q0` 到 `q3` 的成员三值。 |
| `remaining_pins` | 1703740 | 当前层后还能使用的尾针次数，整数 `0`～`3`。在同一批次保持稳定。 |
| `filter_ready` / `filter_ok` | 1703741 / 1703742 | 接到新请求后，稳定送出 `ready=1` 和整数结果 `ok=0` 或 `1`。保持到请求转空，再清除回报。 |
| `filter_request` | 1703743 | `1` 请求整图像过滤，`2` 请求递归过滤。与当前 `mask` 一起读取。 |
| `crystal_allowed` | 1703775–1703778 | `q0` 到 `q3` 的加晶许可，随冻结四槽保持。 |

## 外接过滤

- 收到 `filter_request=1` 时，用冻结四槽恢复前四层，并以 `pin_families` 对照目标图形与当前掩码。回报应覆盖最大族代表的顶针像和本掩码必需的顶盖接触。可用 `_required_cap_contacts` 及已核实的顶针像判断得到相同结果。
- 收到 `filter_request=2` 时，对当前族模板检查 `pin_base_possible`、允许可选顶格的接地支撑和最低晶层严格下降。还要核对 `PinFamily.members()` 的列 A 前置条件。无成员可发时回 `ok=0`。本层的 `remaining_pins` 已由遍历板检查。
- 两种请求都先等待上一回报清除。整图像或递归条件仍待判断时，让 `filter_ready` 保持 0。遍历器继续等待当前掩码。单层控制按原证书与正向顶针回放接口判定接受。

## 离线验收

参数板和原生单层搜索控制板一起回放，封存、闭包、证书和回放端口使用按接口生成的回报。模型为板内组合传播及无线固定 12 信号 tick。

| 输入 | 对照结果 |
| --- | --- |
| `P-P-P-P-:CuRuSuWu:CuRuSuWu:CuRuSuWu:CuRuSuWu`，槽 `(0,0,0,0)`，余量 0 | 16 个掩码各给一个模板，成员数为 0。首个整图像回报延迟 220 个无线周期，等待期间无穷尽。 |
| `P-P-P-P-:P-P-P-P-:CuCuCuCu:cr------:cr------`，槽 `(7,4,4,4)`，余量 1 | 8 个模板、81 个成员，包含单列有针和无针的两种域。掩码、三值和次序逐项匹配 Python `attempts`。 |
| 两组不同冻结四槽及一次模板成功 | 核对整图过滤排除非法掩码、递归过滤为假、旧回报清除、批次复位，以及成功后保持参数。 |

样件为 26 块平台、32,991 个建筑。游戏内时序待验。
