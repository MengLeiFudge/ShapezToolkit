# S 候选并行筛选

动态 S 枚举器有新候选时，本件同时启动追加许可和 K/G 支撑扫描。任一项失败就自动跳过。两项都通过时，候选原色行和保留计数保持到上层拒绝。推进前先撤销两项扫描并等两个完成位清零。

| 频道 | 用途 |
| --- | --- |
| `1704800` | `1` 启动，`0` 取消并复位 |
| `1704801` | 拒绝当前候选。先等 `ready=1`，再从 `0` 置 `1`。看到 `ready=0` 后恢复 `0` |
| `1704802` / `1704803` | 候选可读 / 枚举已穷尽 |
| `1704710`–`1704714` | 目标原色五行，由底至顶 |
| `1703509`–`1703512` | 四列计数上界，整数 `0`–`5` |
| `1703513`–`1703517` | 候选原色五行，由底至顶 |
| `1703518`–`1703521` | 候选四列保留计数 |
| `1704413` | `0` 检查 K，`1` 检查 G。G 流程由上层保证原目标通过列判据 |

空行使用空信号。目标原色、计数上界和 K/G 模式保持到搜索结束。合装使用普通支撑模式时，将 `1704414` 置 `0`，`1704430`–`1704432` 保持空。上层可将候选保持到另一项查询结束，随后发新的拒绝请求继续枚举。持续为 `1` 的旧拒绝信号只作用于已确认的那一项。

```bash
scope=shapez2_tmam/circuits
python -m shapez2_tmam.circuits.compiler_backend.s_candidate_search \
  --enumerator "$scope/compiler_frontend/s-predecessor-dynamic.spz2bp" \
  --addition "$scope/compiler_backend/s-addition-filter.spz2bp" \
  --support 'shapez2_tmam/blueprints/验收/电路/顶针逆推/support-scan.spz2bp' \
  --output s-candidate-search.spz2bp
```

省略三个部件参数可导出 8 板控制器。合装将枚举目标改接 `1704710`–`1704714`，支撑扫描改读候选 `1703513`–`1703517`。`--grounded-channel` 可改接 G 模式输入。枚举器采用严格比较修订 `4ad26f4`，追加许可采用 `faea55e`。

合装件为 136 板、154,489 个建筑，259 个发射频道各有一个发射器。原生离线回放四批共检查 15 个候选，公布的 7 个按 Python `Solver4._predecessors` 顺序逐项匹配。对照回放覆盖两项筛选分别提前失败、等旧完成位清零、持续拒绝只推进一次、中途取消和无候选穷尽。游戏内时序待实机验收。
