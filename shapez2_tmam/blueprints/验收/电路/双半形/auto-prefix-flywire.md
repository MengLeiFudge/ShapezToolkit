# 自动前缀闭包三参数飞线合装

合装件以 `c7e3067` 的 81 板闭包为基线。行、下层、地面标志共用一块参数板，经过三对同层飞线接双板编码器。这三块板位于原占地内的 `(10,4,0)`、`(13,4,0)`、`(16,4,0)`。原闭包保留整件批量导入或完整重载的时序要求。

在包含 `c7e3067` 对应验收蓝图和 `e68c3c6` 飞线生成模块的检出中，可以重导合装件。

```bash
python -m shapez2_tmam.circuits.compiler_backend.auto_prefix_flywire \
  --baseline shapez2_tmam/blueprints/验收/电路/双半形/auto-prefix-scan.spz2bp \
  --output auto-prefix-flywire.spz2bp
```

| 指标 | 81 板基线 | 飞线合装 |
| --- | ---: | ---: |
| 五行接线平台 | 20 | 18 |
| 全部平台 | 81 | 79 |
| 建筑 | 104,188 | 101,961 |
| 无线接收器 | 300 | 291 |
| 无线发射器 | 173 | 170 |
| 飞线对数 | 58 | 61 |

`1701240`–`1701242` 由飞线替代。参数与编码器之间省去一次 12 信号 tick 的无线传递，原采样等待仍适用。原生离线对照覆盖普通模式、可选顶格、换向、两向耗尽和中途复位。169 个无线输出在 186,576 信号 tick 内逐拍一致。编码器的内部频道 `1700881` 提前更新，锁存后的五行、闭包启动和 `1701584`、`1701585` 的发布时刻一致。游戏内时序待验。
