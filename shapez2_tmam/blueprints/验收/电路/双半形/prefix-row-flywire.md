# 五行编码邻层飞线对照

```bash
python -m shapez2_tmam.circuits.compiler_backend.prefix_row_flywire \
  --baseline shapez2_tmam/blueprints/验收/电路/双半形/prefix-scan-wiring.spz2bp \
  --output prefix-row-flywire.spz2bp
```

样件替换五行编码的 `below` 私有频道 `1701241`。下方邻层选择板移到双板编码器西侧，三个平台同岛层相邻。发送口在岛内 `(37,9,0)`，接收口在 `(-18,9,0)`，相隔 5 格。生成器核对原有飞线、新增飞线和每个保留输入端的实际来源。

| 指标 | 原无线版 | 飞线样件 |
| --- | ---: | ---: |
| 平台 | 22 | 22 |
| 建筑 | 24,335 | 24,358 |
| 全局接收器 | 74 | 73 |
| 全局发射器 | 38 | 37 |
| 飞线对数 | 7 | 8 |

飞线让邻层数据少经过一次 12 信号 tick 的无线传递。样件沿用原采样等待，五行编码结果从 `1700770` 到 `1700774` 发布，编码完工和闭包启动分别为 `1701252` 和 `1700760`。用 12 tick 无线与板内组合传播模型逐拍对照了这七个输出，共 50,988 信号 tick。覆盖五层原色、上部空层、两种前置完工顺序和中途复位。游戏内时序待验证。
