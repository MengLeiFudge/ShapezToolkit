# 双半形工序控制

`pair-writer.spz2bp` 包含四角的槽位调度、紧柱六字段、角释放、半形拼合、尾料逐层堆叠和一份实体写入桥。它使用 58 块 3×3 平台。合装件已经包含本目录的独立工作板、紧柱调用和角释放板。导入合装件时只放一份各频道的发送器。

| 接点 | 频道 | 用途 |
| --- | --- | --- |
| 选列及回读的前缀高度 | 1700873、1700766～1700769 | 当前列号由工序控制发布。四列高度来自自动闭包。 |
| 工序阶段和调用种类 | 1701690、1701691 | 依次制前两角、拼前半、制后两角、拼后半、合并、添尾料及恢复方向。 |
| 输出槽和输入槽 | 1701692～1701694 | 固定分配槽 0～2 存成品和两半。输入槽 `-1` 表示缺料，槽 `0` 可用。 |
| 指令来源 | 1701740 | `1` 紧柱，`2` 释放，`3` 拼合，`4` 追加。 |
| 子方法运行和完工 | 1701761、1701766 | 调用方先复位，再启动并等待完工。运行期间保持选择和参数。 |
| 本笔写入字段、地址 | 1680001～1680007 | 接实体提交桥。实体在当前地址收齐字段后返回确认。 |

拼合会按实际输入槽跳过空半形。尾料读五份原色行 `1701200` 至 `1701204`、前缀高度和切向。空层跳过，第一份非空尾料可直接放入空的目标槽。每层装料后原先已有下料时才堆叠。各子方法的空步位等字段稳定后直接推进，有配方的步位等同址确认。

本件用于单笔写入和工序联接。上层提供角原料、槽位及顺序，并在配方回放验证后发布整单长度和放行信号。完整动态角调用、整单发布及游戏内满带仍待接续。 [接口表](pair-writer.json)

在仓库根目录重导合装蓝图和各板接口。

```bash
python -m shapez2_tmam.circuits.compile_pair_writer \
  --circuits shapez2_tmam/blueprints/验收/电路/双半形 --output-dir pair-writer
```
