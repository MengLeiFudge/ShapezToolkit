# 制角与双半形共用配方写入桥

将本确认器与验收分册中的 `pair-writer` 合装。已有 `pair-sequence-bridge` 时，用本件替换。确认器占 47 块平台，合装共 105 块平台、114,493 个建筑。导出器解码两件蓝图，检查 202 个全局发射频道及接入端口。

```bash
circuits=shapez2_tmam/blueprints/验收/电路/双半形
python -m shapez2_tmam.circuits.compiler_backend.pair_corner_bridge \
  --writer "$circuits/工序控制/pair-writer.spz2bp" \
  --dense-clock "$circuits/dense-confirmed-call.json" \
  --output pair-corner-bridge.spz2bp
```

| 频道 | 方向 | 信号 |
| --- | --- | --- |
| `1702052` | 主确认器 → 制角 | `kind 1` 的总运行信号 |
| `1702053` | 制角 → 主确认器 | 整角完工。复位后发整数 `0`，最后一个子步骤完成后发 `1` |
| `1701636` | 制角 → 写入确认器 | 子步骤来源。`1` 紧柱，`2` 释放 |
| `1701637` | 制角 → 写入确认器 | 子步骤请求。整数 `0` 复位，`1` 请求 |
| `1701638` | 写入确认器 → 制角 | 当前子步骤的有效完工。未完成或未取得写入权时为 `0` |

收到 `1702052=1` 后，先保持 `1701637=0` 至少 96 信号 tick，并发布该子步骤的稳定参数。随后拉高 `1701637`，保持来源和参数直到 `1701638=1`。每个子步骤完成后重新拉低 `1701637`，维持至少 96 tick 并等 `1701638` 回到 `0`，再开始下一个。结束制角时保持子步骤请求为 `0`，由 `1702053` 向主确认器报整角完工。

确认器在拉高共用写入启动 `1701761` 前，检查紧柱和释放时钟的内部状态归零以及公开完工 `1701766` 已撤销。启动后只接受当前来源的内部完工和公开完工。`kind 2/3/5` 选择来源 `3`，`kind 4` 选择来源 `4`，此时制角子步骤请求不会进入共用写入桥。中断订单时同时复位 `1701695` 和实体工道，再从地址 `0` 重开。

离线回放使用 `pair-writer` 和确认器的原生接线及 12 信号 tick 的无线模型。制角子步骤请求、整角完工和实体地址 ACK 由模型给出。共验证 37 笔写入，覆盖紧柱、释放、拼合、追加和切向恢复，还核对了旧公开或内部完工残留、相同来源连续请求、无写入权时发起请求，以及首笔中断后重用地址 `0`。游戏内联调待验。
