# 成功路径串行回放

外层搜索选定一条路径后，提供已冻结的叶端输入、父帧和帧数。回放先让叶端制造前态，再按父帧从叶到根的顺序追加。叶端和尾帧共用六字段写入桥，工道地址连续递增。最后一个方法的完工信号清零后，`1701699` 才向两遍控制报告整条路径完成。

| 频道 | 用途 |
| --- | --- |
| `1704000` | 冻结父帧数，整数 `0`–`3`，两遍期间保持 |
| `1704201` | 父帧读号，按 `帧数−1` 到 `0` 递减；空信号撤销读取 |
| `1704205` | 同一读号的数据有效，撤销读取后清零 |
| `1704220`–`1704224` | 父目标五行，由底至顶 |
| `1704225`–`1704229` | 冻结顶针结果五行，由底至顶 |
| `1704003` | 回放阶段，`0` 待机、`1` 叶端复位、`2` 叶端运行，`3`–`12` 依次复位和回放父帧，`13` 完成 |
| `1701699` | 整条路径完成 |

外接帧存储按根深度编号，根帧为 `0`。回放先撤销上次读号，等有效位以及叶端和尾帧的完工信号清零，再读下一帧。读号保持至少 1920 信号 tick 且有效位为 `1` 后才启动尾帧。有效位一直为 `0` 时，回放保持当前读号等待。两遍共用同一份冻结帧，不在两遍之间清除帧存储。

## 重导

先按 [尾帧写入说明](../顶针逆推/tail-frame-writer.md) 将三块尾部方法板加到叶端 writer，生成 `pair-writer-with-tail.spz2bp`。然后导入方法确认器、制角排程和父帧存储。已冻结的叶端信号接 `1703002`、`1703006`–`1703016` 和 `1703116`–`1703119`，整单目标接 `1600000`。

```bash
parts=shapez2_tmam/blueprints/验收/电路/双半形/工序控制/自动制角
python -m shapez2_tmam.circuits.compiler_backend.success_path \
  --writer pair-writer-with-tail.spz2bp \
  --caller "$parts/pair-corner-stream-bridge.spz2bp" \
  --corner-jobs "$parts/corner-jobs.spz2bp" \
  --frame-store shapez2_tmam/blueprints/验收/电路/顶针逆推/tail-frames.spz2bp \
  --two-pass --output success-path.spz2bp
```

省略 `--frame-store` 可接独立的父帧存储。省略 `--two-pass` 时，路径模块用 `1701695` 启动，仍在 `1701699` 报整条路径完成。

## 离线回放

含两遍控制及三层帧存储的蓝图为 294 板、286,581 个建筑，502 个全局发射频道各有一个发射器。

使用真实父帧连续核对 `3→2→1→0` 帧的四单，逐级读取顺序与根深度一致。每单虚拟与实体的地址从 `0` 连续推进，两遍六字段及最终实体存储一致。零帧只执行叶端。必须尾针目标 `P---P---:Cu------:crCu--Cu` 的动态两遍各为 75 笔，最后一笔是父帧顶针。Python 独立回放只在槽 `0` 留下目标。游戏内时序留待实机验收。
