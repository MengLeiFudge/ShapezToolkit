# 配方主控的虚拟验收与实体写入

第一遍由虚拟六槽提供地址、请求和 ACK。主控完工后，控制器锁存通过位、唯一槽 0 的结果与累计长度。第二遍复位并重启同一主控，将它接到实体地址、请求和回读 ACK，同时在实体原频道发布订单元数据和六字段。实体运行与供料由本件门控。

| 方向 | 频道 | 信号 |
| --- | --- | --- |
| 输入 | `1600000` | 原目标，开单后保持至生产结束 |
| 输入 | `1702850` | 批次启动，整数 `0` 复位，`1` 运行 |
| 输入 | `1702851` | 允许供料请求 |
| 输入 | `1640060` | 实体站点已清空确认 |
| 输出 | `1702852` | 当前阶段，`0` 待机、`1` 虚拟回放、`2` 复位切换、`3` 实体写入、`4` 核对入库、`5` 可供料、`6` 停机 |
| 输出 | `1702853` / `1702854` | 停机 / 第二遍完成 |
| 输出 | `1640030` / `1640059` | 实体运行 / 实体供料 |
| 输出 | `1640043`–`1640045` | 虚拟验收锁存的长度、成品、通过位 |
| 输出 | `1640002`–`1640007`、`1640046` | 实体六字段和提交地址标签 |

开单前将 `1702850` 置 `0`，按工道协议排空。提供稳定的原目标和选定原色行、材料字、高度、切向，再置 `1702850=1`。两遍之间保持这些订单输入，作业地址和当前列由方法主控推进。第一遍期间实体运行和供料口均为 `0`，实体字段为空。

第一遍通过后，控制器保持方法主控复位至少 192 信号 tick，确认旧完工清零、实体处于复位且已清空，再从地址 `0` 发送第二遍。收到第二遍完工后，等实体 `1640057=1` 才置 `1702854=1` 并允许供料。虚拟验收失败或目标撤销时停机，重新开单须先复位批次。

## 重导蓝图

固定含晶样件内置六步配方，目标为 `CucyRuRu:CuCuCuCu`。接六工段的双回读写入控制与存储即可离线核对两遍。

```bash
python -m shapez2_tmam.circuits.compiler_backend.two_pass_recipe \
  --output two-pass-recipe-sample.spz2bp
```

动态版合装 86 板写入、47 板方法确认器和 21 板制角排程，从共用闭包读取选定前缀。实体页签沿用原频道，生成器重绑合装件内的六路握手接收器。

```bash
parts=shapez2_tmam/blueprints/验收/电路/双半形/工序控制/自动制角
python -m shapez2_tmam.circuits.compiler_backend.two_pass_recipe \
  --writer "$parts/pair-writer.spz2bp" \
  --caller "$parts/pair-corner-stream-bridge.spz2bp" \
  --corner-jobs "$parts/corner-jobs.spz2bp" \
  --output two-pass-recipe.spz2bp
```

固定版为 62 板，动态版为 254 板。两版的同名 JSON 给出实体接口、重绑频道和额外外部输入。

离线按 12 信号 tick 无线模型连接实体双回读控制及逐地址存储。固定样件两遍的地址均为 `0`–`5`，第二遍逐字段与配方一致。覆盖错目标、第一遍撤销、实体未清空、第二遍写到一半时撤销及重新上目标仍锁止。共用闭包给直接落角样例前缀 `3、3、0、3`，给悬空样例 `3、3、5、5`。两份分别写入 87 和 175 道，两遍逐地址字段与两块实际存储一致。87 道样例划出 94 个地址，末七道为空并直通。虚拟遍不供料，实体末笔与成品核对通过后才开放供料。游戏内时序待验。
