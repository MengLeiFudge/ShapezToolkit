# 通用九道页的六槽中继缩短版

四角合板后的每道工段有四块纯六槽中继、三块取料与加工台（取料、通用加工、六机堆叠）、两块回料连接台（北转、合流）和一块收料台。把工段间距从 18 个岛格缩到 12 个，可以每道去掉两块纯中继。9 格间距下，相邻的基础料卸货站和上道备料台占地重叠。

| 布局 | 通用原版 | 四角合板 | 六槽缩短 |
|---|---:|---:|---:|
| 单道续接页，大平台 | 32 | 31 | 29 |
| 九道续接页，大平台 | 288 | 279 | 261 |
| 九道续接页，建筑 | 241,236 | 239,814 | 233,766 |
| 九道成品末页，大平台 | 285 | 276 | 260 |
| 486 道含公共控制，大平台估算 | 15,557 | 15,071 | 14,101 |

486 道按 53 张续接页、1 张成品末页和 8 块公共控制板计算。相对四角合板版共少 970 块大平台。

每道整段平移，站场与工段的相对坐标、四路同料的车厢层位、两路操作数、六台堆叠机和六字段频道沿用四角合板版。每个槽独占一条原规格带，两个保留的中继板均是六进六出，保持每槽一带的结构带宽。

## 导出和对接

在仓库根目录运行下列命令。一起生成蓝图和同名 JSON，接线表收录页端六带、车站来去轨、成品口及堆叠观察点。

```sh
python -m shapez2_tmam.circuits.factory_assembly.compact_slot_pages --start 0 --count 9 --output compact-slot-page.spz2bp
python -m shapez2_tmam.circuits.factory_assembly.compact_slot_pages --start 477 --count 9 --terminal --output compact-slot-page-final.spz2bp
```

`--start` 保留绝对工段地址和公开频道。续接页支持 1～9 道，整线最后一页加 `--terminal`。相邻缩短页按 `place_at` 摆放。混接 18 格节距的四角合板页时，平移后一页整件，使其 `input.island` 位于前页 `output.island` 正东三格，再按平移后的来去轨接站。

原生解码核对了九道续接页、地址 477～485 的成品末页、两种页互接和相邻站轨端。游戏内持续满带与换单清空由 #72 验收。
