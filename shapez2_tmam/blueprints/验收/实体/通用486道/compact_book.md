# 486 道通用工道册

整册采用 [12 格间距工道](compact_slot_pages.md)，包括 53 张续接页、1 张成品末页和 1 份共用控制。54 张页各有九道，覆盖绝对地址 0～485。每道配置基础料混编车站和结晶染料车站，支持任意合法的供料工序。共用控制接收 1～486 笔六字段配方。

| 项目 | 数量 |
|---|---:|
| 工道续接页 | 53 × 261 块大平台 |
| 成品末页 | 260 块大平台 |
| 共用控制 | 8 块大平台 |
| 整册 | 14,101 块大平台，12,632,496 个建筑 |

## 分批重导

在仓库根目录执行。`--pages` 使用从 0 开始的页码和左闭右开区间，可重复指定。省略该参数时生成全部 54 页。分批导出可共用目录，各批沿用相同的 `--origin-x`、`--belt-rate` 和 `--headway`。

```sh
python -m shapez2_tmam.circuits.factory_assembly.compact_book --output-dir compact-book-486 --pages 0 1 --pages 27 28 --pages 53 54
python -m shapez2_tmam.circuits.factory_assembly.compact_book --output-dir compact-book-486 --pages 1 27 --pages 28 53
```

[整册索引](compact_book_486/book.json) 列出每页的绝对地址、放置原点、文件名和配方接口。每页的同名 JSON 给出六槽带口、两类车站的来去轨和逐卸货口需求。单次导出只布置两个续接工段和一个末段模板。生成各道时平移原生岛块，按绝对地址写入 48 个整数常量，其中包括写入、确认和本道加工频道。

`--origin-x` 以岛格为单位移动整册。整套工道及共用控制按各自 `place_at` 放置。前页出板与后页入板相距三格，六个槽按原带行直连。末页将最后一道的六槽合成一条成品带，先按目标过滤，清料时走废料口。由接线表中的 `product_reader` 观察成品带。

换单前撤掉进料许可，检查六槽、A/B 两路、堆叠缓冲和回料合流是否排空，再按共用控制入口确认清空。写入层使用相位 3 连续复位 128 信号 tick。配方长度短于安装工段数时，多出的工段沿六条槽带通行。

## 混合车接轨和供货

下表坐标相对本道取料平台，外接轨点的岛层均为 0。按页接线表的绝对坐标和方向接轨。基础料混编车每三节为两节整片车和一节三原色车，四角重复四组。结晶车为一节三原色车。每车厢层按原约定装同一物料。

| 车站 | 车头 | 外接来轨 | 外接去轨 | 每站有效卸货口 |
|---|---|---|---|---|
| 基础料 | `(-6, -17)` | `(-7, -19)` 向南 | `(-6, -19)` 向北 | 16 条形状带，48 条原色管 |
| 结晶 | `(-6, 3)` | `(-6, 8)` 向北 | `(-7, 8)` 向南 | 12 条原色管 |

默认一满带按每秒 2 件计算，到站间隔按 60 秒计算。每条形状卸货带峰值为每秒 2 件，即一次有效到货至少 120 件。每条原色管按该口可服务的颜色分别核算。基础料纯色染色最高每秒 20 L，制针红最高 40 L。结晶纯色最高 40 L。混色行按该原色在成品色中的份额计算。`max_per_second` 是该卸货口的独立峰值，`min_per_visit_at_peak` 是按到站间隔换算的最低有效卸量。不同颜色用料口的峰值对应不同订单，调度时按该订单选用的口统计。
