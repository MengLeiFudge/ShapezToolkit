## 地址、接带与换单

- 普通页的末段输出六条槽带，下一页输入同走 `−12、−9、8、11、28、31` 行和建筑层 0。相邻两平台端口隔五格。末段 144 的成品过滤在 `(2598, 0, 0)`，走东侧第 31 行，外接一条成品带。出带和废料分流都经过终点过滤。
- 装方沿 `recipe` 的六字段、地址、标签和双回读接口。置 `RUN=1` 前发布目标、实际配方长度、回放结果和成功位。实体确认最后一笔并发布 `1640057=1` 后才放行供料。当前容量取 145，通用版可为短单发布更小长度。
- 换单先停料，维持旧配方排出在途品。逐处检查六槽带、六机两侧进料、加工位和合流回带，清掉卡在单侧的料。确认尾部和成品带也已清空后，按共用控制流程使写入相位 3 连续至少 128 信号 tick，再装新单。复位后的未写地址按六槽直通，直到容量末端的过滤器。
- `pages[].rails` 给出 49 个基础料站、6 个结晶站的外接岛格，已与四路基础料加一路结晶站表逐点核对。按 `supply.unload_rows` 检查 214 个用料卸货行。每车厢层同一货种，保留原 12 节基础料编组和单节结晶车。[混合车接轨与卸货记录](long_haul_routes.md)

## 重新生成与扩展

```bash
python -m shapez2_tmam.circuits.factory_assembly.full_line_pages --output-dir full-line-fixed
python -m shapez2_tmam.circuits.factory_assembly.full_line_pages --universal --output-dir full-line-universal
python -m shapez2_tmam.circuits.factory_assembly.full_line_pages --universal --stages 971 --window 962 971 --output-dir full-line-last-page
```

省略 `--window` 时生成全线。`--page-size` 默认每页九道，`--window START STOP` 可按全线地址补页，安装时只取一张同容量的控制页。固定版默认用悬空样件，也可用 `--recipe` 传入含 `target` 和 `instructions` 的六字段文件。通用版可按指定容量生成，并可额外读取一份配方以生成用量和放行参数。停靠路线还要按实机场地铺设外轨。

写入接口地址为 `0–970`。按新版制角排程与至多三层外层尾部计算，可把该发令程序的通用工道容量配置为 486 道。[工段数证明](../../../../docs/proofs/08-circuits.md#s08-40)

若主控允许操作 14 和 10 出现在任一地址，固定地点的一组双站只能服务接到该处的工段。通用布局给每个地址各一条基础料和结晶领料路，容量 971 时分别为 971 处停靠点。共用车队可以访问多个同型站，运量仍按各停靠点求和。要共用一处卸货站承担更多地址，需要另外铺设到这些地址的有址分发、缓冲和清空路径。当前已重导地址 969、970，核对最后两种站、六机、六槽页接点及槽 0 成品出口，972 道超出写入控制上限。

按 2 件/秒设计时，堆叠的 A/B 输入和合流回料各需 120 件/分钟。六台中的每台需持续达到 20 件/分钟。其他加工点也按有效流量实测，实物清尾、实机装方和持续满带沿用房间 #72 验收。
