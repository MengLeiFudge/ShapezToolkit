## 面积与无线预算

已验收的 `read-five`、`decoder-4q5l-wired` 和 `autonomous-scan` 实测为每岛格 27.43、8.10、9.38 个逻辑门。按最高与最低密度折算旧网表并对每部件向上取整，初估范围为 994～3,347 岛格。这个范围用于比较迁移工作量。整厂面积还取决于门是否能复用、闭环状态、板缝容量和顶层排板，走廊与网关按实际布线计量。

整厂在 `Z=0` 同层规划。对外收发由顶层工道与操作网关承担，按已有协议预留 25 个全局无线端点。若使用一块六频道共享时钟，另预留 6 收、6 发。合计 37 个，较旧版少 99.33%。同层状态板与计算板通过板缝接共用相位。时钟到各部件的端口和走廊用最终排板确认。

## 迁移顺序

1. 先定外部网关、配方工道协议和共享时钟。仅传入目标、启停与收货确认，传出配方及完工状态。
2. 迁 `direct-root` 与 `tail-node-inputs`。边界传目标、切向、四高度包、接受位和叶端参数。原色和逐格布尔在消费处生成。
3. 迁 `tail-search-workers` 和 Pin 路线。跨板传子目标、候选图形、候选四槽包、顶盖掩码和握手。将预取并回读行，将晶体接触与落点并入 Pin 图像判定，并共享支撑扫描。
4. 迁 `tail-search` 和父帧相关控制。边界传帧地址、图形对、深度与读写确认，父搜索游标随帧压缩保存。
5. 每迁完一个职责，从 `shared-space` 核销归属相同的门和频道，再复算剩余面积与跨板线束。

## 重导盘点

从仓库根目录运行。`--sample` 可重复传入已完成端口与回放核对的原生蓝图。输出 Markdown 包含端点数与迁移边界，JSON 保留逐部件、逐频道的证据。

```sh
python -m shapez2_tmam.circuits.factory_wired_budget \
  shapez2_tmam/blueprints/电路/四象限五层/factory-v1.spz2bp \
  --sample <read-five.spz2bp> \
  --sample <decoder-4q5l-wired.spz2bp> \
  --sample <autonomous-scan.spz2bp> \
  --output-dir .codex/tmp/deliverables/wired-factory
```
