# 十二节混合车换装

混合车从车头起按「图形、图形、流体」重复四组。每组三节依次装 C/R/S、W/空/空、红/绿/蓝。每节均按底、中、顶排列，同一层的四条带或管装同一种货。[混合车库](mixed-stage-depot.spz2bp)

在混合车的北向线路上依次接入七个换装站。每站东轨停十二节混合车，西轨接运送该种原料的通用单车厢列车。西轨沿行驶方向有四个停靠点，车头停在等待站时，第一节货车正对本站卸货口。单料从底层卸入，平台内的四条线把它送到东轨指定层位。原料车在矿点或染料源的装车站也使用底层。[通用车库和装货站](../../火车/README.md)

游戏的 `WaitStopDecider` 和 `QuickStopDecider` 都从第一节货车开始查找货运交换器。遇到普通直轨时，扫描会在该节结束。东轨十二个车位因此连续放置装车站或对应货类的直线占位站。西轨的每个等待站只需扫描其紧邻的一节货车。
