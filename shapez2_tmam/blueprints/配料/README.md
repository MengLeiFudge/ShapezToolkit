# 混合货运配料站

一组配料站有三个单料输入和一列三车厢混合车。图形、染料分别用自己的车站、车厢和运输平台。每条来线由单料列车卸货，每条来线的三个层位均可使用。

| 配料平台西侧入口 | 出站第 1 节 | 出站第 2 节 | 出站第 3 节 |
|---|---|---|---|
| 北口 A | A 来线底层 → 底层 | A 来线中层 → 底层 | A 来线上层 → 底层 |
| 中口 B | B 来线底层 → 中层 | B 来线中层 → 中层 | B 来线上层 → 中层 |
| 南口 C | C 来线底层 → 上层 | C 来线中层 → 上层 | C 来线上层 → 上层 |

原料名按配料平台的输入口固定。需要三种基础染料时，A、B、C 分别接红、绿、蓝。图形组可用同样的表接三种无色原料，额外货种用另一组。制作厂按同一张表收货。每条原始带保留自己的通道，一个车厢层位的四路货来自同一入口。每份装车蓝图内含换装平台、三个装车位和车头站。车头方向朝北。制作厂的三个卸货口朝东，放置接收平台时对齐西侧入口。固定接 RGB 的车可直接对接[厂内调色平台](../实体/基础单层/base-palette-4q5l.spz2bp)。

| 货物 | 配料站和装车位 | 混合车机库 | 制作厂收货位 |
|---|---|---|---|
| 图形 | [换装](图形/mixed-shapes-load.spz2bp) | [三节图形车](图形/mixed-shapes-depot.spz2bp) | [卸货](图形/mixed-shapes-unload.spz2bp) |
| 染料 | [换装](染料/mixed-fluids-load.spz2bp) | [三节流体车](染料/mixed-fluids-depot.spz2bp) | [卸货](染料/mixed-fluids-unload.spz2bp) |

换装平台内部先将同货不同层的四路分别移到独立行，然后升降到该货固定的输出层，最后按来料层号移到三个装车口。36 条带或管保持一一对应。供货率还取决于列车容量、实际往返周期与来料量。
