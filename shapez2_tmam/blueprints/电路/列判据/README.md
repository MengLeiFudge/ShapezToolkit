# 五层列判据

[自动列扫描](column-scan-4q5l.spz2bp)接收从地面到顶层的五个材料编号。空格为 0，普通形状为 1，针为 2，晶体为 3。保留原层号，矮列用空格补足。按照[接口表](column-scan-4q5l.json)同时提交五格材料，保持 `run=0` 至少 128 个信号 tick，然后保持 `run=1` 和同一列材料至少 160 个信号 tick，再读 `status`。整数 1 表示通过列判据，整数 2 表示违反。通过后还要检查半形支撑和完整图形的制造条件。

扫描器占上层岛，转移表占下层岛，俯视为一个 3×3 平台。扫描器调用转移表时发出状态和材料，转移表返回新状态。上述三个频道就是两块板之间的全部通信。蓝图内已包含[单步板](column-step-4q5l.spz2bp)，使用自动版时只放自动版。

## 转移表及读数依据

编译器把五层材料列在末端按 Python 列判据分成通过与违反。对每个较短前缀，依次接上空、普通、针、晶体，得到四个后继编号。如果两份前缀的四个后继相同，其余任意后缀都会得到相同结论，所以能共用一行。这一步从第五层向下重复，得到含两个吸收终态的 25 行表。表的四个后继以四种有色普通角编码在同一整片上。按本次材料旋转并裁出一角，即可读得后继，表数据里的普通格不会碎裂。

初态位于深度 0。每个非终态只属于一个深度，编译时核对这一点。上层据此选取对应的输入层。到达任一终态后，四种材料都返回同一终态。复位期间上层一直送出初态和底层材料，故下层返回第一步结果。启动后每经过一个往返，上层多消耗一层，至多再往返四次。

采样时间采用[原生信号传播证明](../../../docs/proofs/08-circuits.md#s08-05)的批量放置、固定接线及常速推进条件。每块板内部都是无环的本地计算。在一个游戏信号 tick 内先算提供者后算消费者，每次跨方法频道读取 12 tick 前的信号。复位稳定后，启动输入、上层调用、下层返回和状态输出沿此路径传播。一次往返为 24 tick，启动到外部读到第五码的等待上界为 `12 + 4×24 + 12 = 120` tick。接口给出的 160 tick 包含余量。
