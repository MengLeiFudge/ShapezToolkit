# 四象限五层电路首版

导入 `factory-v1.spz2bp`。这一份含目标读取、直接闭包、顶针逆推、成功路径回放和六字段装单。蓝图尺寸、频道及各部件数量见 `factory-v1.json`。同一组频道只放一份主控。

本册蓝图占 2,253 个 1×1 岛格，共 313 块平台、567,060 个建筑，外框为 38×35，使用三个岛层。

## 放置

解锁三个岛层和三个建筑层，在最低岛层的空地放置。游戏把蓝图里的岛层偏移加到鼠标所在岛层，整厂以最低岛层为 `Z=0`。放置前还需解锁基础、长形、方块、3×3 和不规则平台，以及线路基础、逻辑门、全局线路传输和模拟设备。

L 形平台属于「不规则平台」研究。预览中只有 L 形板标红时先检查这项研究。整层平台标红时检查当前岛层和放置范围，平台要落在已解锁岛层内。

## 开单与读数

1. 接上[六槽工道和共用控制](../../验收/实体/通用486道/compact_book.md)。电路把第一遍配方送入虚拟六槽，成品完全等于目标后才进入第二遍装单。实体的地址、请求、复位、确认、入库和清空信号按工道控制接口回传。
2. 保持 `1704673=0` 至少 456 信号 tick，清空工道并接入目标。目标在求解、装单和生产期间保持稳定。置 `1704673=1` 开单。
3. 在 `1705399` 读结果。进入状态 `1` 后，`1640043` 给工序数，`1640044` 给已核对的成品。按工道协议确认来料后置 `1702851=1`，实体从 `1640059` 接收供料许可。

| 方向 | 频道 | 用途 |
| --- | --- | --- |
| 输入 | `1600000` | 目标图形 |
| 输入 | `1704673` | 整数 `0` 复位，`1` 开单 |
| 输入 | `1702851` | 整数 `1` 请求供料 |
| 工道回传 | `1640000`、`1640011`、`1640012`、`1640013`、`1640057`、`1640060` | 地址、请求、复位、确认、入库完成、清空确认 |
| 输出 | `1705399` | 订单状态 |
| 输出 | `1640002`–`1640007`、`1640046` | 六字段和地址标签 |
| 输出 | `1640030`、`1640043`–`1640045`、`1640059` | 工道运行、配方长度、回放成品、通过位、供料许可 |

| 状态 | 含义 |
| --- | --- |
| `0` | 求解或写入中 |
| `1` | 配方已写入工道 |
| `2` | 搜索穷尽，不可制作 |
| `3` | 含未着色晶体，供料规则未定 |
| `4` | 目标为空 |
| `5` | 计算或写入核对失败 |

将接口表 `unused_inputs` 列出的频道留空。完整的复位和装单时序见[两遍配方接口](../../验收/电路/配方回放/two-pass-recipe.md)。

## 重导

在仓库根目录执行。

```bash
python -m shapez2_tmam.circuits.compile_factory_v1 --output factory-v1.spz2bp
```

生成器从项目分册合装，并从 `direct-root-stacked.spz2bp` 载入三个岛层的叶端锁存。它缩短能安全合并的直线，优先在同一部件内合板，再让不依赖飞线位置的稀疏平台共用空间。接口表把共用平台列为 `shared-space`。有飞线的组可以整体转向，缩板时保留端口的相对坐标。导出使用第 5 版蓝图封装，核对建筑占地、飞线配对及收发频道。

同名 JSON 的 `island_cells` 是实际岛格总数，3×3 计 9 格，各岛层分别累计。`platforms` 是平台件数。`occupancy` 给出占格和无线数据，`sparsest_platforms` 和 `radio_over_limit` 用于定位还值得缩板的位置。坐标相对蓝图原点。计算口径见[电路走线与压缩](../../电路走线与压缩.md)。

已有整厂蓝图和同名接口表时，可以分批缩板，每批的输出可继续作为下一批的输入。默认重布无飞线的单板，`--pairs` 重布同层横向相邻且独立成组的双板，`--merge` 将同一部件内无飞线的独立板合到一个平台。程序逐端口核对驱动来源和频道，保留每对原有飞线的方向和跨板信号级数。只采用实际岛格减少的替换件。

合板优先试排预计能放得下、又能共用输入频道的组合。预估把每个全局收发器按 27 格算。逻辑门只有在类型、配置和每个输入的驱动来源都一致，且各自独立驱动输出线时才合并。新板优先使用原位置，也可利用原外框内的空位。

```bash
python -m shapez2_tmam.circuits.compile_factory_dense factory-v1.spz2bp \
  --pairs --count 2 --workers 2 --output factory-compact.spz2bp
python -m shapez2_tmam.circuits.compile_factory_dense factory-compact.spz2bp \
  --merge --count 6 --workers 6 --output factory-merged.spz2bp
```

每轮只重布选中的小部分板，其余板直接保留。用 `--rounds` 在内存中连续尝试多轮，最后统一核对整图并生成一份蓝图和接口表。接口表的 `dense_layout` 记录已经尝试的位置。候选排布失败时原板继续使用。`--merge-shared` 可尝试合并不同部件中读取相同频道且没有飞线的板，合成板计入 `shared-space`。

部件接口一致时可先只重导该部件，再替换现有整厂中的旧版。准备完整蓝图及新、旧两份部件蓝图，分别附同名 JSON。替换器按频道从共用板去掉旧部件，核对其他建筑的输入驱动和短距端口，只重布受影响平台。它按实际岛格和建筑数选优。

```bash
python -m shapez2_tmam.circuits.replace_factory_part factory-v1.spz2bp \
  old/pin-landings.spz2bp new/pin-landings.spz2bp \
  --part pin-landings --output factory-updated.spz2bp
```

单独修改叶端锁存后，从仓库根目录重导合装所用的直接路线。

```bash
parts=shapez2_tmam/blueprints/验收/电路
python -m shapez2_tmam.circuits.compile_root_search \
  --reader "$parts/原层读取/read-five-rows.spz2bp" \
  --closure "$parts/顶针逆推/dual-source-closure.spz2bp" \
  --path "$parts/配方回放/success-path.spz2bp" --stacked-leaf \
  --output "$parts/顶针逆推/direct-root-stacked.spz2bp"
```

这版用原生解码核对了建筑占格、飞线配对及静态接线。游戏内放置及整单生产仍待验收。

另可导出闭包复用验收版。闭包保持本单已选的原色行、材料和前缀高度，供两遍配方回放读取。这一版需要单独验收连续订单和尾针路径。

```bash
python -m shapez2_tmam.circuits.compile_factory_v1 --retain-leaf --output factory-retain-leaf.spz2bp
```
