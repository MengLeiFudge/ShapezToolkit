# 单车厢货运

本册负责从各地搬运单一货物至配料站，同一列车的所有车厢装同一种货。配料站到制作厂的混合列车及对应层位见[配料册](../配料/README.md)。两类通用站例均采用红色车头和一节货车。图形和流体可走各自的专线。沿默认朝向，车头向北运行。机库的车厢在车头南侧，出库端在北侧。站场的等待站在北，装卸器在南，停靠时正对货车。

| 货物 | 发车 | 加载 | 接收 |
|---|---|---|---|
| 基础图形或成品 | [图形车库](图形货运/shape-depot.spz2bp) | [图形装货站](图形货运/shape-loading.spz2bp) | [图形卸货站](图形货运/shape-unloading.spz2bp) |
| 染料 | [流体车库](染料货运/fluid-depot.spz2bp) | [流体装货站](染料货运/fluid-loading.spz2bp) | [流体卸货站](染料货运/fluid-unloading.spz2bp) |

各站采用游戏原生车站平台。按矿点、染料源与配料站位置铺设单向线路，客制线路长度不影响装卸器与货车的对位。装货侧接太空带或太空管，卸货侧接对应的缓冲供料线。每种染料使用独立卸货口和管路。需要循环运输时将卸货后的线路接回装货站。在游戏中核对站牌方向、停站条件及启动中的第一列车。

本册包含机库和直线站段。矿点、取液点、站间回路及厂内槽位调度需要随整厂配置一起布置。
