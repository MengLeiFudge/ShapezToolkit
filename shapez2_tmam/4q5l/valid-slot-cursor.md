# 单列合法槽直接后继

四列来源游标原来按固定桶长前进，桶内仍包含不满足目标晶体、保序和列A的模式。Python已先筛选每列再组合；电路也可以先计算每个槽的单列合法性，再选择下一个合法槽。公开槽号和SOURCE_PATTERNS的顺序保持不变，没有编译目标目录。

## 固定模式的合法性

固定一个桶及其四格控制字。K是保留NPC位置，C是全部来源晶体位置；二者不交。g决定来源地面是否占用，t决定K的格数。目标保留序列不包含新地面针，各项只有N或P。以下条件恰好等价于原pattern_column的单列接受条件：

1. 目标五格材料均属于0～3，地面不是C；选中桶满足g和t。
2. 目标第r+1层的C记作F_r，必须位于C中。相邻两个来源C的F标志必须相同，排除强制C和辅助C混合的竖边。
3. K中的第j个来源位r对应目标保留序列第j项；该目标项高度至多r+1。对F_r还要求目标第r+1层以前的保留数等于K在r以前的数量，防止穿越保留晶体。两者分别是原位置条件和晶体屏障等式。
4. 固定四格来源再加空顶格满足列A。

计数、g、F包含关系给出无冲突材料路由；其余控制位本来都是布尔值。故原有效性中的数量相等、地面一致和掩码合法条件均已由桶及固定控制字保证。标签不参与这些结构判断。无表项、无合法材料或地面C不能得到合法槽。

## 将列A化简成控制字条件

固定布局的占用与晶体均为常量，只有各保留NPC是否为P由目标序号提供。它们可按目标一热前缀计数共用解码。

- 某NPC正下方为空时，它不能是P。
- 某NPC上方还有C时，若该NPC为P，则它之前所有格必须为P。此前有E或C时直接要求该NPC不是P；否则检查此前NPC全为P。
- 某非地面C正下方为空时，最近的更低占用必须存在且为N。最近占用是C或不存在时直接拒绝，否则要求对应NPC不是P。
- 四格来源中的两颗C最多相距三层。其间若有空格，五层列A中“两N加空格”的例外无法出现，直接拒绝；无空格则通过这项。

保序与晶体屏障只依赖K，强制C包含及竖边状态只依赖C，分别按固定掩码共用。屏障蕴含式可以对四个r都生成：F_r不在C时，包含条件已使该模式失败；F_r为假时，蕴含式自动成立。静态布局已不可能满足列A时直接生成假常量，不再展开其余门。

这逐项展开column_admissible对四格加空顶格的原式。没有检查完整顶盖，也没有用结构合法性代替Pin像或可制作性。

## 后继与进位

对当前目标列，令V_i表示原槽i合法。计算所有大于当前地址的合法槽，取其中最小者；不存在时回到全列最小合法槽，并令last为真。has等于任意V_i为真。

选中事件分别为“合法且此前无合法项”与“比当前大、合法且此前无更大合法项”，两组由回绕条件互斥。前缀OR从中间分段，左段结果保留、右段每项与左段总和求OR，按长度归纳得到全部正确前缀；共用子段避免逐前缀重新展开。

这只是从原槽序列删除全部单列非法元素。任一可制作逆像的四列均合法，因此保留的四列笛卡尔积完整。跨列晶体冲突、顶盖、物理判据及制造递归仍使用原规则。

初始、换S前缀及坏高位跳转时可以继续把槽清为0。如果0合法，它就是最小合法槽；如果0非法，它不可能被接受，下一次该列推进会直接跳到最小合法槽。若全列没有合法槽，has使整个S前缀直接跳过。普通进位回到最小合法槽；坏高位清除较快列后重复以上初始化论证。最高坏槽推进及其溢出仍只跳过已知不可能成立的较快组合。

has与后继只依赖当前目标列，不依赖其他列、顶盖或制造状态；父帧挂起期间目标及S前缀保持。换前缀后的状态传播仍受慢更新冻结协议保护。生产编译重新计算完整DAG时序，不能因减少访问槽而擅自缩短时钟。

## 证据边界

该变化减少单列无效地址进入控制循环的次数，可能增加组合电路体积。最坏的合法来源组合、顶盖和递归数量仍需继续压缩。验证限于数学等价证明、源码静读、LSP及生产蓝图编译；没有运行目标、枚举目标、求解器、测试或模拟。
