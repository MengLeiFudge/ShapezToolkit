# 面向电路的堆叠压缩与尾部标准化

本文限定四象限五层，给出保持覆盖的局部简化，以及对应的 [Python 堆叠规划模块](../stacking.py)。目标是减少制造步骤、搜索分支和电路状态；三项成本分别计算。完整可制作性的依据仍是[统一合成定理](synthesis.md)，本文没有把它的巨大半形闭包变成实用的全图求解器。

基础输入沿用任意无晶体单层 N/P 及合法标签。层号从 1 开始；K、S(D,T) 和落点公式沿用[堆叠约化](stacking-proof.md)。代码使用从 0 开始的层号。

## 1. 一段连续堆叠只需至多五份上料

**定理。** 对非空 D∈K，只要 S(D,T) 成立，就能从 D 出发，至多五次堆叠无晶体单层原料得到 T。

令 Δ 为 T 相比 D 新增的格位。对每个目标层 z，把 Δ 在该层的全部普通块及针放在一份单层上料 B_z 中；按 z 递增堆叠，跳过空 B_z。

证明如下：

1. B_z 的水平普通连通块恰好是 Δ 在该层的普通连通块；针仍独立成组。不能把 D 同层的旧格加入 B_z，它们可能把本应独立下落的新增块连接起来。
2. 由 S 的前缀条件，每个新增格所在列的旧格均低于 z。已追加的更低目标层也低于 z。
3. 每个新增块接地，或在 T 的 z−1 层有支撑；支撑属于 D 或已经完成的更低层。因此每块的落点恰为 z。
4. 同一份 B_z 中各块占据互不相交的列，不能相互阻挡。它们可以在一次堆叠中独立落到 z。既有 D 不动，新增接触在本次下落中不重新合组；写回后的输出仍属于 K。

逐层归纳得到 T。最多五个目标层，故最多五次堆叠。这个构造取代的是逐个水平块或针追加的二十次宽松上界。

**无晶体推论。** 任意非空、可制作的无晶体目标可用至多五份基础单层制造：第一份直接取为基础物品，其余至多四次堆叠。稳定的无晶体目标不能有空底层或整层空隙，否则最低的悬空水平块没有下方支撑。

这里计数的是已有单层供料之后的堆叠次数；各份原料的种类、配色、供料线路不折算成免费实体工厂。

## 2. 固定追加段的最少上料可用十五种选择求出

五份上料的构造没有保证最少。例如，不同目标高度的两个新增块若不粘连，可以放在同一份上料中，各自落到不同高度。

### 2.1 四个前缀计数足以描述中间状态

固定 D、T，每列列出 T 的所有非空格，保留其真实层号及标签。记列 j 的总格数为 n_j，D 占有该列前 d_j 格。候选中间状态只需四个计数：

```text
p = (p0,p1,p2,p3)，d_j ≤ p_j ≤ n_j
```

状态包含每列目标列表的前 p_j 格。空底层、内部空格仍由列表中的层号表示，不能压缩成连续填充。

为什么不需要一般四列图形？因为纯追加不会移动或删除旧格，任何新增格必须高于该列已有最高格。成功历史若先放入较高目标格，就再也放不进同列更低的缺失目标格；因此每列只能依次追加下一个目标格。

D 不是 T 的逐列带坐标、带标签前缀，或剩余目标格含 C 时，直接判定不存在该追加段。

### 2.2 一步只有十五种候选

一份单层原料每列最多一格。选择非空列掩码 m∈{1,…,15}，每个选中列放入该列下一个目标格，未选列为空。

在这份上料中划分水平普通连通块及独立针。设当前列顶为 h_j，空列为 0。对每个块 J 检查：

```text
J 中所有格的目标层号 = 1 + max(h_j : j∈J)
```

全部通过就有一条合法边 p→p′，其中选中列的计数加一。每条边严格增加格数，图无环。

这里的普通块分组包括 q3 与 q0 的环邻接。不同块可以有不同落点，但同一个水平普通块的全部格必须落在同一层。

### 2.3 最优性与规模证明

任意成功的单层 N/P 堆叠步骤都能化为以上一种选择：保留进结果的格只能是各列下一个目标格。若某个水平块超高删除，整块同层且一起删除；它和其他上料块占据不同列，没有阻挡关系，可以省去。空效果步骤也可以省去。删除这些材料不会改变其他保留块的落点。

因此，所有有效单层追加方案都对应此图的一条路径；反过来，每条路径由落点公式保证合法。对单位边权作广度优先搜索，首次到达目标即得到最少上料份数。

```text
状态数 ≤ ∏(n_j−d_j+1) ≤ 6^4 = 1296
每状态选择数 ≤ 15
边检查数 ≤ 19440
最短成功路径长度 ≤ 5
```

19440 是单段的候选边检查上界，不是游戏 tick 数；也不包含完整合成中的半形搜索。最短性只针对固定 D、T、纯单层 N/P 上料，不包括允许复杂多层上料、切割或顶针后的全局最短制造树。

当 D 为空时，第一条边表示直接取基础原料。所有路径都少计算一次实体堆叠，所以最少上料份数也给出这一模型内的最少堆叠次数。

### 2.4 逐层方案与最短方案的手推差异

取下料和目标：

```text
D = Cu------:Cu------
T = CuP-----:Cu------:Ru------
```

目标新增 q1 的地面针和 q0 的第三层普通块。逐层方案先加 `--P-----`，再加 `Ru------`，需要两次堆叠。

最短方案使用一份 `RuP-----`：针独立落到 q1 地面，普通块落到 q0 第三层，恰好得到 T。目标与下料不同，至少需要一次堆叠，故一次是最少。这是落点公式的手工推导，未运行实例。

不能总把所有下一格合在一份上料中：若改成相邻普通块，而两格要求的落点不同，它们在上料中已经粘连，整块只有一个落点。十五种掩码的检查保留了这一差别。

## 3. Python 的职责与调用

[stacking.py](../stacking.py)复用现有 `Shape` 编码，独立提供两个入口：

| 入口 | 输出与计算方式 |
|---|---|
| `plan_layer_stacks(lower, target)` | 按目标层扫描，至多五份上料；不保存候选状态表 |
| `plan_stacks(lower, target)` | 对前缀状态作广度优先搜索，输出最少上料份数 |

两个入口都先检查非空下料属于 K：建立粘连组及直接支撑边，计算可达关系，检查每组是否到达地面或包含针的非空支撑环。针不与普通块、晶体粘连；不能用任意稳定性代替 K。每条追加边再用落点公式计算，不调用物理模拟器。

返回值约定：

- `tuple[Shape, ...]`：顺序上料；每个条目都是可取用的 N/P 单层，保留目标种类和颜色。
- 空元组：输入已经等于目标，无需堆叠。
- `None`：此固定追加段无解；含晶体目标可能仍可通过其他操作制造。
- 非空下料不属于 K：抛 `ValueError`，拒绝超出该局部算法前提的调用。

`lower=None` 表示尚未取料，返回序列第一份直接作为基础物品，其余依次堆叠。它不表示机器能接受空物品。以 `lower=None` 调用时，对于无晶体目标，这两个入口都是完整的目标到基础制造流程；对于含晶体目标，它们只负责已有下料之后的追加段，需要传入相应非空下料。

调用形式：

```python
from shapez2_tmam.mari.shapes import Shape
from shapez2_tmam.stacking import plan_layer_stacks, plan_stacks

lower = Shape.from_key("Cu------:Cu------")
target = Shape.from_key("CuP-----:Cu------:Ru------")
layer_plan = plan_layer_stacks(lower, target)
short_plan = plan_stacks(lower, target)
```

这段代码说明接口，没有作为验证执行。模块没有接入 Mari 的六候选命令，也没有将其 `None` 结果包装成通用不可制作结论。

## 4. 尾部的旋转可以全部吸收到起点及供料

记 R 为任意合法旋转。列重编号保留环邻接、同列上下关系、地面层号和顶破层号，因此晶体融合、静止组及落点关系均在旋转下保持。由[精确顶针关系](pin-inverse.md)得到：

```text
R(Π(D)) = Π(R(D))
S(D,T) ⇔ S(R(D),R(T))
```

第二式的制造对应为：把下料及每份基础上料都旋转同样角度。它允许保持工序次序，把尾部中的一个旋转向前移过 Π 或 S，并相应旋转更早的供料。反复移动，所有尾部旋转合为起点的一次净旋转。

[半形文法](half-closure.md)的起点集合 A(X) 已包含各合法朝向：基础层、紧图形、单半形及两个互补半形的拼接都在旋转下封闭。因此对整个起点集合，可以把尾部搜索标准化为：

```text
A → S → (Π → S)^k
```

无需在每个 S 后再选择四种朝向。四次顶针时，原来五个段末旋转有最多 4^5 个语法组合；标准化后只在起点的朝向中处理净效果。此处消除的是冗余语法变量，未测量实际运行加速比。

制造半形时，末次半切也可以固定保留标准 q0、q1：原先在方向 d 切割再标准化的输出，等于先把完整输入旋转到标准方向再作固定半切。该旋转可继续向前吸收到起点及供料。两列内部顺序保持，不能引入镜像去重。

这个证明没有交换 S 与 Π 的次序。[堆叠与顶针不能直接交换的例子](coverage-research.md#53-顶针与堆叠不能直接交换顺序)仍成立。

## 5. 目标约束进一步缩短尾部与前态选择

### 最低晶体决定顶针深度

由[保留晶体高度不变量](coverage-research.md#4-最终保留晶体的高度不变量)，设所需末端最低晶体层号为 m，则标准尾部只需考虑：

```text
0 ≤ k ≤ m−1
堆叠次数 ≤ 5(k+1) ≤ 5m
顶针次数 ≤ m−1
```

末端有地面晶体时，尾部没有顶针，只剩一段 S。半形规则末尾的切割不会让保留晶体下降，所以也能用所需半形的最低晶体限制它前面的尾部。

最宽松的尾部界由一百次有效基础块堆叠降为二十五次单层堆叠，另有至多四次顶针。起点制造、半形递归、朝向调整和末切不计入这个局部界；不能把它说成整套 TMAM 只有二十九步。

### 只保留不同的列前缀

反推固定目标 T 的 S 前态时，每列不必遍历六个高度后再对重复图形去重。按非空格计数即可：令 n_j 是该列非空格数，r_j 是从底到最高 C 为止的非空格数；无 C 时 r_j=0。所有 C 必须保留，所以该列保留格数仅需取 r_j,…,n_j。

```text
不同前态候选数 ≤ ∏(n_j−r_j+1)
```

这是目标结构给出的精确候选生成范围，随后仍需检查 K 和 S 的支撑条件。它和第 2 节从固定 D 正向追加的前缀状态用途不同，不能混作整个求解器的状态数。

## 6. 电路实现的取舍与未闭合部分

逐层方案的控制流程可固定为“读取当前目标层 → 提取相对下料的新增格 → 检查支撑 → 发出一份上料 → 转下一层”。层计数器只需经过五个位置；不需要为五层各复制一套完整判定器。已经由合法配方保证的 K 中间物品，可以依据不变量保持 K，而不必在每次追加后重复求全支撑图。

最短方案额外需要候选遍历、队列、去重及父记录。对游戏电路，可以先采用至多五份的逐层方案；只有实体工序或吞吐成本值得额外搜索硬件时，再考虑实现最短方案。Python 同时保留两者，便于明确区分控制体积与上料次数。本文没有给出门数、tick 数或时序存储器蓝图。

这轮简化已经覆盖所有合法 S 段，并给出无晶体 4q5l 的完整 Python 合成流程。含晶体的全覆盖机器仍有两个主要缺口：

1. 顶破逆像还要恢复可能消失的辅助晶体和第五层，不能仅保留无顶破的唯一逆像。
2. 半形部分已由[逐列角构造](corner-synthesis.md)替换为局部充要判据及至多285节点制造；完整全图的顶针与堆叠尾部仍需继续压缩。

完整求解电路必须区分处理中、有解、有证明的不可解；局部段无解或搜索预算耗尽不能输出全局不可解。六象限已存在可制作但非 K 的图形，因此本页的堆叠实现与证明不能直接用于所有 6q5l 下料。一般范围只研究偶数象限。

证据为落点公式、前缀路径对应、旋转等变性的人工证明，以及直接代码静态核对；未运行测试、目标枚举、物理模拟或游戏验证。
