# 列A网格的十次行闭包

[格位可达判据](support-reachability.md)对任意四象限五层网格可用十九轮传播。完整求解器另行保证列A，可改用本页的十次行闭包，保持K/G可达集合完全相同。实现为[`_admissible_reach`](../support_circuit.py)；默认通用入口仍使用十九轮传播。

## 1. 传播方向与行闭包

行号为0～4。反向传播“能走到支撑种子”的标记：已标记下格可标记同列占用上格；水平两个非针相互传播；向下传播仅限相邻两个C。K的种子为地面占用格与所有P，G只有地面占用格。

`row_reach`取一行的非针占用与种子，精确闭合水平路径。P可保留自身种子，但不能沿水平边传播。四格圆环的非针分量只有三种情形：零个、一个、两个；两个时必为相对的单格。

记U_z(B)为从下行B向第z行传播、加入本行P种子后做行闭包；记D_z(R,T)为保留本行R、从上行T沿CC向下传播后做行闭包。两者只增加沿真实图边可达的标记。

## 2. 两行闭包

固定下部外来支撑B，考虑两行L、T，允许两行各自有P种子。计算：

```
L0 = U_L(B)
T0 = U_T(L0)
L1 = D_L(L0, T0)
T1 = U_T(L1)
```

这就是两行的最小闭包。P在L中的可达性只依赖种子和B，向下CC及水平传播均不能新增P。于是只需考虑L的非针分量：

- 零个时没有可新增格。
- 一个时，L1若比L0增大就已包含整个非针分量；T1不能再向L增加任何非针格。若没有增大，T1=T0。
- 两个时，各分量只有一格。L1新增加的格必为C，且它正上方的C已经属于T0。这一格向上传回的种子已经在T0中，因此T1=T0，不会产生下一轮新格。

所得集合对所有传播边闭合，且每一步都有真实路径证据，所以等于最小可达集合。调用方只需要L1时可以省去T1的实体门；需要上行结果时再计算U_T(L1)。

## 3. 三行闭包

固定下部支撑B，考虑行M以及上部两行。以Pair(M)表示上节两行精确闭包的下行结果：

```
M0 = U_M(B)
L0 = Pair(M0)
M1 = D_M(M0, L0)
L1 = Pair(M1)
T1 = U_T(L1)
```

M只有一个非针分量时，新增即覆盖该分量；M有两个分量时，新增加的单格只能沿CC从L0得到标记。该单格新增的上行种子已经在原上部闭包中，因此Pair(M1)=Pair(M0)。M中的P可达性仍固定。与两行证明相同，最终对所有边闭合，且只使用真实路径，因此精确。

## 4. 列A固定底部边界

列A的晶体间隙条件要求：某C正下为空时，最近的更低占用格必须是N。第1行C若第0行为空，就不存在这样的更低N，因而违反列A。所以列A网格的第1行C必有占用正下格，全部从地面得到标记。

第0行已全部标记。第1行用一次U_1求出精确结果：上方只能沿CC新增标记，但第1行的所有C已经标记；N/P不能接收来自上方的传播。第2～4行于是可直接套用三行闭包。

总计十次行闭包：第1行一次，第2行向上和向下各一次，两次Pair各三次，最后第4行一次。每次都是固定四格布尔式，没有迭代寄存器。对K仍将所有P作为种子；不能把K改为仅接地的G。P正下占用仍由末端单独合取。

## 5. 调用前提与可选顶格

完整求解器的ENTRY独立合取列A；非法目标即使短扫描给出任意结果也不能进入搜索。Pin来源下降前已验证完整列A。可选族模板只把自由最高NPC改为N，不改变低层或C，保持列A。S前缀只删除本列最高C之上的NPC尾部，同样保持列A。故所有会影响成功或失败分支的支撑查询均满足本页前提。

`admissible=True`是编译期专用选项，不替代列A检查。默认值为False，任意网格接口保持原十九轮传播。Python通用支持判据仍使用原图洪泛。

[来源族G筛选](family-grounding.md)仍对整个含可选N的模板求可达集合，最后才豁免未达的可选顶N；短扫描不改变该顺序，也不改变实际前缀的要求。
