# Mari 六候选的整层空隙反例

在 [Mari 调查记录](mari-tmam.md)指定的原包、本机游戏规则和默认关闭的 `Pin For Gap Replacement` 下，六个固定候选不覆盖全部可制作的四象限五层图形。下面给出一个可制作目标，并按最终是否顶针分成两类，排除全部六个候选。论证不依赖候选编号、支撑阈值或最后交换方向的具体取值。

这是源码、接线和操作规则上的人工证明，没有运行目标求解、门电路仿真或游戏。结论针对原包的稳定组合逻辑；实体产线和自动切换时序的其他行为没有据此获得正确性证明。

## 1. 目标与支撑关系

目标 T 的短代码是：

```text
CuCu----:--------:crCu----:crP-----:crCu----
```

象限按短代码顺序记 q0、q1、q2、q3，层号自底向上。N 是普通块，C 是红晶体，P 是顶针，`.` 是空格。

| 层 | q0 | q1 | q2 | q3 |
|---|---|---|---|---|
| 5 | C | N | . | . |
| 4 | C | P | . | . |
| 3 | C | N | . | . |
| 2 | . | . | . | . |
| 1 | N | N | . | . |

第二层整层为空。上方三颗晶体纵向相连，并分别与第三层、第五层的普通块粘连，形成组 G。第四层的针不与邻格粘连，单独形成组 P。

- G 的第五层普通块被 P 挡住。
- P 被 G 的第三层普通块挡住。
- 因而 G 与 P 形成支撑环，均不能下落。

这说明它稳定，但稳定性本身不够证明可制作。下一节给出制造路径。

## 2. 从基础输入制造 T

这里只使用任意无晶体单层、堆叠、结晶、旋转、切割和半形交换。保留 q3/q0 或 q1/q2 的切割、交换，可由旋转加常规半切/交换实现。所有中间图形均不超过五层。

### 2.1 制造带牺牲晶体的源形 S

先制造以下三个独立紧列，再拼合：

- q0：`C N C C C`。
- q1：地面一颗 C。
- q3：`N P N N N`。

q2 为空。q0 的紧列可显式这样制造：其他三列每层都用普通块作辅助；q0 从下到上放 `P N P P P`，在加入第一、第三、第四、第五层后分别红色结晶。每次结晶时当前各层四格均占满，只有指定顶针被替换；旧晶体不改色。最后切掉普通辅助列即可。其余两个紧列分别通过单层结晶后切割、普通块与顶针逐格堆叠制造。

先拼 q0/q1，再把它们作为一个完整半形与 q3 所在半形拼合，避免提前切断底层两颗晶体的融合关系。得到：

```text
S = crcr--Cu:Cu----P-:cr----Cu:cr----Cu:cr----Cu
```

### 2.2 切出 A

切 S，保留 q3/q0，删除 q1/q2。

删除的 q1 地面晶体与 q0 地面晶体融合，因此 q0 地面晶体也碎裂。q0 第二层的普通块旁边是针，不能与它粘连，于是普通块下落到地面。

q0 第三至第五层的晶体与 q3 对应的普通块粘连，由 q3 第二层顶针支撑，不下落。结果为：

```text
A = Cu----Cu:------P-:cr----Cu:cr----Cu:cr----Cu
```

### 2.3 制造辅助半形 B

在 q1/q2 上依次堆叠以下五个无晶体单层：

```text
--CuCu--
----Cu--
--CuCu--
--P-----
--CuCu--
```

第三次堆叠的两个普通块相连，由 q2 第二层支撑，停在第三层；最后一层的两个普通块由 q1 第四层顶针支撑，停在第五层。因此：

```text
B = --CuCu--:----Cu--:--CuCu--:--P-----:--CuCu--
```

### 2.4 拼合后去掉辅助列

按 q3/q0 与 q1/q2 两个半形拼合 A、B。两半各自稳定，交换的前置切割不会改变它们：

```text
U = CuCuCuCu:----CuP-:crCuCuCu:crP---Cu:crCuCuCu
```

再切 U，保留 q0/q1。被删的 q2/q3 没有晶体，不会碎掉保留的晶体链。保留部分恰好形成第 1 节的支撑环，底层普通块也保持在地面，因此输出正是 T。

这条制造树证明 T 属于可制作集合 R。它没有把信号拆层器、任意多层常量或沙盒种子当作实体原料。

## 3. 输入拆层丢失了第二层的位置

游戏 `ShapeOperationUnstack.ExecuteInternal` 按当前最高层拆分，下半部分调用 `ShapeLogic.FoldAndConvert`。`Fold` 只构造到最高剩余部件所在层，因此会删除新暴露的空顶层；它不会保留一个全空顶层占位。

对 T 连续取下半部分，层高依次为：

```text
5 → 4 → 3 → 1 → 空
```

第三次移走原第三层后，原第二层成为空顶层并被删掉。

Brain P58 的第一串拆层器为 `(5,11,0)`、`(5,9,0)`、`(5,10,1)`、`(5,11,2)`。XOR 只比较各段的信号真值，用最后一次非空到空的转换选择从哪一级注入原目标。它据此把 T 当作四个非空层处理。

第二串拆层器对各层编号的实际分配如下。端口 0 为下半，1 为上半。

| 主控层号 | P58 来源 | T 对应的实际层 | 分析层信号 |
|---|---|---|---|
| 1 | `(1,11,0):0`，合并 `(2,12,0):0` | 1 | `CuCu----` |
| 2 | `(1,11,0):1` | 3 | `crCu----` |
| 3 | `(1,10,1):1` | 4 | `crP-----` |
| 4 | `(1,11,2):1` | 5 | `crCu----` |
| 5 | `(2,9,2):1` | 无 | Null |

这五路与紧凑目标 T′ 的分层完全一样：

```text
T′ = CuCu----:crCu----:crP-----:crCu----
```

但最终成功比较器 P79 `(8,2,0)` 仍比较完整 T。因此，即使成功重建 T′，也不会被算成 T 的成功。

仅有 T/T′ 混淆还不足以否定六候选：原则上，不同候选可能碰巧恢复不同间隙。下面进一步排除恢复 T 的两类最终路径。

## 4. 不顶针的候选没有第五层晶体

### 4.1 送入角构造的列只能是紧列前缀

P82 按 P70 给出的同一列阈值 h 选择层：第二、第三、第四、第五层分别受 `h >= 2/3/4/5` 控制；地面受 `h != 0` 控制。它对 P58 的各层逐象限取块、恢复颜色并拼成单层，没有把第五层以外的数据改接到第五层。

所以不论 h 来自哪一个候选，T 送入此处后，各列只可能是以下串的前缀，或空列：

```text
q0: N C C C
q1: N N P N
q2: 空
q3: 空
```

即使 h 大于实际高度，第五层数据仍是 Null。空信号阈值等无法通过数值比较的情况，也只会去掉上层，不会在保留的下层中插入间隙。

P82 的第五层四路输入门是 `(13,19,1)`、`(19,19,1)`、`(25,19,1)`、`(31,19,1)`，数据端均来自 P58 `(2,9,2):1`。其输出经分象限与交换重建到 P82 `(17/19/21,27,2)`，再经 P44/P31/P19/P4 分配。第五层始终为空。

最终顶针标志记为 p。在 p 为假时，P16 `(13,-35,0)` 使五路直接数据通过 `(8,-33,0)`、`(9,-34,0)`、`(10,-35,0)`、`(11,-36,0/1)`；有顶针时才启用 P63 的另一组处理层。P24 只根据交换方向旋转层信号，其他三个角的接口同理。因此本节的紧列前缀确实是最终四角构造的输入，不是只供早期预测器使用的数据。

### 4.2 紧列前缀走普通角构造，不会升高晶体

以下坐标用第一个角 P17/P18 表示。其余三套为 P34/P35、P48/P49、P67/P68。将外部五路输入统一命名为 L1…L5 后，四套各 1544 个节点的操作、配置、内部连线和输入层号逐项相同；只需证明一套。

对上述四类列前缀，有这些直接条件：

1. 没有位于晶体下方的针。P17 `(18,-14/-10/-6/-2,0)` 的四个“当前为针且上方有晶体”条件全为假。对应归一化顶针选择 `(23,-4,0)`、`(24,-6,0)`、`(25,-10,0)`、`(26,-14,0)` 均不启用；`P-N-C` 间隙特例也不启用。
2. 没有内部空格。紧列描述不会命中归一化中的悬空模板，也不会命中 P18 的 41 个悬空列键。后者每个键都有晶体下方的间隙。故 P18 的三组查表输出全为 Null，`(-6,8,0)`、`(-13,-8,0)` 为真，进入普通构造。
3. 地面是 N 或为空，没有地面针前缀。P17 `(-20,16,1)`、`(-23,15,1)`、`(-25,13,1)`、`(-27,11,1)` 及 `(-12,2,0/1/2)`、`(-12,10,0)` 的移位命令均不启用。连续列也不满足 `(-19,2,2)` 的间隙/颜色边界特例；P18 `(-35,6,2)`、`(-36,6,2)` 的最终补针命令为空。

普通构造的五个单层载体位于 P17 `(-15/-20/-25/-30/-35,4,0)`。它们只依赖对应输入层及单层辅助常量，经切割、旋转、交换生成；没有升层操作。目标晶体位先用针占位，辅助格使用普通块。

P18 依次堆叠这些载体，并在对应目标层需要晶体时结晶。五个结晶阶段是 `(-30,-7,0)`、`(-33,-3,0)`、`(-31,-3,1)`、`(-32,12,0)`、`(-32,12,1)`；查表输出为空时，控制它们的交换标记也为空，按第一至第五层的自然顺序加工。

第五层颜色选择源 P18 `(-13,-16,2)` 分析的是空的 L5，所以最后的结晶分支不启用。前四次结晶时载体总高度至多四层；最后只追加不含晶体的第五层辅助载体。无补针、无查表特殊支路，之后只有切割和旋转。因此，四个完成角中都不存在第五层晶体。

P80 的三次交换和旋转不能提高晶体。接下来的堆叠也不能把上料晶体放到第五层：非空下料时，上料从提高六层的位置下落，晶体会碎；累计结果为空时，XOR 旁路至多直接采用一个单层 Hybrid 载荷。故不顶针的候选最终仍没有第五层晶体，与 T 不同。

这里无需假定整个 CMAM 对任意列都正确。只使用这组紧列前缀所到达的普通支路，以及第五层晶体的高度上界。

## 5. 顶针的候选无法保留 q0 的底层普通块

现在允许顶针前的 claw 是任意五层图形，不再限制它来自哪一候选或哪种角构造。顶针之后只有五次 Hybrid 堆叠。

若最终要得到 T，q0 第三、第四、第五层的三颗晶体必须来自顶针输出。Hybrid 均为单层；空结果旁路不能引入这些高层晶体，非空下料上的堆叠也不能增加它们。

保留的晶体不会下落。顶针把它们恰好提高一层，所以顶针输入 q0 的第二、第三、第四层必须分别是这三颗晶体。原第五层会在顶针开始时被删除。

考察目标要求的 q0 地面普通块，只剩两种可能：

- 顶针输入 q0 第一层非空：操作必在 q0 地面生成一颗新针。它不会被顶破，也不会消失；后续只有堆叠，无法把这颗针改成普通块。
- 顶针输入 q0 第一层为空：输入 q0 第二至第四层已被必需晶体占用，第五层又会删除，没有普通块能够落到 q0 地面。后续堆叠的 q0 普通块从上方进入，被已存在的第五层晶体挡住，只能停在第六层或更高并被截掉，不能穿过晶体落到地面。

两种情况都与 T 的 q0 第一层为 N 矛盾。故“最后顶针，再连续堆叠”这一整类表达式都不能生成 T。

## 6. 六候选统一排除与适用边界

原机 P80 的最终结构是：四角交换组成 claw，可选一次顶针，然后五次 Hybrid 堆叠。

- p 为假：第 4 节证明没有第五层晶体。
- p 为真：第 5 节证明不能满足 q0 的 `N . C C C`。

两类穷尽所有六个固定候选。结合第 2 节的合法制造树，得到：

```text
T ∈ R，且对所有 i ∈ {1,…,6}，Fᵢ(T) ≠ T。
```

因此，原包默认目标直通配置下的六候选算法不是全覆盖 TMAM。遗漏发生在角模板查表之前：输入拆层将整层空隙压缩，后续直接分支按压缩后的紧列加工；最后顶针分支又受不可逆的地面针约束。

开启 `Pin For Gap Replacement` 会启用另一段反馈预处理，不属于本文已分析配置；把空隙改成针也不能算作原目标 T 的精确重建。本证明没有声称游戏时序或实体运输的其他缺陷，也没有修改原蓝图或 Python 中的原机候选规则。
