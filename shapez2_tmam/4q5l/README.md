# 4 象限 5 层

本部分限定四象限、最多五层。一次半切留下相邻两列。加工采用已核对的游戏局部规则，基础输入为任意无晶体单层；详细前提和程序集来源见[覆盖性研究](coverage-research.md)。

## 接手目标与阅读顺序

本范围已有[统一合成算法与整体覆盖证明](synthesis.md)：给定非空目标，有限生成并展开合法制造树；完整搜索未命中则证明不可制作。算法采用半形目录及有界尾部，尚未取得实用复杂度保证。[电路化简化与 Python 堆叠规划](compact-synthesis.md)进一步给出逐层供料、局部最短追加及旋转标准化。[逆像压缩](compact-inverse.md)合并物理候选；[逐列角构造](corner-synthesis.md)给出半形的局部充要条件和无需目录搜索的制造方法。Mari 主控另有 [Python 模型](../mari/README.md)及[整层空隙漏解证明](mari-empty-layer.md)，通用理论不代表原机已实现该方法。

1. 先读[统一合成算法](synthesis.md)，掌握输入、配方输出、终止及整体覆盖定理；再读[覆盖性研究](coverage-research.md)，核对基础输入、实体操作与标签规则。
2. 读[堆叠约化](stacking-proof.md)，掌握支撑类 K、分组时机和连续堆叠判据；再读[支撑闭包](support-closure.md)，核查四象限五层为何满足其前提。
3. 读[通用列内不变量](../general/column-invariants.md)，再读[独立单列与顶针逆向](column-theory.md)。单列可以独立制造与它能出现在半形中是不同问题。
4. 读[完整顶针逆像](pin-inverse.md)，先掌握静止组和水平落点公式；再读[完整半形有限文法](half-closure.md)，核查闭包、终止、制造证书及全图 Reach 判据。
5. 面向实现时读[堆叠压缩与尾部标准化](compact-synthesis.md)，区分五层扫描与最短上料搜索，并核对 Python 的局部失败语义。
6. 需要原机资料时，再读[Mari 调查记录](mari-tmam.md)、[整层空隙反例证明](mari-empty-layer.md)及[41 项角模板分析](mari-corners.md)。

## 游戏内实现资料

用户确认 Mari 的 TMAM 已在游戏内复刻。下载的 `Mari的TMAM.zip` 经静态解码，包含实体工厂、列车供料、制层器和主控电路共五份蓝图；其中图形配置均为四象限，并包含五层图形，与本部分归属相符。文件清单、沙盒供料情况和证据范围见[Mari 蓝图记录](mari-tmam.md)。

主控组合方程、51 路频道对应和角模板分类已完成静态核对。整层空隙反例进一步否定了默认配置的算法全覆盖；实体运输、动态时序及用户复刻存档的具体连接仍未完整核查。

## 优先推进的问题

完整理论覆盖之外，还需把搜索、存储和制造步骤压缩到适合游戏电路的规模。[堆叠简化](compact-synthesis.md)、[逆像及半形构造](compact-inverse.md)已有证明及 Python 实现；[原生电路部件](../blueprints/README.md)提供无晶体完整子类判定和加工核心。[逐列角构造](corner-synthesis.md)已去掉半形递归；[完整 Python 尾部逆推](tail-solver.md)已实现，游戏完整电路仍需压缩搜索并实现控制和配方输出。未执行目标求解或全量目录计算，也未取得实际半形数量。

- **判据压缩**：用已有半形局部判据替换 H 目录，继续压缩全图顶针及堆叠尾部。K、Q、J 仍不能单独作为全图通过即成功的判定。
- **工程实现**：把制造证书及逆向规则写成高效求解器，保持底部空层、循环支撑、融合删除和下落后不合组等边界。
- **机器适配**：若研究某台 TMAM，另证其实际工序可实现完整文法；原机漏解结论不因通用理论闭合而改变。

这里的 R 是从基础输入经合法操作可达的集合；K 是每个粘连组都能沿支撑边到达地面或含顶针支撑环的结构类。现有 R ⊆ K 是文档中的人工证明，K、Q、J 均不能直接当作完整可制作性判定。1296 是单段固定朝向堆叠的候选数，264 是独立单列结构数，两者都不是全图状态总数。
