# 4 象限 5 层

本部分限定四象限、最多五层。一次半切留下相邻两列。加工采用已核对的游戏局部规则，基础输入为任意无晶体单层；详细前提和程序集来源见[覆盖性研究](coverage-research.md)。

## 理论文档

| 文档 | 内容 |
|---|---|
| [覆盖性研究](coverage-research.md) | 颜色与普通形状标签消除、无晶体判定、保留晶体的顶针次数界，以及相对完整半形集合的有限阶段形式 |
| [支撑闭包](support-closure.md) | 本范围的 R ⊆ K 人工证明；切割使用两列半形，顶针使用四列三层几何引理 |
| [堆叠约化](stacking-proof.md) | K 下料的复杂堆叠约化、连续基础堆叠充要判据、单段固定朝向至多 1296 个前态候选 |
| [独立单列与顶针逆向](column-theory.md) | 五层以内 264 种独立单列结构（含空列），以及依赖稳定输入的逆向特例 |

通用针前缀 Q、晶体下方间隙 J 和顶针位置约束统一引用[一般范围的证明](../general/column-invariants.md)。K 不是可制作性的充分条件；完整可制作半形集合和有顶破时的完整逆向仍是本部分的理论缺口。

## 游戏内实现资料

用户确认 Mari 的 TMAM 已在游戏内复刻。下载的 `Mari的TMAM.zip` 经静态解码，包含实体工厂、列车供料、制层器和主控电路共五份蓝图；其中图形配置均为四象限，并包含五层图形，与本部分归属相符。文件清单、沙盒供料情况和证据范围见[Mari 蓝图记录](mari-tmam.md)。

游戏内实现、某些图形运行成功、全体可制作图形的覆盖性证明是不同层次的证据。这里确认资料与范围，不将压缩包存在直接视为全量覆盖验证。
