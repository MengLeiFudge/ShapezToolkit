# 4 象限 5 层

本部分限定四象限、最多五层。一次半切留下相邻两列。加工采用已核对的游戏局部规则，基础输入为任意无晶体单层；详细前提和程序集来源见[覆盖性研究](coverage-research.md)。

## 接手目标与阅读顺序

本页是四象限五层线程的交接入口。目标是证明候选分类或拆解方案覆盖全部可制作图形，并检查 Mari 原机的接线和六候选规则。主控已写成 [Python 模型](../mari/README.md)，全机覆盖性尚未证明。完整证明保存在下列文档中，接手时按顺序阅读，不能仅凭摘要继续推导。

1. 读[覆盖性研究](coverage-research.md)，明确基础输入、合法实体操作、制造树归纳和各结论的证明强度。
2. 读[堆叠约化](stacking-proof.md)，掌握支撑类 K、分组时机和连续堆叠判据；再读[支撑闭包](support-closure.md)，核查四象限五层为何满足其前提。
3. 读[通用列内不变量](../general/column-invariants.md)，再读[独立单列与顶针逆向](column-theory.md)。单列可以独立制造与它能出现在半形中是不同问题。
4. 读[Mari 调查记录](mari-tmam.md)及[41 项角模板分析](mari-corners.md)，了解接线、实现和局部证明边界。

## 游戏内实现资料

用户确认 Mari 的 TMAM 已在游戏内复刻。下载的 `Mari的TMAM.zip` 经静态解码，包含实体工厂、列车供料、制层器和主控电路共五份蓝图；其中图形配置均为四象限，并包含五层图形，与本部分归属相符。文件清单、沙盒供料情况和证据范围见[Mari 蓝图记录](mari-tmam.md)。

游戏内实现、某些图形运行成功、全体可制作图形的覆盖性证明是不同层次的证据。当前已完成主控组合方程、51 路频道对应和角模板分类；这些局部结论不能直接作为全覆盖证明。

## 优先推进的问题

Mari 方向继续证明六候选支持选择、hybrid/deny/claw 拆解与实体制造的一致性。通用理论仍需完整可制作的两列半形集合及有顶破时的顶针逆向。具体缺口和原始编码规模见[覆盖性研究第 7 节](coverage-research.md#7-还缺哪些证明)。

- **半形方向**：从两列支撑关系出发，检查 K、Q、J 之外是否仍有制造历史限制。候选条件需要同时给出必要性与从基础输入出发的构造；发现反例时写出逐步制造路径，或给出排除全部路径的理由。
- **逆向方向**：保留晶体的位置约束已知，重点是恢复被顶破的顶层、融合删除的晶体，以及下落前的位置。不能把无顶破的唯一前态规则直接用于这些情况。
- **覆盖性收口**：用完整半形集合接上现有有限阶段形式，再证明拆解规则的完备性和终止性。制造树归纳的双输入操作必须同时覆盖两个输入，不能只尝试固定辅助料。

这里的 R 是从基础输入经合法操作可达的集合；K 是每个粘连组都能沿支撑边到达地面或含顶针支撑环的结构类。现有 R ⊆ K 是文档中的人工证明，K、Q、J 均不能直接当作完整可制作性判定。1296 是单段固定朝向堆叠的候选数，264 是独立单列结构数，两者都不是全图状态总数。
