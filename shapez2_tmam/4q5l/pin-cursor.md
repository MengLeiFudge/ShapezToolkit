# 顶针游标的整段跳过

[`full_solver_circuit`](../full_solver_circuit.py)在不删除潜在成功来源的前提下，按局部列约束和共享Pin结果跳过整段地址。本文证明控制顺序；没有运行目标、遍历或模拟。

## 顶盖按晶体掩码分族

参与来源搜索的帧保存四个顶层C排除位，以及四个整数NPC成员。实际C位为“允许该列补C且排除位为0”；实际C为1时顶格固定辅助红C，NPC成员固定0，否则依次取0空、1Cu，以及正下方非空时的2P。排除位初始0，从[最大允许顶盖](maximal-cap.md)开始。

同一C掩码内，四个成员为最快位，C列的成员基数为1，其他列在来源第3层非空时为3，否则为2。成员全耗尽后，排除掩码在允许位置上二进制进位，实际C掩码按补集顺序遍历。目标最高层C所在列的来源顶C被[融合规则](pin-source-conflicts.md)禁止；将该列前四格补为C后违反列A的位置也禁止。禁用列的实际C和排除位始终0，计数时直接传递进位；其余m位恰遍历2^m个掩码。全部位置均允许时有`(3+1)^4=256`个顶盖，这是宽松上界；禁止C的位置仍保留全部符合列A的空、Cu、P选择。

顶盖全部耗尽后，四个来源槽按当前目标列的单列合法槽顺序进位，q0为最快列。原槽号仍来自[固定来源表](pin-patterns.md)，范围0～19；桶尾及桶内单列非法槽均不作为后续候选逐项访问。

## 合法槽与空域

`PatternColumn`返回单列候选、has_slots、last_slot及next_slot。has_slots表示至少有一个单列合法槽；next_slot是大于当前地址的最小合法槽，没有时回到全列最小合法槽；last_slot表示不存在更大合法槽。判据共用目标类型和前缀计数，将固定控制字中的列A、晶体位置、保序及屏障条件提前计算，证明见[单列合法槽后继](valid-slot-cursor.md)。横边、顶盖、完整物理及制造检查仍保持。

四列has_slots任一为假，当前S前态没有任何来源组合，PREFIX直接进入PREFIX_NEXT；都有合法槽时才允许start_source。两个分支互为补集，并保留原S支撑及Pin允许条件。

初始化和坏高位跳过仍将相关槽清0。0合法时就是最小合法槽；否则它只能失败，推进一次就进入最小合法槽。普通末项进位直接回到最小合法槽。父帧挂起期间前缀及槽保持，换S前缀前槽归零；全部传播继续受慢更新冻结保护。Python的pin_families原本就先筛单列再组合，接受集合相同。独立来源蓝图同时公布has_slots、next_slots及last_slots频道，供外部游标使用。

## 整数寄存器与后继选择

来源槽用四个0～19整数寄存器，NPC顶盖用四个0～2整数寄存器。来源模式和合法槽后继共用二十个地址比较。advance为假时保持；为真时来源槽直接写next_slot，并按last_slot传递进位。NPC域仍用模3后继，在不允许顶P的列从1直接归零；C列固定0。

来源后继的一热选择先取更大合法槽的最小项，没有时取全列最小项。不同事件互斥；合法域非空时恰有一个输出，无合法域时输出0并由has_slots阻止进入搜索。前缀OR分半共用，归纳得到每项恰为此前事件的并，不经过二十级串联。组合过渡由慢更新冻结覆盖，不将瞬时地址当作搜索步骤。

每帧因此只需四个整数来源槽及四个整数NPC顶盖，合计8个寄存器，替代原28个布尔寄存器；四帧共减少80个状态寄存器。最高层C掩码、S前缀和全部可制作性判断保持。

## 并行计算进位

来源选择逻辑仍使用当前旧地址判断末项，所有新值在同一状态步提交。令NPC初始推进事件为M，第q列末项为L_q，C位为C_q。原递推的下一进位是 `carry ∧ (C_q ∨ L_q)`：C列旁路，非C列只在末项传递。因此第q列推进可直接写成 `M ∧ ∧_{i<q}(C_i ∨ L_i)`，最终族进位取四列的乘积。各前缀以平衡与门并行求值，不经过前一列的后继数据选择器。

来源槽还允许从坏列直接开始推进。令B为顶盖耗尽进位，J_i为选中的坏列跳过事件，L_i为来源槽末项。第q列的推进恰为：

`A_q = (B ∧ ∧_{j<q}L_j) ∨ ⋁_{i≤q}(J_i ∧ ∧_{i≤j<q}L_j)`。

空乘积为真。对原递推 `carry_{q+1}=(carry_q∨J_q)∧L_q` 逐项展开即得该式；它也适用于基数1及任何末项标志。q=4时仅有i=0..3的跳过事件，此式就是全部来源耗尽。当前实现并行生成五个A_q，前四个驱动原整数后继选择，最后一个报告耗尽。更快列清零、顶盖清零及跳族优先级保持原样。这里仅重排布尔式，不改变候选顺序、跳过集合或终止条件。

## 顶针成员域

最高层P的正下方必须非空，这是列A的直接必要条件。最高层没有更高晶体，因此将前四层已满足A的列补为顶P时，唯一新增的针约束就是第3层非空；顶空和顶N不会引入针或晶体约束。故下方空的非C列恰可删去成员2，下方非空的列保留0、1、2。完整列A检查仍保留。

`PinSource.top_pin_allowed`读取原来源第3层occupied，不读取融合后的活格，也不读取依赖当前顶盖valid的发布材料。这样允许域只依赖S前缀及来源槽，不会因正在判断的顶盖改变。原来源第3层C即使稍后被融合删除，仍能在来源图形中支撑最高P，不能误删。

NPC计数器从0开始，末成员为允许P时的2，否则为1；末成员归零并进位。改变C掩码或来源槽前，NPC位全部归零；更换S前缀由start_source归零；父帧恢复不改变原槽及前缀。因此较短域不会继承旧的成员2，C列仍固定0并旁路进位。可选顶N族检查和完整Pin物理关系不变；仅跳过已被列A否定的成员。

## 顶晶体域与来源合法性共用

来源前四格的完整列A已由column.valid检查，image.passed又包含全部column.valid。在这个前提下，补顶空或顶N不增加针和晶体约束；补顶P只增加第3层非空这一条件；补顶C的合法性恰是 `column_admissible(lower + C)`。所以来源整体合法性可分成原lower检查、顶格编码检查，以及选P/选C时对应的允许标志。原完整五格列A没有被弱化。

`top_crystal_allowed`只读取原来源四格flags；它不读取当前顶盖、发布材料或valid。因此将其否定并入C位禁用条件不会形成组合环，也不会让当前C位影响自己的计数域。Python的pin_families已按同一条件过滤capped列，现在电路的游标也直接跳过这些掩码。

排除位初始化为0；来源槽不变时允许域固定。换S前缀、来源槽正常推进、坏列跳过或最大顶盖整组否定时，排除位全部归零。实际C随新来源重新取全部允许位置，所以不会把旧来源的C位带入新来源。父帧恢复时来源槽与排除位一起保持。所有允许子集仍被覆盖；禁止位置没有实际C，每个被排除的非法掩码均违反列A或删除强制C。

### 补顶C的短判据

令O_z、P_z、C_z、N_z为前四格的占用、针、晶体和普通材料标志。已有lower列A时，补第4层C恰需以下条件：

- 对z=1..3，P_z蕴含所有更低格都是P。
- `O_3 或 N_0 或 N_1 或 N_2`。
- C_0蕴含 `O_1 且 (O_2 或 O_3)`；C_1蕴含 `O_2 且 O_3`；C_2蕴含O_3。

第一项就是新增最高C的针前缀条件Q。按lower中最高C分类，最高C为3时没有新间隙；为2时必须有O_3；为1时中间两格必须全占；为0时中间三格可全占，或恰有两N与一个空格且第1格非空。最后一种由Q排除了C上方的P，且没有更高C，所以恰化为 `O_1 且 (O_2 或 O_3)`。其他较低C的蕴含式由已有lower列A及最高C对应条件保证，未增加额外限制。

若O_3为真，晶体下方间隙条件J直接满足。否则上述晶体间隙条件已排除C_1/C_2/C_3；若有C_0，则O_1/O_2都是N，最近下格必为N；若没有C，Q保证P仅在地面前缀，最近非空格为N恰等价于前三格至少有一个N。因此第二项与J等价。原lower的针直接支撑等条件仍由column.valid检查，不重复串入这条短通路。

## 坏列跳过全部更快地址

`PinSource.column_valid[q]`只依赖目标第q列及该列来源槽；不依赖其他列或顶盖。它包含二十槽选址、强制C、保序、屏障、地面、前四层列A及竖直C保留状态冲突。

若第q列无效，改变全部顶盖或更快的q0～q(q−1)列都无法修复它。因此可将这些更快位全部归零，直接把第q列推进到下一合法槽，再向更慢列正常进位。若同时有多列无效，选择最高列号，跳过的段最大且仍全部无效。

这不是将某个不完整必要条件当作可制作性判据。局部约束的否定已经排除该列的全部组合；跳过只省去重复检查。有效列仍需取得真实制造证明。

[两列晶体冲突](pin-source-conflicts.md)也可跳过全部顶盖：相邻C一保留、一消失时不可能是合法逆像。两列冲突应推进较快列，保留较慢列的后续组合；slot_conflicts按这个推进位置归并，再与坏列一起选择最高安全推进位。q3–q0边只能推进q0，不能跨过q0的后续有效来源。

## 必要筛选失败可跳过整族

`PinSource.image.passed`读取前四层来源、目标及顶层C掩码。第五层NPC在Pin抬升截高时删除，既不参与C融合，也不参与后续下落。因此同一前四层和C掩码的全部NPC顶盖成员共享这项筛选。

筛选失败时，成员全部归零，直接推进C掩码。筛选通过后，每族先共用可选闭包寻找A→S证书；失败的非地面C族再逐成员搜索Pin尾部，不能从局部物理匹配推断成员可制作。

## 精确物理失配跳过整族

[地面可达F检查](pin-grounded.md)作为组合通路，在制造前确认完整Pin关系。若失配，SOURCE_NEXT直接推进到下一C掩码。它不保存缓存；回到父帧后由原参数重新计算。即使当前NPC顶盖违反列A，只要同族存在满足列A的成员，本定理就适用于共同活图；若没有，整个族已不可制作。因此这一跳过不依赖当前NPC顶盖恰好有效。

理由更强于必要筛选：Pin物理结果完全不依赖被删除的顶层NPC。其余成员即使可制作，也不能产生指定P。其他族的单个成员制造失败仍按正常成员进位；含地面C族采用下面的整体判定。

## 地面C族失败可跳过整族

[可选顶格定理](optional-top.md)证明含地面C的前态只能由A→S取得；两次闭包覆盖该族所有NPC顶盖。因此游标初次进入该族时，以空NPC顶盖检查固定结构及Pin关系，子帧用自由顶N模板求解。成功时子帧提交精确成员；失败时直接推进C掩码。无需另外尝试顶P或其他N组合。

地面C取来源融合删除C与抬升后保留C的并集，不能漏掉已删除辅助C。若空NPC顶盖使完整列A失败，改变其他自由顶格也不能修复固定C或更低部分的违例，整族仍可跳过。坏列跳过优先于此分支。

所有族都先共用A→S闭包。非地面C族检查失败后，还做[全族G可行性筛选](family-grounding.md)；有G成员才回父SOURCE，family_checked=1且NPC地址保持，先搜索首个空顶盖成员的Pin尾部。无G成员或地面C族整体失败时回FAMILY_NEXT，强制跳过整族；随后精确成员失败仍按SOURCE_NEXT正常推进。改变C掩码、来源槽或S前缀时清family_checked；同族成员推进保持该位。

## 状态不变量

所有非C成员始终在当前允许的0～1或0～2；C成员始终0；最高C禁位始终0。推进C掩码之前，各成员因正常溢出或整族跳过而全部归零。坏列跳过还清空C排除掩码和更快列；没有用新C掩码解释旧成员。

每次SOURCE_NEXT或精确Pin关系失配，游标都严格进入按上述顺序的后继地址或一段后继地址。跳过段全部已获否定依据，故不会漏解；最后来源列进位时才宣告当前S前缀的来源耗尽。
