# 顶针来源族共用可选顶格闭包

固定一个Pin逆像族：前四层L及第五层晶体掩码不变，其他第五层格可为空、N或P。两个切向的强制闭包即可判定该族是否存在A→S成员，不再为至多81个NPC顶盖重复这项检查。失败后，含地面C的族整体不可制作；其他族仍须逐成员搜索Pin尾部。结论限定四象限五层及既定供料模型，没有把所有可制作前态都当作A→S，也没有把顶盖统一改成全N。

## 1. A→S成员的顶层可以规范化

由[标准尾部定理](tail-solver.md)，含C目标的制造历史可取A→S→(Pin→S)^k。先在整个族内寻找k=0的证书。以下顶格删除仅使用A→S形式，不要求L含地面C。

固定一个这样的证书D→S→T，D是两个稳定半形的拼接，取其对应切向。可以进行两项删除：

- 删除D第五层的全部P。P不与邻格粘连，第五层之上没有格，所以这些P不支撑其他组。剩余两半形仍稳定，列A仍成立，故可由半形构造重新制造。
- 不追加S中的第五层NPC。按层追加时它们最后才加入，且其上没有其他目标格。其余追加步骤与原证书相同，不依赖这些顶格。

删除不改变前四层和顶层C。得到同族另一个可制作成员T′，其顶层非C格全部是D中原有的N。不能据此删除D中的顶层N：它可能粘到C，给整个半形提供外部支撑。

因此，判断族内是否存在A→S成员，只需寻找一个A前态D：它保留本族全部C、每列保留所选成员的非空前缀；前四层剩余NPC能经S追加；第五层可自由选择N，但选择的N必须已经属于D。这项存在性判断不需要顶层P。

每次Pin使保留C上升一层，S不生成、不移动C。若L含地面C，k只能为0，此时上述判断已经覆盖整个族的可制作性。若L不含地面C，A→S失败后仍可能有k>0的成员，必须继续恢复各成员的完整Pin尾部。

## 2. 将可选N接入强制闭包

建立模板U：前四层取L，顶层固定C不变，其他顶格全部暂写Cu。这些Cu只是可用位置，尚未承诺制造。固定集合F包括L的全部非空格和顶层C；可选集合O为其余四个以内的顶层N。

对每个切向，从包含全部C的最小逐列前缀P开始，运行[原强制闭包](prefix-closure.md)，只修改新增块检查：

1. 两半形的不稳定区间仍可从整个U中选择最低N支撑见证，包含O。选择顶N也会强制保留它下方全部固定目标格。
2. 新增块取Δ=F\P，不将尚未选择的O放进Δ。无目标下方支撑的Δ块仍强制移入P。
3. 没有强制补格时，返回P，以及精确成员T′=F∪(P∩O)。只把F\P逐层追加到P。

支撑见证计算读取格的正下方。O只位于最高层，所以不会给任何其他格凭空提供下方阻挡。原两列论证继续适用：全部C固定；新增N不能合并两个旧C组；不稳定组的最低合格见证属于每个可行前缀。Δ坏块的强制性也不变，因为以后Δ只会删格、分裂，不能获得新支撑。

对任意A→S成员的规范化A前态D，P⊆D是循环不变量。初值包含于D；两类强制补格均包含于D；缺失见证就不存在这样的D。停机时P的两个半形稳定且Δ满足S判据，故P及T′有合法配方。第1节保证若原族有A→S成员，就有这种规范化D，因而两个切向都失败等价于整个族没有A→S成员。

每次增长至少加入一个U格，仍至多20次增长及一次终检。覆盖族内全部顶盖不依赖枚举其成员。

## 3. Python及电路对应

`Solver4._family_recipe`对每个来源族建立模板，调用两次`minimal_start(..., optional_top=True)`。成功时先取得真实角制造证书，再向精确成员追加固定Δ。上层继续执行Pin并与指定输出逐格比较。失败后，含地面C族返回失败；其他族先通过[全族G可行性筛选](family-grounding.md)，再恢复空/N/P成员并调用`_tail(..., skip_start=True)`，搜索各自Pin尾部，不重复已整体否定的A→S。

完整电路复用四帧、前缀闭包和制造ROM。每帧增加一位`family_checked`，全局`leaf_mode`保存三种模式：0为普通根目标，1为可选顶格族检查，2为已否定A→S的精确成员。

- 每族第一次以空NPC顶盖检查列A及Pin像。空NPC顶盖若违反列A，其他NPC选择不能修复；融合、静止与落点不受NPC顶盖影响。
- `family_checked=0`时下降，把子目标自由顶格填为标签1（Cu），置全局模式1，并把父帧`family_checked`置1。模板ENTRY仅检查列A，暂不以整体K失败否定该族；模式1只允许A→S及整族G筛选，禁止模板本身继续下降。
- `PrefixSearch.delta`保留全部未选格，供支撑闭包选入可选N；`required_delta`排除未选可选顶N，仅用于S追加及坏块检查。当前P仍须通过半形及K检查才能接受。
- 成功时，把未选顶N写为空，保留已选顶N及固定C，清模式并进入RETURN。此次目标修改属于慢事件，冻结一业务周期。制造与逐帧比较读取已经确定的精确目标。
- 可选A→S失败后，地面C族整体否定；其他族先以同一洪泛检查模板全部固定格能否通地面。无G成员时也整体否定，经FAMILY_NEXT跳族；有G成员时回父SOURCE，保持原NPC地址，先递归首个空顶盖成员，不能提前推进而漏掉它。失败回父时清全局模式，跳族请求由Phase携带。
- 父帧`family_checked=1`时，下降写精确候选及模式2。ENTRY检查K和Pin允许条件，通过后初始化Pin轮并进入PIN_PREFLIGHT检查G，直接跳过A→S阶段。精确成员失败才按正常NPC游标推进。
- 改变C掩码、来源槽或S前缀时清`family_checked`；同族NPC加一保持该位。新子帧也清自己的族检查位。

全局模式1不能继续下降。模式2在ENTRY后不再影响该帧的Pin搜索，父帧挂起后可被新子模式覆盖；失败返回清零，成功叶端提交时也清零。因此无需在父帧保存leaf_mode。根初值0，根目标从不启用可选模式。父帧挂起只保存族检查位及精确游标。

可选检查成功时，父帧保存的空NPC顶盖只是族地址；回放从已确定的子目标制造并Pin，该族的全部NPC顶盖拥有相同Pin输出，所以不需要回写父帧顶盖地址。

含地面C可由来源地面“融合删除C”或“抬升后保留C”求并，不能只检查Pin后存活晶体，否则会漏掉地面辅助C。坏列跳转仍优先于整族跳转。

## 4. 边界

每族至多81次A→S检查合并为一次两切向闭包。含地面C族不再逐成员递归；其他族仍保留每个成员的Pin搜索。四列来源槽、顶层C掩码及更高最低C族的递归数量仍可能很大，这个局部上界不代表完整求解器已具备实用等待时间。

本页依据数学推导和源代码静读；没有执行目标、目标枚举、求解、测试、反馈模拟或游戏。
