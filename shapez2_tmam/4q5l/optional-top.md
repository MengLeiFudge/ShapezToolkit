# 地面晶体来源族的可选顶格闭包

固定一个Pin逆像族：前四层L及第五层晶体掩码不变，其他第五层格可为空、N或P。若L的地面含C，这个族是否存在可制作成员，只需两个切向的强制闭包，不再分别检查至多81个NPC顶盖。结论限定四象限五层及既定供料模型；没有把任意族的顶盖统一改成全N。

## 1. 地面C把制造问题限制到A→S

由[标准尾部定理](tail-solver.md)，含C目标的制造历史可取A→S→(Pin→S)^k。每次Pin使所有保留C上升一层，S不生成、不移动C。因此含地面C的目标只能取k=0；本族的全部可制作成员都必须有A→S证书。

固定一个这样的证书D→S→T，D是两个稳定半形的拼接，取其对应切向。可以进行两项删除：

- 删除D第五层的全部P。P不与邻格粘连，第五层之上没有格，所以这些P不支撑其他组。剩余两半形仍稳定，列A仍成立，故可由半形构造重新制造。
- 不追加S中的第五层NPC。按层追加时它们最后才加入，且其上没有其他目标格。其余追加步骤与原证书相同，不依赖这些顶格。

删除不改变前四层和顶层C。得到同族另一个可制作成员T′，其顶层非C格全部是D中原有的N。不能据此删除D中的顶层N：它可能粘到C，给整个半形提供外部支撑。

因此，只需寻找一个A前态D：它保留本族全部C、每列保留所选成员的非空前缀；前四层剩余NPC能经S追加；第五层可自由选择N，但选择的N必须已经属于D。顶层P完全不需要。

## 2. 将可选N接入强制闭包

建立模板U：前四层取L，顶层固定C不变，其他顶格全部暂写Cu。这些Cu只是可用位置，尚未承诺制造。固定集合F包括L的全部非空格和顶层C；可选集合O为其余四个以内的顶层N。

对每个切向，从包含全部C的最小逐列前缀P开始，运行[原强制闭包](prefix-closure.md)，只修改新增块检查：

1. 两半形的不稳定区间仍可从整个U中选择最低N支撑见证，包含O。选择顶N也会强制保留它下方全部固定目标格。
2. 新增块取Δ=F\P，不将尚未选择的O放进Δ。无目标下方支撑的Δ块仍强制移入P。
3. 没有强制补格时，返回P，以及精确成员T′=F∪(P∩O)。只把F\P逐层追加到P。

支撑见证计算读取格的正下方。O只位于最高层，所以不会给任何其他格凭空提供下方阻挡。原两列论证继续适用：全部C固定；新增N不能合并两个旧C组；不稳定组的最低合格见证属于每个可行前缀。Δ坏块的强制性也不变，因为以后Δ只会删格、分裂，不能获得新支撑。

对任意可行成员的规范化A前态D，P⊆D是循环不变量。初值包含于D；两类强制补格均包含于D；缺失见证就不存在这样的D。停机时P的两个半形稳定且Δ满足S判据，故P及T′有合法配方。第1节保证若原族有任何可制作成员，就有这种规范化D，因而两个切向都失败等价于整个族不可制作。

每次增长至少加入一个U格，仍至多20次增长及一次终检。覆盖族内全部顶盖不依赖枚举其成员。

## 3. Python及电路对应

`Solver4._family_recipe`只对含地面C的来源族建立模板，调用两次`minimal_start(..., optional_top=True)`。闭包返回起点后，先取得真实角制造证书，再向精确成员追加固定Δ。上层继续执行Pin并与指定输出逐格比较。其他族仍逐一恢复空/N/P顶盖，完整递归不变。

完整电路复用现有五帧、前缀闭包和制造ROM。只增加一个全局慢状态`optional_top`：

- 父帧遇含地面C的来源族，第一次仍以空NPC顶盖检查列A及Pin像。空NPC顶盖若违反列A，其他NPC选择不能修复；融合、静止与落点不受NPC顶盖影响。
- 下降时把子目标的自由顶格填为标签1（Cu），同时置`optional_top=1`。这个模板不是已承诺的精确目标，ENTRY仅检查列A，暂不以其K失败否定该族。
- `PrefixSearch.delta`保留全部未选格，供支撑闭包选入可选N；`required_delta`排除未选可选顶N，仅用于S追加及坏块检查。当前P仍须通过半形及K检查才能接受。
- 成功时，把子帧未选顶N写为空，保留已选顶N及固定C，同时清`optional_top`，再进入RETURN。此次目标修改属于慢事件，冻结一业务周期。制造与逐帧比较读取已经确定的精确目标。
- 失败回到父帧时清`optional_top`。父帧SOURCE_NEXT对含地面C的族直接推进晶体掩码，不再递增NPC顶盖。顶层C条件失败或物理失败的族也可以这样跳过。

这个模式只发生在含地面C的子帧，不能继续下降；父帧挂起时不需要保存模式，因此一个全局位足够。根目标不启用可选模式。成功路径父帧保存的空NPC顶盖只是族地址，回放从已确定的子目标制造并Pin；该族的所有NPC顶盖拥有相同Pin输出，所以不需要回写父帧顶盖地址。

含地面C可由来源地面“融合删除C”或“抬升后保留C”求并，不能只检查Pin后存活晶体，否则会漏掉地面辅助C。坏列跳转仍优先于整族跳转。

## 4. 边界

省去的是含地面C族的至多81次成员制造搜索；四列来源槽、顶层C掩码以及更高最低C的族仍可能很多。这个局部上界不代表完整求解器已具备实用等待时间。

本页依据数学推导和源代码静读；没有执行目标、目标枚举、求解、测试、反馈模拟或游戏。
