# 保留晶体屏障与顶针候选界

顶针输出中保留的晶体，在抬升后从未移动。因此同列保留的普通格或针不能穿过它下落。本页把这个必要条件用于四象限五层逆推，并给出无需枚举的候选上界。它不替代整图Pin和可制作性检查。

## 1. 屏障引理

层号从零开始。目标T在第c+1层有保留晶体，所以输入D的第c层必须有同标签晶体。顶针先删除触顶融合分量，再整体上移一层。保留晶体此后不能移动：只要所在组开始下落，它就碎裂，无法成为T中的这颗晶体。

考虑T在同列第z层的一颗保留N/P，来源为D第r层。原物体先上移到r+1，以后只下降，所以z≤r+1。若z<c+1而r≥c，则这颗N/P起于晶体同层或上方，却最终位于它下方。同层来源与强制晶体占位冲突；上方来源必须穿过这颗始终占位的晶体。重力下降不允许穿透格位，故两种情况均不可能。

反方向也不能穿越：若z>c+1，来源不可能在晶体下方，因为只上移一次就已有r+1<z。故每一颗保留N/P在每道保留晶体的前后侧别不变。其他列怎样粘连、哪些辅助晶体碎裂、是否发生横向连接，都不改变这个同列阻挡结论。

在实现中，强制晶体来源行的集合为F。已按列保序的每一对来源r和目标z必须满足：

```text
z ≤ r+1，且不存在 c∈F 使 z ≤ c ≤ r。
```

这只是必要条件。侧别正确仍不保证正确落点、融合删除或真实制造来源。

## 2. 电路用前缀计数检查

令K是来源N/P掩码，L是目标中除新增地面针外的N/P列表。对强制来源晶体行c：

```text
count(K[0:c]) = count(L中目标层号 < c+1 的项)。
```

两个前缀都不包含晶体所在行。原单列通路已经计算K和L的一热前缀计数；各个相同计数位相与再取或，即可比较两边计数。无该强制晶体时旁路。四个屏障条件先合为一项，再加入已有有效条件，保持末端合取的深度。

按保序匹配和总数相等，前缀数量相等当且仅当没有N/P跨过该屏障：如果目标侧有m颗，来源侧也只能由前m颗组成。因而电路计数等式与Python的逐来源侧别检查等价。输入有效时，一热比较的每一位含义由[单列前缀计数证明](pin-column-circuit.md)保证。

[`inverse._sources_fit`](../synthesis/inverse.py)由`pin_column`和`pin_families`共同使用。它在组合其他列之前筛选；`pin_families(check_output=False)`也保留该必要条件。默认物理检查和取证优先模式都不漏真实制造前态。

[`column_candidate`](../pin_column_circuit.py)增加四道前缀等式。独立单列蓝图从490增加到518平台，最大频道依赖深度仍为34；自动单列迭代器从846增加到874平台，仍用P=156、每轮52模拟秒。输入与输出频道以重新生成的JSON为准。八位计数仍遍历256轮，当前优化减少的是有效分支，而非这256轮的等待时间。

## 3. 地面掩码把每列上界降为20

令n为保留N/P数，f为强制晶体数。先忽略列A、屏障和落点限制，仅计来源位置和其他格的空/C选择，所得超集足以给上界。n>4-f时没有候选。

先取f=0。输出地面为P时，来源地面必须占用。把来源地面由保留N/P占用和由辅助C占用两种情况分开，候选上界为：

```text
C(3,n−1) × 2^(4−n) + C(3,n) × 2^(3−n)。
```

某项的组合数下标无效时整项为零。按n=0、1、2、3、4，以上分别为8、20、18、7、1；这是直接代入五个组合式，不是枚举目标或候选。最大值20。

输出地面不为P时，来源地面必须为空，只有其余三行可选。上界为`C(3,n) × 2^(3−n)`，按n=0、1、2、3分别为8、12、6、1，最大值12。

所以无论地面掩码如何，每列有效候选至多20。列A、晶体屏障和位置限制只会继续删减。

## 4. 含保留晶体的列至多12个

现在f≥1。如果强制晶体就在来源地面，地面已占用，其余至多三行可选。忽略额外强制晶体，把这三行全作为自由行，上界为`C(3,n) × 2^(3−n)`，最大12。

如果强制晶体不在地面，最多剩三行自由位置，其中包括地面。地面必须占用时，沿用前节分情况公式，但把总自由行数4改为3：按n=0、1、2、3，上界分别为4、8、5、1，最大8。地面必须为空时，只有两行自由位置，上界最多4。更多强制晶体不增加选择数。

因此有保留晶体的一列至多12个。四象限完整尾部中的Pin目标必含晶体，至少一列满足此界；其余三列各至多20个。前四层的四列组合于是至多：

```text
12 × 20³ = 96,000。
```

这个界没有利用屏障的实际排除效果，也没有计入顶层晶体掩码、顶层非C成员、S前缀或多帧回退。因此它不能当作完整求解时间界。它也不表示要保存96,000项；控制器仍可逐列缓存并按索引惰性组合。
