# 完整的起点到纯N/P追加段

[`s-tail-4q5l.spz2bp`](../blueprints/s-tail-4q5l.spz2bp)输入四象限五层原生目标，完整查找`A→S`，命中后自动输出全部消费式制造指令，并回放比较完整目标。A是[双半形起点](two-half-startpoint.md)，S是逐层无晶体追加；本部件尚不包含顶针逆推。含C未命中返回3，不能判不可制作。

当前10651平台，一份475行ROM共用两遍、六个物品槽、四个整数前缀高度和found/exhausted两位。没有保存半形目录、制造树或全量候选。target全程保持；enable=0至少1612信号tick，再改为1。window上升后48tick在本窗口内读一次；sample为真先接收instruction，再处理同窗done/status。

| 状态 | 含义 |
|---|---|
| 0 | 搜索或制造中 |
| 1 | 制造成功，槽0与完整目标逐格相同 |
| 2 | 违反列A，或无C目标穷尽完整起点/S搜索后不可制作 |
| 3 | 含C目标需要顶针尾部，或cu供料未界定 |
| 4 | 内部程序/回放失配，不构成不可制作结论 |

## 1. 只遍历不同前缀

S不改变旧格、不能新增C，也不能将新格插在原列顶以下。故前态每列只需保留目标非空格列表的一个前缀，且保留全部C。证明见[堆叠判据](stacking-proof.md)及[完整尾部](tail-solver.md)。

对一列，允许截止高度h：h=0时要求该列没有C；h≥1时，目标h−1行须非空，且h行及以上没有C。这样不同高度恰对应不同的允许前缀，不遍历空层造成的重复。最高允许高度始终是该列最高非空格加一；全空列只有0。

[`PrefixSearch`](../prefix_search.py)为每列设置一个[整数高度寄存器](integer-prefix.md)，并只沿允许高度从大到小移动。组合选择器挑出小于当前高度的最大允许高度；不存在时回到该列最高允许高度，并向下一列进位。四列到达各自最低高度后再失败，置exhausted。没有通过逐位整数递减走过无效高度。

初始高度在复位期间从固定目标计算。每轮只改动计数器；每列的允许高度表保持不变。按嵌套计数归纳，每个四列前缀组合恰检查一次，顺序从完整目标开始。最多6⁴=1296个组合。有C时至少一列有一颗必须保留的C，该列至多5个前缀，所以最多5×6³=1080个组合。目标带空格或多颗C时可更少；这里没有测量实际数量。

## 2. S判据只看新增块

令Δ是目标被前缀删掉的格。电路要求非空前态、全部目标C均保留。对每个原层号：

- Δ针独立成块，必须在地面或正下方有目标格。
- Δ普通格按四列环相邻成块。以“地面或正下方有目标格”的Δ普通格作支撑种子，只沿Δ普通格边传播三次。四列环的任何连通块至多四格，因此传播后整块有标志，当且仅当块中有直接支撑。
- 每个Δ普通格都须取得支撑标志。旧格不参加传播，旧同层N不能充当上料粘连边。

这正是S充要判据的新增块部分。下面的起点检查进一步保证前态确实可制作，因此属于K；S判据的下料前提由真实制造证书提供。

## 3. 命中以后才制造

每个前缀只用材料布尔信号检查两个互补切向：两半分别稳定且逐列A。原目标A通过而且保留全部C时，允许前缀的A仍成立：它只删NPC尾，不能补坏或删除任何保留格的直接前缀。任一切向通过，即给出起点的完整角构造。

`accepted = appendable AND available`。搜索未停止且accepted为真时，下次副组只置found，计数器保持当前高度；不再推进到下一候选。之后found永久为真，前态及切向不再变化。制造器下一完整周期才执行PC0。

两遍共用角程序制造前态，按[双半形协议](two-half-startpoint.md)恢复世界朝向。第二遍末尾从低到高发布每层Δ基础料及一次Stack；空Δ层不发指令。每份基础料只含N/P，每块落点由第2节保证。此前态属于K，所以旧格不动；逐层归纳得到完整目标。

制造仍使用六槽：双半形阶段槽5暂存首半形；拼接后仅槽0存前态。追加阶段临时使用槽1，每次Stack后回到仅槽0。返回1前还用原生图形比较槽0和完整target。

## 4. 完整范围与失败语义

任意存在`A→S`历史的目标，其前态逐列前缀一定在允许高度域内；S物理判据和某个起点切向均通过，因而搜索会命中。反向，命中分支由合法角宏、交换、基础NPC原料和Stack构成，故输出指令确实得到目标。这证明本部件对`A→S`范围的可靠性与完备性。

无C目标若可制作，存在底层基础原料加逐层堆叠的制造方法。非空底层本身是起点A，而且属于搜索的某个前缀组合，剩余各层满足S判据；因此无C目标未命中可以判不可制作。这个结论不能推广到含C目标：它可能需要一次至四次顶针。所以含C搜索耗尽只返回3，后续要交给完整顶针帧控制。

cu先返回供料范围3；列A违例可以直接返回2。程序错误返回4，不与上述搜索否定合并。

## 5. 搜索与制造按各自变化路径计时

共用[`execute_program`](../program_controller.py)接收6份`StateUpdate`，用同一个主副时钟锁存。初值可以引用复位期间不变的目标信号，因此高度初始值不用另开一套加载时钟。

搜索期间，计数器改变会使整份角程序的数据表达式重新计算；但found=0，物品、PC及制造确认保持，不能把这些尚未稳定的数据当成指令。搜索只需保证下一份计数器/found/exhausted在主组关闭前正确。

设P是每阶段宽度：

1. 搜索状态变化到搜索更新源的投影深度为37。计算器在`Circuit.changing_depth(..., outputs=...)`中只限制最长路径的终点；仍检查整个频道图无环和静态选频。搜索更新加入口/历史余量至多12×37+36=480tick，须小于3P。
2. found=1后计数器冻结。每轮真正变化的制造状态、遍次、PC等到组合出口的深度为52；同样要求12×52+36=660tick小于3P。
3. 最后一次计数器改变发生在某次阶段2。它对应的accepted最早在下一周期阶段2写入found，这时已过4P；首条制造事务在再下一次主组关闭时采纳，还多3P。因此计数器到首条制造采纳有7P。最长预计算变化深度87，12×87+36=1080tick须小于7P。

当前P=228，3P=684、7P=1596，三项均严格满足。初始计数直接命中时，计数及目标程序已在复位期间算好，不依赖上述等待。这个7P规则要求调用者确实在发令前冻结相应状态一整周期；普通会变化的状态不能任意标成预计算输入。

整图初始深度113；复位max(4P+128,12×113+256)=1612tick，覆盖目标预计算、动态高度初值、状态历史及清空时钟。主副关写后仍有P留作历史保持。窗口发布与原自动半形保持相同的48tick读取合同。

## 6. 当前规模与下一步

每周期912tick、76模拟秒。保守计1296次前缀检查、两遍各475行及一次初始化，总计2247周期，即47小时26分12模拟秒；含C的组合上界改为1080后至多2031周期，即42小时52分36模拟秒。宏跳转和提前命中会缩短流程，但未执行目标以测量耗时。它仍是偏大的中间实现，需要继续压缩时间和平台，不能当作完整实用TMAM验收通过。

本次完成四个Python文件LSP零诊断、生产蓝图逐端口与实际占地静态编译；未使用前缀搜索的独立起点及标准半形沿用原产物。没有执行目标、指令、枚举、测试、反馈模拟或游戏。

[完整控制](full-tail-circuit.md)已把同一材料叶端接入完整Pin逆像和至多四个递归帧，实用性能仍需压缩。范围仍是四象限，不能把本页充要判据用在六象限；六象限要保留已发现的非K和不稳定可制作状态。
