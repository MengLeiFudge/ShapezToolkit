# 半切与顶针逆像的压缩，以及一次半切的制造证书

本页限定四象限五层。它给出保持物理逆像覆盖的压缩，以及一个有明确制造步数界的半形构造子类。完整半形另有[逐列角构造及局部充要条件](corner-synthesis.md)；本页制造子类的失败不构成不可制作证明。

实现见 [`synthesis/inverse.py`](../synthesis/inverse.py) 的 `pin_families`、`cut_families`，以及 [`synthesis/construct.py`](../synthesis/construct.py) 的 `Constructor`。物理结算使用[静止组及落点定理](pin-inverse.md)，保留普通部件、颜色和原层号。

## 顶层只按晶体掩码区分一次顶针的物理输出

固定前四层后，原第五层的普通格和针全部直接被顶破；它们不参与下落，也不参与晶体融合。因此，一次顶针只通过第五层的晶体掩码区分输出。同一掩码下，把其他第五层格任意改为空、普通格或针，输出不变。

保留晶体在前态的位置唯一。每列保留的 n 个非晶体格按顺序嵌入前四层，其他未占位置选空或消失的晶体。忽略目标高度、强制晶体和地面掩码的进一步限制，单列选择至多

```text
C(4,n) × 2^(4−n) ≤ 32。
```

四列至多 `32^4` 种前四层；第五层晶体掩码至多 16 种。因此，每个目标的正向顶针物理计算至多 `2^24` 次。这个上界没有把族内前态制造判定也缩减到同样规模：族内的空/N/P 顶盖仍可能改变前态是否可制作，不能只制造一个代表。

`PinFamily.members` 恢复这些成员。输出中保留的标签精确回填；最终消失的普通格、晶体仅取固定辅助标签，依赖[结构与标签分离](coverage-research.md)的制造前提。

## 半切按保留侧晶体分量的删除效果区分

目标先旋转到标准前半 q0、q1。两列中，保留晶体保持原高度；保留 N/P 在同列保序，原高度不低于目标高度。其他源格只能为空或最终消失的晶体。对单列 n 个保留 N/P，源列选择至多

```text
C(5,n) × 2^(5−n) ≤ 80。
```

固定保留侧格位后，先计算仅含晶体的融合分量。某分量在半切前消失，当且仅当完整输入中有外侧晶体直接与它相邻。含目标晶体的分量必须保留；其他分量只需区分删除或保留。

2×5 网格中，任意两个晶体分量不相邻。从各分量任选一格，得到独立集；逐层覆盖的五条横边限制独立集至多五格。因此晶体分量至多五个，删除效果至多 `2^5` 种。对每个目标，正向物理计算至多

```text
80² × 2^5 = 204800 次。
```

这是物理逆像族的上界。外侧完整格位仍可有很多制造上不同的补全。`CutFamily.members` 明确保留这一区别，不能仅因物理输出匹配就接受输入。

## 不枚举外侧全部格位的一次半切构造

给定 `cut_families` 返回的保留侧及删除效果，采用如下充分条件：

1. 含晶体的保留源列属于[可独立制造的单列分类](column-theory.md)。
2. 不含晶体的保留源列，与一根五层普通辅助柱并排后，可用无晶体逐层构造制造。

为每个待删除晶体分量任选一个格 `(z,q)`。若 q=0，在 q3 同层放辅助晶体；若 q=1，在 q2 同层放辅助晶体。外侧其他位置全部填普通块，统一补足五层。

这恰好删除所选的分量。每个保留格只有一个外侧水平邻居，所选辅助晶体接触的保留分量就是它的指定分量。辅助晶体彼此融合也不会接触额外的保留分量。保护分量没有直接跨界晶体邻居，因此不被连带删除。

制造分两侧进行：

- q3、q0 为一份半形；q1、q2 为另一份半形。
- 主列含晶体时，两根列都可独立制造，再拼接为该半形。
- 主列无晶体时，这侧没有需要触发删除的主列晶体，故辅助列全是普通块，整份半形直接按无晶体层构造。
- 拼接两份半形，再半切保留 q0、q1。由于所选物理逆像已经通过正向结算，得到的就是目标。

每份原料和加工都有实际制造树，成功具有可靠性。这个定理没有证明每个可制作半形都满足上述充分条件。

### 制造步数界

独立单列高度 h≤5。含晶体列写成底针前缀、紧 N/C 段、N/P 后缀。按 `Builder.column` 展开，基础原料、堆叠、结晶、顶针、旋转与切割总节点数至多 `3h+5≤20`；无晶体独立柱至多九个节点。

q3、q0 各造一列后只需一次交换拼接，因此每份侧半形至多 41 个制造节点；无晶体侧半形至多九个节点。两侧拼接至多三个旋转与一次交换，末次半切一个节点。所以本分支的标准半形制造树至多

```text
2×41 + 4 + 1 = 87 个制造节点。
```

四象限的任意旋转可由顺时针、逆时针或半周旋转完成。若全图可按某一方向分为本子类的两份半形，还原两侧朝向、交换并恢复全图朝向，制造节点至多 177 个。此处计数包含基础原料节点，不涉及运输等待；它不是全体可制作目标的步数上界。

### 允许晶体前缀以上的 N/P 后缀留空

实现还允许先制造每列最高晶体及以下的独立前缀，再按目标层追加 N/P。没有晶体的列不进入前缀。追加只增加新格，不覆盖原格；每一层实际虚拟堆叠的结果都必须等于原前缀加已处理的目标格，最多五份单层。由逐步结果相等直接归纳，成功配方可靠；失败仅表示这一追加形式不成立。

这允许主列在最高晶体上方保留空隙，例如地面 C、空第二层、N3/P4/N5，可以在外侧普通柱帮助下逐层添加后缀。每份侧半形的前缀至多两根独立柱加一次交换，最多 41 个节点；追加最多五份原料、五次堆叠，侧半形上界为 51。扩展后一次半切构造的标准半形上界为 107 个节点。原来两列均可独立制造的子类仍保留 87 的较小界。

`Builder.crystal_prefixes` 与 `append_noncrystal` 实现这个构造。它只使用已有晶体前缀，不假设新晶体可以从上料保留下来，也不把六象限的任意下料当成稳定下料。

### 整层空隙例的直接证书

[Mari 默认算法漏解的目标](mari-empty-layer.md)可由以下完整输入的一次标准半切得到：

```text
输入 D：crCuCucr:CucrcrCu:crCuCuCu:crP-CuCu:crCuCuCu
输出 T：CuCu----:--------:crCu----:crP-----:crCu----
```

D 的四根列都属于独立单列分类：q0=`C N C C C`，q1=`N C N P N`，q2=`N C N N N`，q3=`C N N N N`，所以可以按上述两侧构造制造。

半切删除 q3 的地面晶体及 q2 的第二层晶体，分别连带删除 q0 地面晶体和 q1 第二层晶体。q0 第二层普通块落地。q0 第三至第五层晶体与 q1 第三、第五层普通块粘连，q1 第四层针独立；二者形成含针支撑环，保持原位。q1 地面普通块也保持原位，结果恰为 T。

这是人工逐格证书，没有运行目标求解或游戏验证。

## 辅助支撑转交

一次半切构造子类不完备。可制作半形

```text
T：--cr----:Cucr----:crcr----
```

的两列分别为 `- N C` 与 `C C C`。若从独立柱准备保留侧，q0 的 N 必须原在第二层，不能从第三层以上穿过保留晶体落到第二层。q0 第一层为 N/P 会被保留；要消去它只能填待删除晶体。然而它与必须保留的 q1 地面晶体融合，无法单独删除。因此这个 T 不属于上节子类。

T 有如下合法制造证书：

1. 独立柱拼出 `D0=crcr--Cu:Cu----Cu:cr----Cu`，即 q0=`C N C`、q1=`C`、q3=`N N N`。
2. 切割保留 q3、q0。q1 地面 C 连带删除 q0 地面 C，q0 的 N2、C3 由 q3 普通柱保持，得到 `A=------Cu:Cu----Cu:cr----Cu`。
3. 准备 q1=`C C C` 的独立柱，按 q3q0 / q1q2 与 A 拼接。
4. 切割保留 q0、q1。外侧只删普通块，q0 的 N2、C3 改由 q1 晶体柱保持，得到 T。

这给出一种支撑转交：对目标半形选择一根锚列，先将它与外侧全普通辅助柱按晶体前缀及 N/P 追加构造准备。另一目标列也先与它的外侧临时辅助柱组成半形，再拼接两份侧半形，最后移走两个外侧支撑。后一根辅助柱只枚举连续五层 N/P，共 32 种；其半形只调用一次半切的直接构造，不递归调用转交构造。最后用真实半切结果确认目标。

两个辅助柱都不含晶体，不会在末切连带删除目标晶体。只要两份侧半形均有配方、最后半切匹配，就得到可靠证书。直接构造的辅助半形至多 107 个节点，恢复方向一个旋转；锚列侧只有一根含晶体前缀，独立制造及追加至多 30 个节点；拼接至多四个节点、末切一个节点，总计至多 143 个节点。两个这样的半形合成全图至多 289 个节点。这个步数界仍仅适用于构造成功的子类。

## 实现与剩余命题

现行 `Constructor.half` 使用[逐列角构造](corner-synthesis.md)，以稳定性和列条件精确判定合法材料范围的半形，制造上界为285节点。本页保留逆像压缩及有较小步数界的构造子类。完整全图构造未覆盖时仍返回 `unknown`，不会把局部失败当成全局否定。

半形部分已有无需递归的角构造；完整电路仍需压缩四象限全图的顶针与堆叠尾部。六象限存在非 K 与不稳定输出，不能直接沿用四象限的堆叠约化或半形几何结论。
