# Mari 角模板表与晶体间隙约束

本页分析 Brain P18、P35、P49、P68 的特殊角模板表。四份表各有 41 个比较键，键和三组输出常量完全一致。这里证明的是列模式的必要条件及这张表的模式范围；不把它扩大为六候选拆解或实体工厂的完备性证明。

以下层号从 1 开始，由底向上。用 `N` 表示任意普通块，`C` 表示晶体，`P` 表示顶针，`-` 表示空格。短列在上方补 `-` 到五格。这是目标中一列的投影，可以依靠邻列支撑，不是可独立制造的单列。

## 1. 晶体之间的间隙不变量

已有 [Q、J 不变量](../general/column-invariants.md)分别约束晶体下方的针前缀和空隙下方最近的非空格。在它们之外，还可以从部件的制造历史得到：

> 同列两个晶体之间如果有空格，二者之间至少有两个普通块，且下方晶体紧邻的上一格非空。

只需证明对同列相邻的两个晶体成立；这里的“相邻”指中间没有其他晶体，允许有普通块和空格。Q 已排除二者之间的顶针。

**晶体位置与列内次序。** 保留到输出的晶体不能下落，否则会碎裂。顶针使所有保留晶体共同上移一格；旋转只共同改变列号。切割不会在同一列混合两个输入，交换也整列继承一个输入。堆叠的上料晶体不能保留。因此，两颗最终晶体的共同历史在同一条输入支路上，直到至少其中一颗由结晶产生。

**结晶建立起点。** 结晶填满当前高度以内的全部空格及顶针。所以两颗晶体刚开始共同存在时，它们之间没有空格，紧邻下方晶体的上一格也非空。

**第一次出现空格。** 在两端晶体都保留的前提下，中间普通块不能向下穿过下方晶体。切割不能只删掉这列的中间格，截高也不能删除中间格而保留更高的晶体。若区间原本连续，普通块没有可落入的空位。因此，该区间第一次出现空格必然涉及中间晶体消失。

消失的晶体不能与任一保留端点形成连续晶体串，否则融合删除会连带端点；若由下落碎晶引起，连续晶体属于同一粘连组，也会同时下落碎裂。由于此时区间尚无空格，消失部分与两端之间各需至少一个普通块作为隔断。因此至少两个普通块留在区间内。它们不能被切割或截高单独删除，也不能越过下方晶体，所以下落不降低这两个隔断的数量。

紧邻下方晶体的上一格若是普通块，会被该晶体阻挡；若是晶体，与下方晶体融合，不能在保留下方晶体时单独消失。因此这一格始终非空。后续晶体消失可能把多个相邻晶体区间合并：原区间已有空格时，已有的两个普通块和紧邻支撑保留；原区间均无空格时，仍适用上述首次出现空格的论证。新结晶则重新填满所有间隙。由制造树归纳，结论对允许操作的全部输出成立。

这个证明不使用“支撑链必须触地”的简化假设，也没有排除含顶针的循环支撑。它是必要条件，不能单独作为两列半形的可制作性判据。

## 2. 五层内恰有 41 种含悬空间隙的列模式候选

这里的“悬空间隙”指某颗晶体下方紧邻空格；不是普通块下方空格，也不是整列独立悬浮。按最低一颗具有这种间隙的晶体所在层分类：

| 该晶体所在层 | 列模式 | 参数范围 | 数量 |
|---|---|---|---:|
| 第 3 层 | `N-Cxy` | `xy ∈ {--, -N, NN, N-, NP, NC, PN, P-, PP, CN, C-, CP, CC}` | 13 |
| 第 4 层 | `aN-Cx` | `a ∈ {-, N, P}`，`x ∈ {-, N, P, C}` | 12 |
| 第 4 层 | `N--Cx` | `x ∈ {-, N, P, C}` | 4 |
| 第 5 层 | `abc-C` | `abc ∈ {NNN, N-N, PPN, PNN, P-N, -NN, --N, CNN}` | 8 |
| 第 5 层 | `aN--C` | `a ∈ {N, P, -}` | 3 |
| 第 5 层 | `N---C` | 无参数 | 1 |
| 合计 | | | **41** |

分类理由如下：

- 第 2 层晶体若下面为空，没有 J 所要求的更低普通块，故不成立。
- 第 3 层只能是 `N-C`。其上两格的 16 种原始组合中，`PC` 违反 Q，`-C` 违反 J，`-P` 使顶针无直接支撑，余下 13 种。
- 第 4 层前可为 `aN-` 或 `N--`。`CN-C` 在两晶体之间只有一个普通块，被第 1 节排除；其余 `a` 只能取空、普通块或底针。
- 第 5 层前若有一个空格，最近下方非空格必须是第 3 层普通块。前两格受 Q、针直接支撑和第 1 节限制，恰剩表中八种前缀。两个或三个空格分别给出三种和一种。

这不是运行 4⁵ 个编码得到的计数，而是按晶体高度和间隙长度的有限分类。这里“候选”仍只表示满足已证必要条件，不自动宣称每种候选的任意邻列组合都可制作。

## 3. 与原蓝图的对应

P18 的比较器位于 `(x,y,L)`，其中 `x ∈ {2,7,12,17,22,27,32}`，`y ∈ {-15,-7}`，`L ∈ {0,1,2}`；`(2,-7,2)` 不属于该表，共 41 项。

每个比较器把 P17 `(2,14,0)` 交换器的输出 1 与常量描述形状比较。描述形状的第 0 象限恰为上表的一种模式；其他象限是辅助填充，其中部分底针前缀也写入第 1 象限。不能把这四象限描述形状当成目标本身。

每个匹配项选出三组常量：

1. 晶体辅助料描述，例如 `crCucrCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu`。
2. 普通块及顶针辅助料描述，例如 `CuCuCuCu:P-P-P-P-:CuCuCuCu:CuCuCuCu:CuCuCuCu`。
3. 编码为三层形状的加工控制数据。

P18、P35、P49、P68 的键与三组值逐项相同。此结论来自静态读取常量和连线，没有执行门电路。

P17 还含普通部件归一化、底针处理、短列编码表以及 `P-N-C` 特殊分支。因此，41 项表的完整性不等于已经证明原始目标必然被归一化到正确项。仍需核对归一化、三组控制数据、后续加工以及四角拼接的端到端关系。

## 4. 对全覆盖调查的意义

这张表没有在上述 41 种五层列模式中漏项，四个角副本也没有静态表值差异。它排除了一个具体疑点：不能仅因 `NCN-C` 或 `CCN-C` 没有表项就认定 Mari 漏解；它们违反晶体间隙必要条件，本身不能出现在允许的制造结果中。

全机仍需证明支持方向选择、hybrid 拆除、deny 回填和 claw 处理至少有一个候选成功。列模式的完整表不能替代这个全图命题。
