# 顶针逆像：在制造以前筛掉组位移矛盾

[`pin-image-4q5l.spz2bp`](../blueprints/pin-image-4q5l.spz2bp)在给候选找制造证书以前，检查其晶体融合删除、同组静止/移动一致性及移动N/P块的落点支撑。Python对应[`pin_image_possible`](../synthesis/pin_constraints.py)，已接到`pin_families(..., check_output=False)`；默认先做精确正向Pin的模式保持原路径。

这是必要筛选。输出`necessary_pass=1`仍须递归制造来源、在真实产物上做原生Pin并比较目标；它不证明前态可制作，也没有证明推定的F是最大静止集合。

当前5037平台。输入五层四列目标材料0空1N2P3C、四列各八位keep/extraC控制、四位顶层C掩码及enable。输出还包括原来源坐标的融合删除位、抬升后坐标的claimed_fixed位。整组输入保持6656信号tick（D=102，约554.67模拟秒）后读取；没有完成脉冲。这比当前长角制造更便宜，但没有运行目标来测量实际剪枝率。

## 1. 由目标来源直接恢复静止/移动标记

使用从零开始的层号。某保留N/P来自输入r∈{0,1,2,3}，被Pin抬到r+1，按列保序映射到目标z≤r+1。

由[静止组与落点定理](pin-inverse.md)，任何非静止组都至少下降一次。游戏`ShapeLogic.SimulateFallDownPhysics`先判断整组可下降，再将所有格的LayerIndex减一，之后才碎C拆组；拆出的N/P不会失去已经发生的下降。因此：

```text
z = r+1  ⇔  该N/P属于静止集合F；
z < r+1  ⇔  该N/P属于移动部分M。
```

保留C只能位于抬升后的原位置，故强制来源C属于F。其他低层C若没有先因顶破融合删除，就必须属于M并在下落时碎掉。新地面Pin由删除前的底层占用补出，始终接地，属于F。

[`column_candidate(..., with_landings=True)`](../pin_column_circuit.py)沿用已有一热来源秩路由，额外输出每个低层NPC来源的五位目标层onehot。F位就是该来源第r+1个目标位；不含NPC的来源没有任何目标位。默认不开这些元数据，因此原518平台单列及874平台自动单列蓝图重编译不变。

## 2. 精确融合删除与局部组约束

在原输入的20格晶体邻接图上，以第五层C为种子，沿水平C/C及竖直C/C传播19轮。任意连通晶体格与种子间存在不超过19边的简单路径，所以传播恰得到所有触顶融合分量。普通块、针和晶体颜色不参与融合。强制保留C一旦在此集合内，直接拒绝。

删掉触顶C、删除整个第五层、抬升前四层，再按删前底层占用补地面P。对所得活格使用第1节推定F/M：

- 水平相邻的两非针格必须具有相同F位。
- 竖直相邻的两C也必须具有相同F位。
- M格不能直接位于F格上方；若有这样一份静止阻挡，该M初始组本身也不会移动。

前两项沿全部粘连边传播，恰保证每个初始最大组具有统一标记；不需要建立20×20连通矩阵。F位不同的两个格必不是同组，所以第三项没有误把组内格当成外部支撑。

## 3. 移动NPC块

移去M中的晶体，剩下每个原层的水平普通连通块及独立Pin。一个这样的普通块只能整体下落，所有成员的目标层必须相同。电路逐条检查相邻M普通格的目标onehot相同，这就保证整块一致；P不参加水平传播。

最终每个移动块必须落到地面，或被目标中某个正下方格挡住。因此普通块至少一个成员在目标层z=0或目标(z−1,q)非空；Pin单独满足此条件。以具有这种直接支撑的M普通格为种子，沿该来源层的M普通边传播三次，就覆盖四列环的整个块。

这里只从真实输出必须满足的条件推出拒绝规则，不把目标同层的旧格纳入新增粘连。来源到目标的列内保序和[晶体屏障](pin-barriers.md)仍由单列通路提前检查。

## 4. 为什么不漏真逆像

任意真实可制作D满足已有单列来源、地面针和晶体屏障条件。输入顶层NPC在重力前已被删除，既不改变C融合，也不影响低层初始组，所以整个筛选只依赖前四层和顶层C掩码，同一逆像族可共享结果。

真实Pin中保留N/P是否移动与第1节标记一致；保留C不属于触顶融合删除。初始最大组整体是否移动，因此所有粘连边标记一致；真实M不会受F直接阻挡。碎C后的保留块整体下降并最终受地面或正下方目标格阻挡。所以真实逆像通过每一项，提前拒绝不损害完整性。

反向没有在这里成立：推定F的组可能缺乏有效静止支撑，或被标M的组之间仍有支撑环。本部件没有验证F最大性。后续仍需在可制作子证书的真实原生产物上执行Pin并完整比较；筛选通过不能直接接受。

## 5. 实现与当前边界

Python在族生成时只为`check_output=False`调用此必要筛选；随后`Solver4(..., certificate_first=True)`仍按既有逻辑取得子配方并原生比较Pin结果。`check_output=True`仍使用精确`rules.pin`作族检查。两种模式都没有预算失败即不可制作的分支。

四个相关Python文件LSP零诊断。新5037平台生产蓝图完成DAG深度、端口、别名和实际占地静态核对；原518/874两份部件重编译不变。没有运行任何目标、控制字枚举、物理模拟、测试或游戏。

完整四象限控制还需四列/顶盖游标、动态目标网格叶端、至多五帧回退及成功路径重放。新筛选提供更早的拒绝点，没有给出完整搜索的实用最坏时间保证。六象限及一般偶数参数仍须按顺序另行完成。
