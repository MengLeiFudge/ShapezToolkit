# 顶破、碎晶与下落的完整顶针逆像

本文限定四象限五层，材料结构为 `N`（普通块）、`P`（顶针）、`C`（晶体）、`-`（空格），层号自底向上为 1～5。普通种类与合法颜色按[标签替换定理](coverage-research.md#2-颜色与普通形状种类可以抽离)恢复。

结论是一个有限、必要且充分的逆向规则：恢复全部可能的来源格位与第五层，以静态支撑图和落点公式检查顶针结果，再用[半形闭包判定](half-closure.md)筛选可制作前态。这里不把“前态可制作”留作未知判定器。证明不依赖运行枚举、模拟或游戏。

## 1. 一次下落可化为静止组与水平落块

先处理切割或顶破导致的融合删除。以删除完成、重力尚未开始的格位为 X，按当前格位建立最大粘连组。水平相邻的非针格粘连；同列相邻晶体竖向粘连；顶针单独成组。

画直接支撑边 G→H：G 的某格正下方是另一个组 H 的格。含第一层格的组接地。以下求出的集合 F 称为**静止组集合**，它不等同于 K：

1. 起初保留全部组。
2. 删除不接地、且没有指向仍保留组的支撑边的组。
3. 反复删除，直到不能继续。

F 是“每个组接地或被集合内另一个组阻挡”的最大集合。等价地，F 包含初始支撑图中所有能到达地面或任意有向环的组，以及这些路径上的组。这里允许无针环；不能在计算真实重力时先按 K 排除它们。组数至多 20，至多 20 轮删除即可完成。

### 静止组定理

**F 中的组恰好是本次下落从未移动的组。**

充分性：F 中每组始终有地面或 F 内其他组阻挡。假设 F 首次有组移动，则它开始移动时这些阻挡都还在，矛盾。

必要性：设 U 为实际结算中从未移动的组。移动过的格不可能在任何后续时刻直接挡住一个始终未移动的格：它至少下降一格，若最终停在该格正下方，途中或起点就必须占过该格的位置。游戏不允许这种重叠或穿透。结算结束时，U 中每组因此只能被地面或 U 内其他组阻挡，故 U 是上述删除过程的一个不变子集，U⊆F。结合 F⊆U 得到等式。

这里的“移动过”包含晶体碎裂后拆出的子组。它们继承已发生的下降，不会重新成为未移动组。晶体消失条目不再阻挡活组；源码即使继续处理这些消失条目的动画位置，也不影响输出格位。层号下降有界，结算必然终止。

### 剩余部分的精确落点

F 的全部格保持原位。其他初始组至少下降一次，所以其中的晶体全部消失，普通格和顶针全部保留。去掉这些组内的晶体后，把剩余部分分为各层的最大水平 N 连通块及单个 P。记每个块 b 的初始层号为 s(b)，占据列集合为 J(b)。

只把 F 的格作为固定障碍。按 s 从低到高处理其余块，同层顺序任意。令：

```text
z(b) = 1 + max(
    {0}
    ∪ {r : F 在列 j、高度 r 有格，j∈J(b)，r<s(b)}
    ∪ {z(a) : s(a)<s(b)，J(a)∩J(b)≠∅}
)
```

将 b 放到 z(b)。注意只看**初始位置下方**的固定格；不能用整列最高格阻挡本来就在悬空框架下方的块。

公式的证明分三步：

- 非 F 组的任何格都不可能正好被 F 的格从下方阻挡，否则该组也应加入 F。因此上述固定障碍至多在 s(b)−2。归纳地，较低移动块 a 满足 z(a)≤s(a)−1，所以 z(b)≤s(b)−1，与每块至少下降一次一致。
- 同列两个保留格不能交换次序。所有可能位于 b 下方的移动障碍，恰好来自初始层号更低、与 b 共享至少一列的块。同层不同块的列集合互不相交；初始较高的块不能穿过 b 来阻挡它。
- 当下方块到达最终位置后，b 会继续下降，直到地面或公式列出的最高障碍将其挡住。该块水平移动为零，内部只有一个高度，故首次阻挡就是整体落点。先前与晶体共同移动的一步只改变等待时序，不改变这些不可穿越的上下关系。

因此最终输出唯一等于 F 的格，加上按公式落稳的 N/P 块。这个证明也说明，选择哪个可动组先下降不影响这些保留格的最终位置；它没有把下落后的新接触合并后再做一次重力。

上述结算适用于本页的顶针及半切，因为结算起点全部格已在五层以内，不会再发生截高。不能不加说明地拿它替代任意堆叠后的截高流程。

## 2. 顶针的精确静态关系

给定候选输入 D，先在**原始 D** 上计算全部晶体融合分量。融合边仅连接水平相邻或竖向相邻的晶体，不经普通块，也不区分晶体颜色。

令 E 为所有接触原第五层的晶体融合分量的并集。构造结算起点 X(D)：

1. 删除 D 的整个第五层。
2. 删除 E 中位于原第一至第四层的晶体。
3. 其余原第一至第四层格统一上移一层。
4. 对 D 原第一层非空的每一列，在新第一层放一个 P。这个掩码在删晶体之前确定，即使原地面晶体被 E 删除，也仍加针。

随后应用第 1 节的 F 和落点公式。记所得格位为 Π(D)。则：

> Π(D) 与游戏一次顶针输出的材料、列号、层号逐格相同。

证明：源码先展开并记录融合关系，排除原第五层，提高其余引用并根据原底层占用补针，再在 `Collapse` 中处理融合删除与下落。上述四步中补针掩码取原 D，所以与实际调用次序等价。融合删除之后的活组是当前最大粘连组；第 1 节已处理其完整下落。所有活格在五层以内，末尾截高不再影响结果。

被删除的晶体现在有完整分类：原第五层直接删除；E 中低层晶体融合删除；X(D) 中非 F 组的晶体下落碎裂。其余晶体全部留在原层号加一处。不能只恢复 E 而漏掉第三类。

## 3. 从目标生成所有候选前态

以下求的是**可制作输入**的完整逆像。地面针掩码使用[已证明的可制作状态不变量](../general/column-invariants.md#4-顶针逆向的通用位置约束)，不宣称对任意不可制作语法状态也成立。

给定非空目标 T：

1. 若 T 第一层含 C，逆像为空。令 M 为 T 第一层 P 的列集合；这些格全部标为本次新生成的针。
2. T 的每个 C(z,j) 强制 D(z−1,j)=C。z 必须至少为 2。
3. 对每列，去掉第一步标记的新针，按从低到高顺序列出 T 中全部 N/P。这些格与 D 原第一至第四层的 N/P 一一对应，材料及列内次序相同。
4. 为该列的 n 个 N/P 选择严格递增的来源层号 r₁<…<rₙ，均在 1～4，且对应输出层号 zᵢ≤rᵢ+1。来源格不能覆盖第二步强制的晶体；n>4 时没有候选。
5. 原第一至第四层剩余未占格任取 `-` 或 C。原第五层四格任取 `-`、N、P、C。这些选择分别覆盖可能消失的低层晶体和完整的顶破层；不能加入没有输出对应物的低层 N/P。
6. 保留非空 D，且 D 第一层非空列集合必须恰好为 M。
7. 用第 2 节的静态公式要求 Π(D)=T；再用[全图可制作判据](half-closure.md#7-由半形判定全图可制作性)要求 D 可制作。

第 7 步之前可以用 K、Q、J 等必要条件排除候选，但通过这些条件不能替代可制作判据。

### 必要性

任意真实可制作前态 D 都满足地面针等式。保留 C 没有下落，其来源位置唯一。原第一至第四层的 N/P 不被顶破、融合或下落删除，因此全部出现在 T；也没有除新地面针以外的新 N/P。它们只沿本列下降，次序不变、最终高度不超过来源层号加一，故必出现在步骤 3～4 的选择中。

其余低层格只能是空或后来碎掉的晶体；第五层完全由顶破删除，步骤 5 没有限制其真实取值。真实 D 因而一定被生成，并通过步骤 6～7。

### 充分性

通过全部步骤的 D 已由独立判据给出合法制造方法。第 2 节保证其一次顶针结果恰好是 T。因此每个返回候选都是合法前态，不依赖猜测删除原因，也不依赖未定义的可制作性判断。

所以返回集合恰为：

```text
InvPin(T) = {D ∈ R : 一次顶针(D) = T}
```

## 4. 有限界、特例与证书

每列有 n 个待恢复的 N/P 时，忽略强制晶体、掩码及高度约束，可选择至多 `C(4,n)` 组来源层号，剩余格至多 `2^(4−n)` 种空/C 填充。n=0～4 时两者乘积依次为 16、32、24、8、1，最大为 32。顶层另有 `4^4` 种选择，因此整个逆像生成至多：

```text
32^4 × 4^4 = 2^28 = 268435456 个候选
```

这是不用运行枚举即可得到的宽松上界，不是可制作前态数量，也不是实际耗时承诺。强制晶体及底层掩码通常会排除大量选择。本规则首先解决完备性，尚未做工程压缩。

若限定输入高度≤4，则没有 E；可制作 D 属于 K，提高并补针后不下落。候选收缩为原有的唯一前态：T 第一层只有针或空，第一层针掩码等于第二层占用掩码，删第一层后整体下降一层。无顶破规则由完整规则直接推出。

一个前态证书只需记录 D 的制造证书、晶体融合分量 E、静止组集合 F、其余水平块的来源与落点。它覆盖顶破、融合删除、下落碎晶和 N/P 位移四部分；没有逐帧重放或依赖某种下落调度的必要。

## 5. 手推例：融合删除之外还会下落碎晶

取以下紧图形 D。表格从上往下展示，列从左到右为 q0～q3：

```text
原层5    C N N N
原层4    C N C N
原层3    C N N N
原层2    C C C C
原层1    C N N N
```

它可由任意紧图形构造制造。q0 的五格晶体与原第二层整行晶体同属融合分量 E，接触第五层，故全部删除。原第四层 q2 的晶体被 N 隔开，不属于 E。原第五层其他 N 直接顶破删除。

提高并补针后，第一层四个新针和第二层 q1～q3 的 N 构成静止部分 F；第四层的三个 N，以及第五层的 N-C-N 组不属于 F。第四层 N 块落到第三层；第五层组至少下降一次，其中 q2 晶体碎裂，q1、q3 的 N 各落到第四层。结果为：

```text
结果层4  - N - N
结果层3  - N N N
结果层2  - N N N
结果层1  P P P P
```

这个例子同时包含顶层删除、融合向低层传播、融合分量之外的下落碎晶和普通格位移。逆向时若只补 E、不考虑非 F 组碎晶，就会漏掉合法前态 D。以上逐组推导未执行模拟。

## 6. 源码与结论边界

本轮静态重读的依据是 `DecompiledSource/Game.Content.Features/ShapeOperationPushPin.cs` 的 `ExecuteInternal`，以及 `ShapeLogic.cs` 的 `Logic_IsConnected`、`Logic_IsFused`、`Unfold`、`ComputeFusingResults`、`BuildGroups`、`SplitGroupIntoKeepAndVanish`、`SimulateFallDownPhysics`、`Collapse`。版本与程序集摘要沿用[来源记录](coverage-research.md#8-来源及核对范围)。

最需要保留的源码边界是：下落中只在碎晶后拆组，不合并新接触组；消失组不阻挡其他组；顶针的补针掩码在融合删除前取得。F 的删除过程是初始支撑图分析，不是把目标稳定性冒充可制作性。

本页给出人工证明和有限逆像规则，未执行目标枚举、物理模拟或游戏验证。半形闭包只使用 Π 的正向静态定义，不使用 InvPin 或 R 判定；随后才定义 R 和 InvPin，因此两份文档之间没有循环判定依赖。
