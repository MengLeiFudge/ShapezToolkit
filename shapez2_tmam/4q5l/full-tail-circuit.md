# 四帧完整尾部电路与成功路径制造

[`build_solver`](../full_solver_circuit.py)把[完整四象限逆推](tail-solver.md)编成纯电路网表。输入原目标和enable，搜索阶段只处理材料参数；成功后执行并输出消费式制造流，逐层原生回放到原目标。当前先生成[元件与时序报告](../reports/README.md)，暂缓走线；仓库内两份完整蓝图仍为24d0a62快照，不包含最新整数PC与直接有效行后继。

范围沿用任意无晶体单层基础料、合法普通部件、rgbcmyw晶体供料及五层局部物理。cu返回3。已有完整搜索与发令控制，规模和最坏等待仍须压缩，尚未通过实用性能验收。没有执行目标、搜索、指令、反馈模拟、测试或游戏。

## 1. 状态与共用通路

最多四帧，按[帧职责证明](frame-state.md)分别保存18、38、38、24项状态。根目标直接读取固定输入，其余三帧保存20格目标ID；四帧均保存四个整数S前缀高度，只有前三帧保存来源槽、NPC顶盖、顶层C排除位及两个搜索标志。固定原目标提供标签表；[同列不变量](tagged-goal-grid.md)使每格只查本列5个原标签与4种辅助料。所有候选只保存编号，不伪造原生晶体原料。

共享材料查询、S支撑检查、两个切向的半形判据、四列Pin候选与精确物理检查、一份276行ROM和六物品槽。前265行制造叶端，其中233行角主体及保存行供含C半形调用两次；无C半形跳过角宏，直接按层制造，最多9条加工指令。两个半形共用同一程序；后11行是一次Pin与五对基础层/Stack。制造ROM用[整数PC与直接有效行后继](inactive-rom-runs.md)跳过不发包的普通行及分支行，保留可达的调用与终检边界。物理检查没有迭代状态、组编号或族缓存。

[`ClockedState`](../clocked_state.py)闭合全部145项状态。124项慢状态为四帧118项及depth、second_pass、second_corner、support_prefix、leaf_direction、leaf_mode；其余21项快状态包括CPU、整数PC、控制和包快照。慢更新后冻结一轮，指令valid在冻结轮清零。选择器及主副锁存器按原条件Ref[共用等深正反控制](shared-controls.md)，各数据分支、别名和反馈独立，逐tick延迟保持。

## 2. 搜索过程

ENTRY检查有效非空网格、列A及K，初始化前缀和遍次。K用[格位可达判据](support-reachability.md)，列A前提下以[十次行闭包](support-row-scan.md)实现，与后续G检查共用通路。慢选择器support_prefix选择完整目标或当前S前态，pin_search选择K或仅地面种子的G。新子帧写入时同时清pin_search，保证ENTRY使用K。非法内部标签返回4，必要条件失败则本帧失败。

第一遍PREFIX采用[强制前缀闭包](prefix-closure.md)：保留全部C，从最小前缀出发，补入两个半形缺少的最低支撑见证，以及Δ中无法追加的完整坏块。每次补格属于该切向下所有可行解，至多20次增长再检查一次。首切向失败重置最小前缀并换切向；无C时以完整地面层作非空种子。任一当前前态通过S支撑及双半形判据，即记录leaf_depth并RETURN。搜索时不执行制造ROM。

两个切向都无解且含C、[低层C底部条件](pin-base.md)通过、深度尚未达到原目标最高C给出的`max(0,H−1)`界时，重置前缀并置pin_search=1，先在PIN_PREFLIGHT以共用通路检查[完整目标属于G](grounded-tail.md)。若不属于G，直接排除全部Pin尾部；否则切回前缀通路，Pin轮每个P也要求属于G。每个允许P，遍历四列0～19来源槽及完整顶盖。NPC成员在来源正下方非空时按模3推进，否则按模2跳过非法顶P；C列成员固定0；随后只在允许位置推进C排除掩码，实际C从全部允许位置开始按补集次序遍历，目标最高层C对应的来源顶C及补C后违反来源列A的位置禁止，禁位直接传递进位，全部允许时最多16种；再按四列各自[单列合法槽](valid-slot-cursor.md)的直接后继推进，跳过桶尾及桶内非法槽；任一列没有合法槽时直接跳当前S前态。

SOURCE直接要求候选通过完整列A、[融合删除](crystal-boundary.md)、块位移/落点条件以及[地面可达F等式](pin-grounded.md)。全部通过即已精确证明Pin(D)=P，写D的20份ID到下一帧并下降；否则进入SOURCE_NEXT推进来源。无需先制造D，也无需多周期求物理结算。

每族先使用[可选顶格闭包](optional-top.md)：family_checked=0时，子帧把自由顶格作为可选N，暂跳过模板整体K检查，但仍要求实际前缀的K、双半形及必需Δ支撑。两个切向覆盖全族的A→S成员；成功时把未选N写为空并冻结一轮，保存精确子目标。该模式禁止Pin搜索。

可选A→S失败后，低层C底部条件不符的族直接排除；其他族先复用完整目标通路做[全族G可行性筛选](family-grounding.md)，只要求模板固定格可达地面。无G成员时经FAMILY_NEXT整族跳过；通过时回父SOURCE，保持首个空NPC地址。父帧family_checked已置1，此后按精确成员下降，ENTRY检查K及Pin允许条件后直接进入PIN_PREFLIGHT，再搜索Pin尾部，不重复A→S。全局leaf_mode的0/1/2分别表示普通根、可选检查、已否定A→S的精确成员。改变族或S前缀才清family_checked，同族NPC推进保持该位。

精确成员失败回父SOURCE_NEXT；子帧成功只需回父RETURN，因为Pin关系与S追加已在下降前证明。全部父参数保持，最终回到根。来源耗尽换下一个S前缀，第二遍前缀耗尽才本帧失败；根全部耗尽才状态2。

## 3. 整段跳过

按[游标证明](pin-cursor.md)，单列无效时跳过更快地址；[相邻晶体保留状态冲突](pin-source-conflicts.md)已等价改写为每列对固定强制C禁位的检查，并前置到合法槽域。保留的冲突保护推进该坏列，多个坏列选最高安全推进位，跳过全部顶盖。融合、落点或F等式失配时跳过同一前四层和顶层C掩码的全部NPC顶盖；顶层NPC在重力前删除，同族活图和物理比较完全相同。

每份来源前四层先检查[最大允许顶盖](maximal-cap.md)。排除位全0且物理失配时，全部C掩码均无精确Pin像，直接清顶盖游标并推进来源槽；通过后仍逐掩码寻找制造证书。制造失败、可选闭包失败及G失败都不能触发这一整组跳过。

F简化要求完整列A。若当前NPC顶盖违反列A，但同族另有满足列A的成员，同一活图上的F比较也适用于那个成员；若整个族均违反列A，则本就不可制作。因此物理失配仍可跳族。含地面C族由可选顶格闭包整体判定，其失败也跳族；其他族的当前顶盖列A失败或递归制造失败仍只排当前成员。

物理比较是慢输入驱动的组合通路，父帧挂起期间可被子帧复用；回父后由原参数重新稳定，无需保存族证书。

## 4. 根成功后才制造

叶端A→S有已证明的角构造，父边有精确Pin关系与S支撑证明；沿成功路径归纳即可取得完整制造树。

根成功时，0～leaf_depth帧保存唯一成功路径。控制器把活动深度改为leaf_depth，清空六槽、ack、PC和遍次，执行[共享半形程序](shared-angle.md)：含C半形调用两角，无C半形直接逐层制造，再处理另半形；此时才发布指令。第一角旋转暂存在槽4，另半形保存在槽5；第二角通过基础料象限置换与顺逆旋转互换，复用同一主体。完整原生结果与该帧目标相同后向根逐层执行11行Pin/S尾程序，每层仍逐格比较；根再直接比较原目标原生信号，完全相同才状态1。

制造流从空槽开始，基础料创建物品，后续操作消费源槽，没有免费实体复制。条件空行和控制跳转不发包。六槽合法性、原生回放或末端比较任何失配都返回4，不能转成不可制作。

指令保守上界为`2×(265+233)+3×11=1029`，包含不会发包的条件及控制行；它不是最短配方界，理论616节点存在性界也不等于通用ROM已最短。

## 5. 终止与覆盖

每个Pin目标保留全部C，前态至少有一颗低一层的强制C。最低C沿递归边严格下降；[四次尾部Pin改写定理](three-pin-tail.md)又使任何四边历史可改为A→S，因此只需三条边、四帧。同一证明在H层停止，给出更小的`max(0,H−1)`根深度界，H为原目标最高C的零基层号；控制直接读取原目标和depth。每族至多一次可选闭包；它失败后先置family_checked，再重试首个精确成员，不能反复回到族检查。闭包单调加格，其余失败严格推进有限游标。慢更新只插入一轮保持，因此全搜索终止。

可靠性由A叶端存在性、下降前精确Pin与S关系归纳；最终制造再用真实原生结果确认。完备性由标准形、四次Pin可改写为A→S、首轮两个切向最小闭包、全部S前缀、[二十槽覆盖](pin-patterns.md)及顶盖覆盖归纳。每族的可选闭包覆盖全部A→S成员；失败后，地面C族整体排除，其余族逐成员搜索Pin尾部。首个空顶盖保持地址后重试，没有漏过。精确物理判据不漏真实逆像，最低C下降使子目标可归纳；全部穷尽才不可制作。

## 6. 分支互斥

| 旧状态 | 互斥分支 |
|---|---|
| ENTRY | 进入叶端闭包、直接进入Pin预检、必要失败、内部网格无效、根cu、根输入无效 |
| PREFIX | 零Pin轮：叶端存在、强制补格、换切向、进入Pin轮或失败；Pin轮：S和Pin条件通过且四列桶均非空才进入来源，否则跳过前缀 |
| PREFIX_NEXT | Pin轮前缀推进、最终耗尽 |
| PIN_PREFLIGHT | 精确目标G通过后进入前缀、精确目标G失败、可选模板G检查结束转FAIL再决定重试或跳族 |
| SOURCE | 完整结构及物理通过后下降、否则进入来源推进 |
| SOURCE_NEXT / FAMILY_NEXT | 普通成员推进或整族推进、全部地址耗尽 |
| RETURN | 回父、根开始制造 |
| FAIL | 模板G可行则保持首成员重试、整族否定后跳族、精确成员失败后推进、根不可制作 |
| REPLAY_LEAF | 第一角回零、第一半形回零、第二半形结束、加工错误；回零不改Phase |
| REPLAY_PARENT | 结束、加工错误 |
| 重放比较 | 回上一层、根完成、内部失配 |
| DONE | 保持 |

SOURCE的下降和失败互为取反。CPU错误使advance为假，不能同时结束。深度的下降、成功回父、失败回父、重放回父及根跳叶端也互斥。因此并行别名选择不会稳定地产生冲突。[互斥写入证明](parallel-state-writes.md)还逐组覆盖前缀、来源、模式及状态的并行更新，保留未命中条件时已有的next值。

leaf_direction只在首轮使用；挂起父帧总在Pin遍次，子帧改方向不影响父帧；制造时从已保存前缀重新判断切向，所以共享一位足够。

## 7. 时序、规模与边界

当前统计只编译网表，不生成布局。固定局部模板版已确定5491对内部组合门，并按[实际无线级数模型](packed-timing.md)计时；最终几何仍须另行编译。逻辑门包含常量、锁存器及控制元件，不等于建筑或平台数。

|---|---|---|---|---|---|
| 全无线 | 25006 | 47 / 132 / 148 | 240 | 960 / 80 | 2032 |

[来源共用解码及平衡计数](source-counts.md)缩短前置通路。[合法槽后继](valid-slot-cursor.md)增加组合门以跳过单列非法地址，周期保持；没有目标运行数据可用于比较总体收益。最大顶盖整组否定减少一类失败分支，但允许顶盖计算串入物理通路，使未压缩版周期长于仅做分段ROM及并行进位时的76秒；没有证明所有输入总耗时改善。

[慢更新冻结协议](multicycle-control.md)要求快路径`3P > 12D_fast+36`，慢路径`7P > 12D_slow+36`。普通制造一周期，慢状态变化后另冻结一轮。完整window上升后96tick读一次，sample真先收包再处理done/status；启动不完整阶段3忽略。导入、模式和独占频道前提沿用时序合同。

零Pin轮每切向至多21次检查；Pin轮每帧最多1296个S前缀、每前缀原始来源界`20^4×4^4=40960000`，还有最多三层子搜索。精确物理检查已并入组合通路，但最坏分支数仍不适合游戏等待，尚未通过实用性能验收。

当前两个修改后的Python文件LSP零诊断，两份报告通过网表、组合DAG与固定配对编译。旧蓝图24d0a62快照曾通过端口及占地编译：未压缩24041平台；装箱8940平台、95×95外框、5320对局部门。上述旧平台数不用于估算当前网表。通用标签及独立半形部件沿用原产物。没有运行搜索、反馈模拟、测试或游戏。
