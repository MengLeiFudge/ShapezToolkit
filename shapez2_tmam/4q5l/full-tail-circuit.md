# 五帧完整尾部电路与成功路径制造

[`build_solver`](../full_solver_circuit.py)把[完整四象限逆推](tail-solver.md)编成原生纯电路蓝图：[未压缩版](../blueprints/full-tail-4q5l.spz2bp)及[装箱版](../blueprints/full-tail-packed-4q5l.spz2bp)。输入原目标和enable，搜索阶段只处理材料参数；成功后执行并输出消费式制造流，逐层原生回放到原目标。

范围沿用任意无晶体单层基础料、合法普通部件、rgbcmyw晶体供料及五层局部物理。cu返回3。已有完整搜索与发令控制，规模和最坏等待仍须压缩，尚未通过实用性能验收。没有执行目标、搜索、指令、反馈模拟、测试或游戏。

## 1. 状态与共用通路

最多五帧，每帧保存20格目标ID、12位S前缀、四个五位来源槽号、四个两位NPC顶盖、四个顶层C位、一个搜索遍次位及一个族检查位。固定原目标提供标签表；[同列不变量](tagged-goal-grid.md)使每格只查本列5个原标签与4种辅助料。所有候选只保存编号，不伪造原生晶体原料。

共享材料查询、S支撑检查、两个切向的半形判据、四列Pin候选与精确物理检查、一份265行ROM和六物品槽。前254行制造叶端，其中232行角主体及保存行每半形调用两次，两个半形再共用一次；后11行是一次Pin与五对基础层/Stack。物理检查没有迭代状态、组编号或族缓存。

[`ClockedState`](../clocked_state.py)闭合全部365项状态。336项慢状态为五帧330项及depth、second_pass、second_corner、support_prefix、leaf_direction、leaf_mode；其余快状态包括CPU、PC、控制和包快照。慢更新后冻结一轮，指令valid在冻结轮清零。

## 2. 搜索过程

ENTRY检查有效非空网格、列A及K，初始化前缀和遍次。K用[一次格位洪泛](support-reachability.md)，与后续G检查共用通路。慢选择器support_prefix选择完整目标或当前S前态，pin_search选择K或仅地面种子的G。新子帧写入时同时清pin_search，保证ENTRY使用K。非法内部标签返回4，必要条件失败则本帧失败。

第一遍PREFIX采用[强制前缀闭包](prefix-closure.md)：保留全部C，从最小前缀出发，补入两个半形缺少的最低支撑见证，以及Δ中无法追加的完整坏块。每次补格属于该切向下所有可行解，至多20次增长再检查一次。首切向失败重置最小前缀并换切向；无C时以完整地面层作非空种子。任一当前前态通过S支撑及双半形判据，即记录leaf_depth并RETURN。搜索时不执行制造ROM。

两个切向都无解且含C、最低C不在地面、深度小于四时，重置前缀并置pin_search=1，先在PIN_PREFLIGHT以共用通路检查[完整目标属于G](grounded-tail.md)。若不属于G，直接排除全部Pin尾部；否则切回前缀通路，Pin轮每个P也要求属于G。每个允许P，遍历四列0～19来源槽及完整顶盖。NPC成员按模3推进，C列成员固定0，然后推进16种C掩码及四个模20槽。

SOURCE直接要求候选通过完整列A、[融合删除](crystal-boundary.md)、块位移/落点条件以及[地面可达F等式](pin-grounded.md)。全部通过即已精确证明Pin(D)=P，写D的20份ID到下一帧并下降；否则进入SOURCE_NEXT推进来源。无需先制造D，也无需多周期求物理结算。

每族先使用[可选顶格闭包](optional-top.md)：family_checked=0时，子帧把自由顶格作为可选N，暂跳过模板整体K检查，但仍要求实际前缀的K、双半形及必需Δ支撑。两个切向覆盖全族的A→S成员；成功时把未选N写为空并冻结一轮，保存精确子目标。该模式禁止Pin搜索。

可选A→S失败后，含地面C族直接排除；其他族先复用完整目标通路做[全族G可行性筛选](family-grounding.md)，只要求模板固定格可达地面。无G成员时经FAMILY_NEXT整族跳过；通过时回父SOURCE，保持首个空NPC地址。父帧family_checked已置1，此后按精确成员下降，ENTRY检查K及Pin允许条件后直接进入PIN_PREFLIGHT，再搜索Pin尾部，不重复A→S。全局leaf_mode的0/1/2分别表示普通根、可选检查、已否定A→S的精确成员。改变族或S前缀才清family_checked，同族NPC推进保持该位。

精确成员失败回父SOURCE_NEXT；子帧成功只需回父RETURN，因为Pin关系与S追加已在下降前证明。全部父参数保持，最终回到根。来源耗尽换下一个S前缀，第二遍前缀耗尽才本帧失败；根全部耗尽才状态2。

## 3. 整段跳过

按[游标证明](pin-cursor.md)，单列无效时跳过更快地址；融合、落点或F等式失配时跳过同一前四层和顶层C掩码的全部NPC顶盖。顶层NPC在重力前删除，同族活图和物理比较完全相同。

F简化要求完整列A。若当前NPC顶盖违反列A，但同族另有满足列A的成员，同一活图上的F比较也适用于那个成员；若整个族均违反列A，则本就不可制作。因此物理失配仍可跳族。含地面C族由可选顶格闭包整体判定，其失败也跳族；其他族的当前顶盖列A失败或递归制造失败仍只排当前成员。

物理比较是慢输入驱动的组合通路，父帧挂起期间可被子帧复用；回父后由原参数重新稳定，无需保存族证书。

## 4. 根成功后才制造

叶端A→S有已证明的角构造，父边有精确Pin关系与S支撑证明；沿成功路径归纳即可取得完整制造树。

根成功时，0～leaf_depth帧保存唯一成功路径。控制器把活动深度改为leaf_depth，清空六槽、ack、PC和遍次，执行[两角共用程序](shared-angle.md)，每半形依次调用两角，再处理另半形；此时才发布指令。第一角旋转暂存在槽4，另半形保存在槽5；第二角通过基础料象限置换与顺逆旋转互换，复用同一主体。完整原生结果与该帧目标相同后向根逐层执行11行Pin/S尾程序，每层仍逐格比较；根再直接比较原目标原生信号，完全相同才状态1。

制造流从空槽开始，基础料创建物品，后续操作消费源槽，没有免费实体复制。条件空行和控制跳转不发包。六槽合法性、原生回放或末端比较任何失配都返回4，不能转成不可制作。

指令保守上界为`2×(254+232)+4×11=1016`，包含不会发包的条件及控制行；它不是最短配方界，理论627节点存在性界也不等于通用ROM已最短。

## 5. 终止与覆盖

每个Pin目标保留全部C，前态至少有一颗低一层的强制C。最低C严格下降，至多四条递归边、五帧。每族至多一次可选闭包；它失败后先置family_checked，再重试首个精确成员，不能反复回到族检查。闭包单调加格，其余失败严格推进有限游标。慢更新只插入一轮保持，因此全搜索终止。

可靠性由A叶端存在性、下降前精确Pin与S关系归纳；最终制造再用真实原生结果确认。完备性由标准形、首轮两个切向最小闭包、全部S前缀、[二十槽覆盖](pin-patterns.md)及顶盖覆盖归纳。每族的可选闭包覆盖全部A→S成员；失败后，地面C族整体排除，其余族逐成员搜索Pin尾部。首个空顶盖保持地址后重试，没有漏过。精确物理判据不漏真实逆像，最低C下降使子目标可归纳；全部穷尽才不可制作。

## 6. 分支互斥

| 旧状态 | 互斥分支 |
|---|---|
| ENTRY | 进入叶端闭包、直接进入Pin预检、必要失败、内部网格无效、根cu、根输入无效 |
| PREFIX | 零Pin轮：叶端存在、强制补格、换切向、进入Pin轮或失败；Pin轮：进入来源或跳过前缀 |
| PREFIX_NEXT | Pin轮前缀推进、最终耗尽 |
| PIN_PREFLIGHT | 精确目标G通过后进入前缀、精确目标G失败、可选模板G检查结束转FAIL再决定重试或跳族 |
| SOURCE | 完整结构及物理通过后下降、否则进入来源推进 |
| SOURCE_NEXT / FAMILY_NEXT | 普通成员推进或整族推进、全部地址耗尽 |
| RETURN | 回父、根开始制造 |
| FAIL | 模板G可行则保持首成员重试、整族否定后跳族、精确成员失败后推进、根不可制作 |
| REPLAY_LEAF | 第一角回零、第一半形回零、第二半形结束、加工错误；回零不改Phase |
| REPLAY_PARENT | 结束、加工错误 |
| 重放比较 | 回上一层、根完成、内部失配 |
| DONE | 保持 |

SOURCE的下降和失败互为取反。CPU错误使advance为假，不能同时结束。深度的下降、成功回父、失败回父、重放回父及根跳叶端也互斥。因此并行别名选择不会稳定地产生冲突。

leaf_direction只在首轮使用；挂起父帧总在Pin遍次，子帧改方向不影响父帧；制造时从已保存前缀重新判断切向，所以共享一位足够。

## 7. 时序、规模与边界

未压缩版33914平台，频道1211000～1276535；[装箱版](packed-circuit.md)11370平台、107×107外框，频道1277000～1342535。两版快路径58级、慢路径134级、初始151级，阶段252tick、周期1008tick即84模拟秒，复位至少2068tick。

[慢更新冻结协议](multicycle-control.md)要求快路径`3P > 12D_fast+36`，慢路径`7P > 12D_slow+36`。普通制造一周期，慢状态变化后另冻结一轮。完整window上升后96tick读一次，sample真先收包再处理done/status；启动不完整阶段3忽略。导入、模式和独占频道前提沿用时序合同。

零Pin轮每切向至多21次检查；Pin轮每帧最多1296个S前缀、每前缀原始来源界`20^4×4^4=40960000`，还有最多四层子搜索。精确物理检查已并入组合通路，但最坏分支数仍不适合游戏等待，尚未通过实用性能验收。
