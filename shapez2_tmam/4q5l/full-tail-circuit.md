# 五帧完整尾部电路与成功路径制造

[`build_solver`](../full_solver_circuit.py)把[完整四象限逆推](tail-solver.md)编成原生纯电路蓝图：[未压缩版](../blueprints/full-tail-4q5l.spz2bp)及[装箱版](../blueprints/full-tail-packed-4q5l.spz2bp)。输入原目标和enable，搜索阶段只处理材料参数；成功后执行并输出消费式制造流，逐层原生回放到原目标。

范围沿用任意无晶体单层基础料、合法普通部件、rgbcmyw晶体供料及五层局部物理。cu返回3。已有完整搜索与发令控制，规模和最坏等待仍须压缩，尚未通过实用性能验收。没有执行目标、搜索、指令、反馈模拟、测试或游戏。

## 1. 状态与共用通路

最多五帧，每帧保存20格目标ID、12位S前缀、四个五位来源槽号、四个两位NPC顶盖、四个顶层C位、一个搜索遍次位及一个族物理证书位。固定原目标提供24项标签表；所有候选只保存编号，不伪造原生晶体原料。

共享材料查询、S支撑检查、两个切向的半形判据、四列Pin候选及必要筛选、20格组编号与20格静止位、五位轮数、一份486行ROM和六物品槽。ROM前475行两遍共用，制造起点再加S；后11行是一次Pin与五对基础层/Stack。

[`ClockedState`](../clocked_state.py)闭合全部407项状态。333项慢状态为五帧330项及depth、second_pass、support_prefix；其余快状态包括组计算、CPU、PC、控制和包快照。慢更新后冻结一轮，指令valid在冻结轮清零。

## 2. 搜索过程

ENTRY检查有效非空网格、列A及K，初始化前缀和遍次。K用[一次格位洪泛](support-reachability.md)，与PREFIX共用通路；慢选择器support_prefix保证ENTRY读完整目标，PREFIX读当前S前态P。非法内部标签返回4，必要条件失败则本帧失败。

第一遍PREFIX遍历所有允许S前缀，要求新增NPC块有支撑、P属于K且可分成两个稳定半形。列A由保留全部C的原目标前缀继承。命中即由半形构造定理取得存在性证书，记录leaf_depth并RETURN，搜索时不执行制造ROM。

第一遍耗尽且含C、最低C不在地面、深度小于四时，重置前缀进入Pin遍次。每个允许P，遍历四列0～19来源槽及完整顶盖。NPC成员按模3推进，C列成员固定0，然后推进16种C掩码及四个模20槽。坏列和物理矛盾按[游标证明](pin-cursor.md)跳过整段，不跳过没有否定依据的制造成员。

SOURCE先检查单列、完整列A及融合/位移必要条件。通过后确认[精确Pin关系](pin-image-exact.md)：最多19轮原始组编号传播，再最多20轮静止组剥离；整轮不变可提前结束。SOURCE_CHECK要求所得最大F逐格等于推定F。必要条件加这一等式已足以证明Pin(D)=P。

物理匹配才把D的20份ID写入下一帧并下降。子帧失败回父SOURCE_NEXT；子帧成功只需回父RETURN，因为Pin关系与S追加已在下降前证明。全部父参数保持，最终回到根。来源耗尽换下一个S前缀，第二遍前缀耗尽才本帧失败；根全部耗尽才状态2。

## 3. 两项物理复用

同一前四层和顶层C掩码的全部NPC顶盖有相同Pin输出；顶层NPC在重力前删除。每帧pin_verified保存这一族的物理证书，子帧可共用组计算状态，不会覆盖父证书。

只有NPC成员变化时保留该位；C掩码或任一低层槽变化时清除，新S前缀开始来源扫描也清除。物理拒绝跳过整个NPC族；子制造失败只排除当前成员。证书只代表Pin匹配，不代表该成员可制作。

若所有融合后活格都被指定静止，来源逐列映射使活图恰为P。P已由PREFIX证明属于K，故本身稳定，真实F就是全部活格。这一情形直接确认Pin关系，不执行编号与剥离。此捷径依赖当前P属于K，不能搬到任意目标的独立物理部件。

## 4. 根成功后才制造

叶端A→S有已证明的角构造，父边有精确Pin关系与S支撑证明；沿成功路径归纳即可取得完整制造树，不需要在每条搜索分支上执行数百行制造程序。

根成功时，0～leaf_depth帧保存唯一成功路径。控制器把活动深度改为leaf_depth，清空六槽、ack、PC和遍次，执行同一475行叶端ROM两遍；此时才发布指令。完整原生结果与该帧目标相同后向根逐层执行11行Pin/S尾程序，每层仍逐格比较；根再直接比较原目标原生信号，完全相同才状态1。

制造流从空槽开始，基础料创建物品，后续操作消费源槽，没有免费实体复制。条件空行和控制跳转不发包。六槽合法性、原生回放或末端比较任何失配都返回4，不能转成不可制作。

指令保守上界仍为 `2×475+4×11=994`，包含不会发包的条件及控制行；它不是最短配方界，理论627节点存在性界也不等于通用ROM已最短。

## 5. 终止与覆盖

每个Pin目标保留全部C，前态至少有一颗低一层的强制C。最低C严格下降，至多四条递归边、五帧。组编号及剥离有固定轮数界；各局部游标有限，失败后严格推进。缓存不引入回边，慢更新只插入一轮保持，因此全搜索终止。

可靠性由A叶端存在性、下降前精确Pin与S关系归纳；最终制造再用真实原生结果确认。完备性由 `A→S→(Pin→S)^k` 标准形、全部S前缀、[二十槽覆盖](pin-patterns.md)及完整顶盖归纳。精确物理判据不漏真实逆像，最低C下降使子目标可归纳；全部穷尽才不可制作。

## 6. 分支互斥

| 旧状态 | 互斥分支 |
|---|---|
| ENTRY | 进入、必要失败、内部网格无效、根cu、根输入无效 |
| PREFIX | 叶端存在、进入Pin来源、跳过前缀 |
| PREFIX_NEXT | 推进、第一遍重启Pin、最终耗尽 |
| SOURCE | 已有/无移动物理证书下降、开始组计算、候选无效 |
| LABELS / STATIONARY | 本段完成或继续；二者旧状态互斥 |
| SOURCE_CHECK | 精确匹配下降、失配推进整族 |
| SOURCE_NEXT | 地址推进、全部地址耗尽 |
| RETURN | 回父、根开始制造 |
| FAIL | 回父续搜、根不可制作 |
| REPLAY_LEAF | 首遍回零、第二遍结束、加工错误；回零不改Phase |
| REPLAY_PARENT | 结束、加工错误 |
| 重放比较 | 回上一层、根完成、内部失配 |
| DONE | 保持 |

SOURCE中开始组计算要求候选有效且无证书；下降要求有效且有证书，候选无效为第三分支。SOURCE_CHECK匹配/不匹配互斥。CPU错误使advance为假，不能同时结束。深度的下降、成功回父、失败回父、重放回父及根跳叶端也互斥。因此并行别名选择不会稳定地产生冲突。

## 7. 时序、规模与边界

未压缩版41874平台，频道1211000～1276535；[装箱版](packed-circuit.md)18636平台、137×137外框，频道1277000～1342535。两版快路径49级、慢路径167级、初始184级，阶段300tick、周期1200tick即100模拟秒，复位至少2464tick。

[慢更新冻结协议](multicycle-control.md)要求快路径 `3P > 12D_fast+36`，慢路径 `7P > 12D_slow+36`。普通制造或组迭代一周期，慢状态变化后另冻结一轮。完整window上升后96tick读一次，sample真先收包再处理done/status；启动不完整阶段3忽略。导入、模式和独占频道前提沿用时序合同。

一个未缓存、需要运动的候选族至多39轮内部组计算，另有开始、比较及跨帧等控制周期；不能把这一界写成总求解耗时。每帧最多1296个S前缀、每前缀原始来源界 `20^4×4^4=40960000`，还有最多四层子搜索。去掉搜索中的制造大幅减少重复工作，但最坏分支数仍不适合游戏等待，尚未通过实用性能验收。

七个Python文件LSP零诊断，两版生产编译通过DAG、端口、别名及实际占地检查；独立5037平台必要筛选和7486平台来源部件重编译产物保持一致。未运行目标、搜索、制造、模拟、测试或游戏。
