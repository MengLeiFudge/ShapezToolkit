# 四象限五层图形的覆盖性研究

本文限定四象限、最多五层。其他范围见[六象限五层](../6q5l/README.md)和[x 象限 y 层](../general/README.md)，各自的结论不能默认互相外推。基础输入是任意不含结晶的单层图形，包括普通形状、合法配色和顶针组合；空的底层或中间层保留位置。讨论旋转、切割、交换、堆叠、顶针、结晶和染色等实体加工，不把仅用于信号分析的操作自动计入可制造过程。

证据方式为文献核对、当前安装程序集的只读反编译和逐步手推。没有运行枚举、求解器、游戏或蓝图仿真。已对本机 `1.2.0-rc3` 的堆叠、下落、截高、顶针及结晶关键代码进行静态核对；具体范围和程序集指纹见第 8 节。覆盖性定理仍按各节列出的前提判断。

## 主要结论及强度

| 结论 | 强度与限制 |
|---|---|
| 可制作性可以与普通形状种类、颜色分离 | 在第 2 节规则下给出构造证明，包括结晶配色；不保证相同工序数或最短路径 |
| 不含结晶的图形，可制作当且仅当稳定 | 在第 3 节规则下证明；可直接按层检查支撑 |
| 一个最终保留的晶体，从产生后到成品，沿自身经历的路径最多经过四次顶针 | 在第 4 节规则下证明；不限制产生它之前及其他支路上的操作 |
| 全部可制作图形都属于 K 支撑类，但 K 不是充分条件 | 已有操作闭包证明；C-P-C 单列属于 K，却违反列内针前缀不变量，不可制作 |
| 晶体下方的顶针只能属于触地连续针前缀 Q | 已给出列内制造树归纳证明，适用于半形与全图中的每一列 |
| 晶体隔空看到的最近下方格必须是普通形状 J | 已给出保持列内次序的证明；K 与 Q 合起来仍不充分 |
| 独立单列的可制作性已有精确判据及构造 | 五层以内、擦除普通种类与颜色后，263 种非空结构，加空列共 264 种；不能直接当成半形的逐列判据 |
| 任意可制作下料的复杂堆叠可化为基础块序列 | K 内构造证明结合上述闭包；不能扩大成任意语法合法、仅仅稳定的下料 |
| K 中一段连续堆叠的前态至多有 1296 个按列截断候选 | 有充要判据；固定朝向、五层四列，不代表整个求解器只有这些状态 |
| “可分起点 + 最多四次顶针 + 最多五段堆叠”足够覆盖含晶体结果 | 第 5 节的阶段形式已由[半形有限文法](half-closure.md)闭合；给出精确有限判定和制造证书，尚无低成本实现 |
| 全部两列半形已有完整构造判据 | 在至多 4^10 个半形编码上取显式算子的最小不动点，证明可靠、完备及终止；不是 K/Q/J 的局部充分性证明 |
| 有顶破时的顶针逆像已有完整规则 | [静态支撑图、落点公式与来源恢复](pin-inverse.md)覆盖顶破、融合删除及下落碎晶；由全图判据筛选可制作输入 |
| 上料晶体不能保留在堆叠结果中 | 上料统一提高最大层数加一层；按晶体下落即碎的部件规则，下落则碎、不下落则超高删除；不等价于先删除晶体再计算其他部件 |
| A／AC／B／BC 或某台 TMAM 已覆盖当前游戏全部图形 | 尚未证明 |

## 1. 覆盖性究竟需要证明什么

记基础输入集合为 B，合法操作为 O，可制作集合 R 是包含 B 且对 O 封闭的最小集合。若方案覆盖集合为 C，证明 B 包含于 C，且每种合法操作作用于 C 内任意合法输入后仍落在 C，就得到 R 包含于 C。

这是对制造树的归纳：基础输入是叶子，机器操作是内部节点，输出是根。双输入机器需要同时考虑两个输入，不能仅检查一个输入和固定辅助材料。实际工厂重复生产同一部件，可以在有限制造树中复制相应子树。

仅证明封闭性可能把不可制作图形也收入 C。若还要把 C 当作精确可制作性判定，需要反向证明 C 包含于 R，例如给出每类的构造方法。若要证明某个具体程序覆盖 C，还需要证明其判断、分支选择和终止性；分类定理不会自动证明代码正确。

## 2. 颜色与普通形状种类可以抽离

### 2.1 使用的规则

1. 普通形状的具体种类和颜色不影响支撑、连接、碰撞、旋转、跌落、切割及截高行为。
2. 晶体粘连和连锁碎裂不区分颜色。
3. 结晶机把当前高度以内的空位和顶针变成指定合法颜色的晶体，保留已有普通形状和晶体。
4. 基础单层输入可以包含所需普通形状及其合法颜色。晶体颜色仅限游戏允许通过结晶生成的颜色，不能把语法可解析的颜色自动当成可生产颜色。
5. 除结晶外，各操作对既有单元只做移动、保留、删除或普通染色；没有基于颜色的物理分支。

当前程序集的 `ShapeLogic.Logic_IsConnected`、`Logic_IsFused` 只比较形状代码和位置，不比较颜色；普通非顶针形状的水平连接也不区分其种类。`ShapeOperationCrystallize.ExecuteInternal` 只改写空位和顶针，并设置输入颜色，保留已有单元。群内 `shapez.cpp` 的颜色消除说明可作参考，具体规则以游戏实现为准。

### 2.2 任意配色的紧图形可以制造

称高度 h 内四个象限全部由普通形状或晶体占满的图形为“紧图形”，即没有空位和顶针。任意 h 不超过五的紧图形，都可以指定每个普通单元的种类、颜色，以及每个晶体的合法颜色。

构造单个目标列的方法如下：

1. 由下到上处理每一层。其他三个象限始终填普通辅助形状，形成完整辅助列。
2. 目标格要普通形状时，堆叠相应基础层；目标格要晶体时，先在该格放顶针，其他三格放普通形状，再执行所需颜色的结晶。
3. 已完成的所有格均为普通形状或晶体，所以这次结晶只改变新加入的目标顶针，不改变之前各层的配色。
4. 完成 h 层后，通过旋转和切割分离目标列。切线另一侧只有普通辅助形状，没有与目标列连接的辅助晶体，因而不会沿切线引发目标晶体碎裂。
5. 目标列每一层都非空，自底向上稳定。先把两个相邻目标列组合成半形，再把两个半形组合起来。各次切线经过待保留产物外侧的空区域，不需要切断已组合部分内部的晶体连接。

这证明了整个紧图形的任意合法配色可制造，而不只是单个晶体格可染色。

### 2.3 制造树替换证明

给定任意可制作结构的一棵制造树，给最终普通单元和晶体单元指定任意合法标签：普通单元的种类与颜色、晶体的颜色。

从根往叶子追溯这些标签。对非结晶操作，每个保留的输出单元来自某个输入单元，给该输入单元分配相应标签即可；最终会被删除的单元任意赋值。原来的普通染色步骤可以省略，把要求的颜色提前赋给对应原料。

遇到结晶节点时，它的输出是紧图形。用 2.2 的构造直接制造这个节点所需的全部标签，替换该节点及其之前的子树。继续保留后面的结构操作。由于物理规则不依赖这些标签，各次切割、碎裂、跌落等结果的结构不变。

同一原料供给两个支路时，可以分别生产两份、赋予不同标签，不要求一个物理单元同时具有两种颜色。由制造树归纳得到：

> 在上述规则和合法材料范围内，一个结构只要可制作，其任意普通形状种类与配色组合也可制作。

反方向只需擦除标签。因此“擦除颜色和普通形状种类”对可制作性是精确的化简，而不仅是必要条件。它不证明原 TMAM 能接受所有颜色，也不保证原制造路径直接换颜色就仍然有效；制造路径可能需要替换。

另一个直接结论是：可把每棵制造树中靠近输出的结晶节点替换成预制紧图形。紧图形仍需用上面的合法方法制造，不能把它们未经解释地新增为天然原料。

## 3. 无晶体图形的精确判定

普通形状只在同一层与相邻普通形状粘连；顶针不粘连。没有晶体时，每个最大粘连组都在一个水平层中：它或者是一个普通形状连通块，或者是单个顶针。

对每个非底层单元组，检查其占据的象限中是否至少有一个在下一层非空。顶针是单格组，所以要求正下方非空。底层单元组直接受地面支撑。

这个条件对稳定性既必要又充分：组之间的支撑边严格从高层指向低层，不可能成环。每个非底层组只要有下一层支撑，最终就有一条支撑链通向地面；反之，缺少直接阻挡的组会下落。

对满足条件的图形，从底到顶依次堆叠每个普通连通块和每个顶针。制造到第 h 层时，下方各层已经到位，该组恰好落到目标高度。同一层不同组占据不同格位，不妨碍此构造。

因此，在机器输出会完成重力结算的规则下：

> 无晶体图形可制作，当且仅当它满足上述稳定性条件。

这部分不需要全图形数据库，也不需要复杂的角分类。后续覆盖性困难可以集中在含晶体的图形上。

## 4. 最终保留晶体的高度不变量

使用两条规则：晶体随所在组下落就会碎裂；顶针使保留单元上移一层并在高度上限处处理删除。当前 `ShapeOperationPushPin` 先分离原顶层，把其余单元 `LayerIndex++`，在原底层非空处补针，再把原融合关系交给 `Collapse` 处理。`ShapeLogic.Fold` 按原层号补空层，不会自动删除底部空层并重新编号。

选择成品中的一个晶体，沿制造树回溯到产生它的结晶操作。这个晶体此后不能经历任何向下移动，否则它不会保留到成品。旋转不改变层高；切割和交换也不能把一个保留晶体移到更低层。

每次顶针都会把存活晶体的层号加一。根据第 6 节核对的堆叠规则，成品中的晶体不能来自某次堆叠的上料，因此追溯晶体时，堆叠节点只需沿下料继续追溯。

故对这条单元路径，有：

`最终层号 >= 产生时层号 + 产生后经历的顶针次数`

最终层号不超过五，产生时层号至少为一，所以顶针次数最多四次。更精确地，最终处于第 h 层的晶体，产生后最多经历 h−1 次顶针。

这个结论不依赖颜色，也不要求支撑图无环。它限制的是某个最终晶体从产生之后经历的那条路径，不能据此声称整座工厂最多使用四次顶针。其他支路、结晶之前的准备、只用于临时支撑而最终碎掉的晶体，都可能有更多操作。

若某段尾部流程只包含顶针和不含晶体的基础料堆叠，则所有最终晶体都已经存在于该段的起点。记成品最低晶体层号为 m，整段顶针次数满足：

`顶针次数 <= m − 1 <= 4`

特别地，成品有第一层晶体时，这种尾部流程不能包含任何顶针。

## 5. 不必先证明所有堆叠都能移到最后

### 5.1 相对完整起点集合的存在性定理

令 H 是“确实能够制造并独立保留下来的半形”集合，包括旋转后的方向。由 H 中两个半形在合适方向交换得到的形状，连同单独半形、基础输入和紧图形，组成起点集合 A。

这里的 A 是为论证定义的集合，不直接等同于任何文档中仅凭半边稳定性判定的 A 类。两个半边稳定，不足以证明两个半边都可制造。[半形有限文法](half-closure.md)给出了完整 H 的有效构造定义，使本节的相对定理可转化为闭合判据。

定义 K：每个最大粘连组都能沿直接支撑边到达地面，或到达一个包含顶针的支撑环。[支撑闭包证明](support-closure.md)已经补齐切割与顶针：四象限五层中，基础输入属于 K，全部纳入范围的实体操作保持 K，故每个可制作图形都属于 K。结合 K 内的堆叠构造得到：

> 任意上料的一次真实堆叠，都能从同一个下料出发，改用若干次不含晶体的基础块堆叠得到相同结果，且输出仍属于 K。

证明、连续堆叠的充要判据和适用边界见[堆叠约化](stacking-proof.md)。核心是原下料保持不动，最终保留的上料块从低到高追加；含针支撑环不会因新增普通块造成的组粘连而消失。该约化不要求保留上料中的所有非晶体格。

不能把“可制作下料”直接弱化为“稳定下料”。源码在一次下落中不合并新接触的组，下一次加工却会重新分组。[堆叠约化第 7 节](stacking-proof.md#7-任意稳定输入上的反例该下料不可制作)给出稳定但不属于 K 的反例；由本轮闭包定理，该下料不能从允许的基础输入制造出来。

任意制造树上的下料均可制作，因而属于 K。沿堆叠的下料支路向前回溯：

- 遇到结晶，输出是紧图形，属于 A。
- 遇到切割，保留产物是可制造的独立半形，属于 A。
- 遇到交换，输出由两个已按切割流程结算的可制造半形拼成，属于 A。
- 若一直回溯到基础输入，也属于 A。
- 中间各次堆叠可约化为基础块堆叠；旋转暂保留，标签问题由第 2 节处理。

因此，每个可制作结果都有“从 A 出发，经过旋转、顶针和基础块堆叠”的制造尾部。本节给出相对完整 H 的存在性结论；完整 H 的有限判据及制造证书见[后续闭包证明](half-closure.md)。[通用列内不变量](../general/column-invariants.md)仍可用于排除候选，不能替代该判据。

### 5.2 有限阶段形式

若结果含晶体，第 4 节把尾部中的顶针次数限制为四次以内。记 S* 为零次或多次基础块堆叠，P 为一次顶针，R 为零、四分之一、二分之一或四分之三圈旋转，可写为：

```text
A → S* → R → (P → S* → R)^k，0 <= k <= 4
```

这里只把同一纯基础堆叠段中的旋转归并到该段末尾，同时调整基础上料的朝向。这由基础块落点公式的旋转对称性得到；不要求旋转与顶针或任意重力结算交换。也没有把堆叠跨过顶针重排。

各段起点均可制作，故属于 K。段内既有格位不移动、不删除；每次有效堆叠至少增加一格，故每段至多二十次、五段共至多一百次有效堆叠，另有最多四次顶针及各段末的旋转。这个宽松的证书长度界从已取得 A 中起点开始，不包含制造起点的成本。

还可直接反推每段：前态只能保留目标每列某个高度及以下的全部格位。四列五层至多 6^4 = 1296 个候选，再检查 K 和新增格的充要判据。这是单段固定朝向的候选数量界，不是完整算法的运行时间保证。

支撑范围和堆叠约化已不再是未知前提。[半形有限文法](half-closure.md)进一步闭合 H，并给出全图 Reach 判据；[完整顶针逆像](pin-inverse.md)处理第五层、融合删除及下落。当前已得到有限构造理论，尚未将其压缩为高效求解器或具体机器流程。

### 5.3 顶针与堆叠不能直接交换顺序

取基础输入 `X = Cu------`、`b = --Cu----`，短代码按从底到顶书写。

- 先堆叠 b，再顶针，得到 `P-P-----:CuCu----`。
- 先对 X 顶针，再堆叠 b，得到 `P-Cu----:Cu------`。

前一种顺序先让两块并排落在地面，顶针会在两块下方加针。后一种顺序只在 X 下方加针，随后 b 仍能落到地面。两者不同，完全不需要晶体或截高就能看出差异。

因此，操作约化若要改变这两个操作的顺序，必须允许并证明相应的材料或辅助结构变换；不能直接使用交换律。这个例子不否定可能存在的其他等价制造路径。

## 6. 游戏源码确定的堆叠规则

### 6.1 上料的初始高度与结算顺序

`ShapeOperationStack.ExecuteInternal` 展开上下两份图形，复制上料引用并执行：

```csharp
shapePartReference.LayerIndex += MaxShapeLayers + 1;
```

它没有使用下料实际高度。五层模式下，上料原第一层从零基下标 0 移到 6，即人类层号第七层。其余上料也全部位于五层上限之外。该方法没有预先删除上料中的晶体，而是把合并引用交给 `ShapeLogic.Collapse`。

`Collapse` 的相关调用顺序为：

1. `BuildGroups` 按粘连规则分组。
2. 如调用者传入融合关系，先执行 `ComputeFusingResults`；堆叠调用未传入这项参数。
3. `SimulateFallDownPhysics` 逐组尝试下落，直到没有组能再下落。
4. `RemoveExcessLayers` 把零基层号大于等于最大层数的部分标为消失。
5. 合并结果组并输出。截高之后没有第二次下落或融合碎裂调用；本次下落中的新接触也不会合并物理组，下一次加工才会重新按格位分组。

`SimulateFallDownPhysics` 检查地面及其他非消失组的直接阻挡，不要求支撑链通向地面，所以互相阻挡的组可以保持不动。只有确定某组能下落时，才检查每个部件的 `DestroyOnFallDown` 属性并拆分消失部分。这个属性来自部件元数据，不是在堆叠器里写死为形状代码 `c`。本轮读取了该属性的代码入口，没有另外导出游戏部件资源表；“晶体下落即碎”沿用本研究的晶体部件规则。

因此，上料中的晶体若发生下落就会碎；若一直不下落，则仍位于高度上限之外，被截掉。它不能保留在堆叠输出中。

### 6.2 循环上料的源码推导结果

取上料 `U = crCu----:crP-----:crCu----`，下料 `D = ----Cu--`。U 的三个晶体和上下普通块属于一个粘连组 G，中央顶针为另一个组 p。G 的上方普通块与 p、p 与 G 的下方普通块互相阻挡。

真实堆叠把 U 提高六层，放到第七、八、九层。G 与 p 都不下落，随后全部被 `RemoveExcessLayers` 删除。按已核对的源码，输出只有：

```text
----Cu--
```

这排除了该输入能够通过堆叠保留上料晶体的说法。结果来自逐分支静态推导，没有启动游戏执行。

该例同时说明，真实实现不能简单替换成“预删上料晶体，再让所有其他格下落”。若先删掉 U 的晶体，剩余的普通块、顶针、普通块就不再成环，会落到下料旁边，手推输出变为：

```text
--CuCu--:--P-----:--Cu----
```

两个结果不同。需要证明的仍是“存在某个基础块堆叠序列”，不能强制把预删晶体后所有剩余格都堆进去。对这里的实际结果，零次基础块堆叠已经足够。

### 6.3 支撑图需要包含通向环的节点

源码通过组间直接阻挡决定能否下落，能够保留互相阻挡的环，以及被这些环阻挡的其他组。若改用图论判定，应包含能沿支撑边到达地面的块和能到达支撑环的块，而不仅是环内节点。

《MaManalysis》定义 6 的文字是“存在到地面的路径，或这个块在一个环里”。按字面缺少“能到达一个环”的情形。后续建模需要使用与源码逐组阻挡一致的定义，并在部件消失和分组变化后继续结算。

## 7. 还缺哪些证明

在已核对的四象限五层规则下，半形与顶针的两个缺口已有有限构造解：

1. **完整半形集合**：[半形有限文法](half-closure.md)以无晶体稳定半形为种子，结合紧图形、已知半形拼接、有界尾部和末次半切，给出必要且充分的不动点判据及制造证书。至多 4^10 次算子应用即可停稳；未计算实际成员数量。
2. **完整顶针逆向**：[顶针逆像](pin-inverse.md)恢复全部来源格位及顶破层，以静止组集合和落点公式覆盖融合删除与下落碎晶，再通过完整 Reach 判据筛选前态。不存在未知可制作性判定器。

仍未证明的是：K、Q、J 等局部约束能否压缩成同样充分的短规则；如何低成本实现上述判定；某台固定 TMAM 如何覆盖全部制造证书。理论完备性不等同于实际运行效率，也不证明 Mari 或 A／AC／B／BC 方案完备。

颜色消除后，单角五层有 4^5=1024 个原始编码，独立可制作单列恰有 264 种（含空列）。半形有 4^10=1048576 个原始编码，这只是递推状态空间及终止界，不是可制作半形数量。
