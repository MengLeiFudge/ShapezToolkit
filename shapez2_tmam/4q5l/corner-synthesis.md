# 四象限五层：逐列角构造与半形的局部充要条件

本页在既有[列内不变量](../general/column-invariants.md)、[晶体间隙不变量](mari-corners.md)及[四象限支撑闭包](support-closure.md)上，给出无需半形目录枚举的构造。范围为四象限、五层、合法普通部件及可供料的晶体颜色；底部及中间空层保留。证明采用人工逐步推导，没有运行目标枚举、物理模拟或游戏验证。

实现为 [`CornerBuilder`](../synthesis/corners.py) 和 [`Constructor.half`](../synthesis/construct.py)。本页解决的是相邻两列半形；不能据此把全图简单地切成两份就宣称覆盖所有四象限目标。

## 1. 列条件与半形判据

一列按底到顶记为N/P/C/空，补空到五格；层号从0开始。定义列条件A：

1. 每个不在地面的 P 正下方有格。
2. 最高 C 以下的 P 只构成触地连续针前缀，即 Q。
3. C 正下方若为空，向下遇到的第一个非空格是 N，即 J。
4. 同列相邻两颗 C 之间若有空格，中间至少两个 N，且下方 C 紧邻的上一格非空。

**半形定理。** 非空标准半形 T（只占 q0、q1）可制作，当且仅当它重新按自身格位分组后稳定，并且两列分别满足 A。

必要性来自制造树不变量和四象限 R⊆K：每个可制作半形稳定；P 独立成组，必须直接受支撑；Q、J 和晶体间隙不变量适用于所有可制作输出。

充分性的构造分两步：先证明每个满足 A 的非空列，都能与相邻的一根连续 N/P 辅助柱组成可制作的角；再把两角拼接，移走外侧助手。下面逐项给出角构造。

## 2. 简单列：填辅助晶体、半切删除

无 C 列配一根五层全 N 助手，按层制造即可。N 在每层都能与助手粘连，P 由条件 1 的原列下方格支撑。

含 C 列先处理最高 C 及以下；其上 N/P 后缀留到逐层追加。若有一颗 C_r 正下方为空，令最近的下方普通格为 N_m。先考虑m=0或第m−1层非空的情形：

- 把 N_m 的来源提高到第 r−1 层。
- 原 N_m 位置及其他前缀空格填辅助 C。
- 连续五层助手全用 N，唯第 r−1 层用 P。

助手在第 r−1 层的 P 不与源 N 粘连；其上 N_r 保持目标 C。删除辅助 C 后，源 N 独自下降，恰由原列第 m−1 层或地面挡住，落回 m。其余目标 N 由同层助手 N 保持；P 的直接支撑保持。

若没有 C 正下方的空隙，不移动 N，前缀空格直接填辅助 C，助手全部用 N。

### 辅助晶体不会连带目标晶体

没有紧邻 C 下方的空隙时，底部空段上端必为 N；两个目标 C 之间的空段，条件 4 保证下方端点上方是 N，而上端不是 C，故也由 N 隔开。

有 C_r 下方空隙时，移到 r−1 的 N 隔开上方保留 C；其下填充 C 与更低的保留 C 之间也有 N。五层内这种空隙至多一处：若有两颗带空隙的 C，较低者至少在第三层，而二者之间再容纳两个 N 和空格将超过五层。

因此，每个填充 C 分量都不含目标 C。给每个填充位置，在主列另一侧的外部远列放 C；远列其他格填 N，补到五层。远列是可独立制造的紧 N/C 柱。

先造主列的独立晶体前缀，再逐层加入 N/P 助手与主列后缀，得到保留侧角。前缀的 P 仍是触地前缀，其他位置连续 N/C。助手的 P 只在前缀内部；最高 C 以上助手全部是 N，因此后缀的悬空普通格可以与同层新助手 N 一起堆叠，针按条件 1 受支撑。这个追加构造见 `Builder.crystal_prefixes`。

加入远列后半切，只保留主列及 N/P 助手。全部填充 C 因跨界融合删除，目标 C 不删；上述落点给出原目标列。

## 3. 用落点参数统一顶破构造

如果C_r下方最近的N_m不触地，且m−1层为空，直接删除填充C不能把它停在m。r是间隙上端C的层号，m是该N的目标落点。五层及A共同限制`r∈{3,4}`、`1≤m≤r−2`。低于这颗C不可能还有目标C，否则下方C、紧邻N、另一个其下为空的N、上方间隙及C至少需要六层。

因此无须按完整五格字串选择配方。主列的目标C先统一降低一层，N_m的来源放到r−2；更低的目标格至多是地面一格。地面目标为N时，把它先放在r−3；为P时，把主列0至r−3填成牺牲C；为空时保持空底。最高C以上的N/P在最后统一追加。

近锚列只使用一个公式（以下幂表示连续格数）：

`A = N^(m−1) C^(r−m−1) N`。

主列及锚列的全部标签、长度、晶体删除掩码由r、m和地面目标材料决定，不新增制造分支。

### 准备与支撑交接

主列固定为q0，永久近助手q1，临时远助手q3，触顶晶体脊q2；可以镜像使用。

1. 先把主列底部空段填牺牲C；q1放五层N，q3在牺牲位置放C、其余N。按独立柱制造后半切保留q0/q1，删除底部填充C，主列N/C由q1托住。
2. 加入q3的五层N，半切保留q3/q0，转交支撑；再加入公式给出的近锚列A，半切保留q0/q1。主列来源N与锚列顶N同层粘连，目标C前态由主列来源N托住。
3. 加入互补两列：q2为五层C，q3为`P^(r−1)N`。近锚列的C连到q2晶体脊；主列保留C被N隔断，且与q2不相邻。
4. 执行一次Pin。删除晶体脊和近锚列C，全部保留C提高一层，到达最终目标高度。q3针柱的顶N同时提高到r，托住目标C。

### 同一个落点公式

Pin后的近锚列底部是地面P及m−1个连续N，列顶为m−1。主列来源N和近锚列顶N仍组成同一水平块；二者从r−1层下降，近列给出的最高障碍恰为m−1，故落点为m。

地面目标若为N，其前态在r−3，提高后两侧分别是已删除的锚C和独立针，没有水平粘连；主列没有新地面P，因此它单独落到地面。地面目标若为P，主列底部牺牲C被删，而删除前底层占用产生的新P保留。空地面目标则保持原地面空，不补主列P。

近助手最后统一补成

`P N^m P^(r−m−1) N^(5−r)`。

从m+1层开始逐层追加；低于r用P，r及以上用N。主列最高C以上的N/P可与该层助手一起供料。最后半切保留q0/q1；被去掉的临时助手已经没有C，不会删除目标晶体。

落点、补针与融合隔断由上述公式确定，与N/P/C的具体颜色标签无关。原八个困难五格模式都是同一个参数构造的输入，Python不再按这些完整字串分流。与第2节直接释放一起，四象限五层角的主体只有两种制造机制；无C是直接供料的边界情况。

六象限及以上可在半切中保留三列，进一步把两种落点情形统一为[任意层三列释放](../general/angle-synthesis.md)。这条空间条件不能直接套回四象限任意层。

## 4. 两角组成半形

对目标 q0 列，准备助手在 q3 的角；对目标 q1 列，准备助手在 q2 的角。分别制作，交换拼成完整四列。交换的切割保留各角全部格位，不破坏晶体。

再半切保留 q0、q1。两个外侧助手只有 N/P，不发生晶体融合删除。留下的格位正是 T；结算按 T 自身分组。若 T 稳定，所有组不移动，输出就是 T。

这证明半形定理的充分性，也使原来的[有限半形文法](half-closure.md)可以用局部判据及角配方实现，无需计算百万编码的闭包目录。

### 所有半形统一使用两角流程

`Constructor.half`及完整电路均使用上述通用构造。无晶体列已由第2节覆盖，目标自带助手也仍满足同一个两角证明；因此不再为无C直接制造或内向单角匹配保留快捷分支。只有目标列为空时跳过该角。

这项合并允许部分目标使用更多制造步骤，以删除专用分流和ROM。半形判据、标签、最终产物及原285节点上界保持。两角按镜像和遍次共用同一份电路，见[统一半形程序](shared-angle.md)。

## 5. 构造规模与实现边界

计数包含基础原料节点，四象限任意朝向旋转按一个顺时针、逆时针或半周操作计。简单角至多 61 个节点：主列及 N/P 助手的晶体前缀与后缀至多 33，远侧独立柱至多 20，拼接至多 4，半切及恢复方向至多 4。

难角采用宽松上界 140：初始三列制造及拼接至多 51，第一次半切至多 3；加入远侧普通柱及转交至多 16；近锚列及转交至多 20；补充晶体脊和临时针柱并拼接至多 35；顶针、最多三次助手上料、一次主列上料、末切及整体旋转至多 13。合计不超过 138，取整上界 140。

所以每个可制作标准半形可用至多 `2×140+4+1=285` 个节点制造。全图若存在一个方向，使两个原始半面分别满足半形判据，则可用至多 573 个节点制造。后一子类不包含已经证明需要一般顶针/堆叠尾部处理的所有情况，不能当作全图可制作性判据。

r/m原料生成与通用角入口已落实到Python，固定游戏ROM尚未迁移，本轮不更新电路建筑统计。Python在每个角末尾比较完整的目标列和助手编码，在半形末尾比较完整半形。此为生成制造证书时的逐步物理计算；本次只做静态源码和数学核对，没有执行样例、枚举或模拟。
