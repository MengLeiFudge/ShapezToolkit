# K支撑类的一次格位洪泛

本页把[支撑类K](stacking-proof.md#2-一个能抵抗新增粘连的支撑类-k)压缩为一次格位可达性，而不建立二十份组连通矩阵。Python实现为[`synthesis.support.in_support_class`](../synthesis/support.py)，电路实现为[`support_circuit.in_support_class`](../support_circuit.py)。这是K的精确判据；K仍只是四象限可制作性的必要条件。

## 1. 格位图

对所有占用格建有向图：

- 水平相邻的两个非针格之间加入双向边。
- 同列相邻的两个C之间加入双向边。
- 任意占用格向正下方紧邻的占用格加入向下边。

前两类边是原始粘连，最后一类是阻挡方向。同一粘连组中的向下边可以存在于格位图中；收缩整个组后它们只是自环，不会创造通向其他组的路径。反过来，组支撑边可由组内粘连路径加一条向下边表示。因此到地面或某颗针的格位可达性，与原最大粘连组支撑图相同。

令种子集合B为所有地面占用格与所有针格。判据为：

1. 每颗非地面针的正下方都有占用格。
2. 每个占用格都能沿上述边到达B。

## 2. 与K等价

若属于K，每组到达地面或含针支撑环。到达含针环后继续沿环即遇一颗针；组内所有格也能走到这条支撑路径，故条件2成立。非地面针单独成组，只有正下方这一条可能的支撑边；属于K时它不能没有出边，故条件1也成立。

反过来，条件2使每组能到达地面或某颗针。任取非地面针p，条件1给出它到下方组的边；条件2又使下方组到达地面或某颗针p'。若一直没有到达地面，就得到一条针到针的有限节点序列。最终必重复某颗针，形成经过针的非平凡闭合支撑路径，其中包含一个经过针的有向环。针不会与其他格粘连，不能在组收缩时被吞入内部自环。

所以每颗针都能到达地面或含针环，所有到达针的其他组也同样如此，即属于K。

这里把所有针当作洪泛种子并不等于无条件认为它们悬空有效；条件1和有限针序列证明补齐了这一点。只做种子洪泛而省略针的下方占用检查，会误收悬空单针。

## 3. 电路与Python

反向传播“可以到达B”的布尔标记：地面及针初始为真；非针格若水平相邻非针已标记、正下格已标记，或自身与上格均为C且上格已标记，就得到标记。地面行固定，不重复计算。

四象限五层至多20个节点，任意可达路径可去环成为至多19边的简单路径。同步传播19轮得到精确可达集合；不需要模拟重力或反复重新分组。Python按实际格数执行最多N−1轮，提前固定时停止；电路固定展开19轮。

针正下占用另行合取。每个占用格都标记时返回真；空图按空条件属于K，调用端仍自行排除空目标。

## 4. 接入完整搜索

四象限已有[全部可制作图形属于K](support-closure.md)的制造树证明。因此完整搜索可提前拒绝非K目标和非K的S前态P；真实Pin输出若可制作也必属于K，不会因这项筛选丢失成功分支。

Python局部构造器用K判据替代原来的重新下落稳定性检查。K保证每组有地面或其他组的阻挡，所以没有任何组能首先移动，必然稳定；新检查既保留旧必要排除，又能拒绝稳定的无针坏环。`Solver4.predecessors`也在进入Pin逆像前排除非K前缀。

完整电路只建一份K通路：ENTRY读完整帧目标，PREFIX读当前S前态；以Phase控制60个材料布尔量的路由。两处都会等待同一主副状态的完整传播期。切换及19轮路径已计入组合DAG，不以即时切换后的暂态作决定。

六象限存在可制作非K输出，故Python只在四象限调用这项制造必要筛选；完整电路本身也只生成四象限配置。K可达性本身可作结构分析，不能据此将非K六象限目标判不可制作。

## 5. 规模与验证

完整控制增加一份共用K通路后为37278平台、356状态；动态D仍166、初始D仍183，阶段684tick、周期228模拟秒、复位2864tick，没有增加当前时钟周期。它在进入S扫描和Pin逆像前排除整棵无效分支，实际搜索收益未经运行测量；最坏等待仍须继续压缩。

证据为上述人工图论证明、相关Python静态重读、LSP及生产蓝图静态DAG/端口/实际占地编译。没有运行目标、搜索、物理模拟、测试或游戏。
