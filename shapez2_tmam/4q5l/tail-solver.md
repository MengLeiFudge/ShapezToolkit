# 四象限五层：无需半形目录的完整逆推

本文将[逐列角构造](corner-synthesis.md)代入[统一合成定理](synthesis.md)，得到不建立全图或半形目录的目标到配方程序。实现为 [`Solver4`](../synthesis/solver4.py)。范围沿用合法普通部件、可供料晶体颜色、任意无晶体单层基础料和五层上限。本文没有运行目标求解、枚举、物理模拟或游戏。

该程序是完整的有限参考算法。它消除了半形闭包及其递归，却仍可能耗费很长搜索时间；本页不把它称为已完成的游戏 TMAM。

## 1. 起点改为局部构造

原统一定理把制造历史改写为：

```text
A → S → (Π → S)^k，0≤k≤4。
```

A 是基础层、紧 N/C 图形、单个可制作半形，或两个互补可制作半形的交换拼接。旋转已吸收到旋转封闭的起点和供料中。S 是纯 N/P 追加段，Π 是一次顶针。

现在每个非空半形都有局部充要判据及显式角配方，因此不用建立 H 目录。`Constructor.construct` 覆盖上述全部起点：基础层及紧图形由按层、独立柱构造覆盖；单、双半形由两个方向的标准化半形检查覆盖。构造器另外接受的独立晶体前缀及 N/P 后缀也都有真实配方，不会削弱可靠性。

构造器返回 `unknown` 表示它未找到这类直接配方；不能当作不可制作。返回 `unsolvable` 时依据的是已证的列内必要条件、四象限稳定性或完整无晶体判据。

## 2. 一段 S 只有逐列前缀需要恢复

对目标 T 的第 q 列，把全部非空格按原层号排序，得到长度 n_q 的列表。令 r_q 为列表中最高 C 的序号加一；无 C 时 r_q=0。

S 不移动旧格、不创造 C，也不能把新格插入已有列顶以下。因此全部 S 前态 D 恰在以下候选中：每列保留列表前 p_q 格，`r_q≤p_q≤n_q`。原层号和标签都保留。候选数至多 `6^4=1296`。

设 Δ=T\D。每个 Δ 水平普通块或单针，必须在地面，或至少有一个格的正下方属于 T。这个检查只对 Δ 分组，不能通过 T 中的旧普通格把两块新增上料粘在一起。该条件与逐列前缀条件共同构成 S 的静态判据，前提是 D 可制作，因而属于 K。

算法生成前态时只检查坐标、材料及新增块支撑。是否可制作由后续配方搜索确认。得到 D 的真实配方后，`Builder.append_noncrystal` 从低到高加入至多五份单层，并比较每步完整输出；失配抛内部错误，不能伪装成目标不可解。

## 3. 恢复最后一次顶针

对每个 S 前态 P，使用 [`pin_families`](../synthesis/inverse.py) 恢复其顶针输入 D：

1. P 的保留 C 必须来自同列低一层；其标签原样恢复。
2. 除新地面针以外的 N/P 按列保序恢复到前四层，来源不得低于输出层减一。
3. 未被占用的来源格为空或最终消失的辅助 C。输入底层占用与输出地面针掩码一致。
4. 第五层只影响删除掩码。先枚举其晶体掩码，每族计算一次正向 Π；命中后，再分别恢复该族顶层非 C 的空/N/P 选择。

辅助且最终删除的材料可以固定使用红晶体和普通 `Cu`。标签不影响连接、融合和重力；原制造证明可按相同结构重新赋值。顶盖各成员的可制作性仍须分别确认，不能用一个成员的成功替代全族。

候选生成在四列作笛卡尔组合以前，就对各自前四层检查列 A。第五层不能修复更低处的针支撑、针前缀或晶体间隙违例，因此这项提前排除保持完备。顶层 C 另检查完整五格列 A；恢复顶层空/N/P 成员时也检查完整列，避免将不可能成员送入制造递归。

每个 D 再通过直接构造及必要条件检查；未覆盖时递归求其尾部。成功后实际生成 `Π(D)`，比较是否等于 P，再追加到 T。这些排除减少实际分支，但没有取得新的最坏运行时间保证。

`Solver4(..., certificate_first=True)`可把族的正向检查移到真实制造证书之后：`pin_families(..., check_output=False)`先给结构候选超集，递归成功后只在其真实产物上执行Pin，失配则继续回退。两项条件仍均须成立，覆盖与终止证明不变；游戏端可以只保存候选材料格，避免预先编码任意原生图形。相应[两列扫描判据与证明](half-row-stability.md)已有Python和461平台网格部件，完整搜索控制与配方流仍未实现。

## 4. 终止、可靠性与完备性

**终止。** T 含 C 时，所有 S 前态保留 T 的全部 C，故最低 C 层号不变。任何顶针输入 D 至少含有一颗由该最低 C 反推到低一层的 C；可能恢复出的辅助 C 只会使最低 C 更低。因此每次递归最低 C 严格降低。用从零开始的层号，深度至多四条递归边；最低 C 在地面时不再尝试顶针。每层前缀、逆像族和族成员选择均有限。

最多五个递归帧即可遍历；程序按固定顺序重放 S 候选，不保存全量状态集。这里的帧数不等于门数，也不意味着候选数量很小。

**可靠性。** 所有叶端来自有真实制造证书的直接构造。向上只执行真实顶针和按层追加，并逐次检查完整结果。所以任何返回的配方都从基础料出发，逐格得到指定目标。必要条件的否定独立成立。

**完备性。** 取任意可制作目标的标准化历史 `A→S→(Π→S)^k`。最后一个 S 的下料在全部逐列前缀中；若 k=0，直接构造器覆盖 A，该分支成功。若 k>0，完整顶针逆像必包含最后一次 Π 的输入结构；最终删除格的合法标签可按固定辅助标签替换。该输入最低 C 更低，归纳可求得其制造证书，再执行 Π 和 S 即得到目标。

因此，所有分支真正耗尽而未命中时，目标才不可制作。程序没有将预算、运行超时或局部构造失败转换成 `unsolvable`。未着色晶体 `cu` 的实体供料尚未界定，仍返回 `unknown`，不属于此处完整供料范围。

## 5. 局部条件不能直接替代全图逆推

考虑以下三层目标，列号 q0～q3：

```text
L3   C N N .
L2   . . N .
L1   N . N .
```

编码为 `Cu--Cu--:----Cu--:crCuCu--`。每列满足 A；第三层大组经 q2 第二、第一层支撑到地面，因此目标也属于 K。但它不可制作。

若某个可制作 D 经 S 得到该目标，q0 的地面 N 和第三层 C 都必须保留。为保持 C，D 还必须保留 q1、q2 的第三层 N；否则 C 所在组没有直接支撑。q2 的逐列前缀条件又迫使保留其下两格。故唯一可能的可制作 S 前态就是目标自身。

该目标不是紧图形。沿任一对互补半面切开，包含 q0 的一侧都无法保持第三层 C：`{q0,q1}` 缺少 q2 支撑，`{q3,q0}` 则没有同层助手。因此它不是合法半形起点的拼接。

它也不可能是顶针输出：q0 的第三层 C 强制输入第二层为 C。目标地面为 N，故输入地面必须为空，否则必补出不能消失的地面 P。目标地面 N 的来源必须低于输入第二层 C，但那里只剩被要求为空的地面格，矛盾；高处 N 无法穿过保留 C 下落。

结合标准尾部定理，零顶针和最后一次顶针均排除，证明不可制作。这个例子来自人工推导，没有执行目标求解。它说明即使把列 A 和 K 合起来，也不能据此省掉全图尾部判定。

## 6. 全部可制作目标存在至多 627 节点制造树

节点计数包括基础料；四象限顺、逆或半周旋转各算一个实体操作。由[角构造规模](corner-synthesis.md#5-构造规模与实现边界)：

- 每个可制作半形至多 285 节点。
- 双半形、朝向及交换合计起点至多 573 节点；单半形、基础层与紧图形均不超过此界。
- 标准尾部至多四次 Π，至多五段 S。
- 每段 S 至多五份基础单层及五次堆叠，即至多十个新增节点。

所以可以选取一棵制造树，使节点数不超过：

```text
573 + 4 + 5×10 = 627。
```

这是存在性上界，不是全局最短步数。当前程序优先接受额外的已有构造子类，不宣称返回的配方在所有输入上都最短。

## 7. Python 入口及剩余电路成本

在仓库根目录可用：

```bash
python -m shapez2_tmam.synthesis '目标短代码' --quadrants 4 --complete
```

`Solver4(Rules(4)).solve(target)` 输出与局部构造器相同的三态结果和制造树。CLI 只在四象限允许 `--complete`；默认仍走快速局部构造。上述为接口说明，本次没有执行目标命令。

半形目录被两个列构造和局部支撑检查替换，是结构上的压缩。完整尾部每个父目标仍可能检查多达 `2^24` 个物理逆像族，以及恢复顶盖后的更多实际成员。即使递归帧很少，也不能由此推导实用等待时间。

游戏完整实现仍需压缩顶针候选、编码前缀与回退状态、按真实信号延迟实现可靠控制，以及输出完整配方流。现有原生加工核心和无晶体蓝图只完成其中一部分。六象限不满足四象限 K 闭包，不能使用本页递归作为完整六象限求解器。
