# 偶数象限与任意高度

先读[理论 I：模型与不变量](papers/TMAM理论I-模型与不变量.pdf)，再按问题阅读[理论 III：一般偶数象限构造](papers/TMAM理论III-一般偶数象限构造.pdf)、[理论 IV：级联与强制工序](papers/TMAM理论IV-级联与强制工序.pdf)、[理论 V：交替重排与多窗口参数族](papers/TMAM理论V-交替重排与多窗口参数族.pdf)和[理论 VI：落地记录与空间容量下界](papers/TMAM理论VI-落地记录与空间容量下界.pdf)。`n` 只取偶数，`H` 限制整个准备和制造过程；旋转粒度、半切规则和单次重力顺序必须随模型明确。

## 最终命题

给定任意有限正整数序列 `(a1,b1,a2,b2,...)`，能否选择偶数 `n`、共同 `H` 和目标 T，使所有合法最后 Swap 来源都无法绕过指定的 Pin/单层 Stack 阶段？

[主命题与量词](proofs/06-forced-words.md#s06-01)仍未证明或证伪。四象限的[PSPSPS 重排反证](proofs/06-forced-words.md#s06-11)只否定强阶段版本，且可能增加一次 Stack；不能外推到可变偶数宽度，也不能据此否定最短总步数版本。

[双窗口参数族](proofs/06-forced-words.md#s06-16)已覆盖每个 `(1,a,1,b)`：四象限、`H=a+b+10`，任意起点都恰有两次 Pin，中间至少 `a` 次、末尾至少 `b` 次单层 Stack；给定路线达到下界。`b=0` 还把旧 `W_a` 的共同制造高度降到最小容纳高度 `a+10`（系统论述见[理论 V 第 4 节](papers/TMAM理论V-交替重排与多窗口参数族.pdf)）。

[六象限参数族](proofs/06-forced-words.md#s06-17)在共同 `H=a+10` 内强制最短词 `P S^a P`。证明允许三种切向及前置、中间、后置 Stack；利用新增列的低保留晶体和单一屋顶针链排除替代支撑。这个高度限制属于下界的条件，不能直接提高 `H` 后沿用（系统论述见[理论 V 第 5 节](papers/TMAM理论V-交替重排与多窗口参数族.pdf)）。

[最低来源晶体的落地约束](proofs/06-forced-words.md#s06-18)在已知 Pin 总数 `p`、最低保留 C 高度 `c=p+2` 时，将底部针数 `r<p` 锁定为第 `p−r` 次实际顶破。`m` 个不同轮次记录至少需要 `4m` 象限，且有同宽制造证书；该证书的目标另有零尾 Pin 来源，因此不能据记录本身推断全局 Pin 数。

[四列半形的稳定性边界](proofs/06-forced-words.md#s06-19)保证八象限真实半切输出稳定，并将首个必要 Pin 的来源约束扩展到八象限；十象限十一层则已有真实不稳定半切输出。更宽时，不能只靠半形不稳定排除它作为交换来源。

[逐层辅助分量容量](proofs/06-forced-words.md#s06-20)从目标第 `h+p` 层的全部保留 C，计算来源第 `h` 层可供待删除 C 占用的位置；不同删除分量至少占用互不相邻的位置。结合落地记录，可以直接排除超过容量的候选 Pin 总数，强于单独按象限数筛选。

[最低普通格的落地与浅来源空间界](proofs/06-forced-words.md#s06-21)证明：任意来源高度的最低旧 N 只要以后落地，第一次下降就直接落地；三份第 2、第 3 层混合记录在八象限不可能，另加普通格也不能绕过。来源提高到第 4 层时，仍需各消耗不同的第 3 层辅助分量。普通格恰好填满来源晶体下方的格位时，任意高度都能锁定 Pin 专属释放；同高 `m` 份记录仍需 `4m` 象限。十八象限七层实例给出 Stack 释放的真实制造凭据和短代码，区分落地计数与顶破计数。

[底针位置与交换来源](proofs/06-forced-words.md#s06-22)把目标底针转换为实际 Pin 总数、半切方向及来源旧针前缀的精确约束。满普通前缀记录满足 `n≥3m+e`，`e` 统计相邻来源高度差至多 1 的间隔；记录列的最低晶体之上没有普通格时，封闭间隔还限制多份辅助塔横移所需的高度。连续晶体段上方的预存容量可统一扣入供料下界，低支路族达到该界。要把剩余供料锁成内部窗口，仍须另证供料截止时刻（以上五项空间与容量工具统一收于[理论 VI](papers/TMAM理论VI-落地记录与空间容量下界.pdf)）。

局部时钟、三座塔或指定来源的成功路线不足以证明全局强制。尚缺多个中间窗口的全来源串接论证，以及排除改换切向、提前上料和窗口合并的方法。
