# TMAM 理论 II：四象限五层的完整合成

**摘要。** 固定四象限和五层共同制造高度，本文给出从任意非空目标到制造树的有限判定。证明分两步。首先，合法加工保存含针环支撑性质，因而任意一次复杂堆叠可用最终保留的基础块重建。其次，相邻两列半形在有限编码空间内形成递增闭包。对制造树作归纳可证明该闭包恰好收齐所有可用半形。保留晶体的位置约束和四次顶针尾部的消去定理把根配方的搜索限制到至多三次尾部顶针。正判定可逐层展开为实体配方，完整闭包耗尽后得到负判定。

**关键词：** 四象限五层；支撑闭包；顶针逆像；半形文法；构造性判定

## 1. 制造树与支撑闭包

沿用理论 I 的材料、标签及结算规则，层号为 $0,\ldots,4$。可制作集合记为 $\mathcal{R}(4,5)$。给定一棵制造树，每个内部节点保存该次加工的实际格位输出。支撑图的边从受挡的组指向其下方的另一个组。

**定理 1.1（支撑必要条件）。** 每个可制作状态都属于 $\mathcal{K}$，即每个最大粘连组都能沿支撑边到达地面或到达含针环。

**证明。** 分别检查制造树的节点。基础层、紧实的结晶输出均接地。旋转和染色保持支撑。堆叠中下料的旧格静止，落稳的新格有直接下挡。写回后新增的水平粘连只会收缩非针节点。接地路径的终点仍在，含针环上的针也始终独立，环不会整体缩成一个节点。

半切留下两列。不同非针组的高度区间互不重叠，所以没有针的组间支撑边只能走向更低的区间。真实切后半形的支撑终点只能是地面或含针环。交换拼接通过的两半时，非针节点的收缩同样保存这两个终点。

对顶针，假设输出出现既不接地也不到含针环的组。曾下降的块不能成为未移动组的最终下挡，否则它在下降途中就要穿过该组。故未移动组中须有一个无针环。原地面格抬高后由新针支撑，原顶层已截去，环只可能使用原中间三层。四列三层的无针环必须有一组用晶体脊贯穿三层，并在该三层的顶层占至少三格。理由是环上的每个组都要经过中层，否则只有单侧的支撑边。四列环在同一层至多容纳两个分离的非针组，两个中层格必须相对。一条支撑边跨上、中层，反向边跨中、下层，若都跨同一层间，两组就会在外层相接。因此外组必须在上下两层分别从晶体脊绕至相对列，剩余位置紧邻晶体脊。若有晶体删除传播到该层，晶体脊也要随之删除，与环保留矛盾。若删除未传播至该层，则只是截顶、抬升和补针，低部原有支撑仍在。沿制造树归纳即得结论（四列三层无针环的逐列穷举详见文末参考索引 `01-12`）。证毕。

## 2. 堆叠段与顶针的逆像

### 2.1 基础块的精确落点

设下料 $D \in \mathcal{K}$。记 $h_D(q)$ 为列顶，空列取 $-1$。在列集 $J$ 上堆入一个水平普通块或单针时，其落点为

$$
z=1+\max_{q\in J}h_D(q).
$$

若 $z\ge5$，块整体截去。记 $S(D,T)$ 为固定朝向下经过任意有限串基础堆叠可以从 $D$ 制成 $T$，允许零次。

**定理 2.1（堆叠段判据）。** $S(D,T)$ 成立，当且仅当原格位与标签完整保留，新增格只含普通格或针，各新增格均在本列原列顶之上，而且仅用新增格组成的每个水平普通块或单针都触地或至少有一个格在目标中有直接下挡。

**证明。** 下料 $D \in \mathcal{K}$，原格始终静止。落下的上料晶体在首次移动时碎裂，其余上料晶体留在限高外。故任意复杂堆叠中最终新增的也只有从原列顶上方落下的普通块和针。下挡比新增块低一层，截高后仍保留。反过来按目标高度递增投入这些基础块，每个块的目标下挡都已就位，落点公式给出指定高度。同层不同块互不共列。归纳至最后一层，即得到 $T$，至多二十次有效追加。证毕。

**推论 2.2（逆向截断）。** 每列的旧格在该列目标格中构成一个前缀。五层连同空前缀共有至多六种截断位置，故待查旧图至多 $6^4=1296$ 个。保留晶体、旧图可制造性及定理 2.1 进一步排除候选。

### 2.2 顶针的三种删除来源

记 $\Pi(D)$ 为一次真实顶针的结果。旧顶层先被截去，与顶层晶体融合的低处晶体也被删除。剩余格抬高后，以原地面占用补针并结算。初始不静止组中的晶体在第一次下降时还会碎裂。因此逆向恢复必须同时考虑截顶、融合删除和下落碎晶。

**命题 2.3（可制作顶针前态的有限生成）。** 目标地面针的列集就是输入地面占用列集。每颗目标晶体强制其同列下一层是来源晶体。去掉新针后，各列保留的普通格和针与原第 0 至 3 层的普通格和针逐格保序对应。

**证明。** 被保留的晶体没有下落，每次顶针恰提高一层。限高内的旧普通格与针都不会因碎晶消失，只能同列下降。在列内为它们依序选择来源高度 $r$，要求目标高度不超过 $r+1$。剩余低格任选空或牺牲晶体，原顶层任选四种材料，再按原底掩码和精确等式 $\Pi(D)=T$ 筛选。所有真实前态均被生成，正向等式与前态制造凭据保证反向的充分性。单列低部选择最多 32 种，顶层每列四选一，总数至多 $32^4\,4^4=2^{28}$。证毕。

### 2.3 同一次顶针中的两种碎晶

触顶融合删除与重力下落碎晶可在同一次顶针加工中分别清除不同的晶体分量。沿用零基层号 $z \in \{0, \dots, 4\}$ 与列号 $q_0 \sim q_3$，考察紧实可制造前态 $D$：

```text
 z   q0 q1 q2 q3
 4    C  N  N  N
 3    C  N  C  N
 2    C  N  N  N
 1    C  C  C  C
 0    C  N  N  N
```

在 $D$ 中，$q_0$ 的五层晶体柱与 $z = 1$ 整行晶体同属融合组 $E$，因接触最高层 $z = 4$ 而整组删除；$(3, q_2)$ 的孤立晶体被周围普通格 $N$ 隔断，不属于 $E$；原顶层 $z = 4$ 其余三枚 $N$ 直接截顶删去。

剩余格统一抬升一层并在 $z = 0$ 四列补齐新针 $P$ 后，$z = 0$ 的四枚新针与 $z = 1$ 处 $q_1 \sim q_3$ 的普通格构成触地静止集 $F$；升至 $z = 3$ 的三连普通块及升至 $z = 4$ 的 `N-C-N` 混合组因下方 $z = 2$ 已空而不属于 $F$。前者整体落至 $z = 2$；后者开始下降，其中 $(4, q_2)$ 的晶体因下落碎裂消失，两侧 $q_1, q_3$ 的普通格各落至 $z = 3$。输出 $\Pi(D)$ 为：

```text
 z   q0 q1 q2 q3
 3    .  N  .  N
 2    .  N  N  N
 1    .  N  N  N
 0    P  P  P  P
```

该算例同时包含顶层截断、跨层融合删除、融合组外的下落碎晶以及普通格位移。逆向枚举前态时若仅回填触顶融合组 $E$ 而忽略非静止集 $F$ 外的下落碎晶，便会漏掉合法前态 $D$。

## 3. 相邻半形的有限文法

把切后半形旋到相邻两列的标准方向，保持两列内部次序。半形含十个格位，所以含空标记的结构编码总数为 $M=4^{10}$。初始化集合 $X_0$ 包含稳定无晶半形及空标记。无晶半形中每个水平块都有地面或直接下挡，可从低至高制造。空标记代表某个出口没有物品。

**定义 3.1（起点与尾部）。** 从当前集合 $X$ 构造起点的方式有四种：取基础单层、取完整的紧实普通格与晶体图形、旋转一份已知非空半形，或把两份已知非空半形拼到互补两侧。紧实图形可以逐列结晶、切出、再拼接。单侧为空时直接使用另一侧的实物。记 $L(A)$ 为从起点 $A$ 出发，由一段基础堆叠及至多四组“顶针后接基础堆叠”获得的非空末端，各段允许净旋转。

**定理 3.2（半形闭包）。** 每轮从旧集合的起点生成 $L(A)$，对每个末端试四个半切方向，将标准化的切后结果并入旧集合。所得最小不动点 $X_*$ 恰好由所有可制作的切后半形及空标记组成。

**证明。** 每轮的新配方只引用旧轮的真实制造树，故按首次出现轮数归纳，所有非空成员都可制造。反过来沿任意制造树的主干回溯至最后一个基础输入、结晶、半切或交换。该节点给出定义 3.1 的起点，两输入机器所用半形来自更小的子树。此后堆叠段由定理 2.1 约化。如果末端保留晶体，它必从起点存活至今，经过一次顶针就提高一层，故尾部顶针至多四次。无晶末端按稳定水平块逐层制造。对制造树归纳，真实半切输出都由递推收录。每轮严格增长时至少加入一个编码，所以至多 $M$ 轮即停止。证毕。

## 4. 全图合成与三次尾部顶针界

**定理 4.1（四象限五层完整合成）。** 给定有合法材料标签的非空目标 $T$，存在有限算法，恰在 $T$ 可制作时返回逐格产生 $T$ 的制造树。

**证明。** 对无晶目标先检查稳定性，成功时逐层构造。对含晶目标，使用闭包 $X_*$ 的起点，搜索恰以 $T$ 为末端的合法尾部。定理 3.2 的主干分解覆盖所有真实来源，定理 2.1 及精确顶针关系覆盖各段。反向展开首次出现时记录的父节点，轮号严格递减，必在基础原料处停止。把目标标签沿存活格传递至叶子，牺牲格任选合法标签，即得带标签制造树。有限候选全部耗尽后方可拒绝。证毕。

**定理 4.2（第四次尾部顶针的消去）。** 若含晶目标具有四次尾部顶针的标准配方，则该目标存在零次尾部顶针的标准配方（即由某个合法起点仅经基础堆叠即可制成）。

**证明。** 每颗目标晶体必从起点地面升至第 4 层，下面留下四枚连续地面针。执行到第 $t$ 次顶针时，全部晶体高度至少为 $t$。其下方各纯普通块和针有通向地面的逐层支撑，下一次抬升及补针后仍保持。第 $t$ 层各纯普通块也保有直接下挡：原块由低部托住，从更高处落入的块在停止时必有下挡，合并相邻普通块保持这一性质。由 $t=0$ 归纳到 $t=4$。在终态只取各晶体及下方四枚针，两半各自可制并可拼成起点。其余格都满足定理 2.1，按高度补入即可。故完整搜索只须保留零至三次尾部顶针。界限仅计根起点之后的顶针。证毕。

**推论 4.3（整图的两类目标）。** 对可制作目标，先在两个切向检查起点后只做一段基础堆叠是否可达。命中者有零尾部顶针配方。两个切向均失败者的所有标准配方至少有一次尾部顶针，由定理 4.2，搜索一至三次即可。分类依据是整图所需的尾部工序，无须把相同程序按每根列的局部构造再行细分。

### 4.1 一次尾部顶针的必要性

**例 4.4（切向无法同时保留的两个普通格）。** 下面给出五层准备形和一次顶针后的目标。短代码按层从地面向上读。

```text
D = Cu--cr--:crCucrCu:----cr--:----cr--:----cr--
T = P---P---:Cu------:crCu--Cu
```

| 零基层 $z$ | $q_0$ | $q_1$ | $q_2$ | $q_3$ |
|---|---|---|---|---|
| $2$ | $C$ | $N$ | 空 | $N$ |
| $1$ | $N$ | 空 | 空 | 空 |
| $0$ | $P$ | 空 | $P$ | 空 |

在准备形 $D$ 中，$q_0, q_1$ 半形由地面普通格托住，$q_2, q_3$ 半形由连续接地的五层晶体柱托住，两半均可独立制造。一次顶针截去 $q_2$ 的晶塔，$(1, q_0)$ 的晶体隔着普通格而保留；原地面占用在 $q_0, q_2$ 各生成一枚针，剩余材料抬高，输出正是 $T$。

**证明。** 反设可由两份切后半形拼合后再仅用基础堆叠得到 $T$。第 $2$ 层的晶体 $(2, q_0)$ 必须已在拼合起点，其同列下方材料也必须预置，否则后续堆叠无法穿过晶体补入。$(2, q_1)$ 与 $(2, q_3)$ 的两枚普通格各自正下方为空；若留到堆叠阶段再追加，二者在新增格中互不相邻且均无直接下挡，违反定理 2.1，故这两格也必须在拼合起点中同时预置。然而任一半切方向都只能将 $(2, q_0)$ 晶体与其中一格置于同一半面，另一侧普通格会在半切结算时独自下落，矛盾。因此目标 $T$ 最少需要一次尾部顶针。证毕。
