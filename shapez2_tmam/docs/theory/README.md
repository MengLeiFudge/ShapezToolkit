### 阅读与维护约定

- **主线分工**：I 提供全部后续论文共享的物理公理与不变量；II 与 III 处理“给定状态能否制造、如何分列/分半构造”；IV 提出重复结算与全局强制工序问题；V 从操作词代数重排与上料窗口角度给出正规形上界和无限参数族；VI 从目标几何留痕与独立集图论容量角度给出不依赖全图稳定性的来源筛除与宽度/高度下界。
- **双层互链**：正文中的 `[锚点说明](../proofs/XX.md#sXX-YY)` 在阅读 Markdown 时可直接跳转至九卷参考证明查核原始细节；编译 PDF 时会自动剥离超链接、仅保留可读文字，并在篇末“文献来源与参考卷索引”集中给出章节映射。
- **措辞边界**：“未决”仅指明确陈述但尚未证明或证伪的数学命题，不与“缺少紧凑工程实现”或“未在游戏存档内实机验收”混用。

## 论文 Markdown 编写与 PDF 编译规范

所有论文统一由 [`../papers/build_paper_pdf.py`](../papers/build_paper_pdf.py) 转译为 Typst 源码并直接编译为 A4 单栏学术论文 PDF（英文与数学采用 *New Computer Modern*，中文正文采用宋体、标题采用黑体、定理陈述采用楷体、网格代码采用 `Consolas`）。后续修订现有论文或新增第 VII 篇论文时，请遵循以下语法约定。

### 1. 篇首版头与章节层级

篇首固定由顶层标题、摘要段与关键词段组成，编译器会自动提取并生成居中学术版头与缩进摘要区：

```markdown
# TMAM 理论 VII：论文主标题

**摘要。** 在此编写单段连贯摘要，概括研究模型、核心定理与适用边界……

**关键词：** 关键词一；关键词二；关键词三；关键词四

## 1. 第一节标题

### 1.1 第一小节标题
```

- **自动编号**：`##` 与 `###` 标题前手工书写的 `1.`、`2.1` 等序号会在编译时自动剥离，交由 Typst 统一连续编号（渲染为 `1 节标题`、`1.1 小节标题`）。请勿跳级使用 `####`。
- **篇末无编号索引节**：文末固定使用 `## 文献来源与参考卷索引`，编译器识别“参考”或“文献”前缀后自动将其排为**无编号**一级节标题，其下放置两列三线表对照“本文范围”与“完整参考证明”。

### 2. 定理、定义与证明环境

编译器按段落首部的粗体触发词自动切换学术定理样式，推荐按所属一级节编号（如 `定理 2.1`、`引理 2.2`）：

- **楷体命题环境（`#thm-plain`）**：段落以 `**定理 X.Y（可选名称）。**`、`**引理 X.Y。**`、`**命题 X.Y。**`、`**推论 X.Y。**` 或 `**猜想 X.Y。**` 开头，陈述正文自动排为楷体。
- **正体定义环境（`#thm-def`）**：段落以 `**定义 X.Y。**`、`**构造 X.Y。**`、`**算例 X.Y。**`、`**例 X.Y。**`、`**注 X.Y。**` 或 `**问题 X.Y。**` 开头，陈述正文保持宋体正体。
- **证明环境与右对齐证毕符 `□`**：
  1. **常规证明块**：以 `**证明。**`（或 `**构造与证明。**`）起段，编译器会自动将后续连续段落、行间公式、列表与表格收入同一 `#proof-env` 环境，直至遇到以 `证毕。` / `得证。` 结尾的段落（或下一个标题、定理头），自动隐去句末“证毕。”并在行右对齐输出空心方框 `□`。
  2. **跨 `###` 小节的分步长证明**：当一个主定理拆分为多个 `###` 子节逐步证明时，无需用单个证明块跨节包裹，只需在最后一个子节收尾段末尾写明 `定理 X.Y 得证。`（或 `引理 X.Y 证毕。`），编译器同样自动移除该句尾套话并在行右补齐 `□`。

### 3. 数学公式支持范围与三条硬性禁忌

行内公式写为 `$...$`，独占行间公式写为上下独立成行的 `$$ ... $$`（汉字与行内 `$...$` 紧邻时编译器会自动补入中西文间距）。内置转译器支持的常用 LaTeX 数学语法包括：

- **结构与定界**：上下标 `x_i, x_{i+1}, h_D(q)`、分式 `\frac{a}{b}`、根号 `\sqrt{x}`、取整 `\lfloor x \rfloor` / `\lceil x \rceil`、花括号集合 `\{ q \in \mathbb{Z}_n \mid r_q \ge p \}`（空集统一写 `\varnothing`）、分段函数 `\begin{cases} a, & x > 0, \\ b, & x \le 0. \end{cases}`；
- **字体与算子**：花体 `\mathcal{Q}, \mathcal{J}, \mathcal{K}, \mathcal{R}`，黑板粗体 `\mathbb{Z}, \mathbb{N}`，正体算子 `\mathrm{Cut}, \operatorname{Swap}, \max, \min, \gcd`（`cap` 建议写 `\operatorname{cap}`），公式内中文短说明 `\text{且 }`；
- **符号与多字母序列**：`\le, \ge, \neq, \equiv, \approx, \sim, \in, \notin, \subseteq, \supseteq, \subset, \supset, \cup, \cap, \setminus, \times, \cdot, \to, \mapsto, \implies, \iff, \forall, \exists, \dots, \cdots`；形如 `$PS^kPP$`、`$DDD$`、`$CC$` 的多字母大写序列会自动拆分为单字母数学变量并置，不会触发 Typst 未知多字母变量报错。

编写数学式时须严格遵守**三条禁忌**：

1. **禁止在 `$...$`（含 `\text{...}`）内部嵌套反引号 `` `...` ``**：Typst 数学模式不接受内联 raw 标记；短代码如 `` `SuSu----` `` 请置于公式外的正文或代码块中。
2. **禁止用 ` ```text ` 代码块代替数学公式**：所有等式、不等式与推导链一律使用 `$$ ... $$`；` ```text ` 代码框仅用于二维格位矩阵（`z / q0 q1 ...`）和游戏形状短代码。
3. **禁止在普通正文中使用未配对的裸 `$`**：如需书写字面美元符号请转义或改用文字表述，避免整段误入数学模式。

### 4. 学术三线表与防断页控制

- 标准 Markdown 表格自动编译为无竖线学术三线表（顶底线 `1.0pt`、表头分隔线 `0.5pt`）。表格切分器已识别数学模式与行内代码，单元格内可直接书写 `$|G(B)|$` 或 `$I \cap J \neq \varnothing$` 而无需转义竖线。
- **自动防断页**：总行数 `<= 9` 行（含表头）的紧凑三线表，以及行数 `<= 22` 行的 ` ```text ` 格位/短代码框，默认设置 `breakable: false` 保持整块同页；超出阈值的长表或跨层大网格自动允许跨页续排。

### 5. 编译命令与质检流程

1. **新增论文注册**：若新增源文件（如 `07-xxx.md`），先在 [`../papers/build_paper_pdf.py`](../papers/build_paper_pdf.py) 顶部的 `PAPERS` 元组中追加 `(源文件名, 输出 PDF 文件名, "Shapez 2 TMAM 形式化理论系列 · 第七篇")`。
2. **执行零警告编译**：在仓库根目录使用项目虚拟环境运行：
   ```powershell
   # 全量重新编译全部六篇论文
   .\.venv\Scripts\python.exe main.py tmam2 paper --all

   # 单独编译指定论文
   .\.venv\Scripts\python.exe main.py tmam2 paper --source shapez2_tmam/docs/theory/05-alternating-reductions.md --output shapez2_tmam/docs/papers/TMAM理论V-交替重排与多窗口参数族.pdf
   ```
   编译脚本默认调用 `typst.compile_with_warnings`；若输出出现任何字体回退或语法警告，须先消除后再提交。
3. **渲染图像目视复核**：PDF 文本可提取并不代表字形与版式无误。修订复杂公式、宽表格或长网格后，应将受影响页面通过 `typst.compile(..., format="png", ppi=144.0)` 渲染为 PNG 逐页目视核查：① 首页标题与摘要折行；② 分段函数、上下标与集合括号配对；③ 三线表列宽与折行；④ 证明结尾 `□` 与章节标题是否存在孤行断页。
4. **同步索引与参考卷**：若定理范围或编号发生调整，同步更新 [`../papers/README.md`](../papers/README.md)、[`../general.md`](../general.md) 及对应 [`../proofs/`](../proofs/README.md) 参考卷。
