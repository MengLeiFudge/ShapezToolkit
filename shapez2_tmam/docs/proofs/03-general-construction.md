## 03-01 六象限五层的统一合成算法与覆盖定理

原文标识：`6q5l/synthesis.md`。

本页给出第二套完整合成方法：**保存精确操作输出的分轮配方目录**。对任意非空六象限五层目标，算法有限终止；目标可制作时输出合法制造树，不可制作时返回否定结论。

六象限已经存在[可制作但不属于 K 的半形，以及可制作但不稳定的拼合输出](#s03-02)。因此这里保留真实双输入堆叠，允许不稳定中间状态，不能把四象限的基础堆叠约化作为全局规则。这个方法的代价很高；本页证明覆盖与终止，不声称它适合直接用于实时 TMAM 控制。

<a id="s03-01-h1"></a>

### 1. 操作实例与范围

取六列、五层，列按环相邻，允许单象限旋转。基础输入是任意无晶体单层，普通种类与合法颜色不影响结构物理。空物品不作为实体输入。

本轮静态核对了 `Game.Content/ShapeOperations.cs` 的构造函数：旋转实例使用 +1、−1、`shapePartCount/2`；在六列实例中分别为一个象限、反向一个象限和三个象限。`ShapeOperationCut.ExecuteInternal` 按 `PartCount/2` 分割索引，因此六列半切恰为连续三列。通过共同旋转输入和旋转回去，可选择所有六种半切方向。

以下定理适用于将 `shapePartCount=6`、`maxShapeLayers=5` 传入这组操作的模型。它不声称已核验某个具体存档、Mod 或原料供给系统。游戏信号分析的 unstack/analyze 不新增为实体制造操作。

<a id="s03-01-h2"></a>

### 2. 不依赖 K 的精确操作计算

<a id="s03-01-h3"></a>

#### 有界重力计算

将[静止组与水平落点证明](01-foundations.md#s01-13-h1)用于六列：证明只使用同列不穿透、晶体首次下降即消失、其他格不因下落消失、下落中只拆组不合组，没有使用“两列半形”或“四列三层”的几何性质。

在重力开始前的活组支撑图上，反复删除无地面、也没有指向剩余组的直接支撑边的组。最后剩余 F 恰为始终未移动的组；它包含任意有向支撑环，不要求环内有针。其余组第一次移动时晶体全部碎裂，N/P 分成水平块。

按这些块的初始层号递增处理。块 b 的落点为 1 加以下高度的最大值（空集取 0）：它占据列中、初始位置下方的 F 固定格高度；所有更低来源、与它共享列的移动块的最终高度。已移动格不能成为从未移动格的新阻挡，保留格的列内次序不能颠倒，所以这个公式与逐组下落等价。

这个论证也适用于临时高度超过五层的初始格位。五层上限只在全部下落结束后执行一次截高；截高之后不再下落、不再按晶体融合删除。

<a id="s03-01-h4"></a>

#### 操作表

| 操作 | 对非空输入的精确计算 |
|---|---|
| 旋转 | 置换整列，不执行重力 |
| 半切 | 在完整输入上记录晶体融合分量；保留三列；跨切线的融合分量在保留侧也删除；执行上述一次重力 |
| 交换 | 对两输入分别按半切结算，交换互补半面，折叠为格位输出；拼接后不再执行重力 |
| 顶针 | 删除原第五层及其触及融合分量中的低层晶体；原第一至第四层提高一层；按删除前原第一层占用补地面针；执行一次重力 |
| 堆叠 Stack(D,U) | 下料 D 保持初始位置，上料 U 所有格提高六层，再对合并格位执行一次重力，最后删除高于第五层的格；不预删上料晶体 |

一次堆叠最多有六十个初始格，临时高度最高十一层。重力中的活格只下降或消失，所以局部计算有限。新接触仅在下次需要重力的操作开始时重新分组，不能在当前输出后补一次稳定化。

这些定义与静态重读的 `ShapeOperationStack/PushPin/Cut/SwapHalves/Rotate` 及 `ShapeLogic.Collapse` 调用顺序对应。局部计算本身可以写成代码，但本页没有通过执行模拟来取得结论。

<a id="s03-01-h5"></a>

### 3. 显式可制造种子及颜色

结构状态是六列五行的 N/P/C/空编码，固定地面坐标，只补顶部空行，不删除空底层或中间层。非空编码全集 U₆ 的规模为：

```text
N₆ = |U₆| = 4^30 − 1 = 2^60 − 1
```

种子集合 B₆ 包括所有非空无晶体基础单层，以及所有高度 1～5、每格均为 N/C 的紧图形。

紧图形不是天然原料，其配方如下：分别制造每根目标柱，另五列填辅助 N；逐层加入目标 N 或 P，在目标为 P 的层结晶，并指定需要的晶体颜色。已完成的 N/C 不受影响。完成后用两个三列半面相交于目标单列的切割切出连续柱：例如 q0 用 `{q4,q5,q0}` 和 `{q0,q1,q2}`。辅助列无晶体，目标柱连续触地，切出不碎裂、不下落。

将相邻柱拼成长度至多三的片段，再拼成两个三列半形，最后交换合并。追加新柱时选切线把已有连续片段与新柱分置两侧；另一条切线位于片段之外。这样每次预先半切只去掉空列，已拼部分不被拆开。故每个紧图形种子有合法有限配方，全过程不超过五层。

任意结晶输出都是紧图形，可以用上述独立配方代替它及此前历史。这消除了搜索中对结晶前历史的依赖。普通染色不改变结构，可在最终制造树中向来源基础料传递标签；晶体标签在紧图形种子处逐格恢复。两份输入的标签分别赋给两份物品，不要求一份实物同时满足不同标签。

因此可在有限结构全集上推导；结论仍覆盖所有允许的普通种类及合法配色。

<a id="s03-01-h6"></a>

### 4. 分轮目录与目标合成程序

R₀=B₆，并为每个种子记录第 3 节的具体配方。定义：

```text
Rᵢ₊₁ = Rᵢ
       ∪ {Rotate(D), Pin(D), Cut_left(D), Cut_right(D) : D∈Rᵢ}
       ∪ {Stack(D,U), Swap_1(D,U), Swap_2(D,U) : D,U∈Rᵢ}
```

所有非空输出按原始格位写入目录；旋转可取 +1 即可生成全部朝向，也可直接使用全部六个净旋转。每轮只读取旧快照 Rᵢ。对每个第一次出现的编码，记录操作名、参数和一个或两个旧目录输入，称为它的配方记录。

必须保留的实现规则：

- Stack先用[K_add条件化简](04-stacking.md#s04-02)：通过判据的下料使用37种连续普通块或单针；原下料失败但[一次结算后进入K_add](04-stacking.md#s04-04)时，只生成纯C触发上料，下一轮从结算结果继续基础追加；其余下料保留全部真实上料。这些替换保持最终闭包，不保证同一轮出现相同状态。Swap保持精确操作或使用带原输入的[半形凭据](04-stacking.md#s04-16)。
- 不按 K 或全图稳定性筛除状态。[反例中的 H 和 V](#s03-02)均属于必须保留的状态。
- 不在操作后增加重力、删空底层，或把原始输出换成另一个稳定图形。
- 空输出只表示该出口没有物品，不加入非空目录，不接入后续机器。

合成程序如下：

```text
Synthesize6(T):
    preserve coordinates, erase ordinary kinds and colors
    initialize R with all explicit seeds and their recipes
    if T already has a recipe: return ExpandAndLabel(T)
    repeat:
        old := frozen snapshot of R
        apply every listed unary operation to every member of old
        apply every listed binary operation to every ordered pair of old
        record each new nonempty output with parents from old
        if T has appeared: return ExpandAndLabel(T)
        if no new output appeared: return NotManufacturable
```

ExpandAndLabel 按配方记录递归生产输入物品，执行记录的实体操作并选择所需出口。种子展开为基础原料加工。标签从目标向来源回填，在紧图形处使用逐列配色宏。每个共享子配方需要几份物品就生产几份。

此算法可以按目标提前返回；证明不要求先对所有目标分别执行一遍。其全覆盖性由下节的制造树归纳给出。

<a id="s03-01-h7"></a>

### 5. 完整证明

<a id="s03-01-h8"></a>

#### 有限终止

Rᵢ 单调增加且包含于 U₆。每个增长轮至少新增一个编码，最多 N₆ 个编码；首次没有增长后，按相同规则以后也不会增长。因此不超过 N₆ 次扩展就停止。每轮的操作种类、参数及输入对都有限，局部操作计算有限，故每轮也终止。

配方记录只引用更早轮数的输入，展开时轮数严格下降，所以不会产生循环制造依赖。树可能很大，但有限。有限的每格标签回填不会影响终止。

<a id="s03-01-h9"></a>

#### 可靠性

R₀ 的成员都有第 3 节的合法制造树。假设 Rᵢ 中每个成员可制作，Rᵢ₊₁ 新成员只由合法输入执行一个真实实体操作取得，所以新成员也可制作，并且记录的操作给出相应配方。按轮数归纳，目录没有不可制作的非空成员。

不稳定成员不破坏这项归纳：输入是原操作输出的实物，下一次加工按自身规则重建组并结算即可。游戏没有“物品在进入下一台机器前必须再次稳定”的额外前提。

<a id="s03-01-h10"></a>

#### 完备性

设 T 有任意有限合法制造树。擦除标签，把每个靠近根的结晶节点及其输入子树替换成结果紧图形的种子配方；染色节点在结构上省略。剩余树的叶子都在 R₀，内部节点只使用第 4 节列出的操作。

按这棵树的高度归纳：叶子出现在第 0 轮；一个或两个子结果都已出现时，某个后续轮会遍历该节点的真实操作及真实输入对，因此其输出也出现。二输出机器选择的两个出口均已列入规则。根 T 必在有限轮出现。

所以算法对每个可制作 T 必返回配方。若目录停稳仍无 T，却假设 T 可制作，上一段会推出 T 应出现在已封闭的目录中，矛盾；否定结果也正确。

<a id="s03-01-h11"></a>

#### 标签覆盖

物理连接、融合与下落不依赖普通种类或颜色。把最终标签沿保留格来源向基础叶子和紧图形种子传递，分别选择相应普通原料及逐格晶体颜色，就得到目标的完整标签。所有删除格的标签任取合法值。因此结构完备性提升为带合法标签的完备性。

综上：

> Synthesize6 对每个非空六象限五层目标有限终止；它返回合法制造树，当且仅当该目标可制作，且树的输出逐格等于目标。

<a id="s03-01-h12"></a>

### 6. 这套方法完成了什么

这是六象限五层的一种完整合成方式，终止、正向配方正确性和反向覆盖全部历史均已给出证明；不再等待三列半形局部分类或错误的 K 闭包前提。

其规模上界达2^60−1个结构状态，不能称为实用求解器。条件Stack分支上界为`37M_add + M_pre + (M−M_add−M_pre)M`，M_add是K_add成员数，M_pre是其外一次结算后进入K_add的成员数；[推导与适用边界](04-stacking.md#s04-04)。没有证明两类成员占比或整体复杂度足够小。Python已有这个条件候选接口，尚未实现完整六象限目录求解。未运行目录计算、未统计实际可制作状态数，也不把搜索预算耗尽当作不可制作证明。

在这个明确的有限搜索构造意义下，六象限阶段的理论目标完成。下一步进入[一般参数研究](../papers/general.md)：研究哪些结构约化可跨参数保留，以及如何避免这个最坏状态规模；一般局部性质仍须区分偶数/奇数切割约定和具体操作实例。

## 03-02 六象限五层：无针悬空环与不稳定的可制作输出

原文标识：`6q5l/non-k-half.md`。

本页给出从合法基础原料出发、全过程输入和输出都不超过五层的构造：半切可以把 K 中的可制作图形变成不属于 K 的三列半形；两份这样的半形交换拼合，还会得到可制作但不稳定的输出。因此四象限的 R⊆K、全局稳定性及其据此取得的约化不能直接移植。

采用本目录模型：六列按环相邻，允许单象限旋转，半切保留连续三列，基础输入为任意无晶体单层。N/P/C 分别表示普通块、针和晶体。层号从底部 1 开始；以下是源码规则下的人工构造，没有执行仿真或游戏。

<a id="s03-02-h1"></a>

### 1. 独立原料列

分别制造以下三列，其他列全空：

| 列 | 从底到顶的内容 |
|---|---|
| q0 | C N C C C |
| q1 | C |
| q5 | N P N N N |

N/P 列逐格堆叠。任意连续 N/C 列可用五列辅助 N，逐层加入目标 N 或 P、在 P 层结晶取得；再半切保留 `{q4,q5,q0}` 和 `{q0,q1,q2}`，交集仅为 q0。辅助列没有晶体，目标柱连续触地，两刀不会改变目标柱。旋转可取得其他朝向。

先交换拼合 q0、q1：把两份输入分别保留在 `{q4,q5,q0}` 和 `{q1,q2,q3}` 一侧。再把得到的 q0/q1 片段保留在 `{q0,q1,q2}`，与独立 q5 列保留在 `{q3,q4,q5}` 拼合。得到 S：

```text
       q0 q1 q2 q3 q4 q5
L5      C  .  .  .  .  N
L4      C  .  .  .  .  N
L3      C  .  .  .  .  N
L2      N  .  .  .  .  P
L1      C  C  .  .  .  N
```

所需切割轴由共同旋转输入、交换后旋转回去取得；不要求机器有额外切割模式。S 的各组均能沿支撑到地面，故 S∈K。

<a id="s03-02-h2"></a>

### 2. 第一次切割：留下悬空晶体柱及辅助针列

对 S 半切保留 `{q4,q5,q0}`。q1 的地面 C 被切掉，同一融合分量中的 q0 地面 C 连带消失。q0 第三至第五层晶体被第二层 N 隔开，不属于该融合分量。

q0 第二层 N 与 q5 同层 P 不粘连，失去下方 C 后落到地面。上方晶体柱及 q5 第三至第五层 N 属于一个组，被 q5 第二层 P 阻挡；P 又由 q5 地面 N 支撑。得到 A：

```text
       q0 q1 q2 q3 q4 q5
L5      C  .  .  .  .  N
L4      C  .  .  .  .  N
L3      C  .  .  .  .  N
L2      .  .  .  .  .  P
L1      N  .  .  .  .  N
```

A 是占据 `{q4,q5,q0}` 的可制作半形，仍属于 K。晶体下方的空第二层没有通过把保留晶体抬高再落下取得。

<a id="s03-02-h3"></a>

### 3. 制造另一半并拼合

仅用无晶体基础块依次制造 B：

1. q3 单格 N 作为第一层原料。
2. 再堆 q3 单格 N，落到第二层。
3. 堆 q1、q2、q3 三格相连 N，因 q3 列顶为 2，落到第三层。
4. 堆 q2 单格 N，落到第四层。
5. 堆 q1、q2 两格相连 N，因 q2 列顶为 4，落到第五层。

B 占据 `{q1,q2,q3}`，与 A 的半面互补。合法交换拼合得到 U：

```text
       q0 q1 q2 q3 q4 q5
L5      C  N  N  .  .  N
L4      C  .  N  .  .  N
L3      C  N  N  N  .  N
L2      .  .  .  N  .  P
L1      N  .  .  N  .  N
```

第三、第五层的帽形 N 和 q0 晶体柱属于大组 G；第四层 q2 的 N 是独立组 B0。G 与 B0 互相阻挡，但 G 同时通过 q5 的针列及 q3 的普通列取得地面支撑。因此 U∈K。

<a id="s03-02-h4"></a>

### 4. 第二次切割：得到非 K 半形

对 U 半切保留 `{q0,q1,q2}`。被切掉的 q3、q4、q5 没有晶体，不引起任何晶体融合删除。留下：

```text
       q0 q1 q2
L5      C  N  N
L4      C  .  N
L3      C  N  N
L2      .  .  .
L1      N  .  .
```

记此半形为 H。其非地面组只有：

- G：q0 第三至第五层晶体，加上第三、第五层 q1/q2 的 N。
- B0：第四层 q2 的单格 N。

G 的第五层 q2 格被 B0 阻挡；B0 被 G 的第三层 q2 格阻挡。两者互相阻挡，均不下落，晶体全部保留。地面 q0 的 N 与 G 之间隔着空第二层，不提供直接支撑。

因此 H 稳定且可制作，但 G↔B0 的支撑环不经过地面，也没有顶针，H∉K。这给出：

```text
U ∈ R₆,₅ ∩ K
Cut(U) = H ∈ R₆,₅ \ K
```

制造中最高原料和中间结果均为五层；没有借用更高层上限。它与一般模型的八象限八层反例是不同构造。

<a id="s03-02-h5"></a>

### 5. 再拼合两份半形：得到可制作但不稳定的输出

分别制造 H 和旋转三个象限的 H′。H 占 q0～q2，H′ 占 q3～q5。交换器先分别切出两侧：各自只切掉空列，原支撑环仍在，两个半形均保持原位。然后拼合，并且不再执行重力，得到 V：

```text
       q0 q1 q2 q3 q4 q5
L5      C  N  N  C  N  N
L4      C  .  N  C  .  N
L3      C  N  N  C  N  N
L2      .  .  .  .  .  .
L1      N  .  .  N  .  .
```

第三、第五层的跨边界接触把两个外组 G、G′ 粘在一起；第四层 q2 的内块接触 q3 晶体，q5 的内块接触 q0 晶体，所以两个内块也被吸收。按 V 的当前格位重新分组，第三至第五层全部成为一个非针组。

这个组最低在第三层，第二层全空，没有地面格，也没有任何外部直接阻挡。因此下一次触发重力时它必开始下降，所有晶体随即碎裂。V 是交换器的合法非空输出，却在重新分组的意义下不稳定。

这独立证明了六象限五层的“全部可制作图形稳定”为假。不能在交换输出后擅自增加一次重力，也不能把不稳定格位从可制作目录中排除。

<a id="s03-02-h6"></a>

### 6. 对六象限合成的约束

上面的两个构造分别否定六象限五层中的 R⊆K、半切输出必属于 K，以及全部可制作输出稳定。它们没有证明每个非 K 下料都不能拆分堆叠；这里只撤回四象限全局约化的适用依据。

算法若把 K 或稳定性当作全部可制作目标的必要条件，就会错误拒绝 H 或 V。下一次加工对 V 重新分组并碎晶，也使“可制作下料始终原位保留”的全局假设直接失败。

[六象限统一合成算法](#s03-01)因此保留真实双输入堆叠和原始操作输出，不按 K 或重新分组稳定性筛除状态。这个选择有明确的合法反例依据。

## 03-03 任意层角的列条件与三列释放构造

原文标识：`general/angle-synthesis.md`。

本页研究一个主列能否制成可供后续拼装的角。采用偶数象限n、全过程高度上限H、任意无C单层供料、已界定晶体颜色及现有局部加工规则。层号从0开始，N/P/C/空分别表示普通格、针、晶体和空位。

**结论：对所有偶数n≥6、H≥2，非空主列可配一根相邻N/P助手制成角，当且仅当满足下述列条件A。** 充分性使用同一套三列释放构造；多个间隙、落地和中途停止只改变辅助料参数。四象限五层也有相同充要条件，由[直接释放与参数化顶破](02-four-quadrants.md#s02-03)证明；四象限任意层须改用更强的[完整S列判据与构造](02-four-quadrants.md#s02-11)，不能直接沿用A作为充分条件。

这是角的结论，不是任意全图的完整求解定理。指定助手的两列角、存在某个助手的主列，以及全图，是三个不同的问题。这里先解存在助手的主列，再给稳定两列角的合成推论；三列以上的无针支撑环不能强拆为互相独立的稳定两列角。

<a id="s03-03-h1"></a>

### 1. 不按完整列字串分类的必要条件

把主列补空到H格，定义A：

1. 非地面P正下方非空。
2. 最高C以下的P全部属于从地面开始的连续针前缀。
3. C正下方若为空，向下最近的非空格必须是N。
4. 同列相邻两颗C之间若有空位，则中间至少两个N，且下方C紧邻的上一格非空。

条件1来自针独立成组及直接阻挡；条件2、3见[通用列不变量](01-foundations.md#s01-01)，条件4见[晶体间隙不变量](09-sources.md#s09-02)。这些必要性证明不依赖五层、四象限、支撑必须触地或不存在循环。颜色不改变连接关系，但制造时必须保留目标标签。

A可以顺列扫描判定：记录针前缀、最近非空格、上一颗C、其后的N数量和是否出现空位。它检查局部关系，不匹配长度H的完整字串。后面的构造证明A在n≥6时也充分。

<a id="s03-03-h2"></a>

### 2. 四列工作位置与两次半切

固定主列M在q0，最终助手F在q1，临时近支撑A在q(n−1)，切除触发列E在q(n−2)。令h=n/2。最后只保留M、F。

先把M/F放在半面{q0,…,q(h−1)}，把A/E放在互补半面，用Swap拼合。第一次Cut保留从q(n−1)开始的h列：包含A、M、F，排除E。第二次Cut保留从q0开始的h列：包含M、F，排除A。

n≥6恰好保证第一次半切容纳三个工作列。更大n的其余列为空，所需工作列数不随n增加。镜像后同样成立。四象限的半面只有两列，不能直接执行这一步；这只证明本构造需要三列工作空间，不证明四象限目标不可制作。

<a id="s03-03-h3"></a>

### 3. 一次扫描产生辅助料

设c是最高目标C的层号。若没有C，令c=−1；以下区间为空，仍可使用同一供料与切割流程。

<a id="s03-03-h4"></a>

#### 3.1 把待下落N移到间隙顶部

对每颗正下方为空的目标C_r，记最近下方N的目标层为m。把该N的来源位置改为s=r−1，并清空原m。记录映射s→m。目标中m与r之间全空，所以不存在覆盖另一目标格的问题。不同C的这些区间互不重叠。

保留所有其他目标格，将0至c内剩余空位填成牺牲C。这些填充位置组成若干连续区间[a,b]。每个区间的上端b+1都是N：原来C下有空隙时，刚放入的来源N负责隔断；其他空段的上端也只能是N。

填充C不与保留C竖直相连。向上由上述N隔开；向下若有保留C，条件4保证其上一格是N，且另有一个N可作为上方间隙的移动格，不能把唯一隔断移走。底部针前缀保持；整个0至c前缀连续，且内部无P。

<a id="s03-03-h5"></a>

#### 3.2 远助手托住保留格

F的H格默认全部为N；仅在每个来源层s改为P。

F始终是连续触地N/P柱。主列的未移动N及保留C都接触F的同层N，因此保持原位；来源层s的N接触F的P，不能粘上F，保留释放自由度。c以上的普通格也都接触F的N；目标P按条件1受同列直接支撑。

<a id="s03-03-h6"></a>

#### 3.3 近支撑决定落点

A的H格默认全部为N。对每个牺牲区间[a,b]：

- 若b+1=s是一个记录的来源层，把A的m至b改为C。
- 否则只把A的b改为C。

E逐层使用与A相同的N/C材料。A、E都是连续触地N/C柱，可独立制造或共同逐层结晶；其晶体不与任何保留的主列C水平相连。每个主列牺牲区间都接触至少一格A的牺牲C，每格A的C都接触E的C。

这里的两种区间赋值只确定同一释放程序的删除掩码。制造阶段及切割次数不随区间类型或数量增加。

<a id="s03-03-h7"></a>

### 4. 辅助料本身可制造

主列的连续前缀满足独立柱制造条件：先制N/C核心，再补触地针前缀。随后由低到高追加F及主列c以上的N/P。F逐层有正下支撑；主列后缀N通过同层F获得支撑，后缀P由条件1保证。整个准备过程不需要悬空晶体原料。

A/E为同层同色的连续N/C两列，可以使用[共同逐层结晶](#s03-06)制造。准备各支路及拼合时，所有独立柱都连续触地，主列后缀已有F托住，所以Swap预先半切不改变输入。

所有中间产物的高度不超过H。没有顶破；制造主列底针前缀时的Pin不触顶。供料、Stack、Crystal、必要的底针Pin以及固定次数的旋转/切割/交换，足以构成真实制造树。

<a id="s03-03-h8"></a>

### 5. 第一次半切的精确效果

切掉E，晶体融合删除移走A的全部C及主列的全部牺牲区间。没有保留C连接到它们，故目标C不被删除。

F保持连续触地，主列的所有未移动N/C仍由F保持；P的原支撑保持。下面证明近支撑的落点，不能只假设它能停在所需高度。

对牺牲区间[a,b]，若a>0，其下方主列格不会是即将移动的来源N：移动来源的上一格必是保留C。该下方格若为N/C，就由F保持，A在a−1的N与它粘连；若为P，则属于地面针前缀，其旁的A从地面连续为N。因此A在区间起点以下有固定支撑；a=0时直接使用地面。

对于来源区间，A的[a,m−1]为连续N，由上述支撑保持；[m,b]为已删除的C。主列和A在s=b+1的两个N构成同一水平块。它不接触F的非针格，故能够下落。其主列下方最高障碍不高于m−1；A列下方最高障碍恰为m−1（m=0时为地面−1）。落点为

`1 + max(主列可用列顶, 近支撑可用列顶) = m`。

故落地m=0和中途停止m>0使用同一公式。新接触在本次下落中不重新合组，也不需要它来停止水平块。

对于非来源区间，仅删除A的b层C；其下N由低处支撑，b+1层N与主列的固定N粘连，故上方不会塌落。

不同牺牲区间之间的保留N/C恢复固定支撑，前一个区间的删除不会累积成后一个区间的额外下降。沿区间从低到高归纳，全部来源N精确回到目标m；其余主列格均不动。第一次Cut后主列已经等于目标。

<a id="s03-03-h9"></a>

### 6. 第二次半切与充要结论

第一次切割后A不再含晶体。再次Cut去掉A，不会融合删除主列晶体。回到m的N此时接触F在m的N：m不是任何来源层，因而那里没有隔离P。重新分组后这些N与F相连，故切掉A也不会再次下降。其他主列格的支撑同样保持。

最终得到精确目标主列和相邻N/P助手F。无C列、没有间隙的列、多处间隙及不同落点均按同一过程处理。必要性已由第1节给出，因此：

`存在相邻N/P助手使主列可制作 ⇔ A`，适用于偶数n≥6、H≥2。

材料参数可以O(H)扫描产生，制造表项数为O(H)，另外固定次数的净旋转在大n中可能需要O(n)原生单格旋转。每份独立柱/并行两列最多两物品槽；M/F准备支路至多三槽，A/E并行支路至多两槽，合成一个角至多三槽。两个完整角拼合至多四槽。完整中间图形的序列化大小不等于O(H)，也不能把制造表项数当游戏建筑数。

例如九层主列`-N-CN-N-C`满足A，其中两个来源映射为2→1、7→6。准备主列为`CCNCNCCNC`；F为`NNPNNNNPN`；A和E均为`NCNNNNCNN`。两处近支撑分别留下第0层和第5层作为落点下方障碍。一次释放让两格N分别回到第1、6层，不需要为这个九层组合增加模板。

<a id="s03-03-h10"></a>

### 7. 循环支撑按结构判断

两列角中的同层非针格必互相连接，因此两个不同非针组的高度区间不重叠。不同非针组之间的直接支撑只能向更低区间；通过一串针到达另一个非针组时，也只能到更低区间。因此，两列支撑环只能从某个非针组G，经同列一串针，再回到G。

若针链长k≥1，位于a至b层，G在该列同时占a−1和b+1层。G要绕过这些针连接上下端点，只能沿另一列跨过每个层间；竖直连接只存在于C/C之间。因此另一列必须有从a−1到b+1的k+2颗连续C。反之，这个C脊和同组上下端点恰好组成`G→针链→G`，可以形成悬空支撑。端点必须为非针；在可制作列中，上端点进一步由Q限制为N。

k=1就是三颗连续C对应一根针，局部结构如下（上方为较高层，底端N/C与顶端N属于右侧晶体连接的同一组）：

```text
N    C
P    C
N/C  C
```

这个必要性只针对两列中的这种支撑环，不是所有宽图形的通用三C下界。三列以上允许无针环，见[宽半形构造](01-foundations.md#s01-04)。

一般支撑判定仍使用原始最大粘连组：每个非地面组必须至少有一个不同组的直接阻挡。也可反复剔除既不触地、又没有剩余支撑边的组；全部组都保留当且仅当图形静止。环是合法的保留原因，不能用“都能到地面”的条件替换。

<a id="s03-03-h11"></a>

### 8. 指定两列角，包括含晶体助手

给定只占相邻两列的稳定目标T。在n≥6、任意H下，T可制作当且仅当两列各满足A。

必要性仍为列不变量。充分性分别用本页通用构造制造两根目标列，把N/P助手朝向目标外侧。用Swap保留两角完整列并拼合，然后用两个半面的交集切出目标两列。

中间去掉一侧助手时，T本身的地面或含针环支撑仍成立：两列非针组高度区间互不重叠，所以T的支撑环必含P；增加另一侧N/P助手只可能合并非针组，不能吞并针节点和含针环。最后去掉另一侧助手后，T稳定性保证不下落。两根助手都无C，整个拆助手过程不触发目标晶体融合删除。

这允许目标的另一列包含晶体，包括第7节的循环支撑结构。它不意味着含C助手可以随时删掉：上述证明把两根指定目标列都作为成品保留，只删额外生成的N/P助手。

<a id="s03-03-h12"></a>

### 9. 实现与尚未闭合的部分

Python入口为`CornerBuilder.build`；n≥6采用高度参数化的三列释放，4q5l采用直接释放与由r/m生成的统一顶破。指定稳定两列角由`CornerBuilder.pair`生成；它使用同一列构造两次，而不是新增循环支撑专用配方。失败分清列必要条件、目标稳定性和供料边界，未覆盖的全图仍不能判不可解。

四象限任意层的[完整S列构造](02-four-quadrants.md#s02-11)已用递归弱落、三连晶环及一次顶针批量恢复闭合；其判据包含额外的底部资源或递归终点条件。现有[直接释放](02-four-quadrants.md#s02-15)实现仍是其中的局部分支，尚未接入全部新构造。N/P助手可先接纯N柱再去旧助手，所以两种助手要求在存在性上相同；不能把n≥6的A充要判据直接照搬到4q。[递归外侧脚手架](#s03-04)进一步把H_k、V_k及多晶体列环接入通用角和双半形入口，并在六象限覆盖原稳定两列角；无法固定方向剥离的半形及完整全图分解仍开放，本页两列定理没有代替这些缺口。

一代[闲鱼TMAM](../../../shapez1_tmam/xianyu_20221129/logic.md)使用七种制件模板及四种拼装顺序，载荷和朝向是参数。这提供了按加工机制组织实现的参照；不是二代需要或最多只能有七类的证明。

研究依据为逐步制造、融合隔断、精确落点及支撑图证明，以及对应源码静态核对。没有运行枚举、图形探针或游戏；没有据此生成新电路或声称建筑数量下降。

## 03-04 递归外侧脚手架：用同一个角程序制造多晶体列半形

原文标识：`general/scaffold-halves.md`。

设n=2k≥6、H≥2，目标半形T仅占q0至q(k−1)，所有目标列满足A，晶体供料在已确认范围内。以下给出逐列转交支撑的充分构造；允许含针环和无针环，不要求属于K。它覆盖原来“晶体只在一根边列”的脚手架方案，并在六象限覆盖旧稳定两列角入口。

<a id="s03-04-h1"></a>

### 1. 统一的剥离步骤

固定从左端剥离。对当前标准半形U：

1. 检查U自身的全部组静止。支撑环按最大静止集合保留，不能替换为地面可达检查。
2. 若U不含C，用通用逐层N/P程序制造，结束分解。
3. 否则记下q0列，保留q1至q(k−1)原格，在qk补一根H层全N柱，得到下一级脚手架V。
4. 把V旋转−1回标准半面，重复相同步骤。

每步只删除一根原目标列，并在另一端添加全N柱；固定方向不会再次删除新加柱，直到原目标的k列都已删除。所以至多k次剥离后必然没有C。中途任一半形不静止，这个方向失败；再从右端按对称过程尝试一次。右端版本删除q(k−1)、在q(n−1)补全N柱，再旋转+1归一化。

程序只保留至多k个目标半形作为恢复参数，没有逐图形模板，也没有任意状态闭包或二叉分支树。失败仅表示两个固定方向均未覆盖，不表示目标不可制作。

<a id="s03-04-h2"></a>

### 2. 反向恢复的归纳证明

假设已经制造下一级脚手架V。把它旋回q1至qk的互补半面。

使用[通用角构造](#s03-03)制造所记q0列及q(n−1)的N/P助手，得到A。因为该列满足A，任意H都能取得真实基础料配方。A位于{q(k+1),…,q(n−1),q0}，与V互补。若原q0列为空，直接跳过A。

交换A与V。两份输入分别稳定，而且各自在被选半面以外没有格，预切不会改变它们。交换后，目标区域恰好是当前U；两个外侧助手q(n−1)、qk均只含N/P。随后半切保留q0至q(k−1)：

- 删除侧没有C，所以任何目标晶体融合分量都未被切断。
- 保留侧格位恰好为已检查静止的U，所以全部组不移动，包含无针环在内。

得到U的制造证书。由无C基例反向归纳，恢复全部阶段，最终制造T。右端版采用同样的互补半面与去助手步骤，不需要反射机器。

<a id="s03-04-h3"></a>

### 3. 原单边晶体方案被完整覆盖

原方案要求T稳定、C仅在左边列、其余N/P加右外侧全N柱后稳定。新过程第一步恰生成那个普通脚手架，第二步即进入无C基例；恢复步骤相同。右边列同理。因此原H及整个[H_k族](01-foundations.md#s01-04)无需另一条制造路径，原通用H/V配方的加工树保持。

新过程进一步允许脚手架自身含C，只要继续转交后能到达普通基例。每次恢复仍调用同一角制造、交换及去助手程序。

<a id="s03-04-h4"></a>

### 4. 六象限旧两列角入口也被覆盖

三列半形中，若目标只占q0/q1，则先从空的右边q2剥离。下一级是左侧全N柱加原两列目标，归一化后仍为三列。

给稳定两列角外加一根全N边柱，不会合并两个旧非针组：每颗新N只在同一层接触一个旧列，竖直N不粘连。因此旧组间支撑及含针环保持；新柱自身由地面逐层支撑，全部格静止。

继续从右端剥离原q1后，剩下原q0及两根全N柱。所有非针主列格都在同层接到相邻全N柱，P的正下支撑由列A保证，故仍静止。再剥离原q0就进入全N基例。q1/q2目标从左端开始，单列目标也包含在内。

所以任意H下，六象限稳定相邻两列且各列A的目标都由这个过程覆盖。`Constructor.half`在六象限删除独立pair分支，统一使用`supported_half`。四象限仍使用它自己的完整半形构造；八象限以上的内部两列可能两端都有空列，尚未证明固定单方向剥离覆盖全部pair，因此保留原pair入口，不无证删掉已知覆盖。

<a id="s03-04-h5"></a>

#### 共用两列扫描，省去后续三列分组

六象限第一次剥离以后，三列中的一根边列必为完整N柱。另两列仍满足列A。把它们暂看成两列网格：每颗外侧N只接触一列的同层格，不能合并两个旧非针组；旧两列非针组的高度区间互不重叠。

外侧N柱与各旧组连接后的组仍按高度区间排列。每组在N柱的最低占用行，若不触地，其正下方N必属于更低区间或独立单层N，故所有与该柱相接的旧非针组都取得地面支撑。没有相接的旧组则必须继续满足原来的直接阻挡条件，针仍要求自身正下方非空。

因此沿用`stable_half`的层区间扫描，只需把“该区间包含靠助手侧的非针格”加入支撑标志，就与完整三列静止判定等价。实现参数为`supported_column=0/1`；默认None保持原两列判据。六象限根目标仍作一次完整支撑检查，两个剥离方向的后续阶段复用两列扫描，不再求三列组图。没有借此取消任何真实支撑条件。

<a id="s03-04-h6"></a>

### 5. 含两根晶体列的无针环

取五层三列半形W：

```text
层号   q0 q1 q2
  4     C  N  N
  3     C  .  C
  2     C  N  N
  1     .  .  .
  0     N  .  .
```

它把H内侧N改成C。q0三C和上下N帽构成外组G，q2第3层C是另一个组B；G的上帽被B阻挡，B又被G的下帽阻挡。两组互相支撑，不需要针，也不通向地面。各列满足A。

从左剥离q0后，q2的N/C/N接到新增全N柱，q1的两个帽格也通过q2支撑，脚手架静止。再剥离q1，剩下q2目标列及全N柱，仍静止；最后剥离q2进入普通基例。由同一反向流程取得W，再拼两份W得到[完整多晶体列双环](../../examples/6q-multicrystal-loop.md)：231步、5槽。

这个输入没有专用代码分支。原单边C条件无法接受W；新过程通过三次同一支撑转交完成。两半拼出的完整目标可以不稳定，最后交换后直接输出，不额外结算重力。

<a id="s03-04-h7"></a>

### 6. 实现、成本与边界

`CornerBuilder.supported_half`先检查供料与列A，按左右固定方向生成有限阶段；只有取得静止的无C基例后才反向准备各角。`Constructor.paired_halves`共用这个半形入口，缓存已完成半形，再拼出完整目标。没有把整个六象限目标的稳定性设成必要条件。

每个方向至多k+1次支撑检查，每个被接受半形至多k次角调用和k次拼合/去助手。支撑检查用既有分组实现，不能把这个循环次数当作总计算量。无C基例至多两槽，角至多三槽；按子树槽需求调度，单半形至多四槽，两半形至多五槽，均在六槽指令协议内。新过程用循环参数复用工序，不随C列数增加制造核心。

统一入口可能明显增加简单图形的步骤。独立柱/矩形制造仍是角程序内部使用的共用基础模块；机制示例直接调用对应基础模块，不能用其短配方步数冒充完整统一入口的时间成本。尚未生成六象限完整求解电路，不能从删掉一个Python分支推算建筑节省。

本过程仍是充分构造。稳定及列A不保证任一固定剥离方向都能保持中间支撑，完整六象限尾部也尚未约化。当前失败保留None/unknown；继续研究更一般的支撑转交与尾部覆盖，不按新反例逐个增加配方模板。

证据为人工归纳、源码静态核对和固定配方产品导出；没有测试、参数枚举、完整搜索或游戏验证。

## 03-05 两象限任意层数的直接合成判据

原文标识：`general/two-quadrant-synthesis.md`。

主定理采用n=2、H≥2、单象限旋转、等分半切及既有物理规则；H=1另由下述单层构造处理。普通标签及晶体颜色遵守既定供料前提。本文给出完整的必要充分条件及直接制造方法，不通过完整状态目录判定。

层号从0开始。对含C目标T，令h为其最高C的层号，T≤h为保留0至h层的原格位前缀。下列条件当且仅当T可制作：

1. T按当前格位重新分组后稳定。
2. 每列满足[针前缀不变量Q](01-foundations.md#s01-01)：有C在上方的P必须属于触地连续针前缀。
3. T≤h的每个非空列都从地面连续占用到它在该前缀内的最高格。

目标无C时，仅需条件1。含C时，条件3约束的是全图最高C以下的两列，不只是每列各自最高C以下。它允许较短列在h以下结束，也允许h以上的普通块跨列支撑形成空隙。

<a id="s03-05-h1"></a>

### 单层边界：任意偶数象限都可直接制造

H=1时，任意非空、标签合法的单层目标都可制造，且不需要Pin。对每个非空目标列，N/P直接取单格基础料；C则取该列为P、其他列为N的基础层，结晶后以两个半面相交于目标列切出单C。两象限只需一次切割。辅助列没有C，不发生目标C的融合删除；全部格触地。

再把单列逐步拼成两个连续半面，最后Swap合并。每次预切只丢空列，内部目标C不被切断。全程只占一层，允许逐列不同合法颜色。因此两象限的正整数层数范围也包含H=1；一般偶数n的单层问题同样完整解决。此构造不依赖一层上限时Pin的特殊语义，Python Rules仍保持H≥2的现有配置边界。

<a id="s03-05-h2"></a>

### 1. 两列几何保证可制作输出属于K

任一非针粘连组的高度范围是连续区间。如果相邻两列中两个不同非针组的高度区间重叠，它们在共同层只能重叠或水平相邻，都会属于同一组。因此不同非针组的高度区间不相交，彼此直接支撑边严格从较高区间指向较低区间，不可能组成无针环。

一次融合删除和重力结算中，未移动组仍位于原格位；其支撑只来自其他未移动组或地面。否则，一个移动格要从上方落到固定格正下方，必须穿过该固定格。有限未移动支撑图只能到地面或含针环；移动N/P块再沿向下支撑链接到它们。写回后只合并非针组，含针环和地面路径保持。这正是[两列结算证明](01-foundations.md#s01-12-h3)，没有使用高度上限五层。

对两象限制造树逐项归纳：基础料、结晶属于K；半切只保留一列，其结算也满足上述条件；交换拼合两个K单列，K在非针合并下保持；Pin的融合删除后全部格在H层内，可直接用两列结算证明；Stack用已知的K下料闭包；旋转保持K。因此R(2,H)⊆K，所有可制作输出稳定。

这里没有把同一论证扩展到四象限任意H：四象限Pin保留四列，不能使用两列几何。

<a id="s03-05-h3"></a>

### 2. 保留晶体形成顶破融合屏障

设Pin中某颗C在原第r层保留，故r≤H−2。假设另一个原C位于r层或更低处，却因触顶融合分量而被删除。

该C到原最高层H−1的晶体融合路径，每步只作同层相邻或同列相邻层移动，必经过第r层。两象限在第r层只有两格：路径经过保留C本格，或经过与它相邻的另一列C，都会与保留C属于同一个融合分量。这样保留C也必须删除，矛盾。

所以，只要原第r层有实际保留的C，顶破融合删除不可能删除任何第r层及以下的C。该结论只针对融合删除，不把它混同于之后下落碎裂。

<a id="s03-05-h4"></a>

### 3. 全图最高晶体以下的两列连续性是制造不变量

称条件3为连续性条件。无C图形对此条件不作要求。基础料满足；Crystal输出填满全部列；旋转只换列。半切后的单列是稳定独立柱：其组在一条线上上下排列，不可能有悬空支撑环，所以每个保留格下方连续至地面。Swap拼合两个这样的单列，也满足连续性。

下面只需检查Stack和Pin。

<a id="s03-05-h5"></a>

#### Stack

输入D可制作，属于K，所以旧格不动、旧C全部保持；最高C仍在原层h。原两列在h以下分别是连续前缀或空列。

保留下来的上料只剩单层N块或P。一个同时占两列的N块，必被含最高C的那一列挡在h以上。因此能进入0至h层的新块只能占一列。单列块或单P从上方落到该列现有列顶加一；只要进入h以内，该列已有部分就是连续前缀，追加仍连续。按来源顺序归纳，条件保持。

<a id="s03-05-h6"></a>

#### Pin

设输出仍有C，其最高C在h层，来自原第r=h−1层。由第2节，融合删除没有删除任何原r层及以下C；这些层的N/P也不被顶层裁掉。

原输入的最高C不低于r。按归纳条件，原0至r层在每列都是连续前缀或空列。提高一层，并在原地面占用列补P后，新0至h层仍是连续触地前缀或空列。这些前缀逐列有地面支撑，不会在本次重力中移动或碎裂。

其余格中，能下落的保留N/P仍是单层N块或单P。实际保留的最高C在h层阻挡所有同时占两列的N块，使它们不可能进入h以下；进入0至h层的单列块只会连续接到已有列顶上。因而最终前缀仍连续。若Pin输出无C，条件为空。

这完成必要性：所有可制作目标稳定、满足Q及连续性条件。全图最高C以下某列悬空的N，即使靠另一列C横向托住，也会被条件3拒绝，不能只用稳定性代替制造证明。

<a id="s03-05-h7"></a>

### 4. 满足条件时的直接制造

目标无C时，按既有无C判据逐层制造即可。

目标含C时，先取D=T≤h：

1. 分别制造D的每个非空列。条件3保证连续；Q保证最高C以下的P只在底部前缀。去掉这个针前缀后，至最高C都是N/C，可以用普通辅助列、逐层结晶、半切制造；再Pin补回底针，并追加该列最高C以上的N/P后缀。无C列统一逐层制造。
2. 两列都非空时，用Swap合并两根独立柱。原生半切只删空列，不改变已造柱；只有一列时直接使用该列。得到D，且D通地面。
3. 对目标第h+1层起的各层，准备该层无C基础料并Stack。最高C以上没有竖直粘边，T稳定保证每个水平N块及单P有地面或直接下方支撑。按层归纳，每块恰好落在目标层，低层保留。空层不供料；若其上还有无C格而缺少支撑，早已被稳定性条件拒绝。

得到逐格、逐标签等于T的制造树。各列制造和上方追加均线性扫描高度，配方长度为O(H)，不需要猜测来源高度或遍历上料目录。

每根独立列准备至多2个活动物品槽；保存第一列并准备第二列至多3槽；Swap后逐层追加至多2槽。所以整份构造最多需要3个活动物品槽，不包含控制器和搜索状态。

伪代码为：

```text
Synthesize2(T):
    reject unless T is stable and has allowed labels
    if T has no C: return BuildNonCrystal(T)
    h := highest C level in T
    reject unless both columns satisfy Q
    reject unless each column of T[0:h+1] is empty or a solid ground prefix
    D := independently build and join those two prefixes
    for z = h+1 .. highest occupied level:
        if row z is nonempty: D := Stack(D, Base(T.row[z]))
    return D
```

稳定性、Q、前缀检查和基础构造都由输入网格直接取得。该算法的否定结果来自已证明的必要条件，肯定结果有上述制造证书；没有把局部构造失败当作全局否定。

<a id="s03-05-h8"></a>

### 5. 两象限六层代表

取目标：

`P-Cu:crP-:CuCu:cr--:CuCu:--P-`

最高C在第3层。其0至3层前缀由q0的`P C N C`柱及q1的`N P N`柱构成，两列均连续，Q成立。先分别制造并拼合这两根柱；再加入双N基础层，停在第4层；最后加入q1单P，停在第5层。较短列q1的第3层保持为空，第4层N由同层q0的N及其下方C共同承载。

这说明条件没有错误要求全图逐列连续：最高C上方仍允许跨列支撑造成的空隙。对应[Python导出的逐步配方](../../examples/2q6l-crystal-prefix.md)含18个表内步骤、至多3个物品槽；尚未核对具体两象限Mod或在游戏内复现。

<a id="s03-05-h9"></a>

### 6. 可反馈给其他象限的晶体屏障

对一般n，若某个原第r层实际保留的C集合B满足：每一列要么在B中，要么与B中的某列水平相邻，那么任何从第r层及以下通向顶层的C融合路径都必须接触B。

只要B确实全部保留，这种路径不可能属于触顶删除分量，故第r层及以下没有顶破融合删除。两象限任意一颗保留C自动满足此覆盖条件；四象限的相对两颗C、六象限间隔三列的两颗C也满足。

这只是融合传播屏障。一般宽度下，屏障以下仍可能因其他支撑丢失而下落碎晶，不能直接宣布整个低层不动，也不能据此推出四象限任意H满足K。两象限证明还用了连续列前缀及“双列块必碰到最高C列”，这些条件不能自动推广。

<a id="s03-05-h10"></a>

### 7. 实现边界

`Constructor.construct`现已在n=2、H≥2时接入本页完整判据。无C目标沿用原完整逐层分支；含C目标先检查K（两列几何下等价于稳定性）、最高C以下连续前缀和Q，再由`independent_columns`制造完整前缀，最后`append_noncrystal`追加上层。已通过判据却未生成证书会报告内部错误，不把构造器缺陷当作不可制作。`cu`实体供料仍未界定，保持unknown。

默认入口即可调用，不需要四象限专用的`--complete`：

```bash
python -m shapez2_tmam.synthesis 'P-Cu:crP-:CuCu:cr--:CuCu:--P-' --quadrants 2 --height 6
```

否定例`cr--:crCu`虽稳定，但q1在最高晶体以下缺少地面前缀，按已证必要条件返回unsolvable。这个结论来自制造不变量，不依赖搜索超时。

前缀检查为O(H)，制造指令数为O(H)，活动物品至多3槽。Python还计算并保存每一步的完整图形，不能把指令数界直接当作其总运行时间或JSON大小的线性界。游戏实现使用时序循环读取每层并复用制造模块，不按H复制电路；原生六寄存器指令接口仍仅支持4q5l。

依据为两列组几何、融合路径屏障、制造不变量和直接构造。没有运行目标搜索、枚举、测试、物理探针或游戏验证。

## 03-06 同色晶体层的多列并行制造

原文标识：`general/rectangular-columns.md`。

固定偶数象限n≥2、制造高度上限H≥2。目标T有L≤H层，只含普通格N与已界定颜色的晶体C。各层占用同一个列集合I；I是全圈，或长度w≤n/2的连续环区间。每层的目标晶体至多有一种颜色，普通格的部件和颜色可以各不相同。

这些目标可以按层共同制造，并把多层同色晶体一起结晶，不必逐列结晶、切出再交换。删除不含C的行后，设从下到上的晶体颜色序列有k个连续同色段；全圈只需`2L−1+k`步，至多`3L−1`步、两个物品槽。这个界与象限数无关，但使用既定的“任意无晶体单层可供给”合同，不计算基础料工厂和标签数据的规模。

<a id="s03-06-h1"></a>

### 1. 用同层结晶同时处理多列

对第z层，准备一份完整无空格基础层：

- I内需要普通格的位置，放目标的普通格；
- I内需要晶体的位置，放针P；
- I外放辅助普通Cu。

第一层直接供给，后续层依次Stack到已有完整前缀上。完整前缀每列均连续触地；新层中每个针和普通块都直接受下方支撑，恰好停在z层。

暂不立即结晶，记录当前占位针对应的颜色。继续按相同颜色的目标行上料；夹在中间的不含C的行也可继续上料。当下一份含C行的颜色改变时，先把已有占位针统一结晶，再加入新颜色的占位层。最后把剩余占位针结晶。

不变量为：此前完成的颜色段只含正确N/C；当前颜色段的目标C暂为P，其余是正确普通格；I外始终为Cu。每列始终连续触地，所以跨层占位针也有直接支撑，不会落下。结晶恰好转换当前颜色段的全部P；完整网格没有空位可误填，先前的C也不会变色。逐层归纳，最终I内完全等于T，I外是连续Cu柱。

结晶次数等于k，而不是含C的行数。同色段之间允许有普通层；只遇到另一种晶体颜色才必须先结晶。高度方向只需保存一个待结晶颜色，扫描仍为O(L)。

不能跳过“同层C颜色一致”的条件。结晶核心里不能保留最终所需的针，因为Crystal会把它们一起转为C。共同的底部针前缀及最高晶体之上的N/P后缀可以按第3节接入；其他含针或同层晶体颜色不同的目标仍可走独立列构造。

<a id="s03-06-h2"></a>

### 2. 最后只切除普通辅助列

I是全圈时，已经完成，无需切割。

记I从s开始，宽w，h=n/2：

- w=h：保留从s开始的半面，一次window。
- w<h：先保留从`s+w−h`开始的半面，再保留从s开始的半面。两个半面的交集恰为I。

每次半切都包含全部目标晶体，外部只有Cu，因此不会有目标晶体所属的融合组跨入被丢弃侧。保留列均连续触地，不会下落。两次半切不会移动目标，也不会多出普通辅助格。

一个window最多为旋转、Cut、恢复旋转三个表项；共同制造后最多再加3或6个表项。后续[朝向优化](04-stacking.md#s04-18)可减少旋转。这些数仍是制造表项，不是建筑数量，也不保证大象限原生旋转调用数相同。

若目标完全不含晶体，直接按目标行供料及堆叠即可，不准备辅助列、不切割。

<a id="s03-06-h3"></a>

### 3. 共同针前缀及无晶体后缀

目标从地面到全图最高C仍占用同一个连续列集合I或全圈；最高C以上允许逐层缩小占用集合，每列的N/P后缀必须连续，不能中途空出再出现。对含C目标，先取最底部连续p行、且I内全部为P的共同针前缀；令z为全图最高C的零基层号。移除针前缀后，第p至z行组成核心，它必须满足前两节的N/C与同层颜色条件。第z层以上允许任意N/P组合。

先制造核心并裁好I，再执行p次Pin。核心高度加p等于z+1≤H，因此每次Pin之前的最高占用层至多H−2；没有触顶晶体，也没有融合删除。原核心连续触地，Pin上移后新地面针在I内逐列托住它，恰好增加一行纯针。归纳p次，得到目标至最高C的全部格位。

最后按[通用逐层规则](04-stacking.md#s04-15)供给无C后缀并逐层Stack。核心各列连续触地。后缀中仍占用第z层的每列，在所有较低层都非空，所以每个新增格有正下方支撑，各行恰停在对应层；没有新晶体需要结晶，永久针也不会被转换。后缀可含普通块与针的任意逐格交错。

共同前缀p、核心b、后缀t满足L=p+b+t。若核心有k个晶体颜色段，则全圈配方成本为`2L−1+k−p`；局部角区间另计核心末端的裁剪。所有准备仍至多两槽。没有C的矩形可直接用无C构造，无需划分三个部分。

这一化简不要求每列的最高C相同，但要求核心内没有保留针。不同列的针前缀长度不一致、且较长前缀落入核心时，回到独立列路线；不能为扩大并行域而把这部分针晶化。

<a id="s03-06-h4"></a>

### 4. 与独立列构造衔接

[`Builder.rectangular_columns`](../../synthesis/recipe.py)检查固定占用的矩形核心、连续区间及第3节的前缀与逐列连续后缀条件，满足时生成真实配方，否则返回None。它不是完整可制作性判据。

`dense_column`是宽度1的特例，共用同色段结晶与两刀裁剪；任意N/C单列的连续同色晶体也因此可合并加工。`independent_columns`先尝试整图并行；整图条件不成立时，再分别对原来的两个半面尝试并行。半面失败后，按以下固定规则合并相邻列段：

1. 每列从底到顶取模板：空格、针和晶体颜色原样保留，所有普通部件统一记为N。
2. 在各原半面内扫描模板相同的最大连续段；段长至少2时，用矩形构造共同制造。普通部件和颜色仍从原目标逐格读取。
3. 不合并的单列，以及矩形条件未通过的段，沿用原逐列路径。已有列前缀和新段按原半面边界Swap。

相同模板保证列高、共同针前缀、核心C位置及颜色、N/P后缀相同。若其中单列满足独立列合同，整个段就满足矩形合同。段始于q、止于e，长度不超过半圈；以`q−n/2`为交换起点时，已有半面前缀全部在前侧，新段全部在后侧。每列连续触地，交换结算保持格位。所有成功结果仍属于原独立列制造范围，不改变失败的含义。

模板及段边界只需O(nL)扫描；没有尝试全部划分或建立候选目录。整图、半面和各段所需的完整图形结果仍有自身的n列表示成本。分组只利用模板完全相同这一充分条件；不是最优划分，不保证找到普通行可作通配的所有兼容组合。不能把不连续的列集合误认为可两刀切出的区间。

每份并行子配方至多两槽；两份整体并行半面组合至多三槽。按段拼接的每个半面至多三槽，再拼两半至多四槽，保持原逐列拼接的上界。模板相同使并行段与任一单列具有相同的供料/堆叠消费结构；合并不会增加该段的槽需求。不会为每列分配独立实体加工器。游戏中复用同一个供料、堆叠、结晶控制流程，核心完成后裁剪、补针前缀，再追加后缀；输入解码与存储仍须按n、H计量。

若一段含r≥2个有C列，每列不计裁切的共同成本为M≥2，原单列至少各有两次Cut（n≥4），段内还需r−1次Swap。因此原段至少`rM+3r−1`个非旋转表项。共同制造含裁切最多`M+6`个表项；共同针前缀和相同模板的后缀只做一份。这个比较说明了合并可删除的重复工作，不宣称经过全树朝向优化后的全局最短。纯N/P段则直接用无C构造，省去重复供料与列间交换。

<a id="s03-06-h5"></a>

### 5. 六象限代表

固定三层目标：

`crCucrCucrCu:CucrCucrCucr:cbCucbCucbCu`。

第一层在q0/q2/q4放红晶体占位针，第二层在q1/q3/q5放红晶体占位针；叠好两层后统一红色结晶。第三层在q0/q2/q4放蓝晶体占位针，叠入后蓝色结晶。其余格都是Cu。前两层已有红晶体不会被蓝色结晶改变。

流程为三次基础供料、两次Stack、两次Crystal，共7步、两个物品槽；不需要Cut、Swap或Rotate。两层共用一次红色结晶，避免逐列和逐层重复加工。

[完整代表配方](../../examples/6q-rectangular-columns.md)列出每个中间产物。另给[共同针前缀及交错后缀的五层代表](../../examples/6q-pin-framed-rectangle.md)：在三层核心前加一整行针，后加交错普通格/针，共10步、两个物品槽。

[同秩着色的交错上料](../../examples/6q-colored-summary.md)利用不等高后缀：底层为`CucrCucrCucr`，上层只在奇数列放N。全圈核心共用结晶，再供给并堆入奇数列N，共4步、2槽；不必逐列制造再交换。这个两层族可推广到任意偶数象限，见[证明](04-stacking.md#s04-09)。

证据为上述逐层、裁剪、补针及后缀落点归纳、静态源码诊断及固定配方交付导出；没有运行测试、状态枚举或游戏验证。

## 03-07 相邻象限等宽复制与配方提升

原文标识：`general/sector-replication.md`。

采用相同制造高度上限H≥2。设d≥2为偶数，m≥1为整数，n=dm。把d象限每个格(z,q)复制为n象限同层连续m格(z,mq+j)，0≤j<m，标签完全相同，记此映射为E_m。空产物仍映射为空。

这给出可靠的正向制造方法：d象限目标有配方时，E_m目标也有对应n象限配方。反向不成立为一般推理规则：大机器可以使用打破这些相邻块对称性的中间图形，所以不能根据小目标不可制作，就判大目标不可制作。

<a id="s03-07-h1"></a>

### 1. 分组、静止与下落保持对应

每个非针格的m个副本在同层相邻，属于同一个粘连组。原图两个非针格相邻时，复制后的两组格也通过水平边界或竖直C边相连；反之，复制图中任何跨原格的粘边都来自原图的一条粘边。因此非针最大组一一对应。晶体融合组也一一对应。

一根P复制为m根独立P，不能把它们当作一个水平刚性块。每根副本的正下方都对应原P正下方的组或同序号P副本；原非针组对某根P的支撑边则复制为对该P各副本的相同支撑关系。地面属性保持。

用同步剥离证明静止对应：初始保留全部组；每轮删除没有地面、也没有通向剩余组的直接支撑边的组。非针组是否被删除与原图一致，P的全部副本也同时与原P被删除。归纳到固定点，原静止非针组与全部副本静止格对应，原移动组及P副本也对应。该论证同时适用于有地面及空地面结算，不要求原图属于K或稳定。

移动C碎裂后，每个水平N块扩张为对应水平块，P仍分别下落。同一原列的m个副本列具有相同障碍高度；N块落点是占用列顶最大值加一，复制不改变这个最大值。P副本彼此不共享列，同层的处理顺序可以交换，最终落点相同。按来源层归纳，全部落点与标签保持对应；按相同H截高也对应。因此单次物理结算满足

`Collapse_n(E_m(S)) = E_m(Collapse_d(S))`。

这是单次结算关系，不能在输出后擅自增加重新分组和重力。

<a id="s03-07-h2"></a>

### 2. 每个制造操作的提升

| 原操作 | n象限中的操作 | 原因 |
|---|---|---|
| 无C基础层 | 每个格复制m份的基础层 | 仍不含C，符合既定供料前提 |
| Rotate(t) | Rotate(mt) | 把整个复制块移动t个原象限 |
| Cut出口0/1 | 同出口Cut | n/2=m(d/2)，切线位于复制块边界，不会只切掉部分副本 |
| Swap出口0/1 | 同出口Swap | 两边半切对应，再交叉拼接，不追加重力 |
| Pin | 一次Pin | 顶层及其融合删除对应，地面针按同一占用掩码复制，再应用结算对应 |
| Crystal(color) | 同色Crystal | 每格空/P转换为C，其他标签保持；高度不变 |
| Stack | 一次Stack | 上料均抬高H+1，初始网格复制对应，再应用结算对应 |

对Cut，跨切线的原晶体融合组恰好对应跨新切线的融合组，所以保留侧的连带删除也一致。对Pin，触顶融合组及原地面占用按高度判定，不随横向复制改变。由制造树归纳，每个中间产物都恰好是原中间产物的E_m像。

高度上限必须相同，不能把一个较高上限的准备过程直接搬到较低上限。所有旋转都要按m缩放；不能只重复目标编码而沿用原旋转参数。

<a id="s03-07-h3"></a>

### 3. 从输入图形找复制结构

把目标每一列从底到顶的全部标签作为一个列字。相同只指列字完全相同，包括内部空格、部件及颜色。沿象限环把连续相同列分为若干段，长度为r₁…r_k；取真实段边界为起点。全列相同时起点取0，只记一段长度n。

最大的可压缩宽度为

`m = gcd(n/2, r₁, …, r_k)`。

因为商图仍要求偶数象限，所以m必须整除n/2；又因为每个复制块内的列完全相同，它必须整除每个连续段长度。这两个条件也充分：从段边界每m列取一列，即得偶数d=n/m的商图。m=1时没有这种压缩；m>1时d<n，构造递归严格减小象限数。

压缩图按所选起点对齐。小图配方提升后，再旋转回该起点，得到原输入目标。此识别不搜索格位目录，也不猜测标签擦除后的近似对称。

<a id="s03-07-h4"></a>

### 4. 制造证书可以逐节点变换

`Builder.replicate`读取真实小图配方，把每个中间图形按E_m扩张，旋转参数乘m，其他操作及物品输入顺序保持。根据第2节，无需为每个大图节点重新执行一遍物理结算。扩张后的节点仍包含完整中间图形，末端恢复朝向后必须等于目标。

遍历使用显式栈，不因任意H的深制造树依赖Python递归深度。相同源Recipe对象可以共用变换后的对象；消费式计数仍按每个输入出现次数累加，没有复制实体物品。

不计最后恢复朝向，变换保持制造表项数与物品槽需求；恢复朝向至多增加一个净旋转表项。大象限下Rotate(mt)可能要多次调用单象限旋转设备，表项数不能直接当作原生操作次数、建筑数或游戏耗时。

`Constructor`只在已有直接构造未覆盖时尝试商图，不改变旧成功配方。先尝试最大复制宽度；若还能得到另一份四象限商图，再尝试该商图，以保留四象限角构造的能力。商图由较小Rules、相同H的默认Constructor求解，不自动开启完整四象限搜索。成功提升真实配方；失败仍返回unknown，不把商图的否定结果传给原目标，也不宣称遍历了全部可能商图制造方式。

<a id="s03-07-h5"></a>

### 5. 八象限的间隙代表与边界

取已有四象限单次融合删除代表：

`CuCu----:--P-----:crCu----:--Cu----:--Cu----`。

每个象限复制两份，再整体转一个八象限单位。目标含有带空隙的晶体列，原通用独立柱/前缀构造不能制造该列；压缩后可以调用四象限角构造，再提升其配方。恢复方向还覆盖了复制块边界不从q0开始的情况。

[八象限完整代表配方](../../examples/8q-replicated-gap.md)已由默认Constructor取得证书并经[朝向优化](04-stacking.md#s04-18)导出37个表项、3个物品槽。它使用四象限构造器取得的证书，再直接扩张中间图形；不是在八象限重新执行全部物理来验证证明。

这个族说明一般参数可以复用较小象限的结构构造。它没有覆盖所有大象限图形，也没有证明某个旋转、半切或高度规则不同的Mod自动符合本模型。游戏电路应复用较小逻辑核心和逐格扩张/参数换算模块；具体原生信号转换、存储和时序仍需单独设计。

证据来自组图对应、同步剥离、落点归纳和制造树归纳，没有运行枚举、测试或游戏验证。

## 03-08 完整目标的制造流程与覆盖范围

原文标识：`general/whole-shape-synthesis.md`。

本页按“从任意完整输入目标到成品，需要几套制造流程”整理。角、落点、晶体颜色、切向和循环次数都是流程参数，不另算整图类别。例子目录中的不同机制也不是互斥的目标分类。

<a id="s03-08-h1"></a>

### 1. 当前可以给出的数量

| 范围 | 已证的完整目标处理方式 | 尚不能声称的结论 |
|---|---|---|
| 4q5l | 整图按是否必须尾部Pin分为两类；共用一套主程序：双半形起点 → 追加 → 至多三轮“顶针 → 追加” | 不等于每个目标都能直接切成两个可制作半形；不等于搜索已经足够小 |
| 6q5l | 同一个递归脚手架半形入口覆盖旧两列角、H/V及一族多晶体列支撑环，随后共用双半形拼接 | 尚未证明这套局部构造覆盖全部可制作整图，完整的少类划分数量未知 |
| 偶数n、任意H | n≥6的角和脚手架共用参数算法；4q任意H的S列、半边与[零尾Pin来源](02-four-quadrants.md#s02-14)已有完整判据和构造证明 | 尚无紧凑完整整图分解；有限操作闭包的完备性不代替这种分解 |

这里的“一套”是制造主程序数量；按整图是否必须尾部Pin的划分则是两类，且[两类均非空](02-four-quadrants.md#s02-08)。它们不需要两套工厂，也不是任意图形拓扑分类的最少数证明。4q5l原有尾部定理已经给出这套语法，本次把Python入口实际统一到同一双半形制造入口；不能把改换统计口径本身算成电路节省。

不可制作、供料未界定、局部算法未覆盖是结果状态，不增加制造类。尤其六象限的局部失败必须保留`unknown`。

<a id="s03-08-h2"></a>

### 2. 四象限的四种起点统一为双半形

令B为下列图形：存在一个切向d，目标两侧在各自原层号上都是可制作半形，允许一侧为空。制造B时，只调用同一个半形程序两次，再交换拼接；空侧直接跳过，不向机器送空物品。

旧标准形的起点A包括基础层、紧N/C图形、单半形及双半形。它们全部属于B：

1. 基础层的两个半形都触地，各列满足A，因而可制作。
2. 紧N/C图形切成两半后各列连续触地；半形稳定且各列满足A，因而可制作。
3. 单半形是另一侧为空的B。
4. 双半形本身就是B。

反过来B本就是旧起点允许的拼合。所以替换起点不扩大或缩小覆盖集。按[尾部定理](02-four-quadrants.md#s02-06)和[四次顶针消除](02-four-quadrants.md#s02-07)，所有可制作4q5l目标恰有如下合法配方：

```text
B → S → (Pin → S)^k，0≤k≤3
```

S表示保留旧格的逐层N/P追加，可以为空。无晶体目标也适用：取完整地面层作为B，其余格由S制造。因此完整模式不需要无晶体、紧图形、独立柱、单角等独立的整图制造入口。

这不表示可以直接对最终目标切两刀就完成分解。求解器先求某个B和各段S的参数；有时还须恢复顶针之前的完整图形。A列条件与K并不足以确定整图可制作，[三层反例](02-four-quadrants.md#s02-06-h6)仍成立。

<a id="s03-08-h3"></a>

### 3. 循环次数不成为新的工厂

令Z为能用B→S制造的目标，R为全部可制作目标。Z与R\Z是互斥且完整的两类：前者由两个切向的最小前缀闭包决定，后者必须进入尾部Pin搜索。目标`P---P---:Cu------:crCu--Cu`已证明不在Z，却能一次Pin制造。因此尾部循环不能整体删除；这里的分类是完整目标需要的加工，不是角的分类。

零轮、一轮、两轮和三轮尾部顶针只改变循环次数及各轮追加参数。它们复用同一个Pin入口、同一个S程序和同一组物品槽。这里尚未证明四个“最少顶针次数”集合都非空，也没有把它们列成四个必须分别保留的整图类别。

同理，直接释放和支撑转交顶破是角程序内部的两个工序分支。一份完整目标可以同时使用它们；不能把目标依角类型分到两个互斥类别。

Python的`Solver4.solve`只作共用必要条件筛选，随后进入同一尾部求解。`minimal_start`已经确定切向，`Constructor.paired_halves`沿该切向制造起点，不再重新选择无C或独立柱快捷配方。普通局部`Constructor.construct`仍服务其他参数，不承担完整四象限模式的分类定义。

<a id="s03-08-h4"></a>

### 4. 六象限：同一拼接入口，尚缺完整半形构造

`Constructor.paired_halves`也用于六象限及更宽偶数图形。[递归外侧脚手架](#s03-04)已证明覆盖六象限的旧稳定两列角，所以六象限每侧统一走脚手架，删除独立pair分支。八象限以上的内部两列尚未证明全部被固定剥离方向覆盖，继续保留原pair；不能把六象限的覆盖关系直接外推。

脚手架逐列转交支撑，反向重复调用通用角，只有最后的无C基例使用逐层N/P制造。六象限后续脚手架的三列稳定性也已并入带外侧支撑的两列扫描，不再计算一般三列组图。两份H的V沿用相同双半形拼接。整个V不稳定，但两份输入半形分别稳定，交换输出不再结算重力，因此不需要“失稳整图专用配方”。

这仍是充分构造域：多列晶体在三列半形内相互支撑、普通侧无法独立搭脚手架，以及复杂Stack产生的目标，尚不能全部约化到这里。不能为了得到一个好看的类数，把这些目标标成不可制作，或把完整有限闭包算法叫作已经很小的另一套电路。

### 6. 电路收敛的实际结果与下一边界

4q5l游戏控制器原本已共用双半形和Pin/S循环，最近一次网表更新把角ROM的完整字串识别换成(r,m)落点参数，并把主列顶部N/P与同层助手一起上料。编译结果是压缩网表142463→142255个非线缆建筑，少208个；ROM251→249行。145项状态、六物品槽、816tick周期及关键路径保持。数据见[元件报告](../../reports/README.md)，未重新生成走线。

本轮继续完成尾部必要性证明和六象限递归脚手架，未改游戏网表，以上208是上一轮的收益。

因此，减少分类的方向已经落实到代码，但不能预先承诺“大幅缩小”。当前4q5l主要负担仍是顶针逆像搜索、参数存储和跨门传输；6q5l主要缺口仍是完整半形/尾部的紧凑分解。优先补这两个结构问题，再增加游戏端工序，避免把每个新例子变成一个新电路分支。
