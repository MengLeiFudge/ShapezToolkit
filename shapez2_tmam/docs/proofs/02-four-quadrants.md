## 02-01 四象限五层的统一合成算法与覆盖定理

原文标识：`4q5l/synthesis.md`。

目标是给定任意四象限、最多五层的非空目标 T，输出一棵由基础原料和合法实体加工组成的制造树；如果目标不可制作，则在有限步骤内返回不可制作。本页给出一套确定的算法及其整体证明，不要求先知道目标来自哪条历史制造路径。

基础输入、物理规则及合法标签沿用[覆盖性研究](01-foundations.md#s01-09)。本算法使用有限配方搜索，不承诺搜索规模实用；全覆盖结论由下面的证明取得，不以逐个目标试验取得。本页没有执行搜索、模拟或游戏。

<a id="s02-01-h1"></a>

### 1. 合成结果与允许的配方

一份配方是带输入依赖的有限树。叶子为任意无晶体单层原料；内部节点为旋转、切割并选择一个输出、交换并选择一个输出、堆叠、顶针或结晶。染色可以使用，也可以由标签回填消去。

每个内部节点的非空输入先分别制造，再交给对应机器。相同子配方被引用两次时，生产两份物品；共享证明记录不等于复制一个物理物品。切割和交换不需要的副产物丢弃。空结果只作为搜索中的标记，绝不接入实体机器输入。

目标中的空底层和空中间层保留位置。材料结构记为 N/P/C/空；普通种类及合法颜色在最后回填。

<a id="s02-01-h2"></a>

### 2. 三个无需未知配方的构造宏

<a id="s02-01-h3"></a>

#### 无晶体目标

按[无晶体稳定性条件](01-foundations.md#s01-09-h7)检查每层的水平 N 连通块及单个 P。若通过，从低到高制造这些块：第一个块直接取基础输入，以后的块依次堆叠。底层块直接落地；每个非底层块至少有下一层支撑，且其列中没有高于目标落点的旧格，所以精确落到所需层。

同层不同块占据不同列。四象限五层至多二十块，制造中不超过五层。全空图不产生物品，不调用这个宏。

<a id="s02-01-h4"></a>

#### 任意紧图形

紧图形在高度 h≤5 内全部由 N/C 填满。分别制造四个目标列：

1. 由低到高加入完整基础层。目标列该格为 N 时放所需 N，为 C 时先放 P；另外三列均放辅助 N。首层直接取基础输入，后续层堆叠。
2. 需要 C 的层加入后执行结晶。此前已完成的所有格是 N/C，不受影响；新层仅目标 P 被转为该格所需颜色的 C。
3. 完成该列后，先保留目标列及其一侧邻列，再保留目标列及另一侧邻列。两个相邻半面的交集仅为目标列，因此两次半切切出独立柱。辅助列都是 N，切线不引起目标晶体融合删除；目标柱连续触地，不下落。
4. 用交换器先把相邻两柱拼成两个半形，再拼成整图。每次保留各输入已有格的切线都经过其外侧空区域，不切断目标柱或已拼合半形内部的晶体。

所需方向由合法旋转取得。整条构造均在五层内；不存在从未知的“任意晶体原料”开始的步骤。

<a id="s02-01-h5"></a>

#### 一段基础堆叠

对关系 S(D,T) 使用[四项精确判据](01-foundations.md#s01-11-h5)。通过时把新增格分成水平 N 块及单个 P，按目标层号递增堆入，至多二十次；无新增格则不加工。D 的已有配方作为这个宏的输入。

<a id="s02-01-h6"></a>

### 3. 明确的配方生成程序

以下所有循环采用固定顺序：材料编码顺序、层号顺序、列号顺序、操作参数顺序。并列的合法配方只保留第一次发现的一个；不要求最短配方。

Π 是[精确顶针静态关系](01-foundations.md#s01-13-h4)，C_d 是[精确半切关系](#s02-02-h4)。S、Π、C_d 均由输入格位直接计算，不调用本合成程序来判断中间状态可不可制作。

<a id="s02-01-h7"></a>

#### 第一步：建立带配方的半形目录

标准半形占有序的 q0、q1 两列，原始编码总数 M=4^10。用全部稳定的无晶体半形和空标记初始化目录 H₀；每个非空成员附第 2 节的制造宏。

一次扩展只读取旧目录快照 X，从以下起点生成：基础单层、紧图形、X 中一个半形的旋转，或 X 中两个半形旋转到互补两侧后的拼合。单侧为空时直接使用另一侧，不调用空输入交换。

对每个非空起点 A，遍历所有满足下式的尾部：

```text
A → S → R → (Π → S → R)^k，k=0,1,2,3,4
```

R 有四种净旋转；每个 S 的末端是一个非空四列五行编码，并通过 S 的精确判据。Π 的结果由静态规则确定；任何空中间物品都排除。对每个尾部末端，取四种方向的 C_d，标准化为两列编码。

新半形附上以下配方记录：起点类型、引用的旧目录半形、各 S 的前后图形、Π、旋转和末切方向。引用的子半形必须来自旧快照，不能引用本轮尚未证明的结果。若整轮没有新增编码，停止；否则进入下一轮。至多 M 轮得到 H*。

这一步就是[半形算子 Φ](#s02-02-h6)的具体带证书计算。一次扩展的内部量化虽然很大，但只有有限个四列五行变量，每个最多 4^20 种结构取值，所有关系均有效可计算。

<a id="s02-01-h8"></a>

#### 第二步：为当前目标选择根配方

- T 无 C：直接执行第 2 节的稳定性检查及逐层构造；不通过则返回不可制作，无须建立半形目录。
- T 含 C：完成第一步目录；从上述四类起点遍历同样的有限尾部，选择首个末端恰好等于 T 的结果。
- 所有起点和尾部均未命中，返回不可制作。不能用运行超时、只查部分目录或某个递归分支失败代替这项结论。

<a id="s02-01-h9"></a>

#### 第三步：展开并执行配方

沿选中的根配方展开。无晶体、紧图形和 S 分别用第 2 节宏替换；单半形引用继续展开其记录，双半形分别展开后拼合；其余节点直接使用实体操作。

半形记录的首次出现轮数沿子引用严格下降，故展开不能成环。没有实体步骤要求搜索器猜测一个输入是否可制造：每份输入都已带基础叶子可达的配方。

伪代码把依赖顺序概括为：

```text
Synthesize4(T):
    erase labels, preserving all cell coordinates
    if no crystal:
        reject unless stable
        recipe := BuildNonCrystal(T)
    else:
        H := stable noncrystal halves with recipes
        repeat using a frozen snapshot of H:
            add every new Cut(Tail(Start(H))) with its first recipe
        until unchanged                 # at most 4^10 rounds
        recipe := first Tail(Start(H)) ending at T
        reject if none exists
    assign target labels backwards to base and tight-shape leaves
    expand the labeled macros to primitive manufacturing operations
    return recipe
```

<a id="s02-01-h10"></a>

### 4. 终止性

H 单调增加，最多 M 个编码；一轮不增加以后不会再增加。每轮的起点、尾部及末切选择都有限，局部物理计算也终止，所以目录计算终止。

根配方搜索只遍历有限目录上的有限尾部。子半形每展开一级，其轮数严格下降；固定宏自身长度有限，因此制造树展开终止。即使同一半形需要生产多份，复制的仍是有限树。

可给出一个不依赖实际目标的宽松树界：每条半形规则至多引用两个子半形，每条引用路径长度至多 M；根起点也至多引用两个半形。故半形规则节点总数至多 `2^(M+1)−1`。每条规则除固定种子构造外，至多含一百次有效基础堆叠、四次顶针、五个净旋转和一次半切；双半形起点另加一次交换及朝向调整。

这个巨大上界只用于证明有限，不代表需要实际造这么大的工厂，也不是性能估计。

<a id="s02-01-h11"></a>

### 5. 可靠性：程序输出必是合法配方

对目录首次出现轮数归纳。初始半形有逐层制造宏；固定紧图形有逐列结晶、切出及拼合宏。若子半形已有合法配方，拼合、Π、C_d 和 R 都是合法实体操作；S 宏与原关系逐格相同。因此本轮新增半形也有合法配方。

根配方只引用这个目录、固定种子和已证明等价的尾部操作，故展开后每个输入均可制造，根结果恰为 T。没有将仅满足 K 或 Q/J 的图形直接当作已知原料。

所有写回状态最多五层。真实堆叠内部按源码临时把上料提高到第七层及以上，这是机器本身的计算过程，不是要求另造超过五层的输入物品。

<a id="s02-01-h12"></a>

### 6. 完备性：任意合法制造历史都有本程序可找到的配方

取任意可制作目标 T 的一棵有限制造树 P。这里仅在证明中使用 P；算法输入不需要提供 P。

**无晶体情形。** 四象限五层的 [R⊆K 定理](01-foundations.md#s01-12)保证 T 稳定；无晶体稳定性判据及逐层构造因此接受 T。

**含晶体情形。** 从 P 的输出向前回溯，堆叠沿下料支路，其他单输入操作沿其输入，直到最后一个切割、交换、结晶或基础输入节点。

- 各个堆叠下料均可制作，属于 K；[复杂堆叠约化](01-foundations.md#s01-11-h8)可从同一下料用基础块制造相同输出。因此删除对原上料历史的依赖，不改变结果。
- 结晶节点输出是紧图形，可用第 2 节的构造替代整个较早子树。
- 切割节点输出是独立半形；交换节点输出由两个分别切割结算的独立半形拼成。
- 对这些半形，按原切割/交换节点的严格输入子树继续改写。树的严格子树下降保证改写终止。[半形完备性证明](#s02-02-h8)据此保证它们都在 H*，无须假设半形本身满足某组尚未证明充分的局部条件。

起点以后的尾部只剩旋转、基础堆叠和顶针。任选 T 的一颗晶体，它已经存在于尾部起点，不能下落，每次顶针上升一层，因此尾部至多四次顶针。每两个顶针之间的基础堆叠合并为一段 S，同段旋转归并到段末。得到的正是第二步穷尽的尾部形式。

所以本程序必有一个根候选命中 T，并返回它的合法配方。反过来，若完整有限搜索没有命中，假设 T 可制作就会由上述改写产生一个已遍历的候选，矛盾。程序的否定结果也正确。

<a id="s02-01-h13"></a>

### 7. 标签恢复不削弱覆盖范围

先在材料结构上求配方，再从根向叶子追踪各个保留格的来源，把目标要求的普通种类及颜色传给来源格。旋转、切割、交换、堆叠和顶针都不复制同一个保留格；两个物品输入由两份独立配方生产，不会发生同一物理格被要求同时具有两种标签的冲突。

到紧图形叶子时，用第 2 节的逐列构造制造指定的每格合法颜色；到基础 N/P 叶子时选择相应基础标签。最终删除的辅助格可以任选合法标签。晶体融合与重力不读取颜色，结构路径不变。

因此覆盖的是所有允许的普通种类及合法配色，而非只覆盖统一颜色的材料图。无效晶体颜色不属于本模型的可制作目标。

<a id="s02-01-h14"></a>

### 8. 最终定理及阶段边界

在本仓库已明确的四象限五层规则下：

> 对每个非空目标 T，Synthesize4 在有限步骤内停止。它返回配方，当且仅当 T 可制作；返回的配方只使用合法基础输入及实体加工，且逐格输出 T。

证明依赖已逐项核查的局部规则、K 闭包、堆叠约化、半形文法及以上算法展开。不依赖全量目标枚举的运行结果。它给出一种覆盖全部可制作 4q5l 目标的统一合成方式，因此四象限阶段的理论目标在这些规则前提下完成。

[无需半形目录的完整 Python 尾部逆推](#s02-06)现已实现，由[四次尾部Pin改写](#s02-07)把制造树存在性上界降为616节点。完整电路已接四帧搜索与发令，实用搜索复杂度及实际半形总数仍未取得。[面向电路的简化](#s02-04)给出本算法保持覆盖的局部改写：每段 S 至多五份单层上料、尾部旋转归并及逐列前缀搜索；其中堆叠段已有 Python 实现。对应的[六象限五层理论](../6q5l.md)另行处理三列半形及加工闭包，不能直接套用四象限的 K 结论。

## 02-02 全部两列半形的有限构造判据

原文标识：`4q5l/half-closure.md`。

本文给出四象限五层中，全部可制作相邻两列半形的**精确有限文法、终止界及制造方法**。它补齐[有限阶段定理](01-foundations.md#s01-09-h9)中未定义的完整半形集合 H，并由此给出全图可制作判据。[逐列角构造](#s02-03)进一步给出同一 H 的局部充要条件和无需目录枚举的制造实现。

这里完成的是有限构造判定，不是把所有半形压缩成几条局部材料公式。K、Q、J 及晶体间隙不变量仍只作为必要条件；它们是否能组成更短的充要判据没有在本文证明。无需运行全部图形来证明下列规则的完备性；本文也没有运行枚举或给出可制作半形的实际数量。

<a id="s02-02-h1"></a>

### 1. 状态、方向和空结果

只保留材料结构 N/P/C/空，普通种类与合法配色由[标签替换证明](01-foundations.md#s01-09-h3)恢复。一个标准半形占 q0、q1 两列，另外两列为空；从地面起保留五行，顶部补空，但不删除底部或中间空行。两列是有序的，不能通过镜像去重。

标准半形原始状态全集 U 有：

```text
M = |U| = 4^10 = 1048576
```

任意相邻两列半形用合法旋转映射到标准方向。空状态 ∅ 仅表示切割无产物或拼接的一侧缺席，不要求机器接受一个不存在的空物品。非空结果的制造树不会使用 ∅ 作为实体输入。

记 H_np 为全部无晶体且稳定的标准半形，加上 ∅。逐层检查每个水平 N 块及单个 P：它接地，或有一个格的正下方非空。这是[无晶体充要判据](01-foundations.md#s01-09-h7)，逐层追加即可制造，每个半形至多十个基础块。因此 H_np 是完全显式的种子集合，不调用未知的可制作性判定。

<a id="s02-02-h2"></a>

### 2. 三种有限、已知的关系

<a id="s02-02-h3"></a>

#### 2.1 一段基础堆叠 S(D,T)

要求 D∈K，并满足[连续堆叠的四项判据](01-foundations.md#s01-11-h5)：旧格原位保留；新增格只有 N/P；新增格严格高于对应列的原列顶；仅在新增格中分组后，每个新增水平 N 块或单个 P 接地或被 T 下一层阻挡。

这既是布尔关系，也是至多二十次基础堆叠的构造。允许零次堆叠。固定目标时，D 只需检查至多 6^4=1296 个按列截断候选。

<a id="s02-02-h4"></a>

#### 2.2 一次顶针 Π 与半切 C_d

Π 采用[完整顶针关系](01-foundations.md#s01-13-h4)。它只用输入格位、晶体融合分量、初始支撑图和水平块落点，既不调用半形集合，也不调用逆像判定。

C_d 保留方向 d 的相邻两列：先在完整输入上计算晶体融合分量；凡分量触及被去掉的列，保留侧该分量的晶体也删除。随后对留下的格使用[静止组与落块公式](01-foundations.md#s01-13-h1)，最后旋转到标准方向。方向 d 有四种。没有格时返回 ∅。

这是游戏半切的精确静态关系。融合删除后、重力之前的格全在五层内，落下后不再触发截高。原来的输入可制作时，非空输出就是可独立保留的半形；若输入已经仅占保留侧并属于 K，切割是恒等操作。

<a id="s02-02-h5"></a>

#### 2.3 有限尾部 L

从非空起点 A 开始，允许：

```text
A → S → 旋转 → (Π → S → 旋转)^k，0≤k≤4
```

每个旋转取四个合法朝向。所有中间实体图形都非空并保持五层坐标；若某次加工得到空结果，该分支不能继续供料。把所有这样的非空末端记为 L(A)。这是有限关系：至多四次 Π、五段 S、五个旋转；每段 S 可制造为至多二十个基础块。

这里不把堆叠跨过顶针交换顺序，也不要求把旋转跨过顶针移动。同一堆叠段内归并旋转只使用基础块落点的旋转对称性。

L 可能生成无晶体结果，这没有问题。但“至多四次顶针足够”的完备性依据仅用于**所需末端仍保留晶体**的情形：最终晶体在尾部起点已经存在，且不下落，每次顶针升一层，五层内至多四次。无晶体目标单独使用显式稳定性判据，不靠这个次数界覆盖其任意历史。

<a id="s02-02-h6"></a>

### 3. 起点与递推规则

对任意 X⊆U，定义 A(X) 的非空起点如下。引用 X 中半形时要求它属于 K；K 是可直接检查的支撑图条件，此处不调用可制作性判定。

- 任意无晶体基础单层。
- 任意高度 1～5 的紧图形：每列每层均为 N 或 C。任意此类图形的合法制造已由[紧图形构造](01-foundations.md#s01-09-h5)给出。
- X∩K 中非空半形的任意合法旋转。
- 将 X∩K 中两个非空半形分别旋转到互补的两侧，然后取两侧格位的并集。

最后一项只取保持两列内部顺序的合法旋转，不加入镜像。半形在各自保留侧之外全空、且属于 K，因此交换器的预先切割不会改变它们；格位并集恰好是合法交换拼合的结果。拼接时可能新增横向粘连，但交换器不再结算重力；K 在非针节点合并下保持，故结果仍属于 K。若一侧为 ∅，直接使用另一侧，不需要虚构空物品；双侧为 ∅ 不作为尾部起点。

定义只引用 X 及显式关系的有限算子：

```text
Φ(X) = X ∪ H_np
       ∪ { C_d(Y) : A∈A(X)，Y∈L(A)，d∈{0,1,2,3} }

H₀ = H_np
Hᵢ₊₁ = Φ(Hᵢ)
```

所有集合元素都标准化为 U 中的两列五行编码。特别地，计算 Φ 不需要知道 R 或“任意可制作全图”；它只需要已有半形、固定基础/紧图形、四次以内顶针及五段精确堆叠关系。每个四列中间变量至多有 4^20 个材料编码，变量个数有界，且每个局部关系都有显式判据，所以一次 Φ 也是有效的有限计算；这里没有执行这个计算。

<a id="s02-02-h7"></a>

### 4. 可靠性：递推接受的半形全部可制作

对 i 归纳。

H₀ 中非空半形可按层制造。假设 Hᵢ 中每个非空成员已有合法制造树，那么 A(Hᵢ) 中每个起点都有合法制造树：基础输入、紧图形使用显式构造；单半形使用归纳假设；双半形复制两棵已有制造树后交换拼合。

L 中每段 S、每次 Π、旋转均是已证明等价的实体加工。末次 C_d 是合法切割，故每个新非空成员也可制作。空成员仍只表示没有输出。

因此所有 Hᵢ 都包含于真实可制作半形集合（连同 ∅）。这一步不靠候选图形“看起来稳定”，也不靠 K/Q/J 反推可制作性。

<a id="s02-02-h8"></a>

### 5. 完备性：任意可制作半形都会进入递推

先说明任何有限制造树都能改写成由第 3 节构成的有限文法树。含晶体的输出沿堆叠下料支路向前追溯；[R⊆K](01-foundations.md#s01-12)使沿途每次复杂堆叠都能替换为基础堆叠段。上料中保留的材料全部是 N/P，所以替换后不再递归依赖上料制造树。

追溯到最后一个基础输入、结晶、切割或交换节点时分别处理：

1. 基础输入直接是固定种子。
2. 结晶输出是紧图形，用其显式制造树替换此前历史。
3. 切割输出记作一个半形文法节点。它来自对该切割的输入制造树继续执行同样改写，然后应用 C_d。
4. 交换输出拆成“分别半切两个输入，再拼接”。每一侧都由相应输入的制造树改写后接 C_d 得到；拼接采用 A(X) 的双半形规则。若某侧为空，使用单半形规则。

被递归处理的都是原制造树中当前切割/交换节点的严格输入子树，因此这个改写终止。交换拆出的 C_d 是当前节点的有限展开，不会再把整个当前交换节点作为递归输入。无晶体半切结果直接使用 H_np；无晶体全图在需要时按层制造。

所遇起点之后只有基础堆叠、旋转和顶针。若所需结果含晶体，至少一颗结果晶体沿尾部全程保留，故尾部最多四次顶针；每段基础堆叠可按 S 合并，同段旋转可归并，得到 L。若这个尾部后还接一次半切，半切保留的晶体也不会下落，仍可用它约束该尾部。没有剩余晶体时直接采用无晶体构造，不需要保留长尾部。

最后，任意真实可制作半形 H 都属于 K。给它补上一刀保留自身占据的两列，不改变 H。若它含晶体，上述改写将这次末切表达为 `C_d(L(A))`；若不含晶体，H∈H_np。因此每个可制作半形都有一棵有限的上述文法树。

对这棵文法树的半形节点深度归纳：H_np 成员属于 H₀；直接从固定基础/紧图形起点生成、没有子半形引用的节点属于 H₁；其余节点只引用有限个较低深度的半形，待这些成员进入某个 Hᵢ，当前节点就进入 Hᵢ₊₁。所有可制作半形均在有限轮内出现，完备性成立。

这不是将 H 再次定义为“全部可制作半形”：递推的叶子、关系、每条规则的长度及状态全集都已明确，未知的制造历史已经换成有界状态上的有限文法。

<a id="s02-02-h9"></a>

### 6. 终止、充要判据与制造证书

Φ 单调且包含 X，故 H₀⊆H₁⊆…⊆U。如果 Hᵢ₊₁=Hᵢ，以后所有轮都相同；否则至少新增一个编码。U 总共 M 个编码，H₀ 至少有 ∅，因此在不超过 M 次算子应用后必已得到不动点。保守地定义：

```text
H* = H_M，M=1048576
```

结合第 4、5 节，有精确充要判据：

> 标准非空两列半形 T 可制作，当且仅当 T∈H*。

该判据对不可制作的输入同样会停止并给出否定结果。实际使用时遇到相邻两轮相等即可提前停止；M 是严格增长轮数的宽松总界，不是每轮候选数或时间复杂度。

<a id="s02-02-h10"></a>

#### 正向制造证书

每个新加入的半形记录第一次加入的轮数、起点类型、零/一/两个已有半形引用、各段 S 的前后格位、旋转、Π 的中间格位及末次切割方向。子半形来自前一轮，轮数严格降低，回溯不会成环。

S 按新增块从低到高展开；紧图形按逐列构造展开；无晶体半形按层展开；双半形分别制造后拼接。由此得到完全由允许实体操作组成的制造树。可共享已证明部件的记录形成有向无环证书，实体生产时复制其制造过程。

<a id="s02-02-h11"></a>

#### 否定证书

若构造出包含 H_np、对 Φ 封闭的集合 X，而 T∉X，则由单调性及归纳 H*⊆X，T 不可制作。特别地，完整不动点 H* 本身给出所有非成员的有限否定判据。

单独搜不到 T、只跑若干轮、或者某个递归分支失败都不是否定证书。无需每个 X 的成员都可制作才能用它排除 T，但必须证明其包含全部种子、对所有规则封闭。

<a id="s02-02-h12"></a>

#### 规模边界

长期递推表仅存两列编码，至多 M 项；一次规则内部仍涉及四列中间格位、多个堆叠段和双半形组合。这是完备且终止的理论算法，不能据此声称已具备可接受的运行时间或存储开销，更不能把 1296 个单段前态当作整个算法的规模。

<a id="s02-02-h13"></a>

### 7. 由半形判定全图可制作性

现在 A(H*) 的定义不再依赖未知集合。对任意非空四列目标 T：

```text
若 T 无 C：Reach(T) ⇔ T 满足无晶体稳定性判据。
若 T 含 C：Reach(T) ⇔ 存在 A∈A(H*)，使 T∈L(A)。
```

必要性是第 5 节的制造树改写，充分性是起点的合法构造及 L 中的实体加工。两个分支都是有限、有效的条件，且能给出制造证书。

于是[完整顶针逆像](01-foundations.md#s01-13)最后一步的“输入可制作”可以直接调用 Reach。依赖顺序为：

```text
源码局部规则与静态下落公式
→ 正向 Π、C_d、堆叠关系 S
→ 有限尾部 L 与半形不动点 H*
→ 全图 Reach
→ 可制作前态的完整 InvPin
```

H* 的计算不使用 InvPin 或 Reach，因此没有互相调用的循环判定器。工程上可以用逆向规则加速寻找证书，但不能用“正在递归访问”当作已经成功，以免把无基础叶子的循环证明收入 H*。

<a id="s02-02-h14"></a>

### 8. 结论强度与验证方式

本页闭合了两列半形的有限判据及构造，并给出了与完整顶针逆像连接的方法。证明依赖四象限五层的 K 闭包、K 下堆叠约化、保留晶体高度界及精确局部结算。这些依据已按各自证明的适用条件重读；没有将结果外推到六象限或任意层数。

尚未得到的是简短局部充要公式、实际半形数量、低成本实现，以及某台固定 TMAM 对这份文法的实现证明。它们与本文“存在一个终止且完整的构造判据”是不同结论。

本轮证据为源码静态阅读、制造树归纳、有限集合不动点证明和文档自审。没有运行全量枚举、目标模拟、游戏或形式化证明器。

## 02-03 四象限五层：逐列角构造与半形的局部充要条件

原文标识：`4q5l/corner-synthesis.md`。

本页在既有[列内不变量](01-foundations.md#s01-01)、[晶体间隙不变量](09-sources.md#s09-02)及[四象限支撑闭包](01-foundations.md#s01-12)上，给出无需半形目录枚举的构造。范围为四象限、五层、合法普通部件及可供料的晶体颜色；底部及中间空层保留。证明采用人工逐步推导，没有运行目标枚举、物理模拟或游戏验证。

实现为 [`CornerBuilder`](../../synthesis/corners.py) 和 [`Constructor.half`](../../synthesis/construct.py)。本页解决的是相邻两列半形；不能据此把全图简单地切成两份就宣称覆盖所有四象限目标。

<a id="s02-03-h1"></a>

### 1. 列条件与半形判据

一列按底到顶记为N/P/C/空，补空到五格；层号从0开始。定义列条件A：

1. 每个不在地面的 P 正下方有格。
2. 最高 C 以下的 P 只构成触地连续针前缀，即 Q。
3. C 正下方若为空，向下遇到的第一个非空格是 N，即 J。
4. 同列相邻两颗 C 之间若有空格，中间至少两个 N，且下方 C 紧邻的上一格非空。

**半形定理。** 非空标准半形 T（只占 q0、q1）可制作，当且仅当它重新按自身格位分组后稳定，并且两列分别满足 A。

必要性来自制造树不变量和四象限 R⊆K：每个可制作半形稳定；P 独立成组，必须直接受支撑；Q、J 和晶体间隙不变量适用于所有可制作输出。

充分性的构造分两步：先证明每个满足 A 的非空列，都能与相邻的一根连续 N/P 辅助柱组成可制作的角；再把两角拼接，移走外侧助手。下面逐项给出角构造。

<a id="s02-03-h2"></a>

### 2. 简单列：填辅助晶体、半切删除

无 C 列配一根五层全 N 助手，按层制造即可。N 在每层都能与助手粘连，P 由条件 1 的原列下方格支撑。

含 C 列先处理最高 C 及以下；其上 N/P 后缀留到逐层追加。若有一颗 C_r 正下方为空，令最近的下方普通格为 N_m。先考虑m=0或第m−1层非空的情形：

- 把 N_m 的来源提高到第 r−1 层。
- 原 N_m 位置及其他前缀空格填辅助 C。
- 连续五层助手全用 N，唯第 r−1 层用 P。

助手在第 r−1 层的 P 不与源 N 粘连；其上 N_r 保持目标 C。删除辅助 C 后，源 N 独自下降，恰由原列第 m−1 层或地面挡住，落回 m。其余目标 N 由同层助手 N 保持；P 的直接支撑保持。

若没有 C 正下方的空隙，不移动 N，前缀空格直接填辅助 C，助手全部用 N。

<a id="s02-03-h3"></a>

#### 辅助晶体不会连带目标晶体

没有紧邻 C 下方的空隙时，底部空段上端必为 N；两个目标 C 之间的空段，条件 4 保证下方端点上方是 N，而上端不是 C，故也由 N 隔开。

有 C_r 下方空隙时，移到 r−1 的 N 隔开上方保留 C；其下填充 C 与更低的保留 C 之间也有 N。五层内这种空隙至多一处：若有两颗带空隙的 C，较低者至少在第三层，而二者之间再容纳两个 N 和空格将超过五层。

因此，每个填充 C 分量都不含目标 C。给每个填充位置，在主列另一侧的外部远列放 C；远列其他格填 N，补到五层。远列是可独立制造的紧 N/C 柱。

先造主列的独立晶体前缀，再逐层加入 N/P 助手与主列后缀，得到保留侧角。前缀的 P 仍是触地前缀，其他位置连续 N/C。助手的 P 只在前缀内部；最高 C 以上助手全部是 N，因此后缀的悬空普通格可以与同层新助手 N 一起堆叠，针按条件 1 受支撑。这个追加构造见 `Builder.crystal_prefixes`。

加入远列后半切，只保留主列及 N/P 助手。全部填充 C 因跨界融合删除，目标 C 不删；上述落点给出原目标列。

<a id="s02-03-h4"></a>

### 3. 用落点参数统一顶破构造

如果C_r下方最近的N_m不触地，且m−1层为空，直接删除填充C不能把它停在m。r是间隙上端C的层号，m是该N的目标落点。五层及A共同限制`r∈{3,4}`、`1≤m≤r−2`。低于这颗C不可能还有目标C，否则下方C、紧邻N、另一个其下为空的N、上方间隙及C至少需要六层。

因此无须按完整五格字串选择配方。主列的目标C先统一降低一层，N_m的来源放到r−2；更低的目标格至多是地面一格。地面目标为N时，把它先放在r−3；为P时，把主列0至r−3填成牺牲C；为空时保持空底。最高C以上的N/P在最后统一追加。

近锚列只使用一个公式（以下幂表示连续格数）：

`A = N^(m−1) C^(r−m−1) N`。

主列及锚列的全部标签、长度、晶体删除掩码由r、m和地面目标材料决定，不新增制造分支。

<a id="s02-03-h5"></a>

#### 准备与支撑交接

主列固定为q0，永久近助手q1，临时远助手q3，触顶晶体脊q2；可以镜像使用。

1. 先把主列底部空段填牺牲C；q1放五层N，q3在牺牲位置放C、其余N。按独立柱制造后半切保留q0/q1，删除底部填充C，主列N/C由q1托住。
2. 加入q3的五层N，半切保留q3/q0，转交支撑；再加入公式给出的近锚列A，半切保留q0/q1。主列来源N与锚列顶N同层粘连，目标C前态由主列来源N托住。
3. 加入互补两列：q2为五层C，q3为`P^(r−1)N`。近锚列的C连到q2晶体脊；主列保留C被N隔断，且与q2不相邻。
4. 执行一次Pin。删除晶体脊和近锚列C，全部保留C提高一层，到达最终目标高度。q3针柱的顶N同时提高到r，托住目标C。

<a id="s02-03-h6"></a>

#### 同一个落点公式

Pin后的近锚列底部是地面P及m−1个连续N，列顶为m−1。主列来源N和近锚列顶N仍组成同一水平块；二者从r−1层下降，近列给出的最高障碍恰为m−1，故落点为m。

地面目标若为N，其前态在r−3，提高后两侧分别是已删除的锚C和独立针，没有水平粘连；主列没有新地面P，因此它单独落到地面。地面目标若为P，主列底部牺牲C被删，而删除前底层占用产生的新P保留。空地面目标则保持原地面空，不补主列P。

近助手最后统一补成

`P N^m P^(r−m−1) N^(5−r)`。

从m+1层开始逐层追加；低于r用P，r及以上用N。主列最高C以上的N/P可与该层助手一起供料。最后半切保留q0/q1；被去掉的临时助手已经没有C，不会删除目标晶体。

落点、补针与融合隔断由上述公式确定，与N/P/C的具体颜色标签无关。原八个困难五格模式都是同一个参数构造的输入，Python不再按这些完整字串分流。与第2节直接释放一起，四象限五层角的主体只有两种制造机制；无C是直接供料的边界情况。

六象限及以上可在半切中保留三列，进一步把两种落点情形统一为[任意层三列释放](03-general-construction.md#s03-03)。四象限的[直接释放也已推广到任意H](#s02-15)，但悬空落点的通用支撑交接仍未解决，不能外推本节五层顶破。

<a id="s02-03-h7"></a>

### 4. 两角组成半形

对目标 q0 列，准备助手在 q3 的角；对目标 q1 列，准备助手在 q2 的角。分别制作，交换拼成完整四列。交换的切割保留各角全部格位，不破坏晶体。

再半切保留 q0、q1。两个外侧助手只有 N/P，不发生晶体融合删除。留下的格位正是 T；结算按 T 自身分组。若 T 稳定，所有组不移动，输出就是 T。

这证明半形定理的充分性，也使原来的[有限半形文法](#s02-02)可以用局部判据及角配方实现，无需计算百万编码的闭包目录。

<a id="s02-03-h8"></a>

#### 所有半形统一使用两角流程

`Constructor.half`及完整电路均使用上述通用构造。无晶体列已由第2节覆盖，目标自带助手也仍满足同一个两角证明；因此不再为无C直接制造或内向单角匹配保留快捷分支。只有目标列为空时跳过该角。

这项合并允许部分目标使用更多制造步骤，以删除专用分流和ROM。半形判据、标签、最终产物及原285节点上界保持。两角按镜像和遍次共用同一份电路，见[统一半形程序](08-circuits.md#s08-31)。

<a id="s02-03-h9"></a>

### 5. 构造规模与实现边界

计数包含基础原料节点，四象限任意朝向旋转按一个顺时针、逆时针或半周操作计。简单角至多 61 个节点：主列及 N/P 助手的晶体前缀与后缀至多 33，远侧独立柱至多 20，拼接至多 4，半切及恢复方向至多 4。

难角采用宽松上界 140：初始三列制造及拼接至多 51，第一次半切至多 3；加入远侧普通柱及转交至多 16；近锚列及转交至多 20；补充晶体脊和临时针柱并拼接至多 35；顶针、最多三次助手上料、一次主列上料、末切及整体旋转至多 13。合计不超过 138，取整上界 140。

所以每个可制作标准半形可用至多 `2×140+4+1=285` 个节点制造。全图若存在一个方向，使两个原始半面分别满足半形判据，则可用至多 573 个节点制造。后一子类不包含已经证明需要一般顶针/堆叠尾部处理的所有情况，不能当作全图可制作性判据。

## 02-04 面向电路的堆叠压缩与尾部标准化

原文标识：`4q5l/compact-synthesis.md`。

本文限定四象限五层，给出保持覆盖的局部简化，以及早期独立的 Python 堆叠规划原型（原 `stacking.py` 已归档移除，逐层供料与通用上料规划现由 [`synthesis/recipe.py`](../../synthesis/recipe.py) 与 [`synthesis/stack_plan.py`](../../synthesis/stack_plan.py) 承接）。目标是减少制造步骤、搜索分支和电路状态；三项成本分别计算。完整可制作性的依据仍是[统一合成定理](#s02-01)，本文没有把它的巨大半形闭包变成实用的全图求解器。

基础输入沿用任意无晶体单层 N/P 及合法标签。层号从 1 开始；K、S(D,T) 和落点公式沿用[堆叠约化](01-foundations.md#s01-11)。代码使用从 0 开始的层号。

<a id="s02-04-h1"></a>

### 1. 一段连续堆叠只需至多五份上料

**定理。** 对非空 D∈K，只要 S(D,T) 成立，就能从 D 出发，至多五次堆叠无晶体单层原料得到 T。

令 Δ 为 T 相比 D 新增的格位。对每个目标层 z，把 Δ 在该层的全部普通块及针放在一份单层上料 B_z 中；按 z 递增堆叠，跳过空 B_z。

证明如下：

1. B_z 的水平普通连通块恰好是 Δ 在该层的普通连通块；针仍独立成组。不能把 D 同层的旧格加入 B_z，它们可能把本应独立下落的新增块连接起来。
2. 由 S 的前缀条件，每个新增格所在列的旧格均低于 z。已追加的更低目标层也低于 z。
3. 每个新增块接地，或在 T 的 z−1 层有支撑；支撑属于 D 或已经完成的更低层。因此每块的落点恰为 z。
4. 同一份 B_z 中各块占据互不相交的列，不能相互阻挡。它们可以在一次堆叠中独立落到 z。既有 D 不动，新增接触在本次下落中不重新合组；写回后的输出仍属于 K。

逐层归纳得到 T。最多五个目标层，故最多五次堆叠。这个构造取代的是逐个水平块或针追加的二十次宽松上界。

**无晶体推论。** 任意非空、可制作的无晶体目标可用至多五份基础单层制造：第一份直接取为基础物品，其余至多四次堆叠。稳定的无晶体目标不能有空底层或整层空隙，否则最低的悬空水平块没有下方支撑。

这里计数的是已有单层供料之后的堆叠次数；各份原料的种类、配色、供料线路不折算成免费实体工厂。

<a id="s02-04-h2"></a>

### 2. 固定追加段的最少上料可用十五种选择求出

五份上料的构造没有保证最少。例如，不同目标高度的两个新增块若不粘连，可以放在同一份上料中，各自落到不同高度。

<a id="s02-04-h3"></a>

#### 2.1 四个前缀计数足以描述中间状态

固定 D、T，每列列出 T 的所有非空格，保留其真实层号及标签。记列 j 的总格数为 n_j，D 占有该列前 d_j 格。候选中间状态只需四个计数：

```text
p = (p0,p1,p2,p3)，d_j ≤ p_j ≤ n_j
```

状态包含每列目标列表的前 p_j 格。空底层、内部空格仍由列表中的层号表示，不能压缩成连续填充。

为什么不需要一般四列图形？因为纯追加不会移动或删除旧格，任何新增格必须高于该列已有最高格。成功历史若先放入较高目标格，就再也放不进同列更低的缺失目标格；因此每列只能依次追加下一个目标格。

D 不是 T 的逐列带坐标、带标签前缀，或剩余目标格含 C 时，直接判定不存在该追加段。

<a id="s02-04-h4"></a>

#### 2.2 一步只有十五种候选

一份单层原料每列最多一格。选择非空列掩码 m∈{1,…,15}，每个选中列放入该列下一个目标格，未选列为空。

在这份上料中划分水平普通连通块及独立针。设当前列顶为 h_j，空列为 0。对每个块 J 检查：

```text
J 中所有格的目标层号 = 1 + max(h_j : j∈J)
```

全部通过就有一条合法边 p→p′，其中选中列的计数加一。每条边严格增加格数，图无环。

这里的普通块分组包括 q3 与 q0 的环邻接。不同块可以有不同落点，但同一个水平普通块的全部格必须落在同一层。

<a id="s02-04-h5"></a>

#### 2.3 最优性与规模证明

任意成功的单层 N/P 堆叠步骤都能化为以上一种选择：保留进结果的格只能是各列下一个目标格。若某个水平块超高删除，整块同层且一起删除；它和其他上料块占据不同列，没有阻挡关系，可以省去。空效果步骤也可以省去。删除这些材料不会改变其他保留块的落点。

因此，所有有效单层追加方案都对应此图的一条路径；反过来，每条路径由落点公式保证合法。对单位边权作广度优先搜索，首次到达目标即得到最少上料份数。

```text
状态数 ≤ ∏(n_j−d_j+1) ≤ 6^4 = 1296
每状态选择数 ≤ 15
边检查数 ≤ 19440
最短成功路径长度 ≤ 5
```

19440 是单段的候选边检查上界，不是游戏 tick 数；也不包含完整合成中的半形搜索。最短性只针对固定 D、T、纯单层 N/P 上料，不包括允许复杂多层上料、切割或顶针后的全局最短制造树。

当 D 为空时，第一条边表示直接取基础原料。所有路径都少计算一次实体堆叠，所以最少上料份数也给出这一模型内的最少堆叠次数。

<a id="s02-04-h6"></a>

#### 2.4 逐层方案与最短方案的手推差异

取下料和目标：

```text
D = Cu------:Cu------
T = CuP-----:Cu------:Ru------
```

目标新增 q1 的地面针和 q0 的第三层普通块。逐层方案先加 `--P-----`，再加 `Ru------`，需要两次堆叠。

最短方案使用一份 `RuP-----`：针独立落到 q1 地面，普通块落到 q0 第三层，恰好得到 T。目标与下料不同，至少需要一次堆叠，故一次是最少。这是落点公式的手工推导，未运行实例。

不能总把所有下一格合在一份上料中：若改成相邻普通块，而两格要求的落点不同，它们在上料中已经粘连，整块只有一个落点。十五种掩码的检查保留了这一差别。

<a id="s02-04-h7"></a>

### 3. Python 的职责与调用

早期独立模块 `stacking.py`（已并入 `synthesis` 包并移除独立文件）当时复用 `Shape` 编码，提供两个原型入口：

| 入口 | 输出与计算方式 |
|---|---|
| `plan_layer_stacks(lower, target)` | 按目标层扫描，至多五份上料；不保存候选状态表 |
| `plan_stacks(lower, target)` | 对前缀状态作广度优先搜索，输出最少上料份数 |

两个入口都先检查非空下料属于 K：建立粘连组及直接支撑边，计算可达关系，检查每组是否到达地面或包含针的非空支撑环。针不与普通块、晶体粘连；不能用任意稳定性代替 K。每条追加边再用落点公式计算，不调用物理模拟器。

返回值约定：

- `tuple[Shape, ...]`：顺序上料；每个条目都是可取用的 N/P 单层，保留目标种类和颜色。
- 空元组：输入已经等于目标，无需堆叠。
- `None`：此固定追加段无解；含晶体目标可能仍可通过其他操作制造。
- 非空下料不属于 K：抛 `ValueError`，拒绝超出该局部算法前提的调用。

`lower=None` 表示尚未取料，返回序列第一份直接作为基础物品，其余依次堆叠。它不表示机器能接受空物品。以 `lower=None` 调用时，对于无晶体目标，这两个入口都是完整的目标到基础制造流程；对于含晶体目标，它们只负责已有下料之后的追加段，需要传入相应非空下料。

调用形式：

```python
from shapez2_tmam.mari.shapes import Shape
from shapez2_tmam.stacking import plan_layer_stacks, plan_stacks

lower = Shape.from_key("Cu------:Cu------")
target = Shape.from_key("CuP-----:Cu------:Ru------")
layer_plan = plan_layer_stacks(lower, target)
short_plan = plan_stacks(lower, target)
```

这段代码说明接口，没有作为验证执行。模块没有接入 Mari 的六候选命令，也没有将其 `None` 结果包装成通用不可制作结论。

<a id="s02-04-h8"></a>

### 4. 尾部的旋转可以全部吸收到起点及供料

记 R 为任意合法旋转。列重编号保留环邻接、同列上下关系、地面层号和顶破层号，因此晶体融合、静止组及落点关系均在旋转下保持。由[精确顶针关系](01-foundations.md#s01-13)得到：

```text
R(Π(D)) = Π(R(D))
S(D,T) ⇔ S(R(D),R(T))
```

第二式的制造对应为：把下料及每份基础上料都旋转同样角度。它允许保持工序次序，把尾部中的一个旋转向前移过 Π 或 S，并相应旋转更早的供料。反复移动，所有尾部旋转合为起点的一次净旋转。

[半形文法](#s02-02)的起点集合 A(X) 已包含各合法朝向：基础层、紧图形、单半形及两个互补半形的拼接都在旋转下封闭。因此对整个起点集合，可以把尾部搜索标准化为：

```text
A → S → (Π → S)^k
```

无需在每个 S 后再选择四种朝向。四次顶针时，原来五个段末旋转有最多 4^5 个语法组合；标准化后只在起点的朝向中处理净效果。此处消除的是冗余语法变量，未测量实际运行加速比。

制造半形时，末次半切也可以固定保留标准 q0、q1：原先在方向 d 切割再标准化的输出，等于先把完整输入旋转到标准方向再作固定半切。该旋转可继续向前吸收到起点及供料。两列内部顺序保持，不能引入镜像去重。

这个证明没有交换 S 与 Π 的次序。[堆叠与顶针不能直接交换的例子](01-foundations.md#s01-09-h12)仍成立。

<a id="s02-04-h9"></a>

### 5. 目标约束进一步缩短尾部与前态选择

<a id="s02-04-h10"></a>

#### 最低晶体决定顶针深度

由[保留晶体高度不变量](01-foundations.md#s01-09-h8)，设所需末端最低晶体层号为 m，则标准尾部只需考虑：

```text
0 ≤ k ≤ m−1
堆叠次数 ≤ 5(k+1) ≤ 5m
顶针次数 ≤ m−1
```

末端有地面晶体时，尾部没有顶针，只剩一段 S。半形规则末尾的切割不会让保留晶体下降，所以也能用所需半形的最低晶体限制它前面的尾部。

最宽松的尾部界由一百次有效基础块堆叠降为二十五次单层堆叠，另有至多四次顶针。起点制造、半形递归、朝向调整和末切不计入这个局部界；不能把它说成整套 TMAM 只有二十九步。

<a id="s02-04-h11"></a>

#### 只保留不同的列前缀

反推固定目标 T 的 S 前态时，每列不必遍历六个高度后再对重复图形去重。按非空格计数即可：令 n_j 是该列非空格数，r_j 是从底到最高 C 为止的非空格数；无 C 时 r_j=0。所有 C 必须保留，所以该列保留格数仅需取 r_j,…,n_j。

```text
不同前态候选数 ≤ ∏(n_j−r_j+1)
```

这是目标结构给出的精确候选生成范围，随后仍需检查 K 和 S 的支撑条件。它和第 2 节从固定 D 正向追加的前缀状态用途不同，不能混作整个求解器的状态数。

<a id="s02-04-h12"></a>

### 6. 电路实现的取舍与未闭合部分

逐层方案的控制流程可固定为“读取当前目标层 → 提取相对下料的新增格 → 检查支撑 → 发出一份上料 → 转下一层”。层计数器只需经过五个位置；不需要为五层各复制一套完整判定器。已经由合法配方保证的 K 中间物品，可以依据不变量保持 K，而不必在每次追加后重复求全支撑图。

最短方案额外需要候选遍历、队列、去重及父记录。对游戏电路，可以先采用至多五份的逐层方案；只有实体工序或吞吐成本值得额外搜索硬件时，再考虑实现最短方案。Python 同时保留两者，便于明确区分控制体积与上料次数。本文没有给出门数、tick 数或时序存储器蓝图。

这轮简化已经覆盖所有合法 S 段，并给出无晶体 4q5l 的完整 Python 合成流程。含晶体的全覆盖机器仍有两个主要缺口：

1. 顶破逆像还要恢复可能消失的辅助晶体和第五层，不能仅保留无顶破的唯一逆像。
2. 半形部分已由[逐列角构造](#s02-03)替换为局部充要判据及至多285节点制造；完整全图的顶针与堆叠尾部仍需继续压缩。

完整求解电路必须区分处理中、有解、有证明的不可解；局部段无解或搜索预算耗尽不能输出全局不可解。六象限已存在可制作但非 K 的图形，因此本页的堆叠实现与证明不能直接用于所有 6q5l 下料。一般范围只研究偶数象限。

证据为落点公式、前缀路径对应、旋转等变性的人工证明，以及直接代码静态核对；未运行测试、目标枚举、物理模拟或游戏验证。

## 02-05 半切与顶针逆像的压缩，以及一次半切的制造证书

原文标识：`4q5l/compact-inverse.md`。

本页限定四象限五层。它给出保持物理逆像覆盖的压缩，以及一个有明确制造步数界的半形构造子类。完整半形另有[逐列角构造及局部充要条件](#s02-03)；本页制造子类的失败不构成不可制作证明。

实现见 [`synthesis/inverse.py`](../../synthesis/inverse.py) 的 `pin_families`、`cut_families`，以及 [`synthesis/construct.py`](../../synthesis/construct.py) 的 `Constructor`。物理结算使用[静止组及落点定理](01-foundations.md#s01-13)，保留普通部件、颜色和原层号。

<a id="s02-05-h1"></a>

### 顶层只按晶体掩码区分一次顶针的物理输出

固定前四层后，原第五层的普通格和针全部直接被顶破；它们不参与下落，也不参与晶体融合。因此，一次顶针只通过第五层的晶体掩码区分输出。同一掩码下，把其他第五层格任意改为空、普通格或针，输出不变。

保留晶体在前态的位置唯一。每列保留的 n 个非晶体格按顺序嵌入前四层，其他未占位置选空或消失的晶体。忽略目标高度、强制晶体和地面掩码的进一步限制，单列选择至多

```text
C(4,n) × 2^(4−n) ≤ 32。
```

四列至多 `32^4` 种前四层；第五层晶体掩码至多 16 种。因此，每个目标的正向顶针物理计算至多 `2^24` 次。这个上界没有把族内前态制造判定也缩减到同样规模：族内的空/N/P 顶盖仍可能改变前态是否可制作，不能只制造一个代表。

`PinFamily.members` 恢复这些成员。输出中保留的标签精确回填；最终消失的普通格、晶体仅取固定辅助标签，依赖[结构与标签分离](01-foundations.md#s01-09)的制造前提。

<a id="s02-05-h2"></a>

### 半切按保留侧晶体分量的删除效果区分

目标先旋转到标准前半 q0、q1。两列中，保留晶体保持原高度；保留 N/P 在同列保序，原高度不低于目标高度。其他源格只能为空或最终消失的晶体。对单列 n 个保留 N/P，源列选择至多

```text
C(5,n) × 2^(5−n) ≤ 80。
```

固定保留侧格位后，先计算仅含晶体的融合分量。某分量在半切前消失，当且仅当完整输入中有外侧晶体直接与它相邻。含目标晶体的分量必须保留；其他分量只需区分删除或保留。

2×5 网格中，任意两个晶体分量不相邻。从各分量任选一格，得到独立集；逐层覆盖的五条横边限制独立集至多五格。因此晶体分量至多五个，删除效果至多 `2^5` 种。对每个目标，正向物理计算至多

```text
80² × 2^5 = 204800 次。
```

这是物理逆像族的上界。外侧完整格位仍可有很多制造上不同的补全。`CutFamily.members` 明确保留这一区别，不能仅因物理输出匹配就接受输入。

<a id="s02-05-h3"></a>

### 不枚举外侧全部格位的一次半切构造

给定 `cut_families` 返回的保留侧及删除效果，采用如下充分条件：

1. 含晶体的保留源列属于[可独立制造的单列分类](01-foundations.md#s01-10)。
2. 不含晶体的保留源列，与一根五层普通辅助柱并排后，可用无晶体逐层构造制造。

为每个待删除晶体分量任选一个格 `(z,q)`。若 q=0，在 q3 同层放辅助晶体；若 q=1，在 q2 同层放辅助晶体。外侧其他位置全部填普通块，统一补足五层。

这恰好删除所选的分量。每个保留格只有一个外侧水平邻居，所选辅助晶体接触的保留分量就是它的指定分量。辅助晶体彼此融合也不会接触额外的保留分量。保护分量没有直接跨界晶体邻居，因此不被连带删除。

制造分两侧进行：

- q3、q0 为一份半形；q1、q2 为另一份半形。
- 主列含晶体时，两根列都可独立制造，再拼接为该半形。
- 主列无晶体时，这侧没有需要触发删除的主列晶体，故辅助列全是普通块，整份半形直接按无晶体层构造。
- 拼接两份半形，再半切保留 q0、q1。由于所选物理逆像已经通过正向结算，得到的就是目标。

每份原料和加工都有实际制造树，成功具有可靠性。这个定理没有证明每个可制作半形都满足上述充分条件。

<a id="s02-05-h4"></a>

#### 制造步数界

独立单列高度 h≤5。含晶体列写成底针前缀、紧 N/C 段、N/P 后缀。按 `Builder.column` 展开，基础原料、堆叠、结晶、顶针、旋转与切割总节点数至多 `3h+5≤20`；无晶体独立柱至多九个节点。

q3、q0 各造一列后只需一次交换拼接，因此每份侧半形至多 41 个制造节点；无晶体侧半形至多九个节点。两侧拼接至多三个旋转与一次交换，末次半切一个节点。所以本分支的标准半形制造树至多

```text
2×41 + 4 + 1 = 87 个制造节点。
```

四象限的任意旋转可由顺时针、逆时针或半周旋转完成。若全图可按某一方向分为本子类的两份半形，还原两侧朝向、交换并恢复全图朝向，制造节点至多 177 个。此处计数包含基础原料节点，不涉及运输等待；它不是全体可制作目标的步数上界。

<a id="s02-05-h5"></a>

#### 允许晶体前缀以上的 N/P 后缀留空

实现还允许先制造每列最高晶体及以下的独立前缀，再按目标层追加 N/P。没有晶体的列不进入前缀。追加只增加新格，不覆盖原格；每一层实际虚拟堆叠的结果都必须等于原前缀加已处理的目标格，最多五份单层。由逐步结果相等直接归纳，成功配方可靠；失败仅表示这一追加形式不成立。

这允许主列在最高晶体上方保留空隙，例如地面 C、空第二层、N3/P4/N5，可以在外侧普通柱帮助下逐层添加后缀。每份侧半形的前缀至多两根独立柱加一次交换，最多 41 个节点；追加最多五份原料、五次堆叠，侧半形上界为 51。扩展后一次半切构造的标准半形上界为 107 个节点。原来两列均可独立制造的子类仍保留 87 的较小界。

`Builder.crystal_prefixes` 与 `append_noncrystal` 实现这个构造。它只使用已有晶体前缀，不假设新晶体可以从上料保留下来，也不把六象限的任意下料当成稳定下料。

<a id="s02-05-h6"></a>

#### 整层空隙例的直接证书

[Mari 默认算法漏解的目标](09-sources.md#s09-03)可由以下完整输入的一次标准半切得到：

```text
输入 D：crCuCucr:CucrcrCu:crCuCuCu:crP-CuCu:crCuCuCu
输出 T：CuCu----:--------:crCu----:crP-----:crCu----
```

D 的四根列都属于独立单列分类：q0=`C N C C C`，q1=`N C N P N`，q2=`N C N N N`，q3=`C N N N N`，所以可以按上述两侧构造制造。

半切删除 q3 的地面晶体及 q2 的第二层晶体，分别连带删除 q0 地面晶体和 q1 第二层晶体。q0 第二层普通块落地。q0 第三至第五层晶体与 q1 第三、第五层普通块粘连，q1 第四层针独立；二者形成含针支撑环，保持原位。q1 地面普通块也保持原位，结果恰为 T。

这是人工逐格证书，没有运行目标求解或游戏验证。

<a id="s02-05-h7"></a>

### 辅助支撑转交

一次半切构造子类不完备。可制作半形

```text
T：--cr----:Cucr----:crcr----
```

的两列分别为 `- N C` 与 `C C C`。若从独立柱准备保留侧，q0 的 N 必须原在第二层，不能从第三层以上穿过保留晶体落到第二层。q0 第一层为 N/P 会被保留；要消去它只能填待删除晶体。然而它与必须保留的 q1 地面晶体融合，无法单独删除。因此这个 T 不属于上节子类。

T 有如下合法制造证书：

1. 独立柱拼出 `D0=crcr--Cu:Cu----Cu:cr----Cu`，即 q0=`C N C`、q1=`C`、q3=`N N N`。
2. 切割保留 q3、q0。q1 地面 C 连带删除 q0 地面 C，q0 的 N2、C3 由 q3 普通柱保持，得到 `A=------Cu:Cu----Cu:cr----Cu`。
3. 准备 q1=`C C C` 的独立柱，按 q3q0 / q1q2 与 A 拼接。
4. 切割保留 q0、q1。外侧只删普通块，q0 的 N2、C3 改由 q1 晶体柱保持，得到 T。

这给出一种支撑转交：对目标半形选择一根锚列，先将它与外侧全普通辅助柱按晶体前缀及 N/P 追加构造准备。另一目标列也先与它的外侧临时辅助柱组成半形，再拼接两份侧半形，最后移走两个外侧支撑。后一根辅助柱只枚举连续五层 N/P，共 32 种；其半形只调用一次半切的直接构造，不递归调用转交构造。最后用真实半切结果确认目标。

两个辅助柱都不含晶体，不会在末切连带删除目标晶体。只要两份侧半形均有配方、最后半切匹配，就得到可靠证书。直接构造的辅助半形至多 107 个节点，恢复方向一个旋转；锚列侧只有一根含晶体前缀，独立制造及追加至多 30 个节点；拼接至多四个节点、末切一个节点，总计至多 143 个节点。两个这样的半形合成全图至多 289 个节点。这个步数界仍仅适用于构造成功的子类。

<a id="s02-05-h8"></a>

### 实现与剩余命题

现行 `Constructor.half` 使用[逐列角构造](#s02-03)，以稳定性和列条件精确判定合法材料范围的半形，制造上界为285节点。本页保留逆像压缩及有较小步数界的构造子类。完整全图构造未覆盖时仍返回 `unknown`，不会把局部失败当成全局否定。

半形部分已有无需递归的角构造；完整电路仍需压缩四象限全图的顶针与堆叠尾部。六象限存在非 K 与不稳定输出，不能直接沿用四象限的堆叠约化或半形几何结论。

## 02-06 四象限五层：无需半形目录的完整逆推

原文标识：`4q5l/tail-solver.md`。

本文将[逐列角构造](#s02-03)代入[统一合成定理](#s02-01)，得到不建立全图或半形目录的目标到配方程序。实现为 [`Solver4`](../../synthesis/solver4.py)。范围沿用合法普通部件、可供料晶体颜色、任意无晶体单层基础料和五层上限。本文没有运行目标求解、枚举、物理模拟或游戏。

[两侧悬空N目标](#s02-08)已证明必须有一次尾部Pin；因此零尾与正尾两类整图均非空，不能只保留A→S。两次、三次是否必要仍未证明。

该程序是完整的有限参考算法。它消除了半形闭包及其递归，却仍可能耗费很长搜索时间；本页不把它称为已完成的游戏 TMAM。

<a id="s02-06-h1"></a>

### 1. 起点改为局部构造

原统一定理把制造历史改写为：

```text
A → S → (Π → S)^k，0≤k≤3。
```

原先由晶体高度得到k≤4；[四次尾部Pin改写定理](#s02-07)证明k=4的目标也属于A→S，因此本实现只需k≤3。这不限制A的角构造内部Pin。

A 是基础层、紧 N/C 图形、单个可制作半形，或两个互补可制作半形的交换拼接。旋转已吸收到旋转封闭的起点和供料中。S 是纯 N/P 追加段，Π 是一次顶针。

现在每个非空半形都有局部充要判据及显式角配方，因此不用建立H目录。上述起点全部可以由同一个双半形程序制造：基础层、紧图形的两侧也都满足半形条件，单半形则跳过空侧。完整求解调用`Constructor.paired_halves`，不再在无C、独立柱和两半形之间挑制造方案；覆盖证明见[完整目标的统一流程](03-general-construction.md#s03-08)。

构造器返回 `unknown` 表示它未找到这类直接配方；不能当作不可制作。返回 `unsolvable` 时依据的是已证的列内必要条件、四象限稳定性或完整无晶体判据。

<a id="s02-06-h2"></a>

### 2. 一段 S 只有逐列前缀需要恢复

对目标 T 的第 q 列，把全部非空格按原层号排序，得到长度 n_q 的列表。令 r_q 为列表中最高 C 的序号加一；无 C 时 r_q=0。

S 不移动旧格、不创造 C，也不能把新格插入已有列顶以下。因此全部 S 前态 D 恰在以下候选中：每列保留列表前 p_q 格，`r_q≤p_q≤n_q`。原层号和标签都保留。候选数至多 `6^4=1296`。

设 Δ=T\D。每个 Δ 水平普通块或单针，必须在地面，或至少有一个格的正下方属于 T。这个检查只对 Δ 分组，不能通过 T 中的旧普通格把两块新增上料粘在一起。该条件与逐列前缀条件共同构成 S 的静态判据，前提是 D 可制作，因而属于 K。

从保留全部晶体的最小前缀出发，可先做一次支撑闭包。当前 Δ 中若有整块没有下挡，将更多格并入前缀只会把这块拆成更小的块。下挡仍按完整目标 T 查找，所以拆出的每一块依然没有下挡。任何合法的 S 前态必包含该块的全部格以及这些格所在列的更低非空格。如此提高前缀下界直到不变，至多补入 20 格。该闭包与双半形起点共用 [`unanchored_additions`](../../synthesis/prefix_closure.py)。更长的候选前缀仍须检查新增块，因为移去原有下挡所在的格可能让剩余块失去支撑。

四象限中，这个检查只须读取同行四格。新增格无晶体，针是独立块，普通格只在环上与相邻新增普通格相连。对一个没有直接下挡的新增普通格，若任一相邻格是有下挡的新增普通格，则整块有支撑。余下唯一可能的支撑在对角，从任一相邻新增普通格可达。四格环中所有连通路径都可以缩短到这两种距离。因此 [`addition_needs_lower`](../../synthesis/row_support.py) 和对新增格分组后检查下挡等价。已在前缀中的格只参与下挡检查，不能作为横向路径中的新增格。

恢复纯堆叠前态时，由最高层到地面各处理一次。每次把本层没有下挡的整块并入前缀。它会连带纳入同列更低的格，但不会纳入任何更高的格。同层其余块与被移除块分离，仍保有原下挡。以后处理更低层时，下挡仍按完整目标 T 查找，因此已经通过的层无需重查。这一遍得到满足新增块支撑条件的最小保晶前缀，只用四个前缀高度。`close_stack_prefix` 将它交给 S 前态的游标，再逐个筛选较长候选；双半形起点还有区间见证条件，继续交替执行两项闭包。

把当层每格的类型和下挡预先合成一层支撑代码。对空格或已保留的晶体用空，对有无下挡的普通格分别用 `Ru`、`Cu`，对有无下挡的单针分别用 `Wu`、`Su`。每一轮再把高度已纳入前缀的对应代码视为空。这样四个列更新方法可共用同一份代码，只读取本轮开始时的四列高度，再一起提交新高度。`stack_scan_rows` 生成五层代码，`stack_scan_q0` 到 `stack_scan_q3` 通过旋转复用同行判据。

算法生成前态时检查坐标、材料、新增块支撑及所需支撑类。是否可制作由后续配方搜索确认。得到 D 的真实配方后，`Builder.append_noncrystal` 从低到高加入至多五份单层，并比较每步完整输出；失配抛内部错误，不能伪装成目标不可解。

<a id="s02-06-h3"></a>

#### 列A对逐列前缀封闭

从一列删去非空格列表的尾部，不会删掉任何保留格下面的格。因此保留针的直接下方支撑、保留C以下的针前缀、C下方最近非空格及任意两颗保留C之间的材料都不变。新的晶体列表只是原晶体列表的前缀，不会使原本不相邻的两颗C变成新的相邻C对。故列A成立时，任意这种前缀仍满足A。

`_tail`的首层目标已经通过`Constructor.construct`的列A筛选，递归目标由`PinFamily.members`逐列筛选。因此所有搜索层的S前态自动继承A。Pin分支使用`_predecessors(..., grounded=True, limits=limits)`，其地面可达条件强于K。所有目标C均保留、没有引入cu，所以构造器在这些前态上既不会触发列A/K否定，也不会进入无C否定分支。

因此不再对每个S前态调用一次`Constructor.construct`、却只读取它是否返回unsolvable。原调用只可能返回solved或unknown，且所得配方从未被使用；删除它不改变候选顺序、搜索覆盖或最终配方。实际制造凭据仍由后续起点/Pin递推取得。这项优化省去每个S候选上的重复独立柱、角构造和物理计算，没有声称减少了逆像族的最坏数量。

**顶针输出的列容量。** 设 $P=\Pi(D)$，$D$ 为合法输入。若 $P$ 的第 $q$ 列没有地面针，则 [Pin 的地面针公式](01-foundations.md#s01-01-h8)给出 $D(0,q)$ 为空。原第 4 层全部删除，幸存格只可能来自第 1、2、3 层。抬升、下落均不换列，故这一列至多保留三格。若目标 $T$ 的该列没有地面针，在任何逐列前缀 $P$ 中也没有地面针，故搜索 $\Pi\to S$ 时可先将该列前缀上界收紧为 $\min(n_q,3)$。若该列的全部保留晶体所需前缀已经超过三格，整个顶针分支可直接排除。此筛选在四列组合前执行，并保留原来的正向物理与制造检查。它同样允许普通格经过顶针后落到地面。

若无地面针的列还具有最低保留晶体 $C_h$，那么抬升后来自原第 1 层及以上的旧格都始于第 2 层及以上。$C_h$ 固定在第 $h$ 层，它下方的幸存格只能来自抬升后的第 2 至 $h-1$ 层。故在最低保留晶体下方的 $h$ 个层位中，至少两个层位必须为空。逐列前缀保留晶体时也保留它以下的全部目标非空格，故可在整个目标上检查这条条件。[`pin_prefix_limit`](../../synthesis/pin_prefix.py) 对一列的五个原层位同时检查最低晶体限制和来源容量，返回允许的最大前缀长度。`Solver4` 用四列上界直接限定堆叠前缀游标，顶针来源入口仍可单独复用最低晶体条件。

<a id="s02-06-h4"></a>

### 3. 恢复最后一次顶针

零Pin闭包失败后，先检查[低层C底部条件](08-circuits.md#s08-22)：C1要求同列P0，C2另要求同列第1层非空，C0不允许Pin。这些格在所有保C的S前缀中不变，失败即可排除全部Pin尾部。再对每个 S 前态 P，使用 [`pin_families`](../../synthesis/inverse.py) 恢复其顶针输入 D：

1. P 的保留 C 必须来自同列低一层；其标签原样恢复。
2. 除新地面针以外的 N/P 按列保序恢复到前四层，来源不得低于输出层减一。
3. 未被占用的来源格为空或最终消失的辅助 C。输入底层占用与输出地面针掩码一致。
4. 第五层只影响融合删除。先验证最大允许晶体顶盖，再用局部接触条件筛选其子掩码。每个命中的掩码仍分别恢复顶层非 C 的空/N/P 选择。

**较小顶盖的精确判定。** 固定前四层 $L$，记最大允许顶盖为 $U$。[最大顶盖定理](08-circuits.md#s08-15)允许在 $U$ 物理失配时整组排除。若 $U$ 命中目标，记它的抬升后活图为 $V$，静止格集合为 $F$。任意允许子掩码 $M$ 相对 $V$ 只会恢复若干个前四层的纯 C 融合分量。分量被删当且仅当 $M$ 含有它正上方的至少一个顶盖位置。新增地面针和所有 N/P 在两图中相同。

对于 $U$ 删除的一个融合分量，如果该分量抬升后有格直接压在 $F$ 上，或与 $F$ 内的非针格水平粘连，就要求 $M$ 仍覆盖它的至少一个顶盖位置。竖直晶体邻边已包含在同一个前四层融合分量内。若恢复了这种分量，它的晶体地面可达并原位保留，因此输出多出目标没有的晶体。

若所有恢复分量都与 $F$ 没有这种直接连接，地面可达集合仍恰为 $F$。任何新到地路径必首次跨入 $F$，但旧活图内 $F$ 以外的格原本就没有这种边，恢复的晶体也没有。这里使用列 A 下[静止等于地面可达](01-foundations.md#s01-15)，因此彼此支撑的恢复分量也会碎。剩余 N/P 的分组、起始位置及静止挡块完全相同，按落点公式输出相同。

所以每份 $L$ 最多完整验证一次顶针像。命中后计算 $F$ 及必须被顶盖碰到的分量，然后按原掩码顺序枚举，保留不同顶盖的制造候选。
辅助且最终删除的材料可以固定使用红晶体和普通`Cu`。标签不影响连接、融合和重力；原制造证明可按相同结构重新赋值。每个来源族先用[两个切向的可选顶格闭包](08-circuits.md#s08-17)整体检查A→S并取得某个精确成员。若失败，低层C底部条件不符或无地面可达成员的族整体不可制作；其他族仍分别恢复顶盖，但只搜索各成员的Pin尾部，不重复已否定的A→S。

候选生成在四列作笛卡尔组合以前，就对各自前四层检查列A。第五层不能修复更低处的针支撑、针前缀或晶体间隙违例，因此这项提前排除保持完备。顶层C另检查完整五格列A。

`PinFamily.members`也把列A检查移到成员组合之前：顶层固定C的列检查完整五格，其余列只检查固定的前四格。补顶层空/N不会新增列A限制；补顶层P只需第四格非空，这已经由该列的取值域保证。因此每族检查四列一次，就与对至多81个成员逐个检查四列等价。即使调用者直接构造PinFamily，这个入口也保留相同的必要条件筛选。

族内所有成员的晶体格位完全相同，仅顶层非C变化，所以最低C高度及严格下降检查也只需由族模板计算一次。候选集合与遍历顺序保持；这些简化不替代成员的制造凭据。

各逆像族先作上述A→S闭包检查，未覆盖的实际成员再递归求Pin尾部。成功后实际生成`Π(D)`，比较是否等于P，再追加到T。这些排除减少实际分支，但没有取得新的最坏运行时间保证。

`Solver4(..., certificate_first=True)`以[最大静止集合及块支撑](01-foundations.md#s01-16)代替族的正向Pin检查：`pin_families(..., check_output=False)`已精确匹配物理关系，随后仍须递归取得D的制造证书。实际制造末端继续核对Pin结果；两种检查方式接受同一规范化逆像族。游戏端只保存候选材料格，A叶端使用[两列扫描判据](01-foundations.md#s01-19)取得存在性证书，根成功后才制造。[完整电路](08-circuits.md#s08-09)已接四帧回退与配方流，性能仍需压缩。

<a id="s02-06-h5"></a>

### 4. 终止、可靠性与完备性

**终止。** T 含 C 时，所有 S 前态保留 T 的全部 C，故最低 C 层号不变。任何顶针输入 D 至少含有一颗由该最低 C 反推到低一层的 C；可能恢复出的辅助 C 只会使最低 C 更低。因此每次递归最低 C 严格降低。最低 C 在地面时不再尝试顶针；四次尾部Pin又可改写为零次，所以完整搜索深度限定为三条边。[按最高C收紧的界](#s02-07-h6)进一步给出`max(0,H−1)`，H为原目标最高C的零基层号。Python的remaining_pins从此界开始，每条边减一，余量为0时仍先完成A→S闭包。每层前缀、逆像族和族成员选择均有限。

最多四个递归帧即可遍历；程序按固定顺序重放 S 候选，不保存全量状态集。这里的帧数不等于门数，也不意味着候选数量很小。

**可靠性。** 所有叶端来自有真实制造证书的直接构造。向上只执行真实顶针和按层追加，并逐次检查完整结果。所以任何返回的配方都从基础料出发，逐格得到指定目标。必要条件的否定独立成立。

**完备性。** 取任意可制作目标的标准化历史 `A→S→(Π→S)^k`。最后一个 S 的下料在全部逐列前缀中；若 k=0，直接构造器覆盖 A，该分支成功。若原历史k=4，先改写为k=0；其余k>0时，完整顶针逆像必包含最后一次 Π 的输入结构；最终删除格的合法标签可按固定辅助标签替换。该输入最低 C 更低，归纳可求得其制造证书，再执行 Π 和 S 即得到目标。

因此，所有分支真正耗尽而未命中时，目标才不可制作。程序没有将预算、运行超时或局部构造失败转换成 `unsolvable`。未着色晶体 `cu` 的实体供料尚未界定，仍返回 `unknown`，不属于此处完整供料范围。

<a id="s02-06-h6"></a>

### 5. 局部条件不能直接替代全图逆推

考虑以下三层目标，列号 q0～q3：

```text
L3   C N N .
L2   . . N .
L1   N . N .
```

编码为 `Cu--Cu--:----Cu--:crCuCu--`。每列满足 A；第三层大组经 q2 第二、第一层支撑到地面，因此目标也属于 K。但它不可制作。

若某个可制作 D 经 S 得到该目标，q0 的地面 N 和第三层 C 都必须保留。为保持 C，D 还必须保留 q1、q2 的第三层 N；否则 C 所在组没有直接支撑。q2 的逐列前缀条件又迫使保留其下两格。故唯一可能的可制作 S 前态就是目标自身。

该目标不属于双半形起点。沿任一对互补半面切开，包含 q0 的一侧都无法保持第三层 C：`{q0,q1}` 缺少 q2 支撑，`{q3,q0}` 则没有同层助手。因此它不是合法半形起点的拼接。

它也不可能是顶针输出：q0 的第三层 C 强制输入第二层为 C。目标地面为 N，故输入地面必须为空，否则必补出不能消失的地面 P。目标地面 N 的来源必须低于输入第二层 C，但那里只剩被要求为空的地面格，矛盾；高处 N 无法穿过保留 C 下落。

结合标准尾部定理，零顶针和最后一次顶针均排除，证明不可制作。这个例子来自人工推导，没有执行目标求解。它说明即使把列 A 和 K 合起来，也不能据此省掉全图尾部判定。

<a id="s02-06-h7"></a>

### 6. 全部可制作目标存在至多 616 节点制造树

节点计数包括基础料；四象限顺、逆或半周旋转各算一个实体操作。由[角构造规模](#s02-03-h9)：

- 每个可制作半形至多 285 节点。
- 双半形、朝向及交换合计起点至多 573 节点；单半形、基础层与紧图形均不超过此界。
- 标准尾部至多三次 Π，至多四段 S。
- 每段 S 至多五份基础单层及五次堆叠，即至多十个新增节点。

所以可以选取一棵制造树，使节点数不超过：

```text
573 + 3 + 4×10 = 616。
```

这是存在性上界，不是全局最短步数。当前完整程序统一使用双半形起点，不宣称返回的配方在所有输入上都最短。

## 02-07 四次尾部Pin可以改写为A→S

原文标识：`4q5l/three-pin-tail.md`。

四象限五层的[标准尾部定理](#s02-06)原给出`A→S→(Pin→S)^k`、k≤4。本页证明：含C目标若具有k=4的这种历史，它也具有k=0的历史。因此完整搜索只需k=0、1、2、3，至多四帧。

这里计数的是起点A之后的尾部Pin。A的角构造内部仍可使用Pin；结论没有限制整份实体配方的Pin操作总数。规则和基础供料保持不变，不使用目标枚举。

<a id="s02-07-h1"></a>

### 1. 四次Pin迫使保留C从地面到最高层

层号为0～4。S不新造C；C一旦下落就碎，存活C在每次Pin中恰上升一层。含C目标经过四次尾部Pin，最终每颗C只能来自起点第0层，最终全部位于第4层。

在已完成t次Pin、并做完随后S的状态中，全部存活C的高度至少为t。辅助C同样不能下落后存活，且S不能补C，所以此性质对辅助C也成立。选择最终保留的一颗C，其所在列在第t层为该C，第0～t−1层全为P：第一次Pin给原地面C补地面P，以后每次将整根P链提高并再补P；这些P都有直接下方支撑，不会移动或消失。S不能插入C以下，也不会改变旧格。

<a id="s02-07-h2"></a>

### 2. C以下的NPC区域在下次Pin中不动

假定当前全部C都位于第t层或更高。第0～t−1层的每个N粘连组只是单层水平N块，每个P单独成组；它们不能向上连接C。因此支撑边严格降低层号。

当前状态可制作，属于K。上述低层块若不在地面，必须有某格正下方非空；它们的支撑链必到地面。对这些低层格做Pin时：

- 没有C可被融合删除，原层号低于t≤3，也不会被截顶。
- 原地面占用列都得到新地面P，原地面NPC提高后被直接支撑。
- 按旧层号向上归纳，每个更高NPC块的原直接下方支撑也已提高并保持，故该块不动。

所以这一区域整体上移一层，原支撑关系保持。与更高C的新增接触不影响论证：低层N/P不能通过CC竖边连到上层，N块本身只占一层。

<a id="s02-07-h3"></a>

### 3. 最低C高度上的每个纯N块保有直接支撑

证明如下不变量I(t)：在第t层，仅用N格建立水平连通块，不借用同层C或P连接；t=0时每块在地面，t>0时每块至少有一个格的正下方占用。

初始t=0成立。插入一段S保持此性质：旧格及其下方支撑不变；新增N上料块落在地面或已有下方格上；合并相邻N块只会保留这些支撑。S没有删除或拆开已有N块。

再考虑下一次Pin，从边界层t变成t+1，其中t≤3。输出第t+1层的N格只有两类来源：

1. 原第t层N块提高后不动。t=0时，每个原N格下都新增地面P；t>0时，I(t)给出的支撑位于C以下区域，由第2节保证提高后仍在。故原纯N块整体受到直接支撑，不会下落。它的N格不会融合删除、截顶或被拆开。
2. 原来更高的N格发生下落，到达第t+1层。由[Pin精确落点定理](01-foundations.md#s01-16)，每个实际移动水平N块在最终落点触地，或至少有一个格的最终正下方非空。此处t+1>0，所以必有直接下方支撑。静止的更高N格不会出现在这一层；更低N格不能向上移动到这一层。

这两类块覆盖全部边界N。若最终有新水平接触，将它们合为最大纯N块仍保有至少一个支撑；证明不要求下落中因新接触重新分组。因此I(t+1)成立。归纳得到I(4)，并且最后一段S也保持它。

<a id="s02-07-h4"></a>

### 4. 从针柱起点重新构造目标

取最终目标T。构造U：只在T含最高层C的列中保留完整`P,P,P,P,C`，其他列全空，C标签与T相同。由第1节，U逐格包含于T。

U的任一相邻两列半形都满足列A，而且每颗P、每个C组有通向地面的直接支撑。由[半形局部充要判据](#s02-03)，这些半形可制作；把两半拼合即可取得起点A中的U。U非空，且属于K。

令Δ=T\U。核对S的四项条件：

- 原格和标签保持；Δ全部为NPC。
- 有C的列已被U占满五层，没有新增格；其他列在U中全空。因此所有新增格严格高于各自旧列顶。
- 第0～3层没有C。T属于K，每个非地面纯N块有直接下方占用，单P的直接下方也非空。U在这些层只删去P，不会拆开Δ的N块。
- 第4层纯N块由I(4)保证直接支撑；U在该层只有C，原本就不参与纯N块的连接。第4层P也由列A保证直接下方占用。

所以Δ的每个N块和单P都满足S支撑条件。按[连续基础堆叠充要判据](01-foundations.md#s01-11-h5)，存在U→S→T的合法逐层制造。T于是已有A→S历史。

<a id="s02-07-h5"></a>

### 5. 完整搜索深度可以减为三条边

任意含C可制作目标原有k≤4的标准历史。k≤3者不变；k=4者由本页改写成k=0。因此只搜索三条尾部Pin边仍然完备。原本k=4的目标会由两个切向的完整A→S闭包命中，不能成为必须深入第四条Pin边的目标。

Python的remaining_pins初值最多为3，并按第6节收紧；每条Pin逆推边减一。即使余量为0，来源族仍先尝试其完整A→S闭包；只有还想追加Pin时才拒绝。完整电路保存0～3四帧，最深帧仍允许A→S，不允许继续下降。预算限制来自已证覆盖界，不是运行时间预算，也不会将未完成搜索误报为不可制作。

以起点最多573节点、每段S最多10节点计，制造树存在性界进一步变为`573+3+4×10=616`。这是理论存在性界；当前共享ROM的发包上界另由实际程序计算，不能把616当成已实现的最短程序。

<a id="s02-07-h6"></a>

### 6. 按最高目标C收紧深度

设目标最高C的原层号为H，0≤H≤4。原标准形有k≤最低C层号≤H。若H>0且k=H，目标所有C都只能源自起点地面，最终全在第H层；否则更低目标C会需要负层号的来源。

第1～3节的归纳可以停在任意H，而非只能停在4。取U为每颗目标C所在列的`P^H,C`，其余列为空。第H层及以下的Δ支撑与第4节相同；第H层以上没有C，T中的每个N组都是单层纯N块，P仍单独成组，K保证非地面组有直接下方占用。U在这些更高层没有格，不会拆分新增N块。因此全部Δ仍满足S判据，k=H的历史同样可以改写为A→S。

所以每个含C目标都有满足以下界的标准历史：

```
k <= max(0, H - 1)
```

H=0时原高度界本就要求k=0。普通格可以高于H，不影响这个界。换成人类层号：最高C在第1或第2层时只需A→S；在第3、4、5层时分别至多1、2、3次尾部Pin。

Python在根solve确定H，将该界传给remaining_pins，随后沿边递减。完整电路保留四帧以容纳最高情形，但深度d仅在原目标第d+2层或更高处有C时允许下一条边；这里层号仍从0开始。判据读取全程保持的原目标及当前depth，不依赖来源中的辅助C，也不新增寄存器。最深允许帧始终完成A→S闭包再失败。

<a id="s02-07-h7"></a>

### 7. 根目标预算已经包含全部子目标高度界

最高C界也适用于递归子目标，但它不会在现有根预算之外再减少分支。取原目标位于最高层H的某颗C。S前态保留全部C，Pin逆像将这颗强制C恰降低一层；物理匹配不能删除它。故深度d的每个有效子目标都仍含这颗C的来源，层号为H−d，其最高C层号H_d必满足 `H_d ≥ H−d`。辅助C可以更高，不能使此下界变小。可选顶NPC也不改变C集合。

根预算在深度d剩余 `max(0,H−1−d)`，因此不大于该子目标自身的 `max(0,H_d−1)`。再取一次两者的最小值没有效果。特别是H_d≤1的子目标，根预算已经为0，本来就只能尝试A→S；无需再加“高两层之外存在C”的独立门或保存每帧局部高度预算。

当前Python只传递根预算沿边减一，电路只保留原目标与深度决定的允许条件。不能把重复的局部高度检查算成新增剪枝收益，也不能将高度界加入pin_families的通用物理逆像条件：H=1的目标仍可能有合法Pin逆像，只是制造证书无需Pin尾部。

<a id="s02-07-h8"></a>

### 8. 证据与边界

本证明使用已证四象限R⊆K、S精确判据、Pin移动块落点及两列半形充要判据。没有假设悬空K组都接地；只对严格位于全部C以下的NPC区域使用层号下降。也没有将最高层N借C连接形成的整组误当成可直接上料块。

实现验证限于静态重读、LSP及完整生产蓝图的DAG、端口和占地编译。没有执行目标、求解器、测试、模拟或游戏。剩余三层搜索仍可能很大，本页不宣称实用性能已完成，也不直接推广到六象限。

## 02-08 四象限五层：确实存在不能省去尾部顶针的完整目标

原文标识：`4q5l/necessary-tail-pin.md`。

本页给出一个人工构造，证明双半形起点加纯N/P追加并不覆盖全部可制作4q5l目标。至少一次尾部Pin的处理必须保留；这不证明两次或三次尾部Pin也不可省。

基础输入、列A、两列半形和S关系沿用[完整尾部定理](#s02-06)。层号从0开始，C取合法红晶体，N取Cu。

<a id="s02-08-h1"></a>

### 1. 目标与可制作起点

目标为：

```text
T = P---P---:Cu------:crCu--Cu

层号   q0 q1 q2 q3
  2     C  N  .  N
  1     N  .  .  .
  0     P  .  P  .
```

它由以下起点D执行一次Pin得到：

```text
D = Cu--cr--:crCucrCu:----cr--:----cr--:----cr--

层号   q0 q1 q2 q3
  4     .  .  C  .
  3     .  .  C  .
  2     .  .  C  .
  1     C  N  C  N
  0     N  .  C  .
```

D的q0/q1半形由地面N支撑第1层C/N；q2/q3半形由触地连续C柱支撑第1层N。两个半形分别稳定、每列都满足A，所以通用半形构造可以制造它们，D属于双半形起点B。

<a id="s02-08-h2"></a>

### 2. 一次Pin的逐步结果

q2的五颗C属于一个触顶融合分量，全部删除。q0的C位于对面的列，与q2晶体不相邻；两侧隔着N，非针粘连不等于晶体融合，因此它不随辅助塔删除。

原地面q0的N及q2的C占用产生新地面P。q0的N提高到第1层，被新P支撑；q0的C和两侧N提高到第2层，重新组成同层非针组，由q0第1层N支撑。其余来源格全部已删除。

所以Pin(D)逐格等于T。全过程最高输入为五层，目标虽只有三层，却不能据此把准备上限改成三层。固定基础料配方见[48步制造路径](../../examples/4q-required-tail-pin.md)，另有同名JSON和六槽指令包；不是全局最少步骤证明。

<a id="s02-08-h3"></a>

### 3. 零尾部Pin不可能

反设存在双半形起点B₀，经S得到T。

S不能创造C、移动旧格或删除格。故q0的第2层C必须已经在B₀；按逐列前缀性质，q0的第0、1层也必须在B₀。

再看q1与q3的两个第2层N：它们各自正下方都为空。只对新增格分组时，两者隔着旧C和空列，不是一个水平N块，也不能借旧C把自己当成已支撑上料。任何S新增N块在最终落点都必须触地或有某格正下方占用，因此这两个N都不能由S添加，必须已经在B₀。

B₀于是必含第2层的`C N . N`。任何相邻两列划分，都只能把q0的C与q1、q3中的一个放在同一半形。另一个N所在半形只有它自己和可选的q2地面P；该N既无同层非针助手，也无正下方阻挡，不稳定。它不可能是可制作半形。

两个切向都矛盾，所以T不属于B→S。结合第2节，它在标准尾部语法中的最小尾部Pin数恰为1。

<a id="s02-08-h4"></a>

### 4. 整图可以明确区分的两种情况

令R为全部可制作4q5l目标，Z为具有B→S配方的目标。则：

- Z：无需尾部顶针，可直接制造双半形起点再追加。由两个切向的[最小前缀闭包](#s02-09)精确判定。
- R\Z：必须使用尾部顶针；由完整尾部定理，仍只需1至3轮同一个Pin/S循环。本页T证明这一集合非空。

两类是按完整目标的制造需要划分，互斥且覆盖R；角内部是否顶破不参与分类。第一类可用[原完整四象限代表](../../examples/4q-whole.md)，第二类用本页T。不可制作及供料未界定仍是结果状态，不算制造类。

两类继续共用一个制造主程序：前者循环零次，后者循环一至三次。没有必要复制工厂，也没有依据继续细分最少一次、两次、三次的独立电路。此前“一套主程序”的结论保持；现在补上了“尾部循环不能整体省掉”的严格边界。

<a id="s02-08-h5"></a>

### 5. 同一反例结构适用于最高C的三个高度

把目标C的零基层号记为h，取h=2、3、4。令目标q0为`P^(h−1) N C`，q2为`P^(h−1)`，q1和q3仅在第h层各有一个N。这三个高度都不能零尾制造，理由仍是两侧无下方支撑的N必须同时进入起点。

它们也都只需一次尾部Pin：起点q0为`P^(h−2) N C`，q2为`P^(h−2) C^(7−h)`，后者总高五层；q1和q3各在第h−1层放N。两半形分别稳定，Pin删除q2全部C，留下所需针前缀并把其他目标提高一层。

因此最高C在第三层时，既有一次尾部Pin上界已经达到；把此例继续顶针到第四、第五层，也不能证明最少需要两次、三次，因为上述起点改写仍只用一次。这里是同一参数构造的人工证明，没有枚举或增加目标专用代码。

<a id="s02-08-h6"></a>

### 6. 证据与下一问题

反例及排除零尾的论证为人工推导；配方只从给定起点生成，没有执行完整求解、枚举、测试或游戏。程序保留原Pin逆推核心，不把此例扩展成新的目标匹配分支。

仍值得研究的是1次是否足以覆盖R\Z，或能否把多次Pin的来源检查统一化。若要减少三次上界，必须另给覆盖证明；本页只排除了零次全覆盖。

## 02-09 A→S前缀的强制闭包

原文标识：`4q5l/prefix-closure.md`。

固定四象限目标T及一种半切方向。假设T满足[列A条件](#s02-03)，颜色供料在既定范围内。P取T的逐列原层位前缀，保留全部晶体。以下算法求该切向下最小的A→S前态，替换第一遍至多1296种前缀扫描；顶针后的S前态仍须另行完整遍历。本页不把这个局部改进当作整个求解器的实用性能保证。

<a id="s02-09-h1"></a>

### 两列中的强制支撑

设每列最高晶体层为h[q]，无晶体时为−1。保留全部晶体的前缀必然保留该列所有不高于h[q]的目标格。以后能加入的格都是高于h[q]的N/P。

增加这种格不会在旧格正下方添加阻挡：若旧格已在前缀内，它正下方的目标格早已保留。新N没有竖向粘边；两列中它也只有一个水平邻居。因此新N不能合并两个旧晶体组，只能作为同层另一格的叶子，或补成一层的纯N组。新P独立成组。

若新增N要粘到晶体上，它位于某列q的层z>h[q]，而另一列必有晶体在z，故h[1−q]≥z>h[q]。所以一个旧晶体组的新增叶子只可能出现在最高晶体较低的那一列。两列最高晶体相同则没有可添加的晶体叶子。这个结论用的是整个列的最高晶体，不是组内最高晶体。

对当前不稳定的晶体组，旧成员不可能因补入其他格获得新的下方阻挡。任何稳定扩展必须添加一个带外部下方阻挡的新N叶子。可能的叶子均在同一列，逐列前缀按高度构成一条链，因此其中最低的合格叶子属于每个稳定扩展。若不存在合格叶子，则没有稳定扩展。

对当前不稳定的纯N组，它只占一层。若两列已有N，无格可补，故无稳定扩展。若只有一格N，唯一可能的新支撑是同层另一列的N及其下方阻挡；若存在，该N同样属于每个稳定扩展。P的直接下方条件由列A及前缀性质继承，不能靠其他列补救。

由此也得到交集结论：两个包含全部C的稳定两列前缀，其逐列较小前缀仍稳定。每个非空的稳定扩展集合有唯一最小元；上述强制补格给出构造，不需要枚举36种两列前缀。

<a id="s02-09-h2"></a>

### 直接找支撑叶子

采用[两列按层稳定性定理](01-foundations.md#s01-19)。令V[z]表示两列中存在从z−1到z的CC竖边。全部C已保留，故V不随补格改变。V连接的层区间就是非针组；单独一层也算区间。

目标非针格(z,q)可作为该区间的外部支撑见证，当且仅当满足以下之一：

- z=0；
- z>0、V[z]为假，且目标(z−1,q)非空；
- z>0，目标(z−1,q)为P。

前缀性质保证保留该格时也已保留它的下方目标格。区间内部的非针下方格属于本组，不能算外部支撑。

若一个当前非空区间没有已保留的见证，它不稳定。对每列取区间内最低的目标N见证。前节证明保证：在不稳定区间中，这些候选最多出现在一列，且该列最低候选是强制格。没有候选则该切向无解。可以同时处理全部不稳定区间，再检查一次；补入较高见证时按前缀连带保留的低层NPC可能引入其他不稳定组。

<a id="s02-09-h3"></a>

### 新增层的强制格

令Δ=T\P，不含C。按仅Δ中的水平N粘边分组，P各自单独成组。如果一个块没有任何成员触地或正下方有目标格，则S不能在原层位放置这个块。

以后增大P只会从Δ删除格，剩余块是原坏块的子集；它们仍没有任何目标下方支撑。因此每个可行扩展都必须把这个坏块全部移入P。将各列前缀推进到这些格，仍是强制操作。这里读取目标T的下方格，允许它属于更早追加的层；不要求下方格已经在P中。

<a id="s02-09-h4"></a>

### 算法、终止与最小性

有C时，从每列包含全部C的最小前缀开始。无C时，选目标的完整地面层作为非空基础物品；T∈K保证它非空且其余层满足逐层追加支撑，因此直接得到一个A→S解。空物品不作为制造原料。

对固定切向重复：

1. 找到两个半形全部不稳定区间，补入各自强制支撑见证；缺失见证则拒绝该切向。
2. 找到Δ中全部无目标下方支撑的块，把这些块全部补入P。
3. 若没有补格，P的两个半形稳定且Δ可逐层追加，返回P；否则继续。

实现可在同一轮从同一P计算两类强制格，并一次推进各列前缀。两类更新都属于每个可行扩展，故并行更新保持相同不变量。

用循环不变量“当前P包含于任一可行前态D”证明最小性：初值必含于D；每一步只加已证明在每个D中的强制格；无候选时不存在D；停机时P本身可行，故它是唯一最小解。列A的晶体以下部分完全不变，新增NPC尾部不破坏列A。两个稳定半形可由角宏制造，故无需额外K搜索来证明P可制作。

每个非终止轮至少增加一个目标占用格，总共至多20格，因此每切向至多20次增长及一次最终检查。尝试两个切向即覆盖全部A→S起点。这个界计补格轮，不包含制造ROM或后续Pin分支。

<a id="s02-09-h5"></a>

### 实现对应

Python入口为[`minimal_start`](../../synthesis/prefix_closure.py)，[`prefix_closure`](../../circuits/prefix_closure_circuit.py)输出单轮强制补格、无扩展标志与下一前缀位。两者保留原层号、全部C及普通材料标签。首轮按两个切向求A→S；[同一Pin来源族](08-circuits.md#s08-17)还可把最高层N作为可选助手，新增块只检查必需Δ。完整电路第二遍Pin搜索仍使用原有全部前缀游标。

本证明按源代码静态核对；未运行目标、目标枚举、测试、重力模拟或游戏。

## 02-10 保留晶体屏障与顶针候选界

原文标识：`4q5l/pin-barriers.md`。

顶针输出中保留的晶体，在抬升后从未移动。因此同列保留的普通格或针不能穿过它下落。本页把这个必要条件用于四象限五层逆推，并给出无需枚举的候选上界。它不替代整图Pin和可制作性检查。

<a id="s02-10-h1"></a>

### 1. 屏障引理

层号从零开始。目标T在第c+1层有保留晶体，所以输入D的第c层必须有同标签晶体。顶针先删除触顶融合分量，再整体上移一层。保留晶体此后不能移动：只要所在组开始下落，它就碎裂，无法成为T中的这颗晶体。

考虑T在同列第z层的一颗保留N/P，来源为D第r层。原物体先上移到r+1，以后只下降，所以z≤r+1。若z<c+1而r≥c，则这颗N/P起于晶体同层或上方，却最终位于它下方。同层来源与强制晶体占位冲突；上方来源必须穿过这颗始终占位的晶体。重力下降不允许穿透格位，故两种情况均不可能。

反方向也不能穿越：若z>c+1，来源不可能在晶体下方，因为只上移一次就已有r+1<z。故每一颗保留N/P在每道保留晶体的前后侧别不变。其他列怎样粘连、哪些辅助晶体碎裂、是否发生横向连接，都不改变这个同列阻挡结论。

在实现中，强制晶体来源行的集合为F。已按列保序的每一对来源r和目标z必须满足：

```text
z ≤ r+1，且不存在 c∈F 使 z ≤ c ≤ r。
```

这只是必要条件。侧别正确仍不保证正确落点、融合删除或真实制造来源。

<a id="s02-10-h2"></a>

### 2. 电路用前缀计数检查

令K是来源N/P掩码，L是目标中除新增地面针外的N/P列表。对强制来源晶体行c：

```text
count(K[0:c]) = count(L中目标层号 < c+1 的项)。
```

两个前缀都不包含晶体所在行。原单列通路已经计算K和L的一热前缀计数；各个相同计数位相与再取或，即可比较两边计数。无该强制晶体时旁路。四个屏障条件先合为一项，再加入已有有效条件，保持末端合取的深度。

按保序匹配和总数相等，前缀数量相等当且仅当没有N/P跨过该屏障：如果目标侧有m颗，来源侧也只能由前m颗组成。因而电路计数等式与Python的逐来源侧别检查等价。输入有效时，一热比较的每一位含义由[单列前缀计数证明](08-circuits.md#s08-23)保证。

[`inverse._sources_fit`](../../synthesis/inverse.py)由`pin_column`和`pin_families`共同使用。它在组合其他列之前筛选；`pin_families(check_output=False)`也保留该必要条件。默认物理检查和取证优先模式都不漏真实制造前态。

[`column_candidate`](../../circuits/pin_column_circuit.py)增加四道前缀等式。采用[平衡计数](08-circuits.md#s08-35)的独立单列蓝图为555平台，最大频道依赖深度32；自动单列迭代器为911平台，沿用P=156、每轮52模拟秒。输入与输出频道以重新生成的JSON为准。八位计数仍遍历256轮，当前优化减少的是有效分支，而非这256轮的等待时间。

<a id="s02-10-h3"></a>

### 3. 地面掩码把每列上界降为20

令n为保留N/P数，f为强制晶体数。先忽略列A、屏障和落点限制，仅计来源位置和其他格的空/C选择，所得超集足以给上界。n>4-f时没有候选。

先取f=0。输出地面为P时，来源地面必须占用。把来源地面由保留N/P占用和由辅助C占用两种情况分开，候选上界为：

```text
C(3,n−1) × 2^(4−n) + C(3,n) × 2^(3−n)。
```

某项的组合数下标无效时整项为零。按n=0、1、2、3、4，以上分别为8、20、18、7、1；这是直接代入五个组合式，不是枚举目标或候选。最大值20。

输出地面不为P时，来源地面必须为空，只有其余三行可选。上界为`C(3,n) × 2^(3−n)`，按n=0、1、2、3分别为8、12、6、1，最大值12。

所以无论地面掩码如何，每列有效候选至多20。列A、晶体屏障和位置限制只会继续删减。

<a id="s02-10-h4"></a>

### 4. 含保留晶体的列至多12个

现在f≥1。如果强制晶体就在来源地面，地面已占用，其余至多三行可选。忽略额外强制晶体，把这三行全作为自由行，上界为`C(3,n) × 2^(3−n)`，最大12。

如果强制晶体不在地面，最多剩三行自由位置，其中包括地面。地面必须占用时，沿用前节分情况公式，但把总自由行数4改为3：按n=0、1、2、3，上界分别为4、8、5、1，最大8。地面必须为空时，只有两行自由位置，上界最多4。更多强制晶体不增加选择数。

因此有保留晶体的一列至多12个。四象限完整尾部中的Pin目标必含晶体，至少一列满足此界；其余三列各至多20个。前四层的四列组合于是至多：

```text
12 × 20³ = 96,000。
```

这个界没有利用屏障的实际排除效果，也没有计入顶层晶体掩码、顶层非C成员、S前缀或多帧回退。因此它不能当作完整求解时间界。它也不表示要保存96,000项；控制器仍可逐列缓存并按索引惰性组合。

<a id="s02-10-h5"></a>

证据为源码规则、上述人工证明、Python静态重读、LSP和两份生产蓝图的占地及端口编译。没有运行目标、候选枚举、门级模拟或游戏。

## 02-11 四象限任意高度：带普通支柱列的完整构造

原文标识：`general/column-construction-complete.md`。

本文补齐 everain 列判据的充分方向。采用[文献记录](09-sources.md#s09-04)的四象限模型和固定全过程高度上限H；层号从1开始，N为普通格、P为针、C为晶体。每格保留原种类、颜色和标签。

**定理：满足共用列条件P，并满足D或E的任意目标列，都能在同一H内制成“目标列＋相邻纯普通支柱”。** 结合[必要性](#s02-12-h16)，得到四象限任意H的S列充要判据。

这里E对应PDF的终点条件F，避免与一次下落Φ混淆。D和E定义为：

- D：没有C，或地面是P，或最低C以下至少有两个空位。
- E：每个正下方为空的C段底，或者从该处起至少三连C，或者与最近下方C之间有同列相邻NN；没有下方C时，也允许地面N作终点。

共用条件包括针直接受支撑、C以下针为触地前缀、非最高C有直接上盖、C下洞需要普通资源，以及两C之间有洞时至少有两枚普通格。具体定义见[列条件](#s02-13-h1)。

<a id="s02-11-h1"></a>

### 1. 所有分支共用的制造动作

<a id="s02-11-h2"></a>

#### 1.1 紧列、普通柱与支撑交接

连续接地的N/C列可以逐层制作。首层直接取一个仅目标象限为空的三普通格原料，后续层把同类原料堆上去；再填入所需目标N，或结晶填入唯一空位生成所需C。旧层已经填满，不被后续结晶改写。两次适当半破删除普通外框，保留连续接地的目标列。

底部针前缀可以先制作其上的紧N/C核心，再顶针补齐；只要预定总高度不超过H，就不会截去目标C。单针可由满高纯C件顶破取得，再切出指定象限。连续N/P辅助柱由单N、单P逐层堆叠取得。

支柱交接始终先接新柱，再拆旧柱。例如目标在q0、旧柱在q3，先保留q3/q0接入q1的新柱，再沿q0/q1切开，留下目标和新柱。两根柱都覆盖目标当前高度。切除纯N/P助手不会融合删除目标C。

<a id="s02-11-h3"></a>

#### 1.2 无C列和最高C以上尾部

无C列只需满足针的直接支撑。首层若需要N或P，直接取对应单格并接入普通支柱；空首层只准备支柱。后续用支柱逐层确定高度：空层只增加柱高；N层堆跨目标和柱的普通双格；P层在目标现有顶格上堆单针，再补柱。空目标列只保留支柱。

含C列先保存最高C以上的尾部，完成核心后用同一方法补回。若当前柱过高，先换成恰覆盖现有目标的普通柱，再继续增长。尾部各N/P的原层号、标签均保持。

<a id="s02-11-h4"></a>

#### 1.3 正规核心与定向删晶

称核心正规，是指每颗C接地或正下方非空。对满足共用条件的正规核心，把空位填成临时C，去掉底部针前缀，制作紧N/C列，再补回针前缀。

临时C不会与保留C融合。上方保留C已有直接下邻；若它不是C，则是N或触地针前缀。下方保留C若上面还有C，共用条件保证它的直接上盖存在。因而每段临时C与保留C之间有非C格隔开。

给目标保留普通柱，再从另一侧接一根只有指定层为C、其余为N的满高桥柱；切掉桥柱，删除与该层相连的一整段临时C。目标其余N/C继续被普通柱托住。逐段删除后得到正规核心。此操作也允许删除底部临时C，使最低目标N悬空保留在柱旁。

<a id="s02-11-h5"></a>

#### 1.4 弱下落与环下落

弱下落：把普通柱换成仅在待移N源层为P、其余为N的连续柱。该N失去横向粘连，落到同列最近下邻上或地面；其他目标N/C仍被柱托住。恢复普通柱后完成一次动作。各分支在核心中操作，不带最高C以上的尾部针。

环下落：设目标在t、t+1、t+2为三连C，待移的最高N位于s<t，其与t之间为空。选择h=s−1，且h为空。换入辅助列：h层C、t+1层P、其余N。三连C与辅助列的N/P/N构成针环。接外桥并切掉h层辅助C，h以上、t以下的辅助普通列下落一层，带着s层目标N下降一层；上部针环保留三连C。接回普通柱，再拆辅助列。

反复令h为活动N正下方的空位，即可把它送到任意指定d<s；每次只降一层，不越过下方目标材料。所有辅助件均不高于H，因为t+2本来就是目标C层。该机制的八层实例见[三连晶窗口](09-sources.md#s09-04-h3)。

<a id="s02-11-h6"></a>

### 2. 不依赖底部资源的递归恢复

假设D为假而E为真。由针前缀条件，最高C以下没有针。

从下向上处理各C段。若段底已有下邻，不动。若段底c下方有洞，取最近N，原位置为a。

- 段长至少三：把N从a提到c−1，记录环下落恢复。
- 段长一或二：把N从a提到c−1。若a=1或a−1是N，停止递归；若a−1为空，取更低最近N，将它提到a−1，再检查这枚N的原位置下方。

短段的递归必终止在地面N或相邻NN。E保证同一晶体区间内存在这样的终点；递归只会经过从上往下的N序列，遇到最高一对相邻NN即停止，不会越过它碰到更低C。因此不会搬走下方C唯一的直接上盖。

每次提升都只穿过空位。不同晶体区间的记录互不交叉，目标材料顺序保持。处理完成后，所有C底都有下邻，得到可按第1.3节制造的正规核心v。

实际恢复按源层从高到低执行。短段递归中，上层N回到原位置a时，下层被临时提到a−1的N还没移动，恰好充当落脚点；最后一枚N由原相邻N或地面托住。故每次弱下落恰回原层。长段只提升了最近的一枚N，它与三连C之间没有其他目标材料，可用环下落逐层回到原位置。

这个顺序保持已经恢复的上层材料，不需要同时释放递归链。最后补回尾部，得到目标S列。

<a id="s02-11-h7"></a>

### 3. 一次顶针批量下落的装配与证明

接下来两种D分支共用本节。所有移动坐标用Pin后的层号，记录为s→d，且2≤d<s≤H。

四列沿环依次为：

`目标A(q0) — 晶体桥柱B(q1) — 满高触发C柱E(q2) — 针槽柱N(q3)`。

令I为所有下降区间[d,s−1]的并集；如果本次还要删除目标临时C，再加入每段临时C的最高层。令J为全部源层s。Pin前，三根辅助柱都做到实际高度H：

| 辅助列 | Pin前第z层，1≤z≤H |
|---|---|
| B | z+1属于I时为C，否则为N |
| E | 全部为C |
| N | z+1属于J时为P，否则为N |

三根柱连续接地，分别可由紧N/C或连续N/P制造。这里N既是普通材料符号，也是针槽柱名；表中最后一列的材料只有N/P。

<a id="s02-11-h8"></a>

#### 3.1 真实四列装配

目标A先带普通柱q3。接入B后，保留A/B半边，删除旧普通柱；B连续接地，接管目标所有层的支撑。再把已制好的E/N半边交换到q2/q3。

此时B上的C只对齐目标待删C或空位，不对齐保留C；目标内部的临时C也已用N与保留C隔开。E与A相对，不直接相邻，N柱没有C。因此触发塔不会误连目标保留晶体。

<a id="s02-11-h9"></a>

#### 3.2 顶破与活动双格

Pin截去E的顶层，删除整个E分量及所有B晶体桥，并连带删除标记的目标临时C。目标在顶针前整体低一层，保留最高目标C不超过H−1，故本次不截目标。

源层s不在I中，B在该层为N；A源格与B源格组成普通双格。N柱在该层为P，不能把活动格横向固定。删除后A/B两列的[d,s−1]都是空，活动双格可以下降。

每个目标非活动N/C所在层，N柱都是普通格；N柱连续接地，新地面针接续其支撑，所以这些目标材料固定。目标底针前缀也固定。

<a id="s02-11-h10"></a>

#### 3.3 落脚支撑的明确要求

双格落在d的充分条件是：B的d−1层非空且保持原位；从d到s−1的B格都已经删除。d=2时，B的新地面针直接提供落脚点。

若d>2，B在d−1以下的一段连续普通格，必须由新地面针，或某层不参与本批次移动的目标N/C锚定。不能把另一枚也在下降的源N当成这个锚点。后两节逐项证明具体记录满足此要求。

各记录的下降区间互不相交，源层也不在其他区间内。双格在独立空通道内下降，恰停在各自d处。

<a id="s02-11-h11"></a>

#### 3.4 拆除辅助件

顶破后E只剩新地面针，B不再有C。沿q3/q0保留A/N，切掉B/E的N/P余料；目标保留C不会被融合删除，非活动格和已落位格由N柱支撑。再接入一根纯普通柱，完成支撑交接并去掉针槽柱。

全流程的辅助制造、交换、触发和清理都在四列、同一个H内完成。

<a id="s02-11-h12"></a>

### 4. 地面有针的列

对目标核心做一次简单正规化：每个C下洞，只把最近N从d提到该段C底前一层s，记录s→d。得到v。两C之间有洞时至少有两枚N，所以这不会移动下方C唯一的直接上盖。

地面针前缀使所有d≥2。各记录处于不同晶体区间，区间[d,s−1]互不相交；s+1是该记录上方的保留C。

把v的空位填临时C，删去一枚地面针并整体降低一层，制作这个紧列。其余底针照第1.1节补齐。按第3节组装辅助柱；I除下降区间外，还标记每段临时C的最高层。

落脚段为何固定：从低向高看B删除区间的末端e。

- 若e=s−1属于某次下降，e+1=s是活动源格，但e+2=s+1是保留C。B在e+2为N，能被该C锚定；更高的普通B段由此固定。
- 若e是其他临时C段顶，其上第一枚目标材料是固定N。若上面是活动源N，则本就属于前一种情况。故B在e+1可直接被固定N锚定。
- 最低的普通B段由本次新地面针支撑。

后续记录的落点d−1不可能停在前一活动源层s：那要求d=s+1，但s+1是目标C，不能同时是另一记录的目标N。故每段落脚B列在到达d−1之前已有固定锚点。

于是一次Pin补回所欠地面针，同时删除全部临时C、恢复全部N。拆框、补尾部后，目标列与纯普通柱完成。

<a id="s02-11-h13"></a>

### 5. 最低C下有至少两个空位的列

现在地面不是针，核心中没有P。假设最低C以下至少有两个空位。

<a id="s02-11-h14"></a>

#### 5.1 最多两次底块提升

如果最底两层已经全空，不作底块提升。否则取最低非空位置开始的最大连续N块[a,b]，沿其上方紧邻的空段尽量提高，直到紧贴下一份材料；记录原区间、上移量和所有标签。

这个上方空段必存在：否则最低N块直接接到最低C，而a≤2，最低C以下至多只有一个空位，与前提矛盾。下一份材料也必存在，最迟就是最低C。

每次至少提高一层。只有“原来从1开始，第一次只提高一层”还可能留下第2层非空。这时下一份材料必须是N：若它是最低C，整个最低区间原来只有一个空位。把刚移的块与上方N合并成新的最大连续块，再提高至少一层，即清空第1、2层。

因此最多两次。若确实移动了底块，最后一次记录的原起点a只可能是1或2。记该次移动后，块的最低格在β层。

<a id="s02-11-h15"></a>

#### 5.2 正规化不会移动已整理的底块

对整理后的核心执行第4节的简单正规化，得到v和恢复表M。

最后一次提高的块紧贴下一份材料。若下一份是C，块顶已给C直接下邻；若下一份是N，任何C下洞的最近N都位于这些新接入的上方N中。故M不会移动最后提高的块。两次提升时，第一块已包含于最后的块，也不会被M移动。

v的最底两层为空。整体降低一层得到v↓，其地面仍为空，所有C仍有直接下邻。可用第1.3节制造v↓，并在Pin前删除全部临时C。最高目标C低一层，留下本次Pin所需的顶部空间。

<a id="s02-11-h16"></a>

#### 5.3 只有起点2需要额外受控下降

- 没有底块提升：只恢复M。
- 最后底块原起点a=1：先恢复M，再用弱下落把整个块从最低格起依次送回地面。
- 最后底块原起点a=2：增加动作β→2。其余格随后以已回到2层的最低N为支撑，逐格弱落回去。

额外动作的区间[2,β−1]全空，没有目标C；它与M的区间不相交。它在桥柱B的新地面针上落脚。

<a id="s02-11-h17"></a>

#### 5.4 唯一可能的支撑依赖

β层N将参与额外下降时，需要防止M把它误用作固定锚点。

整理后的底块在β上方原本立即接N或C。若该材料保留在v的β+1层，它就是固定锚点。唯一会使β+1空掉的情况，是这枚N被正规化提高，形成M中的一条s→β+1；此时在v中，s以下最近N正是β层N。

这样的记录至多一条。若再有更高的活动源N，它与该记录之间已有保留C及其直接普通上盖，不会仍以β为最近下方N。

对这一条记录，先在v↓上执行弱下落：从s−1落到β，由β−1层N托住。随后Pin只把它提高到β+1，并将它从本次M批次中去掉。其他情况下不需要提前恢复。

因此批量顶针之前，按顶针后的坐标看，β+1处总有一枚固定N或C。它将锚定额外下降源β之上的B普通段。

<a id="s02-11-h18"></a>

#### 5.5 批次落脚与剩余弱下落

对M去掉提前记录，再加入β→2（若有），运行第3节批量构造。主列临时C已在Pin前清理，I只需包含这些下降区间。

没有额外动作时，最低落脚B段由地面新针或不动底块支撑。存在额外动作时，β→2由新地面针支撑；其上各段由第5.4节保证的β+1固定格锚定。更高M区间之间仍由各源s+1的保留C分隔，沿用第4节证明。

目标主列Pin前地面为空，所以本次不会生成额外目标针。M的N恢复到整理后的位置，唯一额外变化是β层N已到2层（若有）。

随后按底块提升记录的逆序恢复。每块内部从最低N到最高N逐个弱下落：原起点1的最低N落地；原起点2的最低N已由额外动作落位，跳过它；其余N都落在上一枚刚恢复的N上。两次提升时，最后一个合并块恢复后，第一块回到第一次提升后的中间位置，再将它逐格弱落即可。

只有被选中的N失去侧向支撑，其他材料继续由柱托住；即使块顶离开某个C下方，该C仍被柱固定。标签按记录依次回到原层。补尾部后得到目标S列。

<a id="s02-11-h19"></a>

### 6. 充要判据与半边构造闭合

D中的无C列由第1节制造；地面有针由第4节制造；两底空资源由第5节制造。D为假时，E由第2节制造。全部分支使用同一H，有限次正规化、支柱交接和恢复动作；没有依赖目标枚举或完整制造目录。

因此：

`S = { w | P(w) 且 (D(w) 或 E(w)) }`。

再结合[半边必要性](#s02-12)和[双候选约化](#s02-13)，四象限任意高度的半边判据也成为充要判据：

1. 目标本身稳定且两列通过S判据；或
2. 按较低最高C所在组确定唯一双格逆提升，前态两列通过S判据，且一次下落回到目标。

通过后分别制造两根带外向普通柱的列，交换成“普通柱、左列、右列、普通柱”，切掉两根外柱，得到半边。整图在两条轴中选一条，两半都通过时，用各自带框输入直接交换得到目标。

这闭合的是四象限S列、半边与可分整图。不可分目标仍可能通过交换后的Pin/Stack制造；没有由此推出任意强制尾部序列的结论，也没有推广到六象限三列半边。

<a id="s02-11-h20"></a>

### 7. 吸收外部批量落位研究的具体部分

[TMAM外部摘录](09-sources.md#s09-05-h5)的C7-BlockBatch与第3节共用同一机械机制。按摘录命名，A是本页A，永久支撑B是本页针槽柱N，触发C是本页E，落脚D是本页桥柱B。

本页吸收的是“源层用针解除侧向粘连、同行N组成活动双格、旁列挡块控制落点、满高C统一触发”的机制，并独立补齐了四列制造、同H装配、融合隔离、固定落脚段及拆框证明。

第5节采用最多两次底块提升和至多一次提前弱落，给出适用于全部D列的完整准备路线。外部前b枚压紧的公式可能进一步合并底块恢复操作；其完整语言定义与供应件尚不齐备，本页不把外部11层前驱的全部加工效果当成已验证结果，也不依赖它证明充分性。

## 02-12 四象限半边：两个候选的必要性与列条件下界

原文标识：`general/half-history-normalization.md`。

本文证明 everain 文献算法8的拒绝方向。使用[两个前态的约化](#s02-13)中的语法列条件B，不预设B已经等价于可制造的S列。

**结论：任意真实半破可得的四象限半边，都能从两列满足B的前态经一次下落得到。因此，目标本身和文中指定的单次双格逆提升均失败时，该半边不可得。** 作为推论，任意可制造的带纯普通柱列都必须满足B。

这里没有用B的充分构造作前提。逆方向由[完整列构造](#s02-11)独立证明，两者合起来给出S列和两个半边候选的充要判据。

层号从1开始，象限数4，高度上限H固定；普通格N、针P、晶体C。Φ表示一次完整下落。B及PDF的底部资源条件D、终点条件E见[定义](#s02-13-h1)。

<a id="s02-12-h1"></a>

### 1. 依赖与归纳对象

使用仓库此前已证明的三项结果：

1. 所有合法列满足[共用列不变量](01-foundations.md#s01-01)及普通资源条件。
2. [全部四象限可制作输出属于K](01-foundations.md#s01-06-h7)。因此合法下料上的Stack保留全部旧材料，只追加N/P；新料不能穿过某列最高旧C进入其下方。
3. 相邻两列的非针组占据互不重叠的高度区间；每个含C组只有一个晶体融合分量。不同列的C要接入同一组，必经同层相邻CC，不能用普通格跨层连接两个融合分量。

定义半边集合：

`C_B = { Φ(X) | X的两列均满足B }`。

这里X允许先带外柱准备，也允许在Φ中碎掉临时C；集合定义本身不宣称X可制作。[前态约化定理](#s02-13)已给出C_B的两个候选表示。

本页沿制造树证明每个真实Cut输出都属于C_B。Swap内的两次Cut使用同一归纳命题；不假设待证结论来制造它的输入。

<a id="s02-12-h2"></a>

### 2. C_B成员的结构证书

对Q∈C_B，前态约化给出两种证书。

**直接证书：** Q稳定，两列本身都满足B。

**双格证书：** Q稳定，有唯一一个相关的悬空针环组G，其C同时出现在两列。记其最低层m。G以下最高非空层r是一对NN，r+1<m；把它们提到m−1后，两列都满足B，且下落回Q。

证明还给出了后续归纳所需的更强事实：

- Q中所有导致B失败的晶体段底都属于同一个G。
- G内全部C属于同一融合分量；切开G的两列会删除整个分量。
- G由内部针环保留，双格所在层不是它最终的支撑来源。
- G在两列都有C，阻止更高的N/P落到G以下；双格与G之间全空。

这些是[前态约化第3至6节](#s02-13)的结论，不是对任意稳定网格的额外猜测。

<a id="s02-12-h3"></a>

### 3. 对列条件的三项保持性质

<a id="s02-12-h4"></a>

#### 3.1 追加最高C以上的材料

对于含C的列，最高C以上追加N/P不改变晶体核心、D或E。只需检查针的直接下邻；合法整图输出已经满足这项局部条件。无C列满足D。

因此在合法K下料上执行任意Stack，不会创造新的B失败核心，也不会改变已有失败的位置。

<a id="s02-12-h5"></a>

#### 3.2 删除完整晶体融合分量

允许删除任意若干完整C融合分量，保留全部N/P。每个同列连续C段只能整段删除或整段保留。对保留C而言，原直接N下邻和上盖保持；原NN终点保持；删掉下面的C只扩大终点查找区间。最低保留C以下的空位不减少，D不会由真变假。

共用普通资源条件也保持：新出现的晶体间空隙来自被删除的C段，而该段与两端保留C之间各有N隔开。若不隔开，就应属于同一融合分量而一并删除。

可能悬空的针只能位于最高保留C以上；先只让这些针下落即可恢复其直接下邻。这是Φ的合法前缀，且不会重新连接任何非针组。完整论证见[临时晶体消去](#s02-13-h11)。

所以原先满足B的列，在删除后整理尾部针，仍满足B。更一般地，原来所有E失败的C若全部被删除，剩下的列也满足B：保留C原有的合格终点仍在，没有新的失败来源。

<a id="s02-12-h6"></a>

#### 3.3 Pin输出的每一列都满足D

无保留C的列直接满足D。有保留C时，分两种情况：

- 输入地面非空：Pin在该列留下新地面针，故满足D。即使原地面C随顶破分量删除，新针仍按输入底层占用生成。
- 输入地面为空：由J，该列最低C下面已有普通格，并且至少有地面这一个空位。Pin把保留C提高一层；该C以下原有N/P不能被截顶，也不能越过它，数量不变，同时本列不生成地面针。因此最低保留C以下的空位至少增加一个，达到两个。若原最低C被删除，新的最低C更高，只会提供更多空位。

故每次合法Pin都把所有列带回D范围。结合合法列的共用条件，每列都满足B。该结论不限Pin之前的列是否满足B。

<a id="s02-12-h7"></a>

### 4. 同一切向下的闭包

设一个旧半边Q∈C_B。先在每列最高C以上追加任意合法尾部N/P，再删除若干完整融合分量，最后下落。证明所得半边仍在C_B。

<a id="s02-12-h8"></a>

#### 直接证书

若Q两列本身满足B，追加尾部不会改变核心，删除C并整理针也保持B。所得网格就是一个B前态，继续Φ得到所求输出。

<a id="s02-12-h9"></a>

#### 双格证书，G被删除

G内C属于同一融合分量，故删除时只能全部保留或全部删去。若G被删除，所有原B失败段底同时消失。第3.2节使剩余两列在整理针后满足B，仍得到一个B前态。

<a id="s02-12-h10"></a>

#### 双格证书，G保留

在实际网格中，把原r层双格提回m−1，再做相同的尾部追加和C删除。提升前的规范前态两列满足B；第3节保证追加、删除并整理针后仍满足B。

还需证明这个前态的下落输出与实际加工相同。

G和内部针环全部保留，因此G固定。新增尾部材料不能越过G在各列的C，进入G下方。所有其他低处材料原来都在r层双格之下，不能穿过双格。提高双格不会改变这些材料的分组、落点或G的针环；双格在两个网格中均为独立的水平NN组，不会在新位置粘到G上。

删除只会让r以下的障碍减少或下降。两种网格中，其余材料以相同的分组和次序下落，得到相同的低处堆积。原双格从r出发或从m−1出发，都落在这个堆积的同一顶部，落点不高于r。G以上的加工也相同。

整理尾部针只是这个计算的合法前缀，不改变结果。因此两个网格的完整Φ输出相同，实际输出属于C_B。

<a id="s02-12-h11"></a>

### 5. 改换切向会删除原失败核心

设整图由两个C_B半边拼成，随后只追加N/P和旋转。现在沿与原分半轴垂直的轴切开。

新半边从每个旧半边各保留一列。若该旧半边只有直接证书，所取列原本满足B。

若旧半边有双格证书，其所有B失败段底属于跨两列的融合分量G。新切向分开这两列，跨界C删除必然把G在保留列中的部分也全部删除。故该列所有B失败核心一起消失。

后续尾部追加没有改变这些核心，也没有产生新的C；其他被连带删除的C只会扩大原终点区间。按第3.2节，保留的两列整理尾部针后都满足B。因此下落输出属于C_B。

这一步不要求两个旧半边的G高度相同，也不要求最多只有一个旧半边不直接满足B。新切向分别删除各自的失败核心，不会把两个缺口拼成新的独立类别。

<a id="s02-12-h12"></a>

### 6. 沿制造树归纳全部Cut输出

为分析一次Cut的输入，沿Stack的下料支路向前追溯，吸收旋转、染色，停在最近一次非Stack结构操作。若最近是Pin，也立即停止，不继续把它归入尾部。

<a id="s02-12-h13"></a>

#### 原料、结晶或Pin

普通基础料没有C，满足D。结晶输出在当前高度内填满空格并替换针，各列为接地连续N/C列，满足B。Pin输出由第3.3节满足B。

其后的Stack只在各列最高C以上追加N/P。目标Cut保留两列并删除跨切线C分量；第3.2节给出B前态，故Cut输出属于C_B。

<a id="s02-12-h14"></a>

#### Swap或已有Cut

对更早的制造节点使用归纳假设。Swap先得到两个属于C_B的真实切后半边，再拼接；已有Cut输出则视为一个C_B半边加空半边。空半边也属于C_B。

其后的Stack只追加尾部N/P。若本次Cut沿原分半轴，适用第4节；若改用另一轴，适用第5节。两种情况下输出均属于C_B。

这穷尽基础料、结晶、Pin、Stack、Cut、Swap、旋转及染色。每次递归引用只涉及制造树中更早的节点，因此所有真实Cut输出都属于C_B。

<a id="s02-12-h15"></a>

### 7. 可用于拒绝的结论

结合前态约化，对任意合法半边Q，只需检查：

1. Q是否稳定且两列满足B。
2. 否则，按较低最高C定位G，将G以下最高非空层的普通双格逆提升到组底前一层；检查前态两列是否满足B以及下落是否回到Q。

如果两个候选都失败，Q不是半破可得半边。该必要性对任意H成立，包含任意多次早期交换、顶针、堆叠和临时晶体删除，不仅针对固定最后一次Cut输入。

整图只有两条分半轴。若每条轴都有至少一个半边被上述必要判据排除，则整图不可直接由两个合法半边交换得到。它仍可能需要交换后的Pin/Stack加工；不能因此判定整个目标不可制作。

<a id="s02-12-h16"></a>

### 8. 带纯普通柱列的必要条件

设目标列w已经能与相邻纯普通支柱共同制成，其他两列为空。这是稳定的两列半形，再沿原轴Cut即可原样输出，故它属于C_B。

其支柱列没有C，不可能满足双格证书要求的“G在两列都有C”。因此只能使用直接证书，两列本身满足B，特别是w满足B。

得到：

`真实S列 ⊆ { w | B(w) }`。

文献判据的必要方向在这里闭合。[完整列构造](#s02-11)已补齐B⇒S，包括底块整理、提前弱落和多间隙批量下降。因此理论上得到S=B；现有Python尚未接入全部新构造，程序失败仍不能直接当作判据失败。

本次只完成理论必要性和前态约化，未修改Python或电路。依据为既有K定理、共用列条件、新前态约化及制造树归纳；没有运行测试、枚举、求解器、物理模型或游戏。

## 02-13 两列前态的两个候选约化

原文标识：`general/half-predecessor-reduction.md`。

本文核对 everain 文献算法8的候选数量，承接[文献记录](09-sources.md#s09-04)。层号从1开始，N为普通格，P为针，C为晶体；高度上限H固定。

**已证范围：若半边能由两列均通过文中列条件的前态经一次下落得到，那么目标本身与算法8指定的一次普通双格逆提升，足以覆盖它。** 即使原前态含有最终碎掉的临时晶体，也可以约化到保留全部晶体的前态。不需要枚举不同提升层位或分别提升多个间隙。

本页负责前态之间的约化。[制造历史归纳](#s02-12)另证任意合法半边都存在这样的B前态，并得到拒绝方向。[完整列构造](#s02-11)另证通过列条件的前态可以实际制造，闭合接受方向。

<a id="s02-13-h1"></a>

### 1. 判据与命题

为避免把待证的S列完备性当作前提，单独记文中的语法条件为：

`B(w) = 共用条件 P(w) 且 (D(w) 或 E(w))`。

这里E是PDF的终点条件F；本页用Φ表示一次完整下落，避免重名。

- P：针接地或有直接下邻；晶体下方的针属于触地针前缀；非最高晶体正上方非空；晶体下洞有普通资源；晶体之间有洞时至少有两枚普通格。
- D：无晶体，或地面是针，或最低晶体以下至少有两个空位。
- E：每个正下方为空的晶体段底，或者从该处起连续至少三颗C，或者与同列最近下方C之间存在相邻NN；没有下方C时，还允许地面N作终点。

先证明不删晶体的情形；第7节再消除这一限制。取只有相邻两列的静态网格X，满足：

1. X的两列均通过B。
2. Q=Φ(X)，并且X中的每颗C都保留；其位置、标签不变。

X可以是不稳定的内部网格。实际制造时，它应先由外柱托住，再去外柱；不能把裸X当作已经完成的机器输出。

则有二择一：

- Q的两列均通过B，且Q稳定，使用Q本身；
- 两列最高C都存在且高度不同。取较低最高C所在最大非针组G，令m为其最低层，r为m以下最高非空层。必有Q[r]=NN、r+1<m、Q[m−1]=空空。仅把该双格从r移至m−1，所得Q′两列通过B，且Φ(Q′)=Q。

这正是算法8的两个候选，但这里只证明上述受限前态的覆盖性。

<a id="s02-13-h2"></a>

### 2. 两列几何与晶体组

使用[两列区间分组](01-foundations.md#s01-19)：每层至多一个非针组；相邻层仅靠同列连续CC连接。因此不同非针组的高度区间不重叠。跨越多层的组必含晶体。

由于本次不删除C，任何含C的初始组都不能移动。所有移动的N只可能属于单格N或水平NN；针仍单独移动。各列最高C以下的针是触地前缀，不移动。

含C组的高度区间在X与Q中相同。移动N可以在结算后贴到某个C组旁边，却不能增加该组的高度区间或把两个不同时段的C组接在一起。固定组也不能靠后来落下的材料补得新的正下方支撑：材料要到达它的某格正下方，必须从上方穿过该格，或原先就位于该格下方；后者只会向更低处移动。

所以Q重新分组后仍稳定。对于无C组，新接触只会把同层普通格合并；其下方支撑仍在更低层，不会因同层合并变成内部支撑。针保留独立身份。

<a id="s02-13-h3"></a>

### 3. 同时含两列晶体的悬空针环至多一个

考虑一个固定非针组G，其底层以下已无直接支撑，但它仍保持原位，而且支撑它的针链下端也在G内。记针链位于u列。

该针链不是触地针前缀：其下端接的是G内的非针材料。由[不变量Q](01-foundations.md#s01-01)，u列所有C都低于针链。因此，如果G在两列都含C，u列的最高C就在G中。

另一列v必须用连续C跨过这段针链，连接G内针链下端的材料和上端受针支撑的材料。因此v列在针链上方还有C，且：

`u列最高C < 针链 < v列最高C`。

G恰是较低最高C所属的组。这样的组不可能有两个：下方那个组的非前缀针已禁止同列在其上方再有C，上方另一个组就不能同时含两列C。

此处限制的是“同时含两列C的悬空针环”。只有一列含C的三连晶环可以有多个，不应把它们也错误地限制成一个。

<a id="s02-13-h4"></a>

### 4. 哪些下落会破坏列条件

<a id="s02-13-h5"></a>

#### D保持不变

C的位置不变。同列N/P不能穿过最低C，最低C以下的格数不变，所以该范围内空位数不变。触地针前缀也不变，故D在X与Q之间不变。

共用条件P同样保持：保留C上下的普通材料不能越过它，同列材料次序和晶体间普通格数不变；非最高C原有的直接上盖不能穿过它向下移动。针的直接支撑在结算结束时成立，晶体以下的针前缀未变。

因此只需检查D为假的列能否丢失E。C连续段长度不变，地面N也不会移动；三连晶终点和已有地面终点不会丢失。

<a id="s02-13-h6"></a>

#### 移动单格N会留下另一个终点

固定某个待检查C段底d，考察它与最近下方C之间的开区间；没有下方C时，考察地面至d以下。

若其中一个单格N确实移动，它最终必须直接落在同列材料或地面上。落在N上会留下相邻NN。落在针前缀上意味着D成立。落到地面则提供最低区间的地面N终点。

它不能通过落在下方C上，成为唯一且无相邻NN的新终点：该下方C不是最高C，X中其正上方原已有N。这颗N受该C阻挡而不动，更高的移动N只能先碰到它。若移动N就是原上盖，则它根本不能移动。

故在一个最终确实丢失E的区间内，移动的N必须都属于水平NN双格。

<a id="s02-13-h7"></a>

#### 原有相邻NN如何丢失

假设同列原有上下相邻两枚N，但输出在整个区间中没有任何相邻NN。下格必然比上格下降得更多。由上一小节，下格属于移动双格。

如果上格也移动，其初始组只能是单格N或水平双格。它的占位列集合包含于下方双格的两列；两者起初相邻，没有第三个材料能夹在它们之间。下面双格能经过的路径，上格也能经过。结算结束时，上格必追到下格正上方，仍形成NN，矛盾。

所以上格固定。它不能只是单层普通组：原下方双格占满两列，一旦双格离开，就没有其他底部阻挡。上格必属于固定含C组G。

原双格占满G紧邻下方的一层，阻断一切向下的CC连接，故上格所在层就是G的最低层m。丢失的终点只能发生在：

`固定G的底层N / 第m−1层普通双格`。

<a id="s02-13-h8"></a>

#### 原有C下邻如何丢失

另一种可能是X的C段底d原有直接下邻N，所以原先无须检查该处E；下邻移动后才出现洞。若最终确实没有其他终点，下邻同样必须属于移动双格。它占满第d−1层，故所在C组最低层就是m=d。

若该C段原有至少三颗连续C，下落后仍通过E。因此导致失败的只可能是短C段。

<a id="s02-13-h9"></a>

### 5. 所有失败都指向同一个G和同一对双格

以上两种失败都来自G下方第m−1层的普通双格下降。双格原来占满两列，任何从G内向下、穿过第m−1层的针链都会被它截断。双格下降后，G仍固定，因此支撑G的针链必须闭合在G内部，形成第3节的悬空针环。

这个G必在两列都含C：

- 若失去的是短C段的直接下邻，而G只有该列C，那么跨层连接只能由这一段连续C承担。针环至少要有下端非针格、针、上端非针格三个高度，迫使该C段至少三连，和短段矛盾。
- 若失去的是相邻NN的下格，上格在G底层。假如G的C只在另一列，针环就只能把非前缀针放在上格所在列。该列更高处仍有正在检查的C，违反Q。

故所有失败只能归到第3节唯一的G，它就是算法8选取的组。

原双格在G正下方，下降后也仍是G以下最高的材料。它占两列，下面的任何材料都不能穿过它；上面材料也不能越过G在各列保留的C，进入双格与G之间。因此其落点r唯一，并且：

`Q[r]=NN；r+1<m；Q[m−1]=空空`。

这不是按目标高度再分多个类别。m和r只是同一个恢复动作的两个参数。

<a id="s02-13-h10"></a>

### 6. 提回一对双格同时修复两列

把这对N从r提回m−1，其他材料保持Q的位置，得到Q′。

原失败列恢复了G底层C的直接下邻，或恢复了G底层N下面的相邻NN，因此E恢复。所有失败都由同一个G造成，不需要第二对逆提升。

还须检查另一列不会因提走r处的N而失去原有终点。若该列在m层是C，Q′直接补齐它的下邻；若是N，Q′在那里形成NN。两者都足以保护本次移动所在的C区间。

剩下m层为空的情况。该列从X开始就没有“m层C的下邻”或“m−1、m层NN”终点，所以要在提升后失去E，只可能是X的终点依赖了移动双格作为上格的NN，即该列在m−2层还有一枚N。逐项排除：

1. 这枚N若固定，原双格就不能向下移动。
2. 它若属于移动双格，两对双格起初上下相邻，最终也相邻。原失败列因此仍有NN，不可能失败。
3. 它若是移动单格，第4节保证它留下另一个NN、最低区间地面N或D。这个终点位于被提高双格以下，逆提升不会破坏它。

所以另一列也仍通过B。其他C区间不含被移动双格，条件不变。提升没有越过任何C，P和D保持；其上方第m层不会是针，因为两列在G中都有C，非前缀针不能位于那些C以下。

最后检查Φ(Q′)。第r+1至m−1层原为空，搬走双格不移除其他材料的直接下邻。G靠自己的针环保留，其他组保持Q中的支撑。只有提回的双格需要下降，它重新落在r处，得到Q。因此Φ(Q′)=Q。

<a id="s02-13-h11"></a>

### 7. 临时晶体可以从前态中消去

现在允许X下落时删除C。记Q中保留的C为保留晶体，其余为待碎晶体。先在原位置擦掉全部待碎晶体，保留所有N/P，得到Z。

<a id="s02-13-h12"></a>

#### 擦除不改变下落结果

采用[最大静止集合及精确落点](01-foundations.md#s01-16)的物理分解。初始最大组中，静止组的全部C保留，移动组的全部C在首次移动时碎掉；不可能在同一个初始组内一部分C保留、一部分C因下落碎掉。

擦除只拆开移动组，不改变任何静止组。拆出的部分是水平N块；针原本就是单独的组。原静止集合拥有只使用该集合内部和地面的支撑证书，因此擦除不会让其中任何组开始移动。

它也不会制造新的静止组。原移动组的支撑图没有通向地面或静止组的边，也没有有向环，否则相应组就应属于最大静止集合。擦除只删边；拆组产生的新边只在同一原组内，从较高的水平块指向较低的水平块。若拆分后有环，把各块映回原组，要么得到原移动组之间的环，要么整个环位于同一原组内而沿高度严格下降，两者都不可能。

因此移动N/P的集合保持。两种计算留下同一批水平N块和单针，同列来源次序相同，固定障碍相同。精确落点按来源高度递增，由共享列上较低固定格和已经落位的块决定；据此归纳，两种计算的最终位置及标签完全相同。所以：

`Φ(Z)=Φ(X)=Q`。

这里没有把下落中新产生的接触重新合组。

<a id="s02-13-h13"></a>

#### 擦除后的列条件

擦除保留每个含保留C的同列连续C段：相邻C属于同一融合分量，不可能只删其中一颗。原保留C的直接上盖和直接下邻若是C，也必须保留；若是N则本来就不擦掉。

因此晶体下洞的普通资源仍在。两个保留C之间若因擦除首次出现洞，被擦除的C段与两端保留C之间各有N隔开，至少提供两枚普通资源；原先已有洞的区间则本来已有这些资源。非最高保留C的直接上盖同样保留。

D只可能变得更容易满足：最低保留C不会更低，其下的空位只会增加，原地面针不变。若原来依赖E，则每个保留C段长度不变，原相邻NN终点保留；删除下方C只会扩大查找终点的区间，原地面N也保留。

唯一可能暂时不满足P的是：最高保留C以上的针失去了原来的C下邻。最高保留C以下的针原本属于触地前缀，不会有C被从它下面擦掉。

<a id="s02-13-h14"></a>

#### 先整理尾部针

在Z中先只让针下落到当前N/C或更低的针上，暂不移动N/C，得到X₀。这是一次下落的合法前缀调度。针永不粘连，所以暂停后重新分组不会改变其余组的身份；继续结算仍得到Q。

这个整理只影响最高保留C以上的针，或者已无C的列，不改变晶体核心的N/C条件。针已有直接下邻，X₀两列重新满足B。X₀只含最终保留C，并且：

`Φ(X₀)=Q`。

于是可以对X₀使用第1至6节的约化，原前态中的临时晶体不会增加第三个必要候选。

### 9. 半边落点与针环在两列中的位置

以下层号从1起算，字符串从地面向上读，T为普通格。目标半边有一列不属于S时，第一候选已排除。按第3、5、6节取较低最高晶体的组G、组底m及下方最高占用层r。两列均有晶体且最高晶体不等高、r层是普通双格、r+1<m且m−1层为空空时，把双格从r提到m−1，其他材料保持。两根候选列均属于S且一次共同下落逐格还原目标，当且仅当该半边半破可得。这里允许预制S列，最后半破拆普通外柱。若还要求切前每颗非地面晶体正下方非空，或本刀一定碎掉跨界晶体，须对实际四列前态另外取证。

八层实例的施工列为 `cTccTcPT | TTTcTccc | TTTc.... | ........`。切后保留前两列。第4层三列晶体与第一列第3层晶体同碎。第5层的水平普通双格仍同组，一起降至第4层，由第二列第3层的普通格挡停。成品为 `cT.T.cPT | TTTT.ccc`。一般地，若成品普通格u[d]脚下为空且d>1，v[d]必须有可与它同组的非针材料，否则这枚普通格还能再降一层。若它在本刀确实下降，能随行的只可能是普通格，因为活动晶体在首次下降时碎掉。因此v[d]是同行者，v[d−1]是双格最终的下挡。另有本来就在固定组内的普通格，目标列的空洞本身不足以确定它本刀移动。

[两列针环](03-general-construction.md#s03-03-h10)跨过k枚连续针需要对列k+2枚连续晶体，覆盖针串及上下两个非针端点。对侧只要在针旁断开一次竖直接合，就无法用两列绕过这串针。端点上方可以另叠材料。例如给八层例子的目标列和前态第一列顶上各加一枚T，得到九层目标 `cT.T.cPTT | TTTT.ccc.`。新增T直接立在原第8层T上，原环仍只有三连晶。多个针段须逐段检查是否返回同一组，固定的端点也可直接承托上方材料。

十二层例子区分连接两段材料的晶体与真正跨针的晶体。空尾保留以对齐高度。

```text
前态   cTccTcTcccTc | TTTcTcccPT.. | TTTc........ | ............
成品   cT.T.cTcccTc | TTTT.cccPT..
前态短代码
crCuCu--:CuCuCu--:crCuCu--:crcrcr--:CuCu----:crcr----:Cucr----:crcr----:crP-----:crCu----:Cu------:cr------
```

前两根施工列分别为紧N/C列、紧N/C后接P/T，第三列为紧N/C。各列均可独立制成接地紧列。先拼第一、二列，再接第三列，每列自身接地。切前所有非地面晶体的下格非空。切后下部删除和双格落点与八层例相同。第二列第6—8层晶体把第一列第6层晶体连到第8层。针只在第二列第9层，真正跨针的是第一列第8—10层晶体，第11层T与第12层c站在环上。第一列第6层短晶下有洞，又没有纵向TT终点，D、F均失败。其最高晶体却是第12层的单晶。若要求环脊位于第一列最高晶段，或由第二列跨针，便会拒绝这个可制作目标。若只要求某列有三连晶，该例仍满足。

在上述跨针意义下，十二层也是此类位置反例的最低高度。非S目标的D、F都失败。某段短晶体下有洞且没有终点。其下必有较低晶体，否则D失败要求最低晶体之下至多一空，正下方的洞用掉这唯一的空位，由普通资源与无底针可知地面为T，反而有终点。有较低晶体时，中间至少有两枚不相邻的T，并且上端还要留一个洞，故失败段底至少在第6层。按第6节，把双格提回m−1便修好F。这一步没有越过任何晶体，所以修好的坏段是从双格原层往上遇到的第一段u晶体。若v没有跨针的晶脊，G的环脊就在u中，其底至少为m。它至少三连，故不可能就是修好的短晶段，也不可能夹在双格与修好的短晶之间。因此u的环脊在短晶段上方，中间至少隔一格，最早占第8—10层。要使u的最高晶段少于三连，还要用一格隔开再放晶体，至少到第12层。

对论文构造H还可从最低保留晶体推出底部必要条件。设最终最低晶体在h层，目标核心经过一次Pin、按H下落及拆框。若目标没有地面针，Pin前目标地面必须为空，否则新地面针无法在本工序移走。抬高后第1、2层都空。h≤2时保留晶体无来源。h≥3时它下方至少两个空位，后续下落无法把保留晶体上方的材料补到下方，删晶也只能增加空位数。所以含晶目标能用H必满足D。`TcT.T.cPT`的最低晶体在2层，所需前身须占地面，Pin却会在那里生成无法去除的针。给定共同高度和论文H的装配顺序，还可有限判定这一模板。在带普通柱的起点枚举所有S列A，以及所有满足2≤d<s≤H的下降对的子集和临时晶锚层子集，按构造H生成I、J与三根辅助列。逐步核对辅助列制造、换柱、一次Pin、拆框和目标逐格相等。有候选通过当且仅当存在该规格的路线，每个通过者给出配方，规格内每份配方的A、下降表、锚层都在枚举范围内。已有固定输入的简单底部排除不需要这项搜索。该判定的制备范围是允许预制S列，核心恢复限一次Pin。

<a id="s02-13-h17"></a>

### 10. 半破前哪些空位必须已经留好

沿用第9节的记号。两组带上方间隙的实例给出了完整逆提升结果。

| 目标两列 | 抬升层号 | 提升后交给角工序的两列 |
|---|---|---|
| `cT.T.cT.Tccc` 和 `TTTT.cccccPT` | 4→5 | `cT..TcT.Tccc` 和 `TTT.TcccccPT` |
| `T.cT.T.cccccT.Tccc` 和 `PPTTTT.cT.TcccccPT` | 6→7 | `T.cT..TcccccT.Tccc` 和 `PPTTT.TcT.TcccccPT` |

两例提升后各列均过S。拆普通外柱时，双格分别由右列第3层和第5层的T挡停。第二例还可以实碎晶体。左列底部既可在角工序就做成 `T.`，也可在半破前保留 `cT`，切去地面临时晶体，让第2层的T落地。右列第10层和左列第14层在这两条路线切前都为空。

**必须预留的空格。** 若目标空格的水平邻格是同一半边的成品晶体，切前该位置不能放临时晶体或普通格。临时晶体会与成品晶体融合，两者同存同碎。普通格在碎晶后仍与成品晶体同组，成品晶体能留下就说明该组静止。若空格同列的上方和下方各有成品晶体，切前也不能放针，因为最高晶体以下的针只能位于接地针前缀。三种材料均已排除，故该格切前必为空。

**双格下方也有必须预留的洞。** 取下列13层施工列。第三列是爆破柱，第四列为空。

```text
切前   cTT.ccTccTcPT | cccccTTTcTccc | TTTTTTTTc.... | .............
成品   cTT.ccT.T.cPT | cccccTTTT.ccc
```

两根施工列都过S。左列第5、6层晶体脚下有洞，下方第2、3层相邻TT满足F。其余晶段有直接下邻或触地。右列及爆破柱为紧列。先拼带普通外柱的两列，换入爆破柱时右列从地面连续托到第10层双格，第11层以上另有针环。切时左列第8、9层、右列及爆破柱第9层晶体同碎。第10层双格由右列第8层挡停在第9层。成品左列第11层短晶脚下有洞，第6层晶体以上只有不相邻的第7、9层T，故成品左列非S。左列第4层空格远在双格下方，右邻、同列上方及下方都有成品晶体，必须在切前预留。若方案一要求下方每个洞都在最后一刀新开，此例排除方案一。方案二预留第4层，仅在双格下方的相邻空区实碎即可。

**针环上方也能在最后一刀开晶下洞。** 下列各施工列均为接地紧列，可独立制造后拼合。

```text
切前   cTccTcPTTTPT | TTTcTcccTcTc | TTTcTTTTTc.. | ............
成品   cT.T.cPTTTPT | TTTT.cccTT.c
```

第4层触发下部碎晶，第5层双格降至第4层，第6—8层针环保持。右列第10层的临时晶体也与第三列同层晶体同碎。右列第11层T旁边是针，单独落到第10层。右列第12层原生晶体与左列同层T相连，左列第11层针从下方托住它们。右列第11层的空位因此开在针环上方、原生晶体正下方。

**五项通过仍可能配不出半边。** 取11层单列 `cT.T.cT.T.c`。三颗晶体分别在第1、6、11层。每对相邻晶体间都有两枚普通格，低晶体都有直接上盖，列中无针，满足五项。地面晶体令D失败。第6、11层各有一个脚下为空的单晶，下方直到前一颗晶体都没有相邻TT，F有两处独立失败。半边若可得，第6节的逆提升必须修好这两处。逆提升只移动一枚本列T且不越过任何保留晶体，故至多修好其中一区间。无论另一列如何选择，该列都不能作为四象限一次半破的成品列。

若还要求切前填满整片相邻空区，需明确区域边界。取目标 `cT..T.cPT | TTcTT.ccc`，将第5层双格提回第6层后，左列第3—5层与右列第5层属于同一片边相连的空区。左列第3层有保留晶体为右邻，同列上下也有保留晶体，切前无法填满。此半边却有一刀配方 `cT...TcPT | TTcTcTccc | TTTTc.... | .........`。第5层右侧两枚临时晶体同碎，第6层双格落到右列第4层T上。若“下方相邻”只指双格实际扫过的层，第3层在指定范围之外，上述排除只适用于整片填满的解释。

## 02-14 四象限任意高度的零尾针起点闭包

原文标识：`general/zero-pin-source-closure.md`。

[完整列构造](#s02-11)使四象限任意H的半边判据成为充要判据。本页把既有[4q5l强制前缀闭包](#s02-09)推广到任意高度，不依赖外部Half目录或F0自动机表。

**结论：给定完整目标T，可以用两条切向上的强制前缀闭包，加上完整半边判据，决定T是否能由“合法双半形交换起点＋仅Stack追加”制造。** 该结论只解决零尾Pin来源，不给出任意目标的Pin次数上界。

<a id="s02-14-h1"></a>

### 1. 任意高度下仍成立的强制补格

先检查合法目标必需的共用列条件和K。失败即可排除本子问题。层号从1开始，无C列的最高C高度取0。

固定切向，从每列包含全部C的最小目标前缀U开始。任何仅用Stack追加到T的来源都必须包含U：Stack不能带入新C，也不能把新格插到旧列顶以下。

逐轮执行已有两种强制补格：

1. 在每个半边中，按连续CC竖边得到非针组的高度区间。若某组不稳定，补入能提供外部阻挡的最低目标N叶子及其列前缀；没有这样的叶子则拒绝该切向。
2. 对差额Δ=T\U按水平N块、单针分组。没有目标正下方支撑的块不可能由追加取得，必须整体移入U，并补齐相关列前缀。

前者的必要性只使用两列几何：新增N只能是原C组同层叶子，不能连起两个原C组。能新增这样的叶子的列，必是最高C较低的一列；该列的前缀顺序使最低合格叶子属于每个稳定扩展。纯N组只有同层另一列N这一种可能的新增支撑。针的直接下邻已由目标列条件及前缀保证。

后者的必要性只使用追加规则：以后扩大U只会从坏的Δ块删格，剩下子块仍无任何目标下方支撑，不能变成可追加块。

这些理由都不依赖H=5。每轮补入的格属于所有可能来源；没有补格时，得到唯一最小的“两半稳定且Δ可追加”的前缀U*。每个非终止轮至少增加一个目标占用格，因此每切向最多4H次增长。

但“两半稳定”在任意H下不能单独保证可制造，下一节补上这一点。

<a id="s02-14-h2"></a>

### 2. 稳定前缀之间的可制造性不再分叉

固定目标和切向，比较两个包含全部C的稳定半边前缀Q₁⊆Q₂。差别只在各列最高C以上的N/P尾部。

使用[完整半边判据](#s02-11-h19)：

- 直接候选的列条件只涉及C核心和底部资源；尾部针的直接支撑由目标及前缀保证。因此直接候选的列条件在两个前缀之间相同。
- 联合候选所选的两枚最高C不变。两列中的一个含C组只有一个融合分量；增加N叶子不会改变C融合分组及其最低层m。
- 可能需要联合候选的组G在两列都有C。因此m不高于任一列最高C；G以下的全部材料都已经属于强制核心。最高下方非空层r、r层双N以及中间空区间不随尾部扩展改变。
- 逆提升r→m−1只改核心内的两枚N。逆提升后的列条件仍只依赖同一个核心，故两个前缀也同时通过或失败。

稳定性之外的候选检查因此一致。若一个稳定前缀的两候选都失败，增加更多最高C以上的目标尾部不能修复；若通过，其他稳定前缀也有相同的核心制造入口。

这里依赖完整半边定理，不把普通列条件A直接当作任意高度半边构造。

<a id="s02-14-h3"></a>

### 3. 第二候选不必执行一般下落模拟

对已稳定的Q，设其候选满足：G底为m；m以下最高非空层r为双N；r+1<m；中间全空；提高双N后的两列通过完整列条件。

Q中的G底下没有阻挡，却稳定。两列组区间定理使它必须由组内针链支撑；中间空层阻止针链从G延伸到更低处。所以G有独立于r层双N的内部针环。

把双N提高到m−1时，它仍是独立水平普通组。原r+1层为空，搬走双N不会拆掉其他材料的直接下邻；G的针环保持。只有双N需要下降，沿空区间回到r，受Q中原有落脚点阻挡。

因此在这些条件下，Φ(Q′)=Q自动成立。可使用区间稳定扫描与上述局部条件完成候选检查，不必为每个候选重建一般物理模拟。任意不稳定输入不能省掉这些前提。

<a id="s02-14-h4"></a>

### 4. 完整算法与制造证书

对两个切向分别执行：

1. 运行第1节强制闭包，得到U*或证明该切向无稳定可追加前缀。
2. 对U*的两半执行完整半边判据。
3. 若某半失败，第2节证明任何更大稳定前缀也失败，故拒绝该切向。
4. 若两半通过，用[列构造与带框交换](#s02-11)实际制造U*，再按层追加Δ，得到T。

若某切向存在合法来源V，强制补格保证U*⊆V。V的两半稳定可造，第2节便保证U*的两半也可造。因此算法不会漏掉任何零尾Pin路线。反过来，成功时已给出真实的制造证书。

无C目标可直接以完整地面层为起点，再逐层追加。无C时K的支撑沿高度向下，没有晶体跨层环；所以其余N/P块均有直接下方支撑。非空目标必有地面材料，空物品不作为机器输入。

<a id="s02-14-h5"></a>

### 5. 扫描与时序复用

列判据只需扫描针前缀、C段长度（饱和到3）、相邻NN终点、最低C前空位计数（饱和到2）和共用条件。两列稳定性沿用区间扫描。

最直接的实现每轮扫描O(H)行，强制闭包最多O(H)轮，所以判定阶段有O(H²)时间上界。目标网格、最终配方和标签需要随H存储；循环控制只需四个前缀位置、扫描位置及有限标志。这里没有构造或统计外部DFA的状态表。

游戏端可复用同一行扫描器完成列条件、半边稳定性及两候选检查；两切向、两半和补格轮次都是控制参数。判定复杂度不等于生成配方的机器步数，以上也不是建筑数测量。

[外部游标摘录](09-sources.md#s09-05-h9)要求来源具有完整识别器。本页补齐了任意H下零尾Pin来源的判定和构造依据；其逐行游标、晶体连接边界、支撑义务及来源扫描状态如何联合合并，仍需另行设计，不能只按四个输出游标缓存。

本页是理论推广，尚未改动现有五层`minimal_start`或求解器。没有运行测试、目标搜索、物理模型或游戏。

## 02-15 四象限任意层：一刀碎晶的判据与批量环下落

原文标识：`general/four-quadrant-release.md`。

四象限五层的直接释放可推广到任意H≥2。第1—4节保留既有构造，第6节补直接碎晶的必要性，第7—10节给出一刀批量环下落及其紧前态边界；一般角仍使用完整S列构造。

<a id="s02-15-h1"></a>

### 1. 可直接推广的条件

设指定主列w满足[列条件A](03-general-construction.md#s03-03)。对每颗正下方为空的目标C_r，记最近下方N的目标层为m，层号从0开始。再要求：

```text
m=0，或w[m−1]非空。
```

也就是每个需要回落的N在目标位置有地面或同列直接阻挡。这不是要求整列连续；可以有多个晶体区间和多个间隙，数量随H增长。

<a id="s02-15-h2"></a>

### 2. 同一个制造过程

主列固定q0，永久助手放q1；另一朝向对称。

1. 把每个上述N_m的来源移到r−1。最高目标C以下其余空位填牺牲C，保留其余目标格。永久助手为H层N，仅在各r−1放P，防止把活动N固定在来源层。
2. 用连续晶体前缀和N/P后缀构造主列及助手。主列最高C以下连续；针仍只在触地前缀，所以该准备步骤合法。
3. 若没有牺牲C，直接得到目标角。否则在q3准备一根H层N/C柱：牺牲C所在层放C，其余放N。与前两列交换拼合。
4. 半切只保留q0/q1，切掉q3并连带删除主列牺牲C，活动N落回各自目标m。

这是`CornerBuilder._simple_corner`原来的过程，只把助手及触发柱长度从5换成H。

<a id="s02-15-h3"></a>

### 3. 为什么不会删除目标C

每段目标C正下方若有空隙，其最近N被放在该段C的正下方r−1，从上方把牺牲C与目标C隔开。下方若还有目标C，A要求其正上方非空，且两段C之间有空格时至少有两个N。

因此被上移的最近N不会是下方目标C正上方唯一的N；至少有一个未移动N把下方目标C与牺牲区间隔开。底部没有下方目标C时也不产生融合风险。其余直接相连的目标C构成连续段，不需要在段内填牺牲C。

永久助手没有C，远侧柱的C只与牺牲C同层相邻；原本隔离的牺牲区间也由远柱的N层隔开。所以任何触及切除侧的晶体融合分量都不含目标C。

<a id="s02-15-h4"></a>

### 4. 为什么多个落点互不干扰

永久助手是一根连续N/P柱。所有未移动主列N/C都在同层接到助手N；助手P只位于活动N的来源层r−1。因此未移动的主列格及保留C被固定。

若m>0，条件要求目标(m−1)非空。该格不会是另一个被上移N：它若为另一间隙的最近N，则对应的C必须在m−1与当前最近N_m之间，整数层号上不存在这个位置。它也不在某个活动N的来源层，因为这将要求目标m本身为C，与N_m矛盾。故它保留在m−1并获得固定支撑；移动N恰好落到m。m=0时则落地。

不同间隙由保留C及不移动N分隔，单列先后顺序保持，不会累计错落一层。最高C以上的目标N/P也没有被移动，按与助手共同构造的原层位保留。最终角是指定主列加永久N/P助手。

<a id="s02-15-h5"></a>

### 5. 程序中的范围

四象限任意H的`build`和`pair`接受上述直接释放；两列目标还须稳定。制造外向两角、拼合后去助手的证明同样适用，因为助手只含N/P。四象限五层仍另有已证的参数顶破，所以其列A充要条件保持完整。

### 6. 紧列前态的一刀问题

固定四象限、共同高度 H，层号从0开始。N、P、C分别表示普通格、针和晶体；交接包字符串中的 T、c对应 N、C。先剥离最高 C以上的尾部。目标核心 w满足共用列条件，至少有一个空位；底部连续针数记为 m。

这里的一刀问题采用以下前态范围：主列 A在 q0，保留的辅助列 S在 q1，q2为空，触发列 F在 q3。A从地面到最高目标 C连续非空，保留目标的底针前缀、全部原生 C及普通格标签，其余 C均为临时晶体。S也是覆盖核心的连续接地列，允许底针前缀，全部 C都必须在本刀中删除。F为连续接地 N/C前缀，只连接需要删除的晶体。一刀保留 q0/q1；之后只交接普通支柱、补回无晶体尾部，不再移动核心材料。

前态各列必须真实可制造，不能把另一份已经完成的非紧目标直接当作起点。一刀指核心恢复中的一次碎晶；前态的基础制造和普通支柱交接另行计数。m枚底针允许预制在 A中，其制造成本仍须计入完整配方。

按高度列出所有正下方为空的原生晶体段，得到记录

```text
(c_i, e_i, d_i, s_i)，
[c_i,e_i]：原生连续晶体段；
d_i：其下最近普通格的目标层；
s_i=c_i−1：该普通格在前态中的源层。
```

共用列条件保证 d_i存在，且 d_i至 c_i之间没有其他材料。把 d_i>0且 w[d_i−1]为空的记录称为悬空落点。它只描述最终位置下方为空，不表示目标整体不稳定。

**直接碎晶的充要条件。**若进一步要求 S只含 N/P，则存在上述一刀前态，当且仅当没有悬空落点。

**充分性。**把每个最近 N提高到 s_i，其他格保持，剩余空位填临时 C。S全取 N，仅在各 s_i改为 P。每段临时 C的顶端接到 F的晶体锚，一刀全部删除。所有未移动 N/C仍粘在 S上；d_i−1处的目标格不是另一枚待移 N，否则两枚相邻 N之间还须存在一段 C，层号上不可能。因此各活动 N都由固定下挡或地面恰好挡在 d_i。共用列条件保证下方原生 C的直接上盖没有被移走，临时 C与原生 C隔离。

**必要性。**原生 C不能下降或被删除，列内普通格不能互相穿过。为隔开原生 C与待删临时 C，原生晶体段 c_i的下方在前态中必须是其最近普通格，源层恰为 s_i。因为 d_i<s_i，这枚普通格必须下降。若 S在 s_i为 N，它会与连续接地的 S粘连而保持不动；故该层只能放 P。切去 F并删去临时 C后，它成为单列普通块，只能由地面或同列下方材料挡停。在一次下落中，经过邻列的同层普通格不产生新的粘连，不能作为刹车。因此 d_i>0时，最终 d_i−1必须非空。证毕。

这一条件与 H无关。对已经通过共用条件的字符串，禁止的局部模式可以写成正则表达式 `\.T\.+c`：一格空、一个孤立普通格、一段非空的空位、再接晶体。最高晶体以上的尾部不会匹配这个模式。

### 7. 把单孔环下落合并成一次任意距离下落

直接碎晶失败时，三连晶可以提供另一种一刀构造。设唯一悬空落点是第 j条记录 (c,e,d,s)，且 e−c+1≥3。允许两种位置：j=0；或 j=1，且目标第0至 d_0层连续非空。分别取辅助底针长度 a=0、a=c_0。这里记录从0编号，L=s−d≥1。

把每条记录的最近 N移到源层 s_i，再把 A的其余空位填成临时 C。S先全部取 N，作如下修改：

```text
S[0…a−1] = P；
S[d…s−1] = C；
S[c+1]   = P；
其他记录的 S[s_i] = P。
```

其余位置仍为 N。触发列 F只做到 A最高临时段的锚层，在每段临时 C的最上层放 C，其余位置放 N。环下落通道 [d,s−1]全部位于同一个 A临时晶体段内，因此这根 F同时能删除 A临时段和 S通道，不需要增加第三根辅助列。

**前态制造。**A先制作去掉底针的紧 N/C核心，再补回 m次底针 Pin。S的所有 C都高于其底针前缀，低于第一枚非前缀 P；先制造去掉底针的紧 N/C前缀，补回 a次底针 Pin，再追加 N/P后缀即可。F为紧 N/C列。三列均连续接地，可以先拼 q0/q1，再从另一份真实半形接入 q3。各列高度不超过目标核心高度，整个过程共用 H。

**一刀后的支撑环。**保留的原生 C_c、C_(c+1)、C_(c+2)，与 S同层的 N_c、P_(c+1)、N_(c+2)形成互相支撑：含三连 C的非针组被 P_(c+1)挡住，这根针又立在同一组的 N_c上。因此该组和这根针均不下降；S在其上方的连续 N/P也保持。

**指定落点。**A与 S在 s层的两枚 N属于同一水平块。本刀删除 S[d,s−1]及 A临时段之后，这个双格可以下降 L层。S的 d−1层是固定 N；A在 d至 s−1的材料已经删除，所以下方没有更高阻挡。双格恰停在 d层。这里 d>0，刹车由邻列双格的下方提供，不依赖目标 A的 d−1层。

a>0时，唯一更早记录的 N_s_0单独下降，由目标连续前缀恰好挡在 d_0。A第0至 d_0−1层全部保留且连续接地。更早的原生 C段从 c_0层起接到 S的 N_c_0，而这枚 N直接站在固定底针前缀上，保持不动。环与更早原生 C之间的普通格，也由 S下部连续前缀支撑。

其余更高记录按直接释放下降，源层的 S针不与活动 N粘连，目标下方的固定格决定落点。其他主列 N/C均由未移动的 S普通格或自身连续地面前缀保持。所有临时 C与原生 C之间仍有未移动的 N隔开，F不会误删原生 C。

故一次碎晶即可恢复整个核心，L可以任意大。它把单孔环下落的逐层重复改为删除一整段辅助通道；不要求 L≤1，也不依赖八层枚举。之后先接普通柱，再拆掉已经不含 C的 S，即可交接为普通支柱成品。证毕。

### 8. 允许临时晶体辅助列时的精确边界

**紧前态一刀定理。**在第6节定义的前态范围内，允许 S使用可制造的 N/P/C紧列，则一刀恢复核心当且仅当满足以下二者之一：

1. 所有晶下空段都具有直接落脚点。
2. 只有一个悬空落点，其原生 C段至少三连 C；它是第一条记录，或是第二条记录且目标第0至第一条记录的 d_0层连续非空。

两个充分方向分别由第6节和第7节证明。下面证明第6节范围内其他 S选择也不能越过这个边界。

**悬空落点必须带辅助普通格共同下降。**前态中 s=c−1层的主列 N必须移动。若同层 S为 P，或者 S的 C在切割或首次下降中碎掉，主列 N在余下下落中都是单列块，无法停在下方为空的正高度 d。因此 S[s]必须为 N，且它随主列 N共同下降。

这时原生晶体组的两个底部位置——A与 S的 c−1层——都失去原格。原生 C组不能随之下降。它不能含 S的 C，因为这些 C本刀都要删除，而原生 C必须保留。该组的高度区间仅为原生连续 C段 [c,e]；它与 S普通格的连接不会越过段端。

由[两列支撑区间性质](03-general-construction.md#s03-03-h10)，其余非针组不能形成跨不同高度区间的悬空环。下方双格移走后，原生组只能在自身高度区间内借 S的一串针返回自身；针链上下必须各有一枚同组普通格。因此区间至少三层，且 S内部存在一枚针 g，c<g<e，其上下各有不移动的同组普通格。尤其 e−c+1≥3。

**环上方不能再有悬空落点。**g针以下已有同组普通格，所以它不属于底针前缀；源列条件禁止它上方再有 C。环内 g以上的普通格固定，其上方连续 N/P全部固定。更高源层若在 S为 N，主列 N便粘到固定前缀而不能下降；要下降只能在 S源层放 P，使其成为单列块。因此所有更高落点必须有直接下挡，悬空落点至多一个。

**环之前至多有一条晶下空段记录。**考察任一更早记录 i。若 S[s_i]为 N，它与主列 N一同下降；若为 C，它在本刀删除。这两种情况都令更早原生 C组的两个直接下邻消失，迫使该组也用内部针环保持。这枚非前缀针和环内较高的固定普通格将锁住所有更高 S材料，排除本次悬空下降。

所以更早源层只能为 P。它也不能是非前缀针：否则其上没有 C，更早原生 C组至少有一枚固定 S普通格，该格以上的 N/P全部固定，本次普通双格仍不能下降。因此该 P必须属于 S的地面针前缀。设此针前缀长度为 a，得到 a≥c_i。为了保持更早原生 C组，S在 [c_i,e_i]中至少有一枚固定 N，故 a≤e_i。下一条更早记录的源层已经高于 e_i，不属于这个针前缀；重复上述论证即矛盾。故悬空落点之前至多有一条记录。

若确有一条更早记录，它就是记录0，且 a≥c_0>d_0。目标第0至 d_0层必须连续非空。否则取其中一处空位之后的第一个非空格：若是 C，它已构成更早的晶下空段，违反记录0的定义；若是 N，它最终所在高度的 S是固定底针，不可能带着同层辅助 N进入该格，只能单列下落或单独保持。同列正下方为空又不触地，无法停止。两种情况均矛盾。

必要性成立。底针前缀给出额外的一条可吸收记录；忽略它，会把第二条记录的合法环下落误判成无解。定理只约束紧 A、紧 S及本刀删除全部辅助 C的前态；非紧辅助列或保留辅助 C后再处理的路线须另证边界。

### 9. 一次扫描的选择算法

对已经通过共用条件的核心，只需从下到上扫描。记录最近普通格及其下方是否为空，遇到晶体段时读取该段的底层 c、顶层 e；仅在 c−1为空时生成一条记录。由此得到：

```text
没有悬空落点：                          直接碎晶；
唯一悬空落点为首记录，且≥3C：            环下落，a=0；
唯一悬空落点为次记录，且≥3C，前缀连续：  环下落，a=c_0；
其他情况：                              本紧前态一刀族不适用。
```

判定时间 O(H)，判定状态只需固定数量的标志与层号；输出 A/S/F证书占 O(H)空间。实际生成按第6节和第7节直接赋值，不搜索辅助柱，不逐个尝试完整前态。没有记录而核心含洞时，只填临时 C并一刀删除，所有原有 N/C由普通柱保持；核心本身连续时则无需碎晶。

第7节核心恢复只有一次 Cut，没有 Pin或单独 WeakDrop；前态底针和原料制造仍另算。这个结论保证所定义前态范围内的最少核心刀数，不断言七项完整成本的全局最优。对于未通过判据的列，继续使用已有可行构造，不能据此判为不可制造。

### 10. 七层、十层实例与底针前缀

目标字符串从下向上写作 `.T..ccc`，共同 H=7。其唯一晶下空段为 c=4、e=6、d=1、s=3；目标 d−1为空，是悬空落点。取

```text
A = cccTccc；  S = TccTTPT；  F = TTc；  q2为空。
```

下表画出切割前态和直接输出，N取 Cu，C取 cr：

```text
      前态 A S · F             一刀后 A S · ·
z=6        C N . .                    C N . .
z=5        C P . .                    C P . .
z=4        C N . .                    C N . .
z=3        N N . .                    . . . .
z=2        C C . C                    . . . .
z=1        C C . N                    N N . .
z=0        C N . N                    . N . .
```

前态短代码，各行拼接：

```text
crCu--Cu:crcr--Cu:crcr--cr:CuCu----:
crCu----:crP-----:crCu----
```

沿01/23切割，只保留01。A的 C0…2与 S的 C1…2、F的 C2同属待删融合分量。它们全部删除，N3双格下降两层，由 S的 N0挡停；三连 C与 S的 N4、P5、N6构成的环保持。直接输出为

```text
--Cu----:CuCu----:--------:--------:
crCu----:crP-----:crCu----
```

主列恰为 `.T..ccc`。交接纯普通支柱后，目标列不变。同一族 `.`后接 N、再接任意非空空段及至少三连 C，都可用第7节得到同高度一刀证书；空段长度决定一次下落距离。

十层目标 `T.cT.T.ccc`展示 a>0的情形。两条记录为 (2,2,0,1)与 (7,9,5,6)；第二条是唯一悬空落点，第一条的目标前缀只有地面 N，连续非空。取 a=2：

```text
A = cTcTccTccc；  S = PPTTTcTTPT；  F = cTTTTc。
```

前态短代码，各行拼接：

```text
crP---cr:CuP---Cu:crCu--Cu:CuCu--Cu:crCu--Cu:
crcr--cr:CuCu----:crCu----:crP-----:crCu----
```

同向一刀删除 A的 C0、C4、C5及 S的 C5。N1单格落地，N6双格降到5；第一颗保留 C2由 S的 N2及其下两根底针固定，上部 C7…9由 S的 N7、P8、N9组成针环保持。直接输出为

```text
CuP-----:--P-----:crCu----:CuCu----:--Cu----:
CuCu----:--------:crCu----:crP-----:crCu----
```

目标主列逐格为 `T.cT.T.ccc`，没有增加核心加工次数。S的两根底针需要在准备中预制，其 Pin成本不能遗漏。

底针也不是一刀的物理禁区。例如目标 `P.Tc`，取 H=4、A=`PcTc`、S=`TTTT`、F=`Tc`，前态为

```text
P-Cu--Cu:crCu--cr:CuCu----:crCu----
```

同向一刀只删除 A第1层临时 C及 F，保留下来的主列就是 `P.Tc`。A可先造 `cTc`，再在同 H内 Pin一次得到；该准备 Pin不截去原格。一般 m枚底针同理先造其上的紧 N/C核心，再补 m次准备 Pin，所有层仍不超过 H。

交接包 `no-one-cut.txt`把 `.T..ccc`和 `P.Tc`列作失败；上述制造证书说明这些标签不能解释为游戏中不存在一刀前态。正样本 `cT.T.ccc`又包含环下落，超过“S仅 N/P、只在提升源层放针”的直接碎晶规格。匹配现有样本与证明时，必须同时标明前态范围和准备成本，不能把当前生成器的拒绝当作不可制造证明。

本节结论来自任意 H的构造与必要性论证，例子的格子和短代码为静态转写；未运行测试、枚举、物理模拟或游戏。
