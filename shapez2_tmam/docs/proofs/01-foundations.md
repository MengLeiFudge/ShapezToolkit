## 01-01 通用列内不变量与顶针位置约束

原文标识：`general/column-invariants.md`。

本文属于 x 象限 y 层的一般理论，采用[参数化模型](#s01-03)的局部加工规则：普通形状与顶针下落不消失，晶体下落即碎，同列格位不能穿透。下列证明不要求整个图形稳定。不同象限数的切割、旋转仍须满足模型定义；没有运行枚举、仿真或游戏验证。

用 N 表示任意普通形状，P 表示顶针，C 表示晶体。层号从地面起为 1；“列”指某一个象限的纵向格位。四象限五层的独立单列数量和依赖稳定输入的逆向规则另见[特例文档](#s01-10)。

<a id="s01-01-h1"></a>

### 1. 列内格位可以怎样变化

源码依据是 `ShapeOperationCrystallize.ExecuteInternal`、`ShapeOperationPushPin.ExecuteInternal`、`ShapeOperationSwapHalves.ExecuteInternal/MergeHalves`，以及 `ShapeLogic.Logic_IsConnected/Logic_IsFused/Logic_AllowFallDownByOne/SimulateFallDownPhysics`。程序集及部件规则的核对范围见[来源记录](#s01-09-h18)。

1. 旋转只置换整列。切割保留或去掉整列；交换先切割、再拼接半形，不会把两份输入的同一列按层混合。
2. 重力只沿原列下降。两个最终保留的格不能在同列互相穿过；若两个格暂属同组，其相对位置也不会颠倒。
3. 普通格和顶针不会因下落或晶体连锁碎裂而消失。只要同列更高处的某个晶体还保留，这些较低的非晶体格也不能被顶层截断删掉。
4. 保留晶体不能下落。顶针会让它提高一层，其他研究范围内的操作不改变其层高。
5. 结晶把当前高度以内的空格和顶针都变成晶体，结果没有空格和顶针。
6. 堆叠上料的晶体不能进入结果。若下料中的某个晶体保留，它在本次堆叠中没有下落；上料格从高度上限外下降，不能穿过这个保留晶体进入其同列下方。下料其他部分可能移动或碎裂，不假设整个下料不动。

这些事实允许沿保留晶体所在列追溯制造过程。不能先把某个较低普通格删掉，再从上方把材料塞进晶体下方；上述操作并没有这种能力。

<a id="s01-01-h2"></a>

### 2. 不变量 Q：晶体下方的顶针必须属于触地针前缀

定义一列的触地针前缀为从第一层开始连续的 q 个顶针。q 可以是 0；紧接其上的格只要存在，就不能再是顶针，否则前缀还应继续延长。

**Q：一列中，只要某个顶针上方还有晶体，这个顶针就必须在该列的触地针前缀内。** 等价地，最高晶体以下的顶针只能构成底部连续前缀，不能悬空、不能夹在其他材料之间。

证明可沿制造树归纳：

- 基础输入没有晶体，条件为空；结晶输出没有顶针，也满足 Q。
- 旋转只换列。切割和交换保留某列时，也保留该列的整个针前缀。前缀从地面逐格受支撑，不下落；它不能被晶体碎裂删除。原先位于保留晶体上方的顶针也不能穿过晶体，变成它下方的新顶针。
- 堆叠的保留晶体来自下料且不下落。新顶针从上方进入，不能穿过它；原先就在它下方的顶针属于触地针前缀，不会移动或消失。原来位于它上方的旧顶针同样不能穿过它。
- 顶针把保留部分提高一层。原针前缀若非空，其下方必补一个地面针，得到更长前缀。若原前缀为空，新加在地面的针本身就是长度一的前缀；若该列原第一层为空，就不加针。原来位于保留晶体下方的顶针仍只来自旧前缀，其他顶针不能穿过保留晶体。
- 染色不改变位置或材料类别。

所以所有可制作图形满足 Q。该证明不要求每列独立受支撑，也不要求整个图形稳定，适用于半形和全图中的每一列。

<a id="s01-01-h3"></a>

#### 稳定但不可制作的单列

独立单列 C-P-C 逐层受支撑，但中间顶针上方有晶体，下面却是晶体，违反 Q。四象限表示为：

```text
cr------:P-------:cr------
```

它属于 K，却不可制作。在四象限五层中，结合 R ⊆ K 可知 R 严格小于 K；一般参数下不能反过来要求全部可制作状态都属于 K。

<a id="s01-01-h4"></a>

### 3. 不变量 J：晶体下方若有空隙，最近的下方格必须是普通形状

**J：对任意晶体，若其正下方在图形范围内为空，沿同列向下遇到的第一个非空格必须是 N。不能是 P、不能是 C，也不能一直到地面都没有格。** 第一层晶体直接接触地面，不适用这个空隙条件。

先看一次切割或顶针中保留的晶体。用加工前、统一升高前的坐标分类：

- 若它原来正下方是晶体，两格属于同一融合组，也属于同一粘连组。发生切割或顶破连锁碎裂时会一起删除；若下落，也不能只保留其中一个。因此在上格保留的情况下，下格也保留，二者保持相邻。
- 若它原来正下方是普通格，这个较低普通格不会消失。普通格即使下落，也不能穿过其他保留格；它仍是该晶体下面最近的非空格，只是间距可能增大。
- 若它原来正下方是顶针，Q 保证那里是触地针前缀的末端。切割时该前缀不动，顶针时整体升高并补地面针，不能在其上方凭空产生间隙。
- 若原来已有间隙，归纳前提 J 保证最近的下方格是普通格。它不会被删掉，也不会与其他保留格交换列内次序，因此仍满足 J。
- 若晶体原来在地面，切割后仍在地面；顶针后正下方是新针，不产生空隙。

堆叠时，保留晶体来自下料且不下落；下料其他格位的下落适用同样的分类论证，上料不能穿过该晶体插入其下方。结晶输出没有空格；旋转、交换拼接和染色不改变列内关系。因此，制造树归纳同样得到 J，无须先假设整个下料稳定。

直接推论：若某列底部为空，那么该列最低非空格不能是晶体。顶针也不能作为悬空的最低格：它独立成组，结算停止时必须有正下方格位；最后的截高不能删掉这个比它更低的支撑。这项局部性质在旋转、拼接后仍保持，结晶则消除所有顶针。因此，底部悬空的非空列，最低格只能是普通形状。这不等于整个图形重新分组后稳定。

<a id="s01-01-h5"></a>

#### 满足 K 和 Q 仍不够

四象限中的以下半形逐层通过右列向地面传递支撑，属于 K；没有顶针，所以满足 Q：

```text
crCu----:--Cu----:crCu----
```

但左列上方晶体隔着空格看到的下一个非空格是晶体，违反 J，不可制作。一般参数下保留的必要关系是 R ⊆ Q ∩ J；加入 K 的关系只在已有对应闭包证明的范围内使用。

<a id="s01-01-h6"></a>

### 4. 顶针逆向的通用位置约束

设 D 为非空可制作输入，T 为一次顶针的输出。这里只确定必然成立的信息，不把必要条件当作完整逆向算法。

<a id="s01-01-h7"></a>

#### 保留晶体的前态位置唯一

T 在第 z 层的晶体，必来自 D 同列第 z−1 层的晶体，且 z 至少为 2。不能用“先提高再掉回原位”解释保留晶体，因为晶体一旦下落就消失。D 可以另外含有后来碎掉的晶体；这些消失部分仍是一般逆向问题的未知量。

<a id="s01-01-h8"></a>

#### 输出地面针精确记录输入底层的占用列

D 第一层每个非空列都会生成一个新地面针，它不会移动或消失。因此这些列在 T 第一层一定是 P。

反过来，若某列在 D 第一层为空，任何旧顶针下面都必有一个更低的普通格：该列最低非空格不能是晶体（J），也不能是悬空顶针（局部针支撑性质）。如果旧顶针能保留，该较低普通格也不会被顶层截断或碎裂删除。它始终挡在旧顶针下面，所以旧顶针不能落到地面。

于是有精确等式：

```text
T 第一层为 P 的列集合 = D 第一层非空的列集合
```

T 的地面普通格只能落在 D 原第一层为空的列。T 第一层不能有晶体。

不稳定输入即使没有顶破，也可能在本次加工中下落。因此，一般情况下不能直接去掉输出底层、整体下移，就当成唯一前态。依赖稳定输入的四象限五层结论见[单列与逆向特例](#s01-10)。

## 01-02 单次物理结算的队列与列顶扫描

原文标识：`general/physics-scan.md`。

本页优化Python局部物理计算，保留原分组、最大静止集合、来源层落点和最后截高的语义。目标数、制造覆盖及游戏电路均不因此改变。

<a id="s01-02-h1"></a>

### 1. 分组只排序一次

原groups每发现一个组都在剩余格中重新取最小格。改为先排序全部候选格，再依次跳过已访问者。每次尚未访问的第一格仍恰好是当前剩余集合的最小格，邻接遍历和组划分保持。返回组仍按最小格位排序，因此不含C的移动块天然按来源层、同层最小象限排序。

每格最多检查两个横邻接和两个竖直晶体邻接。设m为输入非空格数，分组耗时由反复取最小值的最坏O(m²)变为O(m log m)，其中排序以外的邻接遍历为O(m)。

<a id="s01-02-h2"></a>

### 2. 用反向支撑队列求最大静止集合

先保持原粘连组，建立组间向下支撑边。对每组记录仍在集合中的不同支撑组数量；同时保存每个支撑组的反向依赖者。地面组永不剥离。初始把没有支撑且不触地的组加入队列；每剥离一个组，只递减其反向依赖者的计数。某依赖者计数首次归零且不触地时入队。

正确性分两步：

- 每次删除的组既不触地，也没有仍可能静止的支撑组。它不可能属于任何满足静止方程的集合，所以不会删掉最大不动点中的组。
- 队列为空时，剩余每组都触地或有一个剩余支撑，故剩余集合本身是不动点。结合第一点，它恰好是原反复全表过滤得到的最大不动点。

支撑环不会被误删；直接或间接依赖支撑环的组也保留。地面组即使计数归零仍保留。空地面种子使用相同算法，得到被抬高上料的静止集合。计数按不同支撑组去重，与原集合交判据一致；多处接触同一组不能重复记账。

每个组最多入队一次，每条组间边最多处理一次，图剥离为O(v+e)。每格只产生至多一条竖直支撑关系，v、e均不超过m；包括分组的总成本仍由O(m log m)排序主导。Rules.stationary返回原格位的静止集合，供collapse和上料摘要共用，避免两处维护同一套剥离逻辑。

<a id="s01-02-h3"></a>

### 3. 按来源高度引入固定障碍

原落点公式对每个移动块遍历全部结果格，只取同列且低于来源层的障碍。不能简单把每列所有静止格的最高值提前放入列顶：高于当前块来源的悬空静止格不会挡住该块向下运动。

新方法把全部固定格按高度排序。移动块仍按原来源层递增处理。处理来源层s前，仅把高度严格小于s的固定格加入列顶，取已有列顶与固定格高度的较大者。然后令块落点为其占据列最高列顶加一，并更新各列列顶。

不变量：处理每块前，列顶恰为“低于当前来源的全部固定格，以及更早移动块的落点”在该列的最高值。所有更早同列移动块原来源更低，且下落不升高，故其落点必低于当前来源。同层块不共享列。当前块落点计算因此与原过滤公式完全相同。

固定格保留在最终结果中；事件扫描只决定何时将它纳入障碍计算。超高格仍参与阻挡，直到最后fold才截高。该规则也覆盖Stack中高度上限外的静止上料，不能在扫描前裁掉它们。

每个固定格事件及每个移动格只更新列顶一次。除排序外，扫描为O(m+n)；折叠为实际输出高度与象限数的乘积。空输入、没有移动块、同层多个独立块都遵循同一规则。

<a id="s01-02-h4"></a>

### 4. K/G可达性也只需逐边传播

[support.py](../../synthesis/support.py)保留针必须紧邻下方格的先行检查。K使用地面格与全部针为种子，G仅使用地面格；随后从已可达格沿以下方向传播：

- 向上到紧邻同列格，表示下方支撑；接收格可以是针。
- 向同层邻格传播，要求两端都不是针。
- 向下到紧邻同列格，要求两端都是晶体。

这些有向边恰好对应原逐格判据的三个析取条件。队列从种子出发，每格首次可达时入队一次；因此结果是同一最小可达闭包。没有种子的悬空环不会自行变成可达；这与stationary求最大不动点并保留悬空环是两个不同问题，不能相互替代。

每格只有常数个候选邻接，故传播为O(m)，不再反复扫描全部格。optional_top仍只在最后允许最高层普通格不在可达集，不改变传播种子或边；针的先行检查也不会因此豁免。

<a id="s01-02-h5"></a>

### 5. 无C结算可以省去静止组计算

融合删除后的live若完全没有C，所有物理组都只占一层，支撑边严格向下。空地面种子下不可能有静止组，stationary可直接返回空集。

正常有地面的collapse也可以把所有组都交给来源层扫描，而不必先区分静止/移动。按来源层归纳：原本静止的地面组仍停在地面；更高的原静止组至少由下一层原静止组直接支撑，该下方组已由归纳保持原位，故它仍停在原层。更早来源块不会升到当前来源以上，无法把它抬高。原移动组则看到与原公式相同的更低来源结果，落点也相同。

因此无C快路虽然把原静止块也交给落点计算，输出仍逐格相同。它不会假定一般含C结算幂等；只在融合删除后的实际live无C时使用，仍保持最后截高。

<a id="s01-02-h6"></a>

### 6. 所有列顶一次计算

Rules.column_tops从−1初始化每列最高格，再对每个非空格执行一次max更新。归纳可知，它等于原先逐列过滤全部格得到的最大值；空列为−1，超高格仍计入。

Stack摘要求值、下料筛选、补C前缀高度及普通追加共用此方法，把O(nm)的逐列全表扫描改成O(m+n)。最高晶体层等其他专用判据不混用普通列顶。返回列表由当前调用持有，后续落点修改不会污染其他物品或缓存。

<a id="s01-02-h7"></a>

### 7. 范围与证据

[physics.py](../../synthesis/physics.py)实现分组、静止集合和落点扫描；[stack_plan.py](../../synthesis/stack_plan.py)复用空地面静止集合，并按列一次建立固定障碍高度。Cut仍先按原晶体融合组删除，Pin仍先按原底层补针且删除触顶融合组，Swap仍不追加拼接后重力。

本页给出操作级等价和复杂度推导。静态诊断不等于游戏验证，也没有测得完整求解耗时的加速比例。没有运行测试、枚举或运行时性能探针。

## 01-03 任意层数与象限数：可制作但不稳定的构造

原文标识：`general/general-model.md`。

当前研究先处理可制作性理论。用 n 表示象限数，H 表示层数上限。[四象限任意H的K定理](#s01-06)已将原4q5l支撑结论扩展到全部四象限可制作输出；它依赖四列融合屏障，不能推广到六列或八列。下文的八象限构造展示这一宽度边界。

用户补充的群内讨论把目标设为任意层、任意象限，并报告在八象限八层 Mod 中做出了需要再次执行下落才稳定的图形。下面独立给出一个八象限八层构造，按已核对的游戏操作代码进行手推；没有读取该 Mod 的实现，也没有运行 Mod、仿真或枚举，不能把群内验证当成本构造已经实测。

<a id="s01-03-h1"></a>

### 1. 参数化规则和证明范围

采用游戏源码的同一组局部规则：同层环邻接的非顶针格粘连，竖直相邻晶体粘连且融合；晶体下落即碎，普通格和顶针不因下落消失。堆叠上料提高 H+1 层；顶针排除原第 H 层并处理晶体融合删除；切割保留连续 n/2 列，交换先切割再拼接。

本构造取偶数 n=8、H=8，允许按一个象限为单位旋转、任意无晶体单层基础输入，以及所需的结晶颜色。`ShapeOperationRotate` 的代码按整数列数旋转；具体 Mod 是否提供相同旋转粒度，仍须以其操作定义为准。本文不预先规定奇数象限的切割方式。

N 表示普通形状，C 表示晶体，P 表示顶针，点表示空格；列 q0 至 q7 按环排列，q7 与 q0 相邻。所有晶体可以使用同一种合法颜色，颜色不是隔断融合的手段。

机器的一次加工只在开始时按格位分组。下落途中可以因晶体消失而拆组，但新接触不会合并独立物理组。输出只保存格位，下次加工会重新分组。因此，单次结算算子 F 不应被默认当成幂等算子；F(F(X)) 可能不同于 F(X)。实际状态仍可用格位表示，无须把上次的分组历史作为持久状态。

<a id="s01-03-h2"></a>

### 2. 构造可制作的悬空无针支撑环

<a id="s01-03-h3"></a>

#### 2.1 准备各列并拼接

先分别制造下列独立、连续占满的 N/C 列，字串从底到顶：

| 列 | 内容 |
|---|---|
| q0 | C N C C C |
| q1 | C |
| q2 | C C |
| q3 | C |
| q4 | C N C C C |
| q5 | C |
| q6 | C C C C C C C C |
| q7 | C |

每列都可通过逐层结晶配合普通辅助列制成，再切出目标列；辅助列与目标列切线两侧不同时为晶体，所以切出时不碎目标晶体。这是主文紧图形构造的 N/C 单列版本，提升到八层不改变该构造。

把相邻单列两两拼成两列片段，再拼成四列半形，最后拼成整图。每次交换的切线都选在当前片段外侧空列中，保留已组合片段内部的晶体连接。最终第一层八个 C 相连；q2 第二层 C 和 q6 的高晶体塔属于同一辅助融合组。q0、q4 第三至第五层的晶体被各自第二层 N 隔开，不属于辅助融合组。

<a id="s01-03-h4"></a>

#### 2.2 添加框架和内部普通格

在上述准备形上依次堆叠：

1. q1、q2、q3 三格相连的普通基础块。列顶最高为 q2 的第二层，故落到第三层，连接 q0 与 q4 的晶体柱。
2. q2 的单格普通形状。落到第四层，与两侧晶体柱不相邻，保持独立。
3. q2、q3 两格相连的普通基础块。落到第五层，连接 q4 晶体柱。

这时得到 D：

```text
       q0 q1 q2 q3 q4 q5 q6 q7
L8      .  .  .  .  .  .  C  .
L7      .  .  .  .  .  .  C  .
L6      .  .  .  .  .  .  C  .
L5      C  .  N  N  C  .  C  .
L4      C  .  N  .  C  .  C  .
L3      C  N  N  N  C  .  C  .
L2      N  .  C  .  N  .  C  .
L1      C  C  C  C  C  C  C  C
```

框架组 G 包含 q0、q4 的第三至第五层晶体、第三层的普通连接块和第五层 q2、q3 的普通块。第四层 q2 的普通格 B 独立：它与 q0、q4 分别间隔一列。

G 的第五层 q2 格被 B 阻挡，B 又被 G 的第三层 q2 格阻挡。两者已经互相支撑，同时 D 还有底部辅助材料。

<a id="s01-03-h5"></a>

#### 2.3 顶破辅助融合组

对 D 执行一次顶针。原第八层 q6 晶体被顶破，辅助融合组整组消失：第一层八个晶体、q2 第二层晶体和 q6 的晶体塔都消失。八列原第一层均非空，所以新增八个地面针。

q0、q4 原第二层 N 提高到第三层后，落到新地面针上，停在第二层。G 与 B 整体提高一层后仍互相阻挡，不下落，得到 S：

```text
       q0 q1 q2 q3 q4 q5 q6 q7
L6      C  .  N  N  C  .  .  .
L5      C  .  N  .  C  .  .  .
L4      C  N  N  N  C  .  .  .
L3      .  .  .  .  .  .  .  .
L2      N  .  .  .  N  .  .  .
L1      P  P  P  P  P  P  P  P
```

G 与 B 的支撑环没有经过地面或顶针；下面的针和普通格与它们之间有空层，不能提供直接支撑。S 是稳定的可制作图形，但不属于 K。

因此，K 对一般参数的可制作性甚至不是必要条件。这里的反例通过八层准备形取得，不能拿最终只有六层就声称它在六层上限下也可制作。

<a id="s01-03-h6"></a>

### 3. 再堆一格，得到不稳定但可制作的输出

对 S 堆叠 q1 的单格 N。q1 当前最高格在第四层，所以新格落到第五层。

本次下落中，G 和 B 仍是两个独立组，互相阻挡。新格到位后同时接触第五层 q0 的晶体和 q2 的 B；但本次结算不合并它们，故晶体保留。输出 T 为：

```text
       q0 q1 q2 q3 q4 q5 q6 q7
L6      C  .  N  N  C  .  .  .
L5      C  N  N  .  C  .  .  .
L4      C  N  N  N  C  .  .  .
L3      .  .  .  .  .  .  .  .
L2      N  .  .  .  N  .  .  .
L1      P  P  P  P  P  P  P  P
```

下一次按 T 的格位建立最大粘连组时，新格把 G 与 B 合并成一个组。这个组最低在第四层，第三层全空，原先 G 与 B 之间的支撑已成为同组内部关系，不再阻挡下落。它至少下落一层，其中晶体随即消失。

所以 T 可制作，却在重新分组后的意义下不稳定。无需假设游戏有单独的“重力机器”：再用 q7 单格普通料触发一次堆叠，也会重新结算下料；q7 的上料不能为 q0 至 q4 的悬空组提供直接下方支撑，无法阻止该组下落。

这个构造直接展示“机器输出”与“反复重新分组、下落直至稳定”的不同。一般理论若自动把每个输出替换成最终稳定态，就会改变合法制造过程。

<a id="s01-03-h7"></a>

### 4. 一般参数下，复杂堆叠也不能总拆成基础块序列

仍以下料 S 出发，这次上料 U 是 q1 上连续两层的普通格。U 本身可以由两次基础料堆叠制成。

真实的一次堆叠把两个格分别放在 q1 第五、第六层。G、B 在这整次模拟中保持原分组，所有框架晶体保留，得到 S 加上这两格的输出 V。

如果只允许从同一个 S 出发，改用基础单层块逐次堆叠，就不能得到 V：

- V 只增加 q1 的两个普通格。纯堆叠不能删除已落入高度上限内的普通格或顶针，也不能横向移动它们；因此不能先在其他列加永久辅助格，再假装这些格最后会消失。
- 一个基础单层块不能同时加入同列的两格。先加的 q1 单格必落在第五层，得到上一节的 T。
- 再次堆叠时，T 的框架重新分组合并，开始下落并碎裂。后续堆叠无法补回晶体。

因此，一般参数下“所有复杂堆叠都能从同一下料改成基础块堆叠”是假的，而且这里的下料已经有合法制造路径。此前该约化在 n=4、H=5 下由 R⊆K 保证；本构造不否定那个限定范围内的证明。

<a id="s01-03-h8"></a>

### 5. 对一般理论保留什么、撤掉什么

必须撤掉的一般性假设是：所有可制作图形都稳定；每次操作输出都可无损替换成完全稳定态；K 覆盖任意层、任意象限的全部可制作状态；复杂堆叠无条件等价于逐块堆叠。它们在上述参数化模型中已有反例。

仍可使用的局部事实包括：保留晶体不下落；堆叠上料晶体不能保留；同列保留格不能互相穿透；切割/交换不按层混合一列；每次顶针使保留晶体提高一层。因此，固定 H 时，某个最终晶体产生后沿自身路径最多经过 H−1 次顶针的高度界仍成立。任意 H 时没有由该界得到的统一常数。

[通用列内不变量](#s01-01)的 Q、J 可以改用这些局部事实证明，不必假设整个下料稳定；但无顶破时“只需删底层即可唯一反推”的结论仍需要输入稳定，不能直接搬到当前一般模型。

群内提到的 Rank 3 必须区分“展示一条用了三次顶针的路径”和“证明所有更少顶针的路径都不可能”。前者是构造上界，后者才是最小工序下界。[4q12截图的来源推导](06-forced-words.md#s06-01)与[全局交替排除](06-forced-words.md#s06-03)已证明：T₂从任意合法最后Swap起点出发都需要两次Pin，且中间必须Stack，最短尾部为P→S→P。证明使用[四象限任意H的K定理](#s01-06)：先通过历史融合屏障和支撑证书转交覆盖整个尾部，再处理基础料、Cut及Crystal根，得到R(4,H)⊆K。任意给定次数序列能否被强制仍未解决。截图最后一次Pin没有顶破事件，不能把Pin总数和顶破次数混用。[同列复用级联](05-cascades.md#s05-04)另证固定八象限、H=6k−1时存在恰需k次重新结算的可制作起点；这个固定起点结论不替代全局rank或强制工序的下界。

当前一般理论应先描述原始操作的可达集合，再寻找只在明确结构条件下成立的约化。不依赖具体 TMAM 的布局或控制流程。

## 01-04 一般参数：三列以上半形的悬空环与不稳定输出族

原文标识：`general/wide-half-loops.md`。

本页开始从固定范围转向 xqyl。先给出一个无限构造族：在单象限旋转、等分半切、任意无晶体单层原料及相同局部物理规则下，对所有偶数 `n=2k≥6`、层数上限 `H≥5`，都存在可制作但不属于 K 的半形，以及可制作但不稳定的整图。

构造只使用五层，不依赖顶破。增大 H 只改变堆叠机的临时上料高度，不改变所用普通块的落点及制造输出。结论来自下面的显式配方和人工证明，没有运行参数枚举、模拟器或游戏。

<a id="s01-04-h1"></a>

### 1. 目标半形 H_k

占据连续 k 列 q0～q(k−1)，其余 k 列全空。定义：

| 层 | q0 | q1～q(k−2) | q(k−1) |
|---|---|---|---|
| 5 | C | 全部 N | N |
| 4 | C | 全部空 | N |
| 3 | C | 全部 N | N |
| 2 | 空 | 全部空 | 空 |
| 1 | N | 全部空 | 空 |

q0 的三格晶体及第三、第五层的 N 帽属于一个外组 G；第四层 q(k−1) 的 N 为内组 B。因为 k≥3，B 与 q0 晶体不水平相邻。G 的顶帽被 B 阻挡，B 被 G 的底帽阻挡。

这个环不经过地面或顶针，故 H_k 稳定但不属于 K。接下来证明每个 H_k 都可制作，不能只凭这一语法结构就把它收入可达集合。

<a id="s01-04-h2"></a>

### 2. 制造辅助半形 A

分别制造三个连续独立列：

```text
q0       C N C C C
q1       C
q(2k−1)  N P N N N
```

N/P 柱逐层堆叠；N/C 柱用其余列辅助 N，逐层选择目标 N 或 P 并在 P 层结晶，最后切出目标柱。两个长度 k 的半面可以只交于目标列，例如 q0 使用 `{q0,…,q(k−1)}` 与 `{q(k+1),…,q(2k−1),q0}`。辅助列无 C，目标柱连续触地，故切割不改变它。

三个相邻列 q(2k−1)、q0、q1 的片段长度为 3≤k，可逐柱交换拼合。每次选切线分开已有片段和新柱，另一条切线落在已有片段之外，所以交换器的预先半切只丢掉空列。

然后半切保留：

```text
A侧 = {q(k+1), …, q(2k−1), q0}
```

q1 地面 C 被删除，与它融合的 q0 地面 C 也消失。q0 第二层 N 落到地面；q0 第三至第五层晶体通过同层相邻的 q(2k−1) 普通格连接到辅助针列，因此保持原位。

所得 A 只有 q0=`N - C C C`、q(2k−1)=`N P N N N` 两列非空，其他列均空。A 仍由辅助针列取得地面支撑。

<a id="s01-04-h3"></a>

### 3. 制造互补半形 B 并去掉两侧支撑

互补半面是 `{q1,…,qk}`。按下列顺序只用普通基础块制造 B：

1. 在 qk 取地面 N，再堆一个 qk 单格 N 到第二层。
2. 堆连续列 q1～qk 的 N 块，落到第三层。
3. 堆 q(k−1) 单格 N，落到第四层。
4. 堆连续列 q1～q(k−1) 的 N 块，落到第五层。

每步的落点由已有列顶及直接支撑确定；B 无晶体且稳定。

把 A 与 B 旋转到机器对应的互补半面并交换拼合。第三、第五层 N 帽连接 q0 晶体柱；第四层内块与外组互相支撑，外组此时还由 qk 普通辅助列和 q(2k−1) 针列支撑。

最后半切保留 `{q0,…,q(k−1)}`。两根辅助列 qk、q(2k−1) 均在删除侧，且没有被删除的晶体，故保留晶体不发生融合删除。留下的 G 和 B 仍互相阻挡、不下落，q0 地面 N 保持原位。结果恰好是第 1 节的 H_k。

这完成了所有 k≥3 的制造证明。准备形和每个输出最多五层；对任意上限 H≥5 均合法。

H_k的全部非空列顶都为4，因此由[接地来源与潜在粘合定理](04-stacking.md#s04-02)，它虽然不属于K，仍属于K_add，任意后续Stack可改成基础块序列。这不适用于下节不稳定的V_k。

<a id="s01-04-h4"></a>

### 4. 两个半形拼合，得到不稳定输出 V_k

再制造一份旋转 k 个象限的 H_k。两份分别占互补半面，各自稳定；交换器预先半切时只去掉空列，结果不变。随后拼接而不再执行重力。

输出 V_k 的第三、第五层全部填满非针格：q0、qk 为 C，其余为 N。第四层只有 q0、qk 两格 C，以及 q(k−1)、q(2k−1) 两格 N。第二层全空；第一层只有 q0、qk 两个 N。

第三、第五层的跨边界连接合并两个外组。第四层 q(k−1) 的内块接触 qk 晶体，q(2k−1) 的内块接触 q0 晶体，因此两个内块也被并入。按输出格位重新分组，所有第三至第五层格形成一个大组。

该组最低在第三层、正下方整层为空，无地面格也无外部阻挡，所以下一次重力结算必开始下落并碎裂全部晶体。V_k 本身是合法交换输出，故可制作，却不是重新分组意义下的稳定图形。

得到参数区域定理：

```text
对每个偶数 n≥6 和 H≥5：
存在 H_k ∈ R(n,H) \ K；
存在 V_k ∈ R(n,H)，V_k 不稳定。
```

这覆盖整个参数区域，不是只把八象限八层的现象复制到六象限。k=3 就是[六象限五层的具体矩阵](03-general-construction.md#s03-02)。四象限五层不在这个区域内，其 K 闭包没有被反驳。

<a id="s01-04-h5"></a>

### 5. 一般合成现在可以保留的保证

[六象限精确配方目录](03-general-construction.md#s03-01)的可靠性、完备性和终止证明不需要 R⊆K 或全局稳定性。对任意固定的偶数 n≥2、H≥2，在相同的明确操作模型下可作参数替换：

- 非空结构全集至多 `4^(nH)−1` 个编码。
- 种子为无晶体基础单层及可逐列制造的紧图形；半面宽度为 n/2。
- 保留真实旋转、半切、交换、顶针和双输入堆叠的原始输出，遍历旧目录中的全部合法输入组合。
- 堆叠临时上料升高 H+1；重力结束后截高一次；不增加稳定化。
- 每个新配方只引用更早轮次，有限目录停稳后未命中的目标不可制作。

当 n=2 时半切本身直接切出单列；其余紧图形拼合证明同样成立。H≥2 保证顶针原底层不等于被排除的顶层，适用目前采用的补针公式。

由相同的轮数归纳和制造树高度归纳，得到**固定偶数参数下的统一、有限但可能极昂贵的合成算法**。它给出一般研究的覆盖保证；不能据状态数有限就声称已经获得紧凑通用 TMAM 或实用求解器。

奇数象限切割、H=1 的顶针行为及具体 Mod 可用操作，仍须分别明确。`ShapeOperationCut` 的整数除法可以给出一个候选的不等分切割约定，但本页不把它未经说明地替换为已经约定的奇数模型。

<a id="s01-04-h6"></a>

### 6. 尚未解决的结构问题

本页证明了一个无限反例族及固定偶数参数的有限搜索覆盖保证。[主干线性界](#s01-07)已限制任意含C尾部的Stack/Pin次数，[K_add](04-stacking.md#s04-02)已扩大安全逐层堆叠范围。尚未完成的结构结论包括：

- 是否能给出随 n、H 增长仍紧凑的合成分解，避免完整格位目录与双输入笛卡尔积。
- 四象限更高层、六象限更低层等剩余参数区域的稳定性及可用约化；本页没有证明反例区域是精确最小边界。
- 固定象限数下的重新分组级联界、明确代价定义下的最少工序下界及强制工序。[逐级加宽的支撑环](05-cascades.md#s05-01)已另证n、H可增长时任意有限轮才稳定；该证明补足了从一次不稳定输出到多次级联的构造。

研究这些性质时，不能以稳定性或 K 作为一般目标的先验筛选，也不能把一次机器输出改写成反复重力后的状态。有限配方目录可作为理论上的完整后备方法，但新的结构定理仍需独立构造及证明。

## 01-05 四象限任意层：交换后第一次顶针保持 K

原文标识：`general/first-pin-support.md`。

本页证明一个比四象限五层闭包更窄、但不限制层数的结论。它用于[强制尾部顺序](06-forced-words.md#s06-01)中的任意交换起点逆推。采用相同的游戏分组、晶体融合删除、下落及截高规则；K 的定义见[堆叠约化](#s01-11)。以下均为静态人工证明。

<a id="s01-05-h1"></a>

### 1. 定理及范围

令 B 是两个合法切后半形交换得到的四象限图形，每个半形占相邻两列。高度上限 H 任意。先执行任意有限段 Stack，再执行第一次 Pin，得到 E。允许旋转，吸收到各段朝向中。则：

`B → Stack* → Pin → E  ⇒  E ∈ K`。

所以再接任意 Stack 段时，E 的旧格与晶体全部保留，后续只在列顶追加普通块或针。尤其不能用“第一次 Pin 留下额外晶体，随后 Stack 再碎掉它们”绕过目标前缀约束。

本页证明只处理第一次 Pin，输入从 B 到本次 Pin 之间没有其他 Pin 或删除加工；制造 B 的两份半形时可以使用这些操作。[整个尾部闭包](#s01-06)另用历史屏障与支撑证书转交，证明同一起点范围下第二次及后续 Pin 也保持 K。该页第7节再处理基础料、Cut和Crystal起点，进一步证明全部四象限可制作输出属于 K；这项推广不属于本页单次 Pin 证明本身。

<a id="s01-05-h2"></a>

### 2. 相邻两列中，一个非针组至多含一个晶体融合分量

非针粘连允许水平的 N/N、N/C、C/C，以及竖直的 C/C；晶体融合只允许相邻 C/C。

考虑同一个两列非针组内两颗 C 之间的一条简单粘连路径。任何竖直边两端都是 C。若路径经过一个 N，则只能从该 N 的水平邻格进入或离开；两列半形中它只有一个可用水平邻格。因此 N 不可能是连接两颗 C 的简单路径的内部点。两颗 C 之间必有完全由 C 构成的路径，即属于同一个融合分量。

还得到两个后续需要的性质：

- 含 C 的两列组，每个被占用的高度都含 C。N 只能是同层 C 的水平附着格；不含 C 的组只占一层。
- 若这样的组有任意一颗 C 在 Pin 后保留，则整个原晶体分量都保留。其全部 N 也保留：N 与同层 C 相连，而且该组最高占用层也是最高 C 层，不能只截去高处 N、却留下该组的全部 C。

上述“全部保留”包括不下落。只要原分量中有 C 下落或被融合删除，就不会还有该分量的 C 留下。

<a id="s01-05-h3"></a>

### 3. 四列任意高度的无针环有一道融合屏障

本节只研究互不粘连的非针组及它们的支撑边，不先假设这些组可制作。若若干这样的组构成有向支撑环，则其中某个组 G 有一层满足：

1. G 在这一层至少占三格；
2. 这一层有 G 的晶体；
3. 若还有未被 G 占用的位置，它与这一层 G 的某颗晶体水平相邻。

这里把这一层称为融合屏障。它不要求整个环只占三层。

<a id="s01-05-h4"></a>

#### 从一个支撑边找到相对的两根分支

取一个包含环的非针强连通分量，在其中选择最低占用层最小的组 G。选 G 指向该分量内另一组 J 的边。设支撑发生在同一列 q：G 占 (q,z)，J 占 (q,z−1)。因为 G 的最低层不高于 J 的最低层，G 也经过第 z−1 层。

四列环中，两个不同非针组若在同层共存，只能各占一个格，且位于相对列；否则它们重叠或水平粘连。因此第 z−1 层 G 在 q+2，J 在 q。

若 J 还经过第 z 层，那么 G、J 在这两层都只能各占相对的一格。跨层连接只能是同列 C/C，故各自不能换列。这与 G 在第 z 层占 q 矛盾。因此 J 的最高层就是 z−1；G 必有 C 位于 (q+2,z−1) 和 (q+2,z)。

第 z 层 G 同时占 q、q+2。若还占第三格，这一层已经是所需屏障：唯一可能空出的格必邻接 q+2 的保留 C。

<a id="s01-05-h5"></a>

#### 两根分支必须在上方接通

剩下的情形是第 z 层 G 恰好只占相对的 q、q+2。位于 q 的格若是 N，就没有同层邻格，也不能竖直粘连，不可能属于 G。因此它也是 C。

q 分支不能向下连接：它正下方属于 J。它只能向上延伸，才能与 G 的另一分支接通。沿这两根分支向上，直到 G 首次在某层占至少三格。在到达该层前，每层只有相对的两格，跨层连接又只能同列 C/C，所以两根分支不能横移或提前终止。若始终没有这样的层，两根分支永远不连通，与同属 G 矛盾。

首次出现第三格的那一层包含两根分支传入的相对 C。它至多留下一个空位，该空位必邻接保留 C。所需屏障存在。

<a id="s01-05-h6"></a>

### 4. 屏障阻止本次顶破删除传播到下方

在 Pin 的融合删除之后、下落之前建立组；考察最终从未下落的组。它们一直保持整体抬升后的原位置。

若这些组中存在无针支撑环，第 3 节给出一个屏障层。以下换回 Pin 输入的原坐标，记该层为 l。屏障是保留格，所以 l≤H−2。

第 l 层不可能有被本次顶破融合删除的 C：

- 已被屏障组占用的位置保留，不能同时被删除；
- 剩余位置若有待删除 C，就与屏障的保留 C 融合，后者也应删除，矛盾。

融合删除从原第 H−1 层传播到第 l 层或更低，必须经过第 l 层的 C。因此，本次 Pin 没有融合删除任何第 l 层及以下的 C。该区域的 N/针也不受顶层截断影响。

这里只论融合删除；不能直接断言下方全部格已经稳定。下一节用原半形支撑证书排除下落。

<a id="s01-05-h7"></a>

### 5. 屏障组仍保有原半形的支撑证书

交换输出 B 属于 K；前置 Stack 保持 B 的所有格、全部 C 和 K。这些事实分别来自[两列切割闭包](#s01-12-h3)与[堆叠约化](#s01-11)，证明不依赖 H=5。

选第 4 节屏障上的一颗保留 C，记为 v。Stack 不能带入新 C，所以 v 来自 B 的某个原半形。记它在这个半形里的原非针组为 G₀。

由第 2 节，G₀ 的全部 C 属于一个融合分量。既然 v 保留，G₀ 的全部 C 与水平附着 N 都保留，保持原组内部连接和统一抬升后的位置。交换或前置 Stack 新增的连接可能把它并入更大组，但不会拆开这份原组。

在原两列半形中，不同非针组的高度区间互不重叠：若同层各有一格，两格必相邻并属于同一组。因此从 G₀ 沿支撑边走：

- 若在经过若干针后回到 G₀，就得到含针环；其中的针处在 G₀ 高度范围内。
- 若走到另一个非针组，它的整个高度区间严格低于 G₀。
- 继续沿较低组向下，最终到达地面，或某个含针环。这也是两列切后半形属于 K 的证明。

第一种证书的 G₀ 已全部保留；环内针不会融合删除，其高度又不超过 G₀ 最高 C，所以不会被顶部截断。向下离开 G₀ 的证书中，其他非针组均低于 G₀ 最低层，从而低于或等于 v 所在的屏障层 l，第 4 节保证这些组的格全部通过融合删除和截断。途经的针可能仍在 G₀ 的高度范围内，但不会高于 G₀ 最高 C，因此同样不受融合删除或截断影响。若 G₀ 自身或证书末端原来触地，整体抬升后由新地面针托住。

因此至少有一份完整的地面路径或含针环证书被保留。这份证书本身稳定；它不会因为其他组下落而消失。交换和前置 Stack 合并非针组时也不会破坏证书：地面路径仍到地面，针节点不会被合并进非针组，含针闭合路径仍存在。

结论是：包含 v 的未移动组必有 K 支撑。

<a id="s01-05-h8"></a>

### 6. 排除所有坏组，完成证明

反设 Pin 结算后的某个未移动组不能到地面或含针环。未移动组不能靠移动组获得最终支撑，见[结算引理](#s01-12-h2)。在它能到达的支撑子图中取一个末端强连通分量。它不能包含地面或针；否则已有地面路径或含针环。因此其中有一个仅含非针组的环。

对这个分量应用第 3 至 5 节，得到其中某组仍有 K 支撑，矛盾。所以全部未移动组属于 K。移动过的保留组只剩水平 N 块或单针，它们沿向下的支撑路径到地面或未移动组，也属于 K。最终按新接触合并非针组继续保持 K。

于是第一次 Pin 的输出 E 属于 K，定理成立。

<a id="s01-05-h9"></a>

### 7. 对全局顺序问题的作用

对任意目标 T，研究 `B → Stack* → Pin → Stack* → T` 时，可以直接要求：

- Pin 输出 E 含 T 的全部 C，而且不能含额外 C；
- E 逐格包含于 T；
- 每列 E 是 T 的下方前缀；
- T−E 满足基础堆叠的落点与支撑判据。

这把“一次 Pin 后允许继续碎晶”的未知支路完全排除。它本身尚未排除具体目标的全部 Pin 逆像；[T₂ 的一次 Pin 排除](06-forced-words.md#s06-02)进一步完成了该例的两种切向及材料来源分析。两次及更多次 Pin 的支撑分析由[整个尾部闭包](#s01-06)补齐；这依赖新增的历史归纳，不能仅由本页定理重复套用得到。

## 01-06 四象限任意层：交换后的整个顶针／堆叠尾部保持 K

原文标识：`general/four-quadrant-tail-support.md`。

本页将[第一次顶针的结论](#s01-05)推进到任意有限个 Pin 和 Stack。对象仍是两个合法相邻两列半形交换得到的起点 B；不把任意稳定格位图当成合法起点。

**定理：四象限、任意高度上限 H，从 B 出发，只执行 Pin、Stack 和旋转，所有中间输出均属于 K。** K 表示每个最大粘连组都能通向地面或含针支撑环。允许任意合法上料，不要求上料只有一层。本文为人工证明，没有执行枚举、物理模型或游戏。

这个起点范围已足以处理[强制尾部顺序](06-forced-words.md#s06-01)中的任意最后 Swap 起点。第7节再单独处理基础料、切割和结晶起点，得到同一规则下全部四象限可制作输出均属于 K。

<a id="s01-06-h1"></a>

### 1. 贯穿尾部的材料来源

旋转可以通过调整起点和上料朝向吸收，以下保持列编号固定。

Stack 不带入能留在输出中的新 C。保留的旧 C 不下落；每次 Pin 只把它提高一层。因此在同一尾部中，任意两颗仍保留的 C 的相对位置始终不变。它们之间的融合邻接关系也不变。

固定 B 的某个原半形非针组 G₀，其中含 C。相邻两列中，G₀ 只含一个 C 融合分量，每个 N 都水平附着于同层 C，最高占用层也是最高 C 层。故只要 G₀ 有任意一颗 C 保留，整个 G₀ 都保留，并随 Pin 统一抬升；不能只删除其中部分 C 或同层 N。证明见[两列组引理](#s01-05-h2)。

G₀ 在原半形内有一份 K 支撑证书。离开 G₀ 后经过的其他非针组都严格低于 G₀ 的最低层；路径上的针可以在 G₀ 高度范围内，但不会高于它的最高 C。证书也可能直接回到 G₀，形成含针环，或 G₀ 本身触地。

这里的证书指完整保留相关组及其支撑边，足以给出地面路径或含针闭合路径。只要证书的格不被删去，它本身就能阻止下落；后续合并非针组也不会吞掉地面或针节点。

<a id="s01-06-h2"></a>

### 2. 同层两颗 C 构成可追溯的融合屏障

四列环中，同层两颗不同 C 的闭邻域覆盖全部四列。不论两颗 C 相邻还是相对，该层的任何其他位置都邻接至少一颗 C。

因此，只要这两颗 C 在一次 Pin 中保留，该层就不可能有被顶破融合删除的 C。顶破删除从顶部传播到该层及以下，必须经过该层，故该层及以下没有融合删除。

更强的是：若两颗 C 在某个较晚状态 Y 中仍存在，那么它们从 B 到 Y 一直存在。这道屏障也就一直存在，只随 Pin 平移。之前任何一次 Pin 都不能通过它删除下方 C。

于是得到历史保护引理：

> 设原半形组 G₀ 有 C 保留到 Y，其最低层在 Y 中为 a。若 Y 的某个不低于 a 的层含至少两颗 C，则 G₀ 的原半形 K 证书从 B 到 Y 一直保留。

证明：证书的其他非针组都低于 a，始终在这道屏障下；G₀ 自身因有 C 保留而整体保留；针不参与融合删除，其高度又不超过 G₀ 的保留最高 C，不能被截顶。原地面支撑在每次 Pin 后由新增地面针接续。按加工次数归纳，证书不会先失去支撑再下落。Stack 仅增加格位，不会破坏这份证书。

<a id="s01-06-h3"></a>

### 3. 没有同层双 C 时，支撑证书不能绕到上方晶体

设状态 Y∈K，G₀ 的最低 C 层为 a，且 Y 中所有不低于 a 的层都至多有一颗 C。

G₀ 的 C 分量只能是一根单列连续塔，记范围为 a 至 b。否则要在相邻列间连接 C，某层就至少有两颗 C。

含这根塔的最大非针组 V 也不能再含其他 C。任何粘连路径跨层都必须经过 C/C；从这一根塔接入别的 C 列，必在某层出现两颗 C。同列相邻 C 原已属于 G₀；若要接入隔着间隙的同列 C，也须借其他 C 列绕行，仍产生同层双 C。V 的所有普通格因此也在 a 至 b 内。

一般地，一个含 C 的非针组，每个被占用层都含 C：若某层只有 N，它不能通过竖直连接接入其他层。因此，Y 中其他含 C 组的高度范围不能与 a 至 b 重叠，否则又会出现同层双 C。它们只能全部在 a 以下，或全部在 b 以上。

现在沿 V 的 K 支撑路径行走。支撑边下降一层，纯 N 组和针没有跨层的内部连接；低处含 C 组的整个范围又在 a 以下。所以路径不能进入全部位于 b 以上的含 C 组。

这证明 V 有一份满足以下界限的 K 证书：

- 证书中的 C 只来自 G₀，或位于 a 以下；
- 证书中的全部 N/针都不高于 b。

它不要求仍使用原半形证书，允许之前的加工已经换过支撑。

<a id="s01-06-h4"></a>

### 4. 与保留 C 相连的普通横条形成持久屏障

考虑某层的一颗 C v，以及同层与它连续相连的普通横条。假设这些格占满四列，或占三列且唯一空位邻接 v。它们阻止顶破融合删除穿过这一层，理由与同层双 C 相同：已占位置保留，空位若放待删除 C，就会连带删除 v。

只要 v 在后续尾部中保留，这条普通横条也始终保留：它与 v 的连接只经过 N，Pin 不会拆断这种连接；整组不能下落而仍保留 v；同层 N 也不能比 v 先被截去。因而它是一道从形成时刻起持续存在的屏障。

令 Y 是这条横条已经形成的某个 K 状态，G₀ 是 v 所属的原半形组，a、b 为 G₀ 在 Y 中的最低与最高 C 层，横条所在层为 l。于是 a≤l≤b。

分两种情况：

1. **Y 中某个不低于 a 的层含两颗 C。** 第2节保证 G₀ 的原半形证书一直保留到 Y。从 Y 往后，新横条在 l 层继续保护证书的较低非针组；G₀ 整体保留，证书的针不受融合删除，也不高于保留最高 C。因此证书继续保留。
2. **Y 中不低于 a 的层都至多一颗 C。** 第3节给出另一份证书：其他 C 全在 a 以下，全部 N/针不高于 b。新横条阻止删除传播到 a 以下；G₀ 保留，其最高 C 又保证这些 N/针不会被截掉。因此这份证书也继续保留。

两种情况都得到：**横条一旦在 K 状态形成，其所属保留 C 此后始终有 K 支撑。** 这一步允许制造过程中更换支撑证书，解决了不能直接重复套用“第一次 Pin”证明的问题。

<a id="s01-06-h5"></a>

### 5. 反证排除首次离开 K

B∈K，K 上的 Stack 保持 K，旋转也保持 K。若存在反例，取第一次输出不属于 K 的操作，它必为 Pin；其输入及此前所有输出均在 K。

分析这次 Pin 融合删除后的结算。至少有一个未移动组不能到达地面或含针环，否则[未移动／移动组结算引理](#s01-12-h2)会使全部输出仍在 K。

在这些坏组可达的支撑子图中取一个末端强连通分量。它不含地面或针，必含非针支撑环。[四列任意高度的环屏障引理](#s01-05-h3)给出其中某组的一道保留屏障：某层至少占三格，并有保留 C，唯一可能空位邻接保留 C。

- 若屏障层有至少两颗 C，直接应用第2节。选其中任意一颗 C 的原半形组，其最低层不高于屏障层；原证书一直保留，坏组实际上有 K 支撑，矛盾。
- 若屏障层只有一颗 C，其余格全是相连的 N，属于第4节的持久横条。屏障来自未移动组，所以在本次 Pin 输入里已存在，不能是本次下落后才新接上的横条。取此前第一次形成它的输出 Y；按“首次离开 K”的选择，Y∈K。第4节保证直到本次 Pin 后，该 C 仍有 K 支撑，同样矛盾。

所以不存在首次离开 K 的 Pin。整个有限尾部始终保持 K。

<a id="s01-06-h6"></a>

### 6. 对强制工序研究的直接作用

对任意 `B → Stack* → Pin → Pin → Stack* → T₂`，第二次 Pin 的输出也在 K。因此它必须逐格包含于 T₂，并含恰好三颗目标 C；不能额外留 C，再用尾部 Stack 碎掉。

这消除了连续两次 Pin 逆推中的支撑范围缺口。[T₂ 的全局交替证明](06-forced-words.md#s06-03)再分析两次删除的时间、第一轮普通格下落及顶条来源，完成连续两次 Pin 的排除。本页闭包本身不直接给出具体目标的最少工序。

<a id="s01-06-h7"></a>

### 7. 补齐其他起点：全部四象限可制作输出属于 K

前述证明对起点只用了下列来源结构：它由若干不重叠的稳定一列或相邻两列片段拼成；每个原片段中，含 C 的非针组只有一个融合分量，所有附着 N 不高于该组最高 C；其支撑路径离开本组后只经过更低的非针组。原片段不要求仍是全图最大组，拼接后的水平粘连按非针节点合并处理。

一列片段同样满足这些条件。其含 C 组是连续 C 段；其他 N/针各自成组，支撑向下，含 C 组的最高格自然是 C。因此把证明中的“原半形”换成“原片段”，第1至5节的全部步骤仍成立。

沿任意制造树的 Stack 下料支路回溯，忽略旋转及仅改标签的染色，找到最后一次不属于 Pin/Stack 的操作。其输出分以下几种：

- **基础单层。** 按四个单列分片，每个非空格触地，满足条件。
- **Cut。** 输出占相邻两列，属于 K，原两列组与支撑区间引理直接适用；不要求 Cut 输入原本属于 K。
- **Swap。** 两个合法切后半形，正是已证起点。
- **Crystal。** 在当前高度内填满空格并把针转为 C，输出每列都是从地面连续占满的 N/C 前缀。按四个单列分片，各片段独立静止，具有逐段向下的支撑证书。拼接只合并非针组，不破坏地面支撑。

空产物按空条件处理。以上覆盖本研究制造操作的全部根情形。每个根之后的整个 Pin/Stack 尾部均由同一证明保持 K，所以任意 H 下都有：

`R(4,H) ⊆ K`。

这里只改变象限数与高度，不改变已约定的晶体融合、基础供料和加工规则。没有推出 K 是可制作的充分条件，Q/J 等必要条件仍不能省去。

直接推论：四象限合法成品的纯重新结算 F 恒为恒等；不存在需要再次纯下落才稳定的可制作四象限状态。该结论不禁止 Pin 顶破引起下落，也不禁止像 T₂ 那样强制交替 Pin 与 Stack。对偶数象限的非平凡 F 级联，结合两象限定理，最小象限数至少为6；已有八象限构造给出的上界仍为8。

## 01-07 一般参数下的堆叠进展量与线性尾部界

原文标识：`general/stack-progress.md`。

采用偶数象限n≥2、制造高度上限H≥2的既有规则，层号从0开始。F表示按当前格位分组、执行一次重力并截高。下文的输入是实际可制作图形，不把任意语法网格当作可制作输入；允许非K及不稳定输出。

结论：令b(S)为普通格与针的总数，c(S)为晶体数，θ(S)=b(S)−c(S)。每次改变结果的Stack都使θ至少增加1。含晶体目标T从最后一次Cut、Swap、Crystal或基础供料之后，存在至多

`θ(T) + nH + n·h ≤ n(3H−1)`

次Stack/Pin的主干尾部，h为T最低晶体的零基层号；另计一个净朝向调整；若只调用单象限旋转，它至多需要⌊n/2⌋次原生操作。这个界不包含各次上料的制造子树，不是完整制造树、搜索时间或建筑数量的线性界。

<a id="s01-07-h1"></a>

### 1. 可制作输出的无晶体组有直接支撑

性质B：重新按输出格位分组时，每个不含C的最大粘连组都触地，或至少有一格的正下方属于另一个组。不含C的组只能是单层水平N块或一个P，所以其下方格必然在组外。

基础单层显然满足B。旋转、染色保持B。结晶输出在其高度内每格都是N/C；不含C的组是一整行N，触地或受完整的下一层支撑。

对Cut、Pin及Stack，考察一次物理结算结束后、输出重新分组之前的组：

- 移动过的组不再含C，只剩水平N块或单P；它触地或在紧邻下方有最终阻挡。
- 未移动且不含C的组同样是单层N块或单P。它在结算终点有地面或另一个未移动组的直接支撑。
- 未移动且含C的组，不会因为截高而只留下一个无C低层片段。Cut和Pin的保留格在结算前已全部位于H层内。Stack中未移动的下料组全部在H层内，未移动的上料组则全部在H层外、整体删除；上下料最初分离，不能属于同一个初始组。

高度小于H的单层块不会部分截高，其直接支撑比它更低，也不会在最后截高时消失。输出重新分组时，如果某个最终组不含C，它只能合并若干同层N块，或者仍为原单P。原有下一层支撑不可能变成这个单层组内部的格。因此B成立。

Swap先分别生成上述Cut输出，再拼合。若拼合后的组含C，B不对它作要求；否则它仍只合并同层N块，或保持单P，低一层的支撑不会消失。故Swap也保持B。沿制造树归纳，所有可制作输出满足B。

B没有声称含C组稳定。交换后把多个旧组粘成一个无外部支撑的晶体组，仍然允许；[V_k](#s01-04-h4)正是这种情况。

<a id="s01-07-h2"></a>

#### 纯晶体组也保留直接支撑

另有性质C：实际可制作输出中，每个只含C的最大粘连组都触地，或至少有一个组外格紧邻其下方。它的组外直接支撑只能是N/P；如果下方也是C，就已竖直连接到本组。

证明：Cut、Pin、Stack结算后留下的C都来自未移动组。若输出中的该组只含C，原组也不可能含N：原N不随晶体碎裂删除；含幸存C的原未移动组全部在有效高度内，不会在最终截高时只失去N。原组的C位置没有变化，其他幸存C也没有移动，因此重新分组不能使原先分离的纯C组新增连接。故这个纯C组就是一个原未移动组，保留地面或最终组外直接支撑。

Swap会合并切后两半中的相邻纯C组，但各旧组的N/P支撑不会变成新纯C组的内部格，故仍保持性质C。基础料、旋转和染色显然保持；结晶结果是连续填满的N/C前缀，任一不触地的纯C组在其最低层下方必接N，否则下方C已属本组。因此制造树归纳完成。

结合B与性质C，实际输出中第一次重新结算就能开始下落的组，必须同时包含N和C。这个结论不适用于Pin/Cut已删除融合分量、但尚未执行重力的内部暂态，也不声称所有混合组都会下落。

特别地，横向一整片保留C若下面有整行空隙、同组又没有N，不能借“合法半切输出可能不稳定”解释成可制造半形。后续来源排除可以直接使用这个必要条件。

<a id="s01-07-h3"></a>

#### 实际加工输出中可锁定的未移动普通格

若实际Cut输出的某个含C最大组，其全部N都在第H−1层，则该组也触地或有直接外部下挡。Cut开始结算前没有高于H−1的格，所以这些顶层N没有下落；幸存C同样没有下落。这个输出组全部由未移动格组成，组内连接在结算前已经存在，不可能是落下的N新接出来的。它就是一个未移动的旧组，保留最终直接支撑。

Pin在截顶、抬升和补针后，也只在H层内执行重力，因此同样结论适用于其原始输出。这里的“未移动”仅指本次重力阶段，不排除Pin的统一抬升。不能把此结论直接用于任意Swap输出，也不能用于含从上料落入顶层的新N的Stack输出。

另一个可从输出直接识别的未移动条件是：一段连续N紧贴同列上方的幸存C。设C在c层，下面c−m至c−1层恰有m枚连续N。这些N不能来自该C上方，也不能由Stack上料穿过C添加；在本次重力前，它们必须保持列内顺序、各自不低于输出位置，又全部低于c。m个格位恰好填满m个位置，故每枚N在本次重力中都没动。这个条件适用于实际Cut、Pin及Stack的原始输出。

因此，如果某个含C输出组的每枚N都由上述连续N段锁住，或者在Cut/Pin中位于最高层，该组全部由未移动格组成，也必触地或有直接外部下挡。它可以含多颗C、多段N；不要求整个输出稳定。这个必要条件用于排除候选半形，不允许把Swap新拼合后的组也当作原未移动组。

<a id="s01-07-h4"></a>

### 2. 非空可制作输出必有地面格

使用[通用J不变量及针的直接支撑](#s01-01)。假设非空图形最低占用层m>0：

1. m层不能有C，否则该C正下方为空，J要求同列更低处有N，与m最低矛盾。
2. m层不能有P，否则违反针必须有正下方支撑。
3. 因而m层只有N。此层没有C，N又没有竖直粘边，所以这些N属于仅占m层的无C组。它们不触地、下方全空，与B矛盾。

故至少一列在第0层占用。此结论不要求全图稳定，也不允许因此删掉中间空层。

<a id="s01-07-h5"></a>

### 3. 一次重新结算若改变结果，必减少晶体

在D的最大粘连组支撑图上，静止集合由反复剥离“无地面、无剩余外部下方支撑”的组得到。如果第一轮没有可剥离组，所有组均静止，F(D)=D。

如果存在第一轮可剥离组，B保证它不可能是无C组，因此至少一个含C组开始下落并碎掉晶体。随后是否还有普通格下落不影响这个事实。F不生成晶体，所以

`F(D) ≠ D ⇒ c(F(D)) < c(D)`。

反过来，晶体数减少当然意味着图形改变。因此对可制作D，F(D)=D当且仅当晶体数保持。不能将此判据用于任意网格：悬空单N就不满足B。

F还可由合法实体操作取得：把全P基础层结晶为一层纯C上料，然后Stack到D。该上料抬高后无静止组，C全部碎裂、不加入N/P；结果恰为F(D)。故反复F的每个非空状态仍可制作，每次非恒等结算至少损失一颗原晶体；至多c(D)次改变后稳定。判断已经稳定可能还需一次相等检查。另由[逐级加宽的支撑环](05-cascades.md#s05-01)给出n=4k+6、H=6k−1的可制作族，每次恰损失六颗C、共k轮后稳定。[同列复用构造](05-cascades.md#s05-04)进一步给出固定n=8、H=6k−1的任意有限轮族。因此即使宽度固定为八象限，允许高度增长时次数也无统一常数上界；这不声称达到本页的c(D)上界。

<a id="s01-07-h6"></a>

### 4. 任意堆叠段的线性长度界

[精确堆叠分解](04-stacking.md#s04-06)保证：下料贡献恰为F(D)，上料不贡献C，只能贡献新的N/P。下料N/P不消失、不升高，也不可能在最后截高时被删。

记a为实际保留的上料N/P格数，d为损失的下料C数。则

`b(Stack(D,U)) = b(D)+a`，

`c(Stack(D,U)) = c(D)−d`，

`θ(Stack(D,U))−θ(D) = a+d ≥ 0`。

若a=d=0，由第3节d=0得到F(D)=D；又没有任何上料格保留，所以Stack输出就是D。故每次非恒等Stack均有a+d≥1。这个结论保留一次加工的原始输出，没有在结果后补F。

一段仅含Stack及旋转的制造过程可删除恒等Stack。旋转不改变θ，且−nH≤θ≤nH，所以从起点D开始，有效Stack数量至多

`nH−b(D)+c(D) ≤ 2nH`。

更精确地，若该段终点T已知，数量至多θ(T)−θ(D)。这把一般下料的Stack段变成按θ严格递增的有向无环关系；上料选择仍可能很大，也不能把非K下料的一次复杂Stack改成多次基础Stack。

<a id="s01-07-h7"></a>

### 5. 顶针的计数损失最多n−1

对非空可制作输入D，记g为原地面占用列数，t为原最高允许层H−1上的N/P数，d为本次消失的C数。

Pin只删除原最高层的N/P；其余N/P先升高一层，再下落，不会超出H层或因融合而消失。按删除前地面占用补出g根新针。因此

`b(Pin(D)) = b(D)−t+g`，

`θ(Pin(D))−θ(D) = g−t+d ≥ 1−n`。

这里用到第2节的g≥1，以及t≤n、d≥0。H≥2保证原地面不是被排除的最高层。该结论允许Pin触发顶破、原不稳定结构下落及晶体消失。

<a id="s01-07-h8"></a>

### 6. 任意含晶体目标的主干尾部界

从制造树根沿Stack的下料支路、Pin/Rotate的唯一输入回溯，停在最近的Cut、Swap、Crystal或基础供料，记该输出为A。尾部仅含Stack、Pin和旋转；各上料仍保留自己的真实制造子树。

每颗最终晶体都已在A中：Stack上料不能增加C，Pin只抬高或删除C。最终保留的C不能下落。若尾部有p次Pin，T中每颗晶体的层号都等于其A中层号加p，因此p≤h，其中h是T最低C的零基层号。

令i为尾部已经执行的Pin次数，定义

`Ω = θ(当前物品)+n·i`。

有效Stack使Ω增加至少1；Pin由第5节也使Ω增加至少1。删除恒等Stack后，主干Stack/Pin总数L满足

`L ≤ θ(T)−θ(A)+np ≤ θ(T)+nH+nh ≤ n(3H−1)`。

可单独给出Stack次数s的界：

`s ≤ θ(T)−θ(A)+(n−1)p ≤ θ(T)+nH+(n−1)h`。

旋转与Pin等变；旋转后的Stack等于共同旋转两输入再Stack。把主干旋转移到末尾，同时调整各次上料的净朝向，即可只留一个主干净朝向调整。它可以用至多⌊n/2⌋次单象限旋转执行；若机器还提供半周旋转，可能更少。移入上料的旋转计入上料子树，不是免费加工。

例如6q5l的宽松界为84次主干Stack/Pin，8q8l为184次；各自另加一个净朝向调整。这里不把一般n下的任意角度旋转误计为一次原生加工。四象限五层已有依赖K及半形构造的更强专项结论，本页通用界不替代它。

<a id="s01-07-h9"></a>

### 7. 对搜索与时序电路的含义

本页给出每条规范化制造尾部的线性深度界，只依赖n、H与目标计数，并不限制搜索要尝试多少条尾部。寻找起点、恢复上料制造凭据、展开侧支及判断不可制作仍未因此完成；候选总数和完整制造树可以远大于主干长度。

后续实现可用一个θ计算器和一个Pin计数器管理尾部进展，用同一份候选生成、物理判定和回放模块逐次循环。不能按尾部上界复制84套或184套电路。状态存储、候选分支、请求/确认和稳定采样时序仍需分别设计、统计；本页未生成新的游戏网表或走线。

证明依赖局部物理、B及J的制造树归纳、计数恒等式和保留晶体的来源追踪。已静态核对[Rules.collapse/stack/pin/cut/swap](../../synthesis/physics.py)的直接边界，没有执行测试、目标枚举、物理探针或游戏验证。

## 01-08 Pin计数以下的普通材料前缀与可省的高次数尾部

原文标识：`general/pin-clock-prefix.md`。

采用偶数象限n≥2、固定高度上限H≥2。起点是任意合法最后Swap输出，尾部只含Pin、Stack及可吸收的旋转。Stack允许任意合法上料；无需假设全图属于K或稳定。N、P、C分别表示普通格、针和晶体，层号从0开始。

**若一条制造尾部含至少H−1次Pin，则同一目标存在零尾Pin的制造路线。** 因此最少尾Pin数为正的目标满足`min Pin ≤ H−2`。这里允许重新准备两个合法半形；不减少固定起点的必需Pin数，也不计半形与上料的准备成本。

<a id="s01-08-h1"></a>

### 1. 随Pin次数提高的晶体下边界

设已经完成i次Pin。尾部中现存的每颗C都来自起点，其当前高度为原高度加i。Stack不能带入保留C，C下落时会碎掉，所以当前所有C都在第i层或以上。来源与计数依据见[主干尾部界](#s01-07-h8)。

记Eᵢ为当前物品第0至i层的N/P，擦去这一范围内的全部C，舍弃更高材料。只在i≤H−1时使用这个记号。

**前缀引理：Eᵢ独立稳定。** 它无需借助任何C或更高材料支撑。因为Eᵢ全为N/P，这等价于每个水平N块和单针都触地，或有直接下方支撑；这些支撑沿高度严格下降，最终到达地面。

<a id="s01-08-h2"></a>

### 2. 前缀引理的操作归纳

<a id="s01-08-h3"></a>

#### 起点

i=0时，E₀只含地面N/P，自然独立稳定。起点的高层可以不稳定，这不影响地面结论。

<a id="s01-08-h4"></a>

#### Stack

已有Eᵢ提供只使用低层N/P的完整支撑路径。第i层以下没有C，非针组不可能从第i层穿进更低层；因此把第i层N与同层C连接，也不会把它正下的支撑合并为组内支撑。旧Eᵢ全部保持。

新进入该前缀的材料只可能是普通块或针。它们若下落并停在第i层以下或恰第i层，阻挡位置必在更低层；那里没有C。因此每个新增块触地，或被更低的N/P直接挡住。按落点高度递增，这些块都加入独立稳定的N/P前缀。

同层普通块重新合并不会吞掉位于下一层的支撑边。一次Stack的原始输出因而仍满足结论，无需额外稳定化。

<a id="s01-08-h5"></a>

#### Pin

由i次进入i+1次，并先设i≤H−2。旧Eᵢ的格不会被截顶；它们提高一层，原地面N/P下方的新针继续提供地面支撑。原地面C下方也可能增加针，这些新针自身触地，不会破坏已有证书。

提高后的所有C都在第i+1层或以上。旧Eᵢ的纯N/P证书因此保持，不能因更高处顶破而失去支撑。

其他材料若进入新前缀第0至i+1层，必在本次结算中下落：它们原来高于i，直接抬升不会进入这个范围。每个落入的普通块或针仍由更低的N/P或地面阻挡，和Stack情形相同。故Eᵢ₊₁独立稳定。

旋转只改变列号，保持上述性质。归纳完成。这个论证没有把六象限以上的整个输出当作稳定图形，也没有把一般Stack替换成基础单层Stack。

<a id="s01-08-h6"></a>

### 3. 达到H−1次Pin时的全部材料

先考虑尾部恰有H−1次Pin，并且成品T含C。

所有目标C都来自起点地面，现在只能位于第H−1层。每个这样的晶体列，在每次Pin之前地面均非空：第一次是旧C，后来是此前生成的针。最终该列恰为：

`P^(H−1) C`。

该列没有空洞，也没有其他N/P可插入其下。目标全部N/P则属于E_H−1，故擦掉目标C后仍独立稳定。

<a id="s01-08-h7"></a>

#### 零尾Pin的显式重建

1. 对每个目标C所在列，预制一根`P^(H−1) C`紧柱。可从地面C开始做H−1次Pin，这些Pin属于起点准备；每次输入C都低于最高允许层，因此不被顶破。
2. 在两个互补半面内分别拼好这些独立紧柱，其他列先空置。各柱都有同列触地支撑，切出半形时保留整段已有C。再Swap得到B′。
3. 从低到高添加目标的其余N/P。每个水平N块作为一次无晶体基础上料，每根针单独追加。由于目标N/P擦晶后独立稳定，各块都有地面或已经完成的下一层支撑，恰好落到目标高度。

B′的晶体列已经占满全部H层；新增材料不会使用这些列，因为其中的目标N/P已经全部是B′的针前缀。因此高晶体不会挡住新增块的落点。其他列按高度递增填入，没有先放上盖、再向其下插料的问题。

得到`B′ → Stack* → T`，零尾Pin。各柱及半形均有实际制造过程，不只是一个稳定候选。

<a id="s01-08-h8"></a>

### 4. 更多Pin与无晶体目标

若尾部含至少H次Pin，任何起点C都会达到上限外，不能留在成品中；Stack也不能补回C。因此成品全为N/P。

[可制作输出的无晶体组支撑性质](#s01-07-h1)保证这样的成品稳定。其所有组都是单层N块或针，支撑边严格向下，可以直接从地面开始逐层Stack制造。第一层可由两个基础半形Swap拼出，其余层逐块追加，仍是零尾Pin。

同理，第3节中恰有H−1次Pin但最终无C的情况也直接归入此处。空目标单独按空输出处理，不构成正Pin数下界。

于是任意一条至少H−1次Pin的路线都具有零尾Pin替代。反过来，若目标的最少尾Pin数为正，它的任何路线都不可能达到H−1次；已有路线必满足：

`1 ≤ min Pin(T) ≤ H−2`。

<a id="s01-08-h9"></a>

#### 全部保留晶体原来触地时的同一改写

更一般地，若一条含p次Pin的路线中，全部目标C都来自起点地面，则它们在目标中同处第p层，各自下面恰为p根连续触地针。先准备这些`P^p C`柱，再从低到高补其余N/P，同样得到零尾Pin路线，不要求p=H−1。

第0至p层的新增N/P由前缀引理独立支撑。第p层以上没有C，所有N块和针由可制作输出的支撑性质获得下一层支撑；该支撑可以是第p层C，也可以是已添加的N/P。晶体列在第p层以下已经占满针，新上料不会在那里插入格；第p层以上则可正常在这些柱上堆叠。因此逐层追加没有来源冲突。

特别地，若目标C全在同一层h，而某条路线有h次Pin，那么该目标其实具有零尾Pin路线。故这类目标若最少尾Pin数为正，还满足`min Pin ≤ h−1`。这没有把“所有C同层”本身当作零尾Pin的充分条件；p=h这一来源条件是证明所必需的。

<a id="s01-08-h10"></a>

### 5. 对三次必要顶破的直接约束

结合[四象限顶破几何与顶盖替换](07-reductions.md#s07-01-h7)：如果一个四象限目标要求每条路线至少有e次晶体破坏，则其任意路线至少需要`e+floor((e−1)/2)`次Pin，而且它不属于零尾Pin目标。因此：

`H ≥ e + floor((e−1)/2) + 2`。

三次必要破坏要求H≥6。因此**四象限五层及更低上限，不能出现强制三次晶体破坏的完整目标**。[四次Pin的完整排除](07-reductions.md#s07-03-h6)进一步要求三次必要破坏至少有五次Pin，把高度下界收紧为H≥7，排除四象限六层及以下。[唯一低处释放与顶层边界](07-reductions.md#s07-05)进一步得到三次必要破坏要求H≥10，排除四象限九层及以下。这里排除任意合法起点下的必要性，并不禁止某个固定起点执行三次破坏。

一般偶数n仍有`min Pin ≤ H−2`，但四象限的DDD排除不能用于六象限。[六象限最低两层来源定理](07-reductions.md#s07-08)另行证明：最终保留C都来自起点第0、1层时，目标至多需要两次晶体顶破。因此六象限五层也不能强制三次顶破；六象限的三破坏目标至少要求H≥6，但六层存在性及四/六象限任意高度命题仍未解决。

<a id="s01-08-h11"></a>

### 6. 保留晶体下面的第一次落地时刻

这一节直接约束任意指定Pin/Stack序列，适用于所有偶数n，不要求稳定或K。主干旋转吸收到输入朝向，下面沿同一材料列追踪。

先固定目标T的一列q：它含保留C，最低C高度为c；最下部恰为r根连续地面针，其上第r层为普通格N。其余N/C及空位不作限制。设任意合法尾部的Pin总数为p。

**若p>r，则起点该列地面必空；目标最低N必来自起点，而且第一次落地恰发生在已经执行`p−r`次Pin时。** 这个时刻可能是第p−r次Pin的下落阶段，也可能是它之后、下一次Pin之前的一次Stack，不能仅凭针数区别二者。

<a id="s01-08-h12"></a>

#### 地面占用一旦出现就不再消失

Stack不删除旧N/P，地面格不能再向下移动；地面C也不会在Stack中下落。Pin只要看到原地面非空，就先按该占用补一根新地面针，即使原地面C随后融合删除，新针也保留。故地面占用掩码沿尾部单调增加。

若起点q地面非空，第一次Pin后q地面为P。以后每次Pin都在现有针前缀下再补一根，旧针前缀不可能下落、被截顶或被Stack改写；目标在第r层有N，保证这些低针尚未达到截顶高度。p次Pin会迫使目标至少有p根地面针，与r<p矛盾。因此原地面为空。

<a id="s01-08-h13"></a>

#### 第一枚落地格只能是原有N

保留C的来源高度是c−p。它始终挡住上方新料，因此目标在它下面的全部普通格，都已经存在于起点；这些旧N既不能穿过C，也不可能在C下方被截顶删除。其列内顺序和标签保持，目标最低N对应原来最低的N。

原地面空时，[Q不变量](#s01-01)禁止保留C下面存在原有P：那会是非触地针。Stack上料也不能穿过保留C到达其下方。C不能下落并保留，Pin不会凭空给原来空的地面补针。因此，该列第一次出现地面占用，只能是原来最低的N落到地面；不会是另一枚随后消失的普通格。

<a id="s01-08-h14"></a>

#### 针前缀精确记录后来的Pin次数

记这枚N首次落地之后，主干已经累计执行j次Pin。同一个Pin步骤先按输入地面补针、后结算下落；若N在这次Pin中才落地，本次不会在它下面补针。

此后每个Pin都把这枚N与已形成的针前缀一起提高一层，补一根地面针。Stack不能从上方插到N下面。故最终这枚N恰处于第p−j层，下面恰有p−j根针。与目标第r层N比较，得到：

`j = p−r`。

此式对每个合法交换起点和上料都成立，不要求预先锁定来源网格。又因为起点地面空，而第1层C下必须非空，保留C的来源高度至少为2，所以同时有`p≤c−2`。

<a id="s01-08-h15"></a>

#### 用于任意序列时能推出什么

若已另证总Pin数p，不同列的针前缀r_q就能锁定对应最低N首次落地的Pin计数：`j_q=p−r_q`，适用于r_q<p的列。这些都是全局路线约束，不能通过提前准备不同针前缀绕过。

但它尚不提供p的下界；p≤r_q时可以把针前缀放进来源。它也不区分同一Pin计数区间内的多次Stack，更不能阻止多个列同时落地。要据此证明任意序列，还必须分别锁定总Pin数、各落地事件由Pin还是Stack触发，以及事件之间不能并行的原因。

[六象限重排反例](06-forced-words.md#s06-11-h13)展示了地面到达时间确实会阻止固定起点的工序交换；该例目标另有零尾Pin来源，所以没有被当作本节所缺全局下界的证明。

证明使用材料来源、纯N/P支撑、原始加工结算和显式起点重建。没有运行测试、枚举、求解器、物理模型或游戏；未修改Python或电路。

### 1. 覆盖性究竟需要证明什么

记基础输入集合为 B，合法操作为 O，可制作集合 R 是包含 B 且对 O 封闭的最小集合。若方案覆盖集合为 C，证明 B 包含于 C，且每种合法操作作用于 C 内任意合法输入后仍落在 C，就得到 R 包含于 C。

这是对制造树的归纳：基础输入是叶子，机器操作是内部节点，输出是根。双输入机器需要同时考虑两个输入，不能仅检查一个输入和固定辅助材料。实际工厂重复生产同一部件，可以在有限制造树中复制相应子树。

仅证明封闭性可能把不可制作图形也收入 C。若还要把 C 当作精确可制作性判定，需要反向证明 C 包含于 R，例如给出每类的构造方法。若要证明某个具体程序覆盖 C，还需要证明其判断、分支选择和终止性；分类定理不会自动证明代码正确。

<a id="s01-09-h3"></a>

### 2. 颜色与普通形状种类可以抽离

<a id="s01-09-h4"></a>

#### 2.1 使用的规则

1. 普通形状的具体种类和颜色不影响支撑、连接、碰撞、旋转、跌落、切割及截高行为。
2. 晶体粘连和连锁碎裂不区分颜色。
3. 结晶机把当前高度以内的空位和顶针变成指定合法颜色的晶体，保留已有普通形状和晶体。
4. 基础单层输入可以包含所需普通形状及其合法颜色。晶体颜色仅限游戏允许通过结晶生成的颜色，不能把语法可解析的颜色自动当成可生产颜色。
5. 除结晶外，各操作对既有单元只做移动、保留、删除或普通染色；没有基于颜色的物理分支。

当前程序集的 `ShapeLogic.Logic_IsConnected`、`Logic_IsFused` 只比较形状代码和位置，不比较颜色；普通非顶针形状的水平连接也不区分其种类。`ShapeOperationCrystallize.ExecuteInternal` 只改写空位和顶针，并设置输入颜色，保留已有单元。群内 `shapez.cpp` 的颜色消除说明可作参考，具体规则以游戏实现为准。

<a id="s01-09-h5"></a>

#### 2.2 任意配色的紧图形可以制造

称高度 h 内四个象限全部由普通形状或晶体占满的图形为“紧图形”，即没有空位和顶针。任意 h 不超过五的紧图形，都可以指定每个普通单元的种类、颜色，以及每个晶体的合法颜色。

构造单个目标列的方法如下：

1. 由下到上处理每一层。其他三个象限始终填普通辅助形状，形成完整辅助列。
2. 目标格要普通形状时，堆叠相应基础层；目标格要晶体时，先在该格放顶针，其他三格放普通形状，再执行所需颜色的结晶。
3. 已完成的所有格均为普通形状或晶体，所以这次结晶只改变新加入的目标顶针，不改变之前各层的配色。
4. 完成 h 层后，通过旋转和切割分离目标列。切线另一侧只有普通辅助形状，没有与目标列连接的辅助晶体，因而不会沿切线引发目标晶体碎裂。
5. 目标列每一层都非空，自底向上稳定。先把两个相邻目标列组合成半形，再把两个半形组合起来。各次切线经过待保留产物外侧的空区域，不需要切断已组合部分内部的晶体连接。

这证明了整个紧图形的任意合法配色可制造，而不只是单个晶体格可染色。

<a id="s01-09-h6"></a>

#### 2.3 制造树替换证明

给定任意可制作结构的一棵制造树，给最终普通单元和晶体单元指定任意合法标签：普通单元的种类与颜色、晶体的颜色。

从根往叶子追溯这些标签。对非结晶操作，每个保留的输出单元来自某个输入单元，给该输入单元分配相应标签即可；最终会被删除的单元任意赋值。原来的普通染色步骤可以省略，把要求的颜色提前赋给对应原料。

遇到结晶节点时，它的输出是紧图形。用 2.2 的构造直接制造这个节点所需的全部标签，替换该节点及其之前的子树。继续保留后面的结构操作。由于物理规则不依赖这些标签，各次切割、碎裂、跌落等结果的结构不变。

同一原料供给两个支路时，可以分别生产两份、赋予不同标签，不要求一个物理单元同时具有两种颜色。由制造树归纳得到：

> 在上述规则和合法材料范围内，一个结构只要可制作，其任意普通形状种类与配色组合也可制作。

反方向只需擦除标签。因此“擦除颜色和普通形状种类”对可制作性是精确的化简，而不仅是必要条件。它不证明原 TMAM 能接受所有颜色，也不保证原制造路径直接换颜色就仍然有效；制造路径可能需要替换。

另一个直接结论是：可把每棵制造树中靠近输出的结晶节点替换成预制紧图形。紧图形仍需用上面的合法方法制造，不能把它们未经解释地新增为天然原料。

<a id="s01-09-h7"></a>

### 3. 无晶体图形的精确判定

普通形状只在同一层与相邻普通形状粘连；顶针不粘连。没有晶体时，每个最大粘连组都在一个水平层中：它或者是一个普通形状连通块，或者是单个顶针。

对每个非底层单元组，检查其占据的象限中是否至少有一个在下一层非空。顶针是单格组，所以要求正下方非空。底层单元组直接受地面支撑。

这个条件对稳定性既必要又充分：组之间的支撑边严格从高层指向低层，不可能成环。每个非底层组只要有下一层支撑，最终就有一条支撑链通向地面；反之，缺少直接阻挡的组会下落。

对满足条件的图形，从底到顶依次堆叠每个普通连通块和每个顶针。制造到第 h 层时，下方各层已经到位，该组恰好落到目标高度。同一层不同组占据不同格位，不妨碍此构造。

因此，在机器输出会完成重力结算的规则下：

> 无晶体图形可制作，当且仅当它满足上述稳定性条件。

这部分不需要全图形数据库，也不需要复杂的角分类。后续覆盖性困难可以集中在含晶体的图形上。

<a id="s01-09-h8"></a>

### 4. 最终保留晶体的高度不变量

使用两条规则：晶体随所在组下落就会碎裂；顶针使保留单元上移一层并在高度上限处处理删除。当前 `ShapeOperationPushPin` 先分离原顶层，把其余单元 `LayerIndex++`，在原底层非空处补针，再把原融合关系交给 `Collapse` 处理。`ShapeLogic.Fold` 按原层号补空层，不会自动删除底部空层并重新编号。

选择成品中的一个晶体，沿制造树回溯到产生它的结晶操作。这个晶体此后不能经历任何向下移动，否则它不会保留到成品。旋转不改变层高；切割和交换也不能把一个保留晶体移到更低层。

每次顶针都会把存活晶体的层号加一。根据第 6 节核对的堆叠规则，成品中的晶体不能来自某次堆叠的上料，因此追溯晶体时，堆叠节点只需沿下料继续追溯。

故对这条单元路径，有：

`最终层号 >= 产生时层号 + 产生后经历的顶针次数`

最终层号不超过五，产生时层号至少为一，所以顶针次数最多四次。更精确地，最终处于第 h 层的晶体，产生后最多经历 h−1 次顶针。

这个结论不依赖颜色，也不要求支撑图无环。它限制的是某个最终晶体从产生之后经历的那条路径，不能据此声称整座工厂最多使用四次顶针。其他支路、结晶之前的准备、只用于临时支撑而最终碎掉的晶体，都可能有更多操作。

若某段尾部流程只包含顶针和不含晶体的基础料堆叠，则所有最终晶体都已经存在于该段的起点。记成品最低晶体层号为 m，整段顶针次数满足：

`顶针次数 <= m − 1 <= 4`

特别地，成品有第一层晶体时，这种尾部流程不能包含任何顶针。

<a id="s01-09-h9"></a>

### 5. 不必先证明所有堆叠都能移到最后

<a id="s01-09-h10"></a>

#### 5.1 相对完整起点集合的存在性定理

令 H 是“确实能够制造并独立保留下来的半形”集合，包括旋转后的方向。由 H 中两个半形在合适方向交换得到的形状，连同单独半形、基础输入和紧图形，组成起点集合 A。

这里的 A 是为论证定义的集合，不直接等同于任何文档中仅凭半边稳定性判定的 A 类。两个半边稳定，不足以证明两个半边都可制造。[半形有限文法](02-four-quadrants.md#s02-02)给出了完整 H 的有效构造定义，使本节的相对定理可转化为闭合判据。

定义 K：每个最大粘连组都能沿直接支撑边到达地面，或到达一个包含顶针的支撑环。[支撑闭包证明](#s01-12)已经补齐切割与顶针：四象限五层中，基础输入属于 K，全部纳入范围的实体操作保持 K，故每个可制作图形都属于 K。结合 K 内的堆叠构造得到：

> 任意上料的一次真实堆叠，都能从同一个下料出发，改用若干次不含晶体的基础块堆叠得到相同结果，且输出仍属于 K。

证明、连续堆叠的充要判据和适用边界见[堆叠约化](#s01-11)。核心是原下料保持不动，最终保留的上料块从低到高追加；含针支撑环不会因新增普通块造成的组粘连而消失。该约化不要求保留上料中的所有非晶体格。

不能把“可制作下料”直接弱化为“稳定下料”。源码在一次下落中不合并新接触的组，下一次加工却会重新分组。[堆叠约化第 7 节](#s01-11-h10)给出稳定但不属于 K 的反例；由本轮闭包定理，该下料不能从允许的基础输入制造出来。

任意制造树上的下料均可制作，因而属于 K。沿堆叠的下料支路向前回溯：

- 遇到结晶，输出是紧图形，属于 A。
- 遇到切割，保留产物是可制造的独立半形，属于 A。
- 遇到交换，输出由两个已按切割流程结算的可制造半形拼成，属于 A。
- 若一直回溯到基础输入，也属于 A。
- 中间各次堆叠可约化为基础块堆叠；旋转暂保留，标签问题由第 2 节处理。

因此，每个可制作结果都有“从 A 出发，经过旋转、顶针和基础块堆叠”的制造尾部。本节给出相对完整 H 的存在性结论；完整 H 的有限判据及制造证书见[后续闭包证明](02-four-quadrants.md#s02-02)。[通用列内不变量](#s01-01)仍可用于排除候选，不能替代该判据。

<a id="s01-09-h11"></a>

#### 5.2 有限阶段形式

若结果含晶体，第 4 节把尾部中的顶针次数限制为四次以内。记 S* 为零次或多次基础块堆叠，P 为一次顶针，R 为零、四分之一、二分之一或四分之三圈旋转，可写为：

```text
A → S* → R → (P → S* → R)^k，0 <= k <= 4
```

这里只把同一纯基础堆叠段中的旋转归并到该段末尾，同时调整基础上料的朝向。这由基础块落点公式的旋转对称性得到；不要求旋转与顶针或任意重力结算交换。也没有把堆叠跨过顶针重排。

各段起点均可制作，故属于 K。段内既有格位不移动、不删除；每次有效堆叠至少增加一格，故每段至多二十次、五段共至多一百次有效堆叠，另有最多四次顶针及各段末的旋转。这个宽松的证书长度界从已取得 A 中起点开始，不包含制造起点的成本。

还可直接反推每段：前态只能保留目标每列某个高度及以下的全部格位。四列五层至多 6^4 = 1296 个候选，再检查 K 和新增格的充要判据。这是单段固定朝向的候选数量界，不是完整算法的运行时间保证。

支撑范围和堆叠约化已不再是未知前提。[半形有限文法](02-four-quadrants.md#s02-02)进一步闭合 H，并给出全图 Reach 判据；[完整顶针逆像](#s01-13)处理第五层、融合删除及下落。当前已得到有限构造理论，尚未将其压缩为高效求解器或具体机器流程。

<a id="s01-09-h12"></a>

#### 5.3 顶针与堆叠不能直接交换顺序

取基础输入 `X = Cu------`、`b = --Cu----`，短代码按从底到顶书写。

- 先堆叠 b，再顶针，得到 `P-P-----:CuCu----`。
- 先对 X 顶针，再堆叠 b，得到 `P-Cu----:Cu------`。

前一种顺序先让两块并排落在地面，顶针会在两块下方加针。后一种顺序只在 X 下方加针，随后 b 仍能落到地面。两者不同，完全不需要晶体或截高就能看出差异。

因此，操作约化若要改变这两个操作的顺序，必须允许并证明相应的材料或辅助结构变换；不能直接使用交换律。这个例子不否定可能存在的其他等价制造路径。

<a id="s01-09-h13"></a>

### 6. 游戏源码确定的堆叠规则

<a id="s01-09-h14"></a>

#### 6.1 上料的初始高度与结算顺序

`ShapeOperationStack.ExecuteInternal` 展开上下两份图形，复制上料引用并执行：

```csharp
shapePartReference.LayerIndex += MaxShapeLayers + 1;
```

它没有使用下料实际高度。五层模式下，上料原第一层从零基下标 0 移到 6，即人类层号第七层。其余上料也全部位于五层上限之外。该方法没有预先删除上料中的晶体，而是把合并引用交给 `ShapeLogic.Collapse`。

`Collapse` 的相关调用顺序为：

1. `BuildGroups` 按粘连规则分组。
2. 如调用者传入融合关系，先执行 `ComputeFusingResults`；堆叠调用未传入这项参数。
3. `SimulateFallDownPhysics` 逐组尝试下落，直到没有组能再下落。
4. `RemoveExcessLayers` 把零基层号大于等于最大层数的部分标为消失。
5. 合并结果组并输出。截高之后没有第二次下落或融合碎裂调用；本次下落中的新接触也不会合并物理组，下一次加工才会重新按格位分组。

`SimulateFallDownPhysics` 检查地面及其他非消失组的直接阻挡，不要求支撑链通向地面，所以互相阻挡的组可以保持不动。只有确定某组能下落时，才检查每个部件的 `DestroyOnFallDown` 属性并拆分消失部分。这个属性来自部件元数据，不是在堆叠器里写死为形状代码 `c`。本轮读取了该属性的代码入口，没有另外导出游戏部件资源表；“晶体下落即碎”沿用本研究的晶体部件规则。

因此，上料中的晶体若发生下落就会碎；若一直不下落，则仍位于高度上限之外，被截掉。它不能保留在堆叠输出中。

<a id="s01-09-h15"></a>

#### 6.2 循环上料的源码推导结果

取上料 `U = crCu----:crP-----:crCu----`，下料 `D = ----Cu--`。U 的三个晶体和上下普通块属于一个粘连组 G，中央顶针为另一个组 p。G 的上方普通块与 p、p 与 G 的下方普通块互相阻挡。

真实堆叠把 U 提高六层，放到第七、八、九层。G 与 p 都不下落，随后全部被 `RemoveExcessLayers` 删除。按已核对的源码，输出只有：

```text
----Cu--
```

这排除了该输入能够通过堆叠保留上料晶体的说法。结果来自逐分支静态推导，没有启动游戏执行。

该例同时说明，真实实现不能简单替换成“预删上料晶体，再让所有其他格下落”。若先删掉 U 的晶体，剩余的普通块、顶针、普通块就不再成环，会落到下料旁边，手推输出变为：

```text
--CuCu--:--P-----:--Cu----
```

两个结果不同。需要证明的仍是“存在某个基础块堆叠序列”，不能强制把预删晶体后所有剩余格都堆进去。对这里的实际结果，零次基础块堆叠已经足够。

<a id="s01-09-h16"></a>

#### 6.3 支撑图需要包含通向环的节点

源码通过组间直接阻挡决定能否下落，能够保留互相阻挡的环，以及被这些环阻挡的其他组。若改用图论判定，应包含能沿支撑边到达地面的块和能到达支撑环的块，而不仅是环内节点。

《MaManalysis》定义 6 的文字是“存在到地面的路径，或这个块在一个环里”。按字面缺少“能到达一个环”的情形。后续建模需要使用与源码逐组阻挡一致的定义，并在部件消失和分组变化后继续结算。

<a id="s01-09-h17"></a>

### 7. 还缺哪些证明

在已核对的四象限五层规则下，半形与顶针的两个缺口已有有限构造解：

1. **完整半形集合**：[半形有限文法](02-four-quadrants.md#s02-02)以无晶体稳定半形为种子，结合紧图形、已知半形拼接、有界尾部和末次半切，给出必要且充分的不动点判据及制造证书。至多 4^10 次算子应用即可停稳；未计算实际成员数量。
2. **完整顶针逆向**：[顶针逆像](#s01-13)恢复全部来源格位及顶破层，以静止组集合和落点公式覆盖融合删除与下落碎晶，再通过完整 Reach 判据筛选前态。不存在未知可制作性判定器。

[逐列角构造](02-four-quadrants.md#s02-03)已把相邻两列半形压缩为稳定性及列条件的充要判据。仍需解决的是：全图顶针与堆叠尾部的低成本判定，以及固定 TMAM 如何覆盖全部制造证书。理论完备性不等同于实际运行效率，也不证明 Mari 或 A／AC／B／BC 方案完备。

颜色消除后，单角五层有 4^5=1024 个原始编码，独立可制作单列恰有 264 种（含空列）。半形有 4^10=1048576 个原始编码，这只是递推状态空间及终止界，不是可制作半形数量。

## 01-10 四象限五层：独立单列与顶针逆向

原文标识：`4q5l/column-theory.md`。

本文限定四象限、最多五层，使用[支撑闭包证明](#s01-12)中的 R ⊆ K。普通格记为 N，顶针记为 P，晶体记为 C；层号自底向上。标签处理见[覆盖性研究](#s01-09)。没有运行枚举、仿真或游戏验证。

通用的针前缀不变量 Q、晶体下方间隙不变量 J，以及保留晶体位置和地面针掩码的证明，统一见[通用列内不变量](#s01-01)。其中 C-P-C 单列和隔空晶体半形说明 K、K ∩ Q 均不充分；本范围当前有 R ⊆ K ∩ Q ∩ J，反向仍未证明。

<a id="s01-10-h1"></a>

### 1. 独立单列的精确判定与构造

这里的“独立单列”指最终图形只占一个象限，另外三列全空。制造过程中允许使用辅助结构，不要求全过程只占这一列。

<a id="s01-10-h2"></a>

#### 必要性

独立单列没有水平支撑。不同组的支撑只能由上向下，不可能成环。因此稳定性要求从地面到最高格连续非空，中间或底部都不能留空格。

若含晶体，Q 又要求最高晶体以下的全部顶针只能形成地面前缀。最高晶体以上不再有晶体，普通格与顶针可以任意排列。

所以非空单列的精确候选形式是：

```text
无晶体：        (N 或 P) 的任意非空连续串
含晶体：        P^q · W · V
                W 是由 N/C 组成、以 C 结尾的非空串
                V 是由 N/P 组成的任意串
                q + |W| + |V| <= 5
```

字串从底到顶书写。空列单独允许。

<a id="s01-10-h3"></a>

#### 充分性

无晶体时，逐格堆叠基础普通格或顶针即可。

含晶体时，先用主文的任意紧图形构造，制出所需 N/C 柱 W：其他列使用普通辅助材料，完成后切出目标列，切线不会切断目标晶体融合组。W 自底向上连续占满，可独立保留。

再执行 q 次顶针，在 W 下方生成 q 个针。中间高度不会超过最终高度，不发生顶破。最后从上方逐格堆入 V 中的普通格和顶针。

这就构造了每个满足候选形式的单列，因而条件既必要又充分。普通格种类和合法配色按主文的构造指定，不新增颜色限制。

<a id="s01-10-h4"></a>

#### 不用枚举也能得到数量

固定高度 h，把 N、P、C 各视为一种结构材料。

无晶体有 2^h 种。若最高晶体在第 r 层，以上 h−r 格有 2^(h−r) 种；以下 r−1 格可写成 P^q 后接 N/C 串，q 从 0 到 r−1，因此有 2^r−1 种。总数为：

```text
a_h = 2^h + Σ[r=1..h] (2^r − 1) · 2^(h−r)
    = h · 2^h + 1
```

| 高度 | 非空可制作单列数 |
|---|---:|
| 1 | 3 |
| 2 | 9 |
| 3 | 25 |
| 4 | 65 |
| 5 | 161 |
| 合计 | 263 |

加上空列，共 264 种。这是解析计数，不是运行枚举的结果；也不包含普通形状种类、颜色和列朝向的组合数。

<a id="s01-10-h5"></a>

### 2. 依赖稳定输入的顶针逆向

以下 D 是本范围内的非空可制作输入，T 是一次顶针的输出。先按[通用位置约束](#s01-01-h6)确定保留晶体前态及输入底层占用列；以下再使用四象限五层的 K 闭包，不能仅凭五层上限就推广到六象限。

<a id="s01-10-h6"></a>

#### 输入不超过四层时，前态唯一

此时没有顶破及融合删除。D 属于 K，提高后加地面针仍属于 K，不发生下落。因此 T 必须满足：

- 第一层只有顶针或空格。
- 第一层有针的列，恰好是第二层非空的列。

删除 T 第一层，把剩余层整体下移一层，就得到唯一候选 D。若该 D 确实可制作，则按上述规则正向顶针必得到 T；反之，任何不超过四层的可制作前态都必须是这个 D。

这解决的是无顶破分支的结构逆像。候选 D 的可制作性现在可由[全图有限判据](02-four-quadrants.md#s02-02-h13)确定。输入原有第五层时，不能直接套用唯一性结论，应使用[完整逆像](#s01-13)。

<a id="s01-10-h7"></a>

#### 输出地面有普通格，必发生了顶破向低层传播

若顶破没有删除原第四层晶体，[支撑闭包证明第 5 节](#s01-12-h7)说明原第一至第四层全部保留，提高并补针后不发生下落，输出地面只有新针或空格。

因此，T 地面出现普通格，意味着顶破至少删除了原第四层晶体，并触发后续下落。这个结论是必要条件，不能倒过来说有第四层碎裂就一定有普通格落地。

<a id="s01-10-h8"></a>

### 3. 对两列半形的意义与边界

Q 和 J 对每一列都成立，可以排除不可制作半形；反例与证明见[通用列内不变量](#s01-01)。

264 种的精确分类只适用于最终独立的一列。半形中的某列可能有空格，依赖邻列支撑；它自身不在这 264 种里，不代表整个半形不可制作。反过来，如果一个半形的两列都各自属于这 264 种，就可以分别制造后拼接，得到一个确定可制作的子类。

[半形有限文法](02-four-quadrants.md#s02-02)已给出全部两列半形的精确有限判据及构造；[完整顶针逆像](#s01-13)补齐有顶破的情形。[逐列角构造](02-four-quadrants.md#s02-03)进一步证明：相邻两列半形的稳定性，加上 Q、J、晶体间隙不变量及针直接支撑，构成局部充要条件；这不构成全图判据。这里的独立单列计数、有限半形判定和稳定输入逆向特例均不自动推广到六象限五层。

## 01-11 堆叠约化：支撑不变量、精确判据与适用边界

原文标识：`4q5l/stacking-proof.md`。

本文承接[覆盖性研究](#s01-09)，研究四象限、五层实体堆叠。结论来自游戏源码的静态核对与手工证明，没有运行模拟器、枚举或游戏验证。部件规则沿用普通形状和顶针下落不消失、晶体下落即碎；程序集版本、指纹及配置核对限制见主文第 8 节。

核心结论是：对下文定义的支撑类 K，任意双输入堆叠都可改用基础块序列；一段连续基础堆叠有直接可检查的充要条件，反推前态最多需要考虑 1296 种按列截断。[支撑闭包证明](#s01-12)进一步证明本研究规则下全部可制作图形都属于 K，因此约化适用于全部可制作下料；这仍不等同于某台 TMAM 已覆盖全部图形。

<a id="s01-11-h1"></a>

### 1. 必须区分本次下落与下次重新分组

`ShapeLogic.Collapse` 开始时调用 `BuildGroups`，按当前相邻关系建立粘连组。`SimulateFallDownPhysics` 逐组下落；晶体消失时，`SplitGroupIntoKeepAndVanish` 只在当前组的保留部分与消失部分中重新分组。它不会因为两个原本独立的组在下落后接触，就把它们合并后重新结算。

结果写回短代码，只保留格位和部件，不保留本次分组历史。下一次调用 `Collapse` 时，`BuildGroups` 会按新接触关系重新分组。截高后的 `MergeGroups` 用于合并结果条目，后面没有再次调用重力。

因此，“本次各组都停止下落”不能直接推出“下一次重新分组后仍不下落”。两个组原本互相阻挡，接触合并后，这些阻挡可能变成同一组内部的格位，不能再阻止整组下落。

下文所说的稳定，专指按图形当前格位重新建立最大粘连组后，没有任何组能开始下落。第 7 节给出这一细节如何阻止无条件堆叠约化。

<a id="s01-11-h2"></a>

### 2. 一个能抵抗新增粘连的支撑类 K

对图形建立支撑图：

- 节点是当前最大粘连组。相邻的普通形状与晶体按游戏规则粘连；每个顶针始终单独成组。
- 若组 G 的某格正下方紧邻另一个组 H 的格，画有向边 G → H。同组内部的上下格不构成支撑边。
- 含第一层格位的组连向地面节点。

定义 K：每个组都能沿支撑边到达地面，或者到达一个包含至少一个顶针节点的有向支撑环。空图形按空条件属于 K。

K 中的图形一定稳定。它允许悬空结构，例如下列晶体框架与中央顶针互相支撑：

```text
--------:crCu----:crP-----:crCu----
```

这只是展示 K 的定义，不据此认定该具体图形可制造。K 排除的是没有地面路径、也没有通向含针环路径的组。稳定性允许的环比 K 更广，所以“稳定”与“属于 K”不能混用。

<a id="s01-11-h3"></a>

#### 为什么新增普通块不能破坏原有 K 支撑

先保持原有格位不变，再加入已经落稳的普通块或顶针。新增普通块可以让若干原粘连组合并，相当于收缩支撑图中的一些节点；原顶针不会粘连，因此顶针节点不会被这种收缩吞入其他组。

原有通向地面的路径仍然通向地面。原有含针环收缩后仍有经过该顶针的非平凡闭合支撑路径：顶针始终与其他节点分离，不可能把整个环收缩成一个组。通向这种环的路径也仍然有效。故原有组不会因新增粘连而丢失所有支撑。

新落入的基础块受地面或下方既有格支撑，后者已有上述支撑路径。即使新块随后与旧组合并，也适用同一个收缩论证。因此，基础块堆叠的输出仍属于 K，原有格位保持不变。

这里不允许删除原格位、把顶针变成可粘连部件或移动原格位。切割、顶针加工不能直接套用这一证明。

<a id="s01-11-h4"></a>

### 3. 基础块的落点公式

一个基础块指同层的一个水平普通形状连通块，或一个顶针。四个象限按环相邻，首尾也相邻。任意不含晶体的基础层可以拆成这样的独立块。

设下料 D 属于 K。用 h_D(j) 表示第 j 列最高非空格的人类层号，空列记为 0。基础块占据的列集合为 J，则它的落点层号为：

```text
z = 1 + max(h_D(j)，j 属于 J)
```

它从所有下料格位上方整体下降，第一次接触最高阻挡时停下；本次下落不因新接触提前粘连。若 z 大于 5，整个基础块被截高删除，输出仍为 D。否则原下料不动，新增基础块停在 z 层，输出仍属于 K。

公式只描述无晶体、单层、单个连通块或顶针的上料，不能直接套用到任意复杂上料。

<a id="s01-11-h5"></a>

### 4. 一段连续基础堆叠的充要条件

固定图形朝向。给定 D 属于 K，以及候选目标 T，记 Δ 为 T 相比 D 新增的格位。存在仅用基础块堆叠、从 D 得到 T 的序列，当且仅当以下四项全部成立：

1. **保留原图**：D 的所有格位在 T 中仍在原位置，部件与标签不变。
2. **不新增晶体**：Δ 只含普通形状或顶针。
3. **不能钻到原图下面**：每个新增格 (z, j) 都满足 z > h_D(j)。
4. **新增块有支撑**：逐层仅对 Δ 中的普通格划分水平连通块，顶针单独成块。每块位于第一层，或者至少有一个格的正下方在 T 中非空。

第 4 项的分组只看新增格，不能借用 D 中同层的旧格把两个新增块拼成一块，再声称它们共同获得支撑。下方支撑则可以来自 D，也可以来自 Δ。

<a id="s01-11-h6"></a>

#### 必要性

第 2 节保证每步堆叠后仍属于 K，既有单元不会移动或消失，因而原图必须完整保留，也无法加入晶体。每个新块由上方下降，不能穿过原图同列的最高格，故满足第 3 项。

每个实际落入的块都在地面或某个下方格上停止。之后的步骤保留该支撑。把同层相邻的新增普通块合并成 Δ 的最大连通块时，至少保留其中一个直接支撑，故满足第 4 项。

<a id="s01-11-h7"></a>

#### 充分性及构造

把第 4 项的新增块按目标层号从低到高排列，同层任意顺序，逐块堆入。

处理 z 层某块时，第 3 项保证其所有列中的原图格位均低于 z；之前加入的低层格也低于 z。同层已处理的其他块占据不同列，不会挡住它。若 z 大于 1，第 4 项保证它至少有一列在 z−1 层已有支撑，因为那格属于原图或已完成的更低层。第 3 节公式于是给出恰好 z 的落点。第一层的块则直接落地。

每一步后仍属于 K，所以归纳可以继续，最终得到 T。每块至少新增一格，最多二十格，因此构造至多需要二十次有效堆叠。零新增格时使用零次堆叠。

这是精确判据和构造证明，不是通过抽样得到的经验规则。

<a id="s01-11-h8"></a>

### 5. K 下料的任意上料堆叠可以约化

令 D 属于 K，上料 U 任意，按真实游戏堆叠得到 T。证明 T 满足第 4 节的四项条件即可。

1. 上料原第一层被提高到第七层，与五层以内的下料不接触。原下料的各组已经稳定，既有阻挡不被删除；上料的新接触也不会在本次模拟中合并它们。因此 D 始终不动且不消失。
2. 上料晶体只有两种结局：随组下落即碎，或一直停在上限外而被截掉。故新增格没有晶体。
3. 一个最终保留的上料组必须曾经下落。若原组含晶体，第一次下落就去掉晶体，剩余组分解为水平普通块或单个顶针；分解时最低格仍至少在第六层，位于下料全部格位上方。其后不会与其他组重新合并。这些块沿各自列向下移动，不可能穿过 D 中的格位，故新增格严格高于 D 的原列顶。
4. 最终保留的每个水平块或顶针都因地面或下方非消失格而停止。支撑格的层号比该块低一层，既然该块不超高，支撑格也不会随后被截高删除。因此新增块在 T 中有直接支撑；合并相邻新增普通块仍保留支撑。

于是可按第 4 节的构造，从同一个 D 出发，用最终保留块的基础堆叠序列得到完全相同的 T；输出也属于 K。

这允许直接丢弃上料中最终没有保留的所有格。它不等同于先删除上料晶体，再把其余格全部堆入：上料的循环支撑可能让其中的普通块或顶针也停在上限外，最后一起被删除。

<a id="s01-11-h9"></a>

### 6. 反推一段堆叠：最多 1296 个前态

固定目标 T 和朝向，只考虑从 K 中前态 D 开始的连续基础堆叠。由第 4 节第 3 项：同一列中，不可能先保留一个高处的原格，又把该列较低的目标格当作新增格。

所以 D 必须具有这种形式：每一列选择一个截止高度，保留 T 在该高度及以下的全部格，删除其上的全部格。每列的截止高度取 0、1、2、3、4、5，共六种，四列最多：

```text
6^4 = 1296
```

然后检查 D 是否属于 K，以及第 4 节的四项条件。通过的候选恰好是本范围内可作为该段堆叠前态的图形；若工厂不允许空下料，再排除空前态。目标中的晶体全部必须保留，因此每列截止高度至少到达该列最高晶体。空格会让不同截止高度产生相同候选，实际数量通常更少。

1296 是单段、固定朝向的前态数量上界。它不包含反推顶针、制造起点、半形完备性，也不是整个求解器的状态数或运行时间。若允许段内旋转，可以在基础块落点公式的对称性下，将这些旋转归并为段末的净旋转，并分别处理四种朝向；这里不需要声称旋转与所有其他加工都可交换。

<a id="s01-11-h10"></a>

### 7. 任意稳定输入上的反例：该下料不可制作

若删去 D 属于 K 的前提，只要求 D 稳定，约化不再普遍成立。下面的短代码按从底到顶书写，空底层保留。

取下料：

```text
L = --------:cr--CuCu:cr--Cu--:crCuCu--
```

以 c 表示晶体、N 表示普通块，列从左到右编号 0 至 3：

```text
层4    c N N -
层3    c - N -
层2    c - N N
层1    - - - -
```

晶体列、第二层两个普通块和第四层两个普通块属于同一组 G：第二层通过列 3 与列 0 的环邻接相连。第三层列 2 的普通块是另一个组 B。G 的第四层列 2 被 B 阻挡，B 又被 G 的第二层列 2 阻挡。因此 L 稳定，但整个支撑环既无地面路径，也无顶针，不属于 K。

取上料：

```text
U = ------Cu:------Cu
```

真实的一次堆叠中，上料两个普通块分别落在列 3 的第三、第四层。新接触不合并旧组，G 与 B 在整次模拟中保持互相阻挡。手推结果为：

```text
T = --------:cr--CuCu:cr--CuCu:crCuCuCu
```

若改用基础块逐次堆叠，则不能从 L 得到同一个 T：

- T 只新增了同一列的两个格，一个单层基础上料不可能同时加入这两个格。
- 不能先加第四层列 3：只占列 3 的块会先落在第三层；若扩大普通块覆盖列 0 或列 2，会被既有第四层挡到第五层，留下目标不需要的普通格。额外的普通格或顶针不能靠后续纯堆叠消失。
- 所以第一次有效追加必须放入第三层列 3。写回结果后，它横向连接第三层的晶体与 B，使 G、B 和新块成为一个粘连组。
- 第二次堆叠重新分组时，这个合并组没有地面格，也没有外部下方支撑，会整体开始下落，原晶体因此碎裂。上料晶体不能保留进堆叠结果，后续基础堆叠更无法恢复它们。

这反驳的是“对任意稳定下料都能约化”。由[支撑闭包定理](#s01-12)，全部可制作图形都属于 K，而 L 不属于 K，所以它在本研究规则下不可制作。该例不构成可制作集合内的反例，也不能用于宣称某台 TMAM 漏解。结果来自源码手推，未在游戏中执行。

[支撑闭包证明](#s01-12)已处理切割、顶针及其后的新接触与重新分组，得到四象限五层下全部可制作图形都属于 K。因此本文第 5 节的约化覆盖全部可制作下料，而第 7 节的稳定反例被排除在可制作集合之外。

## 01-12 四象限五层中，合法加工保持 K 支撑性质

原文标识：`4q5l/support-closure.md`。

本文补齐[堆叠约化](#s01-11)留下的切割、顶针闭包问题。范围、基础输入、部件规则和源码版本沿用[覆盖性研究](#s01-09)：四象限、最多五层，普通形状与顶针下落不消失，晶体下落即碎；讨论实体旋转、切割、交换、堆叠、顶针、结晶及染色。没有运行枚举、模拟器或游戏验证。

在这些前提下，下面给出制造树归纳证明：**每个可制作图形都属于 K。** 这里 K 表示每个最大粘连组都能沿支撑关系到达地面，或到达一个含顶针的支撑环。它是必要条件；[通用列内不变量](#s01-01)以 C-P-C 单列说明它不是充分条件。

因此，K 内的堆叠约化可以用于全部可制作下料。后续的[半形有限文法](02-four-quadrants.md#s02-02)和[完整顶针逆像](#s01-13)已在此基础上闭合两个有限构造判定问题。

<a id="s01-12-h1"></a>

### 1. 源码给出的结算边界

本轮重读了 `ShapeOperationCut.ExecuteInternal`、`ShapeOperationPushPin.ExecuteInternal`，以及 `ShapeLogic.ComputeFusingResults`、`SplitGroupIntoKeepAndVanish`。程序集摘要仍为主文记录的 `c93f84ebe219d974b4aa778a73311c5d776ff6d5f90e48337671e0ee480bca07`。

切割先选出一侧两列，传入原图的晶体融合关系。任何跨越切线的晶体融合组，其保留侧晶体也标为消失。随后按保留格位分组并执行下落。

顶针先排除原第五层，把原第一至第四层整体提高一层，并在原第一层非空的列补地面针。原融合组只要有晶体被第五层删除，剩余晶体也会在下落前消失。虽然代码先改层号再调用融合处理，原引用的对应关系仍保留，所以可用原图坐标描述这次删除。

这两种加工的保留部分在下落前都已位于五层以内，下落只能降低高度，最后的 `RemoveExcessLayers` 不会再删除保留格位。由此避免了“先停稳，再截断支撑”的额外情况。

以下把融合删除完成、正式下落尚未开始的时刻称为结算起点。其非消失组按现有格位最大粘连关系分组；去掉晶体只能拆组，不能使原先不相邻的格位新接触。

<a id="s01-12-h2"></a>

### 2. 下落中移动过的组，不能成为未移动组的最终支撑

区分最终保留的两类组：

- **未移动组**：相对于结算起点没有下落，原格位保持不变。
- **移动组**：至少下落过一次。若原来含晶体，晶体已在第一次下落时消失；剩余组只可能是水平普通块或单个顶针。拆组继承已有下落量，不会重新成为未移动组。

假设移动组的一个保留格最终位于 (j, z)，并直接支撑未移动组在 (j, z+1) 的格。这个移动格只沿原列逐层下降，而且总位移至少为一；它就必须在起点或下降途中占过 (j, z+1)。然而该位置一直有未移动组的格，不可能被穿过或重叠。矛盾。

所以：**未移动组的最终支撑只能来自其他未移动组或地面。** 移动组都是水平组，其相互支撑边严格从高层指向低层，不可能形成环。终止时，每个移动组的支撑路径最终到达地面或某个未移动组。

由此得到一个通用结算引理：如果所有未移动组都能通向地面或含针环，那么全部保留组都满足同样条件。最终写回格位、按新接触重新分组，只会合并非顶针组；顶针不会粘连，因此[上轮的组收缩证明](#s01-11-h3)保证 K 仍然成立。

这一步显式处理了源码没有在本次下落中合并新接触的行为，不假设结算会自动反复重新分组。

<a id="s01-12-h3"></a>

### 3. 切割输出必属于 K

<a id="s01-12-h4"></a>

#### 两列中的非顶针组不能在高度区间上重叠

一个粘连组从最低层连到最高层，必须在中间每层至少占一格。否则无法通过相邻连接跨过缺层。

在相邻两列中，若两个不同的非顶针组高度区间重叠，那么在某个共同层上，它们各有非顶针格。若占同列则重叠；若分占两列，则水平相邻、应当粘连。两种情况都不允许。

所以，不同非顶针组的高度区间互不相交。它们之间的直接支撑只能由整体较高的组指向整体较低的组，不可能形成只含非顶针组的环。

<a id="s01-12-h5"></a>

#### 应用到切割后的结算

切割只保留相邻两列。融合处理后，未移动组在整个下落中保持原位，彼此仍没有粘连。上述区间结论适用于这些组。

结算停止时，每个未移动组要么触地，要么被另一个未移动组阻挡，不能依赖移动组。有限支撑图中，沿支撑边最终到达地面或某个环；该环若不含顶针，就与区间结论矛盾。因此所有未移动组都能通向地面或含针环。

再应用第 2 节引理，最终重新分组后的半形属于 K。

这个证明甚至不要求切割输入已属于 K，只要求输入是本研究范围内的合法格位图。它证明切割输出的支撑性质，不证明所有具有该支撑性质的半形都可制造。

<a id="s01-12-h6"></a>

### 4. 四列三层中的无针支撑环只有一种骨架

考虑一组互不粘连的非顶针组，它们只占连续三层，且形成有向支撑环。这里仅讨论环上的组，允许图中还有其他组和顶针。

每个环上组都必须经过中间层：若只在底层，它没有指向环内其他组的支撑边；若只在顶层，也不可能有环内其他组从更高处以它为支撑。组的高度范围连续，所以不经过中层就只能属于这两种情况。

四列按环相邻。同一层最多容纳两个互不粘连的非顶针组；有两个时，各自只能占一个格，而且必须位于相对的列。因此，这个无针环恰好由两个组 G、B 构成，中层各占相对的一格。

G → B 的支撑边只能跨上、中层，或者跨中、下层。两条反向支撑边不能都跨同一个层间：那会要求两个组同时在该侧外层横跨到对面，发生重叠或粘连。所以一条边在上方，另一条在下方。

由此，一个组必须同时具有上、下两端的跨列结构，另一个组仅留在中央。外组从中层连接上下层，只能依靠中层所在列的连续晶体；其上下两层各要水平连到相对列，至少占三格。旋转之后，骨架为：

```text
上层    c * * ?
中层    c ? B ?
下层    c * * ?
```

`c` 是外组贯穿三层的晶体脊；`*` 是同属外组的非顶针格；上下层也可以从另一侧绕到对面，或占满四格。上下层的 `?` 不限定是否由外组占据。中央 B 是独立的一个非顶针格，不能与外组粘连；中层两个 `?` 只允许为空或顶针，另放非顶针格就会连接两组。

特别重要的是：**上层任何未被外组占据的位置，都与保留的晶体脊水平相邻。** 上层因此不可能藏有一个即将被删除、却不连带破坏晶体脊的晶体。

这个引理只使用四列和三层的几何限制，不通过枚举获得。后面不能把它直接推广到六列或更多层。

<a id="s01-12-h7"></a>

### 5. 顶针的简单情形：没有晶体删除传播到原第四层

若顶破未删除原第四层的任何晶体，则也没有晶体融合删除传播到更低层。理由是：晶体融合路径从第五层进入下方，必经过第四层的晶体；水平连接不能跳层。

此时，原第一至第四层没有任何格位被删除。原第五层的组也不可能与下方粘连，因为唯一的跨层粘连是相邻晶体，而这样的第五、第四层晶体对会导致第四层晶体被删除。

因此，删除第五层只去掉独立的顶层组。这些组也不能作为下方组的直接支撑，下方原有的 K 支撑路径保持。随后整体提高一层，原先触地的格下方补上地面针；原有支撑边只是平移，地面支撑被地面针替代，其他含针环仍保留。

如果输入属于 K，这个中间结果已经属于 K，不发生下落，顶针输出也属于 K。

<a id="s01-12-h8"></a>

### 6. 顶针的一般情形：反证排除坏环

设输入属于 K。融合处理后执行下落，考虑终止时的未移动组。假设其中存在组不能到达地面或含针环。

由于移动组不能为它们提供最终支撑，沿这些未移动组的支撑边，必能找到一个不含顶针的有向环。若能沿途到达地面或含针环，出发组本来就满足 K，故不属于反设。

这个坏环上的组不能含原第一层的保留格。它们提高后处于第二层，下方必有本次新加、不会移动的地面针；只要有这种格，就已经获得通向地面的路径。

原第五层已被排除。因此，坏环上的全部格只能来自原第二、第三、第四层。未移动组保留融合处理后的原位置，彼此没有新粘连，可以应用第 4 节的三层引理。

于是，坏环有一个在原第四层占至少三格的外组，并包含贯穿原第二至第四层的保留晶体脊。考察原第四层所有位置：

- 外组已占据的格是实际保留格，不可能同时也是被融合删除的晶体。
- 唯一可能未被它占据的位置与晶体脊相邻。若该位置原来有被融合删除的晶体，它就属于晶体脊的同一个融合组，晶体脊也必须一起删除，不能留在坏环中。

所以，原第四层没有任何被顶破连锁删除的晶体。第 5 节便适用，顶针处理必须保持 K，与存在坏环矛盾。

因此，所有未移动组都能到达地面或含针环。再由第 2 节，移动组及最终重新分组后的图形也属于 K。得到：

> 四象限五层规则下，顶针对 K 封闭。

这项证明实际使用了“五层”：新地面针排除原第一层，顶破排除原第五层，剩下恰好三层可放坏环。更高层数时，这个证明不再成立；这不表示更高层数必有反例。

<a id="s01-12-h9"></a>

### 7. 制造树归纳：全部可制作图形属于 K

现在可以逐项完成封闭性检查：

| 输入或操作 | 保持 K 的理由 |
|---|---|
| 任意不含晶体的基础单层 | 每个组直接触地 |
| 旋转、仅改标签的染色 | 不改变支撑图结构 |
| 结晶 | 当前高度内全部填为非顶针格，各层完整，具有到地面的支撑路径 |
| 堆叠 | K 下料不动；最终保留上料可按基础块重建，输出仍在 K，见上轮证明 |
| 切割 | 第 3 节；两列中的非针组无法互相穿插成环 |
| 交换 | 先切割得到 K 半形，再拼接；新粘连只收缩非针节点，保留地面或含针环支撑 |
| 顶针 | 第 5、6 节；排除五层内的坏环 |

基础输入属于 K，每种合法操作对相关输入保持 K。沿有限制造树归纳，可制作集合 R 满足：

```text
R ⊆ K
```

上轮给出的稳定但不属于 K 的下料 `--------:cr--CuCu:cr--Cu--:crCuCu--`，现在可以据此判为本研究规则下不可制作。它仍说明任意稳定输入上的约化不成立，但不会反驳全部可制作下料上的约化。

反方向 K ⊆ R 不成立：[通用列内不变量](#s01-01)中的 C-P-C 单列属于 K，却违反晶体下方顶针必须为触地前缀的必要条件。因此不能据 K 实现一个“通过即判可制作”的判定器。

<a id="s01-12-h10"></a>

### 8. 对覆盖性研究的推进

全部可制作下料都在 K，故复杂堆叠约化不再依赖未知的支撑范围。可以对任意制造树沿堆叠下料支路回溯到最后一次结晶、切割、交换或基础输入，得到主文的起点集合 A。

从 A 出发，含晶体的成品存在最多四次顶针、最多五段基础堆叠、段间保留旋转的制造尾部。每段固定朝向的逆向前态至多 1296 个，且有精确堆叠判据。A 按完整可制作半形集合 H 定义，其有效构造由后续证明补齐：

1. [半形有限文法](02-four-quadrants.md#s02-02)给出 H 的必要且充分的有限递推、终止界及制造证书，不以稳定或属于 K 替代可制作性。

相邻两列半形已由[逐列角构造](02-four-quadrants.md#s02-03)压缩为稳定性加列条件的局部充要判据；完整全图的有界顶针与堆叠尾部仍需进一步简化。

## 01-13 顶破、碎晶与下落的完整顶针逆像

原文标识：`4q5l/pin-inverse.md`。

本文限定四象限五层，材料结构为 `N`（普通块）、`P`（顶针）、`C`（晶体）、`-`（空格），层号自底向上为 1～5。普通种类与合法颜色按[标签替换定理](#s01-09-h3)恢复。

结论是一个有限、必要且充分的逆向规则：恢复全部可能的来源格位与第五层，以静态支撑图和落点公式检查顶针结果，再用[半形闭包判定](02-four-quadrants.md#s02-02)筛选可制作前态。这里不把“前态可制作”留作未知判定器。证明不依赖运行枚举、模拟或游戏。

<a id="s01-13-h1"></a>

### 1. 一次下落可化为静止组与水平落块

先处理切割或顶破导致的融合删除。以删除完成、重力尚未开始的格位为 X，按当前格位建立最大粘连组。水平相邻的非针格粘连；同列相邻晶体竖向粘连；顶针单独成组。

画直接支撑边 G→H：G 的某格正下方是另一个组 H 的格。含第一层格的组接地。以下求出的集合 F 称为**静止组集合**，它不等同于 K：

1. 起初保留全部组。
2. 删除不接地、且没有指向仍保留组的支撑边的组。
3. 反复删除，直到不能继续。

F 是“每个组接地或被集合内另一个组阻挡”的最大集合。等价地，F 包含初始支撑图中所有能到达地面或任意有向环的组，以及这些路径上的组。这里允许无针环；不能在计算真实重力时先按 K 排除它们。组数至多 20，至多 20 轮删除即可完成。

<a id="s01-13-h2"></a>

#### 静止组定理

**F 中的组恰好是本次下落从未移动的组。**

充分性：F 中每组始终有地面或 F 内其他组阻挡。假设 F 首次有组移动，则它开始移动时这些阻挡都还在，矛盾。

必要性：设 U 为实际结算中从未移动的组。移动过的格不可能在任何后续时刻直接挡住一个始终未移动的格：它至少下降一格，若最终停在该格正下方，途中或起点就必须占过该格的位置。游戏不允许这种重叠或穿透。结算结束时，U 中每组因此只能被地面或 U 内其他组阻挡，故 U 是上述删除过程的一个不变子集，U⊆F。结合 F⊆U 得到等式。

这里的“移动过”包含晶体碎裂后拆出的子组。它们继承已发生的下降，不会重新成为未移动组。晶体消失条目不再阻挡活组；源码即使继续处理这些消失条目的动画位置，也不影响输出格位。层号下降有界，结算必然终止。

<a id="s01-13-h3"></a>

#### 剩余部分的精确落点

F 的全部格保持原位。其他初始组至少下降一次，所以其中的晶体全部消失，普通格和顶针全部保留。去掉这些组内的晶体后，把剩余部分分为各层的最大水平 N 连通块及单个 P。记每个块 b 的初始层号为 s(b)，占据列集合为 J(b)。

只把 F 的格作为固定障碍。按 s 从低到高处理其余块，同层顺序任意。令：

```text
z(b) = 1 + max(
    {0}
    ∪ {r : F 在列 j、高度 r 有格，j∈J(b)，r<s(b)}
    ∪ {z(a) : s(a)<s(b)，J(a)∩J(b)≠∅}
)
```

将 b 放到 z(b)。注意只看**初始位置下方**的固定格；不能用整列最高格阻挡本来就在悬空框架下方的块。

公式的证明分三步：

- 非 F 组的任何格都不可能正好被 F 的格从下方阻挡，否则该组也应加入 F。因此上述固定障碍至多在 s(b)−2。归纳地，较低移动块 a 满足 z(a)≤s(a)−1，所以 z(b)≤s(b)−1，与每块至少下降一次一致。
- 同列两个保留格不能交换次序。所有可能位于 b 下方的移动障碍，恰好来自初始层号更低、与 b 共享至少一列的块。同层不同块的列集合互不相交；初始较高的块不能穿过 b 来阻挡它。
- 当下方块到达最终位置后，b 会继续下降，直到地面或公式列出的最高障碍将其挡住。该块水平移动为零，内部只有一个高度，故首次阻挡就是整体落点。先前与晶体共同移动的一步只改变等待时序，不改变这些不可穿越的上下关系。

因此最终输出唯一等于 F 的格，加上按公式落稳的 N/P 块。这个证明也说明，选择哪个可动组先下降不影响这些保留格的最终位置；它没有把下落后的新接触合并后再做一次重力。

上述结算适用于本页的顶针及半切，因为结算起点全部格已在五层以内，不会再发生截高。不能不加说明地拿它替代任意堆叠后的截高流程。

<a id="s01-13-h4"></a>

### 2. 顶针的精确静态关系

给定候选输入 D，先在**原始 D** 上计算全部晶体融合分量。融合边仅连接水平相邻或竖向相邻的晶体，不经普通块，也不区分晶体颜色。

令 E 为所有接触原第五层的晶体融合分量的并集。构造结算起点 X(D)：

1. 删除 D 的整个第五层。
2. 删除 E 中位于原第一至第四层的晶体。
3. 其余原第一至第四层格统一上移一层。
4. 对 D 原第一层非空的每一列，在新第一层放一个 P。这个掩码在删晶体之前确定，即使原地面晶体被 E 删除，也仍加针。

随后应用第 1 节的 F 和落点公式。记所得格位为 Π(D)。则：

> Π(D) 与游戏一次顶针输出的材料、列号、层号逐格相同。

证明：源码先展开并记录融合关系，排除原第五层，提高其余引用并根据原底层占用补针，再在 `Collapse` 中处理融合删除与下落。上述四步中补针掩码取原 D，所以与实际调用次序等价。融合删除之后的活组是当前最大粘连组；第 1 节已处理其完整下落。所有活格在五层以内，末尾截高不再影响结果。

被删除的晶体现在有完整分类：原第五层直接删除；E 中低层晶体融合删除；X(D) 中非 F 组的晶体下落碎裂。其余晶体全部留在原层号加一处。不能只恢复 E 而漏掉第三类。

<a id="s01-13-h5"></a>

### 3. 从目标生成所有候选前态

以下求的是**可制作输入**的完整逆像。地面针掩码使用[已证明的可制作状态不变量](#s01-01-h6)，不宣称对任意不可制作语法状态也成立。

给定非空目标 T：

1. 若 T 第一层含 C，逆像为空。令 M 为 T 第一层 P 的列集合；这些格全部标为本次新生成的针。
2. T 的每个 C(z,j) 强制 D(z−1,j)=C。z 必须至少为 2。
3. 对每列，去掉第一步标记的新针，按从低到高顺序列出 T 中全部 N/P。这些格与 D 原第一至第四层的 N/P 一一对应，材料及列内次序相同。
4. 为该列的 n 个 N/P 选择严格递增的来源层号 r₁<…<rₙ，均在 1～4，且对应输出层号 zᵢ≤rᵢ+1。来源格不能覆盖第二步强制的晶体；n>4 时没有候选。
5. 原第一至第四层剩余未占格任取 `-` 或 C。原第五层四格任取 `-`、N、P、C。这些选择分别覆盖可能消失的低层晶体和完整的顶破层；不能加入没有输出对应物的低层 N/P。
6. 保留非空 D，且 D 第一层非空列集合必须恰好为 M。
7. 用第 2 节的静态公式要求 Π(D)=T；再用[全图可制作判据](02-four-quadrants.md#s02-02-h13)要求 D 可制作。

第 7 步之前可以用 K、Q、J 等必要条件排除候选，但通过这些条件不能替代可制作判据。

<a id="s01-13-h6"></a>

#### 必要性

任意真实可制作前态 D 都满足地面针等式。保留 C 没有下落，其来源位置唯一。原第一至第四层的 N/P 不被顶破、融合或下落删除，因此全部出现在 T；也没有除新地面针以外的新 N/P。它们只沿本列下降，次序不变、最终高度不超过来源层号加一，故必出现在步骤 3～4 的选择中。

其余低层格只能是空或后来碎掉的晶体；第五层完全由顶破删除，步骤 5 没有限制其真实取值。真实 D 因而一定被生成，并通过步骤 6～7。

<a id="s01-13-h7"></a>

#### 充分性

通过全部步骤的 D 已由独立判据给出合法制造方法。第 2 节保证其一次顶针结果恰好是 T。因此每个返回候选都是合法前态，不依赖猜测删除原因，也不依赖未定义的可制作性判断。

所以返回集合恰为：

```text
InvPin(T) = {D ∈ R : 一次顶针(D) = T}
```

<a id="s01-13-h8"></a>

### 4. 有限界、特例与证书

每列有 n 个待恢复的 N/P 时，忽略强制晶体、掩码及高度约束，可选择至多 `C(4,n)` 组来源层号，剩余格至多 `2^(4−n)` 种空/C 填充。n=0～4 时两者乘积依次为 16、32、24、8、1，最大为 32。顶层另有 `4^4` 种选择，因此整个逆像生成至多：

```text
32^4 × 4^4 = 2^28 = 268435456 个候选
```

这是不用运行枚举即可得到的宽松上界，不是可制作前态数量，也不是实际耗时承诺。强制晶体及底层掩码通常会排除大量选择。本规则首先解决完备性，尚未做工程压缩。

若限定输入高度≤4，则没有 E；可制作 D 属于 K，提高并补针后不下落。候选收缩为原有的唯一前态：T 第一层只有针或空，第一层针掩码等于第二层占用掩码，删第一层后整体下降一层。无顶破规则由完整规则直接推出。

一个前态证书只需记录 D 的制造证书、晶体融合分量 E、静止组集合 F、其余水平块的来源与落点。它覆盖顶破、融合删除、下落碎晶和 N/P 位移四部分；没有逐帧重放或依赖某种下落调度的必要。

<a id="s01-13-h9"></a>

### 5. 手推例：融合删除之外还会下落碎晶

取以下紧图形 D。表格从上往下展示，列从左到右为 q0～q3：

```text
原层5    C N N N
原层4    C N C N
原层3    C N N N
原层2    C C C C
原层1    C N N N
```

它可由任意紧图形构造制造。q0 的五格晶体与原第二层整行晶体同属融合分量 E，接触第五层，故全部删除。原第四层 q2 的晶体被 N 隔开，不属于 E。原第五层其他 N 直接顶破删除。

提高并补针后，第一层四个新针和第二层 q1～q3 的 N 构成静止部分 F；第四层的三个 N，以及第五层的 N-C-N 组不属于 F。第四层 N 块落到第三层；第五层组至少下降一次，其中 q2 晶体碎裂，q1、q3 的 N 各落到第四层。结果为：

```text
结果层4  - N - N
结果层3  - N N N
结果层2  - N N N
结果层1  P P P P
```

这个例子同时包含顶层删除、融合向低层传播、融合分量之外的下落碎晶和普通格位移。逆向时若只补 E、不考虑非 F 组碎晶，就会漏掉合法前态 D。以上逐组推导未执行模拟。

## 01-14 四列晶体的顶边连通扫描

原文标识：`4q5l/crystal-boundary.md`。

四象限、任意正层数的晶体网格，全部触及最高层的C融合分量，可用一次向下扫描和一次向上补全求出，不需要一般图洪泛。这一结论不要求列A或可制作性，所以可直接用于独立顶针必要筛选。实现为[`top_connected`](../../circuits/ring_circuit.py)。

<a id="s01-14-h1"></a>

### 行内闭包

四格圆环中，两个相邻C直接连接。两个相对C连通，当且仅当两个中间象限至少一个为C；最短路径至多二。给定本行种子，可将全部连通可达格直接写成四个种子的布尔并集。

另一个关键性质是：一行若同时有两个互不连通的非空C分量，它们必各占一个相对象限。这是四列环的性质，六列不满足。

<a id="s01-14-h2"></a>

### 向下与向上

层号从0开始，最高层为h−1。先把该层全部C作为种子，得到D[h−1]。从上到下计算：

```text
D[z] = 本行C中，由 D[z+1] 正下方C格出发的行内闭包。
```

D是只允许水平或向下走的可达集合。若某行D[z]为空，则所有更低行D也为空。

再令U[0]=D[0]，从下到上计算：

```text
U[z] = 本行C中，由 D[z] 与 U[z−1] 正上方C格出发的行内闭包。
```

最高层原本全部为种子，直接保持该层所有C。每个U格均通过真实水平或竖直C边连到顶层，因此没有误加。

<a id="s01-14-h3"></a>

### 两次扫描已经完整

U对水平和向上边已经闭合。只需证明它也对向下边闭合。

对于原来就在D中的格，其下方C已经在下一低层D中，因此也在U中。考虑U[z]中新增、但不在D[z]中的格。

此时D[z]不可能为空：若为空，则全部低层D为空，向上补全在低层也没有种子，不会给本行新增格。既然本行同时有D中的C和不在D中的C，而D已做过行闭包，这些C属于不同分量。四列性质要求两个分量各自为单格，新增格因此不能通过横向扩张加入，只能由其正下方已经属于U[z−1]的C直接加入。它的向下邻居早已到达。

故所有新增格也没有尚未到达的向下邻居，U对全部C邻接边闭合。U包含全部顶层种子，且每个U格都真实可达，因此恰好等于触及顶层的全部融合分量。

五层时只需四次向下行闭包和三次向上行闭包；顶层全种子、底层直接沿用向下结果。门数和组合深度随层数线性增长。没有目标目录、数据相关迭代状态或全连通矩阵。

<a id="s01-14-h4"></a>

### 接入顶针

`image_constraints`把原前四层C及第五层C掩码交给本通路。所得格恰好是顶破连带删除的晶体；后续活格、F/M一致性、NPC目标层和支撑检查保持原定义。Python仍可通过普通融合分组求同一集合，不要求两种实现采取相同计算顺序。

本页只是融合删除的优化；精确Pin关系还需[静止格判定](#s01-15)及[块落点证明](#s01-16)，前态可制作性仍由递归制造证明确认。

结论来自行分量性质及闭包证明。未运行目标、目标枚举、测试、模拟或游戏。

## 01-15 顶针静止格等于地面可达格

原文标识：`4q5l/pin-grounded.md`。

四象限五层、输入满足列A时，顶针融合删除后的最大静止集合F，恰好等于沿粘连和向下支撑可达地面的格。这里不必先证明输入可制作，也不必先证明它属于K。这个结论用来替换[精确Pin像检查](#s01-16)中的组编号及最大集合剥离，不替代来源的制造证明。

以下用输入原层号0～4描述，最高层4已被顶破；其余格提高一层，新地面针另计。所有“保留”均指融合删除后、重力开始前仍存在。

<a id="s01-15-h1"></a>

### 1. 最低两层的保留晶体必连到地面

原第0层的任何保留格提高后，正下方都有本次新增地面针，故属于地面可达集合H。

原第1层若为C，列A禁止其下方为空：下方为空时，再没有更低N可满足晶体间隙条件J。其下方可能是N、P或C。N/P不会被融合删除；C若被融合删除，则相邻的第1层C也会一起删除，与该C保留矛盾。因此该C下方有一个原第0层保留格，后者已经连到地面，所以该C也在H。

故H以外的晶体只能位于原第2、3层。

<a id="s01-15-h2"></a>

### 2. H之外不存在静止组

粘连组中一格属于H，则整组都属于H。若一个组直接压在H的格上，它也属于H。地面可达关系因此在粘连组层面闭合。

反设最大静止集合F中还有不属于H的组，记这些组为S。每个S组都必须由另一个S组直接支撑：不能依赖移动组，若依赖H则自己也在H。

S不含原第0层格。原第1层没有S晶体；其中的N组只能是单层水平块，P则单独成组，均不能向上粘到第2层。它们的下方只有原第0层，那里没有S格，所以也不能属于S。

于是S全部位于原第2、3层。原第2层P下方没有S格，不能属于S。原第3层P不能支撑任何S组，因为其上已是被顶破的最高层。因此任何S支撑环都不含P。

有限S图每个组都有指向S的支撑边，必含有向环。环上每个非针组必须同时经过这两层：只在下层的组没有向环内的支撑边，只在上层的组没有来自环内的支撑边。

四列圆环的一层至多容纳两个互不粘连的非针组；若有两个，它们必须各占一个相对象限。环不可能只有一个组，因为组内下方格不是外部支撑。因此环恰有两个组，它们在上下两层都各占一个相对格。

每组连接两层只能依靠同列CC竖边，所以它在两层占同一列。两个组各占相对列，彼此没有同列上下相邻格，根本不存在外部支撑边。矛盾。

因此F⊆H；反方向H⊆F由地面开始沿粘连和直接阻挡归纳成立。得到F=H。

这个证明依赖四象限、顶破后只余四层以及列A。任意材料网格、六象限和更高层数不使用该捷径。

<a id="s01-15-h3"></a>

### 3. 下部三层与上部八格

以下改用抬升后的活图层号0～4。第0层为新地面针，第1层全部保留格直接压在新针上，所以两层所有占用格都在H。

第2层所有保留C已经由第1节证明在H。其余N只能经水平非针邻居或正下方第1层格获得支撑；P只能经正下方。上方第3层返回第2层的唯一粘边是CC，而所有第2层C早已在H，因此无需从上方补充第2层的可达性。以第2层正下方非空格为种子，求水平非针连通分量的种子并集，得到这一层完整H。

只剩第3、4层共八格。以第3层正下方属于H的格为种子，可达边为：

- 水平相邻非针格之间双向传播；
- 从第3层已到达格传播到其正上方第4层占用格，包括P；
- 从第4层C向正下方第3层C传播。

四格环中，两个已连通非针格的最短距离至多二：相邻格直接连接，相对格经过任一非针中间格。因此可把一行的连通闭包直接写成四个种子的布尔并集，无需三轮洪泛。

上部也无需通用七轮传播。先求第3层水平闭包A0，再从A0直接向上及水平闭包得到B0；然后从B0沿CC向下及水平闭包得到A1；最后从A1向上及水平闭包得到B1。所有步骤都保留已有可达格。

证明A1、B1已经固定：第3层至多有两个非针水平分量。若只有一个，A1新增非针格时就已覆盖该完整分量，B1不可能再向下发现其他非针分量；若A1没有新增，B1=B0，本来也不会产生新向下路径。若有两个，它们各自只能是一个相对格。每个新加入A1的单格必通过其正上方B0中的C获得支撑，再向上只会返回这个已在B0的格，故B1=B0，也不可能继续新增。第3层P不能接受向下或水平传播，只能属于初始种子。全部情况都没有第二次有效向下传播，所以结果完整。

[`stationary_matches`](../../circuits/stationary_circuit.py)将中层水平闭包和上部A0、B0、A1、B1直接展开为组合门，与推定F逐格比较。它没有组编号、静止状态、轮数或缓存寄存器。仍须满足[块落点充要条件](#s01-16)，不能只凭地面可达就判Pin命中。

完整控制仅在`candidate.valid`且本比较为真时下降；前者已检查四列完整列A。因此通过路径满足本定理前提。所有相关输入来自慢状态，更新后的一轮冻结为组合结果留出7P传播期。

同一前四层及顶层C掩码的NPC顶盖拥有相同活图，故物理失配仍可跳过整个NPC族。当前成员若因顶层P而违反列A，不影响这一跳过规则：若该族存在任何满足列A的其他成员，本定理就适用于同一活图及同一比较结果；若没有，此族本就不可制作。物理匹配不缓存，直接共用同一组合通路。

Python精确匹配仍保留一般最大静止集合路径：规范化来源满足列A时从地面组求最小不动点，否则从全部组求最大不动点。两条路径在满足列A的输入上由本定理相等。电路仅用于已经通过列A的候选，所以直接使用格位传播。

未运行目标、目标枚举、测试、重力模拟或游戏；结论来自上述几何证明及源代码静读。

## 01-16 顶针像：静止集合补全后的充要判据

原文标识：`4q5l/pin-image-exact.md`。

本页补齐[制造前必要筛选](08-circuits.md#s08-25)缺少的条件：推定静止格集合必须恰好等于真实最大静止集合F。对[规范化顶针逆像族](08-circuits.md#s08-26)，补上这一等式后，现有条件足以证明一次Pin结果逐格等于目标，无需先制造前态或运行原生Pin。

该判据判断物理映射，不判断前态可制作。前态仍需完整尾部递归，成功后仍须输出从基础料开始的制造流。以下是静态数学推导，没有执行目标、搜索、模拟或测试。

<a id="s01-16-h1"></a>

### 1. 前提与判据

前四层来源由列模式和目标标签确定；顶层只保留晶体掩码用于融合，其他顶格在重力前删除。按已有逆像规则要求：

- 新地面针掩码等于原底层占用，保留C有唯一的低一层来源且不被触顶融合删除。
- 其余N/P与目标N/P逐列一一对应，来源次序和标签保持，目标高度不超过抬升后的来源高度，也不穿越保留C。
- 融合删除、抬升和补针得到活格X。推定静止集合F̂由新地面针、保留C、目标高度等于抬升后来源高度的N/P组成。
- 每个X最大粘连组的F̂标记一致；非F̂格不得直接被F̂格从下方阻挡。
- 去掉非F̂部分的C后，每个水平普通连通块及单针各有统一目标高度，并在该高度触地或至少有一个格的目标正下方占用。
- 新增条件：F̂等于X初始组支撑图的最大静止集合F。

F的定义允许无针支撑环，不能用K替代。原始组内的正下方格不算外部阻挡。[静止组定理](#s01-13)已证明F恰好是整个下落中从未移动的初始组。

<a id="s01-16-h2"></a>

### 2. 充分性：支撑条件已经给出了精确落点

F̂=F后，所有保留C确实静止，其余未融合删除的C都属于移动组并在第一次下落时碎掉；每个固定N/P也确实留在目标位置。剩下只需核对移动水平块b。记抬升后的来源高度为s，指定目标高度为h；移动定义保证h<s。

按来源高度从低到高归纳。对与b共享任意一列的所有可能阻挡：

1. 初始高度小于s的固定C，若位于h以上就违反晶体屏障；也不能位于h，因为该目标格已经是b的N/P。所以它严格低于h。
2. 初始高度小于s的固定N/P，来源秩低于b，逐列保序使它的目标高度严格低于h。
3. 新地面针若在该列，属于目标地面P；该P已从保留NPC列表移出，不能同时是b的目标格。故该针也严格低于h。
4. 来源高度更低的移动块，由归纳已落在其目标高度；逐列保序同样使该高度严格低于h。同来源高度的不同块不共享列。

所以[精确落点公式](#s01-13)列出的全部障碍都不高于h−1。若h=0，没有更高障碍，b落地恰为0。

若h>0，判据给出b某成员目标正下方h−1的一格。该格若固定，就是初始下方的F障碍；若移动，来源秩比b低，因此其来源高度也更低，归纳保证它已成为h−1的实际障碍。更高来源N/P不可能先映射到b之下。故最大障碍至少为h−1，与上界合并，b的精确落点为h。

逐块归纳得到全部移动N/P恰在指定目标位置。固定格、移动NPC及新地面针穷尽所有产物，标签也逐格继承，因此实际Pin结果等于目标。

<a id="s01-16-h3"></a>

### 3. 必要性及范围

真实可制作逆像属于规范化候选族，并满足既有必要条件。静止组定理使其F̂=F，所以通过新增判据。结合充分性，在规范化候选族内得到精确物理匹配判据。

该结论没有把地面针归属规则推广到任意不可制作语法状态，也没有假设下落中新接触会重新合组。实际结算仍只在碎C时拆组；证明使用原组和原来源高度。

<a id="s01-16-h4"></a>

### 4. 列A来源的组合求F

一般材料图的F允许支撑环，应按组的最大静止集合定义。对本求解器已经通过完整列A的四象限五层来源，[地面可达定理](#s01-15)证明活图的每个静止组都连到地面，故最大静止集合等于地面可达集合。

[`stationary_matches`](../../circuits/stationary_circuit.py)先确定下部支撑，再通过上部两次向上及一次向下行闭包求F，没有组编号、轮数或物理状态寄存器。行闭包利用四列圆环内的最短连通距离至多二。融合删除由[顶边扫描](#s01-14)单独精确计算。

Python的[`pin_image_matches`](../../synthesis/pin_constraints.py)在完整列A成立时从地面组向上取最小不动点；否则保留一般最大不动点路径。因此没有改变任意规范化材料输入上的物理含义。

<a id="s01-16-h5"></a>

### 5. 完整控制中的使用

只有完整候选有效且F比较通过时，控制器才递归制造来源。所有物理输入都来自慢状态，其组合传播期限统一纳入7P。物理失配仍可跳过同一前四层和顶层C掩码的全部NPC顶盖；不保存物理缓存。若同族存在满足列A的成员，则本定理适用于该共同活图；若没有，这一族本来就不能制造。

完整搜索只保存材料参数和精确关系，A叶端直接由构造定理返回存在性证书；根成功后才执行制造ROM并逐层原生比较。规模和时序以[完整控制说明](08-circuits.md#s08-09)及生产JSON为准；相关Python静态诊断和生产蓝图编译已通过。没有执行目标、搜索、制造、模拟、测试或游戏。

## 01-17 K支撑类的一次格位洪泛

原文标识：`4q5l/support-reachability.md`。

本页把[支撑类K](#s01-11-h2)压缩为一次格位可达性，而不建立二十份组连通矩阵。Python实现为[`synthesis.support.in_support_class`](../../synthesis/support.py)，电路实现为[`support_circuit.in_support_class`](../../circuits/support_circuit.py)。这是K的精确判据；K仍只是四象限可制作性的必要条件。

<a id="s01-17-h1"></a>

### 1. 格位图

对所有占用格建有向图：

- 水平相邻的两个非针格之间加入双向边。
- 同列相邻的两个C之间加入双向边。
- 任意占用格向正下方紧邻的占用格加入向下边。

前两类边是原始粘连，最后一类是阻挡方向。同一粘连组中的向下边可以存在于格位图中；收缩整个组后它们只是自环，不会创造通向其他组的路径。反过来，组支撑边可由组内粘连路径加一条向下边表示。因此到地面或某颗针的格位可达性，与原最大粘连组支撑图相同。

令种子集合B为所有地面占用格与所有针格。判据为：

1. 每颗非地面针的正下方都有占用格。
2. 每个占用格都能沿上述边到达B。

<a id="s01-17-h2"></a>

### 2. 与K等价

若属于K，每组到达地面或含针支撑环。到达含针环后继续沿环即遇一颗针；组内所有格也能走到这条支撑路径，故条件2成立。非地面针单独成组，只有正下方这一条可能的支撑边；属于K时它不能没有出边，故条件1也成立。

反过来，条件2使每组能到达地面或某颗针。任取非地面针p，条件1给出它到下方组的边；条件2又使下方组到达地面或某颗针p'。若一直没有到达地面，就得到一条针到针的有限节点序列。最终必重复某颗针，形成经过针的非平凡闭合支撑路径，其中包含一个经过针的有向环。针不会与其他格粘连，不能在组收缩时被吞入内部自环。

所以每颗针都能到达地面或含针环，所有到达针的其他组也同样如此，即属于K。

这里把所有针当作洪泛种子并不等于无条件认为它们悬空有效；条件1和有限针序列证明补齐了这一点。只做种子洪泛而省略针的下方占用检查，会误收悬空单针。

<a id="s01-17-h3"></a>

### 3. 电路与Python

反向传播“可以到达B”的布尔标记：地面及针初始为真；非针格若水平相邻非针已标记、正下格已标记，或自身与上格均为C且上格已标记，就得到标记。地面行固定，不重复计算。

四象限五层至多20个节点，任意可达路径可去环成为至多19边的简单路径。同步传播19轮得到精确可达集合；不需要模拟重力或反复重新分组。Python按实际格数执行最多N−1轮，提前固定时停止；通用电路默认固定展开19轮；完整求解器利用另行验证的列A，改用[十次行闭包](#s01-18)求出同一可达集合。

针正下占用另行合取。每个占用格都标记时返回真；空图按空条件属于K，调用端仍自行排除空目标。

<a id="s01-17-h4"></a>

### 4. 接入完整搜索

四象限已有[全部可制作图形属于K](#s01-12)的制造树证明。因此完整搜索可提前拒绝非K目标和非K的S前态P；真实Pin输出若可制作也必属于K，不会因这项筛选丢失成功分支。

Python局部构造器用K判据替代原来的重新下落稳定性检查。K保证每组有地面或其他组的阻挡，所以没有任何组能首先移动，必然稳定；新检查既保留旧必要排除，又能拒绝稳定的无针坏环。`Solver4.predecessors`默认过滤K；Pin轮明确选择`grounded=True`，按[顶针尾部G必要条件](08-circuits.md#s08-10)只保留能通向地面的前缀。

完整电路共用K/G通路：ENTRY读完整帧目标K，首轮PREFIX读前缀K；零Pin失败后PIN_PREFLIGHT读取完整目标G，随后Pin轮PREFIX读取前缀G。support_prefix选择材料，pin_search选择种子；G模式的P不再自动作为种子，而通过已到达的正下方格获得标记。子帧写入时同时清pin_search，保证ENTRY仍按K判定。所有切换都按[慢更新冻结协议](08-circuits.md#s08-16)等待一轮，十次行闭包路径纳入组合DAG。

[来源族G筛选](08-circuits.md#s08-07)另用optional_top放宽最终最高普通格的必达要求。自由顶N仍参与完整洪泛，只在末端允许未接地的可选N被省去，固定格及P下方要求保持。该掩码只在可选模板整体G检查启用；精确目标和实际前缀的判据不放宽。

六象限存在可制作非K输出，故Python只在四象限调用这项制造必要筛选；完整电路本身也只生成四象限配置。K可达性本身可作结构分析，不能据此将非K六象限目标判不可制作。

<a id="s01-17-h5"></a>

### 5. 规模与验证

引入共用K通路时为37278平台、356状态，未增加当时时钟周期。当前完整控制已改用慢更新冻结，规模与时序见[完整版](08-circuits.md#s08-09)。K在进入S扫描和Pin逆像前排除整棵无效分支，实际搜索收益未经运行测量；最坏等待仍须继续压缩。

## 01-18 列A网格的十次行闭包

原文标识：`4q5l/support-row-scan.md`。

[格位可达判据](#s01-17)对任意四象限五层网格可用十九轮传播。完整求解器另行保证列A，可改用本页的十次行闭包，保持K/G可达集合完全相同。实现为[`_admissible_reach`](../../circuits/support_circuit.py)；默认通用入口仍使用十九轮传播。

<a id="s01-18-h1"></a>

### 1. 传播方向与行闭包

行号为0～4。反向传播“能走到支撑种子”的标记：已标记下格可标记同列占用上格；水平两个非针相互传播；向下传播仅限相邻两个C。K的种子为地面占用格与所有P，G只有地面占用格。

`row_reach`取一行的非针占用与种子，精确闭合水平路径。P可保留自身种子，但不能沿水平边传播。四格圆环的非针分量只有三种情形：零个、一个、两个；两个时必为相对的单格。

记U_z(B)为从下行B向第z行传播、加入本行P种子后做行闭包；记D_z(R,T)为保留本行R、从上行T沿CC向下传播后做行闭包。两者只增加沿真实图边可达的标记。

<a id="s01-18-h2"></a>

### 2. 两行闭包

固定下部外来支撑B，考虑两行L、T，允许两行各自有P种子。计算：

```
L0 = U_L(B)
T0 = U_T(L0)
L1 = D_L(L0, T0)
T1 = U_T(L1)
```

这就是两行的最小闭包。P在L中的可达性只依赖种子和B，向下CC及水平传播均不能新增P。于是只需考虑L的非针分量：

- 零个时没有可新增格。
- 一个时，L1若比L0增大就已包含整个非针分量；T1不能再向L增加任何非针格。若没有增大，T1=T0。
- 两个时，各分量只有一格。L1新增加的格必为C，且它正上方的C已经属于T0。这一格向上传回的种子已经在T0中，因此T1=T0，不会产生下一轮新格。

所得集合对所有传播边闭合，且每一步都有真实路径证据，所以等于最小可达集合。调用方只需要L1时可以省去T1的实体门；需要上行结果时再计算U_T(L1)。

<a id="s01-18-h3"></a>

### 3. 三行闭包

固定下部支撑B，考虑行M以及上部两行。以Pair(M)表示上节两行精确闭包的下行结果：

```
M0 = U_M(B)
L0 = Pair(M0)
M1 = D_M(M0, L0)
L1 = Pair(M1)
T1 = U_T(L1)
```

M只有一个非针分量时，新增即覆盖该分量；M有两个分量时，新增加的单格只能沿CC从L0得到标记。该单格新增的上行种子已经在原上部闭包中，因此Pair(M1)=Pair(M0)。M中的P可达性仍固定。与两行证明相同，最终对所有边闭合，且只使用真实路径，因此精确。

<a id="s01-18-h4"></a>

### 4. 列A固定底部边界

列A的晶体间隙条件要求：某C正下为空时，最近的更低占用格必须是N。第1行C若第0行为空，就不存在这样的更低N，因而违反列A。所以列A网格的第1行C必有占用正下格，全部从地面得到标记。

第0行已全部标记。第1行用一次U_1求出精确结果：上方只能沿CC新增标记，但第1行的所有C已经标记；N/P不能接收来自上方的传播。第2～4行于是可直接套用三行闭包。

总计十次行闭包：第1行一次，第2行向上和向下各一次，两次Pair各三次，最后第4行一次。每次都是固定四格布尔式，没有迭代寄存器。对K仍将所有P作为种子；不能把K改为仅接地的G。P正下占用仍由末端单独合取。

<a id="s01-18-h5"></a>

### 5. 调用前提与可选顶格

完整求解器的ENTRY独立合取列A；非法目标即使短扫描给出任意结果也不能进入搜索。Pin来源下降前已验证完整列A。可选族模板只把自由最高NPC改为N，不改变低层或C，保持列A。S前缀只删除本列最高C之上的NPC尾部，同样保持列A。故所有会影响成功或失败分支的支撑查询均满足本页前提。

`admissible=True`是编译期专用选项，不替代列A检查。默认值为False，任意网格接口保持原十九轮传播。Python通用支持判据仍使用原图洪泛。

[来源族G筛选](08-circuits.md#s08-07)仍对整个含可选N的模板求可达集合，最后才豁免未达的可选顶N；短扫描不改变该顺序，也不改变实际前缀的要求。

<a id="s01-18-h6"></a>

### 6. 验证边界

依据为上述图论证明、调用前提静态重读，以及生产蓝图的DAG、端口和占地编译。未执行目标、求解器、模拟、测试或游戏。门数与时序由完整蓝图重新编译后记录在[完整尾部电路](08-circuits.md#s08-09)，本项不减少Pin逆推的最坏分支数。

## 01-19 两列半形的按层稳定性判据

原文标识：`4q5l/half-row-stability.md`。

任意相邻两列、任意高度的 N/P/C 网格，其重力开始前的最大粘连组是否全部静止，可以只按层扫描，不必求十格连通矩阵。五层实现见 [`CornerBuilder.stable_half`](../../synthesis/corners.py)、[`half_stable`](../../circuits/half_circuit.py) 及 [`material-half-4q5l.spz2bp`](../../blueprints/material-half-4q5l.spz2bp)。本结论用于两列，不直接适用于一般三列半形。若第三列已知是一根全高N边柱，可按[脚手架支撑证明](03-general-construction.md#s03-04-h5)，把与该柱相接加入区间支撑标志，继续复用本扫描；六象限根半形仍需完整分组判定。

<a id="s01-19-h1"></a>

### 每层至多一个非针组

一层中去掉空格和针后，只剩至多两个相邻普通块或晶体。如果有两个，它们水平相邻，必粘连；所以该层至多有一个非针水平组。P永不水平粘连，分别单独成组。

不同层之间只有同列相邻C粘连。定义：

```text
R[z] = 第z层存在非针格；
V[z] = 至少一列在z−1与z同时为C（z>0），V[0]=false。
```

V[z]把相邻两层唯一的非针水平组连接起来。因此所有非针最大组都恰是由V连续连接的层区间。各区间没有分叉或同层的另一支，不需要一般图搜索。

<a id="s01-19-h2"></a>

### 区间从哪里得到外部支撑

取一个非针最大组，其层区间为[a,b]，层号从零开始。

- a=0时，该组接地。
- a>0时，第a层组内任一格的正下方有格，就构成外部支撑。否则若该下方格也在本组，区间就应延伸到a−1，与a最小矛盾。
- 对z>a的组内格，若正下方为N或C，则该下方格位于z−1的唯一非针水平组。由于区间内部V[z]为真，该水平组已经在同一最大组内，不能作为外部支撑。
- 对z>a的组内格，正下方为P则是另一个单针组，能作为外部支撑；正下方为空则不能支撑。

故非针组稳定，当且仅当它接地、最底层有直接阻挡、或其任一层有组内格直接压在针上。针自身稳定，当且仅当接地或正下方非空。

只要每个最大组有地面或另一组直接阻挡，初始时就没有任何可以移动的组，整个结算不发生移动。若存在无阻挡组，它会移动，其格位至少改变或晶体消失。因此上述检查正是新分组稳定性，允许真实的互阻支撑环，不把K作为额外假设。

<a id="s01-19-h3"></a>

### 一次向上扫描

令S为当前区间已收集到的外部支撑。

1. 在第0层，S=R[0]。
2. 若V[z]为假，开始新区间，把S设为该层非针格正下方有格。
3. 若V[z]为真，延续前一区间，只把该层非针格下方的针加入S；普通/C下方格属于本组，不能加入。
4. 只有在区间结束，即V[z+1]为假或已经到顶层时，才检查该层R为真时S也为真。
5. 每个非底层针另检查其下方非空。

每层只读本层与下一低层的两格。空间与层数无关，计算量与层数成正比。较高层的针可能给整个区间提供支撑，所以不能在尚未读到区间末端时过早拒绝。

Python用这一扫描替换 `accepts_half` 中的一般组/owner映射，列A和角构造保持原含义。原生图形输入的旧半形蓝图仍用半切比较，作为原有快速路径；新材料网格部件独立使用本判据，不依赖能否把候选编码为原生图形信号。

<a id="s01-19-h4"></a>

### 直接读取材料格的电路

材料半形蓝图使用461块平台。输入十个整数，按原层号自底向上、每层q0/q1排列：0空、1普通、2针、3晶体。其他两列规定为空。所有原层位都显式提供，空底层与中间空层不会被压缩。

输入有效、非空且enable为真时，输出status=1或2，分别表示可制作或不可制作；空网格、非法材料整数或关闭时status为空。依据为[两列A加稳定性的充要定理](02-four-quadrants.md#s02-03)。材料代码3以合法rgbcmyw供料为前提；调用者仍需排除未界定供料的cu，普通种类与合法颜色由制造标签恢复。该部件只判结构，不输出配方。

源码和证明均已静态重读。生产编译核对实际占地与各端口几何接线；未运行任何目标、枚举、测试、门级模拟或游戏。

<a id="s01-19-h5"></a>

### 材料格逆推与精确顶针关系

[`Solver4`](../../synthesis/solver4.py)支持`certificate_first=True`，用[最大静止集合与块支撑判据](#s01-16)精确判断`Pin(D)=P`。默认模式直接计算正向Pin；两种模式接受相同规范化逆像族，均需独立证明D可制作。

## 01-20 无环条件、一次稳定化与交换反例

采用偶数象限 n、共同高度 H的既有规则，层号从0开始。F表示一次按当前格位重新分组、执行重力并写回的操作；它不反复合组到稳定。下文输入位于 H层以内，不在重力结束后截掉原本保留的低部支撑。N、P、C分别表示普通格、针、晶体。

支撑图以当前最大粘连组为节点，针各自独立；G→B表示 G的一格紧邻立在另一个组 B上。同组内部的上下接触不记支撑边，地面节点不是循环。本文的“无环”指这个有向图没有支撑环。它不等于“已经稳定”，也不表示切割后的图仍无环。

| 命题 | 结论 |
|---|---|
| 当前无环的不稳定图形，执行一次 F后稳定 | 成立；输出各组都能到地面 |
| 堆叠前下料无环，任意合法上料的堆叠输出稳定 | 成立；下料可以原本不稳定 |
| 交换器两个完整输入无环，交换输出稳定 | 不成立；切割能从原粘连组中露出支撑环 |
| F后仍不稳定，说明 F前存在无针支撑环 | 成立 |
| F后仍不稳定，说明 F后的支撑图仍有环 | 不成立；旧环可能已经被合成一个无支撑组 |

<a id="s01-20-h1"></a>

### 1. 无环输入的一次结算必稳定

**定理。**若 X的支撑图无环，则 F(X)的每个组都能沿支撑边到达地面。因此

```text
F(F(X)) = F(X)。
```

**证明。**在这次 F中，把从未下落的原粘连组称为固定组。晶体开始下落就消失；移动后保留的组只是一层普通块或单针。

[固定组不能由移动组取得最终支撑](#s01-12-h2)：若一个已下降格最终立在固定格正下方，它此前就必须穿过该固定格。故每个不触地的固定组，最终都被另一个固定组阻挡。

固定组间的这些边早已存在于 X的支撑图，构成它的一个子图。这个子图仍无环。沿固定组的支撑边不断向下追踪，有限图中不能无限走，也不能回到原组，因此最终必到地面。

移动后保留的 N块和针也有直接下挡。若下挡同样来自移动组，支撑边严格降低层号，故经过有限步到达地面或固定组。于是重力结束、尚未按新接触合组时，全部保留组都能到地面。

写回之后的新粘连只合并非针组。原来的地面路径经节点合并后仍到地面；若某段路径变为同组内部关系，省掉这段即可。输出的每个组因而仍有地面支撑，下一次重新分组不再下落。证毕。

这一步使用的是“固定组最终依靠谁”，不能只说“悬空就一定有环”：一个已经合成的悬空大组，可以没有任何组间支撑边。

<a id="s01-20-h2"></a>

### 2. 堆叠结论与更弱的充分条件

**推论。**若下料 D无环，则对任意合法上料 U，Stack(D,U)稳定；输出每个组都能到地面。

**证明。**[精确堆叠分解](04-stacking.md#s04-06-h1)给出：同一次 Stack中下料的贡献恰为 F(D)，与 U无关。由第1节，F(D)全部接地。

保留的上料格不含 C。它们从下料上方下降，拆成水平 N块或单针，每个保留块都被地面、下料或更低的保留上料块阻挡。固定上料留在高度上限以外，不能成为保留格的下挡。沿移动块的下降支撑最终到达地面或 F(D)。写回时的新粘连保持这些地面路径，故输出稳定。证毕。

还可放宽“无环”。如果这次重力的每个固定组，都能经固定组支撑到地面或一个含针环，那么重力输出属于 K，因而稳定；证明见[通用固定组结算引理](#s01-12-h2)。所以只排除所有无针环、允许含针环，也足以保证一次 F及任意上料 Stack的稳定性。某些能接地的无针环同样安全，不必一概拒绝。

这里检验的是本次固定组的支撑证书，不是把“所有可制作图形都属于 K”推广到任意象限。

<a id="s01-20-h3"></a>

### 3. 无环完整输入交换后不稳定：六象限五层反例

取 n=6、H=5。X如下，行号为零基层号：

```text
 z   q0 q1 q2 q3 q4 q5
 4    C  N  N  C  .  .
 3    C  .  N  C  .  .
 2    C  N  N  C  .  .
 1    .  .  .  C  .  .
 0    N  .  .  C  .  .
```

q3为连续触地晶体柱。它在第2、3、4层分别接到 q2的 N，把左侧原本的框架和中央普通块接成同一个触地组。q0地面 N独立触地。因此 X稳定，支撑图也无环。

令 Y为 X旋转3列：

```text
 z   q0 q1 q2 q3 q4 q5
 4    C  .  .  C  N  N
 3    C  .  .  C  .  N
 2    C  .  .  C  N  N
 1    C  .  .  .  .  .
 0    C  .  .  N  .  .
```

Y同样稳定且无环。使用 N=Su、C=cr，两个完整输入的短代码分别为：

```text
X = Su----cr----:------cr----:crSuSucr----:
    cr--Sucr----:crSuSucr----
Y = cr----Su----:cr----------:cr----crSuSu:
    cr----cr--Su:cr----crSuSu
```

每个等号后的两行拼接。交换器取 X的012半面、Y的345半面。X的 q3晶体柱与保留的 q0晶体柱之间只有普通格连接，没有跨切 CC融合；Y同理。因此两根接地晶体柱被切去，却不连带删除保留晶体。

切完后的两个半形分别是[已证明可制造的 H₃](#s01-04-h1)及其旋转：外框的顶格被内部 N挡住，内部 N又被外框底格挡住。它们各自形成无针环，稳定地通过切割重力。

随后拼接得到 Z：

```text
 z   q0 q1 q2 q3 q4 q5
 4    C  N  N  C  N  N
 3    C  .  N  C  .  N
 2    C  N  N  C  N  N
 1    .  .  .  .  .  .
 0    N  .  .  N  .  .
```

```text
Z = Su----Su----:------------:crSuSucrSuSu:
    cr--Sucr--Su:crSuSucrSuSu
```

第2、4层跨边界相连；第3层 q2的 N接到 q3晶体，q5的 N接到 q0晶体。原来的两个外框和两个内块全部成为同一个大组。它最低在2层，正下方1层全空，又不触地，故 Z不稳定。Swap拼接后不再执行 F，所以 Z就是实际机器输出。

**制造凭据。**先按 H₃的已有五层配方制造012半形，再制造只占 q3的触地五层 C柱；两者分别位于互补半面，交换即可得到 X。输入半形本来稳定，预切只删空列，不损坏 C。Y由 X旋转取得。因此反例的完整输入都能在同一 n=6、H=5内真实制造，并非任意填写的语法网格。

这说明：无环不是对切割封闭的性质。切割拆开原来的同一粘连组，原先属于组内的上下格，可能变成两个新组之间的反向支撑边。

<a id="s01-20-h4"></a>

### 4. 交换可以使用的正确条件

若两份实际切后半形都属于 K，则它们拼接后仍属于 K，交换输出稳定。拼接只增加连接、合并非针组；已有地面路径保持，针始终独立，含针环也不会全部变成一个组的内部关系。

特别地，若两份实际切后半形稳定且无环，它们的所有支撑路径都必须到地面，故满足上述条件。不能省略“实际切后”或“稳定”：第3节的完整输入无环，切后半形却有环；而一个无环的当前状态也可能本来就不稳定。

还可在更早的位置检查：完成切割的晶体融合删除、得到保留侧的原始格位后，若该格位的支撑图无环，则第1节保证这份半形经过一次切割重力后全部接地。两边都通过这个检查，拼接结果也全部接地。检查必须针对删除后的实际格位，不能用完整输入的旧组图替代。

<a id="s01-20-h5"></a>

### 5. 下落前有过环，不等于下落后仍有环

第1节的正确逆否命题是：

```text
F(X)不稳定  ⇒  X含支撑环。
```

实际上还能确定：X的某个无针支撑环，已经被新接触完整合并进输出的同一个无支撑组。

**证明。**在 F(X)的当前组图中，取一个不触地又没有组外下挡的组 M。实际结算输出的纯 N块与针都有直接支撑，故 M含 C；这些 C均来自本次未移动的固定组。

任取位于 M内的原固定组。它的最终支撑只能来自地面或另一个固定组。M不触地，且没有组外下挡，所以这条支撑不能到地面，也不能离开 M。M内有限的原固定组子图中，每个节点都有向另一个节点的支撑边，必含有向环。针不会与非针组合并，不可能位于 M内部，故这是无针环。环上全部原组已经同属输出 M；它们原来互相阻挡的格位变成组内关系，恰好不能再提供支撑。证毕。

因此，下面这个改写并不成立：

```text
F(X)不稳定  ⇒  F(X)当前仍有支撑环。
```

一个实际反例是[八象限同列级联](05-cascades.md#s05-04)的 k=2、H=11实例。初始 S中，上级已被接通而不稳定，下级仍有无针环。第一次 F删除上级7颗 C，落下的 q3普通格接通下级最后一个环。F(S)中剩下的6颗 C全部属于同一个悬空组，最低在第2层，第1层仍空，没有组外下挡；其他组只含 N，支撑边严格降层，不能成环。因此 F(S)当前无环，却不稳定。第二次 F才碎掉这6颗 C并稳定。

这与第1节不矛盾：把无环的 F(S)作为新输入，再做一次 F，确实得到稳定态。关键在于把“这次下落前”与“这次下落后”的组图分开。

<a id="s01-20-h6"></a>

### 6. 对重复下落收敛的含义

当一个当前状态的支撑图无环时，反复 F至多还需要一次；无环并不允许直接省掉这最后一次。允许含针环时，可改查第2节的 K支撑证书。

堆叠前下料通过这些条件，则本次 Stack输出稳定，后续 Stack也在 K内保持稳定。交换需要先核对实际半切结果；原完整输入没有环，不能替代这次检查。切割及顶针都会删格、拆组，必须按新格位重新核对，不能因上一阶段曾经接地或无环就自动省略后续结算。
