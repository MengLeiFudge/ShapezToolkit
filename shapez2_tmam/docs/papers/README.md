3. [理论 III：一般偶数象限的列构造与循环支撑](TMAM理论III-一般偶数象限构造.pdf)

5. [理论 IV 附录：交替工序约化](TMAM理论IV附录-交替工序约化.pdf)

论文正文源文件位于 [theory/](../theory/)；使用统一入口或 [build_paper_pdf.py](build_paper_pdf.py) 重新排版：

```bash
# 重新排版单篇
python main.py tmam2 paper --source shapez2_tmam/docs/theory/02-four-quadrants.md --output shapez2_tmam/docs/papers/TMAM理论II-四象限五层合成.pdf

# 重新排版全部四篇正文与附录
python main.py tmam2 paper --all
```

排版后端基于 Python `typst` 库（`uv pip install typst` 或安装项目可选依赖 `.[docs]`）：英文与数学公式采用内置 *New Computer Modern* 衬线及数学字体，中文采用系统宋体（正文）、黑体（标题与强调）和楷体（定理陈述），网格矩阵采用等宽字体 `Consolas`。编译过程中自动启用 `typst.compile_with_warnings` 检查字体与排版警告。

导出含数学记号的正文时，须检查所用字形均有字体覆盖，并检查 PDF 的页尺寸、文字边界和关键公式。文字提取成功不能代替字形覆盖检查。

## 收拢策略

134 篇原专题已合并为 9 卷，Git 历史保留迁移前全文。四篇理论论文从这些证明中按定理依赖拆出。现有 Markdown 链接已经指向新卷及对应章节。蓝图内的旧 `proof` 字符串作为历史来源标识保留，可由 `sources.json` 解析。

后续完整证明直接维护参考卷；论文正文负责连贯论述，`build_paper_pdf.py` 负责从正文重新排版。修改结论时同步正文和对应参考卷，不再恢复零散专题副本。

## 证据边界

本文档和参考卷使用源码静态核对与人工证明。网表数字来自已有静态报告。未运行游戏、Mod、物理模拟、全量状态枚举、浏览器或测试；因此“理论完备”“静态电路规模”和“游戏内验收”保持分开。
