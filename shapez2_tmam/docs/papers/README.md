排版后端基于 Python `typst` 库（`pip install -e ".[docs]"`）：英文与数学公式采用内置 *New Computer Modern* 衬线及数学字体，中文采用系统宋体（正文）、黑体（标题与强调）和楷体（定理陈述），网格矩阵采用等宽字体 `Consolas`。编译过程中自动启用 `typst.compile_with_warnings` 检查字体与排版警告。

导出含数学记号的正文时，须检查所用字形均有字体覆盖，并检查 PDF 的页尺寸、文字边界和关键公式。文字提取成功不能代替字形覆盖与渲染目视检查。

## 收拢策略

134 篇原专题已合并为 9 卷，Git 历史保留迁移前全文。六篇理论论文从这些证明中按定理依赖与研究方法拆出。现有 Markdown 链接已经指向新卷及对应章节。蓝图内的旧 `proof` 字符串作为历史来源标识保留，可由 `sources.json` 解析。

后续完整证明直接维护参考卷；论文正文负责连贯论述，`build_paper_pdf.py` 负责从正文重新编译学术版 PDF（编写规范见 [theory/README.md](../theory/README.md)）。修改结论时同步正文和对应参考卷，不再恢复零散专题副本。

## 证据边界

本文档和参考卷使用源码静态核对与人工证明。网表数字来自已有静态报告。未运行游戏、Mod、物理模拟、全量状态枚举、浏览器或测试；因此“理论完备”“静态电路规模”和“游戏内验收”保持分开。
