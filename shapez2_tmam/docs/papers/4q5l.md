# 4 象限 5 层

理论正文见[理论 II：四象限五层的完整合成](TMAM理论II-四象限五层合成.pdf)。本范围使用相邻两列半切、共同高度上限 5、任意无晶体单层基础料。

## 阅读路径

1. [完整合成与覆盖证明](../proofs/02-four-quadrants.md#s02-01)：终止、可靠性、完备性、制造树及标签恢复。
2. [半形局部判据与构造](../proofs/02-four-quadrants.md#s02-03)：用参数流程取代角模板枚举。
3. [统一完整目标流程](../proofs/03-general-construction.md#s03-08)：双半形起点 → 追加 → 至多三次 Pin/追加；按零尾 Pin 与必须尾 Pin 分两个非空整图集合。
4. [完整尾部逆推](../proofs/02-four-quadrants.md#s02-06)与[四帧电路](../proofs/08-circuits.md#s08-09)：搜索、回退和成功路径回放；实用性能仍未验收。

物理不变量与支撑证明在[卷 01](../proofs/01-foundations.md)，完整合成与来源判定在[卷 02](../proofs/02-four-quadrants.md)，电路各部件在[卷 08](../proofs/08-circuits.md)。九卷均有章节目录，原专题名称可通过[来源映射](../proofs/sources.json)查找。
