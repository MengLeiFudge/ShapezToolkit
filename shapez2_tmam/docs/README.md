# 二代 TMAM 理论与证明文档库

本目录统一收纳二代 TMAM 的范围导览、论文排版产物、理论 Markdown 源文件、九卷完整参考证明及配图资料。

## 目录分工

| 子目录 | 内容 |
|---|---|
| [papers/](papers/README.md) | 研究总入口、范围导览（[4q5l](papers/4q5l.md) / [6q5l](papers/6q5l.md) / [general](papers/general.md)）、A4 排版 PDF 与 [build_paper_pdf.py](papers/build_paper_pdf.py) |

| [proofs/](proofs/README.md) | 按主题收拢的九卷完整参考证明与 134 篇原专题来源映射 `sources.json` |
| `assets/` | 证明与示例引用的示意图（SVG / PNG）及长短代码文本 |

主线阅读建议从 [研究汇编与结论导航](papers/README.md) 开始；工程实现与蓝图资料返回 [二代 TMAM 总目录](../README.md)。
