# Shapez 2 TMAM：从可制作性证明到可复用电路

**研究论文式总览｜版本：当前仓库证明汇总**

> 本文是阅读入口，不替代参考卷中的逐行证明。每个结论都标注了适用范围、证明类型和对应参考卷。没有运行游戏、物理模拟或全量枚举的结论，不写成运行验证结果。

## 摘要

TMAM 的核心不是给每个图形单独做一套配方，而是证明一套有限的结构化制造流程可以覆盖目标集合，并将流程压缩为可循环调用的电路程序。

当前结果分为三层：

1. **四象限五层**：已证明完整可制作性判定与制造树存在性。所有可制作目标统一归入“双半形起点 + 追加 + 有界 Pin/追加循环”，而不是按角、晶体颜色或拓扑细分工厂。
2. **六象限五层**：已证明一个保留真实物理输出的有限闭包算法完备，但最坏结构状态规模为 `4^30−1`，不能直接当作实用电路方案；同时已证明四象限的 K 约化不能外推。
3. **一般偶数象限与任意高度**：列级充要构造、四象限任意高度的 S 列构造、重复下落族和若干全局强制工序已证明；“给定任意正整数交替序列，存在全局不可绕过的目标”仍未解决。

工程上的主结论是：**理论层只保留少数通用机制，Python 层输出制造证书，电路层复用判定、寄存器、时序和回放；不要把每个理论分支直接变成一个电路分支。**

## 1. 问题、模型与量词

### 1.1 目标

给定一个完整图形 `T`，判断它是否能从任意合法无晶体单层基础料开始，通过旋转、Cut、Swap、Stack、Pin、Crystal、染色等游戏操作制造，并在可行时输出一棵真实制造树。

研究中的“强制工序”问题更强：给定 `P^a1 S^b1 P^a2 S^b2 ...`，是否存在目标，使任意合法最后 Swap 起点和上料都只能按该顺序完成？其中 `P` 为 Pin，`S` 为一次单层 Stack。

### 1.2 统一符号

| 符号 | 含义 |
|---|---|
| `n` | 象限数，只研究偶数；环上首尾相邻 |
| `H` | 全过程共同制造高度上限，不等于成品最高层 |
| `N` | 普通格 |
| `P` | 顶针 |
| `C` | 晶体 |
| `F` | 一次重新分组、下落并截高 |
| `K` | 每个最大粘连组可到地面或含针支撑环的结构类 |
| `Q` | 晶体下方顶针必须属于触地针前缀 |
| `J` | 晶体下方有空隙时，最近下方非空格必须是普通格 |

本文统一用**从 0 开始的层号**讲代表图；参考卷中的部分列判据使用从 1 开始，使用时以原文约定为准。

### 1.3 需要严格区分的三件事

- **理论完备性**：任意合法制造历史都能被算法找到。
- **实用性**：状态数量、搜索时间、物品槽和电路规模是否适合游戏。
- **原机覆盖性**：某个存档、Mod 或具体蓝图是否实现了理论流程。

当前四象限和六象限的完备性结论，不等于已经运行了全量求解或在游戏中验证了所有图形。

## 2. 基础不变量：为什么逆向可以收缩

### 定理 2.1：列内次序与晶体来源

旋转只置换整列；Cut 和 Swap 保留整列；重力不允许同列格互相穿过；保留晶体不能下落，只能在 Pin 中整体提高一层；Stack 不能把晶体上料插入保留晶体下方。

因此，在含 `p` 次 Pin、且没有新结晶的尾部中，目标保留晶体来自同列低 `p` 层的位置；晶体下方的目标普通格不能被删除后再从上方补回。一次 Pin 的逆向才对应低一层。

### 定理 2.2：Q 与 J

所有可制作输出满足：

- **Q**：最高晶体以下的顶针只能是从地面连续开始的针前缀。
- **J**：晶体正下方为空时，向下最近非空格必须是普通格；不能是针、晶体或空到底。

这两个条件是必要条件，不是一般偶数象限下的完整充分条件。例：稳定的 `C-P-C` 单列满足支撑直觉，但违反 Q，因而不可制作。

### 定理 2.3：纯材料组的直接支撑

实际可制作输出中，纯 N/P 组或纯晶体组都必须触地或有组外直接下挡；因此一次重新结算若真的改变可制作输出，必然有含晶体的组发生下落并碎晶。

这给出进展量：令 `b` 为普通格与针数量，`c` 为晶体数，`θ=b−c`。改变结果的 Stack 至少使 `θ` 增加 1；对任意可制作输入，普通材料和晶体的来源关系给出线性主干界。该界是证明终止的工具，不是游戏建筑数量的直接估计。

参考：[01-foundations](proofs/01-foundations.md)、[04-stacking](proofs/04-stacking.md)。

## 3. 角与列：从细分类改成充要判据

对一根主列是否能配一根相邻普通/针助手制成角，最有用的不是枚举完整列字符串，而是扫描局部条件 A：

1. 非地面针的正下方非空；
2. 最高晶体以下的针属于连续地面针前缀；
3. 晶体正下方为空时，最近下方格为普通格；
4. 同列晶体之间若有空位，至少有两枚普通格隔断，并满足上下盖条件。

### 定理 3.1：任意偶数 `n≥6` 的列角充要性

对任意高度 `H`，存在相邻 N/P 助手使主列可制作，当且仅当主列满足 A。充分性使用固定四列工作位置：目标列、最终助手列、临时近支撑列、触发列；两次半切先保留临时结构，再去掉助手。`n≥6` 正好提供三列工作空间；更大的象限数不增加核心工作列数。

四象限任意高度不能直接套用这个三列构造，而要使用更强的 S 列判据：共用条件 P，且满足 D 或 E 终点条件。D/E 的递归弱下落、三连晶环下落和一次批量顶破构成完整列构造。

### 循环支撑

两列角中的针环必须是“同一非针组 → 针链 → 同一非针组”。若针链含 `k` 根针，另一列需要连续 `k+2` 颗晶体跨过上下端点。三列以上可以出现无针环，不能强拆成独立两列角。

参考：[03-general-construction](proofs/03-general-construction.md)、[02-four-quadrants](proofs/02-four-quadrants.md)。

## 4. 四象限五层：完整覆盖定理

### 4.1 统一制造语法

令 `B` 表示存在一个合法切向，使目标两侧都是可制造半形，允许一侧为空。则所有四象限五层可制作目标都可写成：

```text
B → S → (Pin → S)^k,    0 ≤ k ≤ 3
```

`S` 表示一段保留旧格、按层追加 N/P 的基础堆叠；空段允许省略。无晶体目标取完整地面层作为 `B`，其余格逐层追加。

这个表达式是**一套主程序、有限循环次数**，不是四个或更多个工厂类别。角类型、颜色、切向、落点和循环次数是参数。

### 4.2 完备性证明骨架

1. 建立两列半形目录，初始包含基础层、紧图形、单半形和双半形。
2. 对冻结快照闭包枚举 `A → S → R → (Pin → S → R)^k`，其中 `k≤4` 用于目录阶段的有界形式；所有物理输出直接计算，不把稳定图形替换成反复结算结果。
3. 以目录首次出现轮数记录制造证书，根配方命中目标后递归展开。
4. 可靠性由目录轮数归纳；完备性从任意合法制造树反向改写：结晶节点替换为紧图形种子，Stack 下料约化为基础块，切割/交换回溯为半形目录，尾部按保留晶体的 Pin 次数合并成有限段。
5. 标签沿保留格来源回填到基础料和紧图形种子，不影响结构证明。

### 4.3 两类完整目标，而不是大量图形类别

设 `Z` 为可由 `B→S` 制造的零尾 Pin 集合，`R` 为全部可制作目标。则：

- `Z`：双半形起点后只需追加；
- `R\Z`：必须进入同一套 Pin/追加尾部搜索。

两者都是完整非空集合。Pin 轮数不是独立工厂类别，只是同一循环的次数。

### 4.4 五层代表与证据

零尾 Pin 与必须尾 Pin 的五层代表见[完整目标例子](../examples/README.md)及[尾部 Pin 必要性证明](proofs/02-four-quadrants.md#s02-08)。高层 T₂、T₃ 和 E 是第 7 节强制工序研究的代表，不属于五层覆盖实例。

## 5. 六象限五层：完备但不实用的基线

四象限证明不能外推，因为六象限存在：

- 可制作但不属于 K 的三列半形；
- 两份稳定半形 Swap 后得到的不稳定输出；
- 新接触后只在下一次加工时重新分组，不能自动追加一次重力。

### 定理 5.1：六象限精确闭包算法完备

令 `U₆` 为六列五层的非空结构编码，规模为：

```text
|U₆| = 4^30 − 1 = 2^60 − 1
```

种子包含所有无晶体单层和紧图形。每轮冻结旧目录，施加真实的 Rotate、Pin、Cut、Stack、Swap 两输入操作，记录第一次出现的输出及父配方。目录单调扩张且有限；任意合法制造树都能按树高被目录重现，因此：

- 可制作目标最终会出现并得到合法制造树；
- 目录闭合后仍未出现的目标不可制作；
- 该结论不要求中间状态稳定，也不允许用 K 过滤状态。

这证明的是理论覆盖，不是电路实现建议。2^60−1 的最坏状态规模说明必须继续寻找结构化约化和时序复用。

### 六象限的当前结构结论

三列释放、递归外侧脚手架和同色层并行制造可复用；但全部六象限可制作半形的紧凑少类分解尚未完成。六象限五层也不能强制三次**深层晶体破坏**：已有低层来源改写定理给出至多两次破坏的替代路线。

## 6. 一般偶数象限与任意高度

### 6.1 支撑与重复下落

- 四象限任意高度的整个 Pin/Stack 尾部保持 K；因此四象限不存在非平凡纯 F 级联。
- 两象限定理与四象限 K 结论共同给出非平凡纯重新结算的最小象限数至少 6。
- 八象限存在同列复用级联：固定 `n=8`、高度 `H=6k−1`，可制作起点恰需 `k` 次 F 才稳定。因此固定八象限但允许高度增长时，稳定轮数没有常数上界；当前只知最小象限数在 6 与 8 之间。

### 6.2 零尾 Pin 来源闭包

对四象限任意高度，固定切向，从含全部目标晶体的最小前缀开始，反复补入：

- 不稳定半边必须拥有的最低目标 N 叶子及其列前缀；
- 不能由追加获得的水平 N 块和单针。

得到唯一最小前缀 `U*`。完整半边判据证明稳定前缀之间制造入口一致；若 `U*` 通过，则 `U*→Stack*→T` 给出真实零尾 Pin 制造证书；若两切向均失败，则不存在零尾 Pin 来源。

该算法上界为 O(H²) 扫描控制；它不提供任意目标的 Pin 次数上界。

### 6.3 可行 Pin 次数的两个参数族

- `L_r`：T₂ 整体抬高 `r≥2` 层并补地面针。可行 Pin 总数恰为 `{2,…,r+2}`。
- `E_r`：PPP 目标 E 整体抬高。可行 Pin 总数恰为 `{3,…,r+2}`。

这两个结果排除了“利用 Pin 次数空档同步多个模块”的简单方案，也说明追加目标材料可能提供新的来源支撑，单个模块的 Pin 下界不能直接拼接成全局下界。

## 7. 已证的强制工序与原命题边界

### 7.1 已证的全局最短词族

| 目标族 | 范围 | 结论 |
|---|---|---|
| `T₂` | 4q、H=12 | 最短词 `PSP` |
| `T₃` | 4q、H=12 | 最短词 `PSPP` |
| `PS^k` | 偶数 n≥4 | 完整最短词 `PS^k` |
| `PS^kP` | 4q、H=k+11 | 完整最短词 `PS^kP` |
| `E` | 4q、H≥11 | 完整最短词 `PPP` |

这些结论都允许更换合法最后 Swap 起点，并允许任意前、中、后单层 Stack；每页证明另有明确范围。

E 的核心机制是跨半形临时支撑交接：右半 N–针–N 环先托住高处临时普通格，第一次 Pin 后由左半晶体塔接手，第三次 Pin 同时清掉塔和临时格。完整格子表、短代码及全来源排除见[卷 06，第 09 章](proofs/06-forced-words.md#s06-09)。

### 7.2 四象限强阶段顺序的否定

四象限任意高度中，若某路线含 `P S^b P S^c P`，`b,c≥1`，三个 Pin 中至少有一次只是无深层破坏的抬升。该 Pin 可移入半形准备；其前方 Stack 可搬到后方，最多增加一次 Stack。因此 `PSPSPS` 不能作为四象限“不可绕过的阶段顺序”。

这不否定它作为某个目标的最短总步数词，因为改写路线可能多一次 Stack；也不否定六象限或可变宽度版本。

### 7.3 仍未解决的最终命题

对每个有限正整数序列 `(a1,b1,a2,b2,...)`，是否存在偶数象限数 `n`、共同高度 `H` 和完整目标 `T`，使任意合法最后 Swap 起点都只能按指定 `P/S` 词制造？

当前没有证明，也没有证伪。特别缺少：

1. 能跨所有合法来源锁定多个支撑交接；
2. 能排除不同窗口合并或替代上料；
3. 能同时证明 Pin 次数和 Stack 窗口的顺序下界；
4. 能把六象限的非 K、不稳定状态纳入统一来源排除。

## 8. 从证明到 Python，再到游戏电路

### 8.1 三层职责

```text
理论不变量/充要条件
        ↓
Python：候选、物理输出、制造证书、短代码
        ↓
电路：寄存器、游标、时钟、回放、循环复用
        ↓
实体：基础料、Stack/Pin/Crystal、Cut/Swap
```

理论层只暴露少量状态摘要：列前缀、晶体段、间隙计数、支撑标志、来源凭据和阶段游标。Python 层保留真实输出，不把“稳定”或“K”当作未经证明的充分条件。电路层用时序循环复用同一比较、搜索和回放通路。

### 8.2 四象限当前电路基线

现有四象限完整控制器已接入：

- 四帧搜索和成功路径回放；
- 六物品槽；
- 249 行 ROM；
- 145 个状态；
- 压缩版 142,255 个非线缆建筑，816 tick 周期；
- 固定模板布局已有静态计数，但未重新生成最终走线蓝图。

历史合并相对 147,216 个非线缆建筑减少 4,961 个，约 3.37%。这不是全局最小电路证明，也不等于总制造时间减少。

### 8.3 六象限电路边界

六象限已有六槽时序回放器和局部操作核心，但完整 `4^30−1` 闭包不能直接硬编码成游戏电路。下一步应优先把递归脚手架、列判据和制造证书做成可复用模块，再决定搜索状态如何分段、缓存和回放。
