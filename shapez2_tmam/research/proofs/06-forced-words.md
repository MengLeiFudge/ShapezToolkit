## 06-01 交换后的强制顶针与堆叠顺序：全局交替实例与任意序列问题

原文标识：`general/forced-tail-order.md`。

本页研究用户截图`106106a7c58f57adf7254a393c7d7ba7.png`的四象限、十二层例子。P表示一次Pin，S表示一次Stack；具体材料另用N/C/针表示。只计最后一次主干Swap之后的Pin/Stack，旋转吸收到起点和上料朝向。上料具有合法制造凭据；讨论逐层堆叠时，每份上料限定一层。

**已证明：T₂从任意合法最后交换起点出发，必须恰好执行2次Pin，而且两次Pin之间必须有有效Stack。** [一次Pin排除](#s06-02)与[连续两次Pin排除](#s06-03)共同完成必要性；指定D的P→S→P路线达到下界。[T₃的次数下界](#s06-04)与[顺序下界](#s06-05)进一步证明：它最少需要四步，最短操作词恰为P→S→P→P。

全局命题的状态：

1. **已证明**：T₂强制全局最短词P→S→P；[参数族Wₖ](#s06-08)进一步对每个k≥1强制P S^k P，所有k次Stack都必须位于两次Pin之间。另有[单段明确参数族](#s06-07)，对每个偶数n≥4和k≥1强制完整最短词P S^k；四象限十一层目标E的[最短词PPP](#s06-09)则证明初始Pin段不能统一压成至多两次。
2. **四象限的强顺序版本已证伪**：不存在必须保留`P S P S P S`阶段顺序的四象限目标；任意高度都能改写掉一个交替间隔，单层Stack至多增加1次。见[序列重排证明](#s06-11)。
3. **原来的可变偶数象限命题仍未解决**：对每个有限正整数序列(a₁,b₁,a₂,b₂,…)分别选择偶数象限数n、共同制造上限H和完整目标T，是否都能强制该序列。四象限的否定不能排除在六象限或更宽范围实现。

“强制阶段顺序”要求更换起点、上料后也不能绕过指定阶段；“这个词是一条最短总步数配方”则是另一命题。前者允许用多一次Stack的重排作反例，后者不允许。本页讨论的原序列目标仍保留这一区分，不用四象限的局部否定冒充可变宽度命题的结论。插入恒等加工或先添加随后丢弃的无用材料，不构成有意义的反例；展示一个给定词的加工结果也只证明可行性。

新一轮来源排除见[加宽Wₖ的两种一次Pin替代](07-reductions.md#s07-10)：新增普通连接列能提供临时顶桥，复制保留C与针链又会增加屋顶落点，两者都允许多用三次总步骤、绕过原两次Pin阶段。另有[晶体封顶目标的条件改写](07-reductions.md#s07-09)：在明确的半形制造证书前提下，可把尾部Pin全部移入新来源的底针准备。[整体抬升族的完整次数](#s06-10-h10)进一步证明r≥2时可行Pin总数恰为2至r+2。这些都是已解决的构造方向或子族，不是原任意序列命题的最终结论。


<a id="s06-01-h2"></a>

### 2. 起点D有基础料制造证书

标准两半q0/q1、q2/q3各自静止：

- 左半的q1第1至4层C由地面N支撑；q0第5层C及上方第7至11层C分别受第4、6层N支撑。q1第7层N接在q0高C柱旁，针有直接下方支撑。
- 右半的q3第2、3层C通过q2第2层N支撑到地面；q3第4至7层针和第8层N由此托住q2第4至10层C柱。不能删掉q3第8层N后仍称这个半形静止。

各列满足A。[四象限任意层直接释放](02-four-quadrants.md#s02-15)所需的额外落点条件也成立：q2第4层C下的最近N在第2层，正下第1层为N；q3第2层C下最近N在地面；q0/q1没有C正下空隙的其他活动落点。因此两份稳定半形可以分别制造，再Swap得到D，准备过程不超过12层。

<a id="s06-01-h3"></a>

### 3. 指定路线的两次删除与上料落点

D中有四个相关晶体融合分量：

- q0第7至11层的上塔，首次Pin触顶删除。
- q1第1至4层C与q2第4至10层C，在第4层连成辅助分量。首次Pin后最高到第11层，第二次Pin才删除。
- q0第5层的保留C。
- q3第2、3层的保留C。

第一次Pin后，q0最高格为第7层N；q1最高格为第8层N，它通过q2仍保留的辅助C柱保持悬空。q0/q1双N上料恰落在第9层。此层原本还有q2的C和q3的N。

第二次Pin删除第二个辅助分量后：

- 新加q0/q1双N与原q3第8层N一起处于第10层，通过q3第9层针受支撑，形成目标顶条。
- 原q1第5层针落到第3层，原q1第7层N落到第4层。
- 原q0第1层N失去q1辅助C的横向支撑，落到地面。
- 两组保留C分别到q0第7层、q3第4/5层；其余直接支撑格保持相应层位。

这得到逐格等于T₂的结果。T₂各组有到地面的支撑路径，故下一次Pin只作第1节的抬升。

<a id="s06-01-h4"></a>

### 4. 从同一个D出发，中间Stack不可省

允许改变上料、增加其他Pin/Stack，但起点固定为D，终点固定为T₂。

<a id="s06-01-h5"></a>

#### Pin数被保留晶体锁定为2

Stack不带入新C，保留C不能下落。把全部主干旋转合到末尾，记初始列到最终列的净旋转为t：

- t=0：q3的两颗C只能来自D的第2、3层，因此p=2。
- t=1：最终q3来自初始q2；要在第4、5层保留两C，只能p=0。但最终q0第7层C将来自初始q3第7层，那里没有C。
- t=2：最终q3来自初始q1，要求p为1、2或3。最终q0却来自初始q2；该列地面有N，经历任一次Pin都会留下地面针，而且位于保留C以下不能被删除，与目标q0地面N矛盾。
- t=3：最终q3来自初始q0；该列第5层以下没有连续两C，更高的连续C不能在非负次Pin后到第4、5层。

所以净旋转只能为0，主干Pin数只能为2。中间旋转仍可通过调整各次上料朝向吸收，不改变下面的排除。

<a id="s06-01-h6"></a>

#### 第一轮Pin以前不能加入目标顶条的q0格

D的q0最高层第11层有C。D属于K，任意前置Stack保持旧下料及其C；新上料不能穿过这颗C落入12层以内。因此目标q0第10层N不能来自第一次Pin之前的Stack。

D原有q0普通格最高仅在第6层，即使经历两次Pin也最多到第8层。故目标q0第10层N必来自某次Stack，而非D中已有格。

<a id="s06-01-h7"></a>

#### 两次Pin都完成以后也不能补入这个格

反设两次Pin之间没有Stack。原q3第8层N始终受原针链和保留C支撑，两次Pin后固定在第10层。

D的晶体融合删除不受普通上料颜色或标签影响：第一轮删q0上塔，第二轮删q1/q2辅助分量，此后只剩目标三颗C。后续Stack不能再损失C，否则无法补回目标；由[晶体数进展量](01-foundations.md#s01-07)，其下料每次F均为恒等。已有N/P也不会再移动或消失。

因此，后续阶段中任何落入高度上限内的新增N/P都必须属于目标尚缺的格。未补顶条q0格时，该列最高只能是目标第8层N；q1若没有第10层顶条格，最高只能是第4层N。q1第10层N也不能独自静止：其下方为空，同层没有q0，也不能借q2或针连接到q3。

考虑包含目标q0新格的上料水平N块：

- 只含q0，或含q0/q1，都会落到第9层，而非第10层。
- 含q3，则被已有q3第10层N挡在至少第11层。
- 含q2，则同时添加一个目标第10层不存在的q2普通格，不能在没有后续Pin的情况下删除。

提前加一个普通支撑格把它垫高也不行：那个支撑格会永久留下，目标在相应位置没有它。上料中的晶体不进入结果，不能借它保留一个悬空水平N块。

两端都排除，所以至少一次Stack必须发生在两次Pin之间。第3节给出恰好一次的制造路线，故**指定D到T₂的最简Pin/Stack词为P S P**。

这项证明的关键是D的顶部阻挡和原q3顶条的来源，不能把D换成任意B后继续沿用。

<a id="s06-01-h8"></a>

### 5. 任意起点下的Pin计数上界

设某条尾部从任意合法起点出发，仅含Pin、Stack及旋转，终点仍保留晶体。选目标某列最低C，其零基层号为c；该列触地连续针前缀长度为r。尾部Pin数为p，则

`p ≤ max(r,c−2)`。

证明：若起点该列地面非空，每次Pin都会生成一根新地面针。它们位于保留C以下，不能被Stack插入、下落穿过或截高删除，因此r≥p。若p>r，则起点该列地面必为空；其保留C来源高度为c−p。由J，该高度既不能为0，也不能为1：地面空时，第1层C下不可能找到更低的N。因此c−p≥2，得到p≤c−2。两种情况合并即得结论。

这不依赖K或起点是否固定。对本图：

- T₂的q3有r=2、c=4，所以任意这种尾部至多2次Pin。
- T₃的q3有r=3、c=5，所以任意这种尾部至多3次Pin。

这个界限制实际可用的Pin数，不是最少Pin数的证明。

<a id="s06-01-h9"></a>

### 6. 任意交换起点都不能零Pin得到T₂/T₃

四象限任意高度下，两列切割输出属于K；交换拼接保持K；K下料的Stack保持旧格和全部C，并可约化为无C追加。这些局部结论不需要假设全部四象限高层图形属于K。

假设某交换起点B不经Pin，仅用Stack得到T₂。于是B逐格包含于T₂，且包含全部目标C。

q0第5层N正下为空，同层唯一相邻目标非针格是q3的旧C。它不能作为新上料单N落在第5层，因此也必须已经在B。

考察B的两个可能半切方向：

- q0/q1与q2/q3：左半的q0第5层N没有同层邻居，也没有正下方支撑，不能是合法切后半形。
- q3/q0与q1/q2：q3第4、5层C及q0第5层N形成的组，底部q3第3层和q0第4层均为空。更高普通格与针不把它连接成一个更高的晶体组，因此该半形不静止，也不可能是切后输出。

两个切向都不成立，故零尾Pin不可能。T₃仅把这个支撑障碍提高一层，新增底部针没有填上障碍正下方的空格，同一排除适用。

本节与第5节先得到T₂含1至2次Pin、T₃含1至3次Pin。[一次Pin完整排除](#s06-02)把T₂收紧为恰好2次；[连续两次Pin排除](#s06-03)进一步证明必须在中间Stack。[T₃的一两次Pin排除](#s06-04)则把它的最少Pin数收紧为3。

<a id="s06-01-h10"></a>

### 7. 全局交替实例与可变宽度的任意序列命题

[四象限任意H的尾部支撑定理](01-foundations.md#s01-06)证明：从合法交换起点出发，整个Pin/Stack尾部都保持K。它通过追溯同层双C屏障和普通横条形成时的支撑证书完成归纳，不是直接重复套用第一次Pin定理。因此第二次Pin输出不能额外留C再靠Stack清理。

[连续两次Pin排除](#s06-03)在这个范围内反推全部起点。目标地面N迫使一份辅助分量撑过首Pin、第二Pin才删除；原右半形又迫使旧顶条已经存在。两轮之间的局部形态被锁定后，悬空普通格必须来自原半形，却需要一根首轮触顶删除的C塔；该塔占满q0第7至11层，使必要屋顶N无处准备。前置和后置Stack也不能绕开这个矛盾。

所以第一个全局存在命题由T₂成立。这里证明最短尾部及中间Stack的必要性，不声称所有合法较长配方逐步完全相同。

[T₃的顺序证明](#s06-05)补充了连续两次Pin的必要实例。它的任意合法尾部都必须在前两次Pin之间Stack；第二次Pin后已经是T₂加可选顶盖，最后一次Pin截盖并抬升，后段Stack可以省去。因此最短词为P→S→P→P。这不表示较长配方不能插入其他Stack，也不要求起点和上料唯一。

[一次Pin后的必要Stack长度](#s06-06)先给出四象限旧族的无界后段下界及每个整数的精确最少后段次数存在性，但没有排除该旧族最优路线中的前置Stack。新的[保留晶体限制辅助路径构造](#s06-07)独立补齐这一缺口：对每个偶数n≥4、k≥1，取H=k+3，给出明确目标及P S^k配方；任意合法起点都恰需一次Pin，且目标某列的k枚N只能在Pin之后逐层加入。完整最短词因此恰为P S^k，前置Stack不能抵消任何必要后段次数。

[两次Pin之间的任意长Stack段](#s06-08)再给出四象限H=k+11的明确族Wₖ。其最短词恰为P S^k P：旧屋顶迫使最终顶盖在第二次Pin前存在，挡住事后向下补料；低处支撑与格数又迫使k枚普通格全部在第一次Pin之后加入。这完成一个指定长度的中间窗口，尚未完成任意多个窗口的串接。

可变宽度的任意序列命题还需可重复的工序约束，并证明多个约束拼合后不会互相提供额外支撑或产生替代起点。T₃最后一次Pin不产生新的支撑交接；当前固定八象限下落级联也没有提供全局指定词的必要性。

有一个可以直接排除的推广方向：[相邻象限等宽复制](03-general-construction.md#s03-07)不会增加必要阶段数。令Eₘ把每列扩成m列，则已有路线直接提升为 `Eₘ(D) → P → S(Eₘ(U)) → P → Eₘ(T₂)`，其中U仍是单层上料。因此无论扩成多少象限，这个复制族都至多用2次Pin、1次Stack；不能用复制规模声称强制更长序列。大图的更强下界也不能从四象限自动继承。

[开头抬升与末尾补针的推广分析](#s06-10)又排除了两种做法。第一次Pin若不顶破C，可以把它移进两半的准备过程，并保持后续单层Stack次数不增加。对T₂整体抬高r≥2层的族Lᵣ，在同一最小容纳高度H=r+11下，另一个合法起点仍只需P→S→P；原先追加r次Pin的路线因此不构成次数下界。r≥2的族已有零次、一次排除，最少Pin数恰为2。r=1的T₃不在这个替代构造内，另证最少Pin数为3：若只做两次，低N必须首次落地，但这又会过早删除屋顶所需的辅助塔。

[序列重排证明](#s06-11)进一步直接研究原序列目标：四象限任何`P S^b P S^c P`路线（b,c≥1）都可以少一次Pin，或消除一个Stack间隔，至多多一次单层Stack。因而四象限强顺序版本已否定；最短总步数版本尚不能据此否定。同页还给出六象限任意有限D/L时钟的显式紧列构造，但它们的最终目标都有零尾Pin来源，说明增加独立塔数量本身不能证明任意阶段必要。

证据为截图逐格转写、支撑定理、材料来源、人工Pin/Stack逆推、半形制造凭据及操作复制对应。没有运行目标搜索、枚举、测试、物理模型或游戏。允许象限数及高度随序列增加的原猜想尚未证明或证伪。

## 06-02 T₂ 不能由任意交换起点只经一次顶针得到

原文标识：`general/t2-one-pin-exclusion.md`。

本页补充[强制尾部顺序](#s06-01)，证明其中四象限十二层目标 T₂ 的最少尾部 Pin 数是 **2**。起点可以是任意两个合法切后半形的交换结果，Pin 前后都允许任意 Stack，上料不固定。已有 `D → P → S → P → T₂` 给出两次的上界；零次已在原文排除。这里排除一次。

本页只证明次数下界；两次 Pin 之间必须有 Stack 的必要性见[全局交替证明](#s06-03)。任意指定交替序列的全局必要性仍未证明。证据是以下人工逆推，未运行搜索或物理模拟。

<a id="s06-02-h1"></a>

### 1. 反设与记号

反设存在路线 `B → Stack* → X → Pin → E → Stack* → T₂`。层号从0开始，H=12，N/C/针表示材料。允许旋转；将朝向吸收到 B 和上料，按 T₂ 的列编号讨论。

[第一次顶针保持 K](01-foundations.md#s01-05)保证 E∈K。后续 Stack 保留 E 的每一格与全部 C，只能从上方追加 N/针。因此 E 是 T₂ 的逐列下方前缀，包含全部目标 C；不能留下额外 C 再靠 Stack 碎掉。

X 中三颗必须保留的 C 为 `(q0,6)`、`(q3,3)`、`(q3,4)`。它们只提高一层，不下落。额外 C 必须在这次 Pin 内消失。低于这些保留 C 的 N/针不能截去或被后续 Stack 插入，其列内次序保持。

下文说某格“固定”，指它在 Pin 中只抬升一层、没有下落。移动过的格不能成为固定组的最终支撑，使用[结算引理](01-foundations.md#s01-12-h2)。

<a id="s06-02-h2"></a>

### 2. 保留晶体以下的位置约束

q0 在目标 C 以下恰有三个 N，位于0、5、6层，无针。因此 X 中：

- 地面为空，否则 Pin 会留下目标没有的地面针；
- 通向目标第5、6层的 N 必分别在原第4、5层。它们不能穿过原第6层 C，且提高一层不足以从更低处到达目标；
- 最低的 N 在原第1或2层。它不能在第0层；也不能在第3层，否则会与保留的 q3 第3层 C 横向粘连，固定到第4层，不能落地；
- 原第3层为空。N 会产生上述矛盾；C 会与保留 C 融合、不能作为额外 C 删除；针又不能消失成目标的 N。

q3 在最低目标 C 以下恰有两根触地针及一个 N。由[Q 与地面针来源](01-foundations.md#s01-01)，X 的 q3 第0层必为针，那个 N 在第1或2层。不存在其他较低 N/针。

保留的 q3 双 C 在 Pin 删除后的固定组，至少含 q0 第4层 N。除可能附着的 q2 第3层 N、q1 第3层 N 外，它不能延伸出其他目标允许的固定格。该组可能的下方支撑位置只有：

- q3 第2层；
- q2 第2层，前提是组含 q2 第3层 N；
- q1 第2层，前提是组还含 q1 第3层 N。

q0 第3层为空。q2/q1 第4层的 N 会固定到目标不存在的位置，不能用来另造支撑分支。

<a id="s06-02-h3"></a>

### 3. 排除 q3/q0 与 q1/q2 切向

最低的 q0 N 在保留 C 下方，不能来自前置 Stack，必须已经在 B 的 q3/q0 半形。

若它在第2层，正下第1层不能另有 N/针；也不能是 C，因为 q0 地面空、该 C 违反 J。同层 q3 第2层若为 N，两 N 会一直粘连，不可能分别到目标 q0 第0层与 q3 第2层；若为 C，则与保留的 q3 第3层 C 融合，不能删除。这个 N 无法在原半形中静止。

所以最低 q0 N 在第1层。它正下为空，同层 q3 只能放辅助 C 托住它；同层 N 又会造成两个 N 不能分离。因此 X 必有 q3 第1层辅助 C，q3 待保留的低 N 则在第2层。

该辅助 C 正下是地面针。如果没有融合删除，它仍会固定，不能自行跌碎。因此它必须通过晶体融合路径连到原第11层。路径跨过第3层时，q0/q2 的 C 都会与保留的 q3 第3层 C 融合，q3 自身也是保留 C；唯一能经过的是 q1 第3层辅助 C。

这禁止 q1 第2层放针：若该针属于触地前缀，Pin 后会留下至少四根连续针，与目标 q1 第2层 N 矛盾；若不是触地前缀，则违反 Q。

再看第2节的固定双 C 组。q3 第2层 N 要下降一层，不能成为它的最终支撑。q1 第2层针已排除。于是只能依靠 q2 第2层的固定 N；但这个 N 与 q3 第2层 N 水平粘连，后者也会固定到第3层，仍与目标矛盾。

所以这个切向不成立。

<a id="s06-02-h4"></a>

### 4. 标准切向强制出低层骨架

只剩 q0/q1 与 q2/q3。q0 第4层 N 位于保留 C 以下，必须已经在 B；它正下第3层为空。在 q0/q1 半形中，它必须靠同层 q1 的非针格支撑。

这个邻格不能是 N，否则在 Pin 中仍与 q0 第4层 N、保留的 q3 第4层 C 连在一起，固定到目标不存在的 q1 第5层。故它只能是辅助 C。

q1 第4层辅助 C 也必须融合删除：若仍在，它通过 q0 第4层 N 与保留 C 连在同一组，不能单独下落碎掉。

Q 随即排除 q1 第2层针，理由与第3节相同。第2节的固定双 C 组必须含 q2 第3层 N，并通过 q2 第2层固定 N 获得支撑。如果 q3 的低 N 在第2层，它会与这个固定 N 粘连、不能下降，因此 q3 的低 N 只能在第1层。

q2 第2层 N 的同层左右邻格不能提供别的固定连接：q1 第2层 N 会留下目标没有的 q1 第3层 N，q3 第2层为空。因此它正下第1层必须是固定 N。目标 q2 第0、1层针也不能事后插到这个 N 下方，故源 q2 第0层为针。

由此锁定 X 的局部骨架：

```text
 z   q0 q1 q2 q3
 6    C  ?  ?  ?
 5    N  ?  ?  ?
 4    N  C  .  C
 3    .  ?  N  C
 2    ?  ?  N  .
 1    ?  ?  N  N
 0    .  ?  针 针
```

这里的点是已排除的格，问号未定；表只表示本节已锁定的信息。q0 最低 N 不能在第1层，因为会粘住 q3 第1层固定 N，故在第2层。

<a id="s06-02-h5"></a>

### 5. 辅助路径必须经过 q2 高塔

先排除 q3 第4层以上的所有辅助 C。

第5层 C 会与保留 C 融合，不能删除。若更高处存在辅助 C，取其中最低的一颗。Q/J 要求它与下面的保留 C 之间至少有一个 N：不能只隔空隙或夹非触地针。这个 N 低于辅助 C，不能在 Pin 中截去；目标 q3 在双 C 以上唯一的 N 是第10层顶条。因此它将成为 E 的旧顶条 N。

既然 E 已含 q3 第10层 N，目标第6至9层的四根针不能事后插入其下，必须也在 E。这些针在 X 中必须连续立在保留 C 上方：针不能悬空，而 C 与针链之间若另有 N，该 N 低于屋顶，也无法消失。故四针固定地来自 X 的第5至8层。这时辅助 C 位于非触地针之上，违反 Q。矛盾。所以 q3 第4层以上没有辅助 C。

q1 第4层的融合删除路径必须通向第11层。在原第4层，只有 q1 能放待删除 C；在第5层，q0 是 N、q3 不允许辅助 C，因此路径必经过 q1 第5层 C。在第6层，q0 是保留 C，q1 的 C 会与它融合，q3 又没有辅助 C。因此路径必经过 q2 第6层 C。

这些 C 全部来自 B，前置 Stack 不能添加它们。

<a id="s06-02-h6"></a>

### 6. 原右半形迫使 q3 顶条已经存在

B 的 q2/q3 半形含 q2 第6层辅助 C。其晶体分量不能延伸到 q2 第4层，否则与 q3 保留 C 融合；原第4层也不能放 N，它会固定到目标没有的 q2 第5层。该层不能放针，因为其上有 C，而它不可能属于触地针前缀。因此 q2 第4层为空。

这个半形中，第4层以上没有 q3 的 C。q2 高塔及附着普通格若不借 q3 的支撑，向下只能遇到 q2 第4层空隙，不能获得地面路径或含针环。相邻两列的支撑区间性质因此要求：高塔在某层 t 接上 q3 的 N，该 N 的正下方由 q3 的针链托住；针链从保留的 q3 第4层 C 上方连续起立。

若 t≤10，这个 N 不会截去，只能成为目标第10层顶条，因此 t≥9。下面 t−5 根针全部固定保留，而目标对应位置只有四根针，所以 t≤9。若 t=11，虽然 N 会截去，下面六根针仍会留下，也不符合目标。因此只能：

- q3 第5至8层为针；
- q3 第9层为 N；
- q2 辅助 C 连续经过第6至9层，连到这个 N。

最后一项来自两列组的连接规则：q3 没有 C，跨层只能沿 q2 连续 C/C。这个第9层 N 是原半形的支撑，不能等到交换后再补入。

<a id="s06-02-h7"></a>

### 7. 整条屋顶必须在 Pin 前就位

q3 第9层 N 由固定针链托住，Pin 后成为 E 的第10层 N。若目标 q0 第10层 N 还没有进入 E，后续 Stack 无法补它：

- 只用 q0 或 q0/q1，目标允许的下方列顶最高为 q0 第8层，只能落在第9层；
- 带上 q3，会被已有第10层 N 挡到至少第11层；
- 带上 q2，会留下目标没有的第10层 N。

后续不能加垫块再删除。因此 q0 屋顶也必须在 E。q1 屋顶同理：单独落不到第10层，带 q0 会被旧屋顶挡住，带 q2 则增加目标外格。

这又迫使 q0/q1 的全部较低目标格都在 E，不能再往旧屋顶下面插入。

X 的 q0 屋顶 N 只能来自第9或10层。若来自第10层，它必须下落一层；移动后的水平 N 块在目标第10层需要第9层的直接支撑。那里只有 q3 的针，但该移动块不能包含 q3：q3 已有一个旧屋顶 N，再来一个 N 就会留下额外格。q0/q1 下方则为空，q2 不允许屋顶格。因此这个 N 不能从第10层落来，只能来自第9层，与旧 q3 屋顶横向相连。

q1 屋顶同理来自第9层；若从第10层落来，既不能再带一份 q0/q3 的 N，也没有自身正下支撑。

故 X 第9层的 q0/q1/q3 已是三个 N。

<a id="s06-02-h8"></a>

### 8. 屋顶下的两个 N 无法同时准备

考虑 X 中两个待保留 N：q0 将成为目标第8层的 N，记为 U；q1 将落到目标第4层的 N，记为 V。

U 位于 q0 保留 C 的第6层之上、屋顶第9层之下，故只能在第7或8层。

q1 有第4、5层辅助 C。先确定其目标第1层旧针的来源。若 X 的 q1 地面不是针，这根旧针就只能位于第5层辅助 C 以上，否则违反 Q。它上面还依次有通向目标第2、3、4层的 N、针、N，四格都须位于第5层以上、第9层屋顶以下，只有三层可放，矛盾。因此旧地面针确实来自 X 的第0层。

目标 q1 第3层的非触地针在 X 中必须高于第4、5层辅助 C，否则违反 Q。它还必须低于 V，而 V 低于第9层屋顶。所以这根针只能在第6或7层。

若针在第7层，它正下第6层必须非空。但该处不能放 C，会与保留的 q0 第6层 C 融合；不能放 N，会粘住该保留 C、固定到目标没有的 q1 第7层；不能再放针，目标只允许这一根非触地针。故针只能在第6层，V 只能在第7或8层。

U、V 不能同层：两个普通格一旦水平粘连，Pin 不会拆开它们，不能分别落到第8层与第4层。只剩两个情况。

<a id="s06-02-h9"></a>

#### U 在第7层，V 在第8层

U 受保留 C 支撑而固定。若 V 已在 B，原 q0/q1 半形中它正下第7层为空，只能由同层 q0 辅助 C 支撑。这个 q0 第8层 C 却无法删除：上方是第9层屋顶 N，下方是 U，左右是 V 与 q3 第8层针，融合分量不接触顶层；U 又使它不会下落。它会作为额外 C 留在 E，矛盾。

若 V 来自前置 Stack，单独加入时，旧屋顶尚未进入该列的落点至多为第6层针上方的第7层；若旧屋顶已在，则被挡得更高。带上 q0 会增加目标不允许的另一格 N；带上 q2 会被原第6至9层 C 塔挡在至少第10层。也无法把 V 放到第8层。

<a id="s06-02-h10"></a>

#### U 在第8层，V 在第7层

若 U 已在 B，原 q0/q1 半形中它正下第7层为空，同层 q1 也没有允许的 N。那里不能用辅助 C，因为 q1 第6层已经是非触地针，Q 禁止更高 C。原半形不静止。

若 U 来自前置 Stack，单独加入只会落到 q0 第6层 C 上方的第7层，或被已经加入的屋顶挡到更高处。带 q1 会增加目标不允许的第8层 N，带 q3 则与必须保留的针链/屋顶冲突。仍不能落在第8层。

两个情况都不成立。

<a id="s06-02-h11"></a>

### 9. 结论

两个半切方向均已排除，因此不存在任意合法交换起点的单次 Pin 路线。结合零次不可能及已给出的两次制造路线：

`min Pin(T₂，任意最后交换起点，任意前后 Stack) = 2`。

这个结论允许改变起点与上料，已经超出固定 D 的证明。[整个尾部的支撑闭包](01-foundations.md#s01-06)排除了第二次 Pin 留下额外 C 再由 Stack 碎掉的支路；[连续两次 Pin 排除](#s06-03)进一步证明换起点也必须保留中间 Stack，从而得到全局最短尾部 P→S→P。

## 06-03 T₂ 强制两次顶针之间堆叠：任意交换起点的排除证明

原文标识：`general/t2-forced-interleaving.md`。

本页证明[四象限十二层目标 T₂](#s06-01-h1)的全局尾部顺序下界：

> 从任意合法最后 Swap 起点出发，只用 Pin、Stack 和旋转得到 T₂，必须恰好执行两次 Pin，而且两次 Pin 之间必须有有效 Stack。

已有指定起点 D 的 `P → S → P` 制造路线，所以这个下界可以达到。[一次 Pin 排除](#s06-02)已证明至少两次，[保留晶体与触地针计数](#s06-01-h8)已证明至多两次。本页排除剩下的“换起点后连续执行两次 Pin”路线。

“全局”限定在上述最后 Swap 后的尾部模型，起点两半与 Stack 上料可任意合法制造。它不把最后一次结晶等其他根操作强行计为 Swap。本文只作人工证明，未运行搜索、枚举或物理模拟。

<a id="s06-03-h1"></a>

### 1. 反设与支撑范围

反设存在：

`B → Stack* → X → P → Y → P → E → Stack* → T₂`。

B 是两个合法切后半形的交换结果。旋转吸收到起点和各份上料，按目标列编号。层号从0开始，高度上限12。

[整个尾部保持 K](01-foundations.md#s01-06)保证 X、Y、E 都属于 K。E 是 T₂ 的逐列下方前缀，包含全部目标 C，不能含额外 C；最后一段 Stack 只追加普通格或针。

目标三颗 C 的来源固定为 X 的 q0 第5层、q3 第2、3层。它们经历两次统一抬升，不下落。其他 C 必须在这两次 Pin 内消失。

一个在某次 Pin 中移动过的格，不能成为该次未移动组的最终支撑。以下反推保留 C 时始终使用这个[结算边界](01-foundations.md#s01-12-h2)，不把本轮新接触当成提前合并。

<a id="s06-03-h2"></a>

### 2. 低处 q0 普通格锁定切向与删除时刻

q0 在目标 C 以下的三个 N 位于0、5、6层。因此 X 的第3、4层必须是 N；最低 N 只能在第1层。它不能在地面，否则第一轮就生成目标没有的地面针；也不能在第2层，否则会与保留的 q3 第2层 C 粘连，最终停在第4层而非地面。

X 的 q0 第2层为空：N 会产生上述矛盾，C 会与保留 C 融合，针也无法消失成目标 N。

q3 最低目标 C 下只有两根触地针及一个 N。X 的低 N 只能在第0或1层。若在第1层，它会与 q0 第1层 N 水平粘连，不能最终分别到第2层与地面。因此 q3 第0层为 N，第1层为空；原有地面针会使两次 Pin 后的针前缀过长，也不允许。

q0 第1层 N 不能来自前置 Stack，因为同列更高的保留 C 已在 B。在 q3/q0 半形中，它正下与同层邻格均为空，无法静止。所以 B 只能按 q0/q1、q2/q3 分半。

在 q0/q1 半形中，这个 N 必由 q1 第1层辅助 C 托住。同层 N 会与它始终粘连，不能成为目标 q1 的较高普通格。

这颗辅助 C 必须撑过第一轮 Pin。若第一轮就失去它，q0 的低 N 会成为单格，直接落地；第二轮随即在 q0 生成地面针，违背目标。它不能只落一层悬停，q0 下方没有其他格，同层也没有能与它一起保留的普通块。

q1 第1层辅助 C 又不能在第二轮自行跌碎：原 q1 第0层不能为空，否则违反 J；不能为针，否则最后触地针过多；若为 N，它一直由新增地面针托住，若为 C，则与第1层辅助 C 属于同一融合分量。只要该分量未融合删除，就仍有固定底部支撑。

因此，这个分量**第一轮保留，第二轮顶破删除**，其在 X 中的最高 C 恰为第10层。记为 R。

<a id="s06-03-h3"></a>

### 3. R 必须穿过 q1 低塔及 q2 高塔

先排除 X 中 q3 第4至10层的辅助 C。若有，取其中最低者。第4层会与保留 C 融合，不允许；更高处的最低 C，由 Q/J 必须与下面的保留 C 之间隔着 N。这个 N 至多在第9层，经历两次 Pin 也不会截去，只能成为目标第10层的唯一上部 N。

于是 E 已含 q3 顶条 N，下面四根针也必须在 E，不能事后插入。原针链必须从保留的 q3 第3层 C 上方连续立起，位于第4至7层：若另有 N 夹在 C 与针链之间，它也不会消失，目标却没有对应材料。这与更高辅助 C 下方不得有非触地针的 Q 矛盾。

因此 q3 第4至10层没有辅助 C。原第11层仍可能有首轮就删除的 C，但它不能属于 R。

R 从 q1 第1层通向第10层，必须跨过第2、3层。那里 q0/q2 的 C 都会与保留的 q3 C 融合，只有 q1 可以通过。所以 q1 第1至3层连续为 R 的 C。继续向上，第4层须经过 q1；第5层的 q0 是保留 C，q1 的 C 会与它融合，q3 又没有可用 C，只能经过 q2。

因此 R 至少含：

- q1 第1至4层 C；
- q2 第4、5层 C。

这些格在第一轮后仍在，Y 相应含 q1 第2至5层 C、q2 第5、6层 C。

<a id="s06-03-h4"></a>

### 4. 第二轮不能临时补出保留 C 的低处支撑

第二轮删除 R 后，保留的 q3 双 C 与 q0 第5层目标 N 构成固定组。它不能依赖最终才下落到位的普通格。

它正下的 q3 第3层、q0 第4层在目标中为空。q1 的目标第4层 N 也不能预先属于这个固定组：在 Y 的对应第3层原本是 R 的 C，第二轮才被删掉。

所以该固定组必须预先包含 Y 的 q2 第3层 N，并依靠 q2 第2层 N。q2 第2层 N 在删除 R 后没有可保留的水平连接：q1 同层为待删 C，q3 同层为空。它还必须依靠 q2 第1层 N。

反推第一轮：q2 原第4层 R 的 C 一直保留，阻止更高普通格下穿。Y 第3层 N 只能来自 X 第2层；X 第3层若为 N，会粘住保留的 q3 第3层 C，一直固定到最终第5层，目标没有它。再按列内顺序反推，Y 第2、1层 N 分别来自 X 第1、0层。

故 X 的 q2 第0、1、2层都是 N，第3层为空。第3层不能放 C，与保留 C 融合；不能放 N，落点错误；不能放针，因为它位于 R 的 C 下方，却不是触地针前缀。

<a id="s06-03-h5"></a>

### 5. 原右半形锁定旧顶条

B 的 q2/q3 半形含 R 在 q2 第4、5层的 C。q2 第3层为空，q3 第4至10层没有 C，R 又不能含第11层 C。因此这个半形必须通过 q3 的普通格和针取得支撑。

先排除 R 自己带一个悬空针环。这样的环在 q3 必有上下两个附着于 R 的 N，中间至少一根针；上 N 不高于 R 的最高层10，故下 N 至多在第8层，中间至少有一根不高于第9层的针。下 N 和这根较高的针经历两轮都不会截去，顺序也不会颠倒。而目标 q3 在保留 C 以上的唯一 N 高于所有针，矛盾。

所以 R 必须沿支撑路径向下，最终借 q3 的针链接到保留的第3层 C。取支撑路径离开 R 时的那个 q3 普通格，记其高度为 t。它下方若又遇到同组较低 N，就回到已排除的含针环；这段高度内 q2 的连续 C 又使同层 q3 N 必属于同组，不能另当成独立支撑。因此这条链直到第3层 C 之间只能是针。

- t≤9 时，N 会保留到最终，只能成为第10层顶条，所以 t≥8。
- t=9 时，下面五根针全部保留，超出目标允许的四根。
- t=10 时，N 虽可能在第二轮截去，但下面六根针仍有多余保留格。
- t=11 不属于 R 所在的原两列非针组：该组每个占用层都须含 C，会要求 R 有第11层 C。

故 t=8。原半形必须已有 q3 第4至7层针、第8层 N；R 的 q2 C 连续经过第4至8层。它们在第一轮全部保留。

于是 Y 确定含 q3 第5至8层针、第9层 N，以及 q2 第5至9层辅助 C 塔。这个旧 N 在第二轮后固定为 E 的 q3 第10层顶条。

<a id="s06-03-h6"></a>

### 6. 两轮之间的上部局部状态被锁定

既然 E 已有 q3 第10层 N，最终 Stack 就不能再补 q0/q1 第10层屋顶：不带 q3 会落得过低，带 q3 会被旧屋顶挡得过高，带 q2 会增加目标外格。也不能加垫块再删除。因此 q0/q1 屋顶都必须在 E。

它们不能在第二轮从更高处落到第10层。移动的水平 N 块需要第9层的直接下方支撑，那里只有 q3 的针；该块不能再带一份 q3 N，因为旧屋顶 N 已存在，也不能带目标没有的 q2 N。因此两格在第二轮不动，来自 Y 的第9层。详细落点论证与[一次 Pin 排除第7节](#s06-02-h7)相同，不使用该文的起点切向假设。

Y 的 q0/q1 第9层既已有屋顶，它们以下的目标普通格和针也都必须在 E。设 Y 的 q0 普通格 U 将成为目标第8层，q1 普通格 V 将成为目标第4层。

- U 在保留的 q0 第6层 C 与第9层屋顶之间，只能位于第7或8层。
- Y 的 q1 已有第5层辅助 C，目标第3层的非触地针只能在它上方，且低于 V 与屋顶，所以只能位于第6或7层。
- 若针在第7层，正下第6层不能放 C（会融合进保留 C）、N（会固定在错误位置）或另一根针（目标没有额外针）。故针在第6层，V 在第7或8层。
- U、V 不能同层，否则普通格不会分离，不能落到不同目标高度。

若 U 在第8层、V 在第7层，U 在 Y 中无法静止：q0 第7层不能有额外 N/针，不能有融合进保留 C 的 C；同层 q1 不能放 C，违反第6层非触地针上方禁 C 的 Q，也没有允许的 N；q3 同层为针，不粘连。

因此只能 U 在第7层、V 在第8层。q1 第7层为空。q0 第8层也为空：若放 C，它被下方 U、上方屋顶、左右 V/针完全隔离，既不触顶又受 U 支撑，第二轮不能删除；若放 N/针，则是目标容不下的额外非晶体格。

Y 的关键上部骨架因而是：

```text
 z   q0 q1 q2 q3
 9    N  N  C  N
 8    .  N  C  针
 7    N  .  C  针
 6    C  针 C  针
 5    N  C  C  针
```

这些是必须存在或必须为空的位置；更低格和更高辅助部分不影响下一步排除。

<a id="s06-03-h7"></a>

### 7. V 不能是第一轮下落产生的

Y 的 V 位于 q1 第8层，左右分别为空与旧 C，所以若它在第一轮移动过，碎晶后保留的普通块只能是一个单格。它不能与旧 C 在下落中提前合组。

单格要停在第8层，正下第7层必须非空，但 Y 的该位置为空。故 V 在第一轮没有移动，必来自 X 的 q1 第7层 N。

Y 第6层的非触地针则来自 X 第5或6层：它必须低于原 V，且至多提高一层。原第6层针不能静止，正下第5层不能是 C（与保留 q0 C 融合）、N（固定到 Y 的针位）、或另一根针（会在 Y 留下第7层额外针）。所以原针在第5层，原 q1 第6层为空。

<a id="s06-03-h8"></a>

### 8. 原 V 无法准备，也无法提前堆入

现在区分 X 的 q1 第7层 V 是否已经在 B。

<a id="s06-03-h9"></a>

#### V 已在 B

原 q0/q1 半形中，V 正下第6层为空，必须靠同层 q0 的非针格托住。同层 N 不行：它会与 V 一起在第一轮固定到第8层，但 Y 的 q0 第8层为空。因此必须是 q0 第7层辅助 C。

该 C 下方第6层必须是 N。若为空，最近的下方格是第5层保留 C，违反 J；若为 C，就融合进保留 C；若为针，则违反 Q。这颗 N 由保留 C 托住，所以辅助 C 不能靠下落消失。

Y 的 q0 第8层为空，故原第7层辅助 C 必须在第一轮融合顶破。它左右是 V 和 q3 第7层针，下方是 N，只能向上连接。原 q1 第5层已有非触地针，Q 禁止其更高 C；q3 第8层是旧屋顶 N，第9、10层也没有辅助 C。因此融合路径只能沿 q0 连续占据第7至11层。

这使 X 的 q0 第8至11层全为 C。但 Y 的 q0 屋顶 N 在第9层，其原材料必须来自 X 的第8层或更高处，不能凭 Pin 新增。这些位置已全被 C 占据，矛盾。

<a id="s06-03-h10"></a>

#### V 来自前置 Stack

B→X 的 Stack 段保持 K，新增普通块必须满足基础堆叠的最终支撑判据。V 在原第7层，其正下第6层为空；同层 q0 不能有 N，否则会与 V 一起保留到 Y 的禁止位置；q2 已是来自 B 的 R 晶体，不能作为新增普通块的一部分。故含 V 的新增水平块只能是单格，而它没有正下支撑。

任意复杂上料在 K 下料上的约化也受这个判据约束。因此 V 不能通过前置 Stack 放到所需位置。

两个来源均不成立，反设路线不存在。

<a id="s06-03-h11"></a>

### 9. 已证明的全局结论与尚未解决的任意序列

T₂ 的尾部 Pin 数恰为2，且不能连续执行。已有 `D → P → S → P → T₂` 达到下界，所以确实存在完整目标，强制在两次 Pin 之间进行有效 Stack。前置或后置 Stack、任意合法上料、另换合法交换起点，都不能取消这次中间加工。

这解决的是一个全局交替实例。它没有证明任意正整数序列 `(a₁,b₁,a₂,b₂,…)` 都能被强制。后者还需构造可重复的约束，并排除不同阶段互相支撑、提前准备屋顶或合并 Stack 的替代路线；不能仅复制本例就宣布成立。

<a id="s06-04"></a>

## 06-04 T₃ 的最少尾部顶针数：从任意交换起点都需要三次

原文标识：`general/t3-pin-lower-bound.md`。

本页继续研究[强制工序](#s06-01)中的四象限、H=12 目标 T₃。P 表示 Pin，S 表示 Stack；N/C/针表示材料，层号从0开始。起点 B 可以是任意合法两半的最后一次交换结果；各次上料任意，不固定为原截图配方。主干旋转吸收到 B 与各次上料的朝向。

**结论：T₃ 的最少尾部 Pin 数恰为3。** 已有 `D → P → S(SuSu----) → P → P → T₃` 达到这个下界。本页排除一切只含一次或两次 Pin 的路线；零次已在原文排除。允许两次 Pin 之前、之间和之后任意补料。

本页确定 Pin 总数；[顺序下界](#s06-05)另证第一次、第二次 Pin 之间必须 Stack，最短操作词恰为 P→S→P→P。两个结论都不证明任意正整数交替次数序列可以被强制。

<a id="s06-04-h1"></a>

### 1. 目标与通用逆推约束

```text
 z   q0 q1 q2 q3
11    N  N  .  N
10    .  .  .  针
 9    N  .  .  针
 8    C  .  .  针
 7    N  .  .  针
 6    N  .  .  C
 5    .  N  N  C
 4    .  针 N  .
 3    .  N  N  N
 2    .  针 针 针
 1    N  针 针 针
 0    针 针 针 针
```

```text
T₃ = P-P-P-P-:SuP-P-P-:--P-P-P-:--SuSuSu:--P-Su--:--SuSucr:Su----cr:Su----P-:cr----P-:Su----P-:------P-:SuSu--Su
```

引用[四象限任意层 K 定理](01-foundations.md#s01-06)：尾部所有状态均属于 K。Stack 保留旧下料及其全部 C，只从列顶上方追加 N/针。最后一次 Pin 的输出 E 因而是目标的逐列下方前缀，含全部目标 C；额外格不能再靠后续 Stack 消除。

另外使用[列内 Q/J 与地面针来源](01-foundations.md#s01-01)、[移动组不能成为固定组的最终支撑](01-foundations.md#s01-12)，以及两列半形的非针组区间性质。普通格不会在尾部被拆开；同列保留格不能穿过彼此。

假设总 Pin 数 p 为1或2，记第一次 Pin 前为 X。所有保留 C 来自 B，在 X 中位于：

- q0：8−p；
- q3：5−p、6−p。

q0 的两个 N，目标层号6、7，必须分别来自 X 的6−p、7−p，且每次只抬升、不下落。它们处在保留 C 以下，不能后补。

<a id="s06-04-h2"></a>

### 2. 两个假设都锁定同一低层骨架

先看最后一次 Pin 前的状态 Y。p=1 时 Y=X；p=2 时 Y 还允许包含两次 Pin 之间的全部 Stack。

保留 C 为 q0 第7层及 q3 第4、5层；q0 的第5、6层 N 固定。q0 第4层必空：N/C 会与 q3 第4层保留 C 粘连或融合，最终留下目标外格；针则违反 Q 或造成过长地面针前缀。

最后 Pin 后，q3 双 C 所在固定组要获得支撑，必须含 q2 第5层 N。它不能靠移动过的普通格补成固定支撑。该 N 已在 E，故其下方目标 q2 第3、4层 N 也必须在 E，不能在旧 N 下方后插。列内次序及最多提高一层把三者来源依次锁定为 Y 的 q2 第2、3、4层，全部固定。

q3 的地面针前缀在 Y 中长2，低 N 只能位于第2或3层。若在第3层，它与 q2 第3层固定 N 粘连，最后会到第4层，不能成为目标第3层 N。因此 Y 的低 N 位于第2层；第3层为空。

p=1 时这就直接给出 X 的低层骨架：q3 针0/1、N2、空3；q2 针0/1、N2/3/4。

p=2 时不能立即把这个结论向前平移：第一次 Pin 后可能还有辅助 C 支撑保留组，q2 的普通格也可能试图在中间补入。现在只可确定 X 的 q3 为针0、低 N 在1或2层；首次 Pin 后，这个 N 已在第2层，因为保留 C 下方不能接受中间补料。q0 的目标底部针0、N1则迫使 X 地面为空，低 N 在第一次 Pin 后落地，第二次再为它补针；否则地面针数不符。源低 N 只能在1或2层，第3层会粘住保留的 q3 C。

第3节先分别排除另一切向，第4节再用原右半形的辅助塔处理“中间补入 q2”这条分支。

<a id="s06-04-h3"></a>

### 3. 原半形切向与辅助分量

先排除 q3/q0 切向。

p=1 时，保留的 q3 双 C 与 q0 第5层 N 所在组，下方 q3 第3层已空；q0 第4层也为空，理由同第2节。较高 N 与针不能从上方给这个组提供支撑。因此原半形不属于 K。

p=2 时，q0/q3 两颗低 N 不能同层，否则不能分落到目标第1、3层。

- 若 q3 低 N 在1层，q0 低 N 就在2层。原 q3/q0 半形中它没有支撑：q0 第1层 C 违反 J；q3 第2层 C 会与保留 C 融合，N/针则多留材料。因此不合法。
- 若 q3 低 N 在2层，q0 低 N 就在1层，原半形必须用 q3 第1层辅助 C 托住后者。该 C 正下是针0，不能跌碎；为了让 q0 低 N 首次落地，它必须首次触顶融合删除。路径跨过第3层只能走 q1，继而第4层也只能走 q1：另外三列不是保留 C，就是会与保留 C 融合的位置。因此 q1 第3、4层辅助 C 均首次删除。

在第二种情形中，首次 Pin 后的 q3 低 N 已在2层，正上3层为空；q0 第4层也为空。原 q1 第4层辅助 C 已删，不能继续经 q0 第5层 N 托住保留组。因此首次 Pin 的输出必须已有 q2 第4层固定 N。其下两颗目标 N 不能再从旧 N 上方插入，也已在首次输出的第2、3层。反推得 X 的 q2 第1、2、3层 N 均固定。但第2层 N 会粘住原 q3 第2层 N，使它不能首次下落到第2层，矛盾。

这里没有把首次输出预先当成目标前缀；是先确定 q1 对应辅助 C 已删除，才排除其残余支撑。

只剩 q0/q1 与 q2/q3。q0 第6−p层 N 必须原已在 B；它正下为空，原左半形中同层 q1 必须有辅助 C。不能换成 N，否则那个 N 会随保留组固定到目标没有的 q1 第6层。

记该辅助 C 的融合分量为 R。它通过 q0 的固定 N 连接保留 C，因此不能下落碎掉；必须在某次 Pin 中触顶融合删除。

R 的向上路径必须经过 q1 第7−p层，再经过 q2 第8−p层：这一带 q0 分别为固定 N 和保留 C，不能放待删 C；q3 也不能提前出现辅助 C。后一点由 Q/J 及目标的唯一上部 N 得到：在 q3 保留双 C 以上再出现辅助 C，前面必须先有一个分隔 N；低于11−p的这种 N 既不能达到目标屋顶，也不能被 p 次截高删除。

原右半形因此含 q2 第8−p层的辅助塔。q2 第6−p层必空：C 会与 q3 保留 C 融合，N 会固定到目标没有的 q2 第6层，针违反 Q。辅助塔不能沿 q2 直接落到低层骨架。

<a id="s06-04-h4"></a>

### 4. 原右半形强制预置屋顶

证明 q3 第11−p层 N 及下面四根针必已在 B。

若辅助塔通过地面路径获得支撑，这条路径必须转到 q3。取保留双 C 以上、路径首先使用的 q3 普通格。它下面不能先出现另一段辅助 C 而没有分隔 N；这是 J 及晶体间隙条件的限制。

这个 N 若低于11−p，不能成为目标唯一的上部 N，也不能截掉。若高于11−p，为了从下面的保留双 C 托住它，至少要预置五根针；最低五根经历 p 次 Pin 都不会截去，已经超过目标的四根。若路径先经过另一颗较低 N，那颗 N 又回到前一种情况。于是地面路径必须使用第11−p层 N，其下恰是第7−p至10−p层的四根针。

还需排除只靠含针环托住辅助塔的替代。两列非针组的高度区间不交叠，q2 的非触地针又不能处于该塔之下。因此这种环必须在 q3 用一根或多根针连接两个普通格。较低 N 至多在第9层：其上至少还要容纳一根针和另一个 N。

- p=1：第9层及以下的 N 不会截去，也到不了目标第11层，矛盾。
- p=2：低于第9层同样不行。第9层 N 则必须保留成目标屋顶；既然旧屋顶已经存在，其下四根目标针不能以后从上方插入，只能预先位于第5至8层。这又得到同一个屋顶与针链。

所以两种支撑都迫使：

```text
q3：针在 7−p…10−p，N 在 11−p。
```

Q 随即排除 q3 保留双 C 以上的全部辅助 C。右半形辅助塔连接这个屋顶，只能沿 q2 连续 C 上行。因此 R 包含 q2 第8−p至11−p层的整段 C。

这个屋顶及四针始终由保留双 C 托住，每次只提高一层。它不能改成交换后的新上料。

<a id="s06-04-h5"></a>

#### 两次 Pin 时，q2 的低 N 也不能中途补入

p=2 时，R 含 q1 第4、5层及 q2 第6至9层 C。分两种删除时刻：

- R 撑过第一次 Pin：q2 的高塔挡住全部中间上料，Y 中第2、3、4层的三颗 N 必须已经在首次输出。第4层 N 不能从 X 第4层落来（会粘住保留 C），也不能从第5层落来（会粘住仍保留的 q1 第5层 R），更不能穿过第6层以上的高塔。因此来源只能是第3层；另外两颗依次来自第1、2层，均固定。
- R 在第一次删除：q1 原第4层 C 已不在。首次输出中 q3 第3层为空，q0 第4层也为空，保留双 C 必须依靠 q2 第4层固定 N 取得支撑。其下两颗 N 不能以后插入，故同样反推出 X 的 q2 第1、2、3层固定 N。

两种情况都得到同一结论。原 q3 低 N 若在第2层，就会粘住 q2 第2层固定 N，不能下落。因此 X 的 q3 低 N 在第1层，正上第2层为空；q0 低 N 则必须在第2层。第6节将利用这个已证骨架进一步确定 R 首次删除。

<a id="s06-04-h6"></a>

### 5. 一次 Pin 路线不成立

此时 p=1。原 q3 屋顶在第10层，Pin 后成为 E 的第11层旧 N。后置 Stack 不能补 q0/q1 第11层屋顶：只带 q0/q1 会落低一层，带 q3 会被旧屋顶挡高，带 q2 则留下目标外格。因此 q0/q1 屋顶也必须原在 X 第10层。

它们不能从更高处落到第11层：移动普通块需要第10层直接支撑，那里仅有 q3 的针；但 q3 已有固定屋顶，不能再多带一个 q3 N。于是屋顶在 Pin 中不下落。

记 q0 目标第9层 N 为 U，q1 目标第5层 N 为 V。屋顶挡住后插，全部较低目标格都必须已在 X。R 含 q1 第5、6层 C，故 q1 的非触地针必须高于第6层，再往上才是 V。它不能在第8层：正下第7层若是 C/N，会连接 q0 第7层保留 C；若是针，则增加另一根非触地针。因此该针在第7层，U/V 只能分别占第8、9层。

U/V 不能同层，否则无法分落到目标的第9、5层。

- U 在9、V 在8：U 下方为空，q1 同层 C 被非触地针的 Q 禁止，q3 同层为针，不能静止。
- U 在8、V 在9：若 V 原在 B，左半形需要 q0 第9层 C 托住它。该 C 被下方 U、上方屋顶和两侧 V/针隔离，又由 U 托住，不能融合删除或下落。若 V 来自前置 Stack，单格只能落在 q1 第7层针上方的第8层；带 q0 会多留一格，带 q2 会被原辅助塔挡到屋顶以上。

两种情形都不成立。这里使用的是原[一次 Pin 排除](#s06-02)的屋顶障碍，低层支撑与切向已在本页重新证明，没有把 T₂ 的全部下界直接平移。

<a id="s06-04-h7"></a>

### 6. 两次 Pin 时，R 必须在第一次就删除

现在 p=2。q0 的目标底部为针0、N1。X 的 q0 地面必须为空；否则两次 Pin 至少留下两根连续地面针。目标 N1 必须在第一次 Pin 后落到地面，第二次才在它下方生成那一根针。若等到第二次才落下，无法同时产生目标地面针。

X 的低 N 只能在第1或2层：第3层会与保留的 q3 C 粘连，第4、5层已是另外两颗固定 N。第1层又会粘住第4节已锁定的 q3 第1层固定 N。因此它必须在第2层。

该 N 位于保留 C 以下，已在 B。原左半形中，其正下 q0 第1层不能有 C（地面空，违反 J），也不能多放 N/针；同层 q1 只能用辅助 C，不能用无法分开的 N。

这颗 q1 第2层 C 不能在第一次 Pin 中靠下落删除：

- 下方若为 N1，它只能成为目标 q1 N3，因而必须固定，继续支撑上面的 C；
- 下方若为 C1，它与第2层 C 融合，并一直支撑到非空地面；地面为空违反 J；
- 下方若为针1，Q 要求针0也存在，两次 Pin 后前缀过长；
- 下方若为空，J 要求地面 N；但地面 N 最多升到第2层，不是目标允许的 q1 N。

所以它必须在首次 Pin 触顶融合删除。其通向第11层的路径跨过第3层时，只能走 q1：该行 q3 是保留 C，q0/q2 的 C 都会与它融合。故路径包含 q1 第3层 C，随即连上第3节强制的 q1 第4层 C。两者属于同一 R。

**R 因而首次删除，包括 q2 第6至9层 C。** q2 第10层 C 若存在也与它相连；第11层 C 不论属于哪个分量都在首次 Pin 删除。因此首次 Pin 后，q2 高处不能留下另一根替代辅助塔。

<a id="s06-04-h8"></a>

### 7. 两次 Pin 之间补屋顶也不成立

仍记最后一次 Pin 前为 Y。q3 的旧屋顶在第10层，针链在第6至9层。与第5节相同，最终 q0/q1 屋顶不能在最后 Pin 之后补入；它们在最后 Pin 中也不能下落到第11层，因为移动块没有合法的第10层直接支撑。因此 Y 的 q0/q1/q3 第10层都是 N。

先证明 Y 的 q0/q1 第9层都为空。

q0 的 U 只能在第8或9层。q1 屋顶以下的非触地针及其上方 V 都已在 Y，不能以后插入。因此 q1 第9层不能是 C：那根较低的非触地针会违反 Q。q2 第9层 C 已随 R 首次删除；q3 第9层是针。

若 U 在第9层，其正下为空，同层 q1 不能放 C，也不能放终点高度不同的 V；q3 是针。U 不稳定，所以 U 在第8层。q0 第9层若改放 C，它被 U、屋顶、q1 非晶体格及 q3 针完全隔离，由固定 U 托住，第二次 Pin 既不触顶也不下落，仍会多留 C。故 q0 第9层为空。

q2 第9层也不能改用 N：q2 已有三颗较低 N，额外 N 不会在最后一次 Pin 中截去，下落也只会多留第四颗。q0/q1 第9层的针同样无法成为目标材料；它不能截去，而 q1 的非触地针还必须低于 V。

若 V 在第9层，它只能由正下方第8层针托住：其他较低 N 必须在那根非触地针以下；q1 第8层 C 也会违反 Q。但这根第8层针的下方第7层无合法支撑：C 会与 q0 第7层保留 C 融合，N 会粘住它而固定到目标外第8层，另一根针又会多留材料。同层 q0 已空，q2 辅助 C 已删，因此 V 也不能位于第9层。

于是，两次 Pin 之间若想新增第10层 q0/q1 屋顶，单用这些列缺少第9层落点；带 q3 被旧屋顶挡住；带 q2 会留下不能删除的第10层普通格。中间所有 Stack 都保留旧格，所以不能先加垫块、随后在同一个 Stack 段移走。

屋顶也不能在首次 Pin 中从更高位置落到第10层：同样没有第9层直接支撑，且不能再带一个 q3 N。故 q0/q1 屋顶只能原已在 X 第9层，首次 Pin 时固定提高。

<a id="s06-04-h9"></a>

### 8. 首次 Pin 前预置屋顶同样矛盾

X 的第9层现在已是 q0/q1/q3 三 N。其下全部待保留普通格和针都必须已经存在，不能以后从屋顶上方插入。

R 含 q1 第4、5层 C。目标非触地针必须高于它、低于 V，且 V 低于第9层屋顶。针若在第7层，其正下第6层既不能是 C/N（连接 q0 保留 C），也不能多放针。因此针在第6层，U/V 只能在第7、8层，并且不能同层。

- U 在8、V 在7：U 正下无支撑，同层 q1 C 违反 Q，q3 为针，不属于 K。
- U 在7、V 在8：若 V 原在 B，左半形只能借 q0 第8层 C 支撑。这颗 C 被 U、屋顶、V 和 q3 针隔离，并始终受保留 C 上的 U 支撑；两次 Pin 都不能删掉它。若 V 来自前置 Stack，单格会落在第7层；带 q0 多留一格，带 q2 被原第6至9层 C 塔挡高。

所以首次 Pin 前也无法预置屋顶。结合第7节，所有两次 Pin 路线均被排除，中间允许任意次 Stack 也没有例外。

<a id="s06-04-h10"></a>

### 9. 结论及对任意序列的限制

零次、一两次 Pin 全部不可能；原制造路线使用三次。因此：

`min Pin(T₃，任意合法最后交换起点，任意前后及中间 Stack) = 3`。

原路线的最后一次 Pin 没有顶破 C，却仍不能据此删掉这个目标所需的第三次 Pin。[首次无顶破 Pin 的前移定理](#s06-10)只适用于第一个 Pin，不能扩成“所有不顶破的 Pin 都可以移到交换前”。

Pin 总数下界本身不确定顺序；[独立的顺序证明](#s06-05)通过第三次 Pin 前的无晶体屋顶行，以及第二次 Pin 后的 T₂ 加顶盖状态，证明最短词恰为 `P S P P`。任意序列的构造仍未完成。与 r≥2 的[整体抬升族](#s06-10)相比，r=1 的底部只容纳一根针，不能把低 N 预放在两次 Pin 所需的负高度，必须真正发生释放。r≥2 时已有更换起点的两次 Pin 配方，不能从本例继续按抬升层数归纳。

证据为人工逆推、支撑与列内不变量、两种半切方向排除及已有制造配方。没有执行枚举、求解器、物理模型、测试或游戏。本页只在四象限、H=12 的既定规则下证明上述目标的 Pin 总数。

<a id="s06-05"></a>

## 06-05 T₃ 的最短尾部操作词恰为 P→S→P→P

原文标识：`general/t3-forced-order.md`。

沿用[强制工序](#s06-01)的四象限、H=12 模型。P 为一次 Pin，S 为一次单层 Stack；起点 B 可以是任意合法最后 Swap 输出，准备两半与上料的操作不计入尾部。旋转吸收入起点及上料方向。N/C/针表示材料，层号从0开始。

[T₃ 的次数下界](#s06-04)已排除少于三次 Pin；列内计数上界又排除多于三次。本页进一步证明：

1. 任意合法尾部都必须在第一次、第二次 Pin 之间进行有效 Stack。
2. 第二次 Pin 后，高度0至10的部分已经恰为 T₂；最多额外带一个第11层顶盖。
3. 后两次 Pin 之间及最后 Pin 之后的 Stack 均可删去，不改变 T₃。

已有 `D → P → S(SuSu----) → P → P → T₃` 达到四步。因此，**最短尾部为四步，忽略旋转后的操作词唯一是 P→S→P→P**。这里的唯一性不涉及起点、上料或较长配方。

<a id="s06-05-h1"></a>

### 1. 三次 Pin 的来源与低格释放时刻

允许路线写成：

`B → S* → X → P₁ → S* → Y → P₂ → E → S* → Z → P₃ → W → S* → T₃`。

[四象限支撑定理](01-foundations.md#s01-06)保证全程属于 K，每段 Stack 只追加 N/针，保留全部旧格和 C。W 是目标的逐列下方前缀。

X 中三颗保留 C 位于 q0 第5层、q3 第2和3层。q0 的两个较低固定 N 位于第3、4层；最低 N 只能在第1层：地面非空会导致最后至少三根地面针，第2层 N 则会粘住保留的 q3 C，无法成为目标第1层 N。因此 q0 第0、2层为空。

q3 的低 N 只能在第0或1层。第1层会与 q0 低 N 粘连，却要到不同终点，故只能为地面 N，第1层为空。原有地面针也会使三次 Pin 后的前缀超过目标三根。

q3/q0 半形不能托住悬空的 q0 第1层 N。因此切向只能是 q0/q1 与 q2/q3；原左半必须以 q1 第1层辅助 C 托住它。

目标 q0 为针0、N1，所以低 N 必须在第二次 Pin 后落地，第三次才在它下方补针。第一次落地会产生两根底针；第三次才落地则没有办法同时取得目标地面针。上方保留 C 又挡住另外补入地面材料。

这颗辅助 C 不能靠下落删除：q1 地面必须非空，地面针会使前缀过长，地面 N 保持直接支撑，地面 C 则与它属于同一融合分量。因此其分量 R **首次保留、第二次触顶删除**，在 X 中最高 C 恰为第10层。

<a id="s06-05-h2"></a>

### 2. 原右半形强制 q3 旧屋顶

R 从 q1 第1层向上，跨过第2、3层时只能留在 q1：另外各列的 C 都会进入保留融合分量。第4层仍须经过 q1，第5层则转到 q2，以避开 q0 保留 C。

这里 q3 第4至9层不能有辅助 C。第4层直接与保留 C 融合；更高辅助 C 之前须有分隔 N。若该 N 低于第8层，它既不能到达目标第11层屋顶，也不会在三次 Pin 中截去；若在第8层，它已经是旧屋顶，下方四根目标针必须预存，Q 又禁止其上再放 C。

因此 R 至少含 q1 第1至4层及 q2 第4、5层 C。q2 第3层为空：C 会融合进保留 C，N 会固定到目标没有的第6层，针则违反 Q 或地面前缀计数。

原右半形的 R 不能沿 q2 直接接地，只能借 q3 的普通格和针取得支撑。该两列非针组只有一个融合分量，附着 N 的高度不超过 R 的最高 C，即第10层。

若靠地面路径支撑，设转到 q3 的 N 位于 t 层。t<8 时，它不能成为目标屋顶，也不能截去；t>8 时，通向下面保留 C 的针链至少含第4至8层五根针，这五根经过三次 Pin 都保留，超过目标四根。若路径先经过另一颗较低 N，则仍归入这个计数。因此只能 t=8。

若靠含针环支撑，q3 必有上下两个 N，中间至少一根针，较低 N 至多在第8层。低于8仍不行；恰为8时，它必须保留成目标屋顶，下面四根目标针不能以后插入，也必须已在原半形。

故两种支撑均得到：

```text
X 的 q3：针4…7，N8。
X 的 R：q2 连续 C4…8，最高 C10。
```

Q 随即排除 q3 保留双 C 以上的全部辅助 C。屋顶和针链只随 Pin 抬升，永不下落。第二次 Pin 后 q3 屋顶在第10层，第三次后在第11层。

还得到一个后面要用的事实：**第二次 Pin 后，q2 第6层及以上不再有 C。** 来源第4至8层属于 R；第9层 C 若有也连着 R；第10层 C 最迟第二次删除；第11层 C 首次删除。Stack 不能补回 C。

<a id="s06-05-h3"></a>

### 3. 第三次 Pin 前，三份屋顶都已就位

W 已有 q3 第11层旧屋顶。最后的 Stack 段不能补 q0/q1 第11层屋顶：只用 q0/q1，目标允许的下方最高格为 q0 第9层 N，会落低一层；带 q3 会被旧屋顶挡高；带 q2 则多留目标外格。也不能加垫块后再删。

所以 W 必须已有全部三份屋顶。这些屋顶也不能在第三次 Pin 中移动到第11层：移动块需要第10层直接支撑，而那里只有 q3 的针；但 q3 已有固定屋顶，不能再带一个 q3 N。故 Z 的第10层已是 q0/q1/q3 三 N。

q2 第10层没有 C，因为第2节已证明全部高 C 都在前两次消失。那里若为 N，会粘住两侧旧屋顶并固定到目标没有的 q2 第11层。若为针，它不会截去，也不能穿过较低 N 落进地面针前缀：W 的保留双 C 需要 q2 第5层固定 N 支撑，其下两个目标 N 不能后插，反推已锁定 Z 的 q2 第2、3、4层 N。因此该针也会多留材料。

因此：

```text
Z 第10层：N N . N
```

**这一整行没有 C。** 第三次 Pin 即使在第11层顶破 C，其融合分量也不能越过第10层。顶层的非针组只有单层，不能从上方支撑较低组。截去整个第11层后，下方 K 支撑不受影响；第三次 Pin 对所有较低格只作整体抬升，并按地面占用补针。

此外，W 已有三份屋顶，q0/q1/q3 较低目标格都不能以后插入。保留的 q3 双 C 组必须包含 q2 第5层 N 才能获得支撑；它下面的两颗 N 也不能后插。因此 W 已经完整等于 T₃。

把这次无下落抬升反向还原，得到：

`Z = T₂ + 第11层的可选顶盖`。

这里允许合法的 N、针或 C 顶盖，不声称任意顶盖都能制造。第三次 Pin 把它全部截去；它不能给下面增加任何支撑关系。

<a id="s06-05-h4"></a>

### 4. 第二次 Pin 后补屋顶也不可能

需要区分 E 与 Z，不能把中间 Stack 段直接当成空。

在第11层顶盖以下，Z 的 q0/q1 第9层均为空，q2 最高只有第4层 N，q3 第10层已经是旧屋顶。若某份中间上料添加 q0/q1 第10层屋顶：

- 只带这些新增列，没有第9层落点；
- 带 q3，被已有第10层 N 挡高；
- 带 q2，产生无法留在 Z 的普通格。

Stack 保留旧格，所以不能先垫高、再把第9层垫块移走。故 q0/q1 屋顶已经在 E。

三个旧屋顶又把全部较低目标材料挡在它们下方。q2 方面，E 中的保留双 C 同样需要旧 q2 第4层 N 支撑；其下两颗 N 也必须已经存在。于是：

`E = T₂ + 第11层的可选顶盖`。

E→Z 的有效变化最多是给第11层追加 N/针；这些材料随第三次 Pin 截去。因此这段 Stack 全部可省。W 已等于 T₃，最后的 Stack 段也不承担目标制造。

这一步只针对该目标及其三次 Pin 来源，不是一般的“末尾 Stack 都可以前移”定理。

<a id="s06-05-h5"></a>

### 5. 假设两次 Pin 之间没有 Stack

现在反设 P₁ 与 P₂ 之间没有有效 Stack。Y 就是第一次 Pin 的输出。

E 的第0至10层已恰为 T₂，另有可能的顶盖。以下只使用屋顶下的材料，因此不能用这个顶盖逃开来源约束。

E 的 q0/q1 第10层屋顶不可能在 P₂ 中下落到位：其正下第9层没有允许的支撑；移动块又不能再包含旧 q3 屋顶。所以 Y 的第9层已是三份屋顶。

Y 的 q0 保留 C 在第6层。记 U 为最终 q0 第9层 N，V 为最终 q1 第5层 N。相对于 E，它们就是 T₂ 第8层、第4层的那两颗 N。

屋顶挡住后补，且 R 在 Y 含 q1 第2至5层 C。因此 q1 非触地针只能在第6层；若在第7层，其正下第6层 C/N 会连接保留 C，针则多留材料。U、V 只能分占第7、8层，不能同层粘连。

U8、V7 会使 U 失去所有支撑，所以必须 U7、V8。q1 第7层为空；q0 第8层也为空。该位置若放 C，会被 U、屋顶、V 和 q3 针隔离，且由 U 托住，后两次 Pin 都不能删除；N/针则多留屋顶下的材料。

因此 Y 的必要上部骨架为：

```text
 z   q0 q1 q2 q3
 9    N  N  C  N
 8    .  N  C  针
 7    N  .  C  针
 6    C  针 C  针
 5    N  C  C  针
```

第11层顶盖不会影响这些格位及其下落判据。

<a id="s06-05-h6"></a>

### 6. 必需的 V 无法提前准备

Y 的 V 在 q1 第8层，左右为空和旧 C，正下第7层为空。如果 V 在第一次 Pin 中移动过，碎晶后的普通块只能是单格，却没有直接落点。因此它必须原在 X 的 q1 第7层、固定提高到第8层。

Y 第6层针来自 X 第5层：若原在第6层，其正下第5层不能是 C/N（连接保留 C），也不能再放一根针。因此 X 的 q1 第6层为空。

分两种来源：

- V 原已在 B。左半形必须以 q0 第7层辅助 C 托住它。J/Q 迫使该 C 正下第6层为 N，该 N 又由第5层保留 C 支撑，所以辅助 C 不能跌碎。Y 的对应第8层为空，说明它首次触顶删除。左右为 V 和 q3 第7层针，下方为 N；q1 的非触地针禁止更高 C，q3 旧屋顶及针链也禁止更高 C。融合路径只能沿 q0 连续占据第7至11层，堵死 Y 第9层屋顶所需的原 N 来源。
- V 来自前置 Stack。它正下第6层为空，同层 q0 不能带 N，否则它也会随 V 固定到 Y 的禁止位置；q2 是旧 R 的 C，不能作为新增普通块的一部分。单格没有第7层落点。

两种来源都不成立。因此 P₁、P₂ 之间必须有有效 Stack。这个屋顶障碍与[T₂ 的顺序证明](#s06-03)相同，但本页已独立处理第三次 Pin、额外顶盖和后段补料，没有直接把 T₂ 的结论套在未知中间态上。

<a id="s06-05-h7"></a>

### 7. 已解决的操作词与尚未解决的推广

三次 Pin 必须保留；至少一次 Stack 必须在前两次之间。因此最短尾部至少四步。既有 D 的路线使用一次单层双 N 上料，恰为：

`P → S → P → P`。

任意四步最短尾部只能具有这个操作词。较长路线可以多插入 Stack；其中第二次 Pin 后的 Stack 对目标均无必要，可以删去。这不声称所有起点和所有中间物品唯一。

现在已有两个完整目标的全局最短词：T₂ 为 P→S→P，T₃ 为 P→S→P→P。T₃ 因而确实提供了“堆叠之后连续两次顶针”的必要实例，而不是仅有三次 Pin 总数。

仍未解决的是任意 `(a₁,b₁,a₂,b₂,…)`。本例末尾第三次 Pin 只抬升，不产生新的支撑交接；把相同结构继续抬高又会落入已有两次 Pin 的替代族。因此不能把这一个连续段机械重复，宣称获得任意次数或任意多次切换。

证据为来源追踪、两列半形支撑、顶盖隔离及人工落点排除。没有运行测试、枚举、求解器、物理模型或游戏。

<a id="s06-06"></a>

## 06-06 一次顶针之后，逐层堆叠的必要次数没有常数上界

原文标识：`general/forced-stack-length.md`。

本页推进[任意指定次数序列](#s06-01)中的 Stack 次数问题。参数固定为四象限，高度上限 H 可增长；P 表示 Pin，S 表示单层 Stack。起点允许任意合法最后 Swap 输出，Pin 前后都允许任意补料，旋转吸收入起点与上料朝向。只计主干尾部，上料及两半的准备另计。

**结论：存在一个显式目标族，每个目标都必须且只能用一次尾部 Pin，而 Pin 之后的单层 Stack 最少次数无界。** 更进一步，对每个正整数 k，都存在该族中的一个目标，使这个后段的最少 Stack 次数恰为 k。后一个结论是存在性证明，尚未给出每个 k 对应的具体成员和最优起点。

这不是任意交替序列的完整证明。本页旧目标族仍允许最优后段路线带前置Stack；新的[保留晶体限制辅助路径构造](#s06-07)已对每个偶数n≥4、k≥1给出明确目标，证明完整最短词恰为P S^k，并排除以前置Stack抵消k次后段Stack。

<a id="s06-06-h1"></a>

### 1. 目标族与统一制造路线

取 H≥5，整数 0≤b≤H−3。N 取 Cu，C 取 cr。定义 A_b：

```text
层号          q0 q1 q2 q3
3…b+2          N  N  N  N   共 b 层；b=0 时没有这些层
2              C  N  .  N
1              N  .  .  .
0              针 .  针 .
```

短代码为基础三层：

```text
P---P---:Cu------:crCu--Cu
```

再接 b 份 `:CuCuCuCu`。

准备 D_H：

```text
层号          q0 q1 q2 q3
2…H−1          .  .  C  .
1              C  N  C  N
0              N  .  C  .
```

两半 q0/q1 与 q2/q3 都稳定：左半由地面 N 支撑保留 C 和侧 N，右半由触地连续 C 塔支撑另一侧 N。它们满足列 A，且没有 C 下方悬空落点，[四象限任意高度直接释放](02-four-quadrants.md#s02-15)给出制造凭据。这个构造是[必须一次尾 Pin 的三层目标](02-four-quadrants.md#s02-08)的辅助塔高度扩展。

P 删除整个 q2 辅助塔，得到 A_0。随后每次堆入一份完整单层 `CuCuCuCu`，依次得到 A_1、A_2、…、A_b。

因此统一可行路线为：

`D_H → P → S^b → A_b`。

它证明 Pin 后最多需要 b 次 Stack，没有先断言这个配方最优。

<a id="s06-06-h2"></a>

#### 利用准备高度预制一部分上层

还可以在最后 Swap 之前预制 s 层，其中 H≥2s+4、0≤s≤b。准备 B_(s,H)，未列出的格为空：

| 列 | 普通格 N | 晶体 C |
|---|---|---|
| q0 | 0；2…s+1 | 1 |
| q1 | 1…s+1 | s+2…H−1 |
| q2 | s+3…2s+2 | 0…s+2 |
| q3 | 1；s+3…2s+2 | 无 |

空区间不放格。两半01/23分别稳定，全部 C 都有直接下邻，两列半形仍由已有构造制造。q1 高塔和 q2 低塔在 s+2 层连接，组成触顶删除的同一分量；q0 的保留 C 被普通格隔开。

Pin 删除这个分量后，q0/q1 的 s 层预制普通双格固定提高；q2/q3 的 s 层普通双格失去低塔支撑，依次落在目标第3至s+2层。最下面的双格由 q3 旧侧 N2 托住，后面的双格由前面已经落位的普通格托住。最高预制 N 在2s+2层，H≥2s+4保证它不被截去。因此一次 Pin 恰好得到 A_s。

之后只需再堆 b−s 层。取 t=floor((H−4)/2)、s=min(b,t)，得到改进的可行上界：

`Pin 后 Stack 次数 ≤ max(0,b−floor((H−4)/2))`。

特别地，同一目标 A_b 在 H≥2b+4 的环境中可以只用一次尾部 Pin。必要次数必须连同全过程高度上限一起讨论，不能只报最终图形的层数。

<a id="s06-06-h3"></a>

### 2. 任意合法尾部恰好一次 Pin

目标 q0 的最低 C 在第2层，触地针前缀长度为1。[保留 C 与地面针计数](#s06-01-h8)给出：

`p ≤ max(1,2−2) = 1`。

零次 Pin 也不可能。由[四象限 K 定理](01-foundations.md#s01-06)，只有 Stack 的尾部保持旧格及全部 C，只追加 N/针。目标两侧的 q1/q3 第2层 N 正下为空；新增块不能借旧 q0 C 把自己当成已支撑普通块，也不能带目标第2层不存在的 q2 N。因此两颗侧 N 都必须已经在交换起点。

任意相邻两列切向，都有一颗侧 N 与 q0 保留 C 分处两个半形。缺少 q0 C 的那个半形不能托住它：同层 q2 为空，正下也为空。较高的全 N 层只有水平粘连，不能从上方支撑这个低 N。这个半形不属于 K，不可能是合法切后结果。

所以所有合法尾部都具有：

`B → S^a → X → P → E → S^c → A_b`，其中 a,c≥0。

下界将允许任意 a，不把提前堆料的路线排除在外。

<a id="s06-06-h4"></a>

### 3. Pin 输入必须有一条贯穿全高的辅助晶体路径

X 的保留 C 必在 q0 第1层，其下方目标 N1 必来自 q0 地面 N。

目标两侧第2层 N 不能在 Pin 后新增，理由与零次排除相同。它们也不能在 Pin 中移动到第2层：移动普通块在该处没有直接下方支撑，不能带目标没有的 q2 N，也不能带 q0 的保留 C。因此两颗侧 N 原在 X 第1层，只随 Pin 固定提高。

它们还必须原已在 B。若通过前置 Stack 加入第1层，单格正下为空；带 q2 新 N 会在 Pin 后留下低于第3层的额外 N，带 q0 又遇到旧 C，均不可行。

原两半中，远离 q0 C 的那颗侧 N，必须借 q2 第1层辅助 C 支撑。同层 q2 若为 N，则该普通格最多提高到第2层，也不能截去，目标没有它。

q2 地面也只能为 C：地面空不满足第1层 C 的 J 条件；地面 N 会留下第1层额外 N；地面针会使目标针前缀变成两根。故 q2 第0、1层同属一个触地融合分量 R。

R 不能下落碎裂：Pin 后其底部仍受新地面针支撑。目标没有 q2 的 C，后续 Stack 又不能删旧 C，所以 R 必须在这一次 Pin 中触顶融合删除。

**R 从第0层连接到第H−1层，因此每个中间层至少占一颗 C。** 路径可以转列、分叉，不要求它始终沿 q2 直上。这是下面计数不依赖具体准备塔的原因。

<a id="s06-06-h5"></a>

### 4. 高度填满时的全局后段下界

现在取 b=H−3，即目标顶部恰好填到 H−1 层。

目标上部需要 4b 颗 N。Pin 前能成为这些普通格的来源，仅在 X 第2至H−2层：

- 第0、1层的普通格只有前述三颗固定 N，它们分别成为目标低处 N1、两颗侧 N2；额外低 N 无法消失或升到上部。
- 第H−1层 N 会在 Pin 中截去，不能留下。
- Pin 不会把 C 或针变成 N。

第2至H−2层共 b 层、4b 个格位。由第3节，每层至少一格属于 R。因此 X 在这些层最多预存 3b 颗上部 N，不管这些 N 原在 B，还是经任意次前置 Stack 加入。

至少有：

`4b − 3b = b`

颗目标 N 必须在 Pin 后补入。每份四象限单层上料最多提供四颗 N，所以任意合法路线都满足：

`c ≥ ceil(b/4) = ceil((H−3)/4)`。

结合统一路线：

`ceil((H−3)/4) ≤ min c(A_(H−3)) ≤ H−3−floor((H−4)/2)`。

对未填满的任意 b，同一来源容量计算与第1节预制构造给出：

`max(0,b−floor(3(H−3)/4)) ≤ min c(A_b) ≤ max(0,b−floor((H−4)/2))`。

这是任意起点、任意前置 Stack 与任意合法单层上料下的界。它已经排除了“每段只保留固定常数次 Stack 就能覆盖所有四象限任意层目标”的设想。

这里的 Stack 在补普通材料，不是在同一个形状上反复执行纯重新结算 F。因此它与四象限全部可制作状态属于 K、F 恒等的结论不冲突。若允许多层上料，一份上料可以提供超过四颗 N，这个次数下界不能照搬。

<a id="s06-06-h6"></a>

### 5. 每个正整数都能成为后段的精确最少次数

固定任意 k≥1，取 H=4k+3。在同一个高度上限下，考虑 b=0…4k 的有限目标族。定义：

`f_H(b) = A_b 所有合法尾部中，唯一一次 Pin 之后的单层 Stack 最少次数`。

前置 Stack 次数不固定，也不计入这个函数。统一配方保证每个目标可制作，故最小值存在，且：

1. `f_H(0)=0`。
2. `f_H(4k)≥k`，由第4节。
3. `f_H(b+1)≤f_H(b)+1`：直接在 A_b 的任意最优后段路线末尾多堆一层全 N，即得到 A_(b+1)，并且不超过相同的 H。

取第一个使 f_H(b)≥k 的 b。它大于0；前一个值小于 k，而向上最多跳1，所以该值只能恰好等于 k。第1节预制构造还给出 f_H(b)≤max(0,b−(2k−1))，因此得到：

**对每个 k≥1，存在 3k−1≤b≤4k，使 f_(4k+3)(b)=k。**

不需要假设 f_H 单调；它可以下降，第一次越过给定整数时仍不能跳过该整数。这个证明没有执行任何成员搜索，也没有计算最优配方。

其精确含义是：该目标所有合法尾部都至少包含 k 次后段 Stack，而且存在某条尾部恰好包含 k 次。达到 k 的路线可能为 `S^a P S^k`，其中 a>0；本页没有把它未经证明地改写成 `P S^k`，也没有宣称它同时最小化尾部总步数。

<a id="s06-06-h7"></a>

### 6. 一个明确可制作、至少需要两次后段 Stack 的成员

取 H=11、b=8。目标由基础三层加八层全 N 构成，短代码为：

```text
P---P---:Cu------:crCu--Cu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu:CuCuCuCu
```

取预制参数 s=3，B_(3,11) 的短代码为：

```text
Cu--cr--:crCucrCu:CuCucr--:CuCucr--:CuCucr--:--crcr--:--crCuCu:--crCuCu:--crCuCu:--cr----:--cr----
```

把其01/23两半按第1节制造并交换，顶针一次先得到 A_3，再连续堆入五份 `CuCuCuCu`，得到 A_8。最高预制普通格在第8层，不会被 H=11 的顶针截去。

任何其他合法最后交换起点也只能用一次 Pin；它之后至少还需两次单层 Stack。因此一段 Stack 不能普遍压成一次。这个具体目标当前证明的范围是 `2≤min c≤5`，没有给出恰好两次的最优配方。

<a id="s06-06-h8"></a>

### 7. 任意交替序列仍缺少的部分

现在已经有全局最短词P→S→P、P→S→P→P，以及[任意偶数n≥4的完整P S^k明确构造](#s06-07)。本页旧族的无界下界和首次越界论证仍成立，但完整单段词已经由新构造独立闭合。

尚未证明的是：任意选定的多个段可以组合，同时排除换起点、前置Stack、并行补料和跨段提供支撑。本页第5节的最小值仍只针对旧族的后段次数，不应把新族的最优配方套给旧成员。新的P S^k定理也没有覆盖任意a≥2的P^a S^b或任意多个段。

证据为半形制造凭据、K 追加性质、保留材料来源、融合路径逐层占位计数及有限整数首次越界论证。没有运行测试、枚举、求解器、物理模型或游戏。

## 06-07 任意长度的完整操作词P S^k：明确目标与全局下界

原文标识：`general/forced-stack-word.md`。

采用偶数象限n=2m≥4、共同制造上限H=k+3，其中k≥1。P表示Pin，S表示一次单层Stack；最后Swap后的主干只允许这两种操作及可吸收的旋转。两半和上料可以任意合法预制，但全过程共用H。层号从0开始。

**对每个k及每个偶数n≥4，下面的目标T_(n,k)恰好需要一次尾Pin，Pin之后至少需要k次单层Stack；显式路线P S^k达到下界。因此它的最短尾部共k+1步，操作词必为P S^k。** 允许任意前置Stack、不同交换起点和上料，不会降低这个下界。

这完成任意序列猜想中单段`(1,k)`的明确构造，包括排除用前置Stack替代所需后段次数。它不证明多个段可以串接，也不把较长配方里的无用加工称为唯一制造过程。

<a id="s06-07-h1"></a>

### 1. 一套参数化目标

记缺口三列为`J={m−1,m,m+1}`，其余列为K。K是经过q0的连续环形区间，q0∈K。N取Cu，保留C取cr。未列位置为空。

| 列 | 地面至低层 | 上部 |
|---|---|---|
| q0 | P0、N1、C2 | C3…H−1 |
| q∈K且q≠0 | N2 | C3…H−1 |
| q(m−1)、q(m+1) | N2 | N3…H−1 |
| qm | P0；第1、2层空 | N3…H−1 |

所以第2层是q0的C、qm的空位和其他n−2枚N；第3至H−1层，K列全是保留C，J三列全是N。qm恰有k枚普通格，全部位于第3至H−1层。

例如四象限、k=3、H=6时，目标自下而上为：

```text
P---P---:Cu------:crCu--Cu:crCuCuCu:crCuCuCu:crCuCuCu
```

六象限、k=3、H=6时，目标为：

```text
P-----P-----:Cu----------:crCuCu--CuCu:crcrCuCuCucr:crcrCuCuCucr:crcrCuCuCucr
```

短代码按表格逐格转写；下面的证明使用参数化格位，不依赖执行模型。

<a id="s06-07-h2"></a>

### 2. 合法交换起点与达到下界的路线

准备D_(n,k)，辅助晶体可取cc：

| 列 | 来源格 |
|---|---|
| q0 | N0；保留C1…H−2 |
| q∈K且q≠0 | N1；保留C2…H−2 |
| q(m−1)、q(m+1) | N1 |
| qm | 辅助C0…H−1 |

两份半形分别占0…m−1和m…n−1。第一半的第1层由q0的C及其余N连成，q0通过N0接地；第二半的第1层由qm的C及其余N连成，qm直接触地。较高的每根保留C柱都立在第1层N上。因此两份半形稳定。

<a id="s06-07-h3"></a>

#### 半形的实际制造

n≥6时，每列满足[列条件A](03-general-construction.md#s03-03)。对两半均从左端开始[递归剥离](03-general-construction.md#s03-04)：删掉首列，在右侧添加完整N助手后，剩下的第1层N横条接到助手；所有上部C都有该横条提供的直接下邻，故仍稳定。后续每次剥离保持同一性质，最终进入纯N基例。反向恢复给出真实制造树，全程不超过H。

n=4时，两半是q0/q1和q2/q3。C柱均连续接地或直接立在地面N上，侧N位于第1层并由C柱托住。它们满足[四象限完整半形构造](02-four-quadrants.md#s02-11)的直接候选；也属于既有无悬空晶体下落点的直接构造范围。故同样具有制造凭据。

两半稳定，Swap预切不会改变它们，拼合得到D。

<a id="s06-07-h4"></a>

#### 尾部加工

D的辅助C只在qm。其左右两列m−1、m+1在第1层是N，更高处为空，因此辅助塔不与保留C融合。执行一次P，恰好删除整根辅助塔；其余C提高一层。q0和qm原来触地，得到两枚地面针。

第1层的N原本横向连接q0的保留C。qm辅助C被删除后，这条横向连接分成左右两臂，但两臂都仍接到q0，所以它们只提高到第2层，不下落。较高保留C的直接下方N也保留。因此本次输出已经具有目标的全部C、两枚地面针及第1、2层材料，只缺J三列在第3至H−1层的普通格。

连续k次堆叠同一份J三列普通块。第一次两侧列的最高格为第2层N，中间qm只有地面针，三格块恰落到第3层；以后每次再提高一层。它们接到K中的保留C，并有之前完成的下一层阻挡，均保持原位。最后逐格得到T_(n,k)。

<a id="s06-07-h5"></a>

### 3. 所有合法尾部至多一次Pin

q0最低目标C位于第2层，其下面是P0、N1。保留C不能下落，Stack不能带入新C，因此p次Pin要求它的来源高度为2−p。

p≥3时来源高度为负，不可能。p=2时，该C必须来自地面；两次Pin会在它下面形成两根连续地面针，不可能得到目标第1层N。因此p≤1。

以下分别排除p=0，并研究p=1的全部来源。证明不假设六象限或更宽状态属于K，也允许Stack触发旧下料下落。

<a id="s06-07-h6"></a>

### 4. 零Pin不可能：低处普通横条不能由Stack补入

反设`B → Stack* → T`。全程不生成C，目标C从B开始就在最终位置。Stack不删除旧N/P，也不提高旧N/P；地面占用不会消失。

令A为除q0、qm之外的全部列。目标在A列第0、1层均为空。因此在整个尾部中，这些位置不可能出现N/P；也不能有C0，因为地面C永远不能下落碎裂。C1也不可能：若正下为空，[J不变量](01-foundations.md#s01-01)要求同列更低处有N，而该列地面始终为空。

所以A列第1层在整条路线中始终为空。目标第2层的N若是在某次Stack中新增或移动到位，其水平普通块必须在某个参与列的第1层取得直接阻挡。但这个块：

- 不能包含q0，因为q0第2层始终有保留C；
- 不能包含qm，因为落入qm第2层的N无法在仅Stack尾部中消失或升到目标第3层以上；
- 只包含A列时，第1层又始终全空。

故这些N不可能由新增或下落取得，必须已经以第2层N的身份存在于B，而且之后不移动。

<a id="s06-07-h7"></a>

#### 缺少q0的半形必含辅助C

任一等分半切中，q0与qm互为对径，必在不同半形。考察不含q0的那份真实切后半形。它在第2层已有上述N，所在列第1层为空；同层除qm之外全是被锁定的N。

合法机器输出的[无C组直接支撑性质](01-foundations.md#s01-07-h1)禁止这些普通块悬空。因此qm第2层必须为C，使其成为含C组。这一步不把切后半形稳定当作一般前提。

qm的目标没有任何第0至2层N，也没有第1层P。此处旧N/P不能通过Stack删除，所以来源C2下面不能用N或P1；若第1层空，J也找不到更低N。故qm第1层只能为C。

第0层不能空（J），不能是N（目标不含该N），也不能是C（地面C无法在Stack中消失）。只能为P。于是辅助C1/C2直接受永久地面针托住。任意新增粘连都不能吞并独立的针节点；这些C永远不能下落碎裂，与目标qm无C矛盾。

因此p=0不可能。结合第3节，每条合法尾部都恰有一次Pin。

<a id="s06-07-h8"></a>

### 5. 一次Pin的全部来源都被迫保留同一根辅助塔

写任意路线为`B → Stack* → X → P → E → Stack* → T`。

q0的保留C来源为第1至H−2层，目标N1必须来自其下的原地面N0。其他K列的保留C来源为第2至H−2层。A列在Pin输入时地面必空，否则会产生目标没有的地面针；qm的最终低部只有一根地面针。

<a id="s06-07-h9"></a>

#### 第2层横条在Pin中不能移动，也不能事后补入

Pin之后，A列第1层不可能有C，因为那必须来自这些列原来的地面C，而它们原地面为空。该处N/P也不可能保留：它们既不能升高，也不能在后续Stack中消失，落到地面同样违反目标。

qm第1层若在E中仍有C，它来自原地面C，下面已生成P0，因此永远不能在后续Stack中删除；目标禁止它。qm第1层N/P也会留下额外低格，故同样排除。q0第1层则为固定N。

因此目标第2层N的移动块仍找不到直接下方阻挡：它不能含q0的保留C位置，不能向qm添加永久多余N，其余列的第1层全空。它们在Pin中只能固定提高，在Pin后也不能新增。所以X在全部A列第1层已有这些N。

它们还必须已经在B。若前置Stack要把某个N块放到第1层，A列原地面全空；带q0会撞上保留C1，带qm则会加入在这次Pin后无法消失的第2层或更低N。故前置Stack不能提供它们。

<a id="s06-07-h10"></a>

#### 原半形与地面材料锁定辅助分量

再取不含q0的原半形。其第1层N在本列没有地面阻挡；除qm外同层均已锁为N。因此无C组支撑性质再次迫使qm第1层为辅助C。

qm原地面不能空（J）；不能为N，否则Pin后多留N1；不能为P，否则得到两根地面针。只能为C。qm第0、1层属于同一触地融合分量R。它在任何前置Stack中都不能跌碎；唯一一次Pin后若未全部删除，也会由新增地面针继续托住。因此R必须在这次Pin中通过触顶融合删除。

R连接第0层和第H−1层，故每个中间层至少有一颗R晶体。第2至H−2层，K中的全部C都是已锁定的保留晶体，R不能占据或融合到它们。两侧缺口列m−1、m+1各自紧邻K中的保留C，放R晶体也会融合到保留分量。故R在这些层只能经过qm。

已知qm第1层为R；第H−2层也只能从qm继续向上到第H−1层。因此qm的第0至H−1层全部为辅助C。这个结论覆盖任意路线中的X，并未把它假设为第2节的特定D。

<a id="s06-07-h11"></a>

### 6. 单层计数给出完整词的精确下界

上一节说明：唯一Pin之前，qm在整个允许高度内没有一个普通格位置。前置Stack既不能插到这根塔下面，也不能在高度上限外储存普通格。Pin只删除C、抬升或下落N/P并补针，不把C变成N。

所以目标qm在第3至H−1层的k枚N，全部必须来自Pin之后的Stack。每份单层上料在qm最多提供一枚N，故后段至少k次Stack。

第2节的`P S^k`恰好达到下界，总计k+1步。因此所有最短尾部都没有前置Stack，P/S操作词均为`P S^k`。任何较长路线也不能用前置Stack抵消这k次后段Stack。

k=0可单独使用[必须一次尾Pin的基础目标](02-four-quadrants.md#s02-08)；本页k≥1使上部保留晶体约束和非空Stack段同时存在。

<a id="s06-07-h12"></a>

### 7. 与原任意序列命题的关系

[此前的全普通上部族](#s06-06)只给出后段次数的无界下界及首次越界存在性，最优后段路线还可能带前置Stack。本页改用保留晶体限制辅助路径，给出每个k的明确目标，并直接锁定完整最短词。

后续[中间窗口构造](#s06-08)已证明每个k≥1都有完整最短词P S^k P。两族仍未证明`P^a S^b`中任意a≥2都可强制，也未证明任意多个交替窗口能够组合。若把本页目标整体抬高并预补地面针，来源也可以预制相同针前缀，不能据此增加必要Pin数。任意有限正整数序列的全局命题仍须另证。

证据为两半制造证书、材料来源、无C组支撑性质、J及永久针支撑、保留晶体隔离和单层计数。全文人工推导，没有运行测试、枚举、求解器、物理模拟或游戏，没有修改Python或电路。

## 06-08 两次Pin之间任意长的必要Stack段

原文标识：`general/forced-middle-stack-word.md`。

采用四象限、共同高度上限H=k+11，k≥1。P表示Pin，S表示一次单层Stack；两半及上料可任意合法准备，主干旋转吸收到来源朝向。层号从0开始，N取Su，C取cr，未列位置为空。

**下面的明确目标Wₖ，从任意合法最后Swap起点制造时，都恰好需要两次Pin，且两次Pin之间至少需要k次单层Stack。路线P S^k P达到下界，所以完整最短词恰为P S^k P。** k=1就是原来的十二层T₂。

本页仍不证明任意多个交替段或任意长的连续Pin段。它把此前单次中间堆叠的全局实例推广为每个指定正整数k，不把固定来源的计数冒充全局下界。

<a id="s06-08-h1"></a>

### 1. 目标与合法起点

目标Wₖ为：

| 列 | 针 | 普通格N | 保留晶体C |
|---|---|---|---|
| q0 | 无 | 0、5、6、8…k+7、k+9 | 7 |
| q1 | 0、1、3 | 2、4、9…k+7、k+9 | 无 |
| q2 | 0、1 | 2、3、4 | 无 |
| q3 | 0、1；6…k+8 | 2、k+9 | 4、5 |

k=1时区间9…k+7为空。q0从第8层起共有k枚连续N；它们上方第k+8层为空，第k+9层另有屋顶N。q1的相同高处空隙和屋顶形成同一条屋顶。q3的旧屋顶位于第k+9层，下面是连续针链。

准备Dₖ：

| 列 | 针 | 普通格N | 晶体C |
|---|---|---|---|
| q0 | 无 | 1、3、4、6 | 保留5；辅助7…k+10 |
| q1 | 5 | 0、7 | 辅助1…4 |
| q2 | 无 | 0、1、2 | 辅助4…k+9 |
| q3 | 4…k+6 | 0、k+7 | 保留2、3 |

按q0/q1与q2/q3分成两半。左半低条由q1接地塔托住，q0的保留C和高塔由其下N托住；q1的N7挂在q0高塔旁。右半保留双C经q2低N接地，高辅助塔通过q3的旧屋顶和针链接到保留C。两半都稳定。

各列满足A；所有C正下空隙的活动落点都与原T₂相同：q2的N2正下为N1，q3的N0触地。其他高处变化只延长连续C塔和已有针链。因此[任意层直接释放](02-four-quadrants.md#s02-15)给出两半实际制造过程，最高只到H−1。Swap得到Dₖ。

<a id="s06-08-h2"></a>

### 2. P S^k P的逐格结果

首次P删除q0辅助塔。q1低塔与q2高塔的融合分量R保留并升到顶层。此时：

- q0最高N为第7层；q1的悬空N在第8层，仍接到q2辅助塔。
- q3旧屋顶在第k+8层；其针链为第5至k+7层。
- q2辅助塔最高为第k+10层，即H−1。

连续k次加入q0/q1双N。每份上料只有一层，依次落到第9、10、…、k+8层。第一份由q1的N8确定落点，以后由上一份确定；它们同时接在q2辅助塔旁。

第二次P删除R。最上面的新双N升到第k+9层，与q3旧屋顶相接，并由q3针链固定。其余k−1份双N先升到第10至k+8层，再各下降一层，依次落到第9至k+7层：最下面由q0的旧N8阻挡，后面逐层叠上。

其余低处下落与T₂相同：q0低N落地；q1原针落到第3层，原悬空N落到第4层；保留C成为q0第7层及q3第4、5层。由此逐格得到Wₖ。

<a id="s06-08-h3"></a>

### 3. 所有来源至多两次Pin，且不能零次

q3最低保留C在第4层，下面是两根地面针和N2。[通用Pin上界](#s06-01-h8)给出p≤max(2,4−2)=2。

零次不可能的证据只涉及低处。四象限所有尾部保持K，Stack只追加；q0的N5不能从上方补到它的保留C7下面，必须已在交换起点。q0/q1切向中N5既无同层邻格也无正下支撑；q3/q0切向中，N5与q3保留双C构成的组正下均空。新增高处普通层和更长针链不改变这两个低组。因此[原零Pin排除](#s06-01-h9)原样适用。

<a id="s06-08-h4"></a>

### 4. 一次Pin的低骨架与旧屋顶

反设B→S*→X→P→E→S*→Wₖ。四象限K闭包保证E是目标的逐列下方前缀，含全部目标C。

[原一次Pin排除](#s06-02)第2至5节只使用目标第7层及以下、q3保留C上方只有一枚N及非触地针上方禁C。这些条件在Wₖ均保持。因此仍可推出：

1. 只能按q0/q1与q2/q3分半；q0保留C在X的第6层，固定N在4、5层，低N在2层。
2. q3保留C在3、4层，低N在1层；q2低部为P0及N1、N2、N3，第4层空。
3. q1的辅助C必须经过第4、5层，删除路径转经q2第6层；q3第4层以上没有辅助C。
4. 原右半形的q2高辅助塔必须通过q3的普通屋顶及针链接到保留C。

设原右半形离开高塔时的q3支撑N高度为t。保留N只能成为目标第k+9层的唯一高N，故t≥k+8；其下从第5层起的针全部保留，目标针链只有k+3根，故t≤k+8。若N高到会截去，保留针只会更多。悬空针环也会留下位于针下方的额外N。因此t=k+8，X含q3第5至k+7层针及N(k+8)，q2辅助C连续经过第6至k+8层。

E于是已有q3屋顶N(k+9)。目标q0/q1屋顶不能事后Stack补入：不带q3时，其允许的下方最高N仅为k+7，只能落在k+8；带q3会被旧屋顶挡到至少k+10；带q2会增加目标外格。额外垫块也不能事后删除。故屋顶及其下方全部目标材料都已在E。

这两个屋顶格也不能在P中从更高处下落到位：移动普通块在第k+9层需要第k+8层的直接阻挡，该层只有q3针；携带另一枚q3 N又与旧屋顶冲突。因此X的q0/q1屋顶也都在第k+8层。

<a id="s06-08-h5"></a>

### 5. 一次Pin仍只有原来的两个低处排布

q0保留C6之上、屋顶(k+8)之下必须装下k枚N，最终成为第8至k+7层N。可用位置是7…k+7，共k+1格，所以恰有一个位置不放N。

q1目标第1层旧针必须来自X的地面针。否则它因Q只能在辅助C5以上，而它及其上的N2、P3、N4和k−1枚高N共k+3格，必须挤进屋顶以下的6…k+7共k+2个位置，不可能。

q1目标P3的来源必须在辅助C5之上。它上方还有k枚N，故只能在第6或7层。第7层不行：正下第6层的C会融合进q0保留C，N会固定到目标q1没有的第7层，另一根针则超出目标数量。因此针在6，最低的上部N记为V，只能在7或8层。

V最终落到第4层，不能与同层q0 N粘连。故q0唯一不放N的位置恰是V所在层。两种情况是：

- V在7：q0的最低上部N在8，q1第8层必须空，否则这个双N不能分别成为q0 N8和q1更高N。原左半形中q0 N8没有正下支撑；q1 C8又违反非触地针上方禁C。它也不能后来Stack到8：单格落到C6上方的7，带q1产生目标外的q1 N8，带q3与针链冲突。
- V在8：q0 N7固定；q1第7层空。V若在原左半形，需要q0 C8托住。但该C下面是N7，上面是N9（k≥2）或屋顶N9（k=1），左右是V与q3针，完全隔离且不能跌碎。V若后来Stack加入，单格只会落在P6上方的7，带q0产生不允许的q0 N8，带q2又被辅助塔挡到屋顶以上。

两种情况均矛盾。故一次Pin不可能，所有合法路线恰有两次Pin。

<a id="s06-08-h6"></a>

### 6. 两次Pin的全部路线锁定中间空位

允许两次Pin之前、之间及之后任意Stack。记首次Pin输入X，第二次Pin输入Y，第二次输出E。

[原全局交替证明](#s06-03)第2至4节的低处推导不要求中间Stack为空：Stack不能移动K中的旧格，也不能在保留C或仍存在的辅助C下面插料。由相同低部目标，得到：

- 原切向只能是q0/q1与q2/q3；q0低N在X的第1层，必须等到第二次Pin才落地。
- 托住它的q1辅助分量R触地，不能靠Stack跌碎，必须第二次顶破，原最高层恰为H−2=k+9。
- R含q1的C1…4及q2的C4、C5。q2低N在0、1、2层，第3层空；q3为N0、空1、保留C2/3。

原右半形仍迫使q3旧屋顶与针链存在。与第4节相同，按两次抬升及保留针数计数，原屋顶只能位于k+7，针为4…k+6，R沿q2连续经过4…k+7。悬空针环会留下针下多余N，不能替代。第二次Pin前Y因此有q3针5…k+7、N(k+8)及q2的连续C5…k+8。

旧屋顶再次迫使q0/q1屋顶在第二次Pin前就位，位于Y的第k+8层；其下目标材料不能等到最后才插入。Y的局部格数与第5节完全相同：q0为保留C6，以上需k枚N；q1辅助C最高至少到5，非触地针在6，其上的k枚N中最低V只能在7或8。

V在7时，q0最低N8在Y不能稳定，理由同第5节，而且Y已经是合法输出。于是只能V8，q0为N7、空8、N9…k+7、屋顶N(k+8)。q1则为P6、空7、V8、N9…k+7、屋顶N(k+8)。q0空8不能藏辅助C：它被上下N及左右V/针隔离，第二次Pin不能删除。

<a id="s06-08-h7"></a>

### 7. k枚普通格只能全部在中间加入

Y的V8不能由两次Pin之间的Stack提供：它正下为空，带q0会填入禁止的N8，带q2会撞上已有C。因此V在首次Pin输出中就已经存在。它也不能在首次Pin中移动后停在第8层，因为移动单格没有第7层直接阻挡。故X的q1第7层已是V。

反推其下针，X的q1针在5，第6层空。这枚V不能来自首次Pin之前的Stack，同样没有可用的直接落点。因此它在原左半形中必须由q0 C7支撑。该C下方只能为N6；它不能跌碎，又必须在首次Pin后消失，故必须首次顶破。

这根辅助塔不能向左右绕行：q1上部有非触地针，q3直到旧屋顶及更高保留范围均不能放辅助C。它只好沿q0占满第7至H−1层，才能连到首次删除的顶层。与[原上塔锁定](#s06-03-h8)相同，这里同时允许任意前置Stack。

Y的q0第9至k+8层共有k枚N。它们不可能来自X：q0第7层以上全是辅助C，更低普通格经首次Pin至多到第7层，不能升到这些位置。它们也不能等到第二次Pin之后补入，因为屋顶已经必须在第二次Pin前就位，阻止向其下方插料。

所以这k枚N全部来自两次Pin之间的Stack。每份单层上料在q0最多一枚N，故中间至少k次。第2节用恰好k次达到下界，总步数k+2；所有最短词均为P S^k P，无前置或后置Stack。

<a id="s06-08-h8"></a>

### 8. 对原命题的作用与边界

与[完整单段P S^k](#s06-07)相比，本族增加了不能移到末尾的Stack时间窗口：旧屋顶及其下空隙迫使顶盖事先存在，顶盖又阻止事后向下补料。单列计数把窗口中的必要Stack数锁为指定k。

这证明两个Pin之间可以强制任意长的堆叠段，尚未提供任意多个这样的窗口。继续复制屋顶或增加针链，必须重新排除来源和跨窗口补料，不能由本页直接归纳任意序列。

证据为参数化两半制造、逐格人工加工、低处骨架、屋顶落点及材料计数。没有运行测试、枚举、求解器、物理模拟或游戏，没有修改Python与电路。

## 06-09 连续三次Pin的全局最短词

原文标识：`general/forced-initial-pin-block.md`。

固定四象限，任取共同制造高度H≥11，层号从0开始。P表示Pin，S表示单层Stack；材料记为N、针、C，N取Su、C取cr。

**下面的目标E从任意合法最后Swap起点出发，最少需要三次Pin。显式路线只执行PPP，所以完整最短操作词恰为PPP。** 下界允许改变起点和上料，并允许任意前置、中间、后置Stack。它没有证明任意长度的连续Pin段或任意多段交替序列。

<a id="s06-09-h1"></a>

### 1. 目标与三次Pin来源

目标E：

| 列 | 针 | 普通格N | 晶体C |
|---|---|---|---|
| q0 | 0、1 | 2、7、8、10 | 9 |
| q1 | 0…3 | 4 | 无 |
| q2 | 0…3 | 4、5、6 | 无 |
| q3 | 0…3 | 4 | 6、7 |

短代码：

```text
P-P-P-P-:P-P-P-P-:SuP-P-P-:--P-P-P-:--SuSuSu:----Su--:----Sucr:Su----cr:Su------:cr------:Su------
```

E最高到第10层，所以制造上限至少为11层。下面的来源通式对每个H≥11成立；下界也不随H增大而失效。

准备来源B：

| 列 | 针 | 普通格N | 晶体C |
|---|---|---|---|
| q0 | 无 | 2、4、5、7 | 保留6；辅助8…H−3 |
| q1 | 0 | 1 | 辅助2…5 |
| q2 | 0 | 1、2、3 | 辅助5…H−1 |
| q3 | 0、H−2 | 1、H−3、H−1 | 保留3、4 |

最小制造高度H=11的来源短代码：

```text
--P-P-P-:--SuSuSu:SucrSu--:--crSucr:Sucr--cr:Sucrcr--:cr--cr--:Su--cr--:cr--crSu:----crP-:----crSu
```

把q1低C与q2高C的融合分量记为R，把q0的C8…H−3记为A。R最高到H−1，A最高到H−3；H=11时A只含第8层的一颗C。

<a id="s06-09-h2"></a>

### 2. 两半有真实制造证书

按01/23分半。左半的R低塔立在q1 N1与地面针0上；q0的N2、N4、N5由该塔托住，C6、N7和A依次直接受支撑。

右半的保留双C由q2 N3及其下连续N/针托住。高R正下第4层为空，但它与q3 N(H−3)、N(H−1)组成一个外组；q3针H−2独立成组，形成外组→针→外组的支撑环。这个环不要求高R接地。

四列满足A。q1/q2/q3的地面都是针，q0最低C下有至少两个空位，因此四列均满足[完整S列构造](02-four-quadrants.md#s02-11)的直接充分分支。两半稳定，可按[完整半形判据与制造](02-four-quadrants.md#s02-13)取得同H的实际半切输出，再Swap得到B。没有把悬空高塔直接当原料。

<a id="s06-09-h3"></a>

### 3. PPP的逐格效果

第一次P删除R，并截掉q3原最高层N。q0低N2落地；其余低部保留。A升到9…H−2层，q3原N(H−3)升到H−2层，此时横向接到A，因而仍保持。原针H−2升到最高层，仍站在这枚N上。

第二次P没有新的深层晶体删除。A升到10…H−1层，临时N升到最高层，仍由A托住；临时针截去。q0原已落地的N升到1层，其下生成针。

第三次P删除A，并在同一次截顶中删除临时N。高支撑已经全部清除，不留下额外N/针。低部结果为：

- q0：低N位于2层、底部两针；原N4/N5到7/8，C6到9，N7到10。
- q1：四针加N4。
- q2：四针加N4、N5、N6。
- q3：四针加N4、C6、C7。

恰为E。临时N先由右半针环保持，再由左半A接住，最后与A同时截去；这个交接是两份真实半形在Swap后的作用。

<a id="s06-09-h4"></a>

### 4. 零Pin不可能

使用[四象限任意高度K定理](01-foundations.md#s01-06)：成功的纯Stack尾保留全部旧格及C，只能向列顶追加。因此起点必须是E的逐列前缀，含全部目标C；q0 N7、N8都在C9以下，必已存在。

01/23切向中，原左半q0 N7正下第6层为空，同层q1也没有允许的非针格，无法稳定。03/12切向中，q3 C6/C7与q0 N7组成的组，其下q3第5层、q0第6层都为空，同样无法稳定。实际两列半切输出属于K，故两个切向均被排除。

<a id="s06-09-h5"></a>

### 5. 一次Pin的来源排除

最后一次Pin输出是目标的逐列前缀，含全部目标C。用[固定组不能由本次移动格获得最终支撑](01-foundations.md#s01-12)逆推：

- 来源保留C为q0 C8及q3 C5/C6；q0 N6/N7固定。
- q0第5层为空；那里的N/C会接到保留C而留下目标外格，针则违反Q或造成过长地面针前缀。
- 保留低C组必须经q2固定N5取得下方支撑；三个q2低N均不能在其下补入，来源为N3/N4/N5。
- q3低N不能在4层，否则与q2固定N4粘连而无法单独下降；所以它在3层，其上第4层为空。

因此03半形的保留低C组没有直接下挡，切向排除。

01半形必须用q1 C6托住q0 N6。这个辅助C连接保留组，不能跌碎，必须在Pin中融合删除。其向上路径经q1 C7转到q2 C8。原右半q2第6层为空：C会融合保留q3 C6，N会固定到目标外第7层，针违反Q或造成过长前缀。

目标q3在保留双C以上没有任何N/针。因此来源中这些位置的N/针若存在，必须在唯一一次Pin中截去，只能处在第H−1层。q3也不能在更低高处放辅助C：它与保留C之间需要一枚N隔断，而这样的N无法截去。

右半高塔因而既不能沿q2跨过空的第6层接地，也不能经q3的低处接地。两列含针环至少需要两枚N和中间一根针，唯一可用的最高层容不下它。故右半形不能稳定，一次Pin不成立。

<a id="s06-09-h6"></a>

### 6. 两次Pin先锁定低部，再排另一切向

第一次Pin前记为X，最后一次Pin前记为Y。保留C在X中为q0 C7及q3 C4/C5，q0固定N5/N6；q0第4层为空，理由与上一节相同。以下不限制q0最低普通格的来源，也允许来源地面放后来顶破的辅助C。

上一节对最后Pin的逆推仍适用：Y的q2已有N3/N4/N5，q3低N在3层。q3保留C挡住中间补入低N，Stack也不移动旧料，所以第一次Pin输出时q3低N已经在3层，不能在第4层继续托住保留双C。

考察第一次Pin输出的保留低C组。q0下方仍为空，q3下方第4层也为空。它要有直接支撑，只能已经接入q2固定N5，或仍经q0固定N6接入q1辅助C6。后者只能来自X的q1 C5；q1同层N会固定成目标外格，不能替代。移动格不能为这个固定组补成最终支撑。

若X中存在q1 C5，记其融合分量为R。R已接到保留组，不能跌碎，必须在某次Pin触顶删除。它的向上路径经过q1 C6及q2 C7：q0的N6/C7挡住左路，q3保留C上方的辅助C又需要一枚不能在两次Pin内截掉的低N作为隔断，故不能走右路。分别检查：

- R不存在或在第一次删除：第一次输出只能已有q2固定N5。它下面两枚目标N不能后来插入，所以三枚N已在输出N3/N4/N5，来源为N2/N3/N4。
- R在第二次删除：q2第7层高C在第一次输出中仍挡住中间补入低N。因此Y的三枚N都来自第一次输出。最高N5若原在第5层，会粘住保留q3 C5；若原在第6层，会粘住保留的q1 C6；均不能下降到第一次输出的第5层。它也不能穿过第7层高塔，故只能来自第4层。其下两N由列内次序和最多提高一层锁在第2、3层。

所以两种切向、所有R删除时刻都迫使X的q2已有固定N2/N3/N4。q3低N若原在3层，会与q2固定N3粘连，不能首次下降到3；因此它原在2层，第3层为空。

现在排除03/12切向：原03半形的q3 C4/C5与q0 N5所成组，下方q3第3层和q0第4层都为空，无地面或外部直接支撑。该两列实际半形不可能稳定。只剩01/23切向。

<a id="s06-09-h7"></a>

### 7. 两次Pin清不掉右半所需的支撑环

01半形迫使q1 C5托住q0 N5，所以上节的R必存在，并通过q1 C6、q2 C7通向顶部。原料q2 N2/N3/N4与q3 N2已经由上节统一锁定。

原右半q2第5层必空：C会融合保留q3 C5，N会固定到目标外第7层，针违反Q或造成过长地面前缀。高R不能沿q2取得低处直接支撑。

另一方面，q3最终在保留C以上没有N/针。来源中任何这样的N/针都不能穿过保留C下落到低处，最多只会提高两层。因此它们必须从最高两层H−2、H−1出发，才可能全部截掉。q3高辅助C又必须先有这样的N作为与保留C的隔断，故不能在第6至H−2层铺晶体来补一条低处支撑路径。

右半的高R若经q3接地，需要在低保留C与高N之间留下N/针链，其中第H−3层及以下的N/针不会全部截去，违反目标。若靠两列内部针环，下端N至少在H−2层，针至少在H−1层，上端N至少在H层，超出共同上限。下端若改成C，它下面还需一枚与保留C分隔的N，所需空间只会更多。两列无针非针组不能形成另一种悬空支撑环，见[两列支撑区间性质](03-general-construction.md#s03-03-h10)。

因此右半形没有合法稳定证书，两次Pin也不成立。这里排除的是任意两次Pin配方，不只排除原B的两次加工。

<a id="s06-09-h8"></a>

#### 临时针环给出的清除期限

上面的计数还可用于其他构造。设原两列半形中的辅助融合分量R是某个针环的晶体脊，另一列的下端N位于l，上端N位于u，中间连续t≥1根针，故u−l=t+1。假设下端N在最后目标中没有对应格，也不能越过保留C落到低处，只能由截顶清除。设整条尾部共有p次Pin，R在第j次Pin中删除。

下端N每次Pin最多提高一层，因此清除它必须满足p≥H−l。晶体脊至少达到u层，其融合分量到第H−u次Pin时至迟已经触顶删除；Swap融合到更高塔、或提前跌碎，只能令j更小。所以j≤H−u，合并得到：

`p−j ≥ u−l = t+1 ≥ 2`。

若环的下端为C而非N，并且该列下面还保留目标C，隔断它们所需的更低N同样必须清除，此时界只会更强。上述假设必须逐项满足，不能把有目标对应格的永久环算成临时环。

因此，如果另一个保留C列的最低N恰随R删除第一次落地，且之后只通过Pin补底针，那么目标底针前缀至少为t+1，尤其不能只有一根。这同时用了[落地计数](01-foundations.md#s01-08-h11)与针环的真实高度；仅改变塔高不能绕过。它不是任意目标的Pin上界，也没有证明所有来源都被迫使用这一个R。

<a id="s06-09-h9"></a>

### 8. 整体抬升族仍恰需三次Pin

令r≥2，把E整体提高t=r−2层，并在四列各补t根地面针，得到Eᵣ。它与[另一页的中间产物Eᵣ](#s06-10-h12)相同。任取共同上限H≥r+9，以下结论成立：

`min Pin(Eᵣ)=3`，且PPP达到三步下界。

<a id="s06-09-h10"></a>

#### 三步来源

| 列 | 针 | 普通格N | 晶体C |
|---|---|---|---|
| q0，r=2 | 无 | 2、4、5、7 | 保留6；辅助8…H−3 |
| q0，r≥3 | 0…r−4 | r−3、r+2、r+3、r+5 | 保留r+4；辅助r+6…H−3 |
| q1 | 0…r−2 | r−1 | 辅助r…r+3 |
| q2 | 0…r−2 | r−1、r、r+1 | 辅助r+3…H−1 |
| q3 | 0…r−2；H−2 | r−1、H−3、H−1 | 保留r+1、r+2 |

r=3时q0的针区间为空，最低N直接触地。r≥3的q0最低N已由自身针前缀托住，三次Pin后到r层，底针长r；r=2则使用第3节的首次落地。其余低部只是原来源提高r−2层并补相应底针。高处仍用最高三层针环，第一次删R、第二次截针、第三次删A并截临时N。

制造证书保持：r≥4四列都有地面针；r=3的q0最低C以下仍有至少两个空位；r=2已证。两半的低部支撑和高环支撑不变，完整S列与两列半形定理仍适用。最高目标层为r+8，所以H≥r+9既必要又足够。

<a id="s06-09-h11"></a>

#### 下界不是从抬升次数直接推得

零Pin时，两切向的低保留组仍无下挡。一次Pin的第5节排除把低层坐标统一加r−2：q2固定N为r+1/r+2/r+3，q3低N为r+1；标准切的辅助路径经过q1 C(r+4)、C(r+5)及q2 C(r+6)。右半的临时N/针仍只能在最高一层，不能形成针环。

两次Pin同样重做第6节的来源锁定。Y中q2为N(r+1)/N(r+2)/N(r+3)，q3低N为r+1。第一次输出的保留组若没有q2固定N(r+3)，只能经q1 C(r+4)获得支撑；该C来自X的q1 C(r+3)，并迫使q1 C(r+4)及q2 C(r+5)的高路。按R是否留过第一次Pin分支，得到X的q2固定N(r)/N(r+1)/N(r+2)。q3低N因横向粘连约束只能原在r，另一切向随即被排除。标准切右半q2第r+3层为空；q3保留C上方没有目标N/针，来源只能在最高两层放可截去的临时材料，仍容不下三层针环。

这里不限制q0最低N在来源中的高度或支撑方式，也不把目标底针数当作来源地面一定为N的依据。地面辅助C和预制底针均已包含在上述支撑排除中。

<a id="s06-09-h12"></a>

#### 可行Pin总数恰为3至r+2

上界由q3最低C(r+4)及地面针前缀r+2给出p≤r+2；零至两次已排除。对3≤p≤r+1，取s=r−p+3≥2，在共同H中用PPP制造Eₛ，再做p−3次不截格的Pin，得到Eᵣ。

最后补p=r+2。E本身另有四次Pin来源：

| 列 | 针 | 普通格N | 晶体C |
|---|---|---|---|
| q0 | 无 | 1、3、4、6 | 保留5；辅助7…H−4 |
| q1 | 无 | 0 | 辅助1…4 |
| q2 | 无 | 0、1、2 | 辅助4…H−2 |
| q3 | H−3 | 0、H−4、H−2 | 保留2、3 |

两半稳定。q0满足两个空位的S充分分支；q1是紧列；q2和q3的C下活动落点分别由N1和地面直接挡住，故有直接释放制造证书。来源最高只到H−2，第一次Pin不顶破，逐格得到第1节的B；随后PPP得到E。再追加r−2次抬升，得到Eᵣ，总计r+2次。全过程目标最高不越过r+8，来源只到H−2，没有提高上限。

因此可行次数集合恰为`{3,4,…,r+2}`。长针环给出的P^(r+1)路线不能强制其长度：同一个Eᵣ始终有三层临时针环的PPP替代。此处完成的是一个具体族的次数集合，不是一般目标的统一三次Pin上界。

<a id="s06-09-h13"></a>

### 9. 结论与用途

零次、一次、两次Pin均不可能，PPP实际达到目标，所以

对每个H≥11，`min Pin(E)=3`，`min 主干步数(E)=3`，`唯一最短操作词=PPP`。制造空间的最小值也恰为11层，因为目标本身已经占到第10层。

这直接排除了“任何开头连续Pin都能统一压成一次或两次，再多用Stack补回”的一般猜测，即使只研究四象限，该猜测也不成立。它没有排除更长的等价配方中穿插Stack，也没有证明能把任意长度的多个窗口串接起来。

临时支撑的尺寸必须计入全局来源排除：本例需要清掉N–针–N三个高度，目标本身却不保留它们。单看成品的C塔数，或只看某个固定来源的破坏次序，都看不到这个下界。

这里证明的是三次Pin，不是三次不同晶体塔的深层顶破。H=11时A只有一颗顶盖C，第三次Pin也没有向下传播的晶体破坏。任意多次必要顶破及多个必要Stack窗口仍须另证。

证据为真实半形制造、人工逐格Pin推导、两切向及全部不足三次Pin来源排除。没有运行测试、枚举、求解器、物理模拟或游戏；没有修改Python或电路。

## 06-10 任意强制序列的推广障碍：开头抬升与末尾补针

原文标识：`general/tail-sequence-extension.md`。

本页继续研究[任意正整数次数序列](#s06-01)，不重复证明已经成立的全局 P→S→P 实例。P 表示 Pin，S 表示单层 Stack；准备两个半形的操作不计入最后 Swap 后的尾部。以下给出两个排除错误推广的结果，并确定整体抬升族的最少 Pin 数；它们不是对任意序列命题的整体证伪。

<a id="s06-10-h1"></a>

### 1. 没有顶破晶体的第一次 Pin 可以移到交换前

设四象限合法尾部的开头为：

`B → S₁ → … → Sₘ → X → P → Y`。

B 来自两个合法切后半形；Sᵢ 的上料都是单层，允许 N/针及随后碎掉的 C。若 X 顶层没有 C，则可以另行准备合法交换起点 B′，只用至多 m 次单层 Stack 得到同一个 Y，尾部省去这次 Pin。

<a id="s06-10-h2"></a>

#### Pin 在这里不引起下落

[四象限任意层 K 定理](01-foundations.md#s01-06)保证 B、X∈K。此前所有 Stack 保留 B 的旧格及全部 C，故 X 顶层没有 C，也等价于 B 顶层没有 C。

这次 Pin 只删除顶层 N/针、把其他格提高一层，并按原地面占用补针。顶层没有 C，顶层的非针组只有单层 N，不能通过竖直连接托住较低组；顶层针也没有上方保留格。下方 K 支撑证书不受影响，所以不发生下落。

<a id="s06-10-h3"></a>

#### 新起点的制造

记 G 为从 B 到 X 新增的地面格。每个这样的格所在列在 B 中必须整列为空：上料不能穿过旧格落地。把 G 按两个半形分别加入原半形，新增格均直接触地，可以用基础单层制造。

随后对这两个半形分别 Pin，再 Swap，得到 B′。两个半形都没有顶层 C，因此没有融合删除；各自只截去顶层 N/针、整体提高并补地面针。切线外仍为空，最后 Swap 的切割不会另碎 C。

B′ 恰好包含旧 B 与 G 经截顶和抬升后的保留格，以及由全部原地面占用产生的新针。余下差额都是原 S 段在非地面、非顶层加入的 N/针，统一提高一层。

<a id="s06-10-h4"></a>

#### 保留单层 Stack 次数上界

逐个处理原 Sᵢ：保留其最终落在原第1至H−2层的普通连通块和针，去掉落地的部分，以及在原顶层或上限外而不进入 Y 的部分。剩余格仍可合成一份单层上料；没有保留格的那一步直接省去。

这些上料按原顺序堆到 B′ 上，落点恰好提高一层。提前放入 G 不会挡住任何较早保留块：若某列较早已有新块，后来就不可能再往它下面加入地面格。去掉原顶层阻挡也不影响保留块：使用该阻挡的后续上料原本只能落在上限外，不属于本次保留部分。

对其余列，原高度和支撑关系统一提高一层，列顶最大值落点公式保持。归纳得到最终逐格等于 Y，Stack 次数不增加。

因此，在允许任意合法半形准备的全局最简尾部中，**第一次 Pin 必须真正顶破至少一个晶体融合分量**。若开头连续几次 Pin 都只是抬高，可以逐次把它们移到交换前；单纯增加开头等待抬升次数，不能强制任意 a₁。

这不是“任何连续 Pin 都能压成一次”的定理。已经发生顶破后，不能直接把中间状态当成新的合法交换起点。

[无顶破Pin与追加闭包交换](07-reductions.md#s07-13-h3)另证：对任意合适中间D，Cl(L(Cl(D)))=Cl(L(D))。它把此前追加移到无顶破Pin之后，需要补回新地面针，且不保持Stack次数；不能用于消除破坏型Pin之间的必要工序。

<a id="s06-10-h5"></a>

### 2. 将 T₂ 整体抬高 r 层，也不强制多 r 次尾部 Pin

取任意整数 r≥2，使用四象限、高度上限

`Hᵣ = r+11`。

定义 Lᵣ：把原 T₂ 的全部格提高 r 层，再在四列底部各加 r 根连续针。它等于在足够高度上限下对 T₂ 连做 r 次无顶破 Pin；最高格位于 r+10，恰为 Hᵣ 的顶层。

直接照着这条路线制造，会得到尾部 `P → S → P^(r+1)`，共 r+2 次 Pin。这里起点的两个辅助塔必须分别补到当前 Hᵣ−1、Hᵣ−2，不能在改变 H 后直接沿用原十二层短代码。

下面给出更短的合法起点 Bᵣ：**对所有 r≥2，仍只需 P→S→P 即得到 Lᵣ。** 高度上限与长路线相同，没有额外借用更高空间。

<a id="s06-10-h6"></a>

### 3. Bᵣ 的统一定义及制造凭据

以下层号从0开始，未列出的格为空，空区间不放格。N 取 Su，C 取 cr。

| 列 | 针 | 普通格 N | 晶体 C |
|---|---|---|---|
| q0 | 0…r−3 | r−2、r+3、r+4、r+6 | r+5；r+7…r+10 |
| q1 | 0…r−1；r+5 | r、r+7 | r+1…r+4 |
| q2 | 0…r−1 | r、r+1、r+2 | r+4…r+9 |
| q3 | 0…r−1；r+4…r+7 | r、r+8 | r+2、r+3 |

q0 底部是这次换起点的关键：原先需要最后释放到地面的那颗 N，现在直接放在 r−2 层，下方预制 r−2 根针。两次尾部 Pin 后，它恰到第 r 层，下方恰有 r 根针。r≥2 正是这个准备方式成立的条件；r=1 不在本构造范围内。

按 q0/q1 与 q2/q3 分半，两半独立静止：

- 左半的低处 q0 N 由自身针前缀或地面托住；q1 的 C 塔由第 r 层 N 托住。q0 第 r+3、r+4层 N 横向接在 q1 塔上，再托住 q0 保留 C 与上塔。q1 第 r+7层 N 接在上塔旁。
- 右半的 q3 双 C 通过 q2 第 r+2层 N 接到较低连续 N/针。q3 的四根非触地针和第 r+8层 N，再托住 q2 辅助高塔。

四列满足列条件 A。C 正下方有空隙的活动落点只有 q2 的第 r+2层 N、q3 的第 r 层 N；前者正下为 N，后者正下为针。两者都有直接下方阻挡。因而两半都由[任意层直接释放](02-four-quadrants.md#s02-15)给出制造凭据，再 Swap 得到 Bᵣ，不把“静止”单独当作可制作证明。

<a id="s06-10-h7"></a>

### 4. 三步路线的逐项结果

**第一次 P：** q0 上塔 r+7…r+10 触顶，全删。q1 低塔与 q2 高塔的辅助分量最高为 r+9，本轮保留并升到顶层 r+10。

原 q0 第 r+6层 N 升到 r+7；原 q1 第 r+7层 N 升到 r+8，仍由 q2 辅助塔横向托住。

**一次 S：** 上料为 q0/q1 双 N，短代码 `SuSu----`。它落在 r+9 层，此层已有 q3 的旧 N 和 q2 的 C。

**第二次 P：** q1/q2 辅助分量触顶删除。新 q0/q1 双 N 与旧 q3 N 同在 r+10 层，由 q3 针链支撑，形成目标顶条。其余关键格为：

- q0：针前缀长度 r，低 N 在 r；其上 N 在 r+5、r+6，C 在 r+7，N 在 r+8。
- q1：针前缀长度 r+2，低 N 在 r+2；原非触地针落到 r+3，悬空 N 落到 r+4。
- q2：针前缀长度 r+2，三个 N 在 r+2、r+3、r+4，辅助 C 全删。
- q3：针前缀长度 r+2，N 在 r+2，双 C 在 r+4、r+5，四根针在 r+6…r+9，顶条 N 在 r+10。

这些格逐项等于 Lᵣ。与直接抬升路线相比，准备 q0 的底部针前缀省去了 r 次尾部 Pin。

<a id="s06-10-h8"></a>

### 5. 具体代表：r=2，四象限十三层

这个例子中，直接抬升路线为 `P→S→P→P→P`，新路线为 `P→S→P`。两条路线都在 H=13 内完成。

<a id="s06-10-h9"></a>

### 6. 整体抬升族的最少 Pin 数

对本页 r≥2、Hᵣ=r+11 的 Lᵣ，第3至4节已经给出两次 Pin 上界。下面补零次和一次的排除，得到精确值：

`min Pin(Lᵣ) = 2，r≥2。`

零次不可能：K 下料只能追加，故目标 q0 第r+5层 N 已在起点。标准切向中它没有同层邻居及正下支撑；另一切向中，它与 q3 第r+4、r+5层 C 构成的组下方为空。两种切后半形都不合法。

反设只用一次 Pin。以下逆推取自[T₃ 下界](#s06-04)第2至5节，但显式保留参数 r；不假设增加底针能保持旧下界。

- 保留 C 的来源为 q0 第r+6层、q3 第r+3及r+4层；q0 固定 N 在r+4、r+5。
- 保留双 C 的输出支撑迫使 q2 三个 N 的来源依次为r+1、r+2、r+3，全部固定。q3 低 N 不能在r+2层粘住它们，故来源为r+1，正上r+2层为空。
- q3/q0 半形内保留组下方为空，切向被排除。标准切向则迫使 q1 第r+4层辅助 C，向上通过r+5层转到 q2 第r+6层。它必须融合删除。
- 原右半形 q2 第r+4层为空，辅助塔只能经 q3 获得支撑。其上部 N 若低于r+9，既不会截去，也达不到目标屋顶r+10；若高于r+9，至少五根旧针会保留，超过目标四根。含针环的较低 N 至多在Hᵣ−3=r+8，也不能成为目标。因此原 q3 必有r+5…r+8四针和r+9屋顶 N；q2 辅助 C 连续到r+9。
- 旧 q3 屋顶阻止最后才补 q0/q1 屋顶；移动普通块也没有允许的直接落点。因此三份屋顶的来源均为r+9层。其下所有目标 N/针已存在。
- q1 非触地针只能在r+6层，U/V只能分占r+7、r+8层。U在上会失去全部支撑；V在上若预置于左半形，需要一颗被屋顶和U隔离、不能删除的 q0 C，若后补又没有正确落点。

因此一次 Pin 也不成立，完成这个无限族的下界。该结论只确定 Pin 总数，没有同时声称每个 r 都强制同一最简操作词。

r=1 是另外一个结果：H₁=12，L₁就是T₃，其[最少 Pin 数为3](#s06-04)。所以这一族并不随着整体抬升次数持续增加必要 Pin 数：r=1需要3次，r≥2反而只需2次。各 r 使用本页规定的高度上限，不能据此声称固定参数下任意目标的复杂度都不单调。

<a id="s06-10-h10"></a>

### 7. 可行Pin总数没有空档

进一步固定r≥2、Hᵣ=r+11，允许任意合法最后Swap来源及任意单层Stack。可实现Lᵣ的尾部Pin总数恰为：

`{2,3,…,r+2}`。

零次和一次已由第6节排除。q3最低保留C在r+4层，地面针前缀长r+2；[保留C与地面针计数上界](01-foundations.md#s01-08)给出p≤max(r+2,(r+4)−2)=r+2。以下覆盖区间内的每个整数，不靠插入恒等Pin。

<a id="s06-10-h11"></a>

#### 7.1 除r+1外的次数

对2≤p≤r，置s=r−p+2≥2。先按第3至4节制造Lₛ，但全过程使用Hᵣ：只把来源q0辅助上塔延至Hᵣ−1，把q2辅助塔延至Hᵣ−2。两塔仍分属不同融合分量，各自原半形支撑仍在；第一、第二Pin的删除时刻不变，输出仍为Lₛ。随后做p−2次不截格的Pin，恰得到Lᵣ，操作词为`P S P^(p−1)`。

p=r+2时，同样延长原T₂来源的两塔，先做PSP取得T₂，再做r次Pin。全程最高成品层不超过r+10。剩下的p=r+1不能用s=1套用，因为L₁没有两次Pin配方。

<a id="s06-10-h12"></a>

#### 7.2 用临时针环实现r+1次Pin

以下来源与r=2的[连续三次Pin目标](#s06-09)共用低部：

| 列 | 针 | 普通格N | 晶体C |
|---|---|---|---|
| q0 | 无 | 2、4、5、7 | 保留6；辅助8…10 |
| q1 | 0 | 1 | 辅助2…5 |
| q2 | 0 | 1、2、3 | 辅助5…Hᵣ−1 |
| q3 | 0；11…Hᵣ−2 | 1、10、Hᵣ−1 | 保留3、4 |

左半01稳定。右半23的高塔用q3的N10、针11…Hᵣ−2、顶层N形成内部支撑环。低双C由q2低N托住。所有列满足完整S判据：q1/q2/q3触地针，q0最低C以下至少两个空位；因此完整两列制造定理给出同Hᵣ的真实两半来源。r≥2保证三层环至少容得下N10、针11、N12。

先连续执行r+1次Pin。第一次删除q1/q2融合塔并截去最上N，q0低N落地；q3 N10改由左塔C8…10的顶部接住。之后每轮针链从上面被截短。第r+1次时，左塔顶部及这枚临时N同到输入顶层，两者同时被删。q0低N已经得到r根地面针。此时产物Eᵣ为：

| 列 | 针 | 普通格N | 晶体C |
|---|---|---|---|
| q0 | 0…r−1 | r、r+5、r+6、r+8 | r+7 |
| q1 | 0…r+1 | r+2 | 无 |
| q2 | 0…r+1 | r+2、r+3、r+4 | 无 |
| q3 | 0…r+1 | r+2 | r+4、r+5 |

再用五次单层Stack：

1. q1、q3各一根针，分别落在r+3、r+6。
2. q1一枚N、q3一根针，分别落在r+4、r+7。
3. q3一根针，落在r+8。
4. q3一根针，落在r+9。
5. q3/q0/q1相连的三N横条，由q3最高针托住，统一落在r+10。

结果逐格为Lᵣ。这给出`P^(r+1) S^5`，填满了最后一个次数。第一、第二步各有两个独立上料组，允许在同一份单层上料中分别落到不同高度。

这个精确次数集合否定了利用Lᵣ“中间缺少某个Pin总数”来同步多个模块的方案。它没有说这些词都最短，也没有说一般目标的Pin次数集合总是区间。所有Eᵣ本身另有[恰需三次Pin的证明](#s06-09-h9)，同H内均可改用PPP；增加后续屋顶和针链得到Lᵣ后，最少Pin数反而降为2，说明追加目标材料可能提供新的来源支撑。

<a id="s06-10-h13"></a>

### 8. 任意序列命题现在还缺什么

无顶破的开头抬升可以移入半形准备；对T₂的整体抬升族，r≥2的最少Pin数为2，全部可行次数恰为2至r+2；r=1的T₃则恰需三次。这些结果解决了该族的Pin计数，不证明任意给定正整数序列都不可能被其他结构强制。

剩下的核心是可重复的支撑交接，以及跨所有合法起点的次数和顺序下界。[T₃的最短词已独立证明为P→S→P→P](#s06-05)，但最后一次Pin只截盖并抬升，没有产生新的支撑交接。这个完整实例仍不能直接升级为任意交替次数序列的证明。

证据为 K 下料的落点约化、半形制造定理、列内次序与顶破的人工推导。没有运行物理模型、目标搜索、枚举、测试或游戏；短代码为表格的文字转写。

## 06-11 四象限不能强制三次Pin逐次交替

原文标识：`general/forced-sequence-obstruction.md`。

固定四象限，制造上限H任意但准备与尾部共用同一个H。P表示Pin，S表示一次单层Stack；交换起点和上料均可任意合法预制，主干旋转吸收到各输入朝向。只计最后Swap后的操作。

**定理：若某个目标有路线`P S^b P S^c P`，其中b,c≥1，则它另有一条路线，使用不更多的Pin，并且不再需要这三个Pin之间的两段Stack同时存在。** 单层上料限制保持；新路线的Stack总数至多增加1。给这段路线接上任意相同后缀，结论仍成立。

因此，在“所有实质制造路线都必须依次保留这些阶段”的意义下，四象限任意高度的任意序列猜想为假。可以取序列`(1,1,1,1,1,1)`，即`P S P S P S`作为不可能被强制的词。这里的反例是一个对任何高度、任何目标都不能强制的序列，不是某个具体候选制造失败。

这项结论不等于“没有目标的某条最短配方恰为PSPSPS”。新路线可能多用一次Stack，故按机器操作总数最小化的版本必须另证。六象限及允许象限数随序列增加的版本也不由本页解决。

<a id="s06-11-h1"></a>

### 1. 三个连续Pin中至少一个不向下破坏晶体

“连续”按Pin的出现次序计数，中间允许任意Stack。采用[顶层几何中的D/L定义](07-reductions.md#s07-01)：D在输入最高两层有同列CC，顶破会向下传播；L没有这样的CC。

反设前三个Pin都是D。以第一个Pin前的坐标计：

- 第一次在a列有C(H−2)、C(H−1)。
- 第二次的幸存分量在b列有C(H−3)、C(H−2)。它不能与第一次同列或相邻，故b=a+2。
- 第三次在c列有C(H−4)、C(H−3)。它必须与第二次相对，故c=b+2=a。

但第三组的C(a,H−3)与第一组的C(a,H−2)上下相邻，原本已经融合，第一次就会一起删除。矛盾。高度不足时，所需格位越过地面，更不可能。

这个证明没有限制中间堆叠次数；上料不能带入保留C，不能补回已经消失的分量。

<a id="s06-11-h2"></a>

### 2. L中的孤立顶晶体可以预先换成普通格

L只可能截去最高层的单层C分量。把这些分量在原交换起点中改成N，非针连接和阻挡高度保持，晶体融合到低处的关系不变；它们在同一个L时刻作为顶层N被截去。

[合法顶盖替换](07-reductions.md#s07-01-h6)已经给出两份半形的制造证书。因而这个替换允许改变真实起点，最终目标和Pin/Stack操作词不变。

以下可以把L视为完全不删C的抬升：截去顶层N/P，提高其他格，并按原地面占用补针。四象限K闭包保证它不触发较低材料下落。

<a id="s06-11-h3"></a>

### 3. 把L前的单层堆叠搬到L后，最多增加一次Stack

设X为合法四象限状态，接下来先做m次单层Stack，再做L。堆叠不改变X的C，所以X本身也满足L的无破坏条件。

已有[追加闭包交换](07-reductions.md#s07-13-h3)给出可达等价。本节保留单层次数界：

`S^m L  ⇒  L S^r`，其中`0≤r≤m+1`。

记G为原m次堆叠新增的地面占用列。任何列若能被新料占据地面，它在X中必整列为空。某列一旦被占用，就不能再往它的地面插料。

在L(X)之后，先用一份单层纯针上料，在G中各放一根地面针。G为空时省去这步。这些针就是原路线先落地、后执行L所产生的新增地面针。不同列的针彼此独立，可在一次Stack中同时补齐。

再依次处理原每份单层上料：

1. 去掉C。单层上料的C不进入堆叠结果，去掉后保留相同的水平N块和单针。
2. 去掉原落点在H−1层或更高的整块，它们本来不能通过L保留。
3. 将其余块合为一份单层上料，在新路线追加。没有保留块时省略该步。

原本落地的块现在落在新增针上，恰在第1层。其他保留块的原阻挡整体提高一层，落点也恰提高一层。提前补G的针不会挡住更早的保留块：如果某列此前已有新块，后来就不可能才在该列新增地面占用。

同一份原单层上料的不同块不共列；去掉整个块不会把其余块连接起来。因而它们仍能合成一份单层上料，无需按块分别计步。归纳得到与原S^m后L逐格相同的输出，最多使用m份改造上料及1份补针层。

如果G为空，新路线至多m次Stack，连总操作数也不增加。G非空时，多出的补针层不能无证省掉。

<a id="s06-11-h4"></a>

### 4. 三个位置穷尽全部路线

取一条`B → P₁ → S^b → P₂ → S^c → P₃ → T`，b,c≥1。第1节保证P₁、P₂、P₃中至少一个是L；先作第2节的合法顶盖替换。

<a id="s06-11-h5"></a>

#### P₁为L

第一次无破坏抬升可以分别在两份半形中完成，再交换，得到合法B′，恰等于L(B)。尾部变为：

`B′ → S^b → P₂ → S^c → P₃ → T`。

Pin少一次，Stack数不增加。准备阶段的Pin不计入尾部，制造上限仍为H。

<a id="s06-11-h6"></a>

#### P₂为L

对P₁后的状态应用第3节：

`B → P₁ → P₂ → S^r → P₃ → T`，其中`r≤b+c+1`。

前三个Pin仍存在，但前两个之间没有Stack。该改写在P₂后重现原来S^b、P₂、S^c之后的精确状态，所以后面的P₃无需改变。

<a id="s06-11-h7"></a>

#### P₃为L

同理得到：

`B → P₁ → S^b → P₂ → P₃ → S^r → T`，其中`r≤c+1`。

后两个Pin之间没有Stack，最后补料仍是单层。

这三个位置覆盖所有可能。新的路线可以有不同上料；没有增加Pin，没有提高H，也没有依靠恒等操作填充词长。若其中某些Stack可删，继续删去也不会重新产生被消除的交替间隔。

<a id="s06-11-h8"></a>

### 5. 对原序列猜想的结论与量词边界

令强顺序要求为：给定正整数序列后，存在目标，使更换任意合法交换起点和上料，都不能绕过其中指定的Pin/Stack阶段顺序。它比“存在该配方”强，也比“存在一条具有该词的最短配方”强。

取`(a₁,b₁,a₂,b₂,a₃,b₃)=(1,1,1,1,1,1)`。任何实现该词的四象限路线，其前三次Pin均落入第4节的一种情况。保留最后S后，替代路线要么只剩两个Pin，要么至少一对Pin之间不再有Stack。因此不存在被这个词强制的四象限目标。这个反例不随H增大而消失。

须分别保留以下命题：

| 命题 | 本页结论 |
|---|---|
| 四象限、任意H，每个序列都能成为不可绕过的阶段顺序 | 已证伪 |
| 四象限、任意H，每个序列都能成为某目标的最短总步数操作词 | 未解决；搬移可能增加1次Stack |
| 任意序列可通过选择更大的偶数象限数与H来强制 | 未解决；六象限允许DDD，第1节不成立 |
| 存在目标必须顶破三次不同晶体塔 | 仍是独立问题；本页只约化含三次Pin的交替词 |

证明强顺序版本为假，无需先解决所有高层支撑交接，也无需构造一个全局三次顶破实例。反过来，不能用这个四象限反例宣称所有偶数宽度的存在性猜想为假，更不能把多一次Stack的路线冒充更短总步数路线。

<a id="s06-11-h9"></a>

### 6. 六象限能实现任意有限D/L时钟，但不强制这个时钟

不能用四象限的DDD排除直接推广到更宽图形。更强地，六象限就能实现任意有限的D/L词，而这些实例的最终目标全部可以零尾Pin制造。下面给出同一构造，不增加目标分类。

给定长p≥1的D/L词，D出现于`1≤τ₁<⋯<τₘ≤p`。取`H=p+3`，只使用q0、q2、q4；奇数列全空。三根柱都以第0层C、第1层N开头。对第j次D，在`q=2((j−1) mod 3)`放置两颗辅助C，原层号为：

`H−τⱼ−1，H−τⱼ`。

每列从地面到本列最高辅助C之间的其他位置全部填N；没有分配辅助C的列只保留底部CN。底部保留C可取cr，辅助C可取cc；不同颜色不是融合隔离的理由。

<a id="s06-11-h10"></a>

#### 来源确实可制造

全部辅助C底层至少为2，和地面C之间有N。三个使用列两两不相邻。分到同列的两组辅助C，其删除编号至少相差3，故τ也至少相差3；两段CC之间至少有一层N，不会融合。

每列都是连续触地的N/C紧列，可按[紧列构造](01-foundations.md#s01-03-h3)独立制造。012半面放q0、q2，345半面放q4；各柱独立接地，拼接和半切不会删除任何目标C。两半Swap得到合法起点，不需要更高上限或额外尾部操作。

<a id="s06-11-h11"></a>

#### 连续p次Pin恰好执行指定的D/L词

辅助分量j在第i次Pin输入中的最高层为`H−τⱼ+i−1`。因此它在且仅在i=τⱼ时触顶。该列中比它更高的辅助C此前已经删除；删除后只有高处N向下补齐空位，不会使较低辅助C移动。较低的全部材料仍为同列连续接地前缀。由此归纳，每个辅助分量保持原高度加已执行Pin数，直到指定时刻整段CC被顶破。

i不是任何τⱼ时，没有辅助C触顶。地面保留C在第i次Pin输入中仅位于i−1层，最高为p−1，低于H−2=p+1，故也不造成D。原列一直紧密，每次L只有截顶、抬升和补针。因此真实D/L词恰为给定词。特别地，取所有τⱼ=j，就能在固定六象限中执行任意多次连续D。

<a id="s06-11-h12"></a>

#### 同一最终目标具有零尾Pin路线

所有辅助C到第p次Pin已删除。每列仍连续，底部是p根针，其上是原地面保留C，再上方有一层或两层N；记各列实际层数为r_q∈{1,2}。第一层N来自原第1层，始终受保留C支撑；H=p+3保证它不会截去。

所以最终每个非空列都形如`P^p C N^{r_q}`。可以先分别制造地面C，执行p次准备阶段Pin，再加r_q层N，最后拼两半并Swap。所得目标逐格相同，最后Swap后不需要Pin或Stack。这也符合[地面晶体来源的零尾Pin改写](01-foundations.md#s01-08-h9)。

这证明：即使在六象限中实现了任意多座独立塔、任意长连续顶破，乃至任意预定D/L时钟，也还没有触及原猜想要求的全局必要性。后续构造必须额外阻止这种重新准备来源的绕过；仅继续增加塔数不能作为证明任意序列的归纳步骤。

<a id="s06-11-h13"></a>

### 7. 六象限中，非顶破Pin也可能不能移过一次Stack

第3节不能只把“四象限”改成“偶数象限”。下面给出同一合法交换起点X下的反例：`S P`可行，但任何`P S*`都不能达到同一目标。P输入没有触顶C，且原路线在P前已经稳定；障碍来自此前一次Stack改变了地面占用。这个例子用于否定无条件重排，不作为全局强制序列实例。

<a id="s06-11-h14"></a>

#### 两份真实半形与交换起点

取六象限、H=10。N取Cu，低处C取cc，高处R取cr；R也表示晶体，字母仅区分标签。未列层为空。交换起点X为：

```text
 z   q0 q1 q2 q3 q4 q5
 8    .  N  R  .  .  .
 7    .  P  R  .  .  .
 6    .  N  R  .  .  .
 4    C  N  N  C  N  N
 3    C  .  N  C  .  N
 2    C  N  N  C  N  N
 0    N  .  .  N  .  .
```

012半形的低处是[三列无针环](01-foundations.md#s01-04)，高处是q2三连晶与q1的N/P/N针环；两者分别静止。345半形是第二份低处无针环。每列满足A。012半形从左剥离q0并在右外侧加全N柱后，低处各N块经q2接到助手，高处晶体也接到助手；再剥离q1仍静止，随后进入普通基例。因此[递归脚手架](03-general-construction.md#s03-04)给出同H制造证书。345半形使用已有三列环证书。

两份半形自身稳定，Swap预切不改变它们。拼合后，低处两外组通过第2、4层合并；第3层q2/q5的内块分别接到另一半的C，也被并入。低处成为一个最低在第2层、正下整层空的无外部支撑组。高处R针环独立，不受这次合并影响。

<a id="s06-11-h15"></a>

#### 先Stack再Pin

S采用纯晶体单层，只触发一次F，不添加N/P。低处六颗cc碎掉，高处三颗cr全部保留。结果Y的低部是：

```text
 z   q0 q1 q2 q3 q4 q5
 2    .  N  N  .  N  N
 1    .  .  N  .  .  N
 0    N  N  N  N  N  N
```

第2层原来的q1/q2、q4/q5两块先落地；第3层两个单N落到第1层；第4层两块落到第2层。高处针环仍在6…8层。Y稳定，最高C在8层，不在H−1=9层。

随后P不顶破任何C，只抬升并给六个原地面格补针。目标T的高处针环移到7…9层，低部为：

```text
 z   q0 q1 q2 q3 q4 q5
 3    .  N  N  .  N  N
 2    .  .  N  .  .  N
 1    N  N  N  N  N  N
 0    P  P  P  P  P  P
```

<a id="s06-11-h16"></a>

#### 先Pin后堆叠无法补回这个结果

从X先P，同样没有顶层C破坏，但本次补地面针时，只有q0、q3原本触地。低处不稳定组随后下落碎晶：q1/q2、q4/q5的底块仍落在地面。于是P(X)的第0层为：

`P N N P N N`。

此后无论堆叠多少次，已经在地面的普通格都不能移动到地面以下、被Stack删除或变成针。因此q1、q2、q4、q5永远不能变成T要求的地面P，`P S*`全部排除。高处cr来源还锁定从这个X到T恰好一次Pin及零净旋转；不能多Pin后再用上料补回同位置cr。

这里不是“多补一层针就好”。四象限证明中的G来自向整列空位追加的新料，可以在前移P后先Stack地面针；本例的新地面N来自旧下料内部的下落，而且q2上方还保留cr。Stack既不能穿过保留晶体插针，也不能覆盖已落地N。

<a id="s06-11-h17"></a>

#### 全局来源边界

T仍有零尾Pin路线。沿012/345切向，低部均为独立稳定的N/P，高处针环完整留在012半形；012按前述脚手架方向可制造，345直接逐层制造，再Swap即得T。故本例否定的是对固定输入无条件应用`S L⇒L S*`，没有证明目标全局必须先S后P。

它指出后续必须同时处理两项：重新结算是否改变地面占用；换起点是否能提前准备新增的针前缀。只检查P输入是否稳定、是否有触顶C，均不足以证明可以跨越此前的Stack。

<a id="s06-11-h18"></a>

### 8. 任意偶数宽度下可以保留的稳定路径重排

仍令L表示最高两层没有同列CC的Pin。对任意偶数n，设合法路径

`X₀ → S₁ → X₁ → … → Sₘ → Xₘ → L`

满足每份上料为单层，而且X₀至Xₘ全部稳定；Xₘ符合L条件。那么仍有同一起点上的改写

`S^m L ⇒ L S^r，r≤m+1`。

证明不再假设K。由于每个Stack输入稳定，旧下料不动、不失C；全部Xᵢ具有同一批、同位置的C，因此都符合L条件。L删去的最高层非针组只占一层，不可能托住低层；故对每个Xᵢ，L都是截顶、抬升及按地面占用补针，输出也稳定。

新增地面占用G只能来自上料，因为旧格始终不动。某列在某次上料中第一次接到地面料，意味着此前整列空；否则上料无法穿过旧格。按照第3节，先在L(X₀)补一份G的地面针层，再逐份过滤原单层上料，删C及原落点≥H−1的整块，保留其余块。

第i次改造上料之后，得到L(Xᵢ)，外加G中原路径尚未落地的那些列的一根预置针。这些列此时原本整列空，预置针不会与旧非针组粘连，也不会改变其他列的支撑。因此每一步仍稳定，下一次Stack不触发额外下落；原保留块的落点均恰好提高一层。第m步后没有尚未落地列，输出逐格等于L(Xₘ)。最多m份过滤上料加一份针层，证毕。

该定理允许稳定的无针环，不要求支撑通向地面或含针环。第7节恰有不稳定X₀，所以没有被错误地纳入。它也不负责把初次L移入交换前：那一步还须核对两份真实切后半形各自稳定，不能从完整X₀稳定反推。
