## 05-01 可制作图形的任意有限次重新结算级联

原文标识：`general/gravity-cascade.md`。

采用偶数象限、任意高度的既有局部规则。N为普通块，C为合法同色晶体，`.`为空；层号和列号均从0开始。F表示重新按当前格位分组并执行一次重力结算。F可用“堆叠一层纯晶体”实现：上料晶体全部碎裂，不增加普通格或针，见[堆叠进展量](01-foundations.md#s01-07)。

**对任意整数k≥1，存在可制作的S，使前k次F每次都改变图形，第k次之后稳定。** 以下给出n=4k+6、H=6k−1的充分构造。k=3对应十八象限、十七层。这里的“需要k次”指从给定S反复施加F到达稳定态；不是最终成品在所有加工配方中的最少堆叠数，也没有证明n、H最小。

<a id="s05-01-h1"></a>

### 1. 逐级加宽的支撑环

把级号j从上到下编为1至k，定义：

- 第j级底层h_j=2+6(k−j)。
- 右晶体柱r_j=2j+2，内部普通块列b_j=2j。
- 左晶体柱始终在q0。

第j级占三层，格位为：

| 层 | 晶体 | 普通格 |
|---|---|---|
| h_j+2 | q0、q(r_j) | q(b_j)、q(b_j+1) |
| h_j+1 | q0、q(r_j) | q(b_j) |
| h_j | q0、q(r_j) | q1至q(r_j−1) |

未列格为空。两根三C柱经底部普通横条连成框架G_j；顶层的两颗N也连到右柱。中层q(b_j)的单N为独立组B_j。G_j的顶帽受B_j阻挡，B_j受G_j的底条阻挡，构成不触地的无针支撑环。

在地面补q0与q(2k+2)两颗N。每个非顶级框架，即j=2至k，另在q0的h_j+3、h_j+4各补一颗N；h_j+5保持空。这些N直接受下方晶体柱支撑，但与上一框架之间留有一格空隙。

称所得图形为D。所有框架分别互阻，补格及地面格也稳定，所以F(D)=D。

<a id="s05-01-h2"></a>

### 2. D确实能从基础原料制造

D只占q0至q(2k+2)，恰在n/2=2k+3列的标准半面内。先核对[列条件A](03-general-construction.md#s03-03)：

1. 没有针，针条件为空。
2. q0最低C在第2层，最近下方格为地面N。上下两段三C柱之间为`N N .`，有两个普通隔断，且下方C的正上方非空。
3. 最宽的底级右柱q(2k+2)下方有地面N；其余第j级右柱恰处在下一级内部块列b_(j+1)，下方最近非空格是下一级顶帽N。每根右柱仅有一段连续C。
4. 其他列没有C，条件自动成立。

采用[递归外侧脚手架](03-general-construction.md#s03-04)的固定右端剥离。第一步移去最右列，给q0左侧补全高N柱。下面证明此方向的全部中间半形稳定：

- 保留原列q0至qt，并在左侧补足已剥离列数的全高N柱。q0所有非针格都接到全高N柱，因此每一级仍保留的左晶体柱及底条有地面支撑。
- 若某级右柱仍在，整个框架经底条连到左柱，其内部N正下方也有底条。
- 若右柱已经移去，残余顶帽只要非空，就仍含q(b_j)，正下方有B_j；B_j正下方是已受支撑的底条。若q(b_j)已被剥离，位于它右侧的整个顶帽也早已移去，不留下悬空尾段。
- q0的补格及地面格保持支撑。最终剥离q0后只剩全高N柱。

所以每个中间半形都稳定。由该算法的反向恢复定理，逐次调用同一个角程序、交换和去助手，就能从无晶体基础料制造D。准备全过程使用同一n、H，不需要超过H的辅助塔。

<a id="s05-01-h3"></a>

### 3. 制造级联起点S

对D堆叠q1的一颗普通N。q1的最高格是第1级的底条，高度h_1；顶帽与中层原来均不占q1。因此上料落在h_1+1，与q0的C和q2的B_1同时相邻。

这次堆叠内，旧G_1、B_1仍按原组互相支撑；新增接触不会在本次结算中合组。输出S等于D加这一颗N，全部18颗晶体在k=3时仍保留。下一次重新分组才把G_1、B_1与新增N并成一个无外部下方支撑的组。

<a id="s05-01-h4"></a>

### 4. 为什么每轮只推进一级

归纳假设：第j轮开始时，前j−1级晶体已消失，第j级已被上一轮的横条接通；更低级仍保留原来的两个互阻组。

第j级底层是h_j，正下方h_j−1在框架各列都空。对q0，上一较低框架的补N最高只到h_j−2。因此合并组可开始下落，两根三C柱共六颗晶体全部碎裂。

若j<k，第j级原底条是连续普通块

`I_j = q1至q(2j+1)`。

它落向下一级。下一级顶帽和内部块从q(2j+2)才开始，q1至q(2j+1)在其顶层和中层全空。下一级底条却占满这些列，所以I_j恰好落在h_(j+1)+1。

落稳的I_j左端邻接下一级q0的中层C，右端邻接下一级B_(j+1)。这条新横条接通G_(j+1)与B_(j+1)，但当前F不会合并新接触，故下一级的六颗C本轮全部不动，留到下一轮才碎裂。

还须排除其他碎片提前越级：

- 第j级其他普通碎片，以及更高各级留下的普通格，除q0补格外，都位于I_j列区间内。第j级碎裂前，其底条挡住它们；碎裂后，下一级底条挡住它们。它们不能穿过这条连续底条去触碰更低级。
- 第j级原底条在上述列内低于其他落料，同列格位不穿透，故不会被别的上方碎片抢占更低落点。
- q0补格只沿q0下降，且被下一根保留的左晶体柱阻挡。它们不能横移到内部块列，也不能把隔着至少一列空位的两个旧组接通。
- 新横条只增加接触和阻挡；本次物理组不因新接触收缩，原有低级支撑环保持。

因此每次F恰好删除当前一级的六颗晶体，并为下一级建立下一轮的合组条件。最后一级碎裂后全图只剩普通格；本次下落已使各水平块落稳，重新分组最多合并同层普通块，不会把低一层的阻挡变成组内格，所以此后F不再改变结果。

由归纳得到：

`c(F^t(S)) = 6(k−t)，0≤t≤k；F^(k+1)(S)=F^k(S)`。

前k轮的晶体数每次严格减少，所以少执行任何一轮都尚未到达稳定态。对任意给定k，构造都有限，证明了在n、H可增长时，必要结算次数没有统一常数上界。

## 05-02 双半形交换后的三次下落及任意有限级扩展

原文标识：`general/alternating-cascade.md`。

本页核对用户提供的20象限、21层完整短代码及交换前短代码。完整输入保存于[source.txt](../../general/alternating-cascade/source.txt)，交换前原料保存于[precut.txt](../../general/alternating-cascade/precut.txt)。均为21行、每行20格；完整输入的前后十列逐行相同。层号、象限号均从0开始。

结论：按既有游戏局部规则，完整输入X连续三次重新结算后稳定，保留晶体数为40→28→16→4；顶部四颗晶体始终保留。两半交换的来源能够解释，且可补出从基础料制造的通用构造。把重复单元及准备区一起扩展，可得到任意有限轮的同类构造；固定20象限仅增加高度不由本证明覆盖。顶针不能任意移位。

以下F均指一次重新分组并下落，在实体中可用Stack一层纯晶体触发。本页采用人工逐格推导及输入文本核对，没有运行物理模型、目标搜索、测试或游戏。

<a id="s05-02-h1"></a>

### 1. 每一艘船由两个互阻组组成

先看前十列中的一个单元。左柱在a，底层在h，局部结构为：

```text
             a a+1 a+2 a+3 a+4 a+5
h+3          .  .   N   .   N   .
h+2          C  .   N   N   C   N
h+1          C  .   G   .   C   N
h            C  N   N   N   C   N
```

C为红晶体cr；N为普通Cu；G为绿色普通Cg，颜色不改变连接和下落规则。两根三C柱、底部横条、顶帽和右侧三颗N连成外框A。中层G是独立组I，A的顶帽被I阻挡，I又被A的底条阻挡，所以可以悬空静止。

本例从下到上三个单元的位置是(a,h)=(0,3)、(2,8)、(4,13)。中级和顶级各在底层左边a−1处带一颗蓝色普通Cb，与左C柱相连。顶级另在(a+1,h+1)=(5,14)已有一颗Cb；它连接左C柱与绿色I，因而顶级在下一次重新分组时失去内部互阻，成为一个可下落的大组。

最上面的Cb是首次触发块。各上级底部左侧的Cb则在对应晶体碎裂后，成为下一艘船的触发块。这是几何位置的作用，不依赖蓝色本身。

<a id="s05-02-h2"></a>

### 2. 交换前短代码怎样产生完整输入

交换前原料记为P。它实际占q0至q10，共十一列；q10是要在半切时去掉的青晶体支柱，不是成品半形的一部分。红晶体与青晶体都按邻接融合，颜色不会阻止融合；本原料靠普通格和空位隔开它们。

保留q0至q9、删除q10至q19时，P中全部青晶体cc通过融合路径连到被删q10，因此一起删除。红晶体不属于该融合分量。随后发生的非平凡位移只有：

| 材料与列 | 原层 | 落点层 | 原因 |
|---|---:|---:|---|
| Cu，q0及q4 | 2 | 0 | 底部青晶体消失 |
| Cu，q6 | 7 | 0 | 该列下方青晶体消失 |
| Cu，q8 | 12 | 0 | 该列下方青晶体消失 |
| Cb，q5 | 17 | 14 | 青晶体释放它；q5第13层底条接住它 |

三个船框在本次半切结算中仍按原外框A和内部I互相支撑。蓝块落到第14层形成的新连接，本次不合组。q4第16、17层的两根针保持原位，继续托住第18层普通横条及上方原料。其余保留格位不变。

得到的Y逐格等于X的前十列。第二份原料旋转十个象限，保留其后十列，可得Y的半圈旋转。因此：

`Swap(P, Rotate(P,10))的出口0 = X`。

交换器先分别半切结算，然后拼合，不在拼合后再额外下落。这一点同时保留了已经接通的两个顶级船框，以及下一节的顶部支撑环。

<a id="s05-02-h3"></a>

### 3. 顶部结构为什么能一直保留

交换前，每个半形的第18层有一条普通横条，受两根针支撑。上面两层为：

- 第19层：q0至q4的N，以及q9的C。
- 第20层：q4至q8的N，以及q9的C。

两半交换后，q9的两C柱经第19层q10至q14的N构成组U，并带第20层q4至q8的顶帽；q19的两C柱经环绕边界连到第19层q0至q4，构成组V，并带第20层q14至q18的顶帽。

U在q4、第20层被V在第19层的格阻挡；V在q14、第20层被U在第19层的格阻挡。二者互相支撑。第18层整圈N、针和下面的船即使随后下落，也不会破坏这个环。后续普通碎片全部低于这两层，不会再把U、V连接成同一组。

因此最后保留的是这四颗顶部晶体，不能把本例描述为晶体全部消失。

<a id="s05-02-h4"></a>

### 4. 三轮分别发生什么

第1轮开始时，两个顶级船均已被Cb接通；中级和底级仍各自保留外框及绿色内块两个组。

1. 顶级六颗C在每个半形中碎裂。原第13层q3的Cb变成单格，穿过中级q3的空隙，落到第9层，被第8层底条接住。它连接q2的C与q4的绿色块。中级在本轮仍按旧组互阻，留到下一轮才碎。
2. 第2轮，中级各六颗C碎裂。原第8层q1的Cb落到第4层，连接底级q0的C与q2绿色块。底级本轮仍按旧组互阻。
3. 第3轮，底级各六颗C碎裂。所有普通块和针落稳，上方U、V继续互阻。再次结算不变。

| 状态 | 剩余C | 第18层原整圈N横条所在层 |
|---|---:|---:|
| X | 40 | 18 |
| F(X) | 28 | 16 |
| F²(X) | 16 | 14 |
| F³(X) | 4 | 10 |
| F⁴(X) | 4 | 10，全部格位保持 |

其中普通条的高度由后文的落料阶梯逐层计算。针不会横向粘连，因此不会把上方横条、下方碎片和船框合成一根竖直实体。

<a id="s05-02-h5"></a>

### 5. 最低船的高度是实质条件

每艘船右侧a+5列有三颗普通格。船框碎裂后，它们变成三个单格沿该列下落。在最高船的右侧q9、q19，下面原来没有地面格，所以形成第0、1、2层的三格小柱。

q9紧邻下一半形的q10，q19又环绕邻接q0。这些位置恰靠近另一半形最低船的左柱。最低船从第3层开始，小柱最高只到第2层，没有同层接触，不会在下一轮分组时把最低船锚到地面。

若把整个下部结构下移一层，让最低船从第2层开始而保留同样的落料机制，前一轮形成的小柱就能在第2层接到最低船左C柱。下一次分组后该框架已有地面支撑，原来的逐级碎裂证明失效。因此“最低船要足够高”不是装饰性的经验；本构造的三层离地设置给出了明确的防接触界，但不是任意结构的最小高度定理。

其余独立落料也受控：右柱正上方那颗N落到同列地面N上，形成最高第1层的低柱；跨列横条与两格帽会被下一艘船的右侧或已有横条挡在船顶以上。不能只检查触发蓝块而忽略这些普通碎片。

<a id="s05-02-h6"></a>

### 6. 顶针位置不能任意选择

两根针的首要作用确实是交换前支撑第18层普通横条，让上面的红晶体留在第19、20层。交换后的上部由U、V自己互阻，针不再是它们保留的必要支撑。

但移动针至少要同时保持以下条件：

1. 半切后的每根针在原层位有直接下方支撑，不能先掉一格再补救。顶部晶体只要被迫下落就会碎裂。
2. 不能切断需要删掉的青晶体到外侧支柱的融合路径，也不能让蓝块释放后被针挡在错误高度。
3. 每列仍满足可制作必要条件，特别是最高晶体以下的针必须属于触地针前缀。
4. 后续针和普通层的落点不为尚未触发的船增加额外固定支撑。

两个具体反例说明“任意象限”不成立：

- **搬到q0的第16、17层**：第15层q0为空，两根针没有原位支撑。青晶体被切掉后，第18层普通条也没有原位支撑，顶部红晶体会在交换的半切阶段碎掉，不能得到X。
- **搬到q7的第16、17层**：q7第15层有N，单看托住普通层似乎可行。但这会把原q7第16、17层的cc改为P。q6第17层的cc随即被隔离：下方是q6第16层Cu，左右为Cb及P，上方是Cu，不再融合连接到被切q10。它会留下并托住q5的Cb，蓝块不能落到第14层触发顶级船。

另外，把针放到q9的高层会落在第19、20层晶体下方，违反针前缀必要条件，即使某个任意网格能暂时托住上方，也不能据此认定该网格可从基础料制造。

本例的q4位置已经满足这些条件。其他位置可以连同辅助料一起重新设计，但不能只挪针就宣称等价；本页不列未经证明的全部可行位置。

<a id="s05-02-h7"></a>

### 7. 补足从基础料制造的路径

提供交换前短代码不等于已经给出全部基础料加工步骤。以下用已有通用构造补上存在性证明，不需要把青晶体当作天然原料。

在P的空白q19处加一根21层全N助手，记为P⁺。最终半切保留q0至q9时，这根助手整体被切掉；它没有C，删除它不产生新的融合碎裂。因此P⁺产生与P完全相同的Y和X。

按切向1，把P⁺划分为两份互补半形：

- **q19/q0部分**位于半面q11至q19、q0内。q0列从下到上为`cc cc N cr cr cr`，上方第18、19层另有N；整列满足A，并由q19全N助手保持原位。它属于已证稳定两列构造。
- **q1至q10部分**包含剩余原料。每列满足A；q10的连续青晶体从地面延伸到第17层。按[递归脚手架](03-general-construction.md#s03-04)从左剥离，右端补全高N柱。每个保留后缀中的青晶体仍连到q10，船的右C柱经右侧普通列接到青晶体。若左柱或绿色块被逐列移去，仍保留的帽、底条和右侧列继续由右端支撑。顶部普通条只要非空就仍含q9，正下方第17层q9为青晶体，因此顶部两层也保持支撑。最终只剩无C基例，可以反向制造全部阶段。

两份稳定半形按切向1交换，可制造P⁺。再准备第二份P⁺、旋转十个象限，按第2节交换取得X。所有操作都在20象限、21层上限内进行，沿用合法颜色结晶及无C单层供料。这里证明制造路径存在，尚未展开该输入的逐步Python配方。

<a id="s05-02-h8"></a>

### 8. 任意有限级的参数构造

令每半有k艘船，从下往上j=0至k−1：

`a_j=2j，h_j=3+5j，w=2k+4，n=2w=4k+8，H=5k+6`。

各船使用第1节相同的六列单元；j>0在(a_j−1,h_j)放Cb。地面每半在q0及所有q(a_j+4)放N。顶级的(a+1,h+1)另放首次触发Cb，(a,h+3)、(a,h+4)放P。令t=h_top+5=5k+3：

- t层：整圈N。
- 每半t+1层：本半q0至q(a_top)为N，q(w−1)为C。
- 每半t+2层：本半q(a_top)至q(w−2)为N，q(w−1)为C。

后半是前半旋转w的副本。每次有一个船级在两个半形中共同碎裂，顶上两组各两C的互阻结构保留，所以：

`c(F^r(X_k)) = 12(k−r)+4，0≤r≤k`。

<a id="s05-02-h9"></a>

#### 逐轮落料为何不越级

设当前尚未碎裂的最高船在(a,h)，它上方已有r级碎裂。每个已碎上级与它横向错开两列。除向下一级传递的单格Cb外，碎片分为低柱和互相搭住的阶梯：

| 上方第s级碎片，1≤s≤r | 所在列 | 停留层 |
|---|---|---:|
| 原底部三N条 | a+2s+1至a+2s+3 | h+3s+1 |
| 触发Cb与绿色块组成的两格条 | a+2s+1、a+2s+2 | h+3s+2 |
| 原顶帽两N | a+2s+2、a+2s+3 | h+3s+3 |
| 原内部列上方单N | a+2s+2 | h+3s+4 |

第一条被当前船第h+3层的右柱上方N接住；后续各条与前一条至少共享一列，落点依次加一，下一上级的底条又接在前级顶帽上。每列来源次序不能穿透，因而这些块不能先落到低处再从侧面锚住船。针落在这套既有支撑上，整圈N又停在所有这些格的上方，均不改变船底的外部支撑条件。

所有右侧三N低柱最高只到第2层，右柱上方单N落地后最高到第1层；各船横向错开两列，同一尾列不会叠加多艘船的三N。最低船从第3层开始，所以低柱也不会提前支撑它。每轮唯一能进入下一级左侧中层缺口的格，是上一级左边底部Cb。它把下一级接通后，本轮不重新合组，留到下一轮才碎裂。

全部k级碎裂后，同样的阶梯自地面搭起：第j级的底条、两格触发条、顶帽、内部列上方N分别停在第3j、3j+1、3j+2、3j+3层。两根针最后在第3k−2、3k−1层，整圈N在第3k+1层；仍与顶部第5k+4、5k+5层互阻晶体分离。普通格、针均已落稳，因此F^(k+1)(X_k)=F^k(X_k)。

<a id="s05-02-h10"></a>

#### 交换前原料也可随k一起扩展

为了给上面的图形提供实际半切来源，按以下规则建立单份原料P_k，仅占q0至qw。未指定格为空，同一行先放青晶体填料，再以指定普通格或针覆盖：

- 第0、1层：q0至qw全cc；第2层同样全cc，但q0、q4改为N。
- 船j的三层按第1节的六列基础单元放红C及普通格，底部左Cb保持；中层q(a_j+1)仍为空，首次触发Cb尚未落入。另把q(a_j+6)至qw填cc。
- 第h_j+3层：q(a_j+2)、q(a_j+4)为N，q(a_j+3)及q(a_j+5)至qw为cc。
- 非顶级的第h_j+4层：q(a_j+3)至qw为cc，但q(a_j+6)改为N。
- 顶级第h+3层另放q(a)的P；第h+4层改为q(a)的P、q(a+1)的Cb及q(a+2)至qw的cc。
- 上方t、t+1、t+2层取上面定义的单个半形；q w在这三层为空。

这正是给定k=3原料的参数化写法。第7节的外侧全N助手改为q(n−1)上的H层N柱，主半面改为q1至qw；切向1分成两份稳定半形、固定左剥离制造的证明逐项适用于P_k。切掉qw时全部cc连锁删除，底部Cu及逐级新右柱的低处Cu落到地面，顶级Cb落入触发位置，其他目标格由支撑环及针保留。两份旋转w后交换，得到X_k。因此该族具有制造证书，不只是一族任意网格。

这个扩展同时增加象限和层数。若要求保持20象限不变、船跨过半形边界后继续绕回，融合切线、尾料碰撞和顶部环都要另证，不能直接由本族推出。

<a id="s05-02-h11"></a>

### 9. 结论的强度

本页确认给定起点的三轮必要性，以及上述参数族恰好k轮才稳定。没有证明其最终成品的所有可能制造路径都必须含k次下落；展示并证明一条级联路径，不排除从其他准备形或通过不同加工直接得到同一成品。

第一张12象限、16层截图的准备矩阵及制造证明见[重复下落的空间界](#s05-03)。它采用单串船及Pin删除辅助晶体，推广后的充分参数为n=2k+6、H=5k+1；本页双半形结构的参数不是最小空间界。两种构造的准备过程和最终保留晶体不同。

## 05-03 重复下落的空间界与单串船构造

原文标识：`general/cascade-space.md`。

对任意整数k≥1，存在全过程使用 **n=2k+6象限、H=5k+1层** 的可制作起点S，使F的前k次调用均改变图形，之后稳定。F是一次重新分组和下落，可由堆叠一层纯晶体实现。k=3得到12象限、16层，来自用户截图`29d73df112fe77b9f06aca7dc2d1821f.png`的单串船机制。

这个结果给出可行上界。它没有证明象限数或层数最小，也没有证明最终成品的全部制作路径都必须包含k次下落。下面同时证明准备形可制作，不能只把截图中的初始网格当作原料。

<a id="s05-03-h1"></a>

### 1. 最小化的对象

记d(S)为最小非负整数r，使F^(r+1)(S)=F^r(S)。定义可行集合：

`E_k = {(n,H)：n为偶数，存在在这些参数下可制作的S，且d(S)=k}`。

这里H是整个制造过程的层数上限，包含辅助料。分别定义：

- n_min(k)：E_k中最小的n，允许H增长。
- H_min(k)：E_k中最小的H，允许n增长。
- 联合空间界：E_k中不能同时降低宽度和高度的参数对。

这三个问题不同。最小宽度和最小高度可能由不同构造达到。已证构造的比较为：

| 构造 | 象限n | 高度H | k=3 |
|---|---:|---:|---|
| [逐级加宽框架](#s05-01) | 4k+6 | 6k−1 | 18×17 |
| [双半形及顶部互阻环](#s05-02) | 4k+8 | 5k+6 | 20×21 |
| 本页单串船 | 2k+6 | 5k+1 | 12×16 |
| [同列复用](#s05-04) | 8 | 6k−1 | 8×17 |

本页构造对所有k≥1同时减小双半形方案的两个参数；对k≥3也同时减小逐级加宽方案的两个参数。k=2与后者等高，k=1则以增加一层换取减少两个象限。

<a id="s05-03-h2"></a>

### 2. 准备形P的参数定义

所有坐标从0开始。N表示普通块，G和B分别是绿色、蓝色普通块；C为要保留的晶体，R为辅助晶体。晶体颜色不阻止融合，C/R的分离必须靠普通块或空位。可分别取cb/cr；普通块可取Su、Sg、Sb。

令u=2k+4，因此q(u+1)是最后一个象限，始终为空。准备形P无针，所有未指定格为空：

1. 第0层：q0至qu全R。
2. 第1层：q0至qu全R，再把q0、q4改为N。
3. 对j=0至k−1，令a=2j、b=2+5j，放下表的三层船；每层另在q(a+6)至qu填R。j>0时，在(a−1,b)另放B。

```text
              a a+1 a+2 a+3 a+4 a+5
b+2           C  .   N   N   C   N
b+1           C  .   G   .   C   N
b             C  N   N   N   C   N
```

4. 每个非顶级船上方补两层：
   - b+3层：q(a+2)至qu全R，再把q(a+4)改为N。
   - b+4层：q(a+3)至qu全R，再把q(a+6)改为N；另放q(a+2)的N。
5. 最顶层H−1=5k只放qu的R。

qu从地面到最高层都是R。所有辅助R经底部两层、船右侧填料或船间填料连到这根柱。每根目标三C柱的上下及侧面由N或空位隔开，不与R融合。

<a id="s05-03-h3"></a>

### 3. P能由基础料制造

使用[列条件A及通用角](03-general-construction.md#s03-03)和[递归外侧脚手架](03-general-construction.md#s03-04)，证明两份半形都具有制造证书。

<a id="s05-03-h4"></a>

#### 列条件

P没有针。每个非空偶数列都是从地面开始的连续N/C柱，因此自动满足A。

奇数列中可能位于两段晶体之间的空位，仅是某艘船局部a+3列的中层空位。其下是底条N，上是顶帽N；更低的相邻C紧邻底条N。因此任何这样的晶体间空隙都有两个N隔断，下C正上方非空。其余空位位于该列最高C以上，不增加晶体间隙条件。所有列均满足A。

<a id="s05-03-h5"></a>

#### 切向与静止证书

记半宽w=k+3：

- w为奇数时，选两份半面q0至q(w−1)、qw至q(n−1)。
- w为偶数时，选q1至qw、q(w+1)至q(n−1)再接q0。

这保证每个保留的非空奇数列都与其右侧偶数列在同一半面内；环绕的q(n−1)为空，不会产生例外。

由第2节格位可逐行看出：每颗奇数列格的右邻偶数格都非空。偶数列连续触地，因此这些格有沿水平粘连及直接下方阻挡到地面的支撑路径。两份半形全部静止。

对每份半形按列序从左剥离。任何保留的奇数格仍保留其右邻偶数列；保留的偶数列仍连续触地。环绕半面末端的q0也是连续触地柱。新增全高N助手同样连续触地。即使新增接触合并旧组，沿上述支撑路径向地面追踪仍能到达地面，不会把全部支撑吞成一个悬空环。因此所有递归中间半形都静止。

列A和全部中间静止证书满足递归脚手架的恢复条件。由无C基例反向制造两份半形，再交换拼合，得到P。各输入仅占自己要保留的半面，预切不删目标C；拼合后允许R重新融合成全图辅助分量。全过程使用同一n、H。

<a id="s05-03-h6"></a>

### 4. 一次Pin释放全部船

对P执行Pin。qu的最高R超高，整个R融合分量删除；全部目标C仍在高度上限内。地面原本q0至qu都有格，所以这些列各得到一根地面针。

令船的新底层h_j=3+5j。删除R后，每艘船的外框与内部G互相阻挡，目标三C柱不移动；普通碎片的落点为：

| 来源 | Pin抬高后 | 最终落点 |
|---|---|---|
| 原第1层q0、q4的N | 第2层 | 第1层，受地面针支撑 |
| 每个非顶级b+4层q(a+6)的N | b+5层 | 第1层，受地面针支撑 |
| 每个非顶级b+3层q(a+4)的N | b+4层 | h_j+3，受该船右C柱支撑 |
| 每个非顶级b+4层q(a+2)的N | b+5层 | h_j+3，落在该船内部顶帽上 |

其余目标N/C原位抬高一层，船底左侧B随外框保持。于是D=Pin(P)由以下部分组成：

- 地面针q0至qu。
- 第1层N：q0、q4、q6、…、q(2k+2)。
- k艘三层船，位置(a_j,h_j)=(2j,3+5j)，三层格位仍按第2节表。
- 非顶级船在h_j+3另有q(a_j+2)、q(a_j+4)两颗N。
- j>0时，船底左侧(a_j−1,h_j)有B。

各船仍由外框和内部G互阻，D静止。顶级没有h+3的两颗N；它的顶帽正好位于H−1。

再Stack一颗位于顶级q(a_top+1)的普通块。该列在顶级中、顶层为空，底条将上料接在h_top+1。新块连到左C及内部G，本次不重新合组。所得S保留6k颗C，且顶级将在下一次F失稳。

制造主线为：`两份脚手架半形 → Swap得P → Pin得D → Stack单N得S → F重复k次`。准备阶段的Pin不计入d(S)。

<a id="s05-03-h7"></a>

### 5. 为什么恰好需要k次F

第1轮重新分组时，顶级外框与内部G被启动块合成一个无外部下方支撑的组。该船两根三C柱共六颗C碎裂。

若还有下一级，碎裂船底左侧(a−1,h)的B成为单格。下一级左柱在a−2，底层在h−5，内部G在q a。B穿过下一级中层的缺口，被其底条接在(h−4)层，恰连接下一级左C与G。该接触本轮不重新合组，下一级留到下一轮才碎。

还需排除别的落料提前越级或把船锚到地面：

1. **底条挡住上方宽碎片。** 对最高未碎船(a,h)，上方第s级的三N底条占q(a+2s+1)至q(a+2s+3)，落在h+3s+1；触发块与G组成的两格条在h+3s+2，顶帽在h+3s+3。非顶级原有内部上方单N在h+3s+4。第一条由未碎船右柱上方的N接住，之后形成重叠阶梯；它们不能穿过未碎船的底条进入更低一级。顶级少一颗内部上方单N，只减少阶梯最上面的载荷，不改变下面三条的接住关系。
2. **右侧三N尾柱不接触未碎船。** 第j级尾列为2j+5，落到地面针上的第1、2、3层。若第l级尚未碎且j>l，则尾列至少比该船右C列2l+4靠右三列。它不会在同层粘到未碎的船。最右尾列2k+3与q0之间还隔着q(2k+4)、q(2k+5)，环绕边界也不接触最低船。
3. **右柱上方单N不接触未碎船。** 它落在对应第1层N上，最高到第2层；全部船底至少在第3层。同列的这颗N仅在自己的船碎裂后才下降。
4. **底部保留空隙。** 最低船底h_0=3，其C下方只有第1层N，第2层为空。地面针和低处N不能阻止已接通框架开始下落。

因此每轮恰好失去一级的六颗C，并且只为下一轮建立一次新的接通关系。最后只剩普通块和针，本次物理结算已使它们落稳，重新分组不会把较低层的支撑变成同一无C组内部的格。

故`c(F^r(S))=6(k−r)`，0≤r≤k，且`F^(k+1)(S)=F^k(S)`，即d(S)=k。

### 7. 已知下界与尚未证明的最小性

由[晶体数进展量](01-foundations.md#s01-07)，每次改变结果的F至少损失一颗C，所以任何(n,H)∈E_k都满足k≤c(S)≤nH。这是很弱的面积必要条件，不能分别推出线性的宽度下界或高度下界。

还有两个与k无关的必要条件，适用于k≥1：

- **n≥6。** [两象限定理](03-general-construction.md#s03-05)与[四象限任意H的K定理](01-foundations.md#s01-06-h7)表明，这两种宽度的全部可制作输出均静止，不能提供非平凡F。这里只考虑偶数象限。
- **H≥3。** H≤2时，地面组固定；第1层C若正下方为空就违反列条件J，因此每个非触地的含C组有地面格阻挡。无C组由性质B同样有地面支撑。所有组都静止。

本页构造给出n_min(k)≤2k+6；结合[八象限同列复用](#s05-04)，可进一步写成：

`6≤n_min(k)≤8，3≤H_min(k)≤min(6k−1,5k+1)`。

这些上下界尚不相等。同列复用已证明固定八象限、允许高度增长时可以实现任意有限轮；四象限的非平凡纯重新结算已被排除。剩余宽度问题是六象限能实现哪些轮数；在偶数象限范围，n_min(k)只能是6或8。更低准备高度及联合空间最优值仍未证明。

“某个最终图形在所有制造方法中至少需要k次Stack”和“必须遵守给定Pin/Stack交替序列”还要量化全部准备起点、上料及配方。本页构造最后不含C，可以另用普通块和针的逐层程序制造，因此它本身不能证明这两种全局工序下界。

证据为截图逐格转写、参数化格位定义、既有角/脚手架定理及人工下落归纳。没有执行物理模型、枚举、测试或游戏验证；原有Python求解器、电路及蓝图保持原版本。

## 05-04 八象限复用同列的任意有限次下落

原文标识：`general/reused-column-cascade.md`。

用户提供的`fe41701d9954ce1cd32d915a2c4d3d94_720.png`展示八象限、五十层的重复单元。核心改进是在每个上级框架的底条中加入一颗晶体；碎裂时底条分开，产生一颗能独自穿过下一级顶帽缺口的普通块。因此级联不需要横向错位。

**对任意k≥1，固定n=8、H=6k−1，就存在可制作起点S，恰经k次重新结算F后稳定。** 制造全过程也在相同高度上限内。由此固定八象限、允许高度增长时，稳定轮数没有统一常数上界；八象限是否最小仍未证明。

本页给出省去截图顶部三层支撑结构后的构造。F仍表示一次重新分组和下落，可以由Stack一层纯晶体实现。结论针对给定起点的稳定轮数，不是最终成品在所有制造路径中的最少Stack数。

<a id="s05-04-h1"></a>

### 1. 重复单元与初始图形

象限q0至q7环绕，q7与q0相邻；层号从0开始。C表示晶体，N表示普通块，空位用`.`表示。各级由低到高编号j=0至k−1，底层h_j=2+6j：

```text
层          q0 q1 q2 q3 q4 q5 q6 q7
h_j+2        C  N  N  .  C  N  N  N
h_j+1        C  .  N  .  C  .  .  N
h_j          C  N  X  N  C  N  N  N
```

最低级j=0取X=N，其他级取X=C。这颗上级底部C就是把传递块分离出来的格。

另放：

- 地面q0、q4各一颗N。
- 每个非顶级在q0、q4的h_j+3、h_j+4各放N；h_j+5全空。

未指定格为空，称所得准备形为D。顶级最高层为6k−2，因此只需H=6k−1。

每级两根三C柱通过底条和顶帽连接成外框A。q7的中层N经环绕边界连到q0的中层C，也属于A。中层q2的N是独立组I：I被底部X阻挡，A的顶帽被I阻挡。两个组互相支撑。地面和柱顶补N也静止，故D静止。

对D堆叠一颗q3单N。它穿过顶级顶帽缺口，落在h_top+1，连接q2的I和q4的C。本次堆叠不合并新接触，所得S保持全部晶体；下一次F才使顶级失稳。

<a id="s05-04-h2"></a>

### 2. 准备形D的制造证明

先检查[列条件A](03-general-construction.md#s03-03)：

- q0、q4的三C段之间为`N N .`；最下段下方最近格是地面N。晶体间隙满足两个N隔断，且下C正上方非空。
- q2的各颗X=C之间有中层N和顶帽N，再接三个空位。最低级的X为N，所以第一颗C下方最近非空格仍为N；下C正上方也是N。
- 其余列无C，且全图无针。

按标准切向分成q0至q3、q4至q7两半：

**左半形。** q0三C柱连接上下帽，q2中层N与它互阻；底部q3的N接在X右边。各级静止，q0柱顶补N及地面N也静止。从左剥离q0、在外侧q4补全高N柱后，各级底条通过q3接到助手，X因而有地面支撑；中层q2的N受X支撑，顶帽受中层N支撑。继续剥离q1、q2后，所有保留格仍沿这些关系或直接接到助手，最终进入无C基例。

**右半形。** q4三C柱连接上下帽，q7的中层N在独立半形中是另一个组，二者互阻。从左剥离q4、在q0补全高N助手后，所有保留水平条及q7中层N都通过q7接到助手，成为稳定无C基例。

两半的固定左剥离全过程都静止，列A成立，所以[递归外侧脚手架](03-general-construction.md#s03-04)分别给出基础料制造证书。两半各自只占最终保留半面，Swap的预切不会删除任何目标C。拼合后右半的中层q7加入完整外框，左半的中层q2仍独立，完整D保持静止。

准备、拼合、单N启动及后续F均只使用8象限、H层。没有把悬空初始网格当作基础原料，也不需要保留截图顶部的针环。

<a id="s05-04-h3"></a>

### 3. 一颗晶体怎样代替逐级加宽

考虑非最低级已被接通，底层为h。重新分组后A、I和启动格合成一个无外部下方阻挡的组，开始下落，七颗C全部碎裂。

底条由：

`C N C N C N N N`

变成三个普通片段：q1单N、q3单N，以及q5至q7的三N条。下一级底层为h−6：

- q1单N被下一级q1顶帽接住，不能进入内部。
- q5至q7的三N条被下一级右顶帽接住。
- **q3单N穿过下一级顶帽q3的空位，落在下一级中层h−5。** 它被下一级q3底条接住，在同层同时邻接q2的I与q4的C。

这恰好在相同象限建立下一次触发。下一级本轮仍按旧组互阻，要到下一轮重新分组才会碎裂。

原方案靠每级横向移动，让较宽底条避开下一级顶帽；这里靠底条晶体碎裂产生单格，所有级都可以复用q3的同一条下落通道。

<a id="s05-04-h4"></a>

### 4. 堆积碎片为什么不使连锁提前停止

对当前最高未碎单元，除这次新释放的q3底部单格外，所有上方落料都被它的顶帽或两根C柱挡在单元顶层以上：

1. 左侧普通片段包含q1或q2。这两列的顶帽都非空，所以它们不能进入中层缺口。
2. 已经用过的q3触发格在重新分组后与q2的I相连。当前单元碎裂后它成为q2/q3两格条；q2顶帽会挡住它，不会让同一触发格连续穿过多级。
3. 右侧片段仅在q5至q7，下面有完整右顶帽阻挡；原中层q7单N也被q7顶帽阻挡。
4. q0、q4的柱顶补N只沿本列下降，被下一根保留C柱挡住。它们不能横移到中层q3。
5. 来自更高层的碎片已被前一单元的顶帽挡住；该单元碎裂后，其片段仍满足上述列区间限制。普通块重新合并只会扩大水平占用，不会把一个同时占q2/q3的片段缩成能通过缺口的q3单格。

因此其他碎片始终在最高未碎单元顶层以上，没有机会从侧面把它的C柱连接到地面。唯一进入其中层的是新释放的底部q3单N，它的下方底条属于即将合并的外框本身，不会新增外部支撑。

每个待触发单元的底层正下方也留空：非最低级的前一级补N只到h−2；最低级地面N上还有第1层空隙。接通后的外框均可以开始下落。

归纳得到：每轮恰好碎一个单元。上面k−1级各七颗C，最低级六颗C，所以

```text
c(S) = 7k−1
c(F^r(S)) = 7(k−r)−1     （0≤r<k）
c(F^k(S)) = 0
F^(k+1)(S) = F^k(S)
```

最终只剩普通块，本次结算已使它们落稳。于是从S开始恰需k次F。

<a id="s05-04-h5"></a>

### 5. 与截图及空间最小化的关系

截图含八个级联单元，占第2至46层；最上面第47至49层另外保留一个三C及针的支撑结构。主级联在这些顶部格之下完成。省去顶部三层，采用第1节的单N上料，八级只需8象限、47层；三次代表为8象限、17层。

截图第1节点的q3、第49层单N既没有水平邻居，也没有正下方格，不符合[可制作输出的性质B](01-foundations.md#s01-07-h1)。它适合表示预先悬放的启动块，不能直接当成已造出的原料。游戏制造时用单N的Stack把启动块送入顶级缺口，稳定轮数从这次启动之后计数。图中第1到第2节点是启动块落位；之后八次单元碎裂才对应本页的k=8。

本页的制造证明和任意k归纳以去掉顶部结构、明确用Stack启动的D/S为对象。没有据此证明截图最终保留三C目标的全局最少工序。

| 构造 | 象限数 | 高度上限 | k=3 | k=8 |
|---|---:|---:|---:|---:|
| [错位单串船](#s05-03) | 2k+6 | 5k+1 | 12×16 | 22×41 |
| 同列复用 | 8 | 6k−1 | 8×17 | 8×47 |

同列复用把宽度从随k增长改为常数。k≥3时，它比错位方案高k−2层，属于宽度与高度的取舍。占用网格的规模从O(k²)变成O(k)，但这不是游戏电路建筑数量的实测结果。

对[空间最小化定义](#s05-03-h1)，本构造给出所有k≥1的`n_min(k)≤8`。[四象限任意H的K定理](01-foundations.md#s01-06-h7)连同两象限定理，进一步排除这两种宽度的非平凡F，所以`6≤n_min(k)≤8`。偶数象限下只剩6或8；六象限能达到哪些轮数，以及高度最小值，仍未证明。

证明依据为截图分段读取、既有列/脚手架定理及人工分组、阻挡归纳。没有运行测试、物理模型、枚举或游戏，没有修改Python求解器或蓝图。
