# 四象限五层图形的覆盖性研究

本文研究如何证明一个 Shapez 2 方案覆盖全部可制作图形。基础输入是任意不含结晶的单层图形，包括普通形状、合法配色和顶针组合。对象为四象限、最多五层，空的底层或中间层保留位置。

证据方式为文献核对、静态源码阅读和逐步手推。本轮没有运行枚举、求解器、游戏或蓝图仿真。“证明”均指在写明的操作规则下的数学论证；尚未完成这些规则与当前游戏版本的逐项核对。

## 主要结论及强度

| 结论 | 强度与限制 |
|---|---|
| 可制作性可以与普通形状种类、颜色分离 | 在第 2 节规则下给出构造证明，包括结晶配色；不保证相同工序数或最短路径 |
| 不含结晶的图形，可制作当且仅当稳定 | 在第 3 节规则下证明；可直接按层检查支撑 |
| 一个最终保留的晶体，从产生后到成品，沿自身经历的路径最多经过四次顶针 | 在第 4 节规则下证明，适用于两种堆叠模型；不限制产生它之前及其他支路上的操作 |
| “可分起点 + 最多四次顶针 + 最多五段堆叠”足够覆盖含晶体结果 | 第 5 节的条件定理：依赖堆叠可约化为基础块堆叠，且起点集合覆盖所有可达半形 |
| 所有上料中的晶体都会在堆叠时破碎 | 在保留循环支撑、只因跌落而碎裂的模型中不成立；第 6 节给出手推见证 |
| A／AC／B／BC 或某台 TMAM 已覆盖当前游戏全部图形 | 尚未证明 |

## 1. 覆盖性究竟需要证明什么

记基础输入集合为 B，合法操作为 O，可制作集合 R 是包含 B 且对 O 封闭的最小集合。若方案覆盖集合为 C，证明 B 包含于 C，且每种合法操作作用于 C 内任意合法输入后仍落在 C，就得到 R 包含于 C。

这是对制造树的归纳：基础输入是叶子，机器操作是内部节点，输出是根。双输入机器需要同时考虑两个输入，不能仅检查一个输入和固定辅助材料。实际工厂重复生产同一部件，可以在有限制造树中复制相应子树。

仅证明封闭性可能把不可制作图形也收入 C。若还要把 C 当作精确可制作性判定，需要反向证明 C 包含于 R，例如给出每类的构造方法。若要证明某个具体程序覆盖 C，还需要证明其判断、分支选择和终止性；分类定理不会自动证明代码正确。

## 2. 颜色与普通形状种类可以抽离

### 2.1 使用的规则

1. 普通形状的具体种类和颜色不影响支撑、连接、碰撞、旋转、跌落、切割及截高行为。
2. 晶体粘连和连锁碎裂不区分颜色。
3. 结晶机把当前高度以内的空位和顶针变成指定合法颜色的晶体，保留已有普通形状和晶体。
4. 基础单层输入可以包含所需普通形状及其合法颜色。晶体颜色仅限游戏允许通过结晶生成的颜色，不能把语法可解析的颜色自动当成可生产颜色。
5. 除结晶外，各操作对既有单元只做移动、保留、删除或普通染色；没有基于颜色的物理分支。

群内 `shapez.cpp` 的 `Type` 注释给出类似的颜色消除思路，其物理实现不保存颜色。这是静态实现证据，不能替代对当前游戏规则的核对。

### 2.2 任意配色的紧图形可以制造

称高度 h 内四个象限全部由普通形状或晶体占满的图形为“紧图形”，即没有空位和顶针。任意 h 不超过五的紧图形，都可以指定每个普通单元的种类、颜色，以及每个晶体的合法颜色。

构造单个目标列的方法如下：

1. 由下到上处理每一层。其他三个象限始终填普通辅助形状，形成完整辅助列。
2. 目标格要普通形状时，堆叠相应基础层；目标格要晶体时，先在该格放顶针，其他三格放普通形状，再执行所需颜色的结晶。
3. 已完成的所有格均为普通形状或晶体，所以这次结晶只改变新加入的目标顶针，不改变之前各层的配色。
4. 完成 h 层后，通过旋转和切割分离目标列。切线另一侧只有普通辅助形状，没有与目标列连接的辅助晶体，因而不会沿切线引发目标晶体碎裂。
5. 目标列每一层都非空，自底向上稳定。先把两个相邻目标列组合成半形，再把两个半形组合起来。各次切线经过待保留产物外侧的空区域，不需要切断已组合部分内部的晶体连接。

这证明了整个紧图形的任意合法配色可制造，而不只是单个晶体格可染色。

### 2.3 制造树替换证明

给定任意可制作结构的一棵制造树，给最终普通单元和晶体单元指定任意合法标签：普通单元的种类与颜色、晶体的颜色。

从根往叶子追溯这些标签。对非结晶操作，每个保留的输出单元来自某个输入单元，给该输入单元分配相应标签即可；最终会被删除的单元任意赋值。原来的普通染色步骤可以省略，把要求的颜色提前赋给对应原料。

遇到结晶节点时，它的输出是紧图形。用 2.2 的构造直接制造这个节点所需的全部标签，替换该节点及其之前的子树。继续保留后面的结构操作。由于物理规则不依赖这些标签，各次切割、碎裂、跌落等结果的结构不变。

同一原料供给两个支路时，可以分别生产两份、赋予不同标签，不要求一个物理单元同时具有两种颜色。由制造树归纳得到：

> 在上述规则和合法材料范围内，一个结构只要可制作，其任意普通形状种类与配色组合也可制作。

反方向只需擦除标签。因此“擦除颜色和普通形状种类”对可制作性是精确的化简，而不仅是必要条件。它不证明原 TMAM 能接受所有颜色，也不保证原制造路径直接换颜色就仍然有效；制造路径可能需要替换。

另一个直接结论是：可把每棵制造树中靠近输出的结晶节点替换成预制紧图形。紧图形仍需用上面的合法方法制造，不能把它们未经解释地新增为天然原料。

## 3. 无晶体图形的精确判定

普通形状只在同一层与相邻普通形状粘连；顶针不粘连。没有晶体时，每个最大粘连组都在一个水平层中：它或者是一个普通形状连通块，或者是单个顶针。

对每个非底层单元组，检查其占据的象限中是否至少有一个在下一层非空。顶针是单格组，所以要求正下方非空。底层单元组直接受地面支撑。

这个条件对稳定性既必要又充分：组之间的支撑边严格从高层指向低层，不可能成环。每个非底层组只要有下一层支撑，最终就有一条支撑链通向地面；反之，缺少直接阻挡的组会下落。

对满足条件的图形，从底到顶依次堆叠每个普通连通块和每个顶针。制造到第 h 层时，下方各层已经到位，该组恰好落到目标高度。同一层不同组占据不同格位，不妨碍此构造。

因此，在机器输出会完成重力结算的规则下：

> 无晶体图形可制作，当且仅当它满足上述稳定性条件。

这部分不需要全图形数据库，也不需要复杂的角分类。后续覆盖性困难可以集中在含晶体的图形上。

## 4. 最终保留晶体的高度不变量

额外使用两条规则：晶体只要随所在组下落就会碎裂；顶针把原图形整体上移一层，再截高和结算重力。形状中的底部空层不能被自动删除并重新编号。

选择成品中的一个晶体，沿制造树回溯到产生它的结晶操作。这个晶体此后不能经历任何向下移动，否则它不会保留到成品。旋转不改变层高；切割和交换也不能把一个保留晶体移到更低层。

每次顶针都会把它的层号加一。若它随上料参加堆叠且存活，初始放置还会使其层号增加；在“先删除上料晶体”的规则中，这种存活分支不存在。

故对这条单元路径，有：

`最终层号 >= 产生时层号 + 产生后经历的顶针次数`

最终层号不超过五，产生时层号至少为一，所以顶针次数最多四次。更精确地，最终处于第 h 层的晶体，产生后最多经历 h−1 次顶针。

这个结论不依赖颜色，也不要求支撑图无环。它限制的是某个最终晶体从产生之后经历的那条路径，不能据此声称整座工厂最多使用四次顶针。其他支路、结晶之前的准备、只用于临时支撑而最终碎掉的晶体，都可能有更多操作。

若某段尾部流程只包含顶针和不含晶体的基础料堆叠，则所有最终晶体都已经存在于该段的起点。记成品最低晶体层号为 m，整段顶针次数满足：

`顶针次数 <= m − 1 <= 4`

特别地，成品有第一层晶体时，这种尾部流程不能包含任何顶针。

## 5. 不必先证明所有堆叠都能移到最后

### 5.1 相对起点集合的条件定理

令 H 是“确实能够制造并独立保留下来的半形”集合，包括旋转后的方向。由 H 中两个半形在合适方向交换得到的形状，连同单独半形、基础输入和紧图形，组成起点集合 A。

这里的 A 是为论证定义的集合，不直接等同于任何文档中仅凭半边稳定性判定的 A 类。两个半边稳定，不足以证明两个半边都可制造。计算或刻画完整 H 仍是独立的证明义务。

再假设以下堆叠约化成立：

> 任意双输入堆叠的结果，都可以从同一个下料出发，改用若干次不含晶体的基础块堆叠得到。

在“先删除上料所有晶体”的堆叠模型中，可以这样论证约化：去掉上料晶体后，只剩单层普通连通块和单个顶针；按其原始层高从低到高落入下料。相互占用同一象限的块不能越过彼此；同层不同块占据的格位不相交。已落稳的块不会因加入后续块失稳。截高只删去新加入且超过上限的非晶体单元，不改变原下料。

在该约化前提下，跟随制造树的下料支路向前回溯：

- 遇到结晶，输出是紧图形，属于 A。
- 遇到切割，保留产物是可制造的独立半形，属于 A。
- 遇到交换，输出由两个已经切割、落稳的可制造半形拼成，属于 A。
- 若一直回溯到基础输入，也属于 A。
- 中间所有堆叠可以约化为基础块堆叠；旋转可通过同步旋转材料与切割方向吸收；标签问题由第 2 节处理。

所以每个可制作结果都存在“从 A 出发，只经过顶针和基础块堆叠”的制造尾部。

### 5.2 有限阶段形式

若结果含晶体，第 4 节立即把尾部中的顶针次数限制为四次以内。记 S* 为零次或多次基础块堆叠，P 为一次顶针，制造尾部一定具有下列某一种形式：

```text
A → S*
A → S* → P → S*
A → S* → P → S* → P → S*
A → S* → P → S* → P → S* → P → S*
A → S* → P → S* → P → S* → P → S* → P → S*
```

这是对任意尾部按照顶针位置分段，不需要把堆叠跨过顶针重排，也不需要先证明只顶破一次就够。

每段 S* 内没有截断原下料、破坏原晶体或移动既有单元的操作。删除没有改变图形的堆叠后，每次有效堆叠至少增加一个格位；最多二十个格位，所以每段至多二十次有效堆叠。得到一个宽松的证书长度上界：五段共一百次有效堆叠，加四次顶针。这个上界从已经取得 A 中起点开始计算，不包含制造起点的成本。

此上界只是有限性的证明，不代表按所有基础块组合搜索会很快，也不表示实际需要这么多操作。它比未经证明地固定某个很小的工序数更有依据。

要把这个条件定理用于实际游戏，仍需证明完整 H，并核对堆叠约化是否适用于游戏的循环支撑行为。即使二者成立，也只证明上述较宽流程覆盖；要缩成“主体 → 一次顶破 → 最后回堆叠”，还需额外定理。

### 5.3 顶针与堆叠不能直接交换顺序

取基础输入 `X = Cu------`、`b = --Cu----`，短代码按从底到顶书写。

- 先堆叠 b，再顶针，得到 `P-P-----:CuCu----`。
- 先对 X 顶针，再堆叠 b，得到 `P-Cu----:Cu------`。

前一种顺序先让两块并排落在地面，顶针会在两块下方加针。后一种顺序只在 X 下方加针，随后 b 仍能落到地面。两者不同，完全不需要晶体或截高就能看出差异。

因此，操作约化若要改变这两个操作的顺序，必须允许并证明相应的材料或辅助结构变换；不能直接使用交换律。这个例子不否定可能存在的其他等价制造路径。

## 6. 循环支撑暴露出的模型差异

### 6.1 两种堆叠描述

- everain《MaManalysis》的操作 9 先把上料晶体替换为空，再堆叠和结算。
- WyuCnk 的 1.3.3 节描述为：下料、一个空层、上料合并，执行下落、截高、再下落。1.2.2 节同时介绍了最大粘连组互相阻挡造成的循环支撑。
- 群内 `shapez.cpp` 固定为四层。`supportedPart()` 注释明确说实现从地面搜索，与游戏的循环支撑行为不同；`stack()` 则假定上料晶体已全部破碎。

不能把这些描述直接视为同一套完整五层物理。尤其不能只从最终结果中过滤循环支撑，便假定中间制造过程也从未依赖它。

### 6.2 按完整粘连组下落规则手推的见证

设上料 U 为：

```text
crCu----:crP-----:crCu----
```

仅画前两个象限，底层在下：

```text
第 3 层   晶  图
第 2 层   晶  针
第 1 层   晶  图
```

三个垂直晶体和上下两块普通形状连成一个最大粘连组 G，中央顶针是独立组 p。G 的上方普通形状被 p 挡住，p 被 G 的下方普通形状挡住，形成 G → p → G 的支撑环。

U 本身有合法构造：分别制作连续三层的晶体列和“普通、顶针、普通”列，两列均独立接地稳定；选择切线方向把它们交换到相邻象限。既有晶体列外侧为空，不会被切碎。

再取单层下料 `D = ----Cu--`。按“下料 + 空层 + 上料”放置，U 整体提高两层。在保留循环支撑的逐组下落规则下，G 与 p 仍互相阻挡，都无法下落；最高层恰好为第五层，没有截高。因此手推结果为：

```text
----Cu--:--------:crCu----:crP-----:crCu----
```

上料的三个晶体全部保留。若从相同 D 出发，只堆叠不含晶体的基础块，根本不可能增加晶体，因此无法复现这一次操作的结果。

该构造恰好需要五层容纳“一层下料、一个空层、三层环结构”。四层实现无法直接容纳同一见证，不能据四层结果排除这类五层差异。

这否定的是“在这种物理模型下，可以把任意上料堆叠局部替换成基础块堆叠”的说法。它没有证明这个结果不存在另一条不同起点、使用其他机器的制造路径，也没有推翻所有可能的全局约化定理。

该见证尚未在当前游戏中验证。它证明两套文字规则不能直接混用；若游戏在堆叠前确实无条件删除上料晶体，则应采用那条明确规则，此见证不会发生。WyuCnk 后续分析本来使用简化下落模型，因此不能把这个见证当成其限定范围内论证的反例。

### 6.3 支撑图还需要包含“通向环”的节点

如果使用支撑图表达循环支撑，受支撑的块应包括能沿支撑边到达地面的块，以及能到达某个支撑环的块。一个额外普通块放在环结构上方，即使自己不处于环内，也会被该环支撑。

《MaManalysis》定义 6 的文字是“存在到地面的路径，或这个块在一个环里”。按字面缺少“能到达一个环”的情形。正式采用该模型时需要澄清，不能只把强连通分量里的节点标作受支撑就结束。这里讨论初始支撑关系；完整跌落仍需在晶体破碎、分组变化后继续结算。

## 7. 还缺哪些证明

优先级最高的是确定真实堆叠规则。它决定第 5 节的局部约化能否覆盖游戏，或者是否需要额外处理保留上料晶体的循环支撑分支。

之后的证明义务已经可以拆得更具体：

1. **半形集合完备性**：每个可制造图形经合法切割得到的半形，都被 H 的定义或算法接纳；接纳的半形也有合法构造。只有“半边稳定”不够。
2. **堆叠约化的边界**：若采用保留循环支撑的模型，要么补充全局替代路径证明，要么把这类双输入堆叠保留为独立生成规则。
3. **有限阶段的完整逆向规则**：在约化成立的范围内，覆盖零至四次顶针及其间的堆叠；每个逆向分支要有正向语义依据，不能凭经验剪掉。
4. **固定 TMAM 的进一步约化**：证明这些有限阶段总能变成该机器实际支持的流程，或者明确机器只覆盖其中的子集。

颜色消除后，单角五层有 4^5 = 1024 个原始编码，半形五层有 4^10 = 1048576 个原始编码。它们只是编码空间，不代表全部可制作。若后续使用小范围计算，应核对操作的局部证明义务，尤其是半形与外部结构的相互支撑，而不是把单角全通过当成整图覆盖。
