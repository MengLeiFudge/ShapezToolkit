# 元件与时序报告

当前研究按“理论约化 → Python流程 → 元件数量与时序 → 游戏走线”推进。先比较分支、制造步骤、状态与组合通路；只有方案值得落实时才重新布局。

```bash
python -m shapez2_tmam.full_solver_circuit --report-only --output shapez2_tmam/reports/full-tail-4q5l.json
python -m shapez2_tmam.full_solver_circuit --report-only --pack --output shapez2_tmam/reports/full-tail-packed-4q5l.json
```

这两个命令只编译生产网表，不运行目标或模拟，不生成蓝图。`--pack`在报告模式只确定私有局部门配对及其时序权重。报告记录逻辑门分类、非线缆建筑数量、状态、固定配对数、DAG深度、周期和复位界。

| 方案 | 逻辑门 | 非线缆建筑 | 状态 / 慢状态 | 固定局部门对 | 快 / 慢 / 初始深度 | 周期tick |
|---|---:|---:|---:|---:|---|---:|
| [全无线](full-tail-4q5l.json) | 24571 | 164861 | 145 / 124 | 0 | 47 / 132 / 148 | 960 |
| [固定局部模板](full-tail-packed-4q5l.json) | 24565 | 142323 | 145 / 124 | 5442 | 39 / 114 / 128 | 816 |

非线缆建筑包含原逻辑门、就地常量、频道常量及无线收发器，不含导线和平台。它按当前模板直接计数，无需生成坐标。当前没有新的平台数或走线长度；固定模板的时序以最终布局保持所登记配对为前提。

计数依据：仅导出公开输出的[完整依赖闭包](../4q5l/output-cone.md)，两版均省去456个无用门，原节点及频道编号不重排；每个非内部输入增加一个常量（信号常量或频道控制），动态Ref输入再增加一个接收器；每个未吸收输出增加一个发射器和一个频道常量。成对私有门的内部输入及提供者输出均不再无线收发。与`Circuit.document`和`_place_pair`逐项对应，`building_counts`只累加这些类别，不调用布局。

设G为保留逻辑门数、I为输入端口总数、R为Ref输入数、F为压缩版可就地复制的常量Ref输入数、O为输出端口总数、P为私有门对数，则总数为`G + I + R − F + 2O − 4P`。全无线版F=P=0。固定模板版仍有37882个接收器、19213个发射器，说明跨门传输是主要体积来源之一；这个计数不宣称模板已最优。

直接有效行后继减少制造期间的空推进周期，整数PC删除八项状态；它也增加了组合门。因此不能只根据门数或单周期长短宣称所有输入更快。[同色段结晶](../4q5l/color-run-program.md)把制造ROM缩到272行，省去同色段内重复的结晶发令，状态数和周期保持。Pin搜索的最坏分支数仍是主要瓶颈。
