# 元件与时序报告

当前研究按“理论约化 → Python流程 → 元件数量与时序 → 游戏走线”推进。先比较分支、制造步骤、状态与组合通路；只有方案值得落实时才重新布局。

```bash
python -m shapez2_tmam.full_solver_circuit --report-only --output shapez2_tmam/reports/full-tail-4q5l.json
python -m shapez2_tmam.full_solver_circuit --report-only --pack --output shapez2_tmam/reports/full-tail-packed-4q5l.json
```

这两个命令只编译生产网表，不运行目标或模拟，不生成蓝图。`--pack`在报告模式只确定私有局部门配对及其时序权重。报告记录逻辑门分类、非线缆建筑数量、状态、固定配对数、DAG深度、周期和复位界。

| 方案 | 逻辑门 | 非线缆建筑 | 状态 / 慢状态 | 固定局部门对 | 快 / 慢 / 初始深度 | 周期tick |
|---|---:|---:|---:|---:|---|---:|
| [全无线](full-tail-4q5l.json) | 25408 | 170498 | 145 / 124 | 0 | 46 / 132 / 148 | 960 |
| [固定局部模板](full-tail-packed-4q5l.json) | 25402 | 147216 | 145 / 124 | 5579 | 38 / 114 / 128 | 816 |

非线缆建筑包含原逻辑门、就地常量、频道常量及无线收发器，不含导线和平台。它按当前模板直接计数，无需生成坐标。固定模板的时序以实际布局保持所登记配对为前提；完整蓝图已另行完成这项几何编译，报告命令自身仍不生成布局。

计数依据：仅导出公开输出的[完整依赖闭包](../4q5l/output-cone.md)，两版均省去570个无用门，原节点及频道编号不重排；每个非内部输入增加一个常量（信号常量或频道控制），动态Ref输入再增加一个接收器；每个未吸收输出增加一个发射器和一个频道常量。成对私有门的内部输入及提供者输出均不再无线收发。与`Circuit.document`和`_place_pair`逐项对应，`building_counts`只累加这些类别，不调用布局。

设G为保留逻辑门数、I为保留门的输入端口总数、R为这些输入中的Ref数、F为压缩版可就地复制的常量Ref输入数、O为保留门的输出端口总数、P为保留的私有门对数，则总数为`G + I + R − F + 2O − 4P`。全无线版F=P=0。固定模板版仍有39105个接收器、19913个发射器，说明跨门传输是主要体积来源之一；这个计数不宣称模板已最优。

直接有效行后继减少制造期间的空推进周期，整数PC删除八项状态；它也增加了组合门。因此不能只根据门数或单周期长短宣称所有输入更快。[共用追加](../4q5l/shared-append.md)删除重复S程序，[纯针行段](../general/pin-row-segments.md)减少可合并目标的发令；最终ROM为262行，状态数和周期保持。Pin搜索的最坏分支数仍是主要瓶颈。

本轮压缩版的逐项取舍：

| 阶段 | 非线缆建筑 | ROM行数 | 周期tick |
|---|---:|---:|---:|
| 本轮前 | 142323 | 272 | 816 |
| 来源槽增加强制C邻接位移筛选 | 143479 | 272 | 816 |
| 叶端与父帧共用S追加 | 142694 | 262 | 816 |
| 纯针行段进入ROM | 147216 | 262 | 816 |

筛选增加1156个建筑，共用追加省785个，行段选择增加4522个。总增4893个非线缆建筑，约3.4%；动态搜索和制造的收益依目标而定，未作运行性能结论。

[现有完整蓝图](../blueprints/README.md)已同步本版网表：145状态、262行ROM；未压缩25408平台，压缩563块3×3大平台、5067个占用区块、72×72区块外框（每区块20×20建筑格）、5579对局部门。读取两份蓝图中的建筑后，非线缆计数分别为170498和147216，各类别均与报告一致。静态几何编译不代表已通过游戏运行或性能验收。
